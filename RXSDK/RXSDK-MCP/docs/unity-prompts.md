# 瑞雪 SDK Unity MCP 工具提示词指南

本文档提供使用瑞雪 SDK Unity MCP 工具的提示词示例，帮助您快速接入 SDK 功能。

## MCP 工具速查表

Unity 使用统一工具 `unity`，通过 `feature` 参数指定功能模块；通过 `version` 自动识别 v1/v2，通过 `sdkApiVersion=tj` 或 `version=ruixue_tj_unity` 生成团结 OpenHarmony 版。调用格式：`unity feature=<功能名> [version=1.6.17|3.0.0|ruixue_tj_unity] [sdkApiVersion=v1|v2|tj]`

Harmony / OpenHarmony 使用独立工具 `harmony`：`harmony feature=<功能名> [version=3.7.12]`，入口为 `RXApi.getInstance()`。

| feature | 功能 | 说明 |
|---------|------|------|
| init | 初始化 | SDK 初始化代码 |
| agent | 接入指南 | 完整接入流程 |
| dependency | 依赖配置 | UPM / .unitypackage 安装说明 |
| setup | 自动化接入 | 一键接入（需 workspacePath） |
| login | 登录 | 游客/账号/验证码/第三方登录 |
| payment | 支付 | 支付功能 |
| passport | 用户通行证 | 登录/注册/指定用户信息 |
| captcha | 验证码 | 发送/校验验证码 |
| real_auth | 实名认证 | 实名认证 / 支付宝 IIFAA 实名 |
| account_binding | 账号绑定 | 绑定第三方账号，绑定/解绑手机、邮箱 |
| password | 密码管理 | 修改/重置密码 |
| deregister | 账号注销 | 申请/撤销注销 |
| social | 社交关系 | 自定义关系、黑名单 |
| friends | 好友管理 | 添加/删除好友 |
| lbs | 瑞雪 LBS 高德定位 | Android/iOS 高德定位、权限与平台配置 |
| rank | 排行榜 | 分数、排行榜列表 |
| game_area | 游戏区服 | 区服管理 |
| game_character | 游戏角色 | SetGameInfo 上报瑞雪、SetThirdGameInfo 上报三方渠道、角色管理 |
| mumu | MuMu/Yofun | Android 渠道配置、闪屏、登录、保活、角色事件 |
| share | 分享 | 分享功能 |
| feedback | 反馈 | 意见反馈、客服 |
| tracking | 数据埋点 | 埋点上报 |
| legal_ui | 法务 | 协议、隐私 |
| promo | 达人福利 | 福利码 |
| announcement | 公告/邮件 | 公告、临时维护公告、邮件系统 |
| device | 设备信息 | 设备码、配置 |
| user_center | 帮助中心 | 客服会话 |
| ad | 广告 | 激励/Banner/插屏 |
| push | 推送 | 推送服务 |
| version_check | 瑞雪版本检查 v2 | updateGameVersion 模块版本检查 |
| review | 评价 | 跳转应用商店 |

## 13. LBS 定位

> 瑞雪定位功能基于高德定位 SDK，Unity 使用 `RuiXue.LBS` 命名空间。
> `RXLBSAndroid` / `RXLBSIOS` 用于获取设备位置，不要与 `RXSocial.LbsUpdate/LbsRadius/LbsDelete` 社交 LBS 接口混用。

### Android 高德定位
```
帮我接入 Unity Android 瑞雪高德定位，包括 rxsdk_gaode 依赖、AMAP_APIKEY、定位权限、RXLBSAndroid 初始化及开始/停止定位
```

### iOS 高德定位
```
帮我接入 Unity iOS 瑞雪高德定位，包括 RXLBSKit、Info.plist 定位权限、高德 AppKey、RXLBSIOS 权限申请及获取位置
```

### Android 定时定位并上报
```
帮我使用 RXLBSAndroid 定时获取位置并上报瑞雪 LBS，定位周期设置为 60 秒
```
