### 1. 指定具体功能
```
❌ 帮我实现 iOS 登录

```

### 2. 说明使用场景
```
❌ 帮我发送验证码
✅ 帮我实现 iOS 注册场景的手机验证码发送功能
```

### 3. 提供上下文
```
❌ 帮我处理支付
✅ 用户点击购买按钮后，帮我实现 iOS IAP 支付流程，需要处理成功和失败的回调
```

## MCP 工具快速参考

| 工具名 | 功能 |
|--------|------|
| `ios_passport` | 登录、注册、指定用户信息 |
| `ios_captcha` | 验证码发送、校验 |
| `ios_real_auth` | 实名认证 / 支付宝 IIFAA 实名 |
| `ios_account_binding` | 第三方账号/手机/邮箱绑定 |
| `ios_password` | 密码管理 |
| `ios_deregister` | 账号注销 |
| `ios_iap` | 内购支付 |
| `ios_game_area` | 游戏区服 |
| `ios_game_character` | 游戏角色 |
| `ios_share` | 分享功能 |
| `ios_feedback` | 反馈功能 |
| `ios_tracking` | 数据埋点 |
| `ios_promo` | 达人福利 |
| `ios_announcement` | 公告/邮件 |
| `ios_device` | 设备信息 |
| `ios_store_review` | App Store 评分 |
| `ios_dns` | DNS 组件（阿里云/腾讯云） |
