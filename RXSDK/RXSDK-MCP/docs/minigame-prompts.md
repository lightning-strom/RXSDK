# 瑞雪 SDK 小游戏 MCP 工具提示词指南

本文档提供使用瑞雪 SDK 小游戏 MCP 工具的提示词示例，帮助您快速接入 SDK 功能。

## MCP 工具速查表

小游戏使用统一工具 `minigame`，通过 `feature` 参数指定功能模块。调用格式：`minigame feature=<功能名>`

| feature | 功能 | 说明 |
|---------|------|------|
| init | 初始化 | SDK 初始化代码 |
| login | 登录 | 微信授权登录 |
| payment | 支付 | 下单、补单、订单查询 |
| passport | 用户通行证 | 获取指定用户信息/修改用户信息 |
| captcha | 验证码 | 发送/校验验证码 |
| account_binding | 账号绑定 | 绑定/解绑手机、邮箱 |
| deregister | 账号注销 | 申请/撤销注销 |
| social | 社交 | 开放数据域、搜索账号 |
| share | 分享 | 转发/海报/消息卡片 |
| lbs | LBS 定位 | 位置上报、附近人 |
| game_area | 游戏区服 | 区服管理 |
| game_character | 游戏角色 | 角色管理 |
| feedback | 反馈 | 意见反馈、客服 |
| tracking | 数据埋点 | 事件上报 |
| ad | 广告 | 激励视频/Banner/插屏 |
| promo | 达人福利 | 福利码 |
| announcement | 公告/邮件 | 公告、邮件系统 |
| device | 设备信息 | 子渠道、IP |
