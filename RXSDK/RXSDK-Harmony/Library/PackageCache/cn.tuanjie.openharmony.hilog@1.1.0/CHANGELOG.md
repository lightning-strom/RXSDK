# Changelog
All notable changes to this package will be documented in this file.

## [1.1.0] - 2025-04-14

### Add

- 新增 Device Info 页面，支持获取已连接设备的设备信息 / Added the Device Info page, which supports retrieving the device information of the connected device.
- 新增 Performance 页面，支持获取在已连接设备上运行的应用程序的实时性能数据，包括 CPU、GPU、FPS、内存等 / Added the Performance page, which supports capturing real-time performance data of the application running on the connected device, including CPU, GPU, FPS, memory, and more.

## [1.0.1] - 2025-01-02

### Fixed

- 修复连接设备并且打开界面会卡死的问题 / Fixed the issue where the interface would freeze when connecting a device and opening the screen.

## [1.0.0] - 2024-09-30

### Added

- 首次发布 OpenHarmony Hilog Package / initial release of OpenHarmony Hilog Package
