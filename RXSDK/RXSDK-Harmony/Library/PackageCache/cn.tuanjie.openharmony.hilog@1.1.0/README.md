# OpenHarmony Hilog

## Description

The OpenHarmony Hilog package has been added to support displaying log messages from OpenHarmony devices in Tuanjie Editor, as well as performing device's information, stack trace restoration, performance data, and ArkUI Dump retrieval.

You can access this window in Tuanjie Editor by navigating to “Window > Analysis > OpenHarmony Hilog.”

If this menu does not appear, please ensure that the OpenHarmony platform is loaded and switch to the OpenHarmony Build Target in the “Build Settings” window.

You can refer to the complete user manual at: [OpenHarmony Hilog](https://docs.unity.cn/cn/tuanjiemanual/Manual/openharmony-hilog-introduction.html)


OpenHarmony Hilog 包支持在 Tuanjie Editor 中显示来自 OpenHarmony 设备的日志信息，并执行堆栈还原、获取设备信息、性能数据以及 ArkUI Dump。

可以在 Tuanjie Editor 中通过 “Window > Analysis > OpenHarmony Hilog” 来访问该窗口。

如果这个菜单不存在，请确保已加载 OpenHarmony 平台，并在 “Build Settings” 窗口中切换到 OpenHarmony Build Target。

完整用户手册可查看：[OpenHarmony Hilog](https://docs.unity.cn/cn/tuanjiemanual/Manual/openharmony-hilog-introduction.html)
