# 代码生成提示词模板

> 用于基于 API 契约文档生成多端 SDK 代码的 AI 提示词模板

## 模板结构

### 1. 基础代码生成

```
你是一个专业的 SDK 开发工程师。请根据以下 API 契约文档，生成 {platform} 平台的 {module} 模块代码。

## 契约文档
{contract_content}

## 要求
1. 严格遵循契约文档中的接口定义
2. 遵循 {platform} 平台的编码规范
3. 包含完整的错误处理
4. 添加必要的注释和文档
5. 确保线程安全（如适用）

## 输出
请生成完整的代码实现，包括：
- 接口定义
- 实现类
- 错误处理
- 单元测试（可选）
```

### 2. 多端代码生成

```
你是一个专业的跨平台 SDK 开发工程师。请根据以下 API 契约文档，同时生成 Android、iOS、Unity、小游戏四个平台的 {module} 模块代码。

## 契约文档
{contract_content}

## 要求
1. 所有平台的接口行为必须一致
2. 错误码和错误信息格式统一
3. 遵循各平台的编码规范
4. 包含完整的错误处理
5. 添加必要的注释和文档

## 输出
请为每个平台生成完整的代码实现。
```

### 3. 增量代码生成

```
你是一个专业的 SDK 开发工程师。现有代码需要新增 {feature} 功能，请根据以下 API 契约文档生成增量代码。

## 现有代码
{existing_code}

## 契约文档
{contract_content}

## 要求
1. 保持与现有代码风格一致
2. 不破坏现有接口的兼容性
3. 遵循 {platform} 平台的编码规范
4. 包含完整的错误处理

## 输出
请生成增量代码，并说明对现有代码的影响。
```

## 使用示例

### 生成 Android 通行证模块

```python
prompt = f"""
你是一个专业的 Android SDK 开发工程师。请根据以下 API 契约文档，生成 Android 平台的通行证模块代码。

## 契约文档
{read_file('common/api/20_passport.md')}

## 要求
1. 严格遵循契约文档中的接口定义
2. 遵循 Alibaba Java 开发手册
3. 使用 RXJSONCallback 进行异步回调
4. 回调切回主线程
5. 包含完整的错误处理
6. 添加 Javadoc 注释

## 输出
请生成完整的代码实现。
"""
```

## 最佳实践

1. **契约优先**：始终以契约文档为唯一可信来源
2. **平台规范**：遵循各平台的官方编码规范
3. **错误处理**：统一的错误码和错误信息格式
4. **文档完整**：包含完整的接口注释和文档
5. **测试覆盖**：生成单元测试和集成测试
