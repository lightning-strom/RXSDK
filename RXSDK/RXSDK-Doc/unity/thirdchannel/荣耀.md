## SDK集成

```json
//华为渠道库
  implementation 'com.ruixue:rxsdk_honor:${version}'
```

## 参数说明

| **参数**  | **类型** | **说明**              |
| --------- | -------- | --------------------- |
| honor_appid | String   | InitThirdSdk 接口传入 |
| honor_cpid    | String   | InitThirdSdk 接口传入      |
| sandbox_token    | String   | InitThirdSdk 接口传入  ，沙盒支付时传此参数    |
 
## 配置说明

- 打开 `settingsTemplate.gradle` 并添加以下存储库：

```groovy
allprojects {
    repositories {
        maven { url 'https://developer.hihonor.com/repo' }
    }
}
```
