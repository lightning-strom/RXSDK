## 配置说明
- <span style='color:red'>1、游戏包名称命名规范全新游戏包名使用".aligames"，仅需出一个游戏包，接入九游SDK即可，包于开放平台上传即可，已在九游上线过的游戏，保持原包名不改</span>
- <span style='color:red'>2、icon图片游戏图标需增加九游角标，角标位置在接入包内“角标logo及使用说明”文件夹下，添加角标后在AndroidManifest.xml中指定。如android:icon="@drawable/iconuc"。其中iconuc为在原游戏图标基础上制作的能表明九游渠道的图标文件。</span>
- <span style='color:red'>3、游戏包体在开放平台提审时，九游这边会对游戏包体进行重签名。游戏若有加固的，请改为支持修改游戏包，或不加固。
       <span style='color:red'> 游戏需支持SDK修改的地方：</span> <br/>
      <span style='color:red'>1）将游戏META-INF删除重签名</span>  <br/>
        <span style='color:red'>2）修改游戏assets下ucgamesdk目录</span>  <br/>
        <span style='color:red'>3）assets下添加UCGameConfig.ini文件</span>  <br/>
        <span style='color:red'>4）res下替换icon文件</span>  <br/>
   </span>
- <span style='color:red'>4.【新增】更新/接入SDK的时候，请在SDK初始化之前，先弹出游戏自己的隐私协议</span>

- 在 `src/mian/res/values/strings` 文件下
```xml
    <string name="uc_game_id" translatable="false">@your uc_game_id</string>
```
- 在 AndroidManifest.xml 配置
```xml
<!-- application 标签如果需要增加 android:allowBackup="true", 那么需要增加 tools:replace="android:allowBackup"，如果不增加这个标签则不需要设置 tools:replace的值如果有多个则用逗号分隔 形如 tools:replace="android:networkSecurityConfig,android:allowBackup"-->
<application>
    <meta-data
        android:name="uc_game_id"
        android:value="@your uc_game_id" />

    <!-- 增加app拉起相关cn.uc.gamesdk.activity.PullupActivity的声明 -->
    <activity
        android:name="cn.uc.gamesdk.activity.PullupActivity"
        android:excludeFromRecents="true"
        android:exported="true"
        android:label="PullupActivity"
        android:launchMode="singleTop"
        android:taskAffinity="游戏包名.diff"
        android:theme="@android:style/Theme.Translucent"
        tools:node="replace"
        tools:replace="android:taskAffinity">

        <intent-filter>
            <action android:name="android.intent.action.VIEW" />

            <category android:name="android.intent.category.DEFAULT" />
            <category android:name="android.intent.category.BROWSABLE" />
            <!-- 这里的格式为 ng + gameId -->
            <data android:scheme="ng3098544" />
        </intent-filter>
    </activity>
</application>
```

####  初始化第三方渠道

```csharp

Dictionary<string, object> map = new();
        
// 设置 SDK 屏幕方向
// ActivityInfo.SCREEN_ORIENTATION_LANDSCAPE 横屏（默认值）
// ActivityInfo.SCREEN_ORIENTATION_PORTRAIT 竖屏
map.put("screen_orientation", ActivityInfo.SCREEN_ORIENTATION_LANDSCAPE);

// 如果游戏已经申请了权限，不想sdk主动请求权限，避免重复弹授权弹窗被拒
// true 游戏已经弹了，SDK不需要弹出权限申请窗
// false 游戏没有弹，SDK可以按需弹出权限申请窗(默认值)
map.put("had_req_permission", false)
        
RuiXueSdk.InitThirdSdk(map, InitThirdSdkResponseDelegate, InitThirdSdkErrorDelegate);
        
    
public void InitThirdSdkResponseDelegate(string data)
{
    LogUtil.Log("EventManager", $"RequestResponseDelegate: {data}");
}
public void InitThirdSdkErrorDelegate(string data)
{
    LogUtil.Log("EventManager", $"RequestErrorDelegate: {data}");
}

```
