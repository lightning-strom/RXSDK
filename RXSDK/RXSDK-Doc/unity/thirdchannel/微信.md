- 打开Assets/RuiXueSettings/RuiXueSDK_WeiXinXcodeSetting.asset 文件，在文件中填写
```
  AppID: 您的AppID
  AssociatedDomains: 微信通用链接使用的域名。形式例如：applinks:xxx.ruixue.com
```

2. android
```groovy
    //二选一
    //不包含支付功能
    implementation " com.ruixue:rxsdk_weixin:${version}"
    //包含支付功能
    implementation " com.ruixue:rxsdk_weixin_withpay:${version}"
```

appid 在后台配置。

在 Player Settings 中勾选 Custom Main Manifest, 打开 AndroidManifest.xml, 在 \<application\> 中新增：

微信sdk 验证微信 包名、签名、AppID，三个参数要完全和开放平台配置一致。

```xml

        <!--    微信回调activity 可继承重写    -->
        <!--  android:taskAffinity  activity归属默认使用自己应用的包名   -->
        <activity
                android:name="com.ruixue.wechat.WXEntryActivity"
                android:enabled="true"
                android:exported="true"
                android:taskAffinity="com.xxx.xxx"
                android:launchMode="singleTask"
                android:theme="@android:style/Theme.Translucent.NoTitleBar" />

        <!--    微信回调activity别名类，因为微信需要回调到指定包名指定类名，所以设置别名     -->
        <activity-alias
                android:name="${applicationId}.wxapi.WXEntryActivity"
                android:enabled="true"
                android:exported="true"
                android:targetActivity="com.ruixue.wechat.WXEntryActivity" />

```
