## 5. 平台接入信息

### 5.1 Android

- **包名**：`com.ruixue.sdkdemo`
- **签名/证书要求**：
  - App 支付签名使用 `appid`、`timestamp`、`noncestr`、`prepayid` 生成待签名串。
  - 签名算法为 SHA256 with RSA，签名结果进行 Base64 编码。
- **依赖与初始化要求**：
  - 集成抖音支付 Android SDK。
  - 使用 `DyPay(activity).pay(payInfoMap, callback)` 或 Java 版本 `new DyPay(activity).pay(...)` 拉起支付。

### 6.2 支付

- **支付方式 pay_type**：`xy`
- **请求参数**：
  - `pay_type`：固定传 `xy`。
  - `order_id` / `orderNo`：[待确认 RXSDK 现有订单字段映射]
  - `amount` / `txAmt`：交易金额，星驿服务端以分为单位。
  - `ext`：透传星驿（抖音）支付所需扩展参数。
- **参数 ext 新增字段**：
  - `appid`：应用 ID。
  - `partnerid`：商户号。
  - `prepayid`：预支付交易会话 ID。
  - `package`：支付产品类型，App 支付固定为 `Sign=DYPay`。
  - `noncestr`：随机字符串。
  - `timestamp`：10 位秒级时间戳。
  - `sign`：签名值。
- **服务端预下单**：
  - 接口：`POST /onlinepay/order/prepay`
  - `payMethod=7` 表示抖音。
  - `payInfoType=APP` 表示 App 支付。
- **支付结果回调**：
  - Android SDK 回调字段包含 `resultCode`、`errorMsg`、`extraParams`。
  - `resultCode=0` 或 `3` 按支付成功展示；`1` 为用户取消；其他错误码按失败处理。
- **服务端通知/验单要求**：
  - 最终支付状态以服务端通知或验单结果为准。
