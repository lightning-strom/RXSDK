## 通用处理

| SDK | 未命中特殊分支时 | 六位码额外上报 |
|---|---|---|
| iOS | 保留原始响应和 `trace_id`，执行失败回调 | 支持按错误码配置多语言文案 |
| Android | 非零码补充 `trace_id` 后在主线程透传 | 形如 `??20??` 的六位码按网关错误上报 |
| JS | 兼容多种错误字段，保留服务端原码；渠道码可转公共码并保存 `thirdcode` | 恰好六位且形如 `??20??` 时上报 `#rx_error` |

> 注意：三个平台用于 Token 刷新的错误码并不完全一致。新增服务端错误码时，需要分别确认 iOS、Android、JS 是否需要补充分支。
