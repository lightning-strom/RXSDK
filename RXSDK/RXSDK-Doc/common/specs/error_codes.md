# 统一错误码规范

> 跨端统一的错误码定义，确保 Android、iOS、Unity、小游戏等平台错误码一致

## 统一错误结构（跨端一致）

SDK 对外失败必须可映射为统一 JSON 字段（Android/iOS/Unity/小游戏一致）：

- `code`：int - 错误码
- `msg`：string - 错误信息
- 可选字段：
  - `trace_id`：string - 追踪 ID（用于排查）
  - `thirdcode`：string - 三方错误码
  - `thirdmsg`：string - 三方错误信息
  - `data`：object - 扩展数据

### 示例

```json
{
  "code": 4000,
  "msg": "支付失败",
  "trace_id": "xxxx",
  "thirdcode": "WX_ERROR",
  "thirdmsg": "微信返回错误",
  "data": {
    "scene": "pay"
  }
}
```

## 错误码分类

### 服务端错误码（6 位整数）

- **格式**：6 位整数（如 `100001`、`200002`）
- **来源**：服务端返回，SDK 必须原样透传
- **原则**：
  - 不改写位数
  - 不复用语义
  - 不修改错误码值

### 客户端错误码（4 位整数）

SDK 3.2.x+ 约定，按区间区分场景：

| 区间 | 场景 | 说明 |
|------|------|------|
| 1000–1999 | 网络相关 | 网络请求失败、超时、连接错误等 |
| 2000–2999 | 初始化相关 | SDK 初始化失败、配置错误等 |
| 3000–3999 | 登录相关 | 登录失败、认证错误、账号相关等 |
| 4000–4999 | 支付相关 | 支付失败、订单错误等 |
| 5000–5999 | 分享相关 | 分享失败、渠道错误等 |
| 6000–6999 | 权限与未安装相关 | 权限拒绝、应用未安装等 |

### 三方错误码

- **存储位置**：`thirdcode` / `thirdmsg` 字段
- **原则**：不要将三方错误码塞进 `code` 字段
- **用途**：保留原始错误信息，便于排查

## 常见错误码定义

### 网络相关（1000-1999）

| 错误码 | 常量名 | 说明 |
|--------|--------|------|
| 1000 | `DEFAULT_ERROR` | 默认错误 |
| 1100 | `IO_ERROR` | IO 错误 |
| 1200 | `NETWORK_ERROR` | 网络错误 |
| 1300 | `TIMEOUT_ERROR` | 请求超时 |
| 1400 | `HTTP_ERROR` | HTTP 错误 |

### 初始化相关（2000-2999）

| 错误码 | 常量名 | 说明 |
|--------|--------|------|
| 2000 | `INIT_ERROR` | 初始化失败 |
| 2100 | `CONFIG_ERROR` | 配置错误 |

### 登录相关（3000-3999）

| 错误码 | 常量名 | 说明 |
|--------|--------|------|
| 3000 | `LOGIN_ERROR` | 登录失败 |
| 3100 | `PASSWORD_FORMAT_ERROR` | 密码格式错误 |
| 3200 | `ACCOUNT_NOT_FOUND` | 账号不存在 |
| 3300 | `ACCOUNT_LOCKED` | 账号被锁定 |

### 支付相关（4000-4999）

| 错误码 | 常量名 | 说明 |
|--------|--------|------|
| 4000 | `PAY_ERROR` | 支付失败 |
| 4100 | `ORDER_ERROR` | 订单错误 |

### 分享相关（5000-5999）

| 错误码 | 常量名 | 说明 |
|--------|--------|------|
| 5000 | `SHARE_ERROR` | 分享失败 |
| 5100 | `CHANNEL_ERROR` | 渠道错误 |

### 权限相关（6000-6999）

| 错误码 | 常量名 | 说明 |
|--------|--------|------|
| 6000 | `DISAGREE_PRIVACY` | 未同意隐私协议 |
| 6100 | `PERMISSION_DENIED` | 权限被拒绝 |
| 6200 | `APP_NOT_INSTALLED` | 应用未安装 |

## SDK 内部对应关系

### Android

- **`RXErrorCode`**：SDK 客户端错误码枚举
- **`RXException`**：网络/运行时类错误码

### iOS

- **`RXErrorCode`**：错误码枚举（Swift/Objective-C）
- **`RXError`**：错误对象

### Unity

- **`RXErrorCode`**：C# 错误码枚举
- **`RXException`**：异常类

### 小游戏

- **`RXErrorCode`**：JavaScript/TypeScript 错误码常量
- **`RXError`**：错误对象

## 重构原则

1. **对外 `code/msg` 语义保持稳定**
2. **新增错误码只能新增枚举值，不可复用历史含义**
3. **错误码变更需更新所有平台实现**
4. **保持错误码文档与代码同步**
