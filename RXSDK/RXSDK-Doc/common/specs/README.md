# 技术规范文档

> 跨端统一的技术规范：错误码、数据结构、命名规范等

## 📚 文档目录

### 错误码规范

- [`error_codes.md`](./error_codes.md)：统一错误码定义（服务端错误码、客户端错误码、三方错误码）

### 数据结构规范

- [`data_structures.md`](./data_structures.md)：统一数据结构定义（请求/响应格式、通用字段等）

### 命名规范

- [`naming_conventions.md`](./naming_conventions.md)：接口命名、参数命名、常量命名等规范

### 版本规范

- [`versioning.md`](./versioning.md)：SDK 版本号规范、接口版本管理

## 🔄 更新原则

1. **跨端一致**：所有平台必须遵循相同的规范
2. **向后兼容**：规范变更需考虑向后兼容性
3. **文档先行**：规范变更需先更新文档，再更新代码
