# 改动记录 - 百度渠道跨平台封装

- **日期**：2026-08-07
- **作者**：Cursor
- **影响范围**：Android 公共接口、Unity Base、Cocos2d-x、百度/MuMu 渠道文档

## 改动内容

### RXSDK-Doc/thirdchannel/baidu/start.md

- 明确百度游戏渠道仅支持 Android。
- 说明 Unity、Cocos2d-x 仅在 Android 平台启用百度渠道能力。
- 新增 `baidu_public.md`，提供 Unity 百度渠道初始化、登录、支付、退出、角色上报及渠道专属 API 接入示例。

### RXSDK-Unity 公共渠道接口

- 百度和 MuMu 不再提供独立 UPM，统一依赖 Base、Login、Pay 公共包。
- 新增 `RuiXueSdk.InvokeChannelAction`，闪屏和浮窗不再调用 `RXBaidu` / `RXMuMu`。
- Android 只需在 `rxsdk_baidu_wangxun` 与 `rxsdk_yofun` 中选择对应渠道库。
- Base Demo 新增百度/MuMu 初始化、通用闪屏和渠道浮窗调用示例。
- RuiXue.Base 导出 Android 工程时统一注入百度和 MuMu/Yofun 混淆规则。
- Base Demo 新增可见渠道功能按钮，并将 Android 渠道依赖切换为 `rxsdk_baidu_wangxun:4.0.18`。
- Base Demo 增加“渠道功能”场景入口；新渠道场景提供百度登录、百度/MuMu 初始化、闪屏和浮窗按钮。
- RuiXue.Base 导出 Android 工程时自动合并百度 FileProvider 的 `provider_paths.xml`。
- 修复 Unity `InvokeChannelAction` 回调类型与 Android `RXJSONCallback` 不匹配导致的 `NoSuchMethodError`。
- `SetThirdGameInfo` 在 iOS 提取 `roleId/serverId` 并复用 `SetGameInfo`；Cocos iOS 同步该语义。
- 百度支付示例统一调用 `RXPay.Pay`，并传入 `hq_type=baidunet`。
- 将百度 Demo 导入 `Assets/Samples/RuiXue.Baidu/4.0.0/`，并加入 Unity Scenes in Build。

```csharp
RuiXueSdk.InvokeChannelAction(
    RuiXueSdk.ChannelActionShowSplash,
    parameters,
    OnSuccess,
    OnError);
```

### RXSDK-Cocos2dx

- 新增通用 `RuixueBridge::invokeChannelAction` C++/JNI 桥接。
- 删除百度专属 Java/C++ 方法；百度和 MuMu 使用相同业务代码。
- Android 示例工程切换为百度渠道 `4.0.18`，最低 API 调整为 22。
- 新增 FileProvider 路径、混淆规则、调用示例和 `install_sdk.sh --baidu`。

```cpp
bridge->invokeChannelAction(
    ruixue::ChannelAction::SHOW_SPLASH,
    "{}",
    callback);
bridge->login(R"({"loginType":"baidunet"})", callback);
bridge->setGameInfo(roleJson, callback);
```

### 百度/MuMu Unity 接入文档

- 按小米渠道模式改为公共 Unity 包 + 单一 Android 渠道库。
- 删除百度/MuMu 专属 UPM、命名空间和渠道类调用。
- 将原 Android 文档中的 Maven、Manifest、Provider、资源路径和混淆配置复制到 Unity 渠道接入文档。
- 删除文档中的固定示例凭证，改为安全配置注入。

### RXSDK-MCP

- 百度/MuMu 模板和 preflight 改为公共 Base/Login/Pay UPM 与通用渠道 action。
- MuMu MCP 最低版本调整为 Unity 公共 UPM `4.0.2`、Android `4.0.19`。
- Unity、Android、Cocos2dx 示例不再生成 `RXBaidu`、`RXMuMu` 或百度专属桥接。
- MuMu `channel_config` 支持 Yofun Maven、APP_ID、MultiDex 和固定原生依赖。

## 验证

- Android 百度渠道：JDK 17 下单测与 release 构建通过。
- Unity：Base 静态编译和代码检查通过；编辑器占用项目，未执行 batchmode。
- Cocos2d-x：Android Manifest 合并通过；远端 Android Base 尚未包含新接口，Java 编译待新版发布后复验。
- Cocos2d-x 完整 APK 构建受既有 NDK 脚本不识别 Apple Silicon `arm64` 主机限制。
- MCP 全量测试、Go 构建和三平台本地二进制生成通过；远程服务未发布。
- 未进行真机验证。
