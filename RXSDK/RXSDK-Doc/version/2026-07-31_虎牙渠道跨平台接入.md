# 改动记录 - 虎牙渠道跨平台接入

- **日期**：2026-07-31
- **影响范围**：Android、Unity、Cocos2dx、接入文档

## 改动内容

### iOS

- 明确虎牙联运不支持 iOS，不生成伪登录或支付接口。

### Android

- Android SDK 计划版本升级到 `4.0.17`。
- 修复虎牙支付下单结果中 `biz_order_id`、`biz_sign`、`prod_name`
  与客户端模型字段未映射的问题。
- 新增虎牙订单解析单元测试并完成 Release AAR 构建。

### Unity

- 新增 `com.ruixue.unitysdk.huya` 4.0.0。
- 新增 `HuyaConfig`，渠道初始化统一调用 `RuiXueSdk.InitThirdSdk`。
- 登录复用 `RXLogin.Login` 并传 `LoginMethod.Huya`。
- 支付复用 `RXPay.Pay` 并传 `hq_type=huya`。
- 角色上报复用 `RuiXueSdk.SetThirdGameInfo`。
- 新增 `RuiXueHuyaDemo.unity` 示例场景并挂载 Demo 脚本。
- 将虎牙示例导入 `Assets/Samples/RuiXue.Huya/4.0.0`，并加入 Scenes In Build。
- 测试环境参数改为 Demo 代码常量，避免 Unity 场景反序列化覆盖为空。
- 虎牙初始化改为直接传递 Android 原生优先识别的 camelCase 参数，绕过中间配置对象。
- 导出 Android 工程时自动接入 `rxsdk_huya:4.0.17` 和 Volcengine Maven。
- 虎牙导出时移除 `rxsdk_overseas`，避免引入无关的 Google 依赖。
- 星驿原生依赖改为按渠道启用，避免注入虎牙工程。
- 移除对 `com.google.guava:listenablefuture` 的全局排除，修复
  `androidx.profileinstaller` 启动时 `NoClassDefFoundError`。
- 构建前检查 Activity 生命周期、授权结果转发。

### Cocos2dx

- 新增通用 `initThirdSdk`、`setGameInfo` C++/JNI 桥接。
- 补充虎牙登录、支付、角色上报示例。
- Android Activity 新增 `onActivityResult`、`onRequestPermissionsResult` 转发。
- Android 瑞雪依赖统一升级到 `4.0.17`。

### MCP

- iOS、Android、Unity、Cocos2dx 新增独立 `huya` feature。
- Unity 最低版本为 `4.0.0`，Android 最低版本为 `4.0.17`。
- 新增依赖、初始化和生命周期结构化 preflight，以及低版本安全升级测试。
- Unity 模板统一使用 `InitThirdSdk`、`RXLogin.Login`、`RXPay.Pay` 和
  `SetThirdGameInfo` 通用接口。

## 验证

- Android 虎牙单元测试和 Release AAR 构建通过。
- `rxsdk_base`、`rxsdk_base_ui`、`rxsdk_huya` 4.0.17 已发布到本机 Maven Local 用于联调。
- Unity 包结构、UPM 版本和 IDE 静态检查通过。
- Unity 导出的 Huya Android 工程使用 Gradle 7.2 完成 `launcher:assembleDebug`。
- Android 真机安装、启动通过，持续运行且未再出现 `AndroidRuntime`/Unity 崩溃。
- 真机确认 Huya Demo 操作面板正常显示，初始化、登录、支付和角色上报入口可见。
- MCP Go 全量测试、race test和多平台二进制构建通过。
- Cocos2dx 完整依赖构建需等待 `rxsdk_huya:4.0.17` 发布。
- iOS 不提供虎牙能力，未进行真机验证。

## 备注

- 未发布 Android Maven 或 Unity UPM 包。
- 未提交代码。

## 后续迁移（2026-08-10）

- 虎牙不再提供独立 Unity UPM，Unity 改用 Base、Login、Pay 公共包。
- MCP 最低版本调整为 Unity 公共 UPM `4.0.2`、Android `4.0.19`。
- Android 通过 `rxsdk_huya` 选择渠道，Volcengine Maven 由 Base 导出流程或
  `channel_config thirdChannel=huya` 配置。
- 初始化、登录、支付、角色上报继续使用公共 API，历史 UPM 方案仅作版本记录。
