# 改动记录 - 星驿支付跨平台接入

- **日期**：2026-07-31
- **影响范围**：Android、Unity、Cocos2dx、MCP、接入文档

## 改动内容

### Android

- 确认星驿 App/H5 支付最低版本为 `4.0.14`，当前源码版本 `4.0.16` 不降级。
- 补充 `xyh5` 兼容、`ext.is_h5` 路由单元测试。

### Unity

- 全部 RuiXue UPM 包和内部依赖统一升级到 `4.0.0`。
- 新增 `com.ruixue.unitysdk.xingyi`，提供 `RXXingYiPay.PayApp` 与
  `RXXingYiPay.PayH5`。
- Android 导出时自动加入星驿 App/H5 原生依赖和 Volcengine Maven 仓库。
- iOS 明确返回“不支持星驿支付”，不映射到 Apple IAP。

### Cocos2dx

- 复用 `RuixueBridge::pay`，补充 `payType=xy` 的 App/H5 示例。
- Android 瑞雪依赖升级到至少 `4.0.14`，并加入星驿依赖。
- iOS 对 `payType=xy` 返回平台不支持。
- 同步修正 Android 4.0.14 下 IIFAA 跳转地址接口的新签名。

### MCP

- iOS、Android、Unity、Cocos2dx 新增独立 `xingyi_payment` feature。
- 支持 `paymentMode=app|h5|both`。
- 新增结构化 preflight，检查初始化、依赖和最低版本；可安全修改时批量升级同系列固定版本依赖。
- 修正通用 Android `payment` 错误复用 RuStore 专用 preflight 的问题。

## 验证

- Android 星驿 App/H5 单元测试通过。
- Cocos2dx Android Java 编译通过。
- MCP Go 全量测试、race test和 macOS/Linux/Windows release 构建通过。
- 当前环境未安装可调用的 Unity Editor，未执行 Unity Editor 编译。
- Cocos2dx C++ 构建受现有 NDK 23 Apple Silicon 主机架构限制，未完成原生编译。
- iOS 不提供星驿能力，未进行真机验证。

## 备注

- 未发布 UPM、Android Maven 或远程 MCP 服务。
- 支付到账和发货最终以后端通知与查单结果为准。
