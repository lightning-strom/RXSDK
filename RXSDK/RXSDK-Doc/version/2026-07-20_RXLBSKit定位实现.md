- **日期**：2026-07-20

## 改动内容

### `RXSDK-iOS/RXLBSKit/RXLBSKit/RXLBSKitService.h`

- 恢复定位权限检查、权限申请、后台定位开关和定位超时公开接口。
- 保持已发布 `RXLBSKit.framework` 的方法签名兼容。

### `RXSDK-iOS/RXLBSKit/RXLBSKit/RXLBSKitService.m`

- 实现 SDK 单例及高德 Key 注册。
- 使用高德定位 SDK 实现单次定位和逆地理编码。
- 将定位结果转换为 `RXLBSModel`，并在主线程回调。
- 实现定位权限、后台定位和超时配置。

```objectivec
[[RXLBSKitService sharedSDK] getLocationInfo:^(RXLBSModel *location, NSError *error) {
    // 处理定位结果
}];
```

### `RXSDK-iOS/RXLBSKit/RXLBSKit.xcodeproj/project.pbxproj`

- 将 `RXLBSKitService.h` 和 `RXLBSModel.h` 设置为 Public Header。
- 将 framework 最低系统版本恢复为与 Podfile 一致的 iOS 12.0。

### `RXSDK-iOS/RXLBSKit/RXLBSKitDemo`

- 增加获取位置信息按钮和 SDK 调用示例。
- 增加使用期间定位权限描述。
- 通过 `AMapAPIKey` 配置项读取高德 Key，不在源码中写入凭证。

## 备注

- 本次为 RXLBSKit iOS 专属 Demo 和 SDK 实现，未修改 Android Demo。
- 定位功能需要配置与 Demo Bundle ID 匹配的高德 Key。
