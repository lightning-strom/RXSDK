# 改动记录 - MCP 苹果登录工程配置

- **日期**：2026-07-20
- **作者**：Cursor
- **影响范围**：RXSDK MCP iOS / Unity 登录

## 改动内容

### iOS MCP `feature=apple_signin_config`

- 传入 `workspacePath` 与 `targetName` 后，只修改指定 Xcode Target。
- 创建或复用 Target 已绑定的 entitlements。
- 写入 `com.apple.developer.applesignin = [Default]`。
- 为 Target 的 Debug / Release 配置绑定 `CODE_SIGN_ENTITLEMENTS`。
- project.pbxproj 与 entitlements 使用原子写入，失败时回滚。
- 普通 `feature=passport` 保持原有基础检查，不会自动添加 Apple Capability。

### Unity MCP `feature=apple_signin_config`

- 检查 `com.ruixue.unitysdk.base` 与 `com.ruixue.unitysdk.login` 依赖。
- 保留 `file:` 和 Git 类型依赖，不重写 `Packages/manifest.json`。
- 自动生成：
  - `Assets/RuiXueSettings/Editor/RXMCPAppleLoginPostBuildProcessor.cs`
- Unity 导出 iOS 时调用 `ProjectCapabilityManager.AddSignInWithApple()`。
- 优先复用 Unity 主 Target 已配置的 entitlements，避免覆盖 Push、Associated Domains、Keychain 等能力。
- 普通 `feature=login` 不会生成 Apple PostBuild。

## 验证

- `go test ./...` 通过。
- `go vet ./...` 通过。
- 多 Target、幂等、非法 entitlements、损坏 manifest、低版本依赖测试通过。
