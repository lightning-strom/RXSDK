# 改动记录 - MCP 高德 iOS 工程配置

- **日期**：2026-07-20
- **作者**：Cursor
- **影响范围**：RXSDK MCP iOS / Unity LBS

## 改动内容

### iOS MCP `feature=lbs`

- 保留瑞雪社交 LBS 的坐标上报、附近用户和坐标删除指引。
- 增加 RXLBSKit 高德设备定位接口与调用示例。
- 强制 RXLBSKit iOS 最低版本为 4.0.0；低版本自动升级，高版本不降级。
- 传入 `workspacePath` 后自动、幂等补齐：
  - `NSLocationAlwaysUsageDescription`
  - `NSLocationAlwaysAndWhenInUseUsageDescription`
  - `NSLocationWhenInUseUsageDescription`
  - `UIBackgroundModes/location`
- 增加 Podfile、SDK 初始化和 Info.plist 结构化 preflight。

### Unity MCP `feature=lbs`

- 自动创建或补全：
  - `Assets/RuiXueSettings/RuiXueSDK_LBSXcodeSetting.asset`
- Unity 导出 iOS 工程时，由 `IOSLBSPostBuildProcessor` 自动写入三个定位权限 Key 和 `UIBackgroundModes/location`。
- 保留原有 UPM 依赖检查与自动升级。
