# 改动记录 - MCP Unity 业务程序集引用校验

- **日期**：2026-07-30
- **作者**：Cursor
- **影响范围**：RXSDK MCP Unity 工具

## 改动内容

### Unity MCP 业务 `.asmdef` 校验

- `unity` 工具传入有效 `workspacePath` 后，扫描 `Assets` 下的业务 C# 源码和 `.asmdef`。
- 从 `Packages` 与 `Library/PackageCache` 发现项目已安装的 `RuiXue.*` 程序集。
- 当业务源码引用瑞雪命名空间、但其所属 `.asmdef` 未声明对应程序集时，自动追加程序集名称引用。
- 支持识别已有程序集名称引用和 `GUID:` 引用，避免重复添加。
- 嵌套 `.asmdef` 按最近的程序集边界处理，不修改 `Packages` 中的 SDK 程序集定义。
- 没有业务 `.asmdef` 的项目继续使用 `Assembly-CSharp`，不会创建或修改程序集定义。
- `.asmdef` 使用原子写入；JSON 无效或 `references` 类型错误时不改动原文件，并通过 `preflight.missing` 返回原因。

### 平台影响确认

- iOS：不适用，Pod/Xcode 工程不使用 Unity `.asmdef`。
- Android：不适用，Gradle/Maven 依赖不使用 Unity `.asmdef`。
- Unity：已实现校验、自动修复及结构化 `preflight` 合并。
- Cocos2dx：不适用，C++/JNI/Objective-C++ 桥接不使用 Unity `.asmdef`。
