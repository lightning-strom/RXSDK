服务端 API

预览达人福利码(弃用)​

**POST: ** /v1/operationtoolsapi/exchange/preview

认证方式: AccessToken

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/operationtoolsapi/exchange/preview' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-accesstoken: {{登录token}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--header 'Content-Type: application/json' \
--data-raw '{
 "cdkey": "6oYwULM"
}'

请求头 Header 参数

参数类型备注
ruixue-languageStringzh-CN
Content-TypeStringapplication/json
ruixue-cpidString内容提供商 CPID
ruixue-productidString产品 ID
ruixue-channelidString渠道 ID
ruixue-platformidString平台 platformid
ruixue-devicecodeString设备码
ruixue-accesstokenString登录 token
ruixue-cptsStringCP 签名时间戳
ruixue-traceidStringTraceID

请求示例

{
 "cdkey": "6oYwULM",
 }

请求参数（JSON）​

参数类型是否必填备注
cdkeyString是福利码

响应示例

{
 "data": [{
 "prop_id": "aaa",
 "prop_name": "bbb",
 "prop_num": "ccc"
 }],
 "msg": "success",
 "code": 0
}

响应结构(JSON)​

参数类型备注
codeNumber0 为成功
msgString失败信息
data[]Data

data​

参数类型说明
prop_idString道具标识
prop_nameString道具名称
prop_numString道具数量

获取达人游戏内显示福利码​

**GET: ** /v1/operationtoolsapi/exchange/game_display

认证方式: AccessToken

CURL 示例​

curl --location --request GET '{{接口域名}}/v1/operationtoolsapi/exchange/game_display?game_id=1' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-accesstoken: {{登录token}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'Content-Type: application/json' \
--header 'ruixue-platformid: {{平台标识}}'
--data-raw '{
 "game_id": "1234"
}'

请求头 Header 参数

参数类型备注
ruixue-languageStringzh-CN
Content-TypeStringapplication/json
ruixue-cpidString内容提供商 CPID
ruixue-productidString产品 ID
ruixue-channelidString渠道 ID
ruixue-platformidString平台 platformid
ruixue-devicecodeString设备码
ruixue-accesstokenString登录 token
ruixue-cptsStringCP 签名时间戳
ruixue-traceidStringTraceID

请求参数（JSON）​

参数类型是否必填备注
game_idString是达人游戏 id

响应示例

{
 "data": {
 "refresh_period": 1,
 "promo_name": "福利码策略",
 "gift_name": "礼包名",
 "promo_valid_start": "2024-01-01 01:01:01",
 "promo_valid_end": "2024-01-02 01:01:01",
 "promo_code": "123456",
 "refresh_period_exp": 1000,
 "polling": 10
 },
 "msg": "success",
 "code": 0
}

响应结构(JSON)​

参数类型备注
codeNumber0 为成功
msgString失败信息
data[]Data

data​

参数类型说明
refresh_periodNumber刷新周期 单位分钟
promo_nameString福利码名称
gift_nameString礼包名称
promo_valid_startString福利码创建时间
promo_valid_endString福利码有效期结束时间
promo_codeString游戏内显示福利码
refresh_period_expNumber刷新周期过期时间 秒
pollingNumber轮询间隔时间 秒

游戏侧需在获取刷新周期过期时间为正数时开启倒计时，当倒计时结束时，在轮询间隔时间后调用此接口，如果获取到的刷新周期过期时间为 0 或负数时， 直接在轮询间隔时间后调用此接口， 直至 promo_code 变更， 主播下线后停止调用此接口， 则福利码暂停生成
