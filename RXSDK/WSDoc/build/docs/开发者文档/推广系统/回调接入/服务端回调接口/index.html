服务端回调接口

推广系统事件

类型：同步

Action: promotion-callback

认证方式： CPSign

请求参数 (JSON)​

字段类型是否必填说明示例
typeString是通知类型data
String是根据通知类型解析不同数据结构的 json 格式

type通知类型定义​

type 键值data 数据类型说明示例
testString固定值"test callback"anchor_prop
GameAnchorProp推广员道具变更anchor_addPromoterGameEvent
添加主播游戏 idanchor_updatePromoterGameEvent更新主播游戏 id （只更新 description 字段)
anchor_deletePromoterGameEvent删除主播游戏 idanchor_welfare_code
WelfareCodeInfo游戏内显示福利码
GameAnchorProp​
字段类型是否必填说明示例
account_idString游戏 idprops[]GameProp
道具变更信息
GameProp​
字段类型是否必填说明
prop_idString是道具标识
countNumber是道具数量
modeNumber是补充道具方式 0:重置 1:累加 默认为 0
standardNumber是标准值 默认为 0 ， 0 为不设置
standard_strString否标准值字符串
请求示例​
{
 "account_id": "123",
 "props": [
 {
 "prop_id": "1",
 "count": 13,
 "mode": 0
 "standard": 0
 }
 ]
}
PromoterGameEvent​
字段类型是否必填说明
product_idString是产品 ID
promoter_idNumber是推广员 ID
game_accountNumber是游戏 ID
descriptionString是主播其它信息
openidString是望舒 openid
anchor_statusNumber是主播状态 0:停播 1:正常 1 试用期
anchor_start_timeString否直播开始时间(24 小时制)时分，未设置默认空字符串
20:15anchor_end_timeString否
直播结束时间(24 小时制)时分，未设置默认空字符串23:30platformsArray
否使用的媒体平台
WelfareCodeInfo​
字段类型是否必填说明
open_idString是达人 openid
refresh_periodNumber是刷新周期，单位分
promo_nameString是福利码名称
gift_nameString是礼包名
promo_valid_startString是福利码有效期开始时间
promo_valid_endString是福利码有效期结束时间
promo_codes[] WelfarePromoCode是福利码
WelfarePromoCode​
字段类型是否必填说明示例
promo_codeString是福利码prop
[] WelfareProp是道具
WelfareProp​
字段类型是否必填说明
prop_idString是道具标识
prop_nameString是道具名称
prop_numString是道具数量
请求示例​
{
 "product_id": "product123",
 "promoter_id": 88,
 "game_account": 81928372,
 "openid": "rx123456789",
 "description": "主播的一些描述信息",
 "anchor_status":1,
 "anchor_start_time":"20:15",
 "anchor_end_time":"23:30"
}

响应参数（JSON）​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码， 0 为成功，非 0 表示出错0
msgString否响应信息，仅在 code 非 0 时返回data
Object否根据 type 不同，返回的信息不同

data返回结构定义​

type 类型data 数据类型说明示例
test无无 data 结构anchor_prop
[]GamePropResp推广员道具变更返回anchor_add无
添加主播游戏 idanchor_update无更新主播游戏 id
anchor_delete无删除主播游戏 id
GamePropResp​
字段类型是否必填说明
prop_idString是道具标识
beforeNumber是道具数量(重置前)
afterNumber是道具数量(重置后)
返回示例​
{
 "data": {
 "props": [
 {
 "prop_id": "1",
 "before": 3,
 "after": 13
 }
 ]
 },
 "code": 0
}
