望舒支付配置​

下单支付​

参数说明​

字段类型是否必填备注
paramsIPay是参数
callbackIMethodParams是回调函数集合

IPay 说明

字段类型是否必填备注
pay_typestring是支付的类型
goods_tagstring是计费点标识
trade_nostring是CP 订单号
serveridstring是区服 ID ，自定义，一般是指角色所在的区服标识
usernamestring是游戏内的角色名称
currencystring否币种 默认传: CNY 根据支付币种传递国家编码 币种字典
indulge_authnumber是是否进行防沉迷支付验证 ， 0 不验证 1 验证，默认不验证

如果为 1 age 必传 notify_url

string否支付成功通知 CP 发货地址
agenumber否
用户年龄

indulge_auth 为 1 时必传该字段

字段类型是否必填说明
is_debugnumber否是否测试订单， 0 正式 1 为测试订单，默认为 0
envnumber否是否使用沙盒环境支付， 0 正式 1 沙盒，默认为 0
game_infoobject否游戏自定义数据， 上报区服和角色需要在 game_info 中传入属性，具体使用方式参考下方 game_info 字段说明
bigdata_reportobject否商业化支付参数， 通过商业化触发的支付行为要传以下参数，否则数据统计会有丢失，具体使用方式参考下方 bigdata_report 字段说明

bigdata_report 字段说明

字段类型是否必填备注
scene_identifierstring否场景标识
scene_namestring否场景名称
trigger_button_identifierstring否触发按钮标识
trigger_button_namestring否触发按钮名称
window_identifierstring否窗口标识
window_namestring否窗口名称
window_sequencestring否窗口展示顺序
gift_packageobject否礼包

gift_package 字段说明

字段类型是否必填备注
identifierstring否礼包标识
namestring否礼包名称
purchase_mediumstring否购买礼包介质
pricenumber否礼包价格
billing_pointstring否礼包计费点

game_info 字段说明

字段类型是否必填备注
cp_game_character_idstring否角色 id
cp_game_area_idstring否区服 id

pay_type 说明

字段备注
unicornh5支付

IMethodParams 说明

字段备注
complete(data) => void

complete ：为函数且必传， data 为结果数据

调用示例

sdk.pay(
 {
 pay_type: "unicornh5",
 goods_tag: "bytest",
 trade_no: "" + new Date().getTime(),
 transmit_args: "a=1&b=2",
 indulge_auth: 1,
 age: 18,
 serverid: "serverid",
 username: "username"

 // 商业化下单参数示例
 // 'bigdata_report': {
 // 'scene_identifier': 'xxx',
 // 'scene_name': 'xxx',
 // 'trigger_button_identifier': 'xxx',
 // 'trigger_button_name': 'xxx',
 // 'window_identifier': 'xxx',
 // 'window_name': 'xxx',
 // 'window_sequence': 'xxx',
 // 'gift_package': {
 // 'identifier': 'xxx',
 // 'name': 'xxx',
 // 'purchase_medium': 'xxx',
 // 'price': 100,
 // 'billing_point': 'xxx',
 // },
 // }

 // 游戏自定义数据示例
 // 'game_info': {
 // 'cp_game_character_id': 'test',
 // 'cp_game_area_id': 'testarea',
 // }
 },
 {
 complete: (data) => {
 console.log(data);
 },
 }
);
