苹果支付账号配置

SDK 集成​

编辑 Podfile 文件，添加如下配置：

pod 'RXSDK_Pure'

补单机制：由于 app 在上传凭证给服务器时发生了网络或各种原因，造成了凭证没有上传成功，产生了掉单， SDK 提供自动和客户端手动补单两种补偿机制。具体如下：

自动补单流程：

客户端调用下单接口时 SDK 会优先判断上次支付是否掉单，如有掉单则先进行补单，补单成功后再次调用下单接口则恢复正常支付流程。补单失败后再次调用下单接口则继续补单。

支付失败后和登录成功后 SDK 会自动进行 5 次补单，使用斐波那契数列 5 秒间隔计算，减少掉单率。

手动补单流程：

订单验证失败 SDK 会将订单号及支付凭证回调给客户端，客户端可自行上报。

SDK 提供查询是否需要补单和补单功能，客户端可配合使用。

下单支付​

接口原型

/**
 * 下单
 */
- (void)iap:(NSDictionary *)dict complete:(RequestComplete)complete;

参数说明​

字段类型是否必填备注
hq_typestring否支付类型(参考 hq_type 对照表) ， 传空或不支持的类型 SDK 会默认为 map
goods_tagNSString是望舒计费点标识
trade_noNSString是CP 唯一订单号，不能重复
is_debugNSInteger否是否测试订单 默认 0 正式 1 为测试订单
envNSInteger否是否使用沙盒环境支付 0 正式 1 沙盒
currencyNSString是币种 全大写 国内传: CNY ，参考 国家编码 币种字典
extNSDictionary否支付扩展字段 三方支付额外传递参数
notify_urlNSString是支付成功通知 CP 发货地址
indulge_authNSInteger否是否进行防沉迷验证 0 不验证， 1 验证，默认不验证
game_infoNSDictionary否游戏自定义数据， 上报区服和角色需要在 game_info 中传入属性，具体使用方式参考下方 game_info 字段说明
bigdata_reportNSDictionary否商业化支付参数， 通过商业化触发的支付行为要传以下参数，否则数据统计会有丢失，具体使用方式参考下方 bigdata_report 字段说明
custom_extNSDictionary否自定义透传参数

custom_ext 结构说明

字段类型是否必填备注
bigdata_extNSDictionary否大数据预置事件透传参数

bigdata_report 字段说明

字段类型是否必填备注
scene_identifierNSString否场景标识
scene_nameNSString否场景名称
trigger_button_identifierNSString否触发按钮标识
trigger_button_nameNSString否触发按钮名称
window_identifierNSString否窗口标识
window_nameNSString否窗口名称
window_sequenceNSString否窗口展示顺序
gift_packageNSDictionary否礼包

gift_package 字段说明

字段类型是否必填备注
identifierNSString否礼包标识
nameNSString否礼包名称

priceint否礼包价格
billing_pointNSString否礼包计费点

game_info 字段说明

字段类型是否必填备注
cp_game_character_idNSString否角色 id
cp_game_area_idNSString否区服 id

hq_type 字段说明

字段备注

查询商品信息​

接口原型

/**
 * 查询商品信息
 * @param productIdArr 商品id
 */
- (void)getProductInfoWithProductIdArr:(NSArray *)productIdArr
 complete:(void(^)(NSArraySKProduct *> *productInfoList))complete;

参数说明​

字段类型是否必填备注
productIdArrNSString是苹果商品 id

调用示例

[[RXSDK sharedSDK] getProductInfoWithProductIdArr:商品id数组 complete:^(NSArraySKProduct *> *productInfoList) {

}];

响应结构​

返回系统库 StoreKit 中的 SKProduct 对象。

订阅商品获取 SKProduct.introductoryPrice 对象。

补单接口​

重试间隔通过斐波那契数列计算，客户端可在合适的时机调用补单接口，如登录成功后。

接口原型

/**
 * 补单
 * @param maxCount 最大重试数，默认5次
 */
- (void)repayFailOrderWithMaxCount:(NSInteger)maxCount
 complete:(RequestComplete)complete;

参数说明​

字段类型是否必填备注
maxCountNSString否最大重试数，默认 5 次

调用示例

BOOL needRepay = [[RXSDK sharedSDK] checkHasFailedOrder];
if (needRepay) {
 [[RXSDK sharedSDK] reFailOrderWithMaxCount:5 complete:^(NSDictionary * _Nullable response, RXCommonRequestError * _Nullable error) {

 }];
}

响应结构​

{
 "code": 0,
 "msg": "success"
}

常见错误码​

21000 ： App Store 无法读取你提供的 JSON 数据

21002 ：收据数据不符合格式

21003 ：收据无法被验证

21004 ：你提供的共享密钥和账户的不匹配

21005 ：收据服务器当前不可用

21006 ：此收据有效，但订阅已过期

21007 ：此收据来自测试环境，但发送到生产环境进行验证
