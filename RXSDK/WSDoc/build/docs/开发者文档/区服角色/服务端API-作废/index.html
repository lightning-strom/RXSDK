区服

创建游戏区服​

POST: /v1/report/cp/game_area

认证方式： CPSign

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/report/cp/game_area' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{cpid}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'Content-Type: application/json' \
--header 'ruixue-cpsign: {{签名}}'
--data-raw '{
 "area_id": "ut labore",
 "area_name": "ipsum quis Duis cillum in"
}'

请求参数（JSON）​

字段类型是否必填说明
area_idString是区服 id
area_nameString是区服名
extensionjson否符合 json 格式的数据

响应参数（JSON）​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码， 0 为成功，非 0 表示出错0
msgString否响应信息，仅在 code 为非 0 时不为空data
Data否响应内容

响应示例

{
 "code": 0,
 "msg": "string"
}
