「废弃」创建游戏角色​

POST: /v1/report/cp/role

认证方式： CPSign

curl --location --request POST '{{接口域名}}/v1/report/cp/role' \
--header 'ruixue-productid:{{产品 ID}}' \
--header 'ruixue-channelid:{{渠道 ID}}' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{cpid}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'Content-Type: application/json' \
--header 'ruixue-cpsign: {{签名}}'
--data-raw '{
 "rx_openid":"xxxasxxsasax",
 "region_tag":"default",
 "cp_role_id":"1234",
 "extension":{"nickname":"昵称","avatar":"头像url","sex":0,"level":"VIP8","attr1":"1","attr2":2,"attr...":false}
}'

创建、修改游戏角色​

PUT: /v1/report/cp/role

如果修改的角色信息不存在，会直接创建一条

认证方式： CPSign

curl --location --request PUT '{{接口域名}}/v1/report/cp/role' \
--header 'ruixue-productid:{{产品 ID}}' \
--header 'ruixue-channelid:{{渠道 ID}}' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{cpid}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'Content-Type: application/json' \
--header 'ruixue-cpsign: {{签名}}'
--data-raw '{
 "rx_openid":"xxxasxxsasax",
 "region_tag":"default",
 "cp_role_id":"1234",
 "extension":{"nickname":"昵称","avatar":"头像url","sex":0,"attr1":"1","attr2":2,"attr...":false}
}'

PUT: /v1/report/sdk/role

认证方式： Accesstoken

curl --location --request PUT '{{接口域名}}/v1/report/sdk/role' \
--header 'ruixue-productid:{{产品 ID}}' \
--header 'ruixue-channelid:{{渠道 ID}}' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{cpid}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'Content-Type: application/json' \
--header 'ruixue-accesstoken: {{accesstoken}}'
--data-raw '{
 "rx_openid":"xxxasxxsasax",
 "region_tag":"default",
 "cp_role_id":"1234",
 "extension":{"nickname":"昵称","avatar":"头像url","sex":0,"attr1":"1","attr2":2,"attr...":false}
}'

请求参数（JSON）​

字段类型是否必填说明
rx_openidString是望舒 openid
region_tagString是区服 (非区服项目 默认值: default)
cp_role_idString是角色 id （非区服项目 传 cp_userid ）
extensionjson是扩展信息符合 json 格式的数据（非区服项目 按需传扩展字段）
extension.nicknameString是角色昵称
extension.avatarString是角色头像地址
extension.sexNumber是角色性别 -1 未知 0 女 1 男
extension.levelstring否用户等级

响应参数（JSON）​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码， 0 为成功，非 0 表示出错0
msgString否响应信息，仅在 code 为非 0 时不为空data
Data否响应内容

响应示例

{
 "code": 0,
 "msg": "string"
}

查询指定用户角色列表​

GET: /v1/report/cp/role/list

认证方式： CPSign

curl --location --request GET '{{接口域名}}/v1/report/cp/role/list?rx_openid=xxxasxxsasax' \
--header 'ruixue-productid:{{产品 ID}}' \
--header 'ruixue-channelid:{{渠道 ID}}' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{cpid}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{签名}}'

GET: /v1/report/sdk/role/list
