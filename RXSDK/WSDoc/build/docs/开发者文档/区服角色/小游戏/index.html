小游戏

设置区服角色信息​

参数说明

字段类型是否必填备注
role_idstring是游戏角色 ID
region_tagstring是区服标识

JS 调用示例

sdk.setGameInfo('test_role_id', 'test_region_tag')

Unity 调用示例

using System;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.UI;
using RuiXue;

#if UNITY_WEBGL
using RuiXue.MiniGame.WeiXin;
#endif

public void OnSetGameInfo()
{
 RXMiniGameWeiXin.SetGameInfo("testrole", "restregion");
}

查询角色信息​

接口原型

参数说明

字段类型是否必填备注
callbackIMethodParams是回调函数集合

IMethodParams 说明

字段备注
complete(data) => void

complete ：为函数且必传， data 为结果数据

JS 调用示例

sdk.searchGameAccount({
 complete(res) {
 console.log('searchGameAccount', res)
 }
})
using System;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.UI;
using RuiXue;

#if UNITY_WEBGL
using RuiXue.MiniGame.WeiXin;
#endif

public void OnSearchGameAccount()
{
 RXMiniGameWeiXin.SearchGameAccount(OnResponse, OnError);
}

响应参数（JSON）​

HTTP 状态码：200 OK

字段类型是否必填说明
codeNumber是响应状态码， 0 为成功，非 0 表示出错
msgString否响应信息，仅在 code 为非 0 时不为空
dataData否响应内容

Data​

字段类型是否必填说明
list[]Item是角色列表

Item​

字段类型是否必填说明
region_tagString是区服
cp_role_idString是角色 id
extensionjson否扩展信息符合 json 格式的数据
