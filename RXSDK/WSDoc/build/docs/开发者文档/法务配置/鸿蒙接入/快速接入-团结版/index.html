获取法务信息​

接口原型

/// summary>
/// 获取法务信息（条款+未成年保护）
/// summary>
/// param name="callback"> code 状态码0时成功 data 返回的数据 msg 错误消息 param>
void Legal(Actionint, object, string> callback)；

参数说明​

无

调用示例

RuiXueSdk.Legal(callback);

响应结构​

参数类型是否必须说明
codeNumber是响应状态码， 0 为成功，非 0 表示出错
msgString否响应信息，仅在 code 非 0 时返回
dataData否key 跟请求的 keys 对应

获取法务信息Data​

参数类型是否必须说明
termsTerms是文档类
permissionsPermissions是权限类
minorMinor是未成年人保护

KeyString是文档标识

获取法务条款​

接口原型

/// summary>
/// 获取法务条款
/// summary>
/// param name="args">参照参数说明param>
/// param name="callback">param>
void LegalTerms(LegalArgs args, Actionint, object, string> callback)

参数说明

参数类型是否必填备注
product_idstring否产品 id
channel_idstring否渠道 ID
keysstring是法务条款 key ，多个使用【,】分隔； 例如： 00001,00002
positionstring否1 登录 2 用户中心 4 其他， 可 keys 二选一

调用示例

string[] k = { "00001", "00002", "00003" };
var data = new LegalArgs().SetKeys(k);
RuiXueSdk.LegalTerms(data，callback);

响应结构​

参数类型是否必须说明
codeNumber是响应状态码， 0 为成功，非 0 表示出错
msgString否响应信息，仅在 code 非 0 时返回
dataMap[String]Data否key 跟请求的 keys 对应
