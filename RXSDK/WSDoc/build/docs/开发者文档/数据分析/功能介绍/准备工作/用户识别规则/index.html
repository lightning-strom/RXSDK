用户识别规则

用户既可能在不同的设备上使用您的产品，也会在未登录状态下进行使用，使得准确地用户标识变得相当复杂。望舒选择了一种较为准确且便于理解的方案。本文档将会详细介绍用望舒大数据平台（以下简称：大数据平台）用户识别的规则，并提供案例帮助您快速理解。

用户标识及关联​

在真实世界中，我们通过身份证号来准确标识一个自然人，在互联网业务体系中，这种方式不再适用。于是产生了两种常见方案：

第一种方案是通过用户的设备 ID 来唯一标识这名用户，这种方式在一定程度上解决了用户标识的问题，但是这种方案缺点也很明显，比如，同一台手机被多个用户用过，产生的行为被标记为同一个“人”；等等问题最终都将导致数据分析的结果不准确。

第二种方案则是通过用户的登录 ID 来识别用户，这种方案在业务后台系统中比较常见，但是用户在未登录状态下发生行为是无法被识别的，因此这种方案只能准确地记录业务数据，主要在业务数仓的搭建中充当用户标识。

望舒大数据平台充分考虑了每种方案的优劣，制定了完善的用户标识体系。关于望舒大数据平台是怎么标识用户的，推荐阅读《如何准确的标识用户》。简单来说，在用户未登录的情况下，大数据平台会选取设备 ID 作为唯一标识，登录状态下选取登录 ID(#distinct_id) ，一个用户既有设备 ID （亦称作“匿名 ID”）又有登录 ID。接下来，通过“用户关联”将同一个用户的设备 ID 和登录 ID 关联到一起，这样不管用户是匿名和登录的状态发生的行为，我们都能准确识别到是同一个用户，这是目前为止较为通用且准确的用户标识方式。

望舒支持的用户关联方案​

大部分情况下，一个用户只有一台设备，因此一个用户只会有一个设备 ID 和一个登录 ID ，针对这种情况，大数据平台提供了设备 ID 和登录 ID 一对一关联的方案，详见：一对一关联方案。
