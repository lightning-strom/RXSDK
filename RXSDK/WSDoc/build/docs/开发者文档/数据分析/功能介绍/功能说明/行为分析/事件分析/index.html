事件分析

事件分析是行为分析中最基础的模型。

通过事件分析模型，可以计算一段时间内用户产生特定行为的聚合指标。

事件分析的意义​

用户（ User ）在 游戏中产生的行为数据被称为事件（ Event ）。

事件数据记录了用户产生各种行为的时间、行为的类型以及行为的详细信息。对这些事件数据进行筛选，最终计算聚合指标的模型称为事件分析模型。

通过事件分析，可以计算一段时间内用户产生特定行为的聚合指标，了解各行为的用户参与情况以及指标的发展趋势，从而对产品获得宏观把控，优化决策。

以充值事件举例来说，可以解决如下问题：

近 7 日每日充值流水的趋势？

近 7 日来各渠道的每日收入流水与分布情况？

事件分析使用方法​

进入望舒平台首页，点击左侧菜单：大数据分析平台。

点击页面上方「行为分析」，选择「事件分析」后点击进入。

分析指标​

添加指标​

点击【添加指标】可按照顺序依次添加多个指标。

分析指标即 「事件」 + 「属性」 + 「计算方法」 或直接 「事件」 + 「计算方法」

事件属性计算方法
事件总次数、触发用户数、人均次数事件
事件属性（数值型）总和、均值、最大值、最小值、人均值、去重数、99 分位数、95 分位数、90 分位数、80 分位数、75 分位数、70 分位数、60 分位数、40 分位数、30 分位数、25 分位数、20 分位数、10 分位数、5 分位数事件
事件属性（列表型）列表去重数、列表元素去重数事件
事件属性（布尔型）去重数、为真数、为假数事件
事件属性（时间、文本型）去重数

添加公式​

点击【添加公式】可按照顺序依次添加多个公式。

如果需要进行分析指标间的、常数间的一些四则运算，可以通过“添加公式”来实现。例如分析 ARPU 值（活跃用户的人均付费金额）可以用“付费事件.付费金额.总和” / “用户登录.触发用户数”

默认会按照指标间计算逻辑展示，需要输入常数时，需要先删除自动加入的指标后，再输入。

除了“添加公式”，还可以在指标上选择“切换为公式”，已选择的分析指标和筛选条件都将带入到公式中。

添加条件​

点击【添加条件】可对当前的指标增加限制条件。

添加多个条件时，条件之间可设置且和或的逻辑关系。最多支持 2 层逻辑嵌套

筛选项目与筛选逻辑间关系

数据类型举例可支持的筛选逻辑关键字
数值消费金额等于、不等于、小于、小于等于、大于、大于等于、有值、无值、区间
文本省份等于、不等于、包含、不包含、有值、无值
列表ID 名单存在元素、不存在元素、元素位置、有值、无值
时间注册时间、最后活跃日期位于区间、小于等于、大于等于、相对当前日期、相对事件发生时刻、有值、无值
布尔Wifi 使用为真、为假、有值、无值

分组项​

添加分组项​

点击【添加分组项】可设置多个分组。

分组项可根据用户属性、事件属性进行不同粒度划分数据。例如计算用户的充值订单金额总和，同时分组项设置为平台名称，那么计算出来的就是不同平台下的订单金额总和。

分组项可设置多重分组。例如计算用户的充值订单金额总和，同时分组项设置为平台名称、支付方式，那么计算出来的就是不同平台 + 不同支付方式下的订单金额总和。

全局筛选​

添加条件​

点击【添加视图条件】可设置多个条件。非必须设置。

视图筛选条件对添加的所有分析指标全部生效。

视图筛选条件可根据用户属性、事件属性进行限制。

其他逻辑与【添加条件】一致。查看第三点内容。
