分布分析

通过分布分析模型，可以根据每个用户(分析主体)聚合后的总完成次数、天数或属性值划分区间，查看不同区间用户的数量及占比

分布分析的意义​

分布分析模型可以根据每个用户(分析主体)聚合后的总完成次数、天数或属性值划分区间，查看不同区间用户的数量及占比。以下是常见的分析场景

事件频率(次数)：按用户每天参与战斗次数划分区间，查看每天不同战斗次数的用户数量

用户黏性(天数)：按用户在过去七天的登录天数，区分不同黏性的用户进行后续分析

属性值：按一段时间内，充值的累计付费金额将用户拆分为大中小 R ，并查看不同等级用户数量占比

分布分析使用方法​

进入望舒平台首页，点击左侧菜单：大数据分析平台。

点击页面上方「行为分析」，选择「分布分析」后点击进入。

用户参与事件​

分析指标​

与事件分析一致，分布分析设置用户参与事件时可以选择(「事件」+「属性」+「计算方法」)或直接(「事件」+「计算方法」)。

支持切换为公式进行计算。

支持添加限制条件。

支持设置分布计算方式（点击右侧的小齿轮）

默认区间：系统根据计算出的结果，自动划分统计区间。

离散数字：按照 1、2、3……分别进行统计。

自定义：设置自身需求，手动划分统计区间。

分组项​

添加分组项​

点击【添加分组项】可设置多个分组。

分组项可根据用户属性、事件属性进行不同粒度划分数据。

分布分析使用示例​

场景：分析一周内，不同渠道的用户下单次数的分布情况。

事件：充值下单

计算方式：总次数

分组项：渠道名称

展现：百分比分布

点击预览视图，即可查看计算结果。
