/// summary>
/// 上报/更新经纬度坐标
/// summary>
/// param name="types">坐标分组，由 CP 自定义param>
/// param name="lon">WGS84 经度param>
/// param name="lat">WGS84 纬度param>
/// param name="radius">限定半径距离，单位：米param>
/// param name="count">获取数量，0 表示获取全部param>
/// param name="page">获取第几页的数据 从 1 开始param>
/// param name="page_size">每页数量param>
/// param name="callback">param>
void LbsRadius(string types, float lon, float lat, float radius, int count, int page, int page_size, Actionint, object, string> callback);

参数说明​

字段类型是否必填备注其他信息
lonnumber是WGS84 经度mock: 125.36970905364038
latnumber是WGS84 纬度mock: 43.814125235156496
radiusinteger是限定半径距离，单位：米mock: @integer(100, 10000)
countinteger否获取数量， 0 表示获取全部mock: @integer(1, 100)
pageinteger是获取第几页的数据 从 1 开始mock: 1
page_sizeinteger是每页数量mock: 10
typestring是坐标分组，由 CP 自定义

调用示例

float lon = 118.19646377354036f;
float lat = 24.4837108022851f;
var radius = 20000;
var count = 0;
var page = 1;
var page_size = 10;
var type = "friend";
RuiXueSdk.SocialAPI.LbsRadius(type, lon, lat, radius, count, page, page_size, RXCallback);

响应结构​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码， 0 为成功，非 0 表示出错0
msgString否响应信息，仅在 code 非 0 时返回data
DataNode否结果数据集
DataNode​
字段类型是否必填说明
openidString是用户望舒 OpenID
nicknameString否用户昵称
birthdayString否用户生日日期
remarksString否当前用户对其的备注
avatarString否用户头像
customString否CP 自定义信息
distFloat64是距离当前用户的距离（米）
sexNumber否用户性别， 1:男； 0:女
cp_useridNumber否CP 侧 用户 id

响应示例

 "data": [
 {
 "openid": "rxuSl4QZoNk0G1HY2-Za6GlO7wO-p_ej",
