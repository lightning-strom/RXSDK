服务端 API

准备工作​

以下是 CP 服务端请求接口，需要准备好 cp_id 、 product_id 、channel_id 、cp_key 等参数。

domain ：为产品对外域名

请求头：望舒服务端请求头

添加自定义关系​

POST： /v1/social/serverapi/addrelation

认证方式： CPSign

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/social/serverapi/addrelation' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--header 'Content-Type: application/json' \
--data-raw '{
 "types":{"pp":true},
 "target":"rxufb2GKDBm5n4u7gYkcOLbOv7J4RrVP",
 "openid":"rxuSl4QZoNk0G1HY2-Za6GlO7wO-p_ej",
 "user_remarks":"",
 "target_remarks":""
}'

请求参数（JSON）​

字段类型是否必填说明
openidString条件必填己方 望舒 openid。和 cp_user_id 任传一个即可
cp_user_idString条件必填cp 侧 userid。和望舒 openid 任传一个即可
targetString条件必填对方 望舒 OpenID。和 target_cp_user_id 任传一个即可
target_cp_user_idString条件必填cp 侧 userid。和 target 任传一个即可
typesObject<String, Boolean>是CP 自定义关系类型列表，其值是一个 map 键值对列表
target_remarksString否用户给 Target 设置的备注信息（最长 512 字符）
user_remarksString否Target 给用户设置的备注信息（最长 512 字符）
{
 "类型标识符(String)": "是否为双向关系"
}
{
 "test": true,
 "aaa": false
}

| target_remarks | String | 否 | 用户给 Target 设置的备注信息（最长 512 字符） | | user_remarks | String | 否 | Target 给用户设置的备注信息（最长 512 字符） | | bbbb | | | |

请求示例

使用望舒 OpenID：

{
 "types":{"pp":true},
 "target":"rxufb2GKDBm5n4u7gYkcOLbOv7J4RrVP",
 "openid":"rxuSl4QZoNk0G1HY2-Za6GlO7wO-p_ej",
 "user_remarks":"",
 "target_remarks":""
}

使用 CP 用户 ID：

{
 "types":{"pp":true},
 "target_cp_user_id":"10000",
 "cp_user_id":"10001",
 "user_remarks":"",
 "target_remarks":""
}

响应参数（JSON)​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码， 0 为成功，非 0 表示出错0
msgString否响应信息，仅在 code 非 0 时返回

响应示例

{"code": 0}

POST： /v1/social/serverapi/lbsradius

认证方式: CPSign

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/social/serverapi/lbsradius' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--header 'Content-Type: application/json' \
--data-raw '{
 "type": "test",
 "lon": 14.2079746,
 "lat": 14.2079746,
 "radius": 1000.00,
 "count": 0,
 "page": 1,
 "page_size": 100,
 "openid" : "rxufb2GKDBm5n4u7gYkcOLbOv7J4RrVP"
}'

请求参数（JSON）​

字段类型是否必填说明
typeString是分组名称
lonFloat64是WGS84 经度
latFloat64是WGS84 纬度
radiusFloat64是限定半径距离，单位：米
countNumber否获取数量，0 表示获取全部
page_sizeNumber是每页数量
pageNumber是页码
是获取第几页的数据 从 1 开始1openid
String条件必填己方 望舒 openid。和 cp_user_id 任传一个即可cp_user_id
String条件必填cp 侧 userid。和望舒 openid 任传一个即可

请求示例

{
 "type": "test",
 "lon": 14.2079746,
 "lat": 14.2079746,
 "radius": 1000.00,
 "count": 0,
 "page": 1,
 "page_size": 100,
 "openid" : "rxufb2GKDBm5n4u7gYkcOLbOv7J4RrVP"
}

响应参数（JSON）​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码， 0 为成功，非 0 表示出错0
msgString否响应信息，仅在 code 非 0 时返回
dataDataNode[]否结果数据集

DataNode​

字段类型是否必填说明

customString否CP 自定义信息
distFloat64是距离当前用户的距离（米）
sexNumber否用户性别， 1:男； 0:女
cp_useridNumber否CP 侧 用户 id
