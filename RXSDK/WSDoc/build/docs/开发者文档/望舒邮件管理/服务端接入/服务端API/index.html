服务端 API

望舒邮件-列表​

POST: /v1/operationtoolsapi/rxmail/cpuser/list

认证方式： Accesstoken PUT时为 CPSign

1、该接口无分页，仅返回最后 1000 条数据。2、当后台望舒邮件任务配置多语言时，会根据请求语言返回相应语言的内容，如果语言内容不存在，则返回配置的默认语言内容。3、过期邮件无法在列表中查看，未读邮件过期时间为 60 天，已读邮件过期时间为 7 天。

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/operationtoolsapi/rxmail/cpuser/list' \
--header 'ruixue-productid: {{产品id}}' \
--header 'ruixue-channelid: {{渠道id}}' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-accesstoken: {{登录token}}' \
--header 'Content-Type: application/json' \
--data-raw '{
 "cp_user_id": "442099939",
 "language_able": "zh"
}'

header参数​

参数类型是否必填约束
ruixue-productidString是望舒产品 ID
ruixue-channelidString是望舒渠道 ID
ruixue-languageString否用户语言

body请求参数​

参数类型是否必填约束
cp_user_idString是游戏用户 ID
language_ableString是用户语言（非必须，与请求头中的 ruixue-language 有一个即可 ）
region_tagString是区服
role_idString是角色
return_propBool否是否返回道具信息
return_contentBool否是否返回内容信息
pageint否默认 1
sizeint否默认 1000

响应示例

{
    "code": 0,
    "msg": "",
    "data": {
        "list": [{
            "rx_mail_id": 2,
            "title": "邮件标题",
            "send_at": "2024-01-01 08:00:00",
            "status": 1,
            "has_reward": 0
        }, {
            "rx_mail_id": 1,
            "title": "邮件标题",
            "send_at": "2024-01-01 08:00:00",
            "status": 2,
            "has_reward": 1
        }],
        "all_count": 2,
        "not_received_count": 1,
        "not_read_count": 1
    }
}

响应结构（JSON）​

参数类型约束
listArray邮件列表
all_countNumber列表邮件总数
not_received_countNumber列表中未领取附件的邮件数量
not_read_countNumber列表中未读的邮件数量

list

参数类型约束
rx_mail_idNumber邮件 ID
titleString邮件标题
send_atString邮件发送时间，格式为 yyyy-MM-dd HH:mm:ss
statusNumber邮件状态： 1-已读 2-已领 3-未读
has_rewardNumber有无附件： 0-无 1-有
propsArray道具内容
contentString邮件内容

望舒邮件-详情​

POST: /v1/operationtoolsapi/rxmail/cpuser/detail

认证方式： Accesstoken PUT时为 CPSign

1、当后台望舒邮件任务配置多语言时，会根据请求语言返回相应语言的内容，如果语言内容不存在，则返回配置的默认语言内容。

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/operationtoolsapi/rxmail/cpuser/detail' \
--header 'ruixue-productid: {{产品id}}' \
--header 'ruixue-channelid: {{渠道id}}' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-accesstoken: {{登录token}}' \
--header 'Content-Type: application/json' \
--data-raw '{
 "rx_mail_id": 1,
 "cp_user_id": "442099939",
 "language_able": "zh"
}'

header参数​

参数类型是否必填约束
ruixue-productidString是望舒产品 ID
ruixue-channelidString是望舒渠道 ID
ruixue-languageString否用户语言

body请求参数​

参数类型是否必填约束
rx_mail_idNumber是望舒邮件 ID
cp_user_idString是游戏用户 ID
language_ableString是用户语言（非必须，与请求头中的 ruixue-language 有一个即可 ）
region_tagString是区服
role_idString是角色

响应示例

{
    "code": 0,
    "data": {
        "title": "邮件标题",
        "content": "邮件内容",
        "sign": "邮件落款",
        "props": [{
            "name": "道具名称",
            "describe": "道具描述",
            "icon": "道具图标url",
            "tag": "道具唯一标识",
            "count": 50000,
            "count_format": "5万",
            "is_permanent": 0,
            "time_limit": 1
        }],
        "status": 2
    }
}

错误示例

{
    "msg": "数据不存在",
 "code": 305404
}

响应结构（JSON）​

参数类型约束
titleString邮件标题
contentString邮件内容
signString邮件落款
propsArray邮件附件列表
statusNumber邮件状态： 1-已读 2-已领 3-已发送

props

参数类型约束
nameString道具名称
describeString道具描述
iconString道具图标 url
tagString道具唯一标识
countNumber道具数量
count_formatString道具数量单位换算，支持简繁体中文、英文和越南文的单位换算，其他语言默认使用英文单位换算
is_permanentNumber道具是否永久有效， 0 ：永久有效 1 ：非永久有效
time_limitNumber道具有效期，以天为单位

望舒邮件-领取（回调发放）​

POST: /v1/operationtoolsapi/rxmail/cpuser/receive

认证方式： Accesstoken PUT时为 CPSign

1、道具领取成功后会通过后台配置的回调发送给服务端。2、一键领取时，无附件的未读邮件会变为已读状态。

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/operationtoolsapi/rxmail/cpuser/receive' \
--header 'ruixue-productid: {{产品id}}' \
--header 'ruixue-channelid: {{渠道id}}' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-accesstoken: {{登录token}}' \
--header 'Content-Type: application/json' \
--data-raw '{
 "rx_mail_id": 1,
 "cp_user_id": "442099939",
 "type": 1
}'

header参数​

参数类型是否必填约束
ruixue-productidString是望舒产品 ID
ruixue-channelidString是望舒渠道 ID
ruixue-languageString否用户语言

body请求参数​

参数类型是否必填约束
rx_mail_idNumber否望舒邮件 ID （ type 字段等于 1 时为必填项）
cp_user_idString是游戏用户 ID
typeNumber是操作类型： 1-领取单封邮件 2-一键领取
region_tagString是区服
role_idString是角色

响应示例

{
 "code": 0,
 "msg": "",
 "data": {
 "cp_user_id": "442099939",
 "rx_mail_ids": [
 1,
 2
 ]
 }
}

响应结构（JSON）​

参数类型约束
cp_user_idString游戏用户 ID
rx_mail_idsArray领取附件的邮件 ID 集合，仅在一键领取时有值

望舒邮件-删除​

POST: /v1/operationtoolsapi/rxmail/cpuser/delete

认证方式： Accesstoken PUT时为 CPSign

1、如果邮件有附件，已领状态的邮件会删除；如果无附件，已读状态的邮件会删除。

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/operationtoolsapi/rxmail/cpuser/delete' \
--header 'ruixue-productid: {{产品id}}' \
--header 'ruixue-channelid: {{渠道id}}' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-accesstoken: {{登录token}}' \
--header 'Content-Type: application/json' \
--data-raw '{
 "rx_mail_ids": [1],
 "cp_user_id": "442099939",
 "type": 1
}'

header参数​

参数类型是否必填约束
ruixue-productidString是望舒产品 ID
ruixue-channelidString是望舒渠道 ID
ruixue-languageString否用户语言

body请求参数​

参数类型是否必填约束
rx_mail_idsArray否望舒邮件 ID （ type 字段等于 1 时为必填项）
cp_user_idString是游戏用户 ID
typeNumber是操作类型： 1-删除单封邮件， 2-一键删除
region_tagString是区服
role_idString是角色

响应示例

{
 "code": 0,
 "msg": "",
 "data": {
 "cp_user_id": "442099939",
 "rx_mail_ids": [
 1,
 2
 ]
 }
}

响应结构（JSON）​

参数类型约束
cp_user_idString游戏用户 ID
rx_mail_idsArray删除的邮件 ID 集合，仅在一键删除时有值
region_tagString是
role_idString是

返回的 rx_mail_ids 不一定等于请求的 rx_mail_ids 无法删除的原因

1、无附件并且未读

2、有附件并且未领

批量创建望舒邮件​

PUT: /v1/operationtoolsapi/rxmail/batch_send

认证方式： CPSign

只支持服务端调用。

CURL 示例​

curl --location --request PUT '{{接口域名}}/v1/operationtoolsapi/rxmail/batch_send' \
--header 'ruixue-productid: {{产品id}}' \
--header 'ruixue-channelid: {{渠道id}}' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-accesstoken: {{登录token}}' \
--header 'Content-Type: application/json' \
--data-raw '{
 "user_info":{
 "products":[],
 "channels":[],
 "cp_user_ids":["441450857"]
 },
 "role_info": {
 "region_tag": "ceshi",
 "role_ids": ["3"]
 },
 "prop_info":[{
 "name": "name",
 "tag":"tag",
 "count":1
 }],
 "mail_info": {
 "zh": {
 "title": "title",
 "content":"content",
 "sign":"sign"
 }
 },
 "mail_default_language": "zh"
}'

body请求参数​

参数类型是否必填约束
user_infoObject否用户信息（非区服游戏为必填项）
role_infoObject否角色信息（区服游戏为必填项）
prop_infoArray否道具信息
mail_infoObject是邮件信息
mail_default_languageString是邮件默认语言,支持 "中文简体:zh","中文繁体:tc","英语:en","日文:ja","泰文:th","越南文:vi","菲律宾语:tl","印尼语:id","阿拉伯语:ar"

user_info​

参数类型是否必填约束
productsArray否产品范围，不填为不限制
channelsArray否渠道范围，不填为不限制
cp_user_idsArray是游戏 id ， 最多 2000 人

role_info​

参数类型是否必填约束
region_tagstring是区服标识
role_idsArray是角色 id ，最多 2000 人

prop_info​

参数类型是否必填约束
namestring是道具名称
tagstring是道具标识
countNumber是道具数量
is_permanentNumber否是否永久有效 0 永久 1 非永久
time_limitNumber否非永久有效道具的有效期（天）

mail_info​

参数类型是否必填约束
titlestring是邮件标题
contentstring是邮件内容
signstring是邮件签名
