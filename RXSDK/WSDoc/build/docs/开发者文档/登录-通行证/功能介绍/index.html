功能介绍

为了访问 Ruixue Developer Services （以下简称 RDS ）的相关服务功能，你需要有望舒系统的登录账号。并且在望舒系统中创建产品、渠道、渠道包中配置您所需要的登录方式（包括三方的关键信息、登录顺序等）。本文档介绍了如何在你的应用中实现望舒统一认证登录。

业务介绍​

厂商的渠道账号需要使用厂商的 UI 登录所以需要参考 Android 登录 API 进行接入。不同的渠道根据 loginType 进行区分。

Android 登录 API

RDS 账号服务是基于标准的 OAuth 2.0 协议构建的授权登录系统，为开发者提供了简单、安全、快速的账号登录授权功能，为用户免去输入账号密码的繁琐步骤，让用户只需选择常用的账号授权，即可使用你的应用。

在取得用户授权之后，开发者可以通过接口调用的方式获得用户的相关公开信息，包括用户昵称、头像等，可用于提高应用的用户体验。

接入准备​

望舒系统中配置登录方式​

请确认已经完成了望舒游戏发行平台的部署以及产品、渠道的创建。可参照入门指南中的准备工作。

请在望舒游戏发行平台中的渠道包管理，配置使用哪些三方登录方式以及登录顺序。

位置：企业管理后台 > 商务管理 > 渠道包管理 > 添加登录方式。

实现交互式登录​

检查当前如果没有用户登录状态时，需要为用户提供一个可视化点击交互的登录界面。

单个登录方式​

当应用中仅提供一种登录方式时，建议在开始游戏的主界面，绘制一个可交互的登录按钮。按钮的范围大小、按钮上的文案使用，均不能误导、不能阻碍用户的正常顺畅点击。

多种登录方式​

如果游戏还有其他登录方式同时存在，应为用户提供合理布局的登录界面，尽可能地从外观明显区分每种登录方式的不同，让用户可以快速找到目标。
