合规（实名）

合规​

实名认证​

POST： /v1/passport/user/realauth

认证方式： Accesstoken

CURL示例​

curl --location --request POST '{{接口域名}}/v1/passport/user/realauth' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--header 'Content-Type: application/json' \
--data-raw '{
 "idcard":"220122199010233211",
 "realname":"xiaoming"
}'

请求示例

{
 "idcard":"220122199010233211",
 "realname":"xiaoming"
}

请求参数（JSON）​

字段类型是否必填说明
idcardString是身份证号码。
realnameString是真实姓名。

响应结构（JSON）​

字段类型说明
ageNumber从实名信息中提取的年龄信息
limitbool防沉迷开关 :true 开启 false 未开启
aasNumber剩余时间

响应示例

{
 "code": 0,
 "data": {
 "age": 18
 }
}

查询实名信息（越南）​

POST： /v1/risk/api/auth/vn/info

认证方式： CPSign

CURL示例​

curl --location --request GET '{{接口域名}}/v1/risk/api/auth/vn/info?rx_open_id={望舒OpenID}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--header 'ruixue-channelid: {{渠道标识}}'

响应结构（JSON）​

字段类型说明
codeNumber响应状态码 0 为正常
dataData响应信息

Data​

字段类型说明
rx_open_idString望舒 OpenID
real_nameString真实信息
birthdayString生日
phoneString手机号
emailString邮箱

响应示例

{
 "data": {
 "rx_open_id": "xxx,
 "real_name": "name",
 "birthday": "2001/01/01",
 "phone": "0912311231",
 "email": "111@123.com"
 },
 "code": 0
}

修改实名信息（越南）​

POST： /v1/risk/api/auth/vn

认证方式： CPSign

使用场景： 适用于自建网站由于官方要求需要提供修改实名的场景。

CURL示例​

curl --location --request POST '{{接口域名}}/v1/risk/api/auth/vn' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'Content-Type: application/json' \
--data-raw '{
 "rx_open_id": "xxx",
 "real_name": "xxx",
 "birthday": "2001/01/01",
 "phone": "0912311231",
 "email": "111@123.com"
}'

请求参数（JSON）​

字段类型说明
rx_open_idString望舒 OpenID
real_nameString真实信息
birthdayString生日 格式:2006/01/02
phoneString手机号 10 位数字、开头为 0
emailString邮箱

响应结构（JSON）​

字段类型说明
codeNumber响应状态码 0 为正常
msgString响应描述

响应示例

{
 "code": 0
}

实名认证（日本）​

CURL示例（服务端）​

POST： /v1/risk/api/auth/jp

认证方式： CPSign

应用场景： 服务端调用

curl --location --request POST '{{接口域名}}/v1/risk/api/auth/jp' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--header 'Content-Type: application/json' \
--data-raw '{
 "cp_user_id":"游戏 ID",
 "openid":"望舒 openid",
 "birthday":"2002/08/01"
}'
请求参数（JSON）​
字段类型是否必填说明
birthdayString是生日 格式:xxxx/xx/xx
openidString否望舒 openid （服务端请求场景与 cp_user_id 二选一）
cp_user_idString否游戏 ID （服务端请求场景与 openid 二选一）
String否游戏 ID （服务端请求场景与 openid 二选一）

CURL示例（SDK）​

POST： /v1/risk/sdk/auth/jp

认证方式： Accesstoken

应用场景： 客户端调用

curl --location --request POST '{{接口域名}}/v1/risk/sdk/auth/jp' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-accesstoken: {{accesstoken}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--header 'Content-Type: application/json' \
--data-raw '{
 "birthday":"2002/08/01"
}'
请求参数（JSON）​
字段类型是否必填说明示例
birthdayString是生日 格式:xxxx/xx/xx2002/08/01

响应结构（JSON）​

字段类型说明
codeNumber响应状态码 0 为正常

响应示例

{
 "code": 0
}
