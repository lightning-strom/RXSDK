implementation 'com.ruixue:rxsdk_overseas:${version}'

"非法注册（限制代码 1 ）" code : 312232 为 注册 ip 限制，默认开启，同一 ip 默认 1 小时注册账号不能超过 2 个，如有需求请联系商务添加 ip 白名单或调整限制条件。"非法注册（限制代码 2 ）" code : 312232 为 注册设备限制，默认关闭，同一设备 x 小时注册账号不能超过 x 个，如有需求请联系商务开启。

登录弹窗​

设置为登录后强制实名认证时登录成功的数据将在实名认证后返回，并且不会返回实名认证的结果，只会在 UI 上体现实名认证成功。如需要获取实名认证回调数据，请关闭登录后强制实名认证设置，并单独调用实名认证 UI。

Logo 参考设计稿：

微乐通行证 ai

微乐通行证 psd

UI 示例

接口原型

/**
    *登录界面 传入自定义配置。
    * @param activity activity
    * @param config 自定义配置，@RXLoginUIModel 结构注释参照下方参数说明
    * @param loginCallback 登录回调
    */
void showLoginUI(Activity activity, RXOSUILoginConfig config, RXUICallback loginCallback)

参数说明​

RXLoginUIModel 结构说明

字段类型是否必填备注
loginMethodsArray否登录方式，默认读取望舒后台配置，没配置则需要手动传入
setPrivaciesArray否协议地址，顺序 0 为用户协议， 1 为隐私协议。默认读取望舒后台配置，没配置则需要手动传入
logoImageDrawable否登录显示的 logo ，不配置显示默认 logo。 Logo 参考设计稿：微乐通行证 ai微乐通行证 psd
isHistoryViewEnablebool否是否展示登录历史弹窗， YES 展示， NO 不展示，默认 YES。 注： SDK 会记录已登录的账号记录，下次调用会展示登录历史弹窗
needRealAuthbool否未实名用户登录成功后是否需要强制实名认证，默认强制。 注：强制实名后登录数据将在实名认证成功后返回。
canCloseRealAuthbool否实名认证是否可关闭，默认不可关闭。
setRealAuthRegionString否实名认证地区，海外根据不同地区展示不同样式的实名认证 UI ，默认 姓名+身份证样式，目前支持 VN （越南地区样式）
setFirstNeedSetPasswordbool否验证码登录的新用户是否弹出设置密码，默认不弹出。注：弹出设置密码后登录数据将在设置成功或关闭设置页面后返回。
setQuickButtonBarVisiblebool否是否显示底部快速登录按钮，默认显示。
setDeregisterShowbool否处于注销中的用户登录后是否显示注销窗口，默认不显示
setLoginContinuebool否如果账号在注销中是继续登录还是退出登录, true 继续登录， false 退出登录，默认 false
setCustomParamsMap<String, Object>否自定义参数
googleClientidString否google 登录客户端秘钥，默认读取望舒后台配置，没配置则需要手动传入
setShowPrivacybool否设置隐私协议是否显示开关, 默认 true 显示隐私协议

loginTypes 结构说明

字段备注
guest游客登录
username账号登录
captchacode验证码登录
google谷歌登录，需要先接入 Google 配置，请参考 Google 接入
facebookfacebook 登录，需要先接入 Facebook 配置，请参考 Facebook 接入
lineline 登录，需要先接入 Line 配置，请参考 Line 接入
zalozalo 登录，需要先接入 Zalo 配置，请参考 Zalo 接入
instagraminstagram 登录，需要先接入 Instagram 配置，请参考 Instagram 接入
tiktoktiktok 登录，需要先接入 Tiktok 配置，请参考 Tiktok 接入
redditreddit ，需要先接入 Reddit 配置，请参考 Reddit 接入
