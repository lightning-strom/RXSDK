抖音小游戏

登录​

启动路径参数注意事项

SDK 登录内部会从启动路径上获取参数，用于裂变和导量效果的数据分析，所以 CP 如果需要自定义分享需要拼接以下参数，分享参数来自 getShareData 接口，并且注意除了 CP 自定义分享场景，不要使用以下参数！！！

字段类型备注
typestringrx
user_sourcestringshare ｜ guide ｜ transmits

share 分享 guide 导量 transmits 自定义透传参数

分享相关字段

字段类型备注
landing_idstring广告推广来源信息
trigger_idstring埋点 ID
trigger_tagstring埋点唯一标识
trigger_typestring埋点类型
material_typestring分享素材类型
material_idstring分享素材类型
strategy_typestring策略类型
strategy_idstring策略唯一 ID
share_timestring分享时间
share_typestringmini ，游戏客户端自定义的分享类型
inviter_regionstring分享者所在地区编码
inviter_openidstring分享者的望舒 openid
inviter_productidstring分享者的产品 ID, 若为空, 则通行证通过 inviter_openid 获取关联信息
inviter_channelidstring分享者的渠道 ID, 若为空, 则通行证通过 inviter_openid 获取关联信息
inviter_subchannelidstring分享者的子渠道 ID, 若为空, 则通行证通过 inviter_openid 获取关联信息

导量相关字段

字段类型备注
guide_platformstring导量来源游戏平台
guide_appstring导量来源游戏 app 标识

transmits 字段

transmits 的数据为透传参数，规则需要满足 user_source=transmits ，除 user_source=transmits 外其他拼接的参数登录后将原样返回。

示例： https://xxx.html?user_source=transmits&a=b&c=d 登录成功数据会新增字段 user_transmits:{"a":"b", "c":"d"}

首次登录​

参数说明​

字段类型是否必填备注
paramsILogin是参数
callbackIMethodParams是回调函数集合

ILogin 说明

字段类型是否必填备注
forceboolean是未登录时, 是否强制调起登录框
methodstring是'douyinh5'，登录账号的类型

IMethodParams 说明

字段备注
complete(data) => void

complete ：为函数且必传， data 为结果数据

调用示例​

sdk.login(
 {
 force: true,
 method: "douyinh5",
 },
 {
 complete: (data) => {
 console.log(data);
 },
 }
);

获取验证码​

优先根据指定 email 或 phone 发送验证码；

否则根据当前登录的手机或者邮箱账号发送验证码。

参数说明​

字段类型是否必填备注
paramsISendCaptcha是参数
callbackIMethodParams是回调函数集合

ISendCaptcha 说明

字段类型是否必填备注
emailstring否接收验证码的邮箱地址
phonestring否接收验证码的手机号
purposestring是验证码的用途

purpose 说明

字段备注
register注册
bindphone绑定手机
unbindphone解绑手机
resetpwd重置密码
bindemail绑定邮箱
unbindemail解绑邮箱
login登录
setpwd设置密码

IMethodParams 说明

字段备注
complete(data) => void

complete ：为函数且必传， data 为结果数据

调用示例​

sdk.sendCaptcha(
 {
 phone: "18626656376",
 purpose: "bindphone",
 },
 {
 complete: (data) => {
 console.log(data);
 },
 }
);

响应结构​

{
 "code": 0,
 "data": {
 "interval": 60,
 "surplus": 60
 }
}

获取用户信息​

参数说明​

字段类型是否必填备注
callbackIMethodParams是回调函数集合

IMethodParams 说明

字段备注
complete(data) => void

complete ：为函数且必传， data 为结果数据

调用示例​

sdk.getInfo({
 complete: (data) => {
 console.log(data);
 },
});

响应结构​

字段类型说明
ageNumber用户年龄，根据实名信息获取。
sexNumber性别。0 表示女性， 1 表示男性。
user_stateNumber用户状态定义, 0 为正常用户。为正数时，使用各位编码用户的不同状态（以下表述中，第 0 位表示最低位）:第 0 位: 为 1 表示玩家已提交注销申请第 1 位: 为 1 表示已注销。可以是客服同意玩家的注销申请，也可以是客服直接在后台操作将账号注销。第 2 位: 为 1 表示已封停。
attrNumber账号状态标记，使用位运算构成。参考下文 attr 标记说明
openidString望舒用户 OpenID。
external_openidString三方 openid
external_unionidString三方 unionid
wx_unionidString[DEPRECATED] 三方 unionid
mobile_phoneString手机号
nicknameString昵称
avatarurlString头像
idCardString身份证号
realNameString姓名
attr标记​

attr 标记，由以下标记位构成

标识备注
0是否已通过望舒完成实名认证， 1 表示已实名。
1用户当前是否有绑定手机号， 1 表示有绑定。
2用户当前是否有绑定邮箱， 1 表示有绑定。
3用户当前是否有已设置密码的登录凭证， 1 表示有。
4用户是否通过望舒完成实名认证， 1 表示是。

响应结构​

{
 "code": 0,
 "data": {
 "avatarurl": "",
 "mobile_phone": "159****7520",
 "nickname": "rssllyn",
 "openid": "rxuWFnlHRbTZ5ED5TkwAG5XVQ==",
 "sex": 0,
 "user_state": 0,
 "attr": 0
 }
}
