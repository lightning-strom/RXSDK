登录​

启动路径参数注意事项

提示

SDK 登录内部会从启动路径上获取参数，用于裂变和导量效果的数据分析，所以 CP 如果需要自定义分享需要拼接以下参数，分享参数来自 getShareData 接口，并且注意 除了 CP 自定义分享场景，不要使用以下参数！！！

字段类型备注
typestringrx
user_sourcestringshare ｜ guide ｜ transmits
share 分享 guide 导量 transmits 自定义透传参数

分享相关字段

字段类型备注
landing_idstring广告推广来源信息
trigger_idstring埋点 ID
trigger_tagstring埋点唯一标识
trigger_typestring埋点类型
material_typestring分享素材类型
material_idstring分享素材类型
strategy_typestring策略类型
strategy_idstring策略唯一 ID
share_timestring分享时间
share_typestringmini，游戏客户端自定义的分享类型
inviter_regionstring分享者所在地区编码
inviter_openidstring分享者的望舒 openid
inviter_productidstring分享者的产品 ID, 若为空, 则通行证通过 inviter_openid 获取关联信息
inviter_channelidstring分享者的渠道 ID, 若为空, 则通行证通过 inviter_openid 获取关联信息
inviter_subchannelidstring分享者的子渠道 ID, 若为空, 则通行证通过 inviter_openid 获取关联信息

导量相关字段

字段类型备注
guide_platformstring导量来源游戏平台
guide_appstring导量来源游戏 app 标识

transmits 字段

transmits 的数据为透传参数，规则需要满足user_source=transmits，除user_source=transmits外其他拼接的参数登录后将原样返回。 示例：https://xxx.html?user_source=transmits&a=b&c=d
登录成功数据会新增字段user_transmits:{"a":"b", "c":"d"}

首次登录​

  • JS
  • Unity

参数说明​

字段类型是否必填备注
paramsILogin是参数
callbackIMethodParams是回调函数集合

ILogin 说明

字段类型是否必填备注
versionstring是是否拉起用户信息授权base 不拉起用户授权弹窗normal 拉起用户授权弹窗==💡：base 不会拉起用户授权所以不会传递加密值可能获得不到头像等数据，如果需要获取头像建议传递 normal==
methodstring是'minigame'，登录账号的类型
sign_fieldsstring[]否指定对登录成功后返回的特定字段, 使用 CPKEY 计算签名. CP 服务器可重新计算签名并与登录返回的签名比对, 作为对望舒登录数据的校验. 支持的字段包括: nickname, avatar, openid, region, sex, age, 计算签名的逻辑会对指定字段进行排序, 此处传参与顺序无关.
reconnect_loginboolean否否是【断线重连】，用于区分 SDK 内部是否需要处理登录后的逻辑（拉取商业化数据）true 不拉取商业化数据==SDK v3.5.0 版本开始支持==
extExt否扩展字段

ext 结构说明

字段类型是否必填备注
custom_extCustomExt否自定义透传参数

CustomExt 结构说明

字段类型是否必填备注
bigdata_extobject否大数据预置事件透传参数

IMethodParams 说明

字段备注
complete(data) => voidcomplete：为函数且必传，data 为结果数据

调用示例​

sdk.login(
  {
    version: "base",
    method: "minigame",
    ext: {
        custom_ext: {
          // 大数据预置事件透传参数
          bigdata_ext: {
            test: `test`
          }
        }
    }
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);

参数说明​

字段类型是否必填备注
versionstring是是否拉起用户信息授权base 不拉起用户授权弹窗normal 拉起用户授权弹窗==💡：base 不会拉起用户授权所以不会传递加密值可能获得不到头像等数据，如果需要获取头像建议传递 normal==
loginTypestring是'minigame'，登录账号的类型

调用示例​

using System;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.UI;
using RuiXue;
using RuiXue.Login;

#if UNITY_WEBGL
using RuiXue.MiniGame.WeiXin;
#endif

public class RuiXueWeiXinMiniGameDemo : MonoBehaviour {
    private void OnLogin()
    {
        LogUtil.Log("RXDemo", "点击登录");
        
        LoginConfig loginConfig = new LoginConfig();
        loginConfig.loginType = LoginMethod.Minigame;
        loginConfig.version = "base";
        
        RXLogin.Login(loginConfig, OnResponse, OnError);
    }
    
    public void OnResponse(string data)
    {
        LogUtil.Log("RXDemo",$"Response: {data}");
    }
    
    public void OnError(string data)
    {
        LogUtil.Log("RXDemo", $"Error: {data}");
    }
}

获取验证码​

提示

优先根据指定 email 或 phone 发送验证码； 否则根据当前登录的手机或者邮箱账号发送验证码。

  • JS
  • Unity

参数说明​

字段类型是否必填备注
paramsISendCaptcha是参数
callbackIMethodParams是回调函数集合

ISendCaptcha 说明

字段类型是否必填备注
emailstring否接收验证码的邮箱地址
phonestring否接收验证码的手机号
purposestring是验证码的用途
authstring否是否使用小游戏登录鉴权，默认false，建议设置为true

purpose 说明

字段备注
register注册
bindphone绑定手机
unbindphone解绑手机
resetpwd重置密码
bindemail绑定邮箱
unbindemail解绑邮箱
login登录
setpwd设置密码

IMethodParams 说明

字段备注
complete(data) => voidcomplete：为函数且必传，data 为结果数据

调用示例​

sdk.sendCaptcha(
  {
    phone: "18626656376",
    purpose: "bindphone",
    auth: true
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);

参数说明​

CaptchaType 说明

字段类型是否必填备注
emailstring否接收验证码的邮箱地址
phonestring否接收验证码的手机号
purposestring是验证码的用途

purpose 说明

字段备注
register注册
bindphone绑定手机
unbindphone解绑手机
resetpwd重置密码
bindemail绑定邮箱
unbindemail解绑邮箱
login登录
setpwd设置密码

修改用户信息​

提示

由于部分项目的 用户信息（头像、昵称、性别） 没有直接使用望舒通行证数据，而是采用由望舒通知游戏服务器同步方式，在网络不好时可能会通知失败，导致游戏服务器存储的用户信息和望舒通行证信息不一致的情况。

每次调用修改用户信息时望舒会重新通知游戏服务器，为 降低通知频率 减少服务器压力 每次调用 updateUserInfo 时可将旧用户信息传入 ext 中，望舒对信息进行比对后将未修改的用户信息通知给游戏服务器，已修改的用户信息不会同步。

  • JS
  • Unity

参数说明​

callbackIMethodParams是回调函数集合

IUpdateUserInfo 说明

字段类型是否必填备注
nicknamestring是昵称
avatarurlstring是头像地址
regionstring是用户所在地区编码
sexstring是性别，0 表示女性，1 表示男性
extNSDictionary否透出参数，目前仅作为数据校验使用

ext 说明

字段类型是否必填备注
old_avatarurlNSString否旧头像 url
old_nicknameNSString否旧用户昵称
old_sexNSString是旧性别，1 男 0 女，无改动传-1，不传会默认修改为女性
