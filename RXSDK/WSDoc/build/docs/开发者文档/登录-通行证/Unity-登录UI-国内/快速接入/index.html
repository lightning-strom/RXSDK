快速接入

接入方式​

Package Manager 导入 RuiXue.UI

SDK 集成​

  • iOS
  • Android

iOS依赖的相关SDK已通过脚本自动引用到工程中，您无需手动引用。受网络环境等因素影响，相关SDK有可能引用失败，所以在生成iOS工程后，您需要检查工程中的Podfile文件中的SDK名称，在Podfile.lock文件中是否存在，如果Podfile中的SDK名称在Podfile.lock中未存在，说明SDK未完全下载成功，您需要进入Podfile文件所在路径，执行以下命令安装SDK：

pod install

具体集成方法参照快速开始 Android SDK 集成

  //[可选] 使用 SDK UI 时候接入此库
  implementation 'com.ruixue:rxsdk_base_ui:${version}'

第三方登录:

  • 微信登录，请参照 微信配置

  • 一键登录引入 SDK:

  implementation 'com.ruixue:rxsdk_alimobile:${version}'

登录​

"非法注册（限制代码 1 ）" code : 312232 为 注册 ip 限制，默认开启，同一 ip 默认 1 小时注册账号不能超过 2 个，如有需求请联系商务添加 ip 白名单或调整限制条件。"非法注册（限制代码 2 ）" code : 312232 为 注册设备限制，默认关闭，同一设备 x 小时注册账号不能超过 x 个，如有需求请联系商务开启。

登录弹窗​

登录弹窗分为两种样式：

（建议）登录配置： loginUIConfig.isHistoryViewEnable = true ， SDK 会记录已登录的账号记录，下次调用会展示登录历史弹窗；

不使用快捷方式： loginUIConfig.isHistoryViewEnable = false ，不显示快捷登录界面；

设置为登录后强制实名认证时登录成功的数据将在实名认证后返回，并且不会返回实名认证的结果，只会在 UI 上体现实名认证成功。如需要获取实名认证回调数据，请关闭登录后强制实名认证设置，并单独调用实名认证 UI。

UI 示例

接口原型

void LoginUI(LoginUIConfig config, RequestResponseDelegate responseDelegate,
 RequestError DelegateerrorDelegate);

调用示例

使用后台配置: 登录方式，以及对应平台登录密钥，等其它参数可在后台配置。


 public void LoginResponseDelegate(string data)
 {
 LogUtil.Log("EventManager", $"RequestResponseDelegate: {data}");
 }
 public void LoginErrorDelegate(string data)
 {
 LogUtil.Log("EventManager", $"RequestErrorDelegate: {data}");
 }

 public void OnLoginUI()
 {
 RXLoginUI.LoginUI(null, LoginResponseDelegate, LoginErrorDelegate);
 }

同步账号记录​

用于同步非望舒的账号密码登录记录，需要在调用登录 UI 前调用同步。

接口原型

public void SyncAccounts(ListDictionarystring, string>> accounts);

调用示例

 public void OnSyncAccounts()
 {
 ListDictionarystring, string>> list = new ListDictionarystring, string>>();
 Dictionarystring, string> map = new Dictionarystring, string>();
 map.Add("username", "username1");
 map.Add("password", "pwd111111!");
 list.Add(map);
 RXLoginUI.SyncAccounts(list);
 }

撤销账号注销​

因翻译问题海外版暂不支持自定义按钮文案。使用自定义文案方式点击 撤销注销 将返回文案 "撤销注销"，点击非撤销注销返回定义的文案。

UI 示例

接口原型

 void DestroyAccountStatusView(bool isLoginContinue, RequestResponseDelegate responseDelegate,
 RequestErrorDelegate errorDelegate, RequestExtDelegates extDelegates);

 void DestroyAccountStatusView(string okButtonText, RequestResponseDelegate responseDelegate,
 RequestErrorDelegate errorDelegate, RequestExtDelegates extDelegates);

参数说明​

字段备注
isLoginContinue右侧按钮文本 true 继续登录
okButtonText设置右侧按钮自定义文本，默认继续登录

调用示例


 public void OnDestroyAccount1()
 {
 RequestExtDelegates extDelegates = new RequestExtDelegates
 {
 IOSDestroyAccountDeregisterTypeDelegate = IOSDestroyAccountDeregisterType
 };

 RXLoginUI.DestroyAccountStatusView(true, DestroyAccountResponseDelegate, DestroyAccountErrorDelegate, extDelegates);
 }

 public void OnDestroyAccount2()
 {
 RequestExtDelegates extDelegates = new RequestExtDelegates
 {
 IOSDestroyAccountDeregisterBtnTitleDelegate = IOSDestroyAccountDeregisterBtnTitlee
 };

 RXLoginUI.DestroyAccountStatusView("知道了", DestroyAccountResponseDelegate, DestroyAccountErrorDelegate, extDelegates);
 }

 public void DestroyAccountResponseDelegate(string data)
 {
 LogUtil.Log("EventManager", $"DestroyAccount RequestResponseDelegate: {data}");
 }
 public void DestroyAccountErrorDelegate(string data)
 {
 LogUtil.Log("EventManager", $"DestroyAccount RequestErrorDelegate: {data}");
 }
 public void IOSDestroyAccountDeregisterType(int param)
 {
 LogUtil.Log("EventManager", $"IOSDestroyAccountDeregisterTypeDelegate: {param}");
 }

 public void IOSDestroyAccountDeregisterBtnTitlee(string param)
 {
 LogUtil.Log("EventManager", $"IOSDestroyAccountDeregisterBtnTitlee: {param}");
 }

响应结构​

  • Android

接口原型

void UserCenterUI(UserCenterUIConfig config, RequestResponseDelegate responseDelegate, RequestErrorDelegate errorDelegate);

参数说明​

Map 结构说明

字段备注
transmit_args透传数据，使用 jsonString 形式
game_user_id用户的游戏 id
nickname用户昵称
head_img_url用户头像
queue_name在望舒客服系统设置的接入点名称 不填写默认为 default

配置用户中心模块 UserCenterView 类 setConfigParams 参数说明

字段类型备注
bntsArray配置用户中心入口

bnts 说明

字段备注
real_name实名认证
privacy_policy撤销注销
binding_phone隐私政策
acount_cancel账号注销
phone_management手机号管理
change_pwd修改密码

配置用户中心模块 UserCenterView 类 setJsDisable 函数说明

字段类型备注
JsDisableboolean是否禁用 js 交互方式

调用示例

 public void OnUserCenterUI()

绑定手机/换绑手机​

当前登录用户未绑定手机时，跳转到绑定页面，正常展示绑定手机页面，如当前用户已绑定过手机，则自动进入换绑手机页面

UI 示例

接口原型

/// summary>
/// 绑定/换绑手机
/// summary>
/// param name="responseDelegate">param>
/// param name="errorDelegate">param>
public static void bindPhone(RequestResponseDelegate responseDelegate, RequestErrorDelegate errorDelegate);

调用示例

public void bindClick()
{
 RXLoginUI.bindPhone(bindResponseDelegate, bindErrorDelegate);
}
