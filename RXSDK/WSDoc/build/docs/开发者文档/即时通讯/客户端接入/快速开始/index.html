快速开始

准备工作​

  • Android
  • iOS

在使用 SDK 时，部分接口对设备权限有要求，因此需要使用者在调用涉及以下功能的接口时注意，动态申请权限：

具备读、写本地磁盘的接口（如：发送图片、文件等）：

android.permission.READ_EXTERNAL_STORAGE
android.permission.WRITE_EXTERNAL_STORAGE

具备录音的特性的接口（如：发送语音）：

android.permission.RECORD_AUDIO

注意：如果不使用读取磁盘和录音操作，可以不用集成这些权限。

无需额外权限配置。

SDK 集成​

  • iOS
  • Android

编辑 Podfile 文件，添加如下配置：

pod 'RXNetworkingKit'
pod 'YYModel'
pod 'AliyunOSSiOS'
pod 'WCDB'
pod 'RXIMSDK-iOS'

手动依赖接入

配置权限（必填）：

<uses-permission android:name="android.permission.INTERNET">
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE">
<uses-permission android:name="android.permission.ACCESS_WIFI_STATE">
<uses-permission android:name="android.permission.CHANGE_WIFI_STATE">

下载 RXSDK_IM-${version}.aar 到 libs 路径下，绑定 libs 的引用路径：

android {
    repositories {
        flatDir {
            dirs 'libs'
        }
    }
}

依赖必要组件：

版本说明

version 为 SDK 版本号（替换为实际版本号），最新版本请从 更新日志 中查看。

implementation fileTree(dir: "libs", include: ["*.jar"])
implementation 'com.squareup.okhttp3:okhttp:3.12.3'
implementation 'com.aliyun.dpa:oss-android-sdk:2.9.5'
implementation 'com.google.protobuf:protobuf-java:3.11.1'
implementation 'com.google.code.gson:gson:2.8.6'
implementation 'org.java-websocket:Java-WebSocket:1.5.3'

implementation(name: 'RXSDK_IM-${version}', ext: 'aar')

自动依赖接入（推荐）

implementation 'com.ruixue.im:rxsdk_im:${version}'

初始化​

将 SDK 集成到客户端后，需要先完成 SDK 的初始化才能使用其他功能。

  • iOS
  • Android

接口原型

/**
 * 初始化SDK
 * @param productId 产品id
 * @param channelId 渠道id
 * @param cpId 产品cpid
 * @param clientType 客户端类型
 * @param version sdk版本号
 * @param baseUrl 服务器域名
 */
- (void)initWithProductId:(NSString * _Nonnull)productId
 channelId:(NSString * _Nonnull)channelId
 cpid:(NSInteger)cpId
 clientType:(NSInteger)clientType
 version:(NSString * _Nonnull)version
 baseUrl:(NSString * _Nonnull)baseUrl;

调用示例

- (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
 [[RXIMSDKManager sharedSDK] initWithProductId:@"test_product" channelId:@"test_channel" cpid:1000000 clientType:262657 version:@"v1.0.0" baseUrl:@"https://ruixue.weiletest.com"];
 return YES;
}

参数说明​

字段类型是否必填备注
productIdNSString是产品 id
channelIdNSString否渠道 id
cpIdNSString是cpid
clientTypeNSInteger是客户端类型参照数据约束，如 iPhone: 0x00000001
versionNSString否版本号，仅做观察使用，不影响功能
baseUrlNSString是请求域名
RXLoginNecessaryArgs args = new RXLoginNecessaryArgs();
args.setContext(this.getApplicationContext());
args.setChanelID("后台channelid");
args.setProductID("后台productid");
args.setCpID("1000000");
args.setClientType(131585);
args.setHostUrl("https://rapi.weiletest.com");
args.setDeviceCode(RuiXueSdk.getDeviceCode());
args.setUserID("用户ID");
args.setSecret("secret");
args.setIMToken("im_token");
args.setRefreshToken("refresh_token");

// 注册连接状态监听器
RXIMEngine.getInstance().registerConnectObserver(new IRXConnectObserver() {
    @Override
    public void onLoginResult(final JXIMStatusMapper mapper, Throwable extra) {
        // 登录结果
    }

    @Override

连接与登录​

  • iOS
  • Android

设置数据库基地址（非必须）​

[[RXIMSDKManager sharedSDK] setDBBasePath:@"沙盒路径"];

连接​

[[RXIMSocketEngine sharedSDK] onStart];

注册连接监听：

[RXIMSocketEngine sharedSDK].delegate = self;

#pragma mark - 连接成功回执
- (void)onSocketConnectSuccess {

}

#pragma mark - 连接断开回执
- (void)onSocketDisconnect:(NSError *)error {

}

登录​

[[RXIMSDKManager sharedSDK] loginRXIMSDKWithUserId:@"用户ID" accessToken:@"访问令牌" refreshToken:@"刷新令牌" aesKey:@"AES密钥" complete:^(RXIMError * _Nonnull error) {
 if (!error) {
 NSLog(@"登录成功");
 } else {
 NSLog(@"登录失败");
 }
}];

参数说明​

字段类型是否必填备注
userIdNSString是格式 ^[a-zA-Z\d_-]{1,32}$，1-32 个字符
accessTokenNSString否访问令牌
refreshTokenNSString是刷新令牌
aesKeyNSString是AES 密钥

绑定消息监听器​

RXIMEngine.getInstance().registerConversationObserver(new IRXConversationObserver() {
    @Override
    public void onReceive(ConversationType conversationType, RXIMMessage contentMessage) {
        // 处理接收到的消息
    }
});

获取模块​

SDK 的方法设计都是按照功能进行模块化分区，可以通过下面接口获取其他模块：

// ProcessModuleInventory.BOOT
// ProcessModuleInventory.CONVERSATION
// ProcessModuleInventory.SESSION
// ProcessModuleInventory.HISTORY
RXIMEngine.getInstance().catchModule(ProcessModuleInventory.枚举值);

退出​

客户端在下线或者切换账号等情况下需要退出 IM，用来断开 socket 连接切断通信以及清理缓存；再次上线或登录新账户时需要重新调用登录接口来完成 socket 连接进行通信。

  • iOS
  • Android
[[RXIMSDKManager sharedSDK] logout];
RXIMEngine.logout();
