基本功能​

同步消息​

拉取用户离线后收到的消息或者在全新设备上拉取当前账号的所有消息。消息会通过 RXIMMessageDelegate 协议回调函数 receiveMessage 通知客户端；同步完成会通过回调函数 syncMessageFinished 通知客户端。可以选择在登录成功之后的回调中触发。

接口原型

/**
 * 同步消息
 */
-(void)syncMessage;

调用示例

[[RXIMChatService sharedSDK] syncMessage];

发送消息​

生成 RXIMMessage 的对象之后，通过此接口进行发送消息操作。客户端需要通过 RXIMMessageDelegate 协议里的方法 sendMessageSuccess 和 sendMessageFailure 来进行消息发送结果的监听。

接口原型

/**
 * 发送消息
 * @param sendMessage 发送的消息对象
 * @param completionHandler 返回消息对象，处理本地逻辑用，发送成功以delegate方式回调。
 */
- (void)sendMessage:(RXIMSendMessage * _Nonnull)sendMessage
 completionHandler:(void (^)(RXIMMessage * message,RXIMError *error))completionHandler;

#param mark -- 发送结果监听
/**
 * 消息发送成功
 */
- (void)sendMessageSuccess:(RXIMMessage *)msgObj;
/**
 * 消息发送失败
 */
- (void)sendMessageFailure:(RXIMMessage *)msgObj error:(RXIMError *)error;

调用示例

#pragma mark - RXIMMessageDelegate>
#pragma mark - 消息发送成功回执
- (void)sendMessageSuccess:(RXIMMessage *)msgObj
{
 NSLog(@"消息发送成功");
 self.msgObj = msgObj;
 [SVProgressHUD showSuccessWithStatus:[NSString stringWithFormat:@"%@ 发送成功",msgObj.msgId]];
}

#pragma mark - 消息发送失败回执
- (void)sendMessageFailure:(RXIMMessage *)msgObj error:(RXIMError *)error
{
 NSLog(@"消息发送失败");
 [SVProgressHUD showErrorWithStatus:[NSString stringWithFormat:@"code = %ld errMsg = %@",error.code,error.developerMessage]];
}

接收消息​

当收到服务器发来的消息时，可以通过此接口对其进行处理，如您可以 RXIMMessage 中的 RXIMMessageType 来区分消息类型用于不同场景。接收消息会通过 RXIMMessageDelegate 协议回调函数 receiveMessage 通知客户端。

接口原型

/**
 * 消息接收
 */
- (void)receiveMessage:(NSArrayRXIMMessage *> *)msgs;

调用示例

#pragma mark - RXIMMessageDelegate>
#pragma mark - 消息接收回执
- (void)receiveMessage:(NSArrayRXIMMessage *> *)msgs
{
 NSLog(@"接收消息");
 self.msgObj = msgs.lastObject;
 for (RXIMMessage *msg in msgs) {
 self.msgCount++;
 NSLog(@"%@", [NSString stringWithFormat:@"接收消息%ld成功",(long)self.msgCount]);
 }

}

发送消息​

获取消息模块

ConversationModule conversationModule = RXIMEngine.getInstance().catchModule(ProcessModuleInventory.CONVERSATION);

说明：发送消息时，使用 Conversation#sendMessage()方法，传入不同的消息模型，发送不同消息。这些消息模型都实现 ISenderMessageEntity 接口。

接口原型

/**
    * 发送消息
    * @param receiver 接收人，使用OpenID
    * @param entity 目标消息模型
    * @param extend 扩展字段
    * @param option 发送消息选项
    * @param type 聊天模式，单聊、群聊、自定义单聊、频道会话
    * @param moreReceivers @群成员，只有群聊生效
    * @param observer 发送消息状态回调
    */
public void sendMessage(String receiver, ISenderMessageEntity entity, String extend, int option, ConversationType type, List<String> moreReceivers, IRXSendingObserverRXIMMessage> observer)

回调参数说明​

作为发送消息的回调接口，IRXSendingAttachmentObserver 接口继承自 IRXSendingObserver 接口，前者更多使用在带附件上传的场景中，比如：发送图片、视频、文件等，需要使用 IRXSendingAttachmentObserver 接口用于监听文件上传过程；而对于普通消息，如：发送文本、转发文本、撤回消息等，只需要使用 IRXSendingObserver 接口监听消息发送状态。

IRXSendingObserver 结构说明

public interface IRXSendingObserverT>{
    void onStart(T contentMessage);//消息发送开始
    //消息发送完成，注意只是代表消息发送完成，需要根据code值判断消息状态，具体值参考状态码部分
    void complete(int code, T contentMessage);
}

IRXSendingAttachmentObserver 结构说明

public interface IRXSendingAttachmentObserverT> extends IRXSendingObserverT>{
    void onUploadStart(RXIMMessage message);//附件上传开始
    void onUploadProgress(String percent, long currentSize);//进度，多附件回显示整体进度
    void onUploadComplete(RXIMMessage message);//上传完成
    void onUploadErrorOccur(RXIMMessage unSendMessage,String errorFromClient,String errorCodeFromRemote,String errorFromRemote);//上传出现错误
}

接收消息​

当收到服务器发来的消息时，可以通过此接口对其进行处理。

接口原型

/**
    * 消息接收监听
    */
void registerConversationObserver(IRXConversationObserver observer)

调用示例

RXIMEngine.getInstance().registerConversationObserver(new IRXConversationObserver() {
    @Override
    public void onReceive(ConversationType conversationType, RXIMMessage contentMessage) {
// LG.e(contentMessage.toString());
    LG.e(contentMessage.getExtend());
    if(contentMessage.getMsgType() == MessageTypeInventory2.TEXT){
    TextMessageEntity entity = contentMessage.getContentEntity();
    LG.e(entity.toString());
    }else if(contentMessage.getMsgType() == MessageTypeInventory2.PIC){
    PicMessageEntity entity = contentMessage.getContentEntity();
    LG.e(entity.toString());
    }else if(contentMessage.getMsgType() == MessageTypeInventory2.AUDIO){
    VoiceMessageEntity entity = contentMessage.getContentEntity();
    LG.e(entity.toString());
    } else if(contentMessage.getMsgType() == MessageTypeInventory2.VIDEO){
    VideoMessageEntity entity = contentMessage.getContentEntity();
    LG.e(entity.toString());
    }else if(contentMessage.getMsgType() == MessageTypeInventory2.POSITION){
    LocationMessageEntity entity = contentMessage.getContentEntity();
    LG.e(entity.toString());
    }else if(contentMessage.getMsgType() == MessageTypeInventory2.FACE){
    EmotionMessageEntity entity = contentMessage.getContentEntity();
    LG.e(entity.toString());
    }else if(contentMessage.getMsgType() == MessageTypeInventory2.FILE){
    FileMessageEntity entity = contentMessage.getContentEntity();
    LG.e(entity.toString());
    }
    mStatusTv.append(contentMessage.getInboxID() + " --- " + contentMessage.getMsgType() + " ---- " + contentMessage.getContent() + "\n");
    }
    });
