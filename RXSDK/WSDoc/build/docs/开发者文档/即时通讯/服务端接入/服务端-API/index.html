服务端 API

以下是 CP 服务端请求接口，需要准备好 cp_id product_id channel_id cp_key 等参数。

domain ：为产品对外域名

请求头：望舒服务端请求头

用户登录（仅限服务端使用）​

POST： /v1/ims/server/login

认证方式: CPSign

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/ims/server/login' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--header 'Content-Type: application/json' \
--data-raw '{
 "user_id": "testuser_abc",
 "product_id": "test",
 "channel_id": "test",
 "client_type": 26265
}'

请求参数（JSON）​

字段类型是否必填说明示例
user_idString是用户在 CP 下的唯一标识符
product_idString是客户端产品 ID ，即望舒产品管理中的对应值
channel_idString是客户端渠道 ID ，即望舒产品管理中的对应值
device_codeString否设备码
client_typeNumber是客户端类型，其是一个位运算结果值

注意：该参数要与 IMS SDK 初始化传入的一致

请求示例

{
 "user_id": "testuser_abc",
 "product_id": "test",
 "channel_id": "test",
 "client_type": 26265
}

响应参数（JSON）​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码， 0 为成功，非 0 表示出错0
msgString否响应信息，仅在 code 非 0 时返回data
Token否返回数据对象

发送消息​

POST： /v1/ims/server/sendmessage

认证方式: CPSign

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/ims/server/sendmessage' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--header 'Content-Type: application/json' \
--data-raw '{
 "option": 3,
 "client_type": 256,
 "type": 2,
 "uuid": "91a5ca77-ab9d-4dee-b5a6-ac440da22c4b",
 "sender": "a",
 "conversation_id": "$1$a:b",
 "conv_type": 1,
 "product_id": "test",
 "channel_id": "test",
 "content": "{\"text\":\"hahaha\"}",
 "ext": null
}'

请求参数（JSON）​

字段类型是否必填说明
optionNumber否消息选项（位运算组合
client_typeNumber是客户端类型，其是一个位运算结果值
typeNumber是消息类型
sub_typeNumber否消息子类型，当 type 为 CP 自定义消息时有效， CP 请使用 [ 1 , 1 亿 ]
uuidString是消息发送者在发送时生成的唯一 ID ，用于去重
senderString是发送人 UserID
receivers[]String否
接收人列表，单聊必须为空；群聊表示 @ 用户列表；自定义单聊表示实际接收人 UserID 清单；conversation_idString
是会话 IDconv_type
Number是会话类型，即会话 ID 两个 $ 中间的值
product_idString是产品 ID
channel_idString是
渠道 IDcontentString
是消息内容 JSON 字符串ext
Map[String]String否CP 扩展字段

注意：服务端发送消息时，该值应尽量为空，否则对于群聊或频道聊天要保证其已加入会话

请求示例

{
 "option": 3,
 "client_type": 256,
 "type": 2,
 "uuid": "91a5ca77-ab9d-4dee-b5a6-ac440da22c4b",
 "sender": "a",
 "conversation_id": "$1$a:b",
 "conv_type": 1,
 "product_id": "test",
 "channel_id": "test",
 "content": "{\"text\":\"hahaha\"}",
 "ext": null
}

响应参数（JSON）​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码， 0 为成功，非 0 表示出错0
msgString否响应信息，仅在 code 非 0 时返回data
Send否返回数据对象

Send​

字段类型是否必填说明
msg_idString是消息唯一 ID ，发送成功后由服务端生成
uuidString是发送者在发送时生成的唯一 ID ，原封不动带回
inbox_idNumber是当前用户信箱序列号
milli_tsNumber是毫秒时间戳

响应示例

{
 "data": {
 "msg_id": "1552973976152571904.$1$a:b",

 },

}

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/ims/server/updateconversatonuserdata' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--header 'Content-Type: application/json' \
