数据约束

userid​

用户 ID 采用字符串类型，格式为 ^[a-zA-Z\d_-]{1,32}$ ，即：只能由 数字、大小写字母、_、- 组成，长度为 1-32 个字符。

注意：不论 CP 方有多少个游戏，每个游戏有多少个区服，一定确保用户 ID 对于 CP 方是唯一的。

会话id​

会话 ID 同样为字符串类型，以支持匿名和客服等多样需求，举例：

单聊： $1$a:b （用户 ID 为 a 的和用户 ID 为 b 的用户聊天）；

群聊： $2$testgroup ；

自定义单聊： $3$test ；

频道聊天： $4$testchannel ；

会话类型​

格式： $会话类型 ID$会话 ID 数据 。

其中 会话类型 ID 是一个整数值； 会话 ID 数据 为该类型的具体参数，会根据不同的类型有各自的规则。

需要注意的是，自定义单聊会话 ID 格式与用户 ID 相同，即：^[a-zA-Z\d_-]{1,32}$

会话类型 ID功能数据拼接规则数据拼接示例

2群聊$2$群 ID$2$testgroup

客户端类型​

// 客户端类型定义, 为一个 int32 整形
// 格式为:
// --------------------------------------
// | 1byte | 1byte | 1byte | 1byte |
// --------------------------------------
// | 预留 | 系统类型 | 实现方式 | 设备平台 |
// --------------------------------------
//
// 同一用户同一时间, 单一设备标记下只能有一个客户端连接, 如重复连接将会把旧连接踢掉
//
// 即: 目前同一用户仅能同时登录 4 个设备
const (
 ClientTypePlatformPhone = 0x00000001 // 设备: Phone
 ClientTypePlatformPad = 0x00000002 // 设备: Pad
 ClientTypePlatformDesktop = 0x00000004 // 设备: 桌面端
 ClientTypePlatformWeb = 0x00000008 // 设备: Web
 ClientTypeTechServerAPI = 0x00000100 // 实现: 服务端接口
 ClientTypeTechNative = 0x00000200 // 实现: Native
 ClientTypeTechJS = 0x00000400 // 实现: Javascript
 ClientTypeOSHarmony = 0x00010000 // 系统: 鸿蒙
 ClientTypeOSAndroid = 0x00020000 // 系统: Android
 ClientTypeOSiOS = 0x00040000 // 系统: iOS
 ClientTypeOSWindows = 0x00080000 // 系统: Windows
 ClientTypeOSMacOS = 0x00100000 // 系统: MacOS
 ClientTypeOSLinux = 0x00200000 // 系统: Linux
)
