创建排行榜​

接口原型

// CreateRank 创建排行榜
func (c *Client) CreateRank(rankID string, startTime, destroyTime time.Time) error

参数说明​

字段类型是否必填备注
rankIDstring是排行榜 id。字符串本身带有类型信息，格式为： Flag_榜单容量_持续时间(单位小时)_自定义标识（ Flag 是一个 int64 位标记，用以扩展和规定绑定属性); 持续时间如果 <=0 表示排行榜永久有效
startTimetime.Time是排行榜开始时间
destroyTimetime.Time否排行榜销毁时间，到时自动销毁。销毁时间一定要大于 开始时间+持续时间

调用示例


startTime, _ := tim.Parser(time.RFC3339, "2022-08-16T08:00:00+08:00")
destroyTime , _ := tim.Parser(time.RFC3339, "2022-08-26T08:00:00+08:00")
err := ruixuego.GetDefaultClient().CreateRank("123_100_168_custom", startTime, destroyTime)
if err != nil { panic(err) }

响应结构​

字段类型是否必填备注
errerror是成功时 nil, 其他为错误
