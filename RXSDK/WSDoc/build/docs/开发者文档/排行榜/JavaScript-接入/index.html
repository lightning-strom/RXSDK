Unity​

对用户托管数据进行写数据操作​

托管数据的限制

  1. 每个 openid 所标识的微信用户在每个游戏上托管的数据不能超过 128 个 key-value 对。
  2. 上报的 key-value 列表当中每一项的 key+value 长度都不能超过 1K(1024) 字节。
  3. 上报的 key-value 列表当中每一个 key 长度都不能超过 128 字节。

响应结构​

成功 code 为 0

Unity​

获取当前用户托管数据当中对应 key 的数据​

该接口只可在开放数据域下使用 开放数据域使用指南

响应结构​

字段类型备注
codenumber0: 表示成功
msgstring仅在 code 为非 0 时不为空
dataKVData[]用户的托管 KV 数据列表， 结构参考 微信小游戏 KVData

响应示例

{
    "code":0,
    "data":[
        {
            "key":"score",
            "value":"{\"wxgame\":{\"score\":16,\"update_time\": 1513080573},\"cost_ms\":36500}"
        }
    ]
}

响应结构​

字段类型备注
codenumber0: 表示成功
msgstring仅在 code 为非 0 时不为空
dataUserGameData[]code 为 0，返回同玩好友的托管数据

UserGameData 结构说明

字段类型备注
avatarUrlstring用户的微信头像 url
nicknamestring用户的微信昵称
openidstring用户的 openid
KVDataListKVData[]用户的托管 KV 数据列表， 结构参考 微信小游戏 KVData
