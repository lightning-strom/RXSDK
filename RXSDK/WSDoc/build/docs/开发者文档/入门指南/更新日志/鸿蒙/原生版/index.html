v3.7.4 更新时间 2025-06-23​

功能更新

  • 修复验证码登录参数错误问题。

v3.7.2 更新时间 2025-05-27​

功能更新

  • 使用望舒登录 UI 支持配置是否自动弹出实名认证，通过 RXLoginConfig.indulgeAuth 或望舒后台发行渠道管理 配置，优先读取代码配置，参考文档：登录 UI；
  • 实名认证可配置是否可关闭， RXLoginConfig.canCloseRealAuth 配置，参考文档：登录 UI；
  • 实名认证新增快速认证模式，在同一企业下其他游戏已进行过实名认证的账号可以不传姓名、身份证号直接认证，该账号是否符合快速认证判定条件未：未实名（ attr 首位不为 1 ）且 有脱敏身份信息（ ext 中 realname、idcard ）， attr 和 ext 从登录返回数据获取，参考文档：实名认证接口；
  • 新增自定义身份证键盘功能，参考文档：身份证键盘；
