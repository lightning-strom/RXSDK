版本：v4.x

团结版

SDK 下载地址

注意 ： SDK 版本和团结引擎版本要对齐更新日志中版本，低版本报错需自行做兼容处理。

v3.7.10 更新时间 2025- 12-08​

  • 请升级团结引擎 1.6.7 或以上版本， DevEco Studio 6.0 Release 或以上版本， OpenHarmony API 使用 14 或以上；

功能更新

  • 增加游戏近场快传 api 支持( OpenHarmony API 18 （ 5.1.0 ） 或以上系统支持)。

v3.7.9 更新时间 2025- 12-02​

  • 请升级团结引擎 1.6.7 或以上版本， DevEco Studio 6.0 Release 或以上版本， OpenHarmony API 使用 14 或以上；

功能更新

  • 用户中心切换账号回调 type 从 swith_account 修正为 switch_user ；

v3.7.4 更新时间 2025-06-23​

  • 请升级团结引擎 1.5.3 或以上版本， DevEco Studio 5.0.7 Release 或以上版本， OpenHarmony API 使用 12 或以上；

功能更新

  • 修复验证码登录参数错误问题。

v3.7.2 更新时间 2025-05-27​

  • 请升级团结引擎 1.5.0 或以上版本， DevEco Studio 5.0.7 Release 或以上版本， OpenHarmony API 使用 12 或以上；

功能更新

  • 使用望舒登录 UI 支持配置是否自动弹出实名认证，通过 RXLoginConfig.indulgeAuth 或望舒后台发行渠道管理 配置，优先读取代码配置，参考文档：登录 UI；
  • 实名认证可配置是否可关闭， RXLoginConfig.canCloseRealAuth 配置，参考文档：登录 UI；
  • 实名认证新增快速认证模式，在同一企业下其他游戏已进行过实名认证的账号可以不传姓名、身份证号直接认证，该账号是否符合快速认证判定条件未：未实名（ attr 首位不为 1 ）且 有脱敏身份信息（ ext 中 realname、idcard ）， attr 和 ext 从登录返回数据获取，参考文档：实名认证接口；
  • 新增自定义身份证键盘功能，参考文档：身份证键盘；

v3.7.1 更新时间 2025-05-12​

  • 请升级团结引擎 1.5.0 或以上版本， DevEco Studio 5.0.7 Release 或以上版本， OpenHarmony API 使用 12 或以上；

功能更新

  • 新增大数据上报客户端版本号；
  • 更新 1.5.0 团结引擎版本适配；

v3.7.0 更新时间 2025-03-29​

  • 请升级团结引擎 1.4.3 或以上版本， DevEco Studio 5.0.7 Release 或以上版本， OpenHarmony API 使用 12 或以上；

功能更新

  • 接口通讯加密；

v2.4.5 更新时间 2025-03-14​

  • 请升级团结引擎 1.4.3 或以上版本， DevEco Studio 5.0.7 Release 或以上版本， OpenHarmony API 使用 12 或以上；

功能更新

  • 新增 用户行为统计(初始化、版本更新、登录、实名认证部分)
  • 新增 实名认证显示奖励 UI ；
  • 新版本 build-profile.json5 文件中 需要添加 useNormalizedOHMUrl 配置。

v2.4.4 更新时间 2025-02-20​

  • 请升级团结引擎 1.4.2 或以上版本， DevEco Studio 5.0.7 Release 或以上版本， OpenHarmony API 使用 12 或以上；

功能更新

  • 团结引擎 SendCaptcha API 支持图形验证码验证。
  • 初始化增加 logoResource 参数 可自定义通行证 ui 标题。
  • 编译 release 版本包。

v2.4.3 更新时间 2025-02-11​

  • 请升级团结引擎 1.4.2 或以上版本， DevEco Studio 5.0.7 Release 或以上版本， OpenHarmony API 使用 12 或以上；

功能更新

  • 初始化通过开关控制是否自动弹出剪贴板权限申请，默认自动弹出，用户允许或拒绝后不再弹出，仅本次允许每次都弹出；

v2.4.2 更新时间 2025-01-26​

  • 请升级团结引擎 1.4.0 或以上版本， DevEco Studio 5.0.5 Release 或以上版本， OpenHarmony API 使用 12 或以上；

功能更新

  • 登录支持设备型号，设备网络类型上报。

v2.4.1 更新时间 2025-01-24​

  • 请升级团结引擎 1.4.0 或以上版本， DevEco Studio 5.0.5 Release 或以上版本， OpenHarmony API 使用 12 或以上；

功能更新

  • 新增微信登录功能；
  • 新增碰一碰分享功能；

v2.4.0 更新时间 2025-01-22​

  • 请升级团结引擎 1.4.0 或以上版本， DevEco Studio 5.0.5 Release 或以上版本， OpenHarmony API 使用 12 或以上；

功能更新

  • 隐私协议默认地址添加产品参数；

v2.3.8 更新时间 2025-01-10​

  • 请升级团结引擎 1.3.5 或以上版本， DevEco Studio 5.0.5 Release 或以上版本， OpenHarmony API 使用 12 或以上；

功能更新

  • 支持 OAID 采集，广告归因激活功能 （需要声明 ohos.permission.READ_PASTEBOARD ， ohos.permission.APP_TRACKING_CONSENT 权限），参考文档：剪贴板权限声明；

v2.3.7 更新时间 2024-12-31​

  • 请升级团结引擎 1.3.4 或以上版本， DevEco Studio 5.0.0 Release 或以上版本， OpenHarmony API 使用 12 或以上；

功能更新

  • 支持 oss 功能；

v2.3.6 更新时间 2024-12-12​

  • 请升级团结引擎 1.3.3 或以上版本， DevEco Studio 5.0.0 Release 或以上版本， OpenHarmony API 使用 12 或以上；

功能更新

  • 支持自动弹出用户协议弹出提示 , Init 接口 InitArgs 中增加了 privacyEnable 属性， true 首次启动 app 自动弹出， false 不弹出。

v2.3.5 更新时间 2024-11-25​

  • 请升级团结引擎 1.3.3 版本， DevEco Studio 5.0.0 Release 或以上版本， OpenHarmony API 使用 12 或以上；

功能更新

  • 适配 1.3.3 版本团结引擎；

v2.3.4 更新时间 2024-10-25​

  • 请升级团结引擎 1.3.2 版本， DevEco-Studio 升级 5.0.3.900 release 或以上版本， OpenHarmony api 使用 12 或以上；

功能更新

  • 关联授权取消时自动调用华为解绑接口，可返回上一级重新选择转移/关联；
  • 支持游戏官方账号登录；

v2.3.2 更新时间 2024-10-25​

  • 请升级团结引擎 1.3.1 版本， DevEco-Studio 升级 5.0.3.900 或以上版本， OpenHarmony api 使用 12 或以上；

功能更新

  • 联合登录 UnionLoginArgs 添加 ext 参数支持，支持自定义参数；
  • UnionLoginArgs ext 自定参数中包含 method 和 login_openid 参数时，优先使用望舒二次登录，如报错自动拉起联合登录窗口；

v2.3.1 更新时间 2024-10-24​

  • 请升级团结引擎 1.3.1 版本， DevEco-Studio 升级 5.0.3.900 或以上版本， OpenHarmony api 使用 12 或以上；

功能更新

  • 适配团结引擎 1.3.1 版本，旧版本团结引擎请使用 v2.0.x 版本；

v2.0.3 更新时间 2024-10-15​

功能更新
