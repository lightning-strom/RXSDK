Api 接入须知

HTTP Headers 定义​

望舒的自定义头并没有采用 "X-" 开头的公共前缀范例，而是以 "ruixue-" 开头。注意：为避免产生歧义，所有望舒头参数全部为"小写"字母。

客户端请求头​

Accesstoken 鉴权方式

参数名说明是否必须示例
ruixue-traceid本次请求唯一标识（UUID v4），接口出现错误时可提供给望舒团队快速定位是0e2971af-823a-4298-b7d8-3ef38094b500
ruixue-cpid望舒 CPID，望舒为每个 CP 分配的唯一 ID，从 7 位数 1000000 开始递增是1000000
ruixue-productid产品标识，CP 在望舒后台自行创建，字符串类型是test
ruixue-channelid渠道标识，CP 在望舒后台自行创建，字符串类型是test
ruixue-platformid客户端类型：1=Android，2=iOS，3=H5，4=微信小程序，5=web，6=鸿蒙，10=望舒服务端 SDK是2
ruixue-devicecode设备码，通过策略推导生成的 C 端设备唯一标识（受系统限制，可能无法获取或不 100% 唯一）否abcdefghijklmnopqrstuvwxyz123456
ruixue-language系统语言标识否zh-CN
ruixue-versionSDK 版本号否ios-v2.0.0
ruixue-accesstoken望舒通行证授权令牌，C 端用户登录后由通行证分发，访问需鉴权的接口时必须携带否见下方示例
ruixue-tzoffset基于 UTC 的时区偏移值（小时），不指定时默认为 8（北京时间东 8 区）否8
ruixue-area地区编码否CN

服务端回调接口​

望舒系统接入前，请仔细阅读本条款。请确认要使用的功能，必须实现对应的接口！！！ 接口实现完成后，需要在望舒系统（产品管理 > 回调参数配置）调试与配置。

服务端回调接口目录​

接口标识接口说明使用场景
user-mail[基础运营工具] 给用户发送邮件 + 奖励使用【违规封号处理】时，奖励举报者时会调用此接口
user-warning[用户账号管理] 给用户发送警告使用【违规封号处理】时，警告被举报者时会调用此接口
user-ban[用户账号管理] 封停用户使用【违规封号处理】或【违规举报管理】时，封停用户时会调用此接口
user-unban[用户账号管理] 解封用户使用【违规封号处理】时，解封用户时会调用此接口
user-get_id[客服服务] 通过望舒 openid 换取游戏用户 id使用【客服面板】时，通过玩家 ID 转换调用此接口
user-get_open_id[用户账号管理] 通过游戏用户 id 换取望舒 openid使用【违规举报管理】时，新建违规时添加用户 id 时会调用此接口
user-deregister[望舒通行证] 通过望舒 openid 注销用户使用【通行证 - 用户中心】时，通过望舒 openid 注销用户调用此接口
versioncheck-maintain[基础运营工具] 维护公告使用【游戏公告】时，望舒发布公告时推送给游戏服务端调用此接口
ke-notify[基础配置] 支付成功通知 CP 接口使用【支付】，望舒通知 CP 方支付成功，可以发放物品
ke-checkout-metadata[基础配置] 支付获取 checkout 风控信息补充中
ke-cporder[基础配置] CP 下单回调通知补充中
ke-appstore-refund-request[基础配置] 苹果支付用户申请退款通知用户使用【苹果支付且退款】时，苹果通知望舒有退款申请，望舒将消息转发给 CP 方服务端
ke-appstore-refund-success[基础配置] 苹果支付用户退款成功通知用户使用【苹果或谷歌支付且退款成功】时，望舒将消息转发给 CP 方服务端
channel-notify[基础配置] 渠道回调消息转发补充中
action_user_info_change[望舒通行证] 用户信息变更通知在用户是否实名、头像、昵称、性别任何一项信息发生变化时，会将变化的字段和变化后的值通知给 CP
ims-userconn[用户社交关系] IMS 用户连接/断开通知使用【IM】，望舒通知 CP 方用户是连接状态还是断开状态
ims-sendmsg[用户社交关系] IMS 消息发送前回调使用【IM】，用户发消息时，望舒回调 CP 方（默认允许）判断是否允许发送消息
ims-sentmsg[用户社交关系] IMS 消息发送通知使用【IM】，消息发送成功时通知 CP 方
ims-createconv[用户社交关系] IMS 会话创建回调使用【IM】，创建会话前询问 CP 方是否允许用户创建会话
ims-deleteconv[用户社交关系] IMS 会话删除回调使用【IM】，创建会话前询问 CP 方是否允许用户删除会话
ims-joinconv[用户社交关系] IMS 加入会话回调使用【IM】，创建会话前询问 CP 方是否允许用户加入会话
service-wechat_notify[客服服务] 转发小游戏客服事件补充中
promotion-callback[主播服务] 主播业务透传数据补充中
user-send-prop直接向用户发送道具补充中
send_awards[基础运营工具] 发送道具补充中
user-update_head_img_url[望舒通行证] 修改用户头像补充中
user-register[即将下线] 注册获取游戏 id补充中
risk-green[用户账号管理] 内容安全检测使用【图片审核管理】功能，通知审核结果时会调用此接口
dy-feed-notify[三方服务] 抖音推荐流补充中
passport_replace_openid[即将下线] 更新单个 openid补充中
passport_replace_openids[即将下线] 批量更新 openid补充中
product-accesstoken_update[即将下线] accesstoken 推送当望舒后台 accesstoken 有刷新时，推送给 CP 方
account-query[已下线] 查询游戏账号信息将已有用户的账号迁移至望舒系统
account-bind[已下线] 绑定望舒账号将已有用户的账号迁移至望舒系统
account-queryandbind[已下线] 查询并绑定望舒账号将已有用户的账号迁移至望舒系统
version-auto_packing[即将下线] 自动打包使用【版本发版管理的自动打包】时，望舒主动调用 CP 方自动代打包程序
version-auto_packing_kill[即将下线] 自动打包取消使用【版本发版管理的取消自动打包】时，望舒通知 CP 方中断打包
version-batch_auto_packing[即将下线] 批量自动打包使用【版本发版管理的自动打包】时，望舒主动调用 CP 方自动代打包程序
versioncheck-h5_game[即将下线] 更新 H5 游戏版本在「版本管理」模块中，相应版本状态变更时，将 H5 游戏版本信息同步给 CP
versioncheck-activity[即将下线] 更新活动版本在「版本管理」模块中，相应版本状态变更时，将活动版本信息同步给 CP
versioncheck-app_info[即将下线] 更新渠道包信息在「产品包管理」模块中，针对产品包操作【新建/编辑/删除】后，将产品包信息同步给 CP
versioncheck-game_info[即将下线] 更新游戏信息在「模块管理」模块中，针对子游戏模块操作后，将子游戏信息同步给 CP
versioncheck-activity_info[即将下线] 更新活动信息在「模块管理」模块中，针对活动模块操作后，将活动信息同步给 CP
versioncheck-main_info[即将下线] 更新大厅组件信息在「模块管理」模块中，针对主模块操作后，将主模块信息同步给 CP
versioncheck-game[即将下线] 更新游戏版本在「版本管理」模块中，相应版本状态变更时，将子游戏版本信息同步给 CP
versioncheck-hall[即将下线] 更新大厅组件版本在「版本管理」模块中，相应版本状态变更时，将大厅组件版本信息同步给 CP
versioncheck-app[即将下线] 更新渠道包版本在「版本管理」模块中，相应版本状态变更时，将渠道包版本信息同步给 CP
versioncheck-product_game[即将下线] 更新渠道包关联的游戏在「产品包管理」模块中，针对产品操作后，将产品和游戏关系同步给 CP
