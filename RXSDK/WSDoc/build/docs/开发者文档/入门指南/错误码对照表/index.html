错误码对照表

SDK 3.2.x 以后版本错误码重新规范，使用下面格式返回。原渠道原始错误码通过 thirdcode、thirdmsg 字段返回。

返回数据结构为 json ： 如果三方 SDK ，具体三方信息通过扩展信息返回。

{
 "code" : 望舒错误码,
 "msg" : "望舒错误描述",
 "thirdmsg" : "三方原始错误描述",
 //无三方错误码时候不返回字段 "thirdcode" : 三方原始错误码,
 //无三方错误消息时候不返回字段 "data" : {}
}
