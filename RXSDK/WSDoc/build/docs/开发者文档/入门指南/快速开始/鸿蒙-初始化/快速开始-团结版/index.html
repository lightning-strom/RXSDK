快速开始-团结版

准备工作​

请登录望舒系统初始化相关服务，如果还没有望舒账号请查看准备工作说明。

望舒系统地址，可登录企业管理后台 > 已部署项目中查看。

环境要求​

DevEco Studio 下载

团结引擎 IDE 下载

团结引擎 鸿蒙版本SDK 下载

Unity 团结引擎版本要求 ，参照对应版本更新日志

DevEco Studio 6.0 Release 版本或以上

Harmony API 14

SDK 集成​

鸿蒙团结引擎版本 IDE 中， Project 窗口 Assets 点击右键选择 Import Package,选择SDK package 资源包，导入 SDK 到游戏工程。

DevEco HarmonyOS 证书配置​

参考链接

https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs-V5/faqs-compiling-and-building-54-V5

https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/ide-signing-V5#section297715173233

https://developer.huawei.com/consumer/cn/doc/app/agc-help-debug-app-0000001914423098

SDK 初始化​

将 Asset 文件夹 RXSDK 目录下 RuiXueSdk Prefab 添加进 Hierarchy 中。

鸿蒙应用参数配置

方式 1 ：点击菜单栏 HMSSetting 配置鸿蒙开发者后台应用参数，证书相关参数参照 HarmonyOS 证书配置文档，证书相关配置如已在 DevEco 中配置 填入。

方式 2 ：点击 File->Build Settings-> Platform 中选择 OpenHarmony ，点击 Export 导出鸿蒙 DevEco 工程。打开 DevEco 工程，在 entry 模块 src/module.json5 文件, metadata 中添加。

metadata": [
 {
 "name": "app_id",
 "value": "华为AGC后台，鸿蒙应用APP ID"
 },
 {
 "name": "client_id",
 "value": "华为AGC后台，鸿蒙应用 Client ID"
 }
]

调用下方接口初始化SDK

string cpId = "112", productId = "1002", channelId = "100";

接入功能​

SDK 提供了众多功能。请在初始化 SDK 后，根据项目需要，参考相应功能的文档，接入相应功能。 绝大多数游戏都会接入望舒登录，所以我们推荐从这一功能开始。

接入望舒登录​

微信登录新增 wx_appid 配置

在 entry 工程中 src/module.json5 文件, metadata 中添加

metadata": [
 {
 "name": "wx_appid",
 "value": "微信开放平台微信应用appid"
 }
]

根据开发者指南，登录（通行证） 完成接入。

接入望舒鸿蒙支付​

请根据开发者指南，支付（鸿蒙支付） 完成操作。

导出DevEco Studio 项目​

在 Tuanjie Ide 中，点击 File -> Build Settings , Platform 中选择 OpenHarmony 并勾选 Export Project ，点击 Export 导出工程。

使用 Deveco Studio 打开 Tuanjie 导出的 Harmony 项目。

DevEco 项目配置​

接入 hmssdk 时，团结引擎 1.4.0 前版本，先将导出工程中鸿蒙工程 ts 文件升级到 ets 文件。

参考 网盘 中 ArktsDevProject.zip 鸿蒙官方提供的参考文件进行升级

在工程根目录中 build-profile.json5 文件, products 数组对象中中添加下面注释中 useNormalizedOHMUrl 配置。

"products": [
 {
 "name": "default",
 "signingConfig": "default",
 "compatibleSdkVersion": "5.0.0(12)",
 "runtimeOS": "HarmonyOS",

 //新增配置项
 "buildOption": {
 "strictMode": {
 "useNormalizedOHMUrl": true
 },
 }
 },

应用权限配置​

应用在申请权限时，需要在项目的配置文件中，逐个声明需要的权限，否则应用将无法获取授权。

在配置文件中声明权限​

应用需要在 module.json5 配置文件的 requestPermissions 标签中声明权限。详细配置说明参考华为文档

受限权限需要弹窗给用户手动授权，为了提升用户体验，建议自行提前申请。受限权限列表 详细使用 参考华为文档

{
 "module" : {
 // ...
 "requestPermissions":[
 {
 "name" : "ohos.permission.APP_TRACKING_CONSENT",
 "reason": "$string:广告标识符权限说明",
 "usedScene": {
 "abilities": [
 "游戏的Ability"
 ],
 "when":"inuse"
 }
 } ,
 {
 "name" : "ohos.permission.READ_PASTEBOARD",
 "reason": "$string:剪贴板权限用途说明",
 "usedScene": {
 "abilities": [
 "游戏的Ability"
 ],
 "when":"inuse"
 }
 }
 ]
 }
}
