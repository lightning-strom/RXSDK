Unity 快速开始

接入方式​

  • Package Manager 导入 RuiXue.Base

准备工作​

请登录望舒系统初始化相关服务，如果还没有望舒账号请查看准备工作说明。

望舒系统地址，可登录企业管理后台 > 已部署项目中查看。

环境要求​

我们开发调试使用的版本为 2022.3.21f1, 在项目配置的时候，不同的版本会有一定差异，需要调用方自行适配。

隐私权限​

SDK 会获取一些设备相关信息，有些信息会涉及到隐私权限。部分渠道审核会有限制，请注意相关配置，并在审核模式下进行相关处理。

名称备注
设备码设备唯一标识，用于生成游客账号、大数据筛选条件
oaid/caid广告标识，用于媒体平台投放归因

登录前使用客服功能会随机生成一个字符串用于标识匿名用户，以便该匿名用户下次再使用客服时获取之前的聊天记录。

工程配置​

  • iOS
  • Android

在 Xcode 中补充以下配置：

  • URL Schemes：添加微信、QQ 等第三方回调 Scheme。
  • Associated Domains：按需配置 Universal Links。

按需编辑 Assets/Plugins/Android/AndroidManifest.xml，补充 SDK 需要的 Activity 与权限。

<manifest xmlns:android="http://schemas.android.com/apk/res/android"
    <package="com.company.game">

    <application>
        <!-- 望舒支付回调 Activity -->
        <activity
            android:name="com.ruixue.sdk.unity.pay.RuiXuePayResultActivity"
            android:exported="true"
            android:launchMode="singleTask" />

        <!-- 微信回调 Activity -->
        <activity
            android:name=".wxapi.WXEntryActivity"
            android:exported="true"
            android:launchMode="singleTask" />
    </application>

    <!-- 网络权限 -->
    <uses-permission android:name="android.permission.INTERNET" />
</manifest>

接入 Unity Package​

添加望舒 UnitySdk 包管理服务器地址, 如下图打开 Edit > ProjectSettings > PackageManager 界面，填入望舒 UnitySdk 包管理服务器地址

  • Name: RuiXueUnitySdk
  • URL: http://60.205.123.114:4873
  • Scope: com.ruixue

在 PackageManager 中引入所需包

如下图打开 Window > PackageManager 界面，切换标签页至 My Registries 界面（ 如没有 My Registries 标签可能网络慢，稍等刷新，或可能地址填写有误）即可看到望舒所有包列表，选中所需包点击 Install 即可。

特别注意：关于 LitJson.dll 冲突问题

RuiXue.Base 包内 Plugins 包含 LitJson.dll ，有可能和项目内已经有的 LitJson 库冲突，比如接入微信小游戏的时候，微信导出小游戏插件里也包含 LitJson.dll, 那么删除其 LitJson 保留一个即可。

SDK 初始化​

接口传参初始化​

初始化 SDK 时需传入 productId、channelId、cpid、baseUrlList 参数信息。

productId、channelId 在望舒游戏发行平台获取（创建产品或渠道），查看使用说明。

cpid、baseUrlList 在望舒企业管理后台获取（创建项目），查看使用说明。

初始化为异步调用，失败将不能使用 SDK 功能，请注意处理调用逻辑。

接口原型

void Initialize(string cpid, string productid, string channelid, List<string> urls,
 RequestResponseDelegate onSuccess, RequestErrorDelegate onFail);

参数说明​

字段类型是否必填备注
cpidString是cpid
productIdString是产品 id
channelIdString是渠道 id
baseUrlListArray是请求域名队列

调用示例

private void OnBtnInit()
{
    string cpId = "114";
    string channelId = "100";
    string productId = "1002";
    List<string> list = new()
    {
        "http://cn-api-test.ruixuecloud.com"
    };

    RuiXueSdk.Initialize(cpId, productId, channelId, list, RequestResponseDelegate, RequestErrorDelegate);
}

private void RequestResponseDelegate(string data)
{
    LogUtil.Log("EventManager", $"RequestResponseDelegate: {data}");
}

private void RequestErrorDelegate(string error)
{
    LogUtil.Log("EventManager", $"RequestErrorDelegate: {error}");
}

用户隐私协议初始化​

iOS 与 Android 调用方式一致。在业务弹窗确认用户同意隐私协议后，调用 SetPrivacyAgree 通知 SDK：

public void OnPrivacyAgree(bool userClick)
{
    Debug.Log($"用户是否点击同意: {userClick}");
}

private void InitPrivacyState()
{
    bool agreed = RuiXueSdk.IsAgreedPrivacy();
    Debug.Log($"当前隐私同意状态: {agreed}");

    RuiXueSdk.SetPrivacyAgree(OnPrivacyAgree);
}

渠道防沉迷初始化​

iOS 与 Android 调用方式一致，建议在 SDK 初始化完成后立即设置监听：

private class AddictDelegate : IAntiAddictDelegate
{
    public bool IsGaming()
    {
        return false;
    }

    public void AddictInfoUpdate(string json)
    {
        Debug.Log($"防沉迷信息更新: {json}");
    }

    public bool EnableCustomUI()
    {
        return false;
    }
}

private void SetupAddict()
{
    RuiXueSdk.SetupAddictDelegate(new AddictDelegate());
}
