VNG小游戏

准备工作​

请登录望舒系统初始化相关服务，如果还没有望舒账号请查看准备工作说明。

望舒系统地址，可登录企业管理后台 > 已部署项目中查看。

环境要求​

点击下载 SDK 最新版本，下载 vng 小游戏 SDK

把 SDK 导入项目工程中

SDK 初始化​

1、初始化为异步调用，失败将不能使用 SDK 功能，请注意处理调用逻辑

2、需要游戏方在 html 顶部引入一个脚本 https://cdn.choingay.vn/js/vnggamessdk-mini-v3.js ，并且监听 vng sdk 初始化完成

head>
 script>
 window.addEventListener('vnggamessdk_ready', () => {
 window.VNGGamesSDK.init().then((res) =>
 console.log('SDK init result:', res)
 )
 })
 script>
 script src='https://cdn.choingay.vn/js/vnggamessdk-mini-v3.js'>script>
head>

初始化 SDK 时需传入 productId、channelId、cpid、baseUrlList 参数信息。

字段类型是否必填说明
string是产品 id ，望舒游戏发行平台创建产品，查看使用说明。channelId
string是渠道 id ，望舒游戏发行平台创建渠道，查看使用说明。cpid
string是CP id ，望舒企业管理后台创建项目，查看使用说明。baseUrlList
string[]是请求域名队列，望舒企业管理后台创建项目，查看使用说明。complete
function是初始化回调函数

接口实例：

// 路径仅为示例，需要传入SDK在项目中的真实路径，如出现引用错误请检查路径是否正确
const channelSdk = require("your path/channelSDK/index.js")
//以下参数为测试参数，需要更换为接入方对应的参数
const sdk = new channelSdk({
 productId: '1', //产品 id
 channelId: '818', //渠道id
 cpid: '1000049', //CP id
 baseUrlList: ['https://ruixue.weiletest.com'],//请求域名队列
 complete: (data) => {
 console.log('init complete: ', data)
 if (data.code === 0) {
 // 初始化成功
 }
 },
})

设置自定义返回错误消息​

规则 1 ：根据错误码直接读取对应提示替换 msg ；

规则 2 ：如果表中有 default 的 key ，将未配置的错误码 msg 统一替换为 default 的 value ；

规则 3 ：$code$ $thirdcode$ $thirdmsg$ 为动态配置字段，如下所示，最终展示的信息为 支付错误 4002

以上规则仅适用于调用了 setErrorMsg 接口，未调用保持原有规则

调用示例

// 同步函数
sdk.setErrorMsg({
 4001: 'cancel pay',
 4002: '支付错误$code$',
 2001: 'init fail',
 default: 'default$code$$thirdcode$'
})

清除自定义返回错误消息​

调用示例

// 同步函数
sdk.clearErrorMsg()

接入功能​

SDK 提供了众多功能。请在初始化 SDK 后，根据项目需要，参考相应功能的文档，接入相应功能。 绝大多数游戏都会接入望舒登录，所以我们推荐从这一功能开始。

接入望舒登录​

请根据开发者指南，登录（通行证） 完成操作。
