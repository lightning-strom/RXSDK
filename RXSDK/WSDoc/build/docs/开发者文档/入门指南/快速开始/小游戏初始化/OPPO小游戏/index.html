OPPO小游戏

准备工作​

请登录望舒系统初始化相关服务，如果还没有望舒账号请查看准备工作说明。

望舒系统地址，可登录企业管理后台 > 已部署项目中查看。

环境要求​

支持最低平台版本号 1040(minPlatformVersion>='1040')

点击下载 SDK 最新版本，下载 Oppo 小游戏 SDK

把 SDK 导入项目工程中

SDK 初始化​

初始化为异步调用，失败将不能使用 SDK 功能，请注意处理调用逻辑。

初始化 SDK 时需传入 productId、channelId、cpid、baseUrlList 参数信息。

字段类型是否必填说明
string是产品 id ，望舒游戏发行平台创建产品，查看使用说明。channelId
string是渠道 id ，望舒游戏发行平台创建渠道，查看使用说明。cpid
string是CP id ，望舒企业管理后台创建项目，查看使用说明。baseUrlList
string[]是请求域名队列，望舒企业管理后台创建项目，查看使用说明。complete
function是初始化回调函数

接口实例：

// 路径仅为示例，需要传入SDK在项目中的真实路径，如出现引用错误请检查路径是否正确
const channelSdk = require("your path/channelSDK/index.js")
//以下参数为测试参数，需要更换为接入方对应的参数
const sdk = new channelSdk({
 productId: '1', //产品 id
 channelId: '818', //渠道id
 cpid: '1000049', //CP id
 baseUrlList: ['https://ruixue.weiletest.com'],//请求域名队列
 complete: (data) => {
 console.log('init complete: ', data)
 if (data.code === 0) {
 // 初始化成功
 }
 },
})

游戏行为数据上报​

参数说明​

字段类型是否必填备注params
IGameInfo是上报信息合集completeIMethodParams
是初始化回调函数

IGameInfo 说明

字段备注
actionCode行为代码
actionFinishTime行为完成时间
dataUniqueId数据唯一标识符

IMethodParams 说明

字段备注
complete(data) => void

complete ：为函数且必传， data 为结果数据

调用示例

sdk.channelGatewayAuthApiOppo({
 actionCode:"actionCode",
 actionFinishTime:"actionFinishTime",
 dataUniqueId:"dataUniqueId"
}, {
 complete: (data) => {
 console.log('上报基础数据: ', data)
 }
})

响应结构​

成功 code 为 0

设置自定义返回错误消息​

规则 1 ：根据错误码直接读取对应提示替换 msg ；

规则 2 ：如果表中有 default 的 key ，将未配置的错误码 msg 统一替换为 default 的 value ；

规则 3 ：$code$ $thirdcode$ $thirdmsg$ 为动态配置字段，如下所示，最终展示的信息为 支付错误 4002

以上规则仅适用于调用了 setErrorMsg 接口，未调用保持原有规则

调用示例

// 同步函数
sdk.setErrorMsg({
 4001: 'cancel pay',
 4002: '支付错误$code$',
 2001: 'init fail',
 default: 'default$code$$thirdcode$'
})

清除自定义返回错误消息​

调用示例

// 同步函数
sdk.clearErrorMsg()
