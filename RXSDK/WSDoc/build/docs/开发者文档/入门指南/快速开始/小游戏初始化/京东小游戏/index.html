SDK 初始化​

初始化为异步调用，失败将不能使用 SDK 功能，请注意处理调用逻辑

初始化 SDK 时需传入 productId、channelId、cpid、baseUrlList 参数信息。

字段类型是否必填说明
string是产品 id ，望舒游戏发行平台创建产品，查看使用说明。channelId
string是渠道 id ，望舒游戏发行平台创建渠道，查看使用说明。cpid
string是CP id ，望舒企业管理后台创建项目，查看使用说明。baseUrlList
string[]是请求域名队列，望舒企业管理后台创建项目，查看使用说明。complete
function是初始化回调函数

接口实例：

// 路径仅为示例，需要传入SDK在项目中的真实路径，如出现引用错误请检查路径是否正确
const channelSdk = require("your path/channelSDK/index.js")
//以下参数为测试参数，需要更换为接入方对应的参数
const sdk = new channelSdk({
 productId: '1', //产品 id
 channelId: '818', //渠道id
 cpid: '1000049', //CP id
 baseUrlList: ['https://ruixue.weiletest.com'],//请求域名队列
 complete: (data) => {
 console.log('init complete: ', data)
 if (data.code === 0) {
 // 初始化成功
 }
 },
})

创建获取用户信息按钮​

创建获取用户信息的按钮，通过绑定 userInfoButton.onTap(callback) 事件，点击获取挂有用户信息的对象

参数说明​

字段类型是否必填备注
paramsIContactButton是参数
callbackIMethodParams是回调函数集合

IContactButton 说明

字段类型是否必填备注
typestring是按钮的类型，取值 image 或 text。image 对应图片按钮， text 对应文本按钮
imagestring否按钮的背景图片， type 为 image 时必填。仅支持本地图片
textstring否按钮上的文本内容， type 为 text 时有效
styleobject是按钮的样式

style 说明

字段类型是否必填备注
leftnumber是左上角横坐标
topnumber是左上角纵坐标
widthnumber是宽度
heightnumber是高度
backgroundColorstring是背景颜色
borderColorstring是边框颜色
borderWidthnumber是边框宽度
borderRadiusnumber是边框圆角
textAlignstring是文本的水平居中方式

"left" / "center" / "right" fontSize

number是字号
lineHeightnumber是
文本的行高textColorstring
是文本颜色

IMethodParams 说明

字段备注
complete(data) => void

complete ：为函数且必传， data 为结果数据

调用示例

sdk.createUserInfoButton(
 {
 type: "text", // image | text
 // image: "./test.jpg", //仅支持本地图片，type为image时生效
 text: "我是一个按钮", //仅在type等于text时生效
 style: {
 //控制按钮的样式
 left: 20, //左上角横坐标
 top: 40, //左上角纵坐标
 width: 150, //宽度
 height: 150, //高度
 lineHeight: 40, //文本的行高
 backgroundColor: "#ffffff", //背景颜色
 textAlign: "center", //文本的水平居中方式
 fontSize: 16, //字号
 borderRadius: 4, //边框圆角
 borderColor: "#ffffff", //边框颜色
 borderWidth: 1, //边框宽度
 textColor: "#ffffff", //文本颜色
 },
 },
 {
 complete: (res) => {
 console.log(res.code) // code为0表示成功
 console.log(res.userInfoButton) //返回一个按钮的实例用于控制按钮
 console.log(res.userInfo) //返回用户信息
 },
 }
);

响应结构​

返回一个 userInfoButton 对象， 方法如下：

方法备注
onTap(function callback)监听按钮点击事件
offTap(function callback)移除 onTap 绑定的监听函数
destroy()销毁按钮
show()显示按钮
hide()隐藏按钮

设置自定义返回错误消息​

规则 1 ：根据错误码直接读取对应提示替换 msg ；

规则 2 ：如果表中有 default 的 key ，将未配置的错误码 msg 统一替换为 default 的 value ；

规则 3 ：$code$ $thirdcode$ $thirdmsg$ 为动态配置字段，如下所示，最终展示的信息为 支付错误 4002

以上规则仅适用于调用了 setErrorMsg 接口，未调用保持原有规则

调用示例

// 同步函数
sdk.setErrorMsg({
 4001: 'cancel pay',
 4002: '支付错误$code$',
 2001: 'init fail',
 default: 'default$code$$thirdcode$'
})

清除自定义返回错误消息​

调用示例

// 同步函数
sdk.clearErrorMsg()
