域名切换/迁移

1.涉及到公众号支付的需要在公众号后台，商户后台配置业务域名，JS接口安全域名，网页授权域名需要换成初始化sdk的baseurl域名队列。​
2.支付后未收到望舒回调通知发货，需要确认后台配置的回调地址域名是否已切换。​
3.使用到微信客服数据转发的cp，需要将已配置好的地址域名修改为新域名。​
4.分享，ios支付卡片不展示图片的情况/跳转客服支付报错，首先确认埋点是否正确，后台是否已有（如果有出现返回埋点不存的情况需要重新保存一下埋点，关联的策略以及内容等关联项）。配置的分享域名是否正确。确认无误后还是存在此情况，联系望舒人员排查。​
5.迁移时测试支付返回参数错误首先核查计费点是否有误，如果存在该计费点还有相同情况手动保存一下计费点，如果还是不行请联系望舒人员排查。​
6.抖音小游戏迁移建议迁移完成后，重置抖音的密钥appsecret并配置到新的后台中。无需重置支付key。防止迁移之前的服务互刷抖音accesstoken，影响支付回调。​
7.ios端微信小游戏使用公众号支付时，返回的图文链接的角标图不显示，可以在<望舒游戏平台消息推送工具--微信客服自动推送--编辑重新上传图片>。​
8.相关后台的配置回执/回调地址可以通过<望舒游戏平台--首页--找到对应的渠道包--复制参数>进行查看或复制使用。​
9.切换域名时上报大数据如果有服务端上报的情况，也需要同时改为新域名。客户端上报只需调整初始化域名地址即可。​
10.集群的切换会导致出口IP更改，所以需要注意一些IP加白的配置项需要同步调整配置。例如：实名认证系统，需要在中宣部后台将新IP加入到白名单。​
11.项目迁移后，有些域名会停止解析。之前配置在望舒产品的一些回调地址，请检查是否需要更改，并且核对该地址是否可以访问。否则可能会影响支付发货地址，无法收到发货通知、发送邮件时CP回调失败、一些相关使用CP回调项的应用都无法正常回调CP。​
12.项目迁移后会对项目进行初始化。会初始化注册限制,望舒默认限制单 IP 每小时最多允许注册3个用户，每个身份信息最多可以实名50 个账号。如果需要调整可以通过<企业管理后台-运维管理-平台集群管理-项目配置-初始化配置-进行调整保存>​

13.迁移数据过程，如果期间同步了数据为进行测试，请及时关闭相关服务或者任务。避免大数据侧数据重复。例如：推送任务。如果不关闭会导致部分任务因渠道侧条数受限而无法完成，导致数据无法区分。​
