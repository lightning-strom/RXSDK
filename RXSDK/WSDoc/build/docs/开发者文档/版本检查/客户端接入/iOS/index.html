产品包版本检查（已废弃）​

已废弃

请使用 检查产品包（通用） 接口。

接口原型

/**
 * 大厅更新检查（GET版本，不返回下载地址）
 * @param region 地区码  非必须
 * @param client_version 客户端大厅当前版本  非必须
 * @param type 脚本类型，默认lua，可选json，u3d等  非必须
 * @param json 输出文件后缀，默认lua，可选json  非必须
 */
- (void)checkUpdate_AppWithRegion:(NSString * _Nullable)region
                   client_version:(NSString * _Nullable)client_version
                             type:(NSString * _Nullable)type
                             json:(NSString * _Nullable)json
                         complete:(RequestComplete)complete;

参数说明​

字段类型是否必填说明
regionNSString否地区码
client_versionNSString否客户端大厅当前版本
typeNSString否脚本类型，默认 lua，可选 json，u3d 等
jsonNSString否输出文件后缀，默认 lua，可选 json

调用示例

[[RXUpdateCheckService sharedSDK] checkUpdate_AppWithRegion:@"" client_version:@"" type:@"" json:@"" complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
            
}];

LoginConfig​
提示

数据会根据后台配置决定
如果登录配置类型为“默认配置”，则由服务端进行匹配，优先级如下

  • 商店账户归属地区优先：（指定地区>商店账户归属地区>IP归属地区>用户设备系统地区>默认地区），仅限 iOS，安卓无法使用
  • IP归属地区优先：（指定地区>IP归属地区>商店账户归属地区>用户设备系统地区>默认地区）

如果登录配置类型为“多付首选”，则将配置直接下发

参数类型说明
login_hostString登录地址
login_nameString登录名
ext_paramString扩展参数
region_tagString地区标签
region_list[]String地区列表 （“多服首选”由游戏测选择）
user_regionString用户匹配到的地区（“默认配置”由服务端根据请求参数判断）

产品包版本检查（通用）​

提示

海外项目在使用望舒分区功能时需要先调用 setIAPProductId 用于获取支付账号所在地区，productId 必须是全球商品。

注意：setIAPProductId 要在版本检查前调用。

国内项目或不使用望舒分区的海外项目可忽略。

提示

用户选择分区后要调用 设置游戏登录配置 接口，将所选的登录配置对象传入，该接口不调用会导致区服相关数据统计丢失。

接口原型

/**
 * 大厅更新检查（POST版本，返回下载地址）
 * @param region 地区码  非必须
 * @param client_version 客户端大厅当前版本  非必须
 * @param games key客户端游戏id value版本  非必须
 * @param activities key客户端活动别名 value版本  非必须
 * @param type 脚本类型，默认lua，可选json，u3d等  非必须
 * @param json 输出文件后缀，默认lua，可选json  非必须
 */
- (void)checkUpdate_AppWithRegion:(NSString * _Nullable)region
                   client_version:(NSString * _Nullable)client_version
                            games:(NSDictionary * _Nullable)games
                       activities:(NSDictionary * _Nullable)activities
                             type:(NSString * _Nullable)type
                             json:(NSString * _Nullable)json
                         complete:(RequestComplete)complete;
                         
/**
 * 设置商品 id 和 超时时间
 * @param productId 商品 id
 * @param timeout 超时时间，默认 2 秒
 */
- (void)setIAPProductId:(NSString *)productId timeout:(NSInteger)timeout;

参数说明​

字段类型是否必填说明
regionNSString否地区码
client_versionNSString否客户端大厅当前版本
typeNSString否脚本类型，默认 lua，可选 json，u3d 等
jsonNSString否输出文件后缀，默认 lua，可选 json
activitiesNSDictionary否key 客户端活动别名 value 版本
gamesNSDictionary否key 客户端游戏 id value 版本

调用示例

[[RXUpdateCheckService sharedSDK] checkUpdate_AppWithRegion:@"" client_version:@"" games:nil activities:nil type:@"" json:@"" complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
            
}];

[[RXService sharedSDK] setIAPProductId:@"iap productid" timeout:2];

响应结构（JSON）​

参数类型约束
loginhostString登录地址
uriString版本类型为 app 时返回更新地址目录，如无更新，返回客户端版本地址目录，如果客户端版本过低， 不返回。非 app 时为客户端指定版本的地址目录，如找不到版本或版本过低，返回最新版本地址目录
upgradeNumber更新状态 0 无更新 1 有更新
latestString升级后的版本号
uptypeNumber1 小版本热更 2 大版本整包更
gamesMap[string]int产品包关联的游戏 id=>最新版本号
activitiesMap[string]int产品包关联的活动别名=>最新版本号
hallHalldata热更信息（js 小游戏不下发）
uipNumber客户端 ip
tsNumber服务端时间戳
extMap[string]interface自定义扩展信息， 值为望舒后台配置的类型
updateUpdate客户端指定的版本下发详细

login_config[]LoginConfig登录配置
attrNumber状态标记 使用位运算

参数类型约束

游戏更新检查​

接口原型

/**
 * 游戏更新检查
 * @param game_id 游戏ID  必须
 * @param game_version 当前游戏版本  必须
 * @param game_check_version 指定游戏版本  非必须
 * @param type 脚本类型，默认lua，可选json，u3d等  非必须
 * @param json 输出文件后缀，默认lua，可选json  非必须
 */
+ (RX_CommonRequest *)checkUpdate_GameWithGame_id:(NSInteger)game_id
                                     game_version:(NSInteger)game_version
                               game_check_version:(NSString *)game_check_version
                                             type:(NSString *)type
                                             json:(NSString *)json;

参数说明​

字段类型是否必填说明
game_idNSString是游戏 ID
game_versionNSString是当前游戏版本
game_check_versionNSString否指定游戏版本
jsonNSString否输出文件后缀，默认 lua，可选 json
typeNSDictionary否脚本类型，默认 lua，可选 json，u3d 等

调用示例

[[RXUpdateCheckService sharedSDK] checkUpdate_GameWithGame_id:1 game_version:1 game_check_version:@"1.0.0" type:@"" json:@"" complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
            
}];

响应结构（JSON）​

参数类型约束
uriString游戏热更地址路径
versionString最新版本
game_idNumber游戏 id

返回参数有也会有“url”字段，是为兼容 js 而返回的， 全部升级后会废弃掉

活动更新检查​

接口原型

/**
 * 活动更新检查
 * @param game_version 当前游戏版本  必须
 * @param game_check_version 指定游戏版本  非必须
 * @param short_name 活动短名  必须
 * @param type 脚本类型，默认lua，可选json，u3d等  非必须
 * @param json 输出文件后缀，默认lua，可选json  非必须
 */
- (void)checkUpdate_ActivityWithGame_version:(NSInteger)game_version
                          game_check_version:(NSString * _Nullable)game_check_version
                                  short_name:(NSString *)short_name
                                        type:(NSString * _Nullable)type
                                        json:(NSString * _Nullable)json
                                    complete:(RequestComplete)complete;

参数说明​

字段类型是否必填说明
game_check_versionNSString是指定游戏版本
game_versionNSString是当前游戏版本
short_nameNSString否活动短名
jsonNSString否输出文件后缀，默认 lua，可选 json
typeNSDictionary否脚本类型，默认 lua，可选 json，u3d 等

调用示例

[[RXUpdateCheckService sharedSDK] checkUpdate_ActivityWithGame_version:1 game_check_version:@"" short_name:@"" type:@"" json:@"" complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
            
}];

响应结构（JSON）​

参数类型约束
uriString热更地址的路径
versionString最新版本
activity_shortnameString活动标识

返回参数有也会有“url”字段，是为兼容 js 而返回的， 全部升级后会废弃掉 响应示例

{
  "uri": "http://rxfile.weilekuiming.com/test/dir/22090873urwkzpsTSXKz0LKL7WXjCiK5fUg0o/",
  "version": "1",
  "activity_shortname": "huodong"
}
