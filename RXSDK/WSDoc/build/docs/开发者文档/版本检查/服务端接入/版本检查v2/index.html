版本检查 V2

版本检查（通用）​

**POST: ** /v1/vcapi/update_module_version

认证方式： 无

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/vcapi/update_module_version' \
--header 'Content-Type: application/json' \
--data-raw '{
 "modules": [
 {
 "module_tag": "dsa",
 "clientversion": 0,
 "checkversion": 0,
 "category_tag": "dass"
 },
 {
 "module_tag": "_nNNN",
 "clientversion": 0,
 "checkversion": 0,
 "category_tag": "default"
 }

 ],
 "type": "js"
}'

请求参数​

参数类型说明
typeString脚本类型 默认 js ， 可选 lua ， u3d
modulesArray ModuleInfo待检查模块数组

待检查模块信息ModuleInfo​

参数类型是否必填说明
module_tagString是模块标识
category_tagString是分类标识
clientversionNumber是客户端当前版本， 0 表示当前客户端无相关版本(首次接）
checkversionNumber是优先检查这个版本，没有此版本时再返回最新版本，不需要传 0 即可

响应示例

{
 "data": {
 "modules": [
 {
 "module_tag": "dsa",
 "category_tag": "dass",
 "uri": "https://rxfile-test.ruixueyun.com/release/pkg/25031110GjPuOV0TkITessHcdWpgyWn3Tb3T2U.zip",
 "version": 88
 },
 {
 "module_tag": "_nNNN",
 "category_tag": "default",
 "uri": "https://rxfile-test.ruixueyun.com/release/pkg/25031110jCFrdMrEvsqRMDnMEC7vMoJO7EinKp.zip",
 "version": 99
 }
 ]
 },
 "code": 0
}

响应结构（JSON）​

参数类型说明
codeNumber接口状态码， 0 标识请求正常，非零表示此次请求出现错误
DataObject接口返回的业务数据

响应Data​

参数类型说明
modulesArray ModuleResponse模块检查结果数组
响应ModuleResponse​
参数类型说明
module_tagString模块标识
category_tagString分类标识
versionNumber最新版本，大于 0 的数字， 0 表示无最新版本
urlString版本地址路径

获取临时维护公告​

**GET: ** /v1/vcapi/maintain/{产品id}/{渠道id}

认证方式： 无

响应结构（JSON）​

参数类型说明
codeNumber接口状态码， 0 标识请求正常，非零表示此次请求出现错误
DataObject接口返回的业务数据

响应Data​

参数类型说明
upgradeNumber0 无公告 2 有公告
maintain_titleString公告标题
maintainString公告内容

获取h5登录地址​

**GET: ** /v1/vcapi/h5_login_config/{产品id}/{渠道id}

认证方式： 无

响应结构（JSON）​

参数类型说明
codeNumber接口状态码， 0 标识请求正常，非零表示此次请求出现错误
DataObject接口返回的业务数据

响应Data​

参数类型说明
login_hostString登录地址
login_configArray LoginConfig新版登录配置
响应LoginConfig​
参数类型说明

region_listArray String区域列表
user_regionString用户区域
ext_paramString扩展参数
login_hostString登录地址
