SDK 集成​

  • iOS
  • Android
pod 'RXGoogleSDK'

如需禁止 GoogleSignIn-GoogleSignIn 签名，在 podfile 中添加：

post_install do |installer|
  installer.pods_project.targets.each do |target|
    target.build_configurations.each do |config|
      if target.respond_to?(:product_type) and target.product_type == "com.apple.product-type.bundle"
        target.build_configurations.each do |config|
          config.build_settings['CODE_SIGNING_ALLOWED'] = 'NO'
        end
      end
    end
  end
end

工程配置​

info.plist 中添加 GIDClientID，value 为 Google 开发后台凭据中的客户端 ID。

URL Types 中添加 Google 后台凭据中的 iOS 网址架构。

使用 Google gaid 时请先调用 initThirdSdk 初始化 Google 服务再初始化望舒，否则可能影响激活时 gaid 采集成功率。

版本说明

version 为 SDK 版本号（替换为实际版本号），最新版本请从 更新日志 中查看。

// 海外渠道引用此库
implementation 'com.ruixue:rxsdk_overseas:${version}'
// 其他渠道使用 Google 登录的，直接引用此库
implementation 'com.ruixue:rxsdk_google:${version}'

google-services.json 配置​

下载 google-services.json 文件并保存到项目根目录下。

在 build.gradle (Project) 中添加：

dependencies {
    classpath 'com.google.gms:google-services:4.1.0'
}

在 build.gradle (Module: app) 中添加：

apply plugin: 'com.google.gms.google-services'

参数类型说明

跳转 openURL​

- (BOOL)application:(UIApplication *)app openURL:(NSURL *)url options:(NSDictionary<NSString *, id> *)options {
    [[RXSDK sharedSDK] application:app openURL:url options:options];
    return YES;
}

RuiXueSdk.getRXSdkApi().initThirdSdk(this, map, new RXJSONCallback() {

Google 登录​

  • iOS
  • Android

登录结果通过登录 API 统一登录回调返回。

接口原型

/**
 * Google 登录
 * @param migrate_args 账号迁移用的参数，非必须
 * @param sign_fields 指定对登录成功后返回的特定字段使用 CPKEY 计算签名，非必须
 */
- (void)GLoginInWithMigrate_args:(id _Nullable)migrate_args
                     sign_fields:(NSArray * _Nullable)sign_fields;

调用示例

[[RXGoogleService sharedSDK] GLoginInWithMigrate_args:nil sign_fields:@[@"xxx", @"xxx"]];

恢复登录​

[[RXGoogleService sharedSDK] GRestorePreviousSignInWithMigrate_args:nil sign_fields:nil];

退出登录​

Google 退出登录后会清除本地缓存，退出后将无法调用 Google 分享等功能。

[[RXGoogleService sharedSDK] GLogout];

请参考 Android 端登录 API

Google 商品详情查询​

  • Android
  • iOS

接口原型

void queryProductDetailsAsync(@NonNull List<String> skusList, @NonNull RXStringCallback callback)

调用示例

GoogleSdkWrapper.getInstance().queryProductDetailsAsync(productIdList, new RXStringCallback() {
    @Override
    public void onSuccess(@Nullable String data) {
        RXLogger.i("product info: " + data);
    }

    @Override
    public void onFailed(int code, String msg, @Nullable String traceId) {
        // 处理失败
    }
});

响应示例

[
  {
    "productId": "com.weile.bombchicken.1001",
    "type": "inapp",
    "title": "Diamonds * 10 (Bomb Chick)",
    "price": "US$0.99",
    "price_currency_code": "USD"
  }
]

iOS 端商品查询请参考 iOS 支付 API。
