准备工作​

接入请前先做好准备工作。可通过 pod 方式接入 RXWXSDK 组件，并使用 RXWXSDK 相关功能。

在需要使用功能的类中引用头文件#import <RXWXSDK/RXWXSDK.h>

前往 微信开放平台 申请相关配置权限。

SDK 集成​

编辑 Podfile 文件，添加如下配置：

pod 'RXWXSDK'

工程配置​

在Xcode > Info > URL Types 中添加 微信 appid。

打开 Associated Domains 开关，将Universal Links域名加到配置上。

在 info 标签栏的 LSApplicationQueriesSchemes 添加 weixin、weixinULAPI、weixinURLParamsAPI（如下图所示）。

配置 Universallink​

如何生成 Universallink 可参考 配置 Universallink注：不配置无法拉起微信

接口原型

/**
 * 配置universallink
 */
- (void)configUniversallink:(NSString *)universallink;

调用示例

[[RXWXService sharedSDK] configUniversallink:@"https://open.weileapp.com/toolapi/"];

跳转到微信并打开小程序​

小程序跳转 APP 开发指南

接口原型

/**
 * 跳转到微信并打开小程序
 * @param params 跳转参数
 * ！username 小程序原始id #NSString类型
 * ！appid 微信appid #NSString类型
 * ！path 拉起小程序页面的可带参路径，不填默认拉起小程序首页，对于小游戏，可以只传入 query 部分，来实现传参效果，如：传入 "?foo=bar"。 #NSString类型
 * ！miniProgramType 小程序类型 0正式版 1开发版 2体验版 #NSInteger类型
 * ！ext 扩展信息 #NSString类型
 * ！extDic 可存放图片等比较大的数据 #NSDictionary类型
 * @param complete 回调，需要小程序接入跳转回到app的功能，否则回调不会执行
 */
- (void)openMiniProgram:(NSDictionary *)params
 complete:(void(^)(NSString *extMsg))complete;

调用示例

NSDictionary *dic = @{@"username" : @"小程序原始id",
 @"appid" : @"微信appid",
 @"path" : @"小程序路径",
 @"miniProgramType" : @(0)
};
[[RXWXService sharedSDK] openMiniProgram:dic complete:^(NSString * _Nonnull extMsg) {

}];

处理 openURL​

处理旧版微信通过 URL 启动 App 时传递的数据。

此系统方法用于处理 app 之间跳转的参数传递，在此添加微信跳转 url 用于接收微信跳转回客户端所携带的参数。此方法与处理 OpenUniversalLink 必须实现一种，否则无法正常使用微信登录或分享功能。

在系统 openURL: 方法中添加 微信跳转 url

接口原型

/**
 * 处理旧版微信通过URL启动App时传递的数据
 * 需要在 application:openURL:sourceApplication:annotation:或者application:handleOpenURL中调用。
 * @param url 微信启动第三方应用时传递过来的URL
 */
- (BOOL)handleOpenUrl:(NSURL *)url;

调用示例

- (BOOL)application:(UIApplication *)app openURL:(NSURL *)url options:(NSDictionaryNSString *,id> *)options{
 if([[RXWXService sharedSDK] handleOpenUrl:url]){
 return YES;
 }
 return YES;
}

处理 openUniversalLink​

此系统方法用于处理 app 之间跳转的参数传递，在此添加微信通过 Universallink 跳转用于接收微信跳转回客户端所携带的参数。此方法与处理 openURL 必须实现一种，否则无法正常使用微信登录或分享功能。

处理微信通过 Universal Link 启动 App 时传递的数据。

在系统 continueUserActivity: 方法中添加微信跳转 url

接口原型

/**
 * 处理微信通过Universal Link启动App时传递的数据
 * 需要在 application:continueUserActivity:restorationHandler:中调用。
 * @param userActivity 启动第三方应用时系统API传递过来的userActivity
 */
- (BOOL)handleOpenUniversalLink:(NSUserActivity *)userActivity;

调用示例

- (BOOL)application:(UIApplication *)application continueUserActivity:(NSUserActivity *)userActivity restorationHandler:(void(^)(NSArrayidUIUserActivityRestoring>> * __nullable restorableObjects))restorationHandler {
 if ([[RXWXService sharedSDK] handleOpenUniversalLink:userActivity]) {
 return YES;
 }
 return YES;
}

商家转账​

接口原型

/**
 * business
 */
- (void)openBusinessViewWithModel:(RXWXBusinessModel *)model
 complete:(void(^)(NSDictionary *response, RX_CommonRequestError *error))complete;

参数说明​

参数类型说明
appidString发起商家转账的微信 appid
businessTypeString【业务类型】固定配置： requestMerchantTransfer
queryString【查询参数】使用 URL 的 query string 方式传递参数，格式为 key=value&key2=value2 ，其中 value、value2 需要进行 UrlEncode 处理。

query 说明

参数类型说明
mchIdString【商户号】商户号，由微信支付生成并下发，和发起转账传入的 mchid 必须是同一个
appIdString【商户 AppID】微信开放平台审核通过的移动应用 appid ，和发起转账传入的 appid 必须是同一个
packageString【package 信息】对应发起转账接口应答参数中的 package_info （仅当转账单据状态为 WAIT_USER_CONFIRM: 待收款用户确认时才返回），用于唤起用户确认收款页面。

调用示例

3.8.3 以上

RXWXBusinessModel *model = [[RXWXBusinessModel alloc] init];
model.appid = @"wx8888888888888888";
model.businessType = @"requestMerchantTransfer";
model.query = @"mchId=1230000000&appId=wx8888888888888888&package=affffddafdfafddffda%3D%3D"; // 示例，根据实际情况填写
[[RXWXService sharedSDK] openBusinessViewWithModel:model complete:^(NSDictionary * _Nonnull response, RX_CommonRequestError * _Nonnull error) {
 if (!error) {
 NSLog(@"调用成功");
 } else {
 NSLog(@"调用失败");
 }
}];

3.8.3 以下

// 微信初始化
[[RXWXService sharedSDK] shareToWWithShareInfo:@{@"appid" : @"wx8888888888888888"} complete:^(BOOL success) {

}];

RXWXBusinessModel *model = [[RXWXBusinessModel alloc] init];
model.businessType = @"requestMerchantTransfer";
model.query = @"mchId=1230000000&appId=wx8888888888888888&package=affffddafdfafddffda%3D%3D"; // 示例，根据实际情况填写
[[RXWXService sharedSDK] openBusinessViewWithModel:model complete:^(NSDictionary * _Nonnull response, RX_CommonRequestError * _Nonnull error) {
 if (!error) {
 NSLog(@"调用成功");
 } else {
 NSLog(@"调用失败");
 }
}];

配置说明​

接收微信回调

注意：路径规范 分享 应用的包名.wxapi.WXEntryActivity ，支付 应用的包名.wxapi.WXPayEntryActivity 为微信硬性要求

微信 sdk 验证微信 包名、签名、AppID ，三个参数要完全和开放平台配置一致。

如果你的 app 接入微信组件，需要接收微信发送的请求，或者接收发送到微信请求的响应结果.

分享回调创建 .wxapi.WXEntryActivity 类继承自 com.ruixue.wechat.WXEntryActivity

支付回调创建 .wxapi.WXPayEntryActivity 类继承自 com.ruixue.wechat.WXEntryActivity


activity
 android:name=".wxapi.WXEntryActivity"
 android:theme="@android:style/Theme.Translucent.NoTitleBar"
 android:exported="true"
 android:taskAffinity="com.xxx.xxx"
 android:launchMode="singleTask">
</activity>

activity
 android:name=".wxapi.WXPayEntryActivity"
 android:theme="@android:style/Theme.Translucent.NoTitleBar"
 android:exported="true"
 android:taskAffinity="com.xxx.xxx"
 android:launchMode="singleTask">
</activity>

回调类文件示例

注意： cp 创建的 WXEntryActivity 、WXPayEntryActivity 类必须在 应用包名.wxapi 包下，类名也不允许随意命名，同时继承SDK 的 com.ruixue.wechat.WXEntryActivity 类。

//WXEntryActivity.java
public class WXEntryActivity extends com.ruixue.wechat.WXEntryActivity {
}

//WXPayEntryActivity.java
public class WXPayEntryActivity extends com.ruixue.wechat.WXEntryActivity {
}

微信错误码

错误码错误描述
-1一般错误
-2用户取消
-3发送失败
-4认证被否决
-5不支持
-6被屏蔽所有操作，可能由于签名不正确或无权限
-7未知错误
-8用户直接通过后台切换返回 app 产生的错误码

跳转到微信并打开小程序​

小程序跳转 APP 开发指南

接口原型

    /**
    * @param context 应用上下文
    * @param hashMap {@link ShareObject}
    * username 填小程序原始id
    * path 拉起小程序页面的可带参路径，不填默认拉起小程序首页，对于小游戏，可以只传入 query 部分，来实现传参效果，如：传入 "?foo=bar"

    * miniprogramType 可选打开 开发版，体验版和正式版
    * @param openCallback 回调
    * code {@link WXErrCode}
    * msg 对应小程序组件 button open-type="launchApp"> 中的 app-parameter 属性
    * @return 请求是发送否成功
    */
    public static boolean openMiniProgram(Context context, Map<String, Object> hashMap, @NonNull RXJSONCallback openCallback)

调用示例


Map<String, Object> share = new HashMap<>();
share.put("appid", this.mWxAppid);
share.put("username", this.mWxAppid);
share.put("path", 拉起小程序页面的可带参路径，不填默认拉起小程序首页，对于小游戏，可以只传入 query 部分，来实现传参效果，如：传入 "?foo=bar");

WXSdkWrapper.openMiniProgram(this, share, callback);
