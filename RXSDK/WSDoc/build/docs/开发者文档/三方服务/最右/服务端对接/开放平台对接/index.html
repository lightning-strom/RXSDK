开放平台对接

渠道方文档地址: https://gamedocs.izuiyou.com/sign

业务数据上报（服务端）​

POST： /v1/thirdparty/api/channel_gateway/minigame_zuiyou/srv_data_report

认证方式： CPSign

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/thirdparty/api/channel_gateway/minigame_zuiyou/srv_data_report' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \

请求参数（POST）​

字段类型是否必填说明
data_typestring是数据类型，见事件数据定义
appstring是来源应用， zuiyou - 最右， zuiyou_lite - 皮皮
game_idstring是平台侧游戏唯一标识
rx_openidstring是望舒 openid
timestring是上报时间；格式 YYYY-MM-DD HH:ii:ss
user_ipstring是用户 IP
payloadstring是数据内容 JSON 序列化字符串；具体数据定义见：事件数据定义

响应示例

{
  "code": 0,
  "data": {
  "code":0,
  "message":"success"
}
}

响应结构（JSON）​

字段名类型描述
codeNumber望舒错误码
data.codeNumber业务错误码
data.messageString业务信息

返回示例

{
  "code": 0,
  "data": {
  "code":0,
  "message":"success"
}
}

获取游戏排行榜(望舒回调CP)​

当最右平台后台配置需要展示该游戏的游戏排行榜时，平均每隔五分钟触发此消息回调通知获取游戏排行榜信

类型：异步

Action: channel-notify

认证方式： CPSign

请求参数​

字段类型是否必填说明
product_idString是望舒产品标识
channel_idString是望舒渠道表示
methodString是最右默认 minigame_zuiyou
channel_notify_typeString是获取排行榜默认 RANK_LIST
queryString否url 参数
bodyString否body 请求体

body字段参数说明​

字段类型是否必填说明
game_idString是平台游戏标识，由平台方提供
appString是平台，最右： zuiyou, 皮皮搞笑： zuiyou_lite。需要返回对应平台的排行榜，如有疑问可以和平台运营同学沟通
countint是数量，获取排行榜前 n 名， n = count ， n 最大为 100

请求示例​

{
  "product_id": "1002",
  "channel_id": "100",
  "method": "minigame_zuiyou",
  "channel_notify_type": "RANK_LIST",
  "query": "",
  "body": ""app=zuiyou&count=3&game_id=testgame"
}

返回示例​

{
  "code": 0,
  "data":"{\"code\":\"success\",\"json\":\"[{\\\"rx_openid\\\":\\\"3dekrl1==\\\",\\\"nickname\\\":\\\"佚名\\\",\\\"avatar\\\":\\\"https://file.izuiyou.com/img/view/id/1110375480\\\",\\\"score\\\":0,\\\"score_unit\\\":\\\"分\\\",\\\"ranking\\\":1},{\\\"rx_openid\\\":\\\"3dekr22==\\\",\\\"nickname\\\":\\\"佚名\\\",\\\"avatar\\\":\\\"https://file.izuiyou.com/img/view/id/1110375480\\\",\\\"score\\\":0,\\\"score_unit\\\":\\\"分\\\",\\\"ranking\\\":2},{\\\"rx_openid\\\":\\\"3dekr33==\\\",\\\"nickname\\\":\\\"佚名\\\",\\\"avatar\\\":\\\"https://file.izuiyou.com/img/view/id/1110375480\\\",\\\"score\\\":0,\\\"score_unit\\\":\\\"分\\\",\\\"ranking\\\":3}]\"}"
}

响应要求​

字段类型说明
codeNumber0 成功
msgString错误信息
dataString响应渠道方数据

响应data要求​

字段类型说明
codeString成功 success
jsonString响应参数

响应参数要求​

字段类型说明
rx_openidstring望舒 openid
nicknamestring用户游戏内昵称，如果返回空值，则平台方会通过 uid 进行兜底
avatarstring用户游戏内头像，如果返回空值，则平台方会通过 uid 进行兜底
scoreinteger用户游戏内成绩，如多少分，多少楼等，如有疑问可以和平台运营同学沟通
score_unitstring用户游戏内成绩对应单位，如分，楼等，如有疑问可以和平台运营同学沟通
rankingint游戏内排名

类型：异步

Action: channel-notify

认证方式： CPSign

请求参数​

字段类型是否必填说明
product_idString是望舒产品标识
channel_idString是望舒渠道表示
methodString是最右默认 minigame_zuiyou
channel_notify_typeString是获取排行榜默认 RANK_USER_INFO
queryString否url 参数
bodyString否body 请求体

body字段参数说明​

字段类型是否必填说明
game_idString是平台游戏标识，由平台方提供

rx_openidString是望舒 openid

请求示例​

{
  "product_id": "1002",
  "channel_id": "100",
  "method": "minigame_zuiyou",
  "channel_notify_type": "RANK_USER_INFO",
  "query": "",
  "body": "app=zuiyou&game_id=testgame&rx_openid=3dekrle%3D%3D&uid=3dekrle%3D%3D"
}

返回示例​

{
