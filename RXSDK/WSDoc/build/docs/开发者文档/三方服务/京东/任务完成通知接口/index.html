任务完成通知接口

任务完成通知接口​

**POST: ** /v1/thirdparty/api/jd_notify

认证方式: CPSign

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/thirdparty/api/jd_notify' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--header 'Content-Type: application/json' \
--data-raw '{

}'

请求头 Header 参数

参数类型备注
ruixue-languageStringzh-CN
Content-TypeStringapplication/json
ruixue-cpidString内容提供商 CPID
ruixue-productidString产品 ID
ruixue-channelidString渠道 ID
ruixue-platformidString平台 platformid
ruixue-devicecodeString设备码
ruixue-cpsignStringCP 签名
ruixue-cptsStringCP 签名时间戳
ruixue-traceidStringTraceID

请求示例

{

}

请求参数（JSON）​

参数类型是否必填备注
cp_useridString是cp 侧 userid
action_typeString是行为类型，注意传字符串，

100000:代表进入活动页面

100011:去小游戏通关,

100012:去小游戏得分

字段类型是否必填说明
scoreInt否累计分数和累计值需要传，默认传 1
request_idString是幂等 id ，保证请求的唯一性
assignment_tokenString是加密任务信息（包含任务 id 和 pin ，时间戳等信息等信息），由前端链接携带，移动任务完成的时候回调，可从前端获取
encrypt_assignment_idString是加密任务 id

响应示例

{
 "data": {
 "jd_raw_resp": "京东接口返回的原始内容",
 },
 "msg": "success",
 "code": 0
}

响应结构(JSON)​

参数类型备注
codeNumber0 为成功
msgString失败信息
dataString京东接口原始的返回内容

异常返回时，错误码​

code描述
303412京东任务完成 API 接口错误
303414京东 app_key 等账号未配置或配置内容错误
303415未获取到用户京东账号信息
303416获取望舒 openid 失败
剩余大于 0 的错误码均为系统异常情况，按照 msg 展示或其它自定义展示
