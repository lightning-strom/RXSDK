准备工作​

接入请前先做好准备工作。可通过 pod 方式接入 RXAdjustSDK 组件，并使用 RXAdjustSDK 相关功能。

在需要使用功能的类中引用头文件#import <RXAdjustSDK/RXAdjustSDK.h>

前往 Adjust 平台 申请相关配置权限。

SDK 集成​

编辑 Podfile 文件，添加如下配置：

pod 'RXAdjustSDK'

添加 iOS 框架​

在应用中添加特定 iOS 框架后， Adjust SDK 就能获取额外信息。添加框架并将其标记为 optional (可选)，即可在 Adjust SDK 中启用额外的功能。

框架描述注意事项
AdSupport.framework如果您希望 SDK 能访问 IDFA 值和 (iOS 14 以前的) LAT 信息，请添加该框架。如果您的应用属于 "儿童" (Kids) 类别，请不要安装该框架。
AdServices.framework该框架对于处理 Apple Search Ads 是必要的。StoreKit.framework
如果您希望访问 SKAdNetwork 框架，同时让 Adjust SDK 在 iOS 14 或未来版本的 iOS 中自动处理与该框架的通讯，请添加该框架。AppTrackingTransparency.framework如果您希望 SDK 能在 iOS 14 或未来版本的 iOS 中包装用户的跟踪许可对话框，并访问用户的许可响应，请添加该框架。
如果您的应用属于 "儿童" (Kids) 类别，请不要安装该框架。WebKit.framework该框架允许您在应用程序中使用网络视图 (web view)。
只有在应用使用 web view 的时候才有必要。

初始化SDK​

安装所有必需的框架后，您就可以初始化应用程序中的 RXAdjust SDK 了。要进行 SDK 初始化，请使用应用识别码及您希望应用程序运行的环境来初始化 RXADJConfig 对象。

在 SDK 初始化方法 之前调用。

接口原型

/**
 * 初始化
 * @param adjustConfig 初始化配置
 */
- (void)appDidLaunch:(RXADJConfig *)adjustConfig;

调用示例

NSString *yourAppToken = @"{YourAppToken}";
NSString *environment = RXADJEnvironmentProduction;
RXADJConfig *adjustConfig = [RXADJConfig configWithAppToken:yourAppToken
 environment:environment];

[[RXAdjust sharedSDK] appDidLaunch:config];

设置日志​

如果要禁用所有日志，请在 RXADJConfig 实例中将 allowSuppressLogLevel 设为 true ，然后用值 RXADJLogLevelSuppress 调用 setLogLevel 方法。

要设置日志的输出级别，请在 ADJConfig 实例中使用 logLevel 属性。您需要在调用 appDidLaunch 之前这么做，才能设置级别。

接口原型

/**
 * 设置日志
 * @param logLevel 日志等级
 */
- (void)setLogLevel:(RXADJLogLevel)logLevel;

调用示例

[[RXAdjust sharedSDK] setLogLevel:RXADJLogLevelVerbose];

SDK集成​

版本说明

version 为 SDK 版本号（替换为实际版本号），最新版本请从 更新日志 中查看。

//海外渠道引用此库
 implementation 'com.ruixue:rxsdk_adjust:${version}'

添加权限​

Adjust SDK 需要下列权限。(如尚未添加) 请将其添加至您的 AndroidManifest.xml 文件中：

<uses-permission android:name="android.permission.INTERNET">
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE">

如果您的应用并非面向 Google Play 商店，请添加以下权限

<uses-permission android:name="android.permission.ACCESS_WIFI_STATE">

设置 Install Referrer​

Install Referrer 是一种唯一标识符，可用来将应用安装归因至来源。Adjust SDK 需要该信息进行归因。您可以用下列 4 种方法收集 install referrer ：

使用 Google Play Referrer API。

SDK 已默认支持, 无需额外配置。

如果您合作的应用商店支持 INSTALL_REFERRER intent ，则可以用广播接收器获取该信息。将下列 receiver 添加至 AndroidManifest.xml 中的 application 标签

receiver
 android:name="com.adjust.sdk.AdjustReferrerReceiver"
 android:permission="android.permission.INSTALL_PACKAGES"
 android:exported="true" >
</intent-filter>
 <action android:name="com.android.vending.INSTALL_REFERRER">
</intent-filter>
</receiver>

使用华为 Referrer API (仅限华为设备)。

SDK 已默认支持, 无需额外配置。

使用插件获取设备特定值。

SDK 已默认支持, 无需额外配置。

集成 SDK 至您的应用​

为了增加 Adjust 归因的准确性，需要先调用 望舒设置初始化参数接口，再调用 RXAdust 初始化，否则数据可能会有一定丢失。

接口原型

    /**
    * 实例化配置
    * @param context Context上下文
    * @param appToken appToken
    * @param environment 当前环境
    */
    public RxAdjustConfig(Context context, String appToken, String environment);

    /**
    * 初始化 Adjust
    * @param context Context上下文
    * @param rxAdjustConfig 相关配置参数
    */
    public void init(Context context, RxAdjustConfig rxAdjustConfig);

参数说明

RxAdjustConfig 说明

参数类型说明
contextContext实例化 RxAdjustConfig 传入
appTokenString您可以在 Adjust 控制面板上找到自己的应用识别码。
environmentStringRxAdjustConfig.ENVIRONMENT_SANDBOX 测试环境

RxAdjustConfig.ENVIRONMENT_PRODUCTION 生产环境

在进行测试时，应当确保将环境设置为 RxAdjustConfig.ENVIRONMENT_SANDBOX 。请在向 App Store 提交应用程序前将此设为 AdjustConfig.ENVIRONMENT_PRODUCTION 。

调用示例

我们建议您使用全局安卓 Application 类进行 SDK 初始化。如果您的应用中还没有此类，请按照下列步骤操作：

创建一个扩展 Application 的类。

打开 AndroidManifest.xml 文件，找到 <application> 元素。

添加 android:name 属性，并将其设置为 Application 类的名称。例如，如果您的 Application 类名称为 GlobalApplication ：

 application
 android:name=".GlobalApplication"
 ... />
</application>

在 Application 类中找到或添加 onCreate 方法。添加下列代码初始化 Adjust SDK ：

public class GlobalApplication extends Application {
    @Override
    public void onCreate() {
    super.onCreate();

    // 为了增加 Adjust 归因的准确性，需要先调用 望舒设置初始化参数接口，再调用 RXAdust 初始化，否则数据可能会有一定丢失。
    RuiXueSdk.setInitParams(cpid, productid, channelid, baseUrl);

    // 可设置 沙盒模式：ENVIRONMENT_SANDBOX 正式模式：ENVIRONMENT_PRODUCTION
    String environment = RxAdjustConfig.ENVIRONMENT_PRODUCTION;
    RxAdjustConfig config = new RxAdjustConfig(this, "{YourAppToken}", environment);
    AdjustSdkWrapper.getInstance().init(this, config);
    }
}

设置会话跟踪​

您需要设置会话跟踪， SDK 才能向 Adjust 后端传送会话信息。请按照下列说明操作，在应用中进行会话跟踪设置。

添加一个私有类 (private class) ，以部署 ActivityLifecycleCallbacks 接口。如果您不能访问该接口，则表示应用仅支持安卓 API level 14 以下版本。您需要按照以下 说明更新每个活动。如果您的应用活动中有 Adjust.onResume 和 Adjust.onPause 调用，请将其移除。

编辑 onActivityResumed(Activity activity) 方法，添加 Adjust.onResume()调用。编辑 onActivityPaused(Activity activity) 方法，添加 Adjust.onPause()调用。

将 onCreate() 方法添加至您的 Adjust SDK 配置步骤。使用已创建 ActivityLifecycleCallbacks 类的实例调用 registerActivityLifecycleCallbacks.

接口原型


    /**
    * 通知Adjust页面处于可见
    * @param activity
    */
    @Override
    public void onResume(Activity activity);

    /**
    * 通知Adjust页面不可见
    * @param activity
    */
    @Override
    public void onPause(Activity activity);

调用示例

API level 14 及更高


public class GlobalApplication extends Application {
    @Override
    public void onCreate() {
    super.onCreate();

    String environment = RxAdjustConfig.ENVIRONMENT_SANDBOX;
    RxAdjustConfig config = new RxAdjustConfig(this, "{YourAppToken}", environment);
    AdjustSdkWrapper.getInstance().init(this, config);

    registerActivityLifecycleCallbacks(new AdjustLifecycleCallbacks());
    }
}

    private static final class AdjustLifecycleCallbacks implements ActivityLifecycleCallbacks {

    @Override
    public void onActivityResumed(@NonNull Activity activity) {
    AdjustSdkWrapper.getInstance().onResume(activity);
    }

    @Override
    public void onActivityPaused(@NonNull Activity activity) {
    AdjustSdkWrapper.getInstance().onPause(activity);
    }

    // ...

    }

API level 9 至 13

如果 gradle 文件中的 minSdkVersion 在 9 - 13 之间，请考虑将其变更为 14 或更高，这样可以简化集成流程。请查看 安卓控制面板 了解目前市场上各主要版本的占比。

在暂停或恢复 Activity 时，您需要调用特定方法。这样， Adjust SDK 才不会错过会话的开始或结束。为此，请针对应用中的每个 Activity 进行下列步骤操作：

在活动的 onResume 方法中调用 AdjustSdkWrapper.getInstance().onResume(activity) 。如有必要请创建该方法。

在活动的 onPause 方法中调用 AdjustSdkWrapper.getInstance().onPause(activity) 。如有必要请创建该方法。

public class YourActivity extends Activity {
    protected void onResume() {
    super.onResume();
    AdjustSdkWrapper.getInstance().onResume(activity);
    }
    protected void onPause() {
    super.onPause();
    AdjustSdkWrapper.getInstance().onPause(activity);
    }
}

对您的应用中的每个 Activity 重复以上步骤。取决于编码方式，您也可通过添加所有 Activitiy 的通用超类来实现它。

设置日志​

接口原型

    /**
    * 设置显示日志级别
    * @param logLevel 日志级别
    */
    public void setLogLevel(RxLogLevel logLevel) {
    this.logLevel = logLevel;
    }

参数说明

    VERBOSE(Log.VERBOSE),
    DEBUG(Log.DEBUG),
    INFO(Log.INFO),
    WARN(Log.WARN),
    ERROR(Log.ERROR),
    ASSERT(Log.ASSERT),
    SUPRESS(8);

调用示例

public class GlobalApplication extends Application {
    @Override
    public void onCreate() {
    super.onCreate();

    String environment = RxAdjustConfig.ENVIRONMENT_SANDBOX;
    RxAdjustConfig config = new RxAdjustConfig(this, "{YourAppToken}", environment);
    config.setLogLevel(RxLogLevel.WARN);
    AdjustSdkWrapper.getInstance().init(this, config);
    }
}

如果您想禁用所有日志，请将日志级别设置为 suppress:

public class GlobalApplication extends Application {
    @Override
    public void onCreate() {
    super.onCreate();

    String environment = RxAdjustConfig.ENVIRONMENT_SANDBOX;
    RxAdjustConfig config = new RxAdjustConfig(this, "{YourAppToken}", environment);
    config.setLogLevel(RxLogLevel.SUPRESS);
    AdjustSdkWrapper.getInstance().init(this, config);
    }
}
