小游戏支付配置

文档说明

本渠道当前仅提供配置说明，暂无独立的客户端 SDK 接入文档。 如需了解各渠道覆盖能力，请查看 渠道矩阵。

准备工作​

好游快爆开放平台地址：https://open.3839.com/console

望舒系统地址：企业管理后台中获取望舒地址。

支付配置​

好游快爆开放平台获取配置​

登录好游快爆开放平台，位置：首页>前往快爆小游戏 >游戏列表。

获取关键配置： 游戏 ID,Security Key。

望舒系统中配置支付信息​

复制到望舒系统，位置：企业管理后台> 三方账号管理 > 支付账号管理 > 新建支付账号。

开放平台配置回调地址​

开放平台配置支付回调地址。位置：首页>前往快爆小游戏 >游戏列表。

回调地址可以从望舒游戏平台>首页>筛选渠道包>复制参数>支付参数>获取需要的支付方式的回调地址
