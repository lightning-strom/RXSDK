服务端接入

文档说明

本渠道当前仅提供配置说明，暂无独立的客户端 SDK 接入文档。 如需了解各渠道覆盖能力，请查看 渠道矩阵。

获取商品包列表 API(望舒回调CP)​

获取用户可购买的商品包信息，返回结果为商品包列表（包含 productID ）。商品包需通过该 API 返回且在 Webshop 内完成配置，方可在 Webshop 中展示。

类型：同步

Action: channel-notify

认证方式： CPSign

请求参数​

字段类型是否必填说明
product_idString是望舒产品标识
channel_idString是望舒渠道表示
methodString是默认 minigame_vng
channel_notify_typeString是默认 getproducts
queryString否url 参数
bodyString是body 请求体

body(JSON)字段参数说明​

字段类型是否必填说明
clientIPString否用户浏览器的 IP 地址
loginChannelString否VNG 侧登录渠道
userIDString是VNG 用户 ID
serverIDString是服务器 ID
roleIDString是角色 ID
countryString否国家，采用 ISO 3166-1 alpha-2 代码，例如： VN （越南）、TH （泰国）、IN （印度）等，参考 ISO 3166-1 alpha-2 标准
currencyString否货币，采用 ISO 4217 代码，例如： VND （越南盾）、THB （泰铢）、USD （美元）等，参考 ISO 4217 标准
rx_openidString是望舒 openid

请求示例​

{
  "product_id": "1002",
  "channel_id": "100",
  "method": "minigame_vng",
  "channel_notify_type": "getproducts",
  "query": "",
  "body": "{\"country\":\"\",\"loginChannel\":\"\",\"roleID\":\"200000028\",\"clientIP\":\"\",\"currency\":\"\",\"serverID\":\"1\",\"userID\":\"1758113059365817146097117\"}"
}

返回示例​

{
  "code": 0,
  "data":{
  "returnCode": 1,
  "returnMessage": "success",
  "data": {
  "1": {
  "productID": "1",
  "enable": true,
  "productName": "500 Vàng",
  "info": {}
},
  "2": {
  "productID": "2",
  "enable": true,
  "productName": "1000 Vàng",
  "info": {}
}
}
}
}

响应要求​

字段类型说明
codeNumber0 成功
msgString错误信息
dataData响应渠道方数据

响应data要求​

字段类型说明
returnCodeNumber错误码，成功 = 1 ，失败≠1
returnMessageString错误描述
dataMap <String, ProductEntity>商品列表，键为 productID

ProductEntity​

字段类型说明
productIDString商品 ID
productNameString商品名称
enableBoolean商品状态，启用 = 1 ，禁用≠1
productDescriptionString向角色展示的商品描述
productBonusString向角色展示的额外奖励说明
infoObject(json)需在 Webshop 展示的商品详细信息

通过 roleID 获取角色信息 API(望舒回调CP)​

通过 roleID 获取用户的角色信息，支持用户使用游戏内 roleID 快速登录（快捷登录）。游戏内 roleID 在所有服务器中唯一，且易于记忆和复制

类型：同步

Action: channel-notify

认证方式： CPSign

请求参数​

字段类型是否必填说明
product_idString是望舒产品标识
channel_idString是望舒渠道表示
methodString是默认 minigame_vng
channel_notify_typeString是默认 getrolesbyroleid
queryString否url 参数
bodyString是body 请求体

body(JSON)字段参数说明​

字段类型是否必填说明
clientIPString否用户浏览器的 IP 地址
roleIDString是角色 ID

请求示例​

{
  "product_id": "1002",
  "channel_id": "100",
  "method": "minigame_vng",
  "channel_notify_type": "getrolesbyroleid",
  "query": "",
  "body": "{\"roleID\":\"200000028\",\"clientIP\":\"\""}"
}

返回示例​

{
  "code": 0,
  "data":{
  "returnCode": 1,
  "returnMessage": "success",
  "data": {
  "70590000002052": {
  "rx_openid": "xxxxx",
  "roleID": "70590000002052",
  "roleName": "YuiSakura",
  "userID": "vng_11331",
  "serverID": "1",
  "serverName": "Server 1",
  "info": {
  "level": 93,
  "power": 695020
}
}
}
}
}
}

响应要求​

字段类型说明
codeNumber0 成功
msgString错误信息
dataData响应渠道方数据

响应data要求​

字段类型说明
returnCodeNumber错误码，成功 = 1 ，失败≠1
returnMessageString错误描述
dataMap <String, RoleEntity>角色列表，键为 roleID

RoleEntity​

字段类型说明
roleIDString角色 ID
roleNameString角色名称
userIDString用户 ID
rx_openidString望舒 openid 和 userID 选填 1 个即可
serverIDString服务器 ID
serverNameString服务器名称
infoObject (json)需在 Webshop 展示的角色详细信息，例如：等级、排名、金币等

字段类型是否必填说明
rx_openidString是望舒 openid

字段类型是否必填说明
