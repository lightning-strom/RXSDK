三方渠道接入说明

华为海外渠道手机系统要求， Android 系统支持 GMS 服务的华为手机 ，国内鸿蒙系统海外不可用。

华为内置 Google Facebook 等三方渠道库，不可再额外引用 Google Facebook 等三方库

SDK集成​

版本说明

version 为 SDK 版本号（替换为实际版本号），最新版本请从 更新日志 中查看。

//华为渠道库
 implementation 'com.ruixue:rxsdk_overseas_huawei:${version}'

参数说明​

参数类型说明
agconnect-services.jsonjson 文件配置文件初始化

配置说明​

需要在华为开发者平台 AppGallery Connect 中在 项目设置>常规> 下载 agconnect-services.json 文件并将其放在 app 根目录下。

在 app 根目录下 build.gradle 添加 AGC 插件配置,请根据实际情况选择.

//方式一：在文件头部声明下一行添加
apply plugin: 'com.huawei.agconnect'

//方式二：在 `plugins` 添加
plugins {
 id 'com.android.application'
 id 'com.huawei.agconnect'
}

在您的项目根目录中，打开 your_app | Gradle Scripts | build.gradle (Project) 并添加以下存储库：

buildscript {
 dependencies {
 //华为
 classpath 'com.huawei.agconnect:agcp:1.9.1.300'
 }
}

allprojects {
 repositories {
 // 华为的库的仓库地址
 maven { url 'https://developer.huawei.com/repo/' }
 }
}

为满足监管要求，集成 SDK 后要求用户在未同意访问网络前不能发送任何网络请求，如何处理？

用户在未同意访问网络前请不要调用 initThirdSdk 接口初始化三方 SDK

提供了设置能否发送网络请求的能力，在 AndroidManifest.xml 的 Application 中增加如下 meta-data 配置， value 配置为 false ，表示未同意协议前不发送网络请求。

在您的项目中，打开 your_app | Gradle Scripts | build.gradle (Module: app) 并将以下语句添加到 defaultConfig 块 部分：

manifestPlaceholders = [
 FACEBOOK_APP_ID : "xxxxxxx"
]

resValue "string", "facebook_app_id", "16881xxxxx629555"
resValue "string", "facebook_client_token", "140aaab9e9xxxxxxxxxxd242be2bc19d"

//需要Google 登录时候添加，从Google firebase 后台 凭证中获取
resValue "string", "google_app_id", "7288xx'xx69094"
resValue "string", "google_client_id", "7288xxxx69094-v0apajj7rd65s3abb8aj9kkub79rdt4f.apps.googleusercontent.com"

混淆配置​

参考链接

在应用级根目录下打开混淆配置文件 proguard-rules.pro ，加入排除 SDK 的混淆配置

-ignorewarnings
-keepattributes *Annotation*
-keepattributes Exceptions
-keepattributes InnerClasses
-keepattributes Signature
-keepattributes SourceFile,LineNumberTable
-keep class com.huawei.hianalytics.**{*;}
-keep class com.huawei.updatesdk.**{*;}
-keep class com.huawei.hms.**{*;}
-keep interface com.huawei.hms.analytics.type.HAEventType{*;}
-keep interface com.huawei.hms.analytics.type.HAParamType{*;}
-keep class com.huawei.hms.analytics.HiAnalyticsInstance{*;}
-keep class com.huawei.hms.analytics.HiAnalytics{*;}

如果您使用了 AndResGuard ，需要在应用级的“build.gradle”文件中加入 AndResGuard 允许清单

"R.string.agc*",

登录​

登录方式

method 参数类型说明
huawei_googlestring华为 Google 登录
huawei_fbstring华为 facebook 登录

请参考 Android 端登录 API

参考代码

String username = null;
String loginType = "hwjos"; // 上面登录方式根据需求选择
String password = null;
String captchaCode = null;
String loginOpenId = null;
Map<String, Object> ext = null;
String[] signFields = null;
Object migrateArgs = null;
RuiXueSdk.getApi().login(DemoActivity.this, loginType, username, password, captchaCode, loginOpenId, ext, signFields, migrateArgs, new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject data) {
    Toast.makeText(DemoActivity.this, "登录成功", Toast.LENGTH_SHORT).show();
    }

    @Override
    public void onFailed(@NonNull JSONObject cause) {
    Toast.makeText(DemoActivity.this, "登录失败", Toast.LENGTH_SHORT).show();
    }
});

接口原型

/** 商品详情查询接口
    * @param skusList googleplay商品id列表
    * @param callback 商品 json字符串信息回调 json 数组

queryProductDetailsAsync(@NonNull List<String> skusList, @NonNull RXStringCallback callback)

调用示例

HmsOSSdkWrapper.getInstance().queryProductDetailsAsync(productIdList, new RXStringCallback() {
    @Override
    public void onSuccess(@Nullable String data) {
    RXLogger.i("product info: " + data);
    }

    @Override
    public void onFailed(int code, String msg, @Nullable String traceId) {

    @Override
    public void run() {

    }
    });

});
