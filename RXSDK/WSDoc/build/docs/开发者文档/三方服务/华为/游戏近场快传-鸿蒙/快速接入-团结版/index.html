版本：v4.x

本模块提供接入鸿蒙 Nex 的游戏近场快传能力。

系统版本要求

鸿蒙系统起始版本： 5.1.0(API Level 18)

兼容性校验：可通过 NearbyTransferService.isSupport() 方法检测当前设备是否满足版本要求

更多功能说明 ：参照华为官方文档

导入模块

import { NearbyTransferService, NearbyEventType } from 'hmssdk';

开发准备​

在工程的 entry 模块 module.json5 文件中，新增 metadata 并配置 app_id ，同时新增 requestPermissions 并配置如下权限。

"module": {
 "name": "entry",
 "type": "entry",
 "description": "xxxx",
 "mainElement": "xxxx",
 "deviceTypes": [
 "phone"
 ],
 "deliveryWithInstall": true,
 "pages": "$profile:main_pages",
 "abilities": [],
 "metadata": [ // 配置如下信息
 {
 "name": "app_id",
 "value": "xxxxxx" // 配置为前面步骤中获取的APP ID
 }
 ],
 "requestPermissions": [ // 配置权限
 {
 "name": "ohos.permission.INTERNET" // 允许使用Internet网络权限
 },
 {
 "name": "ohos.permission.GET_NETWORK_INFO" // 允许应用获取数据网络信息权限
 },
 {
 "name": "ohos.permission.SET_NETWORK_INFO" // 允许应用配置数据网络权限
 },
 {
 "name": "ohos.permission.DISTRIBUTED_DATASYNC", // 允许不同设备间的数据交换权限
 "reason": "$string:distributed_permission",
 "usedScene": {
 "abilities": [
 "EntryAbility"
 ],
 "when": "inuse"
 }
 }
 ]
}

处理协作授权​

注意必须添加，否则无法连接附近设备 ，团结引擎请在 TuanjiePlayerAbility 中添加

 /**
 * 处理协作请求（需在 UIAbility 的 onCollaborate 生命周期函数中调用）
 * @description 接收并处理外部设备发起的协作请求，完成协作参数解析、设备绑定及协作流程初始化，
 * 通常与系统协作机制联动，由 UIAbility 的 onCollaborate 生命周期触发调用
 * @param acceptParameters - 协作请求参数（来自系统传递的 wantParam）
 * 包含协作所需的设备信息、请求类型等关键数据，结构为键值对形式
 * @returns Promise - 异步协作处理结果，无返回值（处理结果通过事件回调反馈）
 * @example
 * // 在 UIAbility 中集成调用示例
 * onCollaborate(wantParam: Record): AbilityConstant.CollaborateResult {
 * // 异步处理协作请求（不阻塞生命周期返回）
 * NearbyTransferService.acceptCollaboration(wantParam).catch(err => {
 * LogUtil.error("协作请求处理失败：", err);
 * });
 * // 同步返回接受协作的结果给系统
 * return AbilityConstant.CollaborateResult.ACCEPT;
 * }
 * @throws {BusinessError} 协作处理异常时抛出错误（如参数无效、协作服务未初始化、设备连接失败等）
 */
 public static async acceptCollaboration(acceptParameters: Recordstring, object>): Promise<void>

示例代码

 //Ability.ets 文件中添加
 onCollaborate(wantParam: Recordstring, Object>): AbilityConstant.CollaborateResult {
 NearbyTransferService.acceptCollaboration(wantParam);
 return AbilityConstant.CollaborateResult.ACCEPT;
 }

事件回调注册​

API 定义

/// summary>
/// 初始化近场通信模块（必须最先调用，模块使用前需完成初始化）
/// summary>
/// param name="param">初始化参数 param>
/// param name="callback">初始化结果回调：
/// param>
void Create(CreateParameters param, ActionRXResultobject>> callback);

示例代码


RuiXueSdk.GameNearbyTransfer().RegisterCallback((ret) =>
{

 if (ret.type == NearbyGameEventType.ConnectNotify)
 {
 Log.D("Nearby onEvent ConnectionStateChanged:" + ret.ToJson());
 }
 else if (ret.type == NearbyGameEventType.TransferNotify)
 {
 Log.D("Nearby onEvent MessageReceived:" + ret.ToJson());
 }
 else if (ret.type == NearbyGameEventType.BindNearbyGame)
 {
 Log.D("Nearby onEvent BindNearbyGameResult:" + ret.ToJson());
 }
 else
 {
 Log.D("Nearby onEvent other type:" + ret.ToJson());
 }

 Log.D("Nearby onEvent:" + ret.ToJson());
 ShowText(RXUtility.ObjectToJson(ret));
});
