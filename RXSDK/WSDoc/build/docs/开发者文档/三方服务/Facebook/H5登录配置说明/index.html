H5 登录配置说明

准备工作​

FaceBook 开发者平台地址：https://developers.facebook.com/

望舒系统地址：企业管理后台中获取望舒地址。

登录配置​

FaceBook开发者平台获取配置​

登录FaceBook 开发者平台，位置：首页>我的应用>应用设置>基本。

获取关键配置： 应用密钥。

H5登录开启JS登录并配置域名​

登录FaceBook 开发者平台，位置：首页>我的应用>产品>FaceBook 登录>设置

开启 JS 登录。并且配置网站的实际相关域名。

数据删除回调配置说明（非必要根据实际情况）​

登录FaceBook 开发者平台，位置：首页>我的应用>应用设置>基本。

选择数据删除回调网址，配置格式为：API 域名/v1/passport/tpcallbacks/facebook/产品/渠道/user_deregistered

望舒系统中配置登录信息​

在 H5 渠道的渠道包中添加 FaceBook 登录并把获取的 应用密钥 复制到望舒系统，位置：渠道&产品 > 渠道包管理 > 添加登录方式。
