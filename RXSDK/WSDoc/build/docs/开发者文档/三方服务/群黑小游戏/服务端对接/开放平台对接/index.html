开放平台对接

渠道方文档地址: http://open.heitu.com/Upload/port/#api-User-Role

角色上报接口(获取用户签名)​

POST： /v1/thirdparty/api/channel_gateway/minigame_qunhei/sdk.role.sign

认证方式： CPSign

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/thirdparty/api/channel_gateway/minigame_qunhei/sdk.role.sign' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \

请求参数（POST）​

字段类型是否必填说明
actNumber是1=创建角色， 2=登录角色， 3=角色升级
usernameString是望舒 openid
serveridNumber是区服 ID
servernameString是开服时间
rolenameString是角色 ID
roleidNumber是角色名称
levelNumber是角色等级(没有传 0)
powerNumber是角色战力(没有传 0)
vipNumber是vip 等级(没有传 0)
rolecreatetimeString是角色创建时间戳(没有传 0)
verNumber是版本号固定值 1

响应示例

{
  "code": 0,
  "data": {
  "sign":"xxxxxxxxxxxx"
}
}

响应结构（JSON）​

字段名类型描述
codeNumber望舒错误码
data.signString签名

提交开服接口​

POST： /v1/thirdparty/api/channel_gateway/minigame_qunhei/serverAdd

认证方式： CPSign

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/thirdparty/api/channel_gateway/minigame_qunhei/serverAdd' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \

请求参数（POST）​

字段类型是否必填说明
unidString是后台登录账号
gidNumber是游戏 id
servernumNumber是开服数
kftimeString是开服日期(2019-11-08)
ddtimeString是开服时间(12:00)

响应示例

{
  "code": 0
}

响应结构（JSON）​

字段名类型描述
codeNumber望舒错误码

角色上下线上报​

POST： /v1/thirdparty/api/channel_gateway/minigame_qunhei/upOnline

认证方式： CPSign

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/thirdparty/api/channel_gateway/minigame_qunhei/upOnline' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \

请求参数（POST）​

字段类型是否必填说明
gidNumber是游戏 id
typeNumber是1 上线， 2 下线
serveridNumber是服务器 id
timeString是行为时间,UnixTime 标准时间，单位秒。示 例： 1616918879
logintimeString是打开游戏时间,UnixTime 标准时间，单位秒。示 例： 1616918879
useridString是登录账号 id

响应示例

{
  "code": 0,
  "data":{
  "code":0,
  "msg":""
}
}

响应结构（JSON）​

字段名类型描述
codeNumber望舒错误码
data.codeNumber业务错误码 1 成功,其他失败
data.msgString业务状态描述

排行接口(望舒回调CP)​

当最右平台后台配置需要展示该游戏的游戏排行榜时，平均每隔五分钟触发此消息回调通知获取游戏排行榜信

类型：异步

Action: channel-notify

认证方式： CPSign

请求参数​

字段类型是否必填说明
product_idString是望舒产品标识
channel_idString是望舒渠道表示
methodString是群黑默认 minigame_qunhei
channel_notify_typeString是获取排行榜默认 ranklist
queryString否url 参数
bodyString否body 请求体

query字段参数说明​

字段类型是否必填说明
gidNumber是游戏 id
timeString是行为时间,UnixTime 标准时间，单位秒。示 例： 1616918879
countString是数量，获取排行榜前 n 名， n = count ， n 最大为 100

请求示例​

{
  "product_id": "1002",
  "channel_id": "100",
  "method": "minigame_qunhei",
  "channel_notify_type": "ranklist",
  "query": "count=xxx&gid=3626&time=1616918879&sign=xxxxx",
  "body": ""
}

返回示例​

{
  "code": 0,
  "data":"{\"code\":\"success\",\"json\":\"[{\\\"rx_openid\\\":\\\"3dekrl1==\\\",\\\"nickname\\\":\\\"佚名\\\",\\\"avatar\\\":\\\"xxxx\\\",\\\"score\\\":0,\\\"score_unit\\\":\\\"分\\\",\\\"ranking\\\":1},{\\\"rx_openid\\\":\\\"3dekr22==\\\",\\\"nickname\\\":\\\"佚名\\\",\\\"avatar\\\":\\\"xxx\\\",\\\"score\\\":0,\\\"score_unit\\\":\\\"分\\\",\\\"ranking\\\":2},{\\\"rx_openid\\\":\\\"3dekr33==\\\",\\\"nickname\\\":\\\"佚名\\\",\\\"avatar\\\":\\\"xxx\\\",\\\"score\\\":0,\\\"score_unit\\\":\\\"分\\\",\\\"ranking\\\":3}]\"}"
}

响应要求​

字段类型说明
codeNumber0 成功
msgString错误信息
dataString响应渠道方数据

响应data要求​

字段类型说明
codeString成功 success
jsonString响应参数

响应参数要求​

字段类型说明
rx_openidstring望舒 openid
nicknamestring角色名称
avatarstring角色头像
scoreint用户游戏内成绩，如多少分，多少楼，多少级等
score_unitstring用户游戏内成绩对应单位，如级，分，楼等
rankingint游戏内排名

类型：异步

Action: channel-notify

认证方式： CPSign

请求参数​

字段类型是否必填说明
product_idString是望舒产品标识
channel_idString是望舒渠道表示
methodString是群黑默认 minigame_qunhei

bodyString否body 请求体

query字段参数说明​
