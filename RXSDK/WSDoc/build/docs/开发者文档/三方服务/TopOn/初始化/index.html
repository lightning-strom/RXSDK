初始化配置​

您的 App 需要制订《隐私政策》，同时在用户首次启动 App 时展示《隐私政策》并取得用户同意。App 制订的《隐私政策》，请参考 隐私合规指南，请务必确保用户同意 App《隐私政策》之后，再初始化 TopOn SDK。

调用 SDK 来获取广告之前必须先进行初始化，建议在 AppDelegate 的 application:didFinishLaunchingWithOptions 方法里面执行

接口原型

/**
 * 初始化方法
 * @param appID - appid
 * @param appKey appkey
 * @param error - error
 */
- (BOOL)startWithAppID:(NSString *)appID
 appKey:(NSString *)appKey
 error:(NSError**)error;

调用示例

#import RXTopOnSDK/RXTopOnSDK.h>
#import AppTrackingTransparency/AppTrackingTransparency.h>

- (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {

 [RXTopOnInitManager setLogEnabled:NO];//日志开关，打包上线时需关闭
 [RXTopOnInitManager integrationChecking];//应用完整性校验，使用时setLogEnabled设为YES
 [[RXTopOnInitManager sharedSDK] setSystemPlatformType:ATSystemPlatformTypeIOS];
 if (@available(iOS 14, *)) {
 [ATTrackingManager requestTrackingAuthorizationWithCompletionHandler:^(ATTrackingManagerAuthorizationStatus status) {
 [[RXTopOnInitManager sharedSDK] startWithAppID:"your TopOn AppId" appKey:"your TopOn AppKey" error:nil];
 }];
 } else {
 [[RXTopOnInitManager sharedSDK] startWithAppID:"your TopOn AppId" appKey:"your TopOn AppKey" error:nil];
 }

 return YES;
}

打开日志​

使用此方法可以在工作台中查看关于 RXTopOnSDK 的日志。

接口原型

/**
 * 设置是否打印日志，YES打印，NO不打印，默认为NO
 */
+ (void)setLogEnabled:(BOOL)logEnabled;

调用示例

[RXTopOnInitManager setLogEnabled:YES];//打开日志开关，打包上线时需关闭

SDK集成完整性检测​

完成准备工作中的 SDK 引入后，可调用[ATAPI integrationChecking](注：需配合[ATAPI setLogEnabled:YES]，打开 SDK 日志打印)作为集成是否正常的参考，参考代码如下:

接口原型

/**
 * 配合[RXTopOnInitManager setLogEnabled:YES]，检查应用完整性
 */
+ (void)integrationChecking;

调用示例

[RXTopOnInitManager integrationChecking];

设置当前平台类型​

初始化时需要调用此 API 设置当前属于哪个系统平台，例如 iOS、Unity 等。

接口原型

/**
 设置平台类型
 */
- (void)setSystemPlatformType:(ATSystemPlatformType)type;

调用示例

[[RXTopOnInitManager sharedSDK] setSystemPlatformType:ATSystemPlatformTypeIOS];

广告流程集成建议​

建议按照以下所示流程来集成广告:

1.应用启动时初始化 RXTopOnSDK

2.进入对应页面后，提前调用 RXTopOnSDK 加载广告 loadADWithPlacementID

3.应用需要展示广告时，判断 isReady

YES ：展示广告，收到 DidCloseForPlacementID(广告关闭)回调后，再次加载广告，等待下次展示。

NO ：调用 TopOn SDK 加载广告 loadADWithPlacementID(提示用户“广告加载中”)，加载完成后继续展示广告。

</manifest>
