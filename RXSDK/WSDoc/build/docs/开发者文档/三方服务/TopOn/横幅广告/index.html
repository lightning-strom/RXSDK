集成建议​

加载广告

通过 loadADWithPlacementID 来执行加载广告，请提前调用加载方法进行广告的请求（比如在开屏展示之后就可以预加载广告），以便需要触发广告时可以快速展示

View 可以自定义宽高，但是部分广告平台不一定能适配自定义的宽高，所以设置的宽高要与在 TopOn 后台配置的宽高比成等比例，具体需要经过测试看看实际效果来进行调整。

展示广告

展示前请先调用 bannerAdReadyForPlacementID 判断广告是否已经准备就绪

YES ：即可调用 retrieveBannerViewForPlacementID 获取广告 View 进行展示

NO ：需要根据你们的需求决定是否放弃该次展示，预加载下一次广告，还是重新加载广告，等待成功后展示

ATBannerView 对象可重复使用，每次加载、展示时不需要重新创建。

广告预加载

横幅广告展示后，可以在广告展示之后 didShowAdWithPlacementID 的回调中调用 loadADWithPlacementID 进行预加载，有助于提升优先级比较高的广告源的展示量

如果已经在后台开启了自动刷新功能，可以不用自己做预加载的逻辑。

预置策略

建议配置预置策略：提高首次冷启动的广告加载效果，具体说明和接入教程见SDK 预置策略使用说明。

注意事项​

1.禁止在 didFailToLoadADWithPlacementID 回调中执行广告加载的方法，否则会引起很多无用请求且可能会导致应用卡顿。

2.Banner 提供自动刷新的功能，默认开启，可在 TopOn 后台广告位 高级设置 中，配置刷新时间或者不刷新，功能具体的逻辑如下：

（ 1 ）横幅广告的 View 必须已经 Add 进 ViewController 且可视状态才会自动刷新

（ 2 ） Banner 隐藏时自动刷新的计时不会停止

（ 3 ）如果隐藏到重新展示之间的时间超过刷新时间，在重新展示 Banner 时会直接调用一次 load 进行刷新

3.开启横幅广告位的自动刷新功能，开发者只需调用一次 load ，加载成功后将 ATBannerView 添加到您的布局中，保证处于可见状态后，后续的展示和刷新都会由 SDK 自动执行

4.统一关闭以下广告平台的自动刷新功能： Inmobi、Mintegral、Tencent Ads、穿山甲、Pangle ，如果需要自动刷新，请开发者统一使用 TopOn 后台的自动刷新功能。

5.集成 Mintegral 的 Banner 广告需要注意，必须先将 ATBannerView 先 add 进展示位置且必须是可视状态，再执行广告的加载才能正常获取广告。

6.开发者根据需要可通过 ATBannerView 的 isHidden 来控制显示和隐藏

7.不需要展示 Banner 时，请将 ATBannerView 移除，同时 ATBannerView = nil 方法来销毁当前的广告资源

8.不推荐 App 处于后台的情况下加载广告，避免系统回收资源引起的不必要的异常

加载广告​

接口原型

/**
 Splash的加载方法
 placementId：TopOn的开屏广告位id
 extra：本地配置参数
 containerView：底部视图
 注意：广告加载超时时间默认为5s
 */
- (void)loadADWithPlacementID:(NSString *)placementID
 extra:(NSDictionary *)extra
 containerView:(UIView * _Nullable)containerView;

调用示例

_adSize = CGSizeMake(CGRectGetWidth(self.view.bounds), 250.0f);
// 加载广告
- (void)loadBannerAdView {
 /* Admob自适应横幅设置，需要先引入头文件：#import
 //GADCurrentOrientationAnchoredAdaptiveBannerAdSizeWithWidth 自适应
 //GADPortraitAnchoredAdaptiveBannerAdSizeWithWidth 竖屏
 //GADLandscapeAnchoredAdaptiveBannerAdSizeWithWidth 横屏
 GADAdSize admobSize = GADCurrentOrientationAnchoredAdaptiveBannerAdSizeWithWidth(CGRectGetWidth(self.view.bounds));
 */
 NSDictionary *dict = @{
 // 设置请求的广告尺寸大小
 kATAdLoadingExtraBannerAdSizeKey:[NSValue valueWithCGSize:_adSize],
// // 仅Admob平台支持，自适应横幅大小
// kATAdLoadingExtraAdmobBannerSizeKey:[NSValue valueWithCGSize:admobSize.size],
// kATAdLoadingExtraAdmobAdSizeFlagsKey:@(admobSize.flags)
 };
 [[RXTopOnATAdManager sharedSDK] loadADWithPlacementID:self.placementID extra:dict];
 [RXTopOnATAdManager sharedSDK].loadingDelegate = self;
 [RXTopOnATAdManager sharedSDK].bannerDelegate = self;
}

检查广告是否准备完成​

接口原型

/**
 判断当前是否存在可展示的广告
 placementId：TopOn的开屏广告位id
 */
- (BOOL)bannerAdReadyForPlacementID:(NSString *)placementID;

调用示例

- (void)checkAd {
 BOOL isReady = [[RXTopOnATAdManager sharedSDK] bannerAdReadyForPlacementID:self.placementID];
 if (isReady) {
 NSLog(@"广告准备好了");
 }else{
 NSLog(@"广告未准备好");
 }
}

到达场景统计​

关于统计用户到达场景的相关信息，可前往广告场景进行了解。

统计用户到达该场景的几率，呈现在后台的数据 数据报表 -> 漏斗分析报表 -> 到达广告场景

一般在广告场景展示前调用此 API。

接口原型

/**
 统计用户到达该场景的几率，呈现在后台的数据 数据报表 -> 漏斗分析报表 -> 到达广告场景 ，所以建议开发者在正确的地方进行调用。
 placementId：广告位Id
 scene：广告展示场景，可从后台创建场景参数 使用请参考 业务场景缓存状态统计
 */
- (void)entryBannerScenarioWithPlacementID:(NSString *)placementID scene:(NSString *)scene;

调用示例

- (void)entryAdScenario {
 [[RXTopOnATAdManager sharedSDK] entryBannerScenarioWithPlacementID:self.placementID scene:"your scene id"];
}

展示广告​

接口原型

/**
 获取横幅广告视图
 placementId：TopOn的广告位id
 scene：场景id，没有可传空 @""
 */
- (nullable ATBannerView *)retrieveBannerViewForPlacementID:(NSString *)placementID
 scene:(NSString *)scene;

调用示例

 _adSize = CGSizeMake(CGRectGetWidth(self.view.bounds), 250.0f);
//展示横幅广告
 - (void)showBanner {
 // 到达场景
 [self entryAdScenario];

 // 判断广告ready状态
 if ([[RXTopOnATAdManager sharedSDK] bannerAdReadyForPlacementID:self.placementID]) {
 // 移除可能存在的旧BannerView
 NSInteger tag = 3333;
 [[self.view viewWithTag:tag] removeFromSuperview];

 ATBannerView *bannerView = [[RXTopOnATAdManager sharedSDK] retrieveBannerViewForPlacementID:self.placementID scene:KTopOnBannerSceneID];
 if (bannerView != nil) {
// bannerView.delegate = self;
 bannerView.presentingViewController = self;
 bannerView.translatesAutoresizingMaskIntoConstraints = NO;
 bannerView.tag = tag;
 self.bannerView = bannerView;

 self.adView = [[UIView alloc]init];
 self.adView.backgroundColor = randomColor;
 [self.adView addSubview:bannerView];
 [self.adView setFrame:CGRectMake(0, 328, kScreenW, 250)];
 [self.view addSubview:self.adView];

 bannerView.frame = CGRectMake(0, 0, _adSize.width, _adSize.height);

 } else {
 NSLog(@"BannerView is nil for placementID:%@", self.placementID);
 }
 } else {
 NSLog(@"Banner ad's not ready for placementID:%@", self.placementID);
 [self loadBannerAdView];
 }
}

// 移除广告BannerView
- (void)removeAd {
 if (self.adView && self.adView.superview) {
 [self.adView removeFromSuperview];
 self.bannerView = nil;
 self.adView = nil;
 }
}

初始化 Banner 广告​

接口原型

    // 初始化 Banner 广告
    public RxATBannerView(Context context);
    // 设置Banner的广告位id
    public void setPlacementId(String placementId);
    // 设置Banner广告监听回调
    public void setBannerAdListener(ATBannerListener listener);

调用示例

    RxATBannerView mBannerView;
    private void initBannerView() {
    mBannerView = new RxATBannerView(this);
    mBannerView.setPlacementId("b62b420ae05bb4");
    //Loading and displaying ads should keep the container and BannerView visible all the time
    mBannerView.setVisibility(View.VISIBLE);
    mBannerView.setBannerAdListener(new ATBannerExListener() {

    @Override
    public void onDeeplinkCallback(boolean isRefresh, ATAdInfo adInfo, boolean isSuccess) {
    Log.d(TAG, "onDeeplinkCallback:" + adInfo.toString() + "--status:" + isSuccess);
    }

    @Override
    public void onDownloadConfirm(Context context, ATAdInfo adInfo, ATNetworkConfirmInfo networkConfirmInfo) {
    Log.d(TAG, "onDownloadConfirm:" + adInfo.toString() + " networkConfirmInfo:" + networkConfirmInfo);
    }

    @Override
    public void onBannerLoaded() {
    Log.d(TAG, "onBannerLoaded");

    }

    @Override
    public void onBannerFailed(AdError adError) {
    Log.d(TAG, "onBannerFailed: " + adError.getFullErrorInfo());
    }

    @Override
    public void onBannerClicked(ATAdInfo entity) {
    Log.d(TAG, "onBannerClicked:" + entity.toString());
    }

    @Override
    public void onBannerShow(ATAdInfo entity) {
    Log.d(TAG, "onBannerShow:" + entity.toString());
    }

    @Override
    public void onBannerClose(ATAdInfo entity) {
    mBannerView.setVisibility(View.GONE);
    Log.d(TAG, "onBannerClose:" + entity.toString());
    }

    @Override
    public void onBannerAutoRefreshed(ATAdInfo entity) {
    Log.d(TAG, "onBannerAutoRefreshed:" + entity.toString());
    }

    @Override
    public void onBannerAutoRefreshFail(AdError adError) {
    Log.d(TAG, "onBannerAutoRefreshFail: " + adError.getFullErrorInfo());
    }
    });
    }
