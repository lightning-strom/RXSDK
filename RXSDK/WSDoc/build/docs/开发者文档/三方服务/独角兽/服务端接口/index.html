服务端接口

文档说明

本渠道当前仅提供配置说明，暂无独立的客户端 SDK 接入文档。 如需了解各渠道覆盖能力，请查看 渠道矩阵。

数据上报​

POST： /v1/thirdparty/unicorn/report

服务端请求头​

参数名说明是否必须示例
ruixue-traceid本次请求唯一标识

格式为 UUID v4 ，当接口出现错误时可将其提供给望舒团队对问题进行快速定位

是0e2971af-823a-4298-b7d8-3ef38094b500
ruixue-cpid望舒 CPID

望舒为每个 CP 分配的一个唯一 ID ，从 7 位数 1000000 开始递增

是1000000
ruixue-cpts时间戳

CP 服务端发起请求时的毫秒时间戳

是1669619948739
ruixue-language语言标识

系统语言标识

否zh-CN
ruixue-productid产品标识

CP 望舒集群内部的产品 ID ，由各 CP 自行在后台创建，字符串类型

是test
ruixue-region数据域标识

CP 游戏服的分区信息

否default
ruixue-cp-role-id数据域标识

CP 游戏服的角色信息

否default

DataObject（action=payment ）​

链接文本

字段类型是否必填说明
whostring是用户角色 ID ：该 ID 由 CP 自定义 , 保证每个区的 who 为唯一值。
deviceidstring是各渠道的 UID （用户身份标识）。
serveridstring是区服 ID ：该 ID 由 CP 自定义，一般是指角色所在的区服标识。

levelstring是角色等级：数据上报时的角色等级。
transactionidstring是发货订单号。
widstring是发货商品 ID ：该 ID 由接入时提供给独角兽运营的固定商品列表中的 wareid。
currencyamountNumber是商品金额（单位：元）
virtualcoinamountNumber是商品对应游戏币获得数量
channelidstring是渠道 ID
subchidstring是子渠道 ID
systemstring是操作系统 （ android ， ios ， pc ）
powerstring否战斗力数据（或其他等价数据）
