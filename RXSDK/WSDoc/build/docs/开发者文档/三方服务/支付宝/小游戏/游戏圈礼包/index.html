游戏圈礼包

功能介绍​

游戏商家可以在小游戏内通过游戏圈组件，在社区内为用户提供交流、互动、领取福利等能力。商家可以通过社区运营实现游戏用户的长线留存和对游戏中心用户的引流。

准备工作​

支付宝开放平台地址：https://open.alipay.com/

支付宝商家平台地址:https://b.alipay.com/page/home

望舒系统地址：企业管理后台中获取望舒地址。

开通游戏圈​

通过支付宝商家平台开通小游戏游戏圈功能。游戏圈开通说明

配置道具发放接口​

登录 支付宝开放平台> 可调用产品 > 小游戏 > 选择产品 小游戏运营，点击 去配置。进入后选择 spi.alipay.user.gameopenpromo.gift.send （三方小游戏游戏道具发放接口） 点击 接入 进行接入，接入完成后 申请上线。确认接口状态为 已接入，状态为 已上线 后，再执行后续流程。

接口配置格式：api 域名/v1/thirdaprty/api/channel_notify_gateway/产品 ID/渠 ID/minigame_alipay/spi_alipay_user_gameopenpromo_gift_send

响应是否加签 为否。

由于环境原因，支付宝只能访问到 后端正式服务地址，如果需要测试，可以先将该地址临时配置为商家测试地址进行联调，但在正式对外前（指发版或礼包正式对 C 端用户前）需切换配置为正式的商家地址，否则用户可能收不到礼包。

新建礼包​

新增礼包前需要先新增道具。登录 支付宝商家平台 > 私域运营>小游戏 > 选择 小游戏卡片 > 游戏礼包，填写对应道具信息后，正常新增上架即可。

获取配置参数​

以下参数和支付参数一致如果获取过可以直接填入即可。

1.登录 支付宝开放平台，获取相关应用内的 App_ID。位置：控制台 > 小游戏/移动应用 > ID。

2.登录 支付宝开放平台，获取相关应用内的 应用私钥 ， 支付宝公钥。位置：开发设置 > 开发信息 > 接口加签方式（密钥/证书） > 设置。

密钥配置流程​

1.设置加签方式，选择 密钥 > 下一步。

  1. 生成密钥文件。

a. 下载并安装 支付宝开放平台密钥工具。

b. 打开密钥工具，进入 生成密钥 功能。

c. 加签方式选择 密钥，加签算法选择 RSA2。（开放平台支持 SM2 算法，但暂未公开配置，如有需要请联系支付宝技术支持）

d. 点击 生成密钥，可以在结果页中看到生成的应用公钥、应用私钥。

说明： RSA2 加密算法默认生成格式为 PKCS8 （ Java 适用），如需 PKCS1 格式（非 Java 适用），可使用 格式转换。

e. 复制 应用公钥 字符串。

f. 返回开放平台控制台中，点击 下一步。

  1. 上传应用公钥。粘贴复制的应用公钥字符串，点击 确认上传。此时需要输入短信验证码或支付密码，完成安全验证。

  2. 密钥配置完成。

私钥文件在支付宝开放平台不保存，请妥善保管

望舒系统中配置信息​

渠道包配置​

通过获取到的 App_ID、支付宝公钥、应用私钥,复制到望舒系统。位置：渠道&产品 > 渠道包管理 > 编辑渠道包。

回调接入与配置​

服务端回调接入​

服务端回调接口参考：回调接口文档

服务端回调配置​

配置产品的回调接口。位置：版本发布>区服配置>选择区服>回调配置>添加回调事件>基础配置>渠道回调消息转发。
