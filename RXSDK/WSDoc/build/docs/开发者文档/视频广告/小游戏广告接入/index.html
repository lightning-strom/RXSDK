激励广告​

JS​

参数说明​

字段类型是否必填备注
paramsIAd是参数
callbackIMethodParams是回调函数集合

IAd 说明

字段类型是否必填备注
funcstring否埋点标记，可在望舒社交分享-广告管理工具配置，同一埋点只能关联一种广告类型，如需关联多种广告类型请使用调度方式
adUnitIdstring否广告单元 id，若传则使用此id，若不传则取埋点对应配置广告单元id
multitonboolean否是否启用多例模式
destroyAdboolean否是否销毁当前广告（单例模式下销毁当前广告，相同广告位不能再次拉起）
isCheckboolean否是否仅检测能否拉取广告, 而不显示ture 表示仅检测能否拉取广告，返回结果包含激励广告实例
custom_extCustomExt否自定义透传参数

CustomExt 字段说明

字段类型是否必填备注
bigdata_extobject否大数据预置事件透传参数

IMethodParams 说明

字段备注
complete(data) => voidcomplete：为函数且必传，data 为结果数据
fail(err) => void非必传，err为拉取广告失败结果数据1、传入adUnitId为错误的广告位id，调用rewardedVideoAd拉取广告失败，会走入该回调2、若未传入adUnitId，且func埋点对应的广告管理配置广告位id为空或为错误的，调用rewardedVideoAd拉取广告失败，会走入此回调3、若未传入adUnitId，调用流程错误，如func埋点对应当前调度为share，使用rewardedVideoAd拉取广告位id为空，则拉取广告失败，会走入该回调4、还有其他场景，拉取广告失败，会走入该回调

调用示例

sdk.rewardedVideoAd(
  {
    func: 'test',
    adUnitId: "adunit-4de541945b96fxxx",
    multiton: true,
    destroyAd: true
  },
  {
    complete: (data) => {
      console.log(data);
    },
    fail: (err) => {
      console.log(err);
    },
  }
);

adUnitIdstring请求的参数，如果传了，原样返回，否则字段不存在
isCheckboolean请求的参数，如果传了，原样返回，否则字段不存在
