辱骂检测​

POST: /v1/smarts/abuse/check

认证方式： CPSign

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/smarts/abuse/check' \
--header 'x-robot-schemas: {{机器人}}' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{APPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{签名}}'

请求参数（JSON）​

字段类型是否必填说明示例
messageString是检测内容

响应参数（JSON）​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码， 0 为成功，非 0 表示出错0
msgString否响应信息，仅在 code 为非 0 时不为空data
Data否响应内容

Data​

字段类型是否必填说明示例
is_abusestring是是否辱骂

响应示例

{
 "code": 0,
 "data": {
 "is_abuse": true
 },
 "msg": "string"
}

会话关闭​

POST: /v1/smarts/session/close

认证方式： CPSign

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/smarts/session/close' \
--header 'x-robot-schemas: {{机器人}}' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{APPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{签名}}'

请求参数（JSON）​

字段类型是否必填说明
session_idString是会话 ID
human_reasonNumber否转人工原因
Number否转人工原因1 是点击转人工;2 是关键词转人工;3 是无答案;4 是负面情绪;5 是重复提问;6 无帮助转人工，注意 reason 为 2 时该值必填
reasonNumber是关闭原因
Number是关闭原因1 是会话结束关闭;2 是会话已转人工

响应参数（JSON）​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码， 0 为成功，非 0 表示出错0
msgString否响应信息，仅在 code 为非 0 时不为空

响应示例

{
 "code": 0,
 "msg": "string"
}
