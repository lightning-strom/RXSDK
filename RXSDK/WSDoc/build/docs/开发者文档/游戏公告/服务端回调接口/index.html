服务端回调接口

维护公告​

类型：同步

Action: versioncheck-maintain

认证方式： CPSign

请求参数 (JSON)​

字段类型是否必填说明
module_idNumber是唯一标识，公告 ID
is_delBool是为 true 时代表删除
datadata否is_del 为 true 时无此字段

data​

字段类型是否必填说明
typeNumber公告类型 1 版本更新公告 2 临时维护公告（版本检查下发） 3 常规公告timezone
Number公告生效时区startString
开始时间endString结束时间
contents[]content公告内容。 数组whitelist
String白名单 ip ，逗号分隔，包含的 ip 不下发公告relation[]relation
维度数组：公告关联
content​
字段类型是否必填说明
languageString是语言 zh en 等
titleString是标题
contentString是内容
relation​
字段类型是否必填说明
product_idString是产品 id ，值为空时为全部产品
channel_idString是渠道 id ，值为空时为全部渠道

💡 望舒后台产品内公告首先是待发布状态，到达开始时间后， 公告状态改为已发布，无法编辑删除，此时只能修改公告结束时间；示例：

{
 "module_id": 68,
    "is_del" : false,
 "data":
 {
        "maintain_id" : 68,
 "type": 1,
 "start": "2022-08-22 00:00:00",
 "end": "2022-08-22 00:00:00",
 "white_list":"",
        "contents" : [
         {
                "language" : "zh",
                "title": "标题",
                "content" : "中文内容"
 },
 {
 "language" : "en",
 "title": "tt",
 "content" : "hello world"
 }
        ],
        "relation":[
         {
         "product_id": "",
         "channel_id": ""
         }
        ]
 }
}

复核后，大于开始时间小于结束时间时，待发布状态自动变更为已发布状态，并同步 CP ；已发布的公告在修改、删除时同步给 CP ， 修改的公告 CP 方根据 module_id 同步修改；删除的公告 CP 需要根据 module_id 做同步删除。

已发布状态的公告可能会重新编辑，只会编辑公告内容、白名单、结束时间等内容， CP 方根据 module_id 做变更处理。

响应参数（JSON）​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码， 0 为成功，非 0 表示出错0
msgString否响应信息，仅在 code 非 0 时返回
