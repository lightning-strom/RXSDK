获取意见反馈类型​

接口原型

 public void GetFeedbackKindList(RequestResponseDelegate onResponse, RequestErrorDelegate onError);

调用示例

 public void OnGetFeedbackKindList()
 {
 RXFeedback.GetFeedbackKindList(FeedbackResponseDelegate, FeedbackErrorDelegate);
 }

响应结构

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码， 0 为成功，非 0 表示出错0
msgString否响应信息，仅在 code 非 0 时返回data
PageData否结果

PageData​

字段类型是否必填说明
pageNumber是第几页
sizeNumber是每页大小
totalNumber是总数量
list[]Kind是意见反馈数据

Kind​

字段类型是否必填说明
idNumber是唯一 ID
namestring是意见反馈类型
email_replyNumber是是否邮件回复
is_accidentNumber是是否产生事故
kind_descNumber是描述

创建意见反馈​

接口原型

 public void CreateFeedback(Dictionarystring, object> hashMap,
 RequestResponseDelegate onResponse, RequestErrorDelegate onError);

参数说明​

字段类型是否必填备注
game_idint是游戏 ID
kind_idint是意见反馈 ID
kind_namestring是意见反馈类型
priorityint是紧急程度 1:紧急 2:不紧急
contentstring是反馈内容
picturestring是图片 url
player_gameidstring是玩家游戏 id
send_voided_mailsint是作废是否发邮件 1:发 2:不发

调用示例

 public void OnCreateFeedback()
 {
 Dictionarystring, object> dic = new()
 {
 { "game_id", 100 },
 { "kind_id", 1 },
 { "kind_name", "意见反馈类型" },
 { "priority", 1 },
 { "content", "说明" },
 { "picture", "图片url" },
 { "player_gameid", "玩家游戏id" },
 { "send_voided_mails", 1 }
 };

 RXFeedback.CreateFeedback(dic, FeedbackResponseDelegate, FeedbackErrorDelegate);

 }

响应结构

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码， 0 为成功，非 0 表示出错0
msgString否响应信息，仅在 code 非 0 时返回
