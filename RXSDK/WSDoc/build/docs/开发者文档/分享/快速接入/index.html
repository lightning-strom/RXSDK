获取分享信息​

接口原型

/**
 * 获取分享信息 New
 * @param func 埋点标识 必须
 * @param platform 分享平台 wechat
 * @param region 地区码 非必须
 * @param transmits 透传参数，原样返回， 请使用key=value形式，并对值使用urlencode，返回时会原样返回 非必须
 * @param ext 扩展字段，拼接url用 非必须
 * @param readCache 是否读取缓存，YES 读取缓存 NO 不读取缓存，默认不取缓存
 */
- (void)getShareInfoWithFunc:(NSString *)func
 platform:(NSString *)platform
 region:(NSString *)region
 transmits:(NSString * _Nullable)transmits
 ext:(NSDictionary * _Nullable)ext
 readCache:(BOOL)readCache
 complete:(RequestComplete)complete;

setCustomExtNSDictionary否cp 自定义数据，目前仅用于大数据预置事件透传参数场景
useShortUrlBOOL否是否使用短链，默认 NO

分享调度​

当埋点配置了分享调度后，诱导类分享会根据分享调度策略决定用户是分享还是广告， 分享成功或者失败， 返回值中会增加 scheduling 对象，值如下：

scheduling_event 分享结果仅代表根据望舒后台设置的成功率计算的结果，不表示实际的分享结果。scheduling_event 是在拉起分享前的预算的结果，三方平台的分享机制不同，建议根据平台处理实际结果。

例如：微信 的机制是用户点击 关闭、取消 都算 分享成功，而 Facebook 有真实的回调，用户点击 关闭、取消 会返回 取消分享 结果。

获取分享调度Scheduling​

字段类型说明
scheduling_typeString值为 ad 时为广告， share 时为分享。
scheduling_signString调度策略当前可分享看广告总数密文, 需用 aes 解密，使用 cpkey 作为 key。
解出值转为字符串， 格式: "type=share&count=10&uuid=xxx&ts=1695796034&ddid=a" 详情scheduling_eventNumber
1 分享成功 -1 分享失败scheduling_failed_msgString
分享失败时的信息

拉起分享​

RXSDK_Pure只提供系统分享，其他分享方式参考三方服务。

一键分享的分享素材需要在望舒后台进行配置 查看使用说明。

接口原型

/**
 * 一键分享
 * @param config 分享配置
 */
- (void)share:(RXShareConfig *)config
 complete:(RequestComplete)complete;

/**
 * 自定义分享
 * @param config 分享配置
 */
- (void)shareCustom:(RXCustomShareConfig *)config
 complete:(RequestComplete)complete;

调用示例

/**
 * 一键分享
 */
RXShareConfig *config = [[RXShareConfig alloc] init];
config.func = @"望舒后台创建的埋点";
config.platform = @"wechat";
[[RXSDK sharedSDK] share:config complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
 if (!error) {
 NSLog(@"分享成功");
 } else {
 NSLog(@"分享失败");
 }
}];

/**
 * 自定义分享
 */
RXCustomShareConfig *config = [[RXCustomShareConfig alloc] init];
config.platform = @"wechat";
config.url = @"http://
config.title = @"title";
config.content = @"content";
config.materialType = @"link";
config.shareScene = 1;
config.thirdAppid = @"wx123123123"; // 微信 appid 为示例，需要根据分享平台传不同的 appid

[[RXSDK sharedSDK] shareCustom:config complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
 if (!error) {
 NSLog(@"分享成功");
 } else {
 NSLog(@"分享失败");
 }
}];

分享/广告结果上报​

如果在望舒后台开启了分享调度功能，在上报时需要将调用 获取分享信息 时的 func、platform、region、transmits 传入。

不使用分享调度只需传入 scheduling_event 即可， properties 按需传入，如果不需要上报自定义数据可传 nil

接口原型

/**

分享调度​

当埋点配置了分享调度后，诱导类分享会根据分享调度策略决定用户是分享还是广告， 分享成功或者失败， 返回值中会增加 scheduling 对象，值如下：

scheduling_event 分享结果仅代表根据望舒后台设置的成功率计算的结果，不表示实际的分享结果。scheduling_event 是在拉起分享前的预算的结果，三方平台的分享机制不同，建议根据平台处理实际结果。

例如：微信 的机制是用户点击 关闭、取消 都算 分享成功，而 Facebook 有真实的回调，用户点击 关闭、取消 会返回 取消分享 结果。

拉起分享​

接口原型

/**
    * 一键分享
    * @param activity activity
    * @param config 分享配置
    * @param callback
    */
void share(Activity activity, RXShareConfig config, RXRequestCallback callback);

/**
    * 自定义分享
    * @param activity activity
    * @param config 分享配置
    * @param callback
    */
void shareCustom(Activity activity, RXCustomShareConfig config, RXRequestCallback callback);

参数说明​

RXShareConfig 结构说明

字段类型是否必填说明
funcstring是埋点标识数组
regionstring否望舒地区码
platformstring是分享平台
transmitsstring否透传参数，原样返回， 请使用 key=value 形式，并使用 urlencode 编码，此数据在落地页中可以通过 key 获取到，示例： "a=b&c={\"d\":\"e\"}"
androidSchemestring是cp 方 android app scheme
iOSSchemestring是cp 方 启动 ios app scheme
useSchemestring否由 cp 控制是否使用游戏协议，如传 0 则在落地页上操作不会尝试打开应用，直接跳转到对应商店，如传 1 则会尝试打开应用
readCacheboolean否默认 false ，是否读取缓存，默认不读取
autoReportboolean否是否自动上报分享结果 YES 自动上报， NO 不自动上报，默认 YES
shareSceneint否分享场景，查看使用说明
useShortUrlboolean否是否使用短链接 YES 使用短链接， NO 不使用短链接，默认 NO

在 link 分享类型时使用短链接 SDK 会将最终的分享 url 替换为短链接

在 image 分享类型时使用短链接 SDK 会将原始的长链接转成短链接后生成二维码并拼接到图片中 properties

Map否使用自动分享上报时可以写入自定义数据，手动上报时该属性不生效
setCustomExtMap否
cp 自定义数据，目前仅用于大数据预置事件透传参数场景

RXCustomShareConfig 结构说明

字段类型是否必填说明
platformstring是支持 wechat、system、facebook、messenger、line、tiktok、zalo、snapchat
androidSchemestring是cp 方 android app scheme
iOSSchemestring是cp 方 启动 ios app scheme
useSchemestring否由 cp 控制是否使用游戏协议，如传 0 则在落地页上操作不会尝试打开应用，直接跳转到对应商店，如传 1 则会尝试打开应用
shareSceneint否分享场景，查看使用说明
thirdAppidstring是三方 appid ，根据所需的平台传
materialTypestring否分享类型，查看使用说明
imagestring否分享图片， url 或本地路径，图片分享必填
urlstring否分享链接，链接分享必填
titlestring否分享标题
contentstring否分享描述
xint否分享图片带二维码 x 坐标
yint否分享图片带二维码 y 坐标
widthint否分享图片带二维码 的 width
heightint否分享图片带二维码 的 height
setBorderSizeint否分享图片带二维码 的 白边框大小

platform​

字段备注
system系统分享，展示的分享平台取决于该平台在系统分享中是否支持当前的要分享的内容，没展示说明三方不支持
wechat微信平台 请参考 微信接入
facebookfacebook 平台 请参考 Facebook 接入
messengermessenger 平台，归属于 Facebook ，参考 Facebook 接入文档
lineline 平台 请参考 Line 接入
tiktoktiktok 平台 请参考 Tiktok 接入
zalozalo 平台 请参考 Zalo 接入
snapchatSnapchat 平台 请参考 Snapchat 接入

materialType 说明​

类型说明
text文本类型，支持平台 wechat/system/line
image图片类型，支持平台 wechat/system/facebook/messenger/tiktok/snapchat
landing/link落地页/链接 类型，支持平台 wechat/facebook/messenger/zalo/line
video视频类型，支持平台 tiktok/snapchat

shareScene 说明​

平台说明
facebook0 为弹框样式 1 为跳转到 fb app 分享，默认 1
wechat0 为好友 1 为朋友圈，默认 0
zalo0 为好友 1 为朋友圈，默认为用户自行选择分享

分享/广告结果上报​

如果在望舒后台开启了分享调度功能，在上报时需要将调用 获取分享信息 时的 func、platform、region、transmits 传入。

接口原型

void shareSchedulingReport(String func, String platform, String region, boolean scheduling_event, String scheduling_type, String transmits, @NonNull Map<String, Object> properties, RXJSONCallback callback)

参数说明​

字段类型是否必填备注
funcString是埋点标识
platformString是分享平台
regionString否地区码
transmitsString否透传参数，原样返回， 请使用 key=value 形式，并使用 urlencode 编码，此数据在落地页中可以通过 key 获取到
scheduling_eventBool是上报结果 true 成功 false 失败
scheduling_typeString是上报类型 ad 广告 share 分享
propertiesMap否自定义属性， 上报区服和角色需要在 game_info 中传入属性，具体使用方式参考下方 game_info 字段说明

properties 结构说明

字段类型是否必填备注
game_infoMap否大数据预置事件透传参数
custom_extMap否自定义透传参数

custom_ext 结构说明

字段类型是否必填备注
bigdata_extMap否大数据预置属性透传参数

game_info 字段说明

字段类型是否必填备注
cp_game_character_idstring否角色 id
cp_game_area_idstring否区服 id

    }

三方分享回调说明​

以下三方分享结果都是由三方机制控制，望舒只进行了回调包装，没有其他特殊处理。

平台成功失败取消
system非真实回调， 拉起分享后，取消、关闭、分享 都返回成功回调无失败回调无失败回调
wechat跳转到微信后点击 取消、关闭、分享 都返回成功回调无失败回调无取消回调
facebook真实回调真实回调真实回调
messenger无真实回调无真实回调无真实回调
line无成功回调无失败回调无取消回调

snapchat跳转到 snapchat 立刻返回成功回调，点击 关闭、分享 后无法返回 app ，需要用户手动返回无失败回调无取消回调

获取自动重定向短链接​

如果拼接后的分享链接过长，可使用此接口获取自动重定向短链接。

接口原型

void getShortUrl(@NonNull Map<String, Object> hashMap, RXRequestCallback callback)

参数说明​

字段类型是否必填备注
urlString是要生成短链接的 url
titleString否标题
contentString否描述
imageString否图片
extString否参数

调用示例

Map<String, Object> m = new HashMap<>();
m.put("url", "www.baidu.com");

// 可传入 title、content、image 对短链接添加 og 标签
// og 标签常用场景为三方平台通过链接中的 开放协议 解析展示的缩略图、标题、描述等，具体说明：https://cloud.tencent.com/developer/article/1820467

m.put("title", "getShortUrl 标题");
m.put("content", "getShortUrl 内容");
m.put("image", "https://rxfile-test.ruixuecloud.com/share/2024/07/06/1720252159611.png");
Map<String, Object> ext = new HashMap<>();
ext.put("exttest", "测试。。。");
m.put("ext", ext);
RXSDK.getInstance().getShortUrl(m, jsonCallback);

字段类型说明
codeNumber状态码 0 为成功
msgString失败时的错误信息
dataMap短链接地址， 当请求短链接时自动重定向到原地址
