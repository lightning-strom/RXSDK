获取分享/广告埋点信息​

接口原型

public void GetShareInfo(RXShareConfig shareConfig,
            RequestResponseDelegate onResponse, RequestErrorDelegate onError);

参数说明​

RXShareConfig

字段类型是否必填说明
funcstring是埋点标识数组
platformstring否枚举，支持 wechat ，facebook
regionstring否地区码。 望舒地区码列表
transmitsstring否透传参数，原样返回， 请使用 key=value 形式，并使用 urlencode 编码，此数据在落地页中可以通过 key 获取到
protocol_androidstring是cp 方 android app scheme
protocol_iosstring是cp 方 启动 ios app scheme
use_schemestring否由cp控制是否使用游戏协议，如传0则在落地页上操作不会尝试打开应用，直接跳转到对应商店，如传1则会尝试打开应用
readCachebool否是否读取缓存，默认不读取
auto_reportbool否是否自动上报

调用示例

public void OnGetShareInfo()
{
    RXShareConfig rxShareConfig = new RXShareConfig();
    rxShareConfig.func = "unity_test";
    rxShareConfig.platform = "wechat";
    rxShareConfig.read_cache = true;
    rxShareConfig.protocol_android = "android_protocal_test";
    rxShareConfig.protocol_ios = "ios_protocal_test";
    RXShare.GetShareInfo(rxShareConfig, GetShareInfoResponseDelegate, GetShareInfoErrorDelegate);
}

自定义数据分享​

接口原型

public void ShareCustom(RXCustomShareConfig shareConfig,
            RequestResponseDelegate onResponse, RequestErrorDelegate onError);

参数说明​

RXCustomShareConfig

字段类型是否必填说明
platformstring否分享平台
protocol_androidstring是cp 方 android app scheme
protocol_iosstring是cp 方 启动 ios app scheme
use_schemestring否由cp控制是否使用游戏协议，如传0则在落地页上操作不会尝试打开应用，直接跳转到对应商店，如传1则会尝试打开应用
thirdAppidstring否三方appid
materialTypestring是分享类型，text/image/landing/link/video
imagestring否url或本地路径
urlstring否分享链接
titlestring否分享标题
contentstring否分享描述
shareSceneint否0好友 1朋友圈
xint否二维码坐标x
yint否二维码坐标y
widthint否二维码坐标width
heightint否二维码坐标height

materialType 说明​

类型说明
text文本类型，支持平台 wechat/system/line
image图片类型，支持平台 wechat/system/facebook/messenger/tiktok/zalo/snapchat
landing/link落地页/链接 类型，支持平台 wechat/system/facebook/messenger/zalo/line
video视频类型，支持平台 tiktok/snapchat

调用示例

public void OnShareCustom()
{
    RXCustomShareConfig rxCustomShareConfig = new RXCustomShareConfig();
    rxCustomShareConfig.platform = "wechat";
    rxCustomShareConfig.appid = "wxd9cba83a0a1ef20d";
    rxCustomShareConfig.material_type = "text";
    rxCustomShareConfig.title = "分享标题";
    rxCustomShareConfig.content = "分享内容";
    rxCustomShareConfig.shareScene = 1;
        
    RXShare.ShareCustom(rxCustomShareConfig, GetShareInfoResponseDelegate, GetShareInfoErrorDelegate);

}
