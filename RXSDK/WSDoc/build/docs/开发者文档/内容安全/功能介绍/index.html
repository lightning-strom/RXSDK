功能介绍

功能介绍​

对于开放聊天、单聊来说，内容的审核和实时过滤是产品运营上的一个基本要求。望舒提供了敏感词过滤、图片审核功能（涉黄、暴恐涉政、广告、不良场景、二维码、logo 等图片）。

敏感词过滤​

望舒敏感词过滤：（免费）仅提供基础的敏感词过滤功能（精准匹配替换）。阿里敏感词过滤：（付费）能够识别内容变形变异情况下的违规风险。

小程序敏感词过滤：要求必须接入，腾讯会根据自己的词库过滤。

望舒敏感词过滤​

在望舒系统 企业管理后台 > 系统功能 > 屏蔽词库 页面配置敏感词。

支持批量创建。被命中的敏感词将会被替换为 * ，支持自定义替换敏感词内容。

阿里敏感词过滤​

采用动态策略和模型引擎，强化内容对抗性，能够识别更多内容变形变异情况下的违规风险。检测能力包含但不限于如下所示（详情请查看阿里文档）：

登录阿里云平台，选择内容安全 > 文本审核增强版 > 规则配置 中选择词库管理，维护需要的敏感词。

小游戏敏感词过滤（腾讯）（无需配置，自动实现）​

图片审核​

图片审核用于识别图像中是否有违反网络内容传播相关规定、影响平台内容秩序、影响用户体验的内容或元素。通过内容安全的图片审核，可以根据业务所处的行业场景规范或平台内容治理规则，基于阿里 API 返回的丰富的风险标签和置信分，将对有异议的图片内容进一步的审核（人工）或治理措施。

一般用于头像审核或图片公开使用的场景。

审核完成后将通过回调地址通知 CP 。在望舒系统 企业管理后台 > 商务管理 > 产品管理 > 回调参数配置 中，配置图片审核回调地址。
