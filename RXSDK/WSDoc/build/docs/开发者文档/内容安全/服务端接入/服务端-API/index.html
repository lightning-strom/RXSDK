服务端 API

文本检测（增强）​

**POST: ** /v1/risk/content/text/scan

认证方式: CPSign

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/risk/content/text/scan' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--header 'Content-Type: application/json' \
--data-raw '{
 "open_id": "xyz_S5HwLxeRIkTEMBuwh6oYwULM",
 "scene": "public_chat",
 "content": "文本内容"
}'

请求头 Header 参数

参数类型备注
ruixue-languageStringzh-CN
Content-TypeStringapplication/json
ruixue-cpidString内容提供商 CPID
ruixue-productidString产品 ID
ruixue-channelidString渠道 ID
ruixue-platformidString平台 platformid
ruixue-devicecodeString设备码
ruixue-cpsignStringCP 签名
ruixue-cptsStringCP 签名时间戳
ruixue-traceidStringTraceID

请求示例

{
 "open_id": "xyz_S5HwLxeRIkTEMBuwh6oYwULM",
 "scene": "public_chat",
 "content": "文本内容",
 "data_id":"rxuRKdm68wYPAV3DJv0t4mC-XtEjJZoxpeNlkQ4M"
 }

请求参数（JSON）​

参数类型是否必填备注
open_idString否微信小程序 openid
sceneString是场景 nick_name: 昵称（对应微信小游戏的场景值 1.资料）； private_chat: 私聊（对应微信小游戏的场景值 1.资料）； public_chat: 公聊评论（对应微信小游戏的场景值 5.聊天）
contentString是文本内容
data_idString否唯一标识， 最好是望舒 OpenID

响应示例

{
 "data": {
 "suggestion": "pass",
 "words": ["abc"],
 "content": "**x**"
 },
 "msg": "success",
 "code": 0
}

响应结构(JSON)​

参数类型备注
codeNumber0 为成功
msgString失败信息
data[]Data

文本检测增强data​

参数类型说明
suggestionString审核结果 pass: 通过； risky: 风险
words[]String敏感词
contentString替换后的文本内容

ruixue-platformidString平台 platformid

 ]
 },

}

参数类型备注
codeNumber0 为成功，返回 152920 时为三方接口限流
msgString失败信息
data[]Data

图片检测增强data​

参数类型说明

urlString图片地址

参数类型说明

实名检测​

**POST: ** /v1/risk/auth_check

认证方式: CPSign

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/risk/auth_check' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--header 'Content-Type: application/json' \
--data-raw '{
 "cpid":{{CPID}},
 "product_id":"1002",
 "id_card": "220122199901011234",
 "real_name": "姓名"
}'

请求头 Header 参数

参数类型备注
ruixue-languageStringzh-CN
Content-TypeStringapplication/json
ruixue-cpidString内容提供商 CPID
ruixue-productidString产品 ID
ruixue-channelidString渠道 ID
ruixue-platformidString平台 platformid
ruixue-devicecodeString设备码
ruixue-cpsignStringCP 签名
ruixue-cptsStringCP 签名时间戳
ruixue-traceidStringTraceID

请求示例

{
 "cpid":1000000,
 "product_id":"1002",
 "id_card": "220122199901011234",
 "real_name": "姓名"
}

请求参数（JSON）​

参数类型是否必填备注
cpidNumber是CPID
product_idString是产品 ID
id_cardString是身份证
real_nameString是真实姓名

响应示例

{
 "data": {

 "verified":1
 },
 "msg": "success",
 "code": 0
}

参数类型备注

msgString失败信息
dataData

参数类型说明
