版本：v3.5

快速接入

SDK 集成​

implementation 'com.ruixue:rxsdk_upay:${version}'

接口原型​

/**
 * 支付
 * @param activity 应用上下文对象
 * @param hashMap  PayParams 参数，参照参数说明
 * @param callback 回调函数
 */
void pay(Activity activity, @NonNull Map map, RXJSONCallback callback)

参数说明​

Map 结构说明

字段类型是否必填说明
hq_typestring否支付类型
goods_tagstring是望舒计费点标识
trade_nostring是商户订单号
transmit_argsstring否透传参数
notify_urlstring否支付成功通知 CP 发货地址
currencystring是币种 全大写 国内传: CNY，参考 国家编码 币种字典
extobject否支付下单扩展信息，不同渠道具体对接
indulge_authint否默认(自运营渠道默认值 1 ,三方渠道默认值 0 )， 是否进行防沉迷验证 ，0 不验证、1 验证。
ageint否默认取登录返回 age 字段
game_infoobject否游戏自定义数据， 上报区服和角色需要在 game_info 中传入属性，具体使用方式参考下方 game_info 字段说明
bigdata_reportHashMap否商业化支付参数， 通过商业化触发的支付行为要传以下参数，否则数据统计会有丢失，具体使用方式参考下方 bigdata_report 字段说明
custom_extMap否自定义透传参数

custom_ext 结构说明

字段类型是否必填备注
bigdata_extMap否大数据预置事件透传参数

bigdata_report 字段说明

字段类型是否必填备注
scene_identifierstring否场景标识
scene_namestring否场景名称
trigger_button_identifierstring否触发按钮标识
trigger_button_namestring否触发按钮名称
window_identifierstring否窗口标识
window_namestring否窗口名称
window_sequencestring否窗口展示顺序
gift_packageHashMap否礼包

gift_package 字段说明

字段类型是否必填备注
identifierstring否礼包标识
namestring否礼包名称
purchase_mediumstring否购买礼包介质
priceint否礼包价格
billing_pointstring否礼包计费点

game_info 字段说明

字段类型是否必填备注
cp_game_character_idstring否角色 id
cp_game_area_idstring否区服 id

hq_type值 说明

hq_type值备注
upay优贝支付
