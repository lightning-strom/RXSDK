隐私声明

SDK 隐私声明 SDK 合规使用指南 使用方根据自己的使用情况结合上面文档做必要的处理。

华为后台获取参数

  1. 登录 AppGallery Connect，位置：AppGallery Connect > 项目设置。获取应用下的APP ID,项目下的Client ID,Client Secret,API密钥（凭据）。

SDK 集成

implementation 'com.ruixue:rxsdk_huawei_moment:${version}'

动态申请权限(只有发布功能需要此权限)

在需要发布动态前，需要动态申请权限，否则可能导致发布不成功。参考代码

  • 在游戏页面，初始化该 SDK 之前，调用如下代码申请权限
// REQUEST_PERMISSION 这个变量定义为页面全局变量即可。
if (ContextCompat.checkSelfPermission(this, Manifest.permission.WRITE_EXTERNAL_STORAGE) != PackageManager.PERMISSION_GRANTED) {
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.M) {
        requestPermissions(new String[]{Manifest.permission.WRITE_EXTERNAL_STORAGE}, REQUEST_PERMISSION);
    } else {
        Toast.makeText(this, "缺少文件读写权限，可能会导致社区发布功能无法使用", Toast.LENGTH_SHORT).show();
    }
}
  • 在游戏界面，覆写如下方法
@Override
    public void onRequestPermissionsResult(int requestCode, @NonNull String[] permissions, @NonNull int[] grantResults) {
    super.onRequestPermissionsResult(requestCode, permissions, grantResults);
    if (requestCode == REQUEST_PERMISSION) {
        RXLogger.d("rxsdk", "grant results " + Arrays.toString(grantResults));
        // 游戏根据权限是否赋予，处理逻辑，如果用户未赋予权限，则高光时刻功能不能使用。
    }
}

初始化

  • API 定义
/**
 * 初始化
 * 
 * @param context 上下文，一般为 activity
 * @param params 初始化参数
 * @param callback 回调
 */
public void init(Context context, Map params, RXJSONCallback callback)
  • params Map 结构说明
字段类型是否必填说明
appIdString是应用APP ID
clientIdString是游戏应用在AGC项目中的客户端ID
clientSecretString是游戏应用在AGC项目中的客户端密钥
cpAccessTokenString否开发者AGC认证凭证 ，clientSecret和cpAccessToken二者传其一即可
orientationint否内嵌社区的打开方向，此处以竖屏方向为例，默认值为 ActivityInfo.SCREEN_ORIENTATION_LANDSCAPE， 还可以设置 SCREEN_ORIENTATION_PORTRAIT
  • 示例代码
Map params = new HashMap<>();
params.put("appId", "应用APP ID ");
params.put("clientId", "游戏应用在AGC项目中的客户端ID");
params.put("clientSecret", "游戏应用在AGC项目中的客户端密钥");
// params.put("cpAccessToken", "xxx");
params.put("orientation", ActivityInfo.SCREEN_ORIENTATION_PORTRAIT);
HuaweiMomentHelper.getInstance().init(this, params, new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject data) {
        // 初始化成功
    }

    @Override
    public void onFailed(@NonNull JSONObject cause) {
        // 初始化失败
    }
});

未成年检查

  • API 定义
/**
 * 未成年检查
 * 
 * @param callback 回调
 */
public void checkAdult(RXJSONCallback callback)
  • 示例代码
HuaweiMomentHelper.getInstance().checkAdult(new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject data) {
        if (data != null) {
            int adult = data.optInt("adult");
            if (adult == 0) {
                // 未成年
            } else if (adult == 1) {
                // 已成年
            } else {
                // 当前用户未完成实名认证
            }
        }
    }

    @Override
    public void onFailed(@NonNull JSONObject cause) {
        ToastUtils.showToast(HuaweiMomentDemoActivity.this, "check adult failed " + cause);
    }
});

一键发布

  • 使用说明
    • 如果从望舒后台获取，前提需要在后台配置分享埋点
    • 望舒配置说明
  • API 定义
/**
 * 一键发布
 *
 * @param context     上下文，一般为 activity
 * @param shareReqMap 如果该参数为 null，则直接调起发布页，不带任何参数，如果非空则会从望舒SDK获取分享参数
 * @param callback    回调
 */
public void publish(Context context, Map shareReqMap, RXJSONCallback callback)
  • shareReqMap 结构说明
字段类型是否必填说明
funcString是埋点标识数组
regionString否望舒地区码
protocol_androidString是cp 方 android app scheme
protocol_iosString是cp 方 启动 ios app scheme
auto_reportboolean否是否自动上报分享结果 true 自动上报，false 不自动上报，默认 true
  • 示例代码
Map shareReqMap = new HashMap<>();
shareReqMap.put("func", "111");//分享埋点
shareReqMap.put("platform", "system");//分享平台
shareReqMap.put("protocol_android", "jixiang433://");//android 客户端scheme
shareReqMap.put("protocol_ios", "jixiang433://");//iOS 客户端scheme
shareReqMap.put("auto_report", false);
HuaweiMomentHelper.getInstance().publish(this, shareReqMap, new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject data) {
        ToastUtils.showToast(HuaweiMomentDemoActivity.this, "调起发布界面");
    }

    @Override
    public void onFailed(@NonNull JSONObject cause) {
        ToastUtils.showToast(HuaweiMomentDemoActivity.this, "publish failed " + cause);
    }
});

/**
 * 一键发布（自定义）
 *
 * @param images String[] 本地图片路径数组， 如果images 为空并且 content 为空字符，则会调起发送动态界面，不携带任何内容
 * @param content 发表的动态内容
 * @param callback 回调
 */
public void publish(String[] images, String content, RXJSONCallback callback)
  • 示例代码
String[] imagePaths = new String[] {
        "/storage/emulated/0/Android/data/test/files/test1.jpg", // app 本地能否访问的绝对路径
        "/storage/emulated/0/Android/data/test/files/test2.jpg",
        "/storage/emulated/0/Android/data/test/files/test3.jpg"
};
String content = "默认想要携带的内容";
HuaweiMomentHelper.getInstance().publish(imagePaths, content, new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject data) {
        ToastUtils.showToast(HuaweiMomentDemoActivity.this, "调起发布界面");
    }

    @Override
    public void onFailed(@NonNull JSONObject cause) {
        ToastUtils.showToast(HuaweiMomentDemoActivity.this, "publish failed " + cause);
    }
});
