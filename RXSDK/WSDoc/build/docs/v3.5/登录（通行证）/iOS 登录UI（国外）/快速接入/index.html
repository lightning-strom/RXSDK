快速接入

准备工作​

SDK 集成​

接入请前先做好准备工作。 可通过 pod 方式接入通行证 UIKit 组件，并使用通行证 UIKit 相关功能。 在需要使用功能的类中引用头文件#import

  • 编辑 Podfile 文件，添加如下配置：
pod 'RXOSUIKit'

初始化​

注意

在 SDK 初始化方法 之前调用。

接口原型

/**
 * 初始化
 */
- (void)regist;

调用示例

[[RXOSUIKitService sharedSDK] regist];

登录​

提示

"非法注册（限制代码1）" code : 312232 为 注册ip限制，默认开启，同一ip默认1小时注册账号不能超过2个，如有需求请联系商务添加ip白名单或调整限制条件。 "非法注册（限制代码2）" code : 312232 为 注册设备限制，默认关闭，同一设备x小时注册账号不能超过x个，如有需求请联系商务开启。

登录弹窗​

::: tip 设置为登录后强制实名认证时登录成功的数据将在实名认证后返回，并且不会返回实名认证的结果，只会在 UI 上体现实名认证成功。 如需要获取实名认证回调数据，请关闭登录后强制实名认证设置，并单独调用实名认证 UI。 :::

Logo参考设计稿： 微乐通行证ai 微乐通行证psd

UI示例

接口原型

/**
 * 调用登录弹窗
 * @param config 登录页基础配置，默认读取后台配置，优先读取代码配置
 * @param complete 登录结果
 */
- (void)setLoginViewWithConfig:(RXOSUILoginConfig *)config
                      complete:(void(^)(NSDictionary *response, RX_CommonRequestError *error))complete;

参数说明​

RXOSUILoginConfig 结构说明

字段类型是否必填备注
loginTypesNSArray否登录方式，默认读取望舒后台配置，没配置则需要手动传入
privaciesNSArray否协议地址，顺序 0 为用户协议，1 为隐私协议。默认读取望舒后台配置，没配置则需要手动传入
privacieTitlesNSArray否协议显示名称，顺序为 0 为用户协议，1 为隐私协议。默认读取望舒后台配置，没配置则需要手动传入
logoImageUIImage否登录显示的 logo，不配置显示默认logo。 Logo参考设计稿：微乐通行证ai微乐通行证psd
keyboardTypeNSInteger否账号密码登录方式键盘类型。1 全键盘 2 数字键盘 3 邮箱键盘 默认全键盘。
isHistoryViewEnableBOOL否是否展示登录历史弹窗，YES 展示，NO 不展示，默认 YES。 注：SDK 会记录已登录的账号记录，下次调用会展示登录历史弹窗
needRealAuthBOOL否未实名用户登录成功后是否需要强制实名认证，默认强制。 注：强制实名后登录数据将在实名认证成功后返回。
canCloseRealAuthBOOL否实名认证是否可关闭，默认不可关闭。
realAuthRegionBOOL否海外根据不同地区展示不同样式的实名认证 UI，默认 姓名+身份证样式，目前支持 VN（越南地区样式）。
setFirstNeedSetPasswordBOOL否验证码登录的新用户是否弹出设置密码，默认不弹出。注：弹出设置密码后登录数据将在设置成功或关闭设置页面后返回。
setQuickButtonBarVisibleBOOL否是否显示底部快速登录按钮，默认显示。
setDeregisterShowBOOL否处于注销中的用户登录后是否显示注销窗口，默认不显示
setLoginContinueBOOL否如果账号在注销中是继续登录还是退出登录, YES 继续登录，NO 退出登录，默认 NO
setCustomParamsNSDictionary否自定义参数
permissionsArrayNSArray否FaceBook、Line登录权限数组
setShowPrivacyBOOL否设置隐私协议是否显示开关，YES 显示 NO 不显示，默认 YES
isAuditBOOL否是否为审核模式，审核模式只展示苹果登录，且和正常样式不同，YES 开启 NO 关闭，默认 NO
setCustomExtNSDictionary否自定义透传参数

登录回调​

登录结果通过 delegate 或 block 方式进行回调，两种方式数据结构一致，推荐使用 block 方式。

注意

注意：指定了 delegate 必须要实现，否则会引起闪退问题，不指定则不用实现。

delegate 方式实现如下： 在需要接收回调的类中添加代理，并指定接受者实现代理方法。

``

 */

    }

忘记密码​

UI示例

接口原型

==使用扩展方式请注意，requestParams 为 retrun block，params 会将手机号或邮箱，密码等参数返回，由客户端处理业务逻辑，SDK会根据 return 的 needBreak 参数决定是否继续执行。 详情请参考调用示例。==


/**
 * 忘记密码
 */
- (void)getBackPasswordWithComplete:(void(^)(NSDictionary *response, RX_CommonRequestError *error))complete;

/**
 * 忘记密码 扩展方式
 * @param params 页面配置信息
 * ！username 默认填充的账号    #NSString类型
 * ！account_type  账号类型提示 （1-通用提示 ，2-手机号提示，3-邮箱提示 [可选 默认 2]）    #NSInteger类型
 * ！password_hint 输入密码提示文本    #NSString类型
 * @param requestParams 回调函数
 * ！params 会将手机号或邮箱，密码等参数返回，由客户端处理业务逻辑，SDK会根据 return 的 needBreak 参数决定是否继续执行
 * 详情请参考文档示例
 */
- (void)getBackPasswordWithParams:(NSDictionary *)params
                    requestParams:(NSMutableDictionary *(^)(NSMutableDictionary *params))requestParams
                         complete:(void(^)(NSDictionary *response, RX_CommonRequestError *error))complete;

参数说明​

params 结构说明

字段类型是否必填备注
usernameNSString否默认填充的账号。
account_typeint否账号类型提示 （1-通用提示 ，2-手机号提示，3-邮箱提示 [默认 2]）。
password_hintNSString否输入密码提示文本。海外需要自行处理国际化。

调用示例

[[RXOSUIKitService sharedSDK] getBackPasswordWithComplete:^(NSDictionary * _Nonnull response, RX_CommonRequestError * _Nonnull error) {
    if (!error) {
        NSLog(@"%@",response);
    }else{
        NSLog(@"%@",error.responesObject);
    }
}];

// 扩展方式
NSDictionary *dic = @{@"username" : @"",
                      @"account_type" : @(1),
                      @"password_hint" : @"请输入密码"};
[[RXOSUIKitService sharedSDK] getBackPasswordWithParams:dic requestParams:^NSMutableDictionary * _Nonnull(NSMutableDictionary * _Nonnull params) {
    NSLog(@"params = %@", params);
    NSMutableDictionary *dic = [NSMutableDictionary dictionaryWithDictionary:params];
    // 会将手机号或邮箱，密码等参数返回，由客户端处理业务逻辑，SDK会根据 return 的 needBreak 参数决定是否继续执行
    // needBreak = YES 为 不继续执行 
    // needBreak = NO或不传 为 继续执行
    // [dic setValue:@YES forKey:@"needBreak"];
    return dic;
} complete:^(NSDictionary * _Nonnull response, RX_CommonRequestError * _Nonnull error) {
    if (!error) {
        NSLog(@"%@",response);
    }else{
        NSLog(@"%@",error.responesObject);
    }
}];

[[RXOSUIKitService sharedSDK] closeUserCenter];

UI示例

接口原型

/**
 * 申请注销
 */
- (void)applyForDeregisterWithConfig:(RXUserCenterConfig *)config
                            complete:(void(^)(NSDictionary *response))complete;

参数说明​

RXUserCenterConfig 结构说明

字段备注
transmit_args透传数据，使用 jsonString 形式
game_user_id用户的游戏 id，不传在望舒后台不会账号注销页面不显示游戏侧的用户id
nickname用户昵称
head_img_url用户头像
queue_name在望舒客服系统设置的接入点名称 不填写默认为 default

    if (!error) {
        NSLog(@"%@",response);
    }else{
        NSLog(@"%@",error.responesObject);
    }
}];
