自定义望舒API请求​

接口原型

/**
 * @param options - 请求配置对象
 * @param options.method - HTTP请求方法，支持标准方法或自定义枚举值
 * @param options.path - 请求路径（相对路径或绝对URL）
 * @param [options.data] - 请求数据，可为字符串或对象（对象会自动JSON序列化）
 * @param [options.headers] - 请求头对象，可自定义任何HTTP头信息
 * 
 * @param [callback] - 可选的回调函数，支持传统回调模式（与Promise并存）
 * 
 * @returns 返回一个Promise，解析为统一的响应结果对象
 *          包含状态码、数据、错误信息等标准字段
 */
request(options: RequestOptions, callback?: RCallback): Promise>

调用示例


 RXRequest.request({
      path: 'https://rxfile-test.ruixueyun.com/sdk' ,
      method: 'GET',
      headers: {
        '自定义 key': '自定义 value'
      },
       body:  请求数据 object 或 string
    }) .then((resp: RXResult) => {
      this.showText(resp)
    }).catch((e: BusinessError) => {
      this.showText(e)
    })

Device

字段类型是否必填说明示例
idfaString否仅用于 iOS 设备。目前 iOS 系统主流的广告获取设备标识符方式。用户可开启、关闭，每次切换会改变为新的取值。10 以下的版本关闭时也能取到唯一值, >=10 的 iOS 版本关闭时取到的值为 00000000000 ；系统大版本升级（如 11 到 12） IDFA 也会发生变化。
android_idString否仅用于 Android 设备。Android 版本 = 8.0，应用签名、用户（即系统上的用户账号）和设备的每个组合都具有唯一的 ANDROID_ID 值，即使系统升级也不变。
imeiString否仅用于 Android 设备。Android 版本 < 6.0，只需要 READ_PHONE_STATE 静态权限（安装 App 时即可获取到该权限），即可通过系统 API TelephonyManager#getDeviceId API 获取准确值；6.0 <= Android 版本 <= 9.0，READ_PHONE_STATE 升级为动态权限，安装 App 时不会获得该权限，需要在 App 运行时用户在弹窗确认授权后才可以获取；Android 版本 >= 10.0，设备不可变 ID 的隐私保护得到进一步升级，需要 READ_PRIVILEGED_PHONE_STATE 权限才可以获取 IMEI，而该权限只有系统级别的应用才可以获得，因此一般 App 无法获取到 IMEI。
oaidString否仅用于 Android 设备。移动安全联盟（简称 MSA）制定的匿名设备标识符。可用于 android 系统的补充设备标示，通常 android10 以上的国内主流设备都可以获取。具体 OAID 介绍以及最新覆盖厂商范围请详见 MSA 官网：http://msa-alliance.cn。
macString否仅用于 Android 设备。设备 Mac 地址。
user_agentString否一种方式获取的 user_agent，若为空，则取 user-agent header 的值
user_agent1String否其他方式获取的 user_agent
user_agent2String否其他方式获取的 user_agent
ipv4String否客户端检测到的自身外网 IPv4 地址，如果客户端调用本激活接口时是使用 IPv4，则激活接口服务端自动检测客户端的 IPv4 地址用于归因，否则使用此字段传的值。
ipv6String否客户端检测到的自身外网 IPv6 地址，如果客户端调用本激活接口时是使用 IPv6，则激活接口服务端自动检测客户端的 IPv6 地址用于归因，否则使用此字段传的值。

登录​

接口原型

/**
 * 用户登录接口，支持多种登录方式（密码、第三方、验证码等）
 * 
 * @param params - 登录请求参数
 * @param params.method - 登录方式（可选），默认使用密码登录
 * @param params.username - 用户名（密码登录时必填）
 * @param params.password - 密码（密码登录时必填）
 * @param params.login_openid - 第三方登录授权码（如微信、QQ登录）
 * @param params.user_attrs - 用户扩展属性（JSON字符串格式）
 * @param params.sign_fields - 需要签名的字段列表（用于安全验证）
 * @param params.migrate_args - 账号迁移参数（如旧系统迁移）
 * @param params.user_transmits - 用户透传数据（会原样返回给客户端）
 * @param params.device - 设备信息（如设备ID、型号、系统版本等）
 * @param params.distinct_id - 客户端唯一标识（首次登录时生成并传递）
 * @param params.ext - 扩展参数（如验证码信息、额外安全校验参数）
 * 
 * @param callback - 可选的回调函数，用于接收登录结果
 * 
 * @returns 返回Promise，解析为包含登录数据的统一响应结构
 */
login(params: LoginParams, callback?: RXCallback>): Promise>

参数说明​

字段类型是否必填说明
methodstring否登录方式 （默认 harmony）
login_openidstring否上次登录返回的 login_openid 数据，同时 method 也要使用上次登录获取 login_openid 时使用的登录方式
user_attrsobject否设置大数据用户属性，仅对本次登录新注册的用户有效
sign_fields[]string否指定对登录成功后返回的特定字段, 使用 CPKEY 计算签名. CP 服务器可重新计算签名并与登录返回的签名比对, 作为对望舒登录数据的校验. 支持的字段包括: nickname, avatar, openid, region, sex, age, 计算签名的逻辑会对指定字段进行排序, 此处传参与顺序无关.
migrate_args任意合法的 json 类型, 比如 string, number, array, object否账号迁移用的参数, 调用 CP account-query 及 account-queryandbind 接口时透传给 CP.

调用示例

 RXApi.getInstance().login({ method:"username", username: 'test', password: '123456' })
    .then(res => console.log('登录成功', res.data.token))

鸿蒙UnionLogin登录​

接口原型

 /**
 * 发起联合登录流程，支持多平台统一认证与授权
 * 
 * @template T - 响应数据的泛型类型，默认为 LoginData
 * 
 * @param params - 登录配置参数
 * @param params.accountInfos - 预填充的账号信息列表（用于自动填充或快速切换）
 * @param params.showLoginDialog - 是否显示内置登录对话框（true: 显示，false: 静默登录）
 * @param params.loginPanelType - 登录面板样式类型（0: 标准，1: 简化，2: 高级）
 * @param params.scopes - 请求的用户权限范围（如 ['user_info', 'phone_number']）
 * @param params.permissions - 请求的系统权限列表（如 ['camera', 'storage']）
 * @param params.forceAuthorization - 是否强制重新授权（忽略已授权状态）
 * @param params.fromUnionLogin - 是否标记为联合登录来源
 * @param params.ext - 扩展配置参数（用于特定业务场景）
 * @param params.loginMethods - 支持的登录方式列表（如 [{ method: 'wechat' }]）
 * @param params.indulgeAuth - 是否开启实名认证（1: 开启，0: 关闭）
 * @param params.firstNeedSetPassword - 首次登录是否需要设置密码
 * @param params.quickLoginEnable - 是否启用快捷登录（如一键登录）
 * @param params.isDeregisterShow - 是否显示注销账号选项
 * @param params.privacyEnable - 是否启用隐私协议功能
 * @param params.privacyText1 - 隐私协议第一行文本
 * @param params.privacyText2 - 隐私协议第二行文本
 * @param params.privacyText3 - 隐私协议第三行文本
 * @param params.privacyUrl1 - 第一个隐私协议链接
 * @param params.privacyUrl2 - 第二个隐私协议链接
 * @param params.privacyUrl3 - 第三个隐私协议链接
 * @param params.logoResource - 登录界面Logo资源（图片URL或组件）
 * 
 * @param uiContext - 登录界面上下文对象，用于控制UI显示逻辑
 *                    （如自定义登录页面、加载状态管理等）
 * 
 * @param callback - 可选的回调函数，用于接收登录结果
 *                   （支持传统回调模式与Promise模式并存）
 * 
 * @returns 返回Promise，解析为统一的响应结果对象
 *          包含状态码、数据、错误信息等标准字段
 */
unionLogin(params: RXLoginConfig, uiContext: UIContext, callback?: RXCallback>): Promise>

参数说明​

RXLoginConfig 主要字段

字段类型是否必填说明
showLoginDialogbool否是否强制弹出联合登录对话框，允许玩家选择重新登录，默认true
indulgeAuthnumber否1 开启实名认证， 0 关闭 未实名用户登录成功后是否需要强制实名认证，默认读取望舒后台配置。 注：强制实名后登录数据将在实名认证成功后返回。
canCloseRealAuthbool否实名认证是否可关闭，默认读取望舒后台配置
accountInfosobject否可在union login 添加一个游戏官方账号类型
privacyText1string否第一个协议文本，默认用户协议
privacyUrl1string否第er个协议文本的链接，默认用户协议链接
privacyText2string否第二个协议文本，默认隐私政策
privacyUrl2string否第二个协议文本的链接，默认隐私政策链接
privacyText3string否第三个协议文本，默认空
privacyUrl4string否第三个协议文本的链接，默认空
loginMethodsList>否显示在望舒ui 中的其他登录方式，默认读取后台配置
extDictionary\否cp 自定义扩展参数
