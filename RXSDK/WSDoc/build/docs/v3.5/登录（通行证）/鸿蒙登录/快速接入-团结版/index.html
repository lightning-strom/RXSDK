注册​

接口原型

void Register(RegisterArgs args, Action callback)

参数说明

字段类型是否必填说明
usernamestring是用户名
passwordstring是密码
nicknamestring否昵称
captcha_codestring否使用 sendCaptcha 接口获取
avatarUrlstring否头像地址
user_attrsobject否设置大数据用户属性，仅对本次登录新注册的用户有效
sexinteger否性别,1:男,0:女
migrate_args任意合法的 json 类型, 比如 string, number, array, object否账号迁移用的参数, 调用 CP account-query 及 account-queryandbind 接口时透传给 CP.

调用示例

    RegisterArgs registerArgs = new()
    {
        type = AccountType.Phone,//手机号类型
        username = usernameFiled.text,// 用户名
        password = passwordFiled.text,//密码
    };

    RuiXueSdk.Register(registerArgs, (code, data, msg) =>
    {
        if (data != null)
        {
            Debug.Log("data= " + data);
            mText.text = data.Tostring();
        }
        else
        {
            Debug.Log("code:" + code + ", msg:" + msg);
            mText.text = "code:" + code + ", msg:" + msg;
        }
    });

字段类型是否必填说明示例

distinct_idString是客户端随机生成的 ID，在用户注册前作为这个用户的唯一标识。
usernameString是用户名，可以是手机号，邮箱地址，或者任意其他形式的用户名。
passwordString否密码，客户端传的密码，可以是用户输入的密码本身，或者将其经过特定步骤转化的结构。为保护用户隐私，建议将用户输入的密码原文进行 hash 运算后作为 password 参数的值。该值将作为登录接口 password 参数的值。
nicknameString否昵称。
avatarUrlString否头像地址。
deviceDevice是客户端设备信息。具体结构参考下文 device 结构说明。

Device

字段类型是否必填说明示例
idfaString否仅用于 iOS 设备。目前 iOS 系统主流的广告获取设备标识符方式。用户可开启、关闭，每次切换会改变为新的取值。10 以下的版本关闭时也能取到唯一值, >=10 的 iOS 版本关闭时取到的值为 00000000000 ；系统大版本升级（如 11 到 12） IDFA 也会发生变化。
android_idString否仅用于 Android 设备。Android 版本 = 8.0，应用签名、用户（即系统上的用户账号）和设备的每个组合都具有唯一的 ANDROID_ID 值，即使系统升级也不变。
imeiString否仅用于 Android 设备。Android 版本 < 6.0，只需要 READ_PHONE_STATE 静态权限（安装 App 时即可获取到该权限），即可通过系统 API TelephonyManager#getDeviceId API 获取准确值；6.0 <= Android 版本 <= 9.0，READ_PHONE_STATE 升级为动态权限，安装 App 时不会获得该权限，需要在 App 运行时用户在弹窗确认授权后才可以获取；Android 版本 >= 10.0，设备不可变 ID 的隐私保护得到进一步升级，需要 READ_PRIVILEGED_PHONE_STATE 权限才可以获取 IMEI，而该权限只有系统级别的应用才可以获得，因此一般 App 无法获取到 IMEI。
oaidString否仅用于 Android 设备。移动安全联盟（简称 MSA）制定的匿名设备标识符。可用于 android 系统的补充设备标示，通常 android10 以上的国内主流设备都可以获取。具体 OAID 介绍以及最新覆盖厂商范围请详见 MSA 官网：http://msa-alliance.cn。
macString否仅用于 Android 设备。设备 Mac 地址。
user_agentString否一种方式获取的 user_agent，若为空，则取 user-agent header 的值
user_agent1String否其他方式获取的 user_agent
user_agent2String否其他方式获取的 user_agent
ipv4String否客户端检测到的自身外网 IPv4 地址，如果客户端调用本激活接口时是使用 IPv4，则激活接口服务端自动检测客户端的 IPv4 地址用于归因，否则使用此字段传的值。
ipv6String否客户端检测到的自身外网 IPv6 地址，如果客户端调用本激活接口时是使用 IPv6，则激活接口服务端自动检测客户端的 IPv6 地址用于归因，否则使用此字段传的值。

登录​

接口原型

/// <summary>
/// 登录
/// </summary>
/// 登录方式
/// 登录参数
/// 回调
void Login(LoginMethod method, Dictionary keyValuePairs, Action callback)

参数说明​

字段类型是否必填说明
methodstring否登录方式 （默认 harmony）
login_openidstring否上次登录返回的 login_openid 数据，同时 method 也要使用上次登录获取 login_openid 时使用的登录方式
user_attrsobject否设置大数据用户属性，仅对本次登录新注册的用户有效
sign_fields[]string否指定对登录成功后返回的特定字段, 使用 CPKEY 计算签名. CP 服务器可重新计算签名并与登录返回的签名比对, 作为对望舒登录数据的校验. 支持的字段包括: nickname, avatar, openid, region, sex, age, 计算签名的逻辑会对指定字段进行排序, 此处传参与顺序无关.
migrate_args任意合法的 json 类型, 比如 string, number, array, object否账号迁移用的参数, 调用 CP account-query 及 account-queryandbind 接口时透传给 CP.

调用示例

string method="hwjos";
Dictionary parm = new()
{
    {"sign_fields",new string[]{"openid"}}
};
RuiXueSdk.Login(method, parm, (code, data, msg) =>
{
    if (data != null)
    {
        Debug.Log("data= " + data.ToJson());
        mText.text = data.ToJson();
    }
    else
    {
        Debug.Log("code:" + code + ", msg:" + msg);
        mText.text = "code:" + code + ", msg:" + msg;
    }
});

鸿蒙UnionLogin登录​

接口原型

/// <summary>
///  鸿蒙union登录
/// </summary>
/// 登录参数
/// 
public static void UnionLogin(UnionLoginArgs unionLoginArgs, Action callback)

参数说明​

UnionLoginArgs 主要字段

字段类型是否必填说明
showLoginDialogbool否是否强制弹出联合登录对话框，允许玩家选择重新登录，默认true
indulgeAuthint否开启实名认证， 0 关闭 ,默认 1 。未实名用户登录成功后是否需要强制实名认证，默认读取望舒后台配置。 注：强制实名后登录数据将在实名认证成功后返回。
canCloseRealAuthbool否实名认证是否可关闭，默认读取望舒后台配置
accountInfosobject否可在union login 添加一个游戏官方账号类型
privacyText1string否第一个协议文本，默认用户协议
privacyUrl1string否第er个协议文本的链接，默认用户协议链接
privacyText2string否第二个协议文本，默认隐私政策
privacyUrl2string否第二个协议文本的链接，默认隐私政策链接
privacyText3string否第三个协议文本，默认空
privacyUrl4string否第三个协议文本的链接，默认空
loginMethodsList>否显示在望舒ui 中的其他登录方式，默认读取后台配置
extDictionary否cp 自定义扩展参数

调用示例

// union login demo 
UnionLoginArgs unionLoginArgs = new()

        privacyText3 = "儿童隐私",
        privacyUrl1 = "http://协议1",
        privacyUrl2 = "http://协议2",
        privacyUrl3 = "http://协议3",

//在unionlogin界面 添加一个游戏官方账号入口
