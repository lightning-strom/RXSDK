快速接入

登录​

启动路径参数注意事项 ::: tip SDK 登录内部会从启动路径上获取参数，用于裂变和导量效果的数据分析，所以 CP 如果需要自定义分享需要拼接以下参数，分享参数来自 getShareData 接口，并且注意 除了 CP 自定义分享场景，不要使用以下参数！！！ :::

字段类型备注
typestringrx
user_sourcestringshare ｜ guide ｜ transmits
share 分享 guide 导量 transmits 自定义透传参数

分享相关字段

字段类型备注
landing_idstring广告推广来源信息
trigger_idstring埋点 ID
trigger_tagstring埋点唯一标识
trigger_typestring埋点类型
material_typestring分享素材类型
material_idstring分享素材类型
strategy_typestring策略类型
strategy_idstring策略唯一 ID
share_timestring分享时间
share_typestringmini，游戏客户端自定义的分享类型
inviter_regionstring分享者所在地区编码
inviter_openidstring分享者的望舒 openid
inviter_productidstring分享者的产品 ID, 若为空, 则通行证功过 inviter_openid 获取关联信息
inviter_channelidstring分享者的渠道 ID, 若为空, 则通行证功过 inviter_openid 获取关联信息
inviter_subchannelidstring分享者的子渠道 ID, 若为空, 则通行证功过 inviter_openid 获取关联信息

导量相关字段

字段类型备注
guide_platformstring导量来源游戏平台
guide_appstring导量来源游戏 app 标识

transmits 字段

transmits 的数据为透传参数，规则需要满足user_source=transmits，除user_source=transmits外其他拼接的参数登录后将原样返回。 示例：https://xxx.html?user_source=transmits&a=b&c=d
登录成功数据会新增字段user_transmits:{"a":"b", "c":"d"}

登录​

参数说明​

| 字段 | 类型 | 是否必填 | 备注 | | ------------ | ----------------- | ---------------- | ---------------- | | params | ILogin | 是 | 参数 | | callback | IMethodParams | 是 | 回调函数集合 |

ILogin 说明

| 字段 | 类型 | 是否必填 | 备注 | | ------------ | ------------ | ---------------- | -------------------------------- | | method | string | 是 | 'minigame_quick'，登录账号的类型 |

IMethodParams 说明

| 字段 | 备注 | | ------------ | ------------------------------------------------------------- | | complete | (data) => void complete：为函数且必传，data 为结果数据 |

调用示例​

sdk.login(
  {
    method: "minigame_quick",
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);

响应结构​

请参考 [服务端登录API](/docs/v3.5/登录（通行证）/服务端接入/服务端 API)响应结构

用户中心​

申请注销账号​

参数说明​

| 字段 | 类型 | 是否必填 | 备注 | | ------------ | ----------------- | ---------------- | ---------------- | | params | IDeregister | 是 | 参数 | | callback | IMethodParams | 是 | 回调函数集合 |

IDeregister 说明

| 字段 | 类型 | 是否必填 | 备注 | | ------------ | ------------ | ---------------- | ------------------ | | idcard | string | 否 | 身份证号码，已实名用户必传，未实名用户可不传 | | realname | string | 否 | 真实姓名，已实名用户必传，未实名用户可不传 | | cpdata | string | 否 | CP 自定义数据，建议传 game_user_id=用户的游戏 id，不传在望舒后台不会账号注销页面不显示游戏侧的用户id |

IMethodParams 说明

| 字段 | 备注 | | ------------ | ------------------------------------------------------------- | | complete | (data) => void complete：为函数且必传，data 为结果数据 |

调用示例​

sdk.deregister(
  {
    idcard: "220123198905030033",
    realname: "真名",
    cpdata: "abc",
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);

响应结构​

{
  "code": 0
}

获取验证码​

::: tip 优先根据指定 email 或 phone 发送验证码； 否则根据当前登录的手机或者邮箱账号发送验证码。 :::

参数说明​

| 字段 | 类型 | 是否必填 | 备注 | | ------------ | ----------------- | ---------------- | ---------------- | | params | ISendCaptcha | 是 | 参数 | | callback | IMethodParams | 是 | 回调函数集合 |

ISendCaptcha 说明

| 字段 | 类型 | 是否必填 | 备注 | | ------------ | ------------ | ---------------- | ------------------------ | | email | string | 否 | 接收验证码的邮箱地址 | | phone | string | 否 | 接收验证码的手机号 | | purpose | string | 是 | 验证码的用途 |

purpose 说明

| 字段 | 备注 | | --------------- | ------------ | | register | 注册 | | bindphone | 绑定手机 | | unbindphone | 解绑手机 | | resetpwd | 重置密码 | | bindemail | 绑定邮箱 | | unbindemail | 解绑邮箱 | | login | 登录 | | setpwd | 设置密码 |

IMethodParams 说明

| 字段 | 备注 | | ------------ | ------------------------------------------------------------- | | complete | (data) => void complete：为函数且必传，data 为结果数据 |

调用示例​

sdk.sendCaptcha(
  {
    phone: "18626656376",
    purpose: "bindphone",
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);

响应结构​

{
  "code": 0,
  "data": {
    "interval": 60,
    "surplus": 60
  }
}

获取用户信息​

参数说明​

| 字段 | 类型 | 是否必填 | 备注 | | ------------ | ----------------- | ---------------- | ---------------- | | callback | IMethodParams | 是 | 回调函数集合 |

IMethodParams 说明

| 字段 | 备注 | | ------------ | ------------------------------------------------------------- | | complete | (data) => void complete：为函数且必传，data 为结果数据 |

调用示例​

sdk.getInfo({
  complete: (data) => {
    console.log(data);
  },
});

响应结构​

字段类型说明
ageNumber用户年龄，根据实名信息获取。
sexNumber性别。0 表示女性，1 表示男性。
user_stateNumber用户状态定义, 0 为正常用户。为正数时，使用各位编码用户的不同状态（以下表述中，第 0 位表示最低位）:第 0 位: 为 1 表示玩家已提交注销申请第 1 位: 为 1 表示已注销。可以是客服同意玩家的注销申请，也可以是客服直接在后台操作将账号注销。第 2 位: 为 1 表示已封停。
attrNumber账号状态标记，使用位运算构成。参考下文 [attr 标记说明](/docs/v3.5/登录（通行证）/服务端接入/服务端 API)
openidString望舒用户 OpenID。
external_openidString三方 openid
external_unionidString三方 unionid
wx_unionidString[DEPRECATED] 三方 unionid
mobile_phoneString手机号
nicknameString昵称
avatarurlString头像
idCardString身份证号
realNameString姓名
attr标记​

attr 标记，由以下标记位构成

标识备注
0是否已通过望舒完成实名认证，1 表示已实名。
1用户当前是否有绑定手机号，1 表示有绑定。
2用户当前是否有绑定邮箱，1 表示有绑定。
3用户当前是否有已设置密码的登录凭证，1 表示有。
4用户是否通过望舒完成实名认证，1 表示是。

响应结构​

{
  "code": 0,
  "data": {
    "avatarurl": "",
    "mobile_phone": "159****7520",
    "nickname": "rssllyn",
    "openid": "rxuWFnlHRbTZ5ED5TkwAG5XVQ==",
    "sex": 0,
    "user_state": 0,
    "attr": 0
  }
}
