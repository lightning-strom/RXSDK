登录​

提示

"非法注册（限制代码1）" code : 312232 为 注册ip限制，默认开启，同一ip默认1小时注册账号不能超过2个，如有需求请联系商务添加ip白名单或调整限制条件。 "非法注册（限制代码2）" code : 312232 为 注册设备限制，默认关闭，同一设备x小时注册账号不能超过x个，如有需求请联系商务开启。

登录弹窗​

::: tip 设置为登录后强制实名认证时登录成功的数据将在实名认证后返回，并且不会返回实名认证的结果，只会在 UI 上体现实名认证成功。 如需要获取实名认证回调数据，请关闭登录后强制实名认证设置，并单独调用实名认证 UI。 :::

Logo参考设计稿： 微乐通行证ai 微乐通行证psd

UI示例

接口原型


/**
 * 调用登录弹窗
 * @param activity 应用Activity
 * @param config 登录页基础配置，默认读取后台配置，优先读取代码配置
 * @param loginCallback 登录结果
 */
public void showLoginUI(Activity activity, RXLoginUIModel config, RXRequestCallback loginCallback)

参数说明​

RXLoginUIModel 结构说明

字段类型是否必填备注
loginMethodsArray否登录方式，默认读取望舒后台配置，没配置则需要手动传入
logoImageDrawable否登录显示的 logo，不配置显示默认logo。注意 logo 资源如果是高倍图，应该放在 res/drawable-xxhdpi（三倍图）目录下，不要将高倍图放在 res/drawable 中，避免显示异常 Logo参考设计稿：微乐通行证ai微乐通行证psd
isShowClosebool否登录页是否显示关闭按钮，默认显示。
setFirstNeedSetPasswordbool否验证码登录的新用户是否弹出设置密码，默认不弹出。注：弹出设置密码后登录数据将在设置成功或关闭设置页面后返回。
needRealAuthbool否未实名用户登录成功后是否需要强制实名认证，默认读取望舒后台配置。 注：强制实名后登录数据将在实名认证成功后返回。
canCloseRealAuthbool否实名认证是否可关闭，默认读取望舒后台配置
setQuickButtonBarVisiblebool否是否显示底部快速登录按钮，默认显示。
setDeregisterShowbool否处于注销中的用户登录后是否显示注销窗口，默认不显示
setLoginContinuebool否如果账号在注销中是继续登录还是退出登录, YES 继续登录，NO 退出登录，默认 NO
setCustomParamsMap否自定义参数
googleClientidString否google登录客户端秘钥，默认读取望舒后台配置，没配置则需要手动传入
wxAppidString否微信appid，默认读取望舒后台配置，没配置则需要手动传入
quickphoneKeyString否一键登录客户端秘钥，默认读取望舒后台配置，没配置则需要手动传入
googleClientidString否google登录客户端秘钥，默认读取望舒后台配置，没配置则需要手动传入
setMethodString否上次使用的登录方法
setLoginOpenidString否上次登录返回的login_openid
setGuestTitleString否快速开始登录方式显示名称，默认显示 快速开始 ，v3.6.17新增
setCustomExtMapMap设置登录携带custom_ext 透传参数 ，v3.6.17新增

setCustomExt 结构说明

字段类型是否必填备注
bigdata_extMap否大数据预置事件透传参数

loginMethods 结构说明

字段备注
wechat微信
guest游客登录
username账号登录
captchacode验证码登录

当前登录用户未绑定手机时，跳转到绑定页面，正常展示绑定手机页面，如当前用户已绑定过手机，则自动进入换绑手机页面

UI示例

接口原型

/**
 * 绑定手机，如果已绑定手机会跳转到换绑页面
 */
IRXView bindPhoneUI(Activity activity, RXUICallback callback)

调用示例

RXSdkUI.getInstance().bindPhoneUI(activity,  new RXRequestCallback() {
    @Override
    public void onResponse(JSONObject jsonObject) {
 
       // todo 业务逻辑
    }
}).show();

图形验证码​

可单独展示图形验证码 UI，验证成功后将凭据回调，客户端可自行处理后续逻辑。

UI示例

接口原型

/**
 * 图形验证 UI
 * @param appid 图形验证码 appid
 */
IRXView captchaVerifyUI(Activity activity, int appid, RXUICallback callback)

调用示例

RXSdkUI.getInstance().captchaVerifyUI(activity, 193923813, new RXRequestCallback() {
    @Override
    public void onResponse(JSONObject jsonObject) {
        // todo logic 
        
    }
});

响应结构​

字段备注
randstr随机串
ticket凭据

身份证键盘​

UI示例

接口原型

/**
 * 显示自定义身份证键盘
 *
 * @param context 上下文
 * @param defaultValue 默认值，输入框中的当前的值
 * @param style 0:默认主题 1:浅色主题（望舒 UI 当前使用）
 * @param callback 回调
 */
void showIdCardKeyboard(Context context, String defaultValue, int style, KeyboardCallback callback)

调用示例

IdCardNumberKeyboardManager.getInstance().showIdCardKeyboard(context, "默认值", 0, new KeyboardCallback() {

    @Override
    public void onShow(float keyboardHeight) {
        // 键盘显示时触发，keyboardHeight 为键盘的高度
    }
    
    @Override
    public void onHideAnimStart() {
        // 键盘执行隐藏动画开始时触发，如果业务需要调整自己 UI 的显示，可根据实际情况做处理，没有则忽略
    }
    
    @Override
    public void onHide() {
        // 键盘隐藏后触发
    }
    
    @Override
    public void onFinish(String content) {
        // 键盘点击完成后回调，content 为输入的内容，业务可以根据自己的需求做回显
    }
    
    @Override
    public void onCancel() {
        // 点击键盘上方透明区域消失时会触发，没有特殊需要可以不处理
    }
});
