商户发零钱​

**POST: ** /v1/operationtoolsapi/wechat/sendredpack 认证方式: CPSign

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/operationtoolsapi/wechat/sendredpack' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{签名}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--data-raw '{
    "amount": 0,
    "open_id": ""
}'

请求头 Header 参数

参数类型备注
ruixue-languageStringzh-CN
Content-TypeStringapplication/json
ruixue-cpidString内容提供商 CPID
ruixue-productidString产品 ID
ruixue-channelidString渠道 ID
ruixue-platformidString平台 platformid
ruixue-devicecodeString设备码
ruixue-cpsignString签名
ruixue-cptsStringCP 签名时间戳
ruixue-traceidStringTraceID

请求参数（JSON）​

参数类型是否必填备注
amountNumber是金额分
open_idString否望舒openid
cp_user_idString否游戏id， 与望舒openid二选一
remarkString否转账备注， 不传默认为“活动红包”

响应示例

{
    "msg": "success",
    "code": 0
}

响应结构(JSON)​

参数类型备注
codeNumber0 为成功
msgString失败信息
dataObject对象信息

data​

参数类型备注
out_batch_noString单号， 用于和微信后台核对

curl --location --request POST '{{接口域名}}/v1/risk/wxa/getuserriskrank' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{签名}}' \

--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--data-raw '{
    "client_ip": "客户端ip",
    "open_id": ""
}'

请求头 Header 参数

参数类型备注
ruixue-languageStringzh-CN
Content-TypeStringapplication/json
ruixue-cpidString内容提供商 CPID
ruixue-productidString产品 ID
ruixue-channelidString渠道 ID
ruixue-platformidString平台 platformid
ruixue-devicecodeString设备码
ruixue-cpsignString签名
ruixue-cptsStringCP 签名时间戳
ruixue-traceidStringTraceID

请求参数（JSON）​

client_ipString是客户端ip
open_idString否望舒openid
