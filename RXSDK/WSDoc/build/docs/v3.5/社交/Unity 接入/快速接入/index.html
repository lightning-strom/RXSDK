定位​

获取附近人​

接口原型


public void LbsRadius(string type, float lon, float lat, float radius, int count, int page, int page_size,
            RequestResponseDelegate onResponse, RequestErrorDelegate onError);

参数说明​

字段类型是否必填备注其他信息
lonnumber是WGS84 经度mock: 125.36970905364038
latnumber是WGS84 纬度mock: 43.814125235156496
radiusinteger是限定半径距离，单位：米mock: @integer(100, 10000)
countinteger否获取数量，0 表示获取全部mock: @integer(1, 100)
pageinteger是获取第几页的数据 从 1 开始mock: 1
page_sizeinteger是每页数量mock: 10
typestring是坐标分组，由 CP 自定义

调用示例


    private void OnLbsRadius()
    {
        RXSocial.LbsRadius("friend", 118.19646377354036f, 24.483710802285128f, 1000, 10, 1, 10, 
            SocialResponseDelegate, RegisterErrorDelegate);
    }

响应结构​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码，0为成功，非0表示出错0
msgString否响应信息，仅在status为非0时不为空
data[DataNode](/docs/v3.5/社交/Unity 接入/快速接入)否结果数据集
DataNode​
字段类型是否必填说明示例
openidString是用户望舒 OpenID
nicknameString否用户昵称
birthdayString否用户生日日期
remarksString否当前用户对其的备注
avatarString否用户头像
customString否CP 自定义信息
distFloat64是距离当前用户的距离（米）
sexNumber否用户性别，1:男；0:女
cp_useridNumber否CP侧 用户id

响应示例

{    
    "data": [       
        {            
            "openid": "rxuSl4QZoNk0G1HY2-Za6GlO7wO-p_ej",            
            "nickname": "xdh"        
        }    
     ],    
     "code": 0
}

添加自定义关系​

接口原型


    public void RelationAdd(string target, Dictionary types, string target_remarks,
                string user_remarks, RequestResponseDelegate onResponse, RequestErrorDelegate onError);

参数说明​

字段类型是否必填备注其他信息
targetstring是对方 OpenIDtest
typesobject是CP 自定义关系类型列表，其值是一个 map 简直对列表，value 必须为 bool
target_remarksstring否用户给 Target 设置的备注信息（最长 512 字符）aaaa
user_remarksstring否Target 给用户设置的备注信息（最长 512 字符）bbbb

调用示例


    public void OnRelationAdd()
    {
        string[] arr =
        {
            "rxuN4ZOvlnP2_16wmj3Lfz3FYiej5xMk07yNKJAz",
            "rxuN4ZOvlnP2_16wmj3Lfz3FYiej5xMk07yNKJAz"
        };
        Dictionary dic = new();
        dic.Add("test", true);
        RXSocial.RelationAdd(arr[1], dic, null, null, 
            SocialResponseDelegate, RegisterErrorDelegate);
    }

响应结构​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码，0为成功，非0表示出错0
msgString否响应信息，仅在status为非0时不为空

响应示例

{
    "code": 
}
