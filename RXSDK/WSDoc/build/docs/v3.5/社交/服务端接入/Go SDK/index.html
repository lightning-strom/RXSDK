设置用户信息​

接口原型

// SetUserInfo 设置用户信息
func (c *Client)SetUserInfo(appID, openID string, userinfo *UserInfo) error

参数说明​

字段类型是否必填备注
openIDstring是望舒 open id
userinfo*[UserInfo](Go SDK#userinfo)是
userinfo​
字段类型是否必填备注
AppIDstring是CP 侧 APPID
OpenIDstring是望舒 open id
Nicknamestring否用户昵称
Avatarstring否用户头像
Regionstring否用户所在地区 例如 220101

调用示例

err := ruixuego.GetDefaultClient().SetUserInfo("{{APPID}}", "openID", &UserInfo{    AppID: "{{APPID}}",    OpenID: "openID"})
if err != nil { panic(err) }

errerror是成功时 nil, 其他为错误

添加自定义好友关系​

接口原型

// AddRelation 添加自定义关系
// remarks[0] openID 用户给 targetOpenID 用户设置的备注
// remarks[1] targetOpenID 用户给 openID 用户设置的备注
func (c *Client) AddRelation(  types RelationTypes, openID, userID, targetOpenID, targetUserID string, remarks ...string) error

参数说明​

字段类型是否必填备注
typesmap[string]bool是自定义关系类型对应的是否为双向好友 例如 {"friend" : true}
openIDstring是望舒 open id, 和userID 任写一个即可
userIDstring是cp侧 user_id 和openID任写一个即可
targetOpenIDstring是给用户设置的自定义信息 和targetUserID任写一个即可
targetUserIDstring是cp侧 user_id 和targetOpenID任写一个即可
remarksslice(string)否数组切片。仅支持两个元素，第一个元素为 targetOpenID 设置的 mark, 第二个元素为openID 设置的mark

调用示例

err := ruixuego.GetDefaultClient().AddRelation(    
    map[string]bool{"friend" : true},     
    "openID",
    "userID",     
    "targetOpenID",
    "targetUserID",    
    "targetRemark",    
    "openIDRemark")
if err != nil { panic(err) }

响应结构​

字段类型是否必填备注
errerror是成功时 nil, 其他为错误

获取附近的人列表​

信息

先更新 openID 位置为参数中 lon lat 位置上， 然后查找这个位置 radius 半径内的其他玩家

接口原型

// LBSRadius 获取附近的人列表
func (c *Client) LBSRadius(   openID, userID, typ string,   lon, lat, radius float64,   page, pageSize int,   count ...int) ([]*RelationUser, error)

参数说明​

字段类型是否必填备注
openIDstring是望舒 open id, 和userID 任写一个即可
userIDstring是cp侧 user_id 和openID任写一个即可
typesstring是分组类型。需要在望舒后台先创建对应的分组
lonfloat64是坐标 经度。 需满足 WGS84 标准
latfloat64是坐标 纬度。需满足 WGS84 标准
radiusfloat64是查询半径。单位 m
pageint是分页请求，第几页。
pageSizeint是分页请求，每页数量
countint是最多查询多少玩家

调用示例

users, err := ruixuego.GetDefaultClient().LBSRadius(    "openID", "userID", "test", 10.1, 100.1, 100, 1, 20, 1000)
if err != nil {   panic(err)}

响应结构​

字段类型是否必填备注
users[]*[RelationUser](Go SDK#relationuser)否返回的好友信息列表
errerror是成功时 nil, 其他为错误
