自动打包​

目的：解决人工上传历史版本包太过耗时的自动化程序。 流程：策划创建并提交版本后， 开发人员在版本详情中点击自动打包， 望舒通知打包机， 打包机处理完成后再主动调用望舒将打包信息返回来。

mime 设置方式​

如果压缩包根目录包含mime.txt文件，会根据文件后缀设置mime，每行一种类型，使用英文“,”分割，前面是后缀，后面是 mime

mime.txt内容示例
txt,text/plain
jpeg,image/jpeg
json,application/json
md,text/markdown
yaml,text/yaml

文件内容说明
1、文件名：mime.txt
2、放在打包文件的根目录
3、上传后会删除 mime.txt文件

{{api接口域名}}/v1/developapi/autopacking/save

}
签名

请求 header 中需带参数Ruixue-Traceid 请求标识Ruixue-Ts 时间戳Ruixue-Sign 签名

签名使用 sha1， 示例：

// GetSign 生成签名方法
func GetSign(cpkey, traceID, ts string) string {        
    h := sha1.New()        
    _, _ = h.Write([]byte(traceID + ts + cpkey))        
    ret := hex.EncodeToString(h.Sum(nil))        
    h.Reset()        
    return ret
}

type LoginIP struct {
