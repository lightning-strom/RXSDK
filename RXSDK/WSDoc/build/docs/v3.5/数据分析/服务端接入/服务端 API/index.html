服务端 API

大数据埋点上报​

本文档将会为您介绍如何使用 HTTP[s] 的 POST 方式上报日志埋点数据，建议通过 Golang SDK 上报数据。

POST： /v1/data/api/track **认证方式：无

CURL示例​

curl --location --request POST 'https://ruixue.weiletest.com/v1/data/api/track' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-datacount: {{日志条数}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}'
--header 'Content-Type: application/json' \
--data-raw '[{
    "distinct_id":"rxuN7pYZwn5jJLf1mM_t6k-178lMJ_x4",
    "devicecode":"cfc1157c-101e-4d7a-8efc-6961589a2d37",
    "type":"track",
    "event":"#role_create",
    "uuid":"21ac0460-01d4-43d7-a5da-9f852a6cbd47",
    "ip":"127.0.0.1",
    "cpid":1000106,
    "product_id":"1001",
    "platform_id":4,
    "channel_id":"1001",
    "sub_channel_id":null
}]'

请求头​

字段类型是否必填说明示例
ruixue-traceidstring是本次请求的TraceID，采用UUID，每次请求都要重新生成957fe69f-9138-42ec-890f-e0a33e6706b0
ruixue-cpidint是CP方 在望舒体系中的 ID1000000
ruixue-languagestring是用户设备当前语系标志zh-CN
ruixue-datacountint是本次上报日志数（必须）
content-typestring是application/json
content-encodingstring否数据压缩格式（空或 gzip或zstd）

请求参数（JSON）​

字段类型属性类型是否必填说明示例
typestring预置属性是事件类型：track
用户属性：user事件类型：track
用户属性：user
timestring预置属性是事件发生时间，格式为 yyyy-mm-dd hh:ii:ss.fff
distinct_idstring预置属性是用户唯一标识，一般为用户 ID（由CP调用时传入）openid
devicecodestring预置属性是设备码（由CP调用时传入）
eventstring预置属性是埋点标识事件名称样例：played
用户属性目前支持类型（全部为小写）：
user_setonce
user_set
user_add
user_min
user_max
uuidstring预置属性是必须36位字符串957fe69f-9138-42ec-890f-e0a33e6706b0
ipstring预置属性是事件发生 IP，字符串类型
product_idstring预置属性是产品 ID
channel_idstring预置属性是渠道 ID
sub_channel_idstring预置属性否子渠道 ID（如有）
cpiduint预置属性是cpid
platform_idint32预置属性是平台 ID, 1：安卓；2：iOS；3：H5；4：微信小程序,10:服务端；
propertiesobject自定义属性是自定义属性map[string]object注意： 1、properties中上传的属性内容，必须与在后台中添加的属性内容保持一致。否则数据无法统计。 2、properties中上传的属性内容不能与以上字段重复。
