鸿蒙Unity接入

SDK 集成​

接口原型

/** 增加用户分数
* @param rank_id  字符串本身带有类型信息，格式为：Flag_榜单容量_重置周期_自定义标识（flag是一个int64位标记，用以扩展和规定绑定属性）
* @param score    增加的分数值
* @param callback callback
*/
void AddScore(string rank_id, int score, Action callback);

参数说明​

字段类型是否必填备注
rank_idstring是排行榜 ID
scoreint是增加的分数值

调用示例

string rank_id = "diddd";
int score = 100;
RuiXueSdk.RankingAPI.AddScore(rank_id, score, RXCallback);

响应结构​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码，0为成功，非0表示出错0
msgString否响应信息，仅在status为非0时不为空

字段类型是否必填备注

open_idstring是目标用户 OpenID

调用示例

string rank_id = "diddd";
string openid = "diddd";

RuiXueSdk.RankingAPI.QueryUserRank(rank_id, openid, RXCallback);

响应结构​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码，0为成功，非0表示出错0
msgString否响应信息，仅在status为非0时不为空
data[DataO](/docs/v3.5/排行榜/服务端接入/服务端 API)否结果数据集
DataO​
字段类型是否必填说明示例
scoreNumber是排行榜分数
rankNumber是排行榜排名
user[UserO](/docs/v3.5/排行榜/服务端接入/服务端 API)是用户信息数据集
UserO​
字段类型是否必填说明示例
openidString是用户望舒 OpenID
nicknameString是用户昵称
birthdayString否用户生日日期
remarksString否当前用户对其的备注
avatarString否用户头像
customString否CP 自定义信息
timeNumber否关系形成时间戳（单位：秒）
sexNumber否用户性别，1:男；0:女

获取排行榜列表​

接口原型

/** 获取排行榜列表
* @param rank_id    字符串本身带有类型信息，格式为：Flag_榜单容量_重置周期_自定义标识（flag是一个int64位标记，用以扩展和规定绑定属性）
* @param start_rank 获取排行榜开始排名。取值[1,榜单容量)。可以用于分页加载 1
* @param end_rank   获取排行榜结束排名。取值[1,榜单容量]。可以用于分页加载 2
* @param callback   callback
*/
void GetRankList(string rank_id, int start_rank, int end_rank, Action callback);

参数说明​

字段类型是否必填备注
rank_idstring是字符串本身带有类型信息，格式为：Flag_榜单容量_重置周期_自定义标识（flag 是一个 int64 位标记，用以扩展和规定绑定属性）
start_rankint是获取排行榜开始排名。取值[1,榜单容量)。可以用于分页加载
end_rankint是获取排行榜结束排名。取值[1,榜单容量]。可以用于分页加载

调用示例

string rank_id = "idxxx";
int start_rank = 0;
int end_rank = 20;

RuiXueSdk.RankingAPI.GetRankList(rank_id, start_rank, end_rank, RXCallback);

响应结构​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码，0为成功，非0表示出错0
msgString否响应信息，仅在status为非0时不为空
data[][Node](/docs/v3.5/排行榜/服务端接入/服务端 API)否结果 数组结构
Node​
字段类型是否必填说明示例
scoreNumber是排行榜分数
rankNumber是排行榜排名
user[UserO](/docs/v3.5/排行榜/服务端接入/服务端 API)是用户信息数据集
