抖音小游戏客服配置

如何接入小游戏客服？ 答：CP 方通过抖音小游戏的客服会话按钮，通过抖音官方服务器或 CP 服务器转发的形式。

整体流程​

跳转抖音小游戏客服​

根据sdk提供的方法跳转到抖音客服进行沟通。

  • 跳转按钮 ：客服会话

小游戏消息推送地址绑定​

进入抖音小游戏详情页，开发-开发设置-消息推送配置 启用消息推送，并按提示填写相关信息，具体如下：

提示

URL(服务器地址):望舒首页域名/v1/servicedouyin/notify_v2/产品id/渠道id

TOKEN:通过望舒游戏发行平台首页选择微信小游戏渠道包-客服参数-进行参数复制获取。如下图所示

数据格式：JSON

抖音后台开通服务​

使用抖音客服需要先开通抖音客服平台服务​

新建客服角色​

搜索添加项目协作者在开放平台的用户名。添加客服组长或者普通客服的权限。

提示

只需要添加一个客服组长保持在线即可。

闭非工作时间提示​

进入抖音客服平台>运营管理>自动回复>关闭非工作时间提示

设置客服状态​

进入抖音客服平台>IM工作台>设置客服为在线
