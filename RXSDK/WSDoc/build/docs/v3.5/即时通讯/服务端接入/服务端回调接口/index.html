服务端回调接口

用户连接/断开通知​

::: tip 当用户连入或断开 IMS 服务后，由 IMS 向 CP 发送的通知请求 :::

类型：同步 Action：ims-userconn 认证方式： [CPSign]](/docs/v3.5/入门指南/服务端接入须知#服务端请求头)

请求参数（JSON）​

字段类型是否必填说明示例
cpidNumber是CPID
client_typeNumber是客户端类型，其是一个位运算结果值，参考
product_idString是产品 ID
channel_idString是渠道 ID
device_codeString否客户端设备码
optionNumber否用户连入传入选项
milli_tsNumber是用户连入、断开时的毫秒时间戳
user_idString是UserID，参考
languageString是客户端语言标记
extMap[String]String否客户端连接时传入的扩展字段
eventNumber是1：连入；2：断开；

请求示例

{    
    "cpid": 1000000,    
    "client_type": 262657,    
    "product_id": "test",    
    "channel_id": "test",    
    "device_code": "",    
    "option": 0,    
    "milli_ts": 1659061339059,    
    "user_id": "a",   
    "language": "zh-CN",   
    "ext": null,   
    "event": 1
}

响应参数（JSON）​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码，0为成功，非0表示出错0
msgString否响应信息，仅在status为非0时不为空

用户发送消息回调​

用户发送消息前的回调事件，CP 服务端可通过实现该接口对用户发送的消息进行审核、替换或转发等功能。

::: warning 注意：服务端发送的消息不会进行回调。 :::

类型：同步 Action：ims-sendmsg 认证方式： [CPSign]](/docs/v3.5/入门指南/服务端接入须知#服务端请求头)

请求参数（JSON）​

字段类型是否必填说明示例
milli_tsNumber是消息发送毫秒时间戳
optionNumber否消息选项（位运算组合）
client_typeNumber是客户端类型，其是一个位运算结果值，
typeNumber是消息类型
sub_typeNumber否消息子类型，当 type 为 CP 自定义消息时有效
uuidString是消息发送者在发送时生成的唯一ID，用于去重
senderString是发送人 UserID
receivers[]String否接收人列表，单聊必须为空；群聊表示 @ 用户列表；自定义单聊表示实际接收人 UserID 清单；
conversation_idString是会话 ID
conv_typeNumber是会话类型，即会话 ID 两个 $ 中间的值
contentString是消息内容 JSON 字符串
product_idString是产品 ID
channel_idString是渠道 ID
extMap[String]String否CP 扩展字段

请求示例

{   
    "option": 3,   
    "client_type": 262657,   
    "type": 2,   
    "uuid": "91a5ca77-ab9d-4dee-b5a6-ac440da22c4b",   
    "sender": "a",   
    "conversation_id": "$1$a:b",   
    "conv_type": 1,   
    "product_id": "test",   
    "channel_id": "test",   
    "content": "{\"text\":\"hahaha\"}",  
    "ext": null
}

响应参数（JSON）​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码，0为成功，非0表示出错
msgString否响应信息，仅在status为非0时不为空
allowBool是是否允许发送该消息，true 为允许，false 为拒绝
contentString是不为空时将对原消息内容进行覆盖，注意其内容要与消息类型对应
receivers[]String否不为空时表示对针对自定义单聊消息的接收列表进行修改
extMap[String]String否不为空时表示对消息扩展信息进行修改

响应示例

{"code": 0,    "allow": true}

用户发送消息通知​

当用户成功发送消息后，IMS 会向 CP 服务端进行通知，以此可实现一些后续行为； 另外，由于 IMS 当前尚未继承 App 消息推送，当用户不在线时并不能立即通知到用户，CP 可通过该接口自行实现 App 推送通知。

::: warning 注意：服务端发送的消息不会进行通知。 :::

类型：同步 Action：ims-sentmsg 认证方式： [CPSign]](/docs/v3.5/入门指南/服务端接入须知#服务端请求头)

请求参数（JSON）​

字段类型是否必填说明示例
msg[Message](服务端 API#message)是消息内容实体
receiversMap[String][Receiver](服务端 API#receiver)是接收者发送结果对象，键名为 UserID
message​
字段类型是否必填说明示例
milli_tsNumber是消息发送毫秒时间戳
optionNumber否消息选项（位运算组合）
client_typeNumber是客户端类型，其是一个位运算结果值
typeNumber是消息类型
sub_typeNumber否消息子类型，当 type 为 CP 自定义消息时有效
uuidString是消息发送者在发送时生成的唯一ID，用于去重
senderString是发送人 UserID
receivers[]String否接收人列表，单聊必须为空；群聊表示 @ 用户列表；自定义单聊表示实际接收人 UserID 清单；
conversation_idString是会话 ID
conv_typeNumber是会话类型，即会话 ID 两个 $ 中间的值
contentString是消息内容 JSON 字符串
product_idString是产品 ID
channel_idString是渠道 ID
extMap[String]String否CP 扩展字段
receiver​
字段类型是否必填说明示例
logined_platformNumber是该用户登录过的平台
success_platformNumber否本消息成功在线投递到的平台，可通过该值与 logined_platform 判断用户是否需要进行 APP 推送

请求示例

{    
    "msg": {        
        "option": 3,        
        "client_type": 262657,        
        "type": 2,       
        "uuid": "91a5ca77-ab9d-4dee-b5a6-ac440da22c4b",       
        "sender": "a",       
        "conversation_id": "$1$a:b",       
        "conv_type": 1,       
        "product_id": "test",       
        "channel_id": "test",       
        "content": "{\"text\":\"hahaha\"}",      
        "ext": null    
    },    
    "receivers": {        
        "b": {            
            "logined_platform": 1,           
            "success_platform": 1       
        }   
    }
}

响应参数（JSON）​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码，0为成功，非0表示出错0
msgString否响应信息，仅在status为非0时不为空

会话创建回调​

::: tip 客户端在创建会话时的回调事件，CP 服务端可对该操作进行审核，控制是否允许执行。 :::

类型：同步 Action：ims-createconv 认证方式： [CPSign]](/docs/v3.5/入门指南/服务端接入须知#服务端请求头)

请求参数（JSON）​

字段类型是否必填说明示例
conversation_idString是会话 ID$2$testgroup
optionNumber否会话选项
conv_typeNumber是会话类型
creatorString否会话创建者 UserID，非频道聊天会话时必填
members[]String否会话为群聊时，加入群聊的用户列表
extMap[String]String否CP 扩展字段
ims_extMap[String]String否IMS 扩展字段

请求示例

{ 
    "conversation_id": "$2$testgroup", 
    "option": 0,  
    "conv_type": 2, 
    "creator": "a", 
    "ext": null, 
    "ims_ext": null,  
    "members": [    "userA",    "userB"  ]
}

响应参数（JSON）​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码，0为成功，非0表示出错0
msgString否响应信息，仅在status为非0时不为空
allowBool是是否允许该操作，true 为允许，false 为拒绝

响应示例

{"code": 0,    "allow": true}

msgString否响应信息，仅在status为非0时不为空
allowBool是是否允许该操作，true 为允许，false 为拒绝

响应示例

{"code": 0,    "allow": true}
