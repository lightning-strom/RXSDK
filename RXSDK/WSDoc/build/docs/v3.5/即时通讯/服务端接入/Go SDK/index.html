用户登陆​

接口原型

// IMSLogin ims 登陆接口
func (c *Client) IMSLogin(req *IMSLoginReq) (*IMSLoginResp, error)

参数说明​

字段类型是否必填备注
req[IMSLoginReq](/docs/v3.5/即时通讯/服务端接入/服务端 API)是消息结构
IMSLoginReq​
字段类型是否必填备注
UserIDstring是CP 下的唯一标识符
ProductIDstring是产品 ID
ChannelIDstring是渠道 ID
DeviceCodestring否设备码
CPIDuint32是CPID
ClientTypeint32是客户端类型

调用示例

ack, err := ruixuego.GetDefaultClient().IMSLogin(&ruixuego.IMSLoginReq {
    UserID:       "cpuserid-123456"
    ClientType:   256,
    ProductID:    testAppID,   
    ChannelID:    testChannelID,
    DeviceCode:   "aaaaaaaaaa",
    CPID:         1001,
    })
if err != nil { panic(err) }

响应结构​

字段类型是否必填备注
ack[IMSLoginResp](/docs/v3.5/即时通讯/服务端接入/服务端 API)是登陆信息
errerror是成功时 nil, 其他为错误
IMSLoginResp​
字段类型是否必填备注
AccessTokenstring是连接令牌
AccessTokenExpireint64是过期时间，毫秒
RefreshTokenstring是刷新令牌
RefreshTokenExpireint64是刷新令牌过期时间，毫秒
AESKeystring是AES 密钥，返回格式为 16 进制 64 位字符串，需解析成 32 Byte 密钥使用

发送消息​

接口原型

// IMSSendMessage 发送消息
func (c *Client) IMSSendMessage(req *IMSMessage) (*IMSMessageAck, error)

参数说明​

字段类型是否必填备注
req[IMSMessage](/docs/v3.5/即时通讯/服务端接入/服务端 API)是消息结构
IMSMessage​
字段类型是否必填备注
Optionint64否消息选项（位运算组合）
ClientTypeint32是客户端类型，其是一个位运算结果值
Typeint32是消息类型
SubTypeint32否消息子类型，当 type 为 CP 自定义消息时有效， CP 请使用 [ 1 , 1亿 ]
UUIDstring是消息发送者在发送时生成的唯一ID，用于去重
Senderstring是发送人 UserID
注意：服务端发送消息时，该值应尽量为空，否则对于群聊或频道聊天要保证其已加入会话
Receivers[]string否接收人列表，单聊必须为空；群聊表示 @ 用户列表；自定义单聊表示实际接收人 UserID 清单；
ConversationIDstring是会话 ID
ConvTypeint32是会话类型，即会话 ID 两个 $ 中间的值
ProductIDstring是产品 ID
ChannelIDstring是渠道 ID
Contentstring是消息内容 JSON 字符串。需要满足各个消息格式
Extmap[string]string否CP 扩展字段

调用示例

ack, err := ruixuego.GetDefaultClient().IMSSendMessage(&ruixuego.IMSMessage{   
    Option:         3,   
    Type:           2,   
    Sender:         "testkk2012",   
    UUID:           "34567890991",   
    ClientType:     256,   
    ConversationID: "$4$worldChannel",   
    ConvType:       4,   
    ProductID:      testAppID,   
    ChannelID:      testChannelID,   
    Content:        "{\"text\":\"22222\"}",   
    Ext:            map[string]string{"userData": "{\"game\" : \"22222\"}"},
    })
if err != nil { panic(err) }

响应结构​

字段类型是否必填备注
ack[IMSMessageAck](/docs/v3.5/即时通讯/服务端接入/服务端 API)是用户排行榜信息
errerror是成功时 nil, 其他为错误
IMSMessageAck​
字段类型是否必填备注
MsgIDstring是消息id
UUIDstring是发消息时的 UUID
InboxIDint64是邮件在发消息玩家邮箱里的 id
MilliTSint64是发消息时间戳

创建会话​

接口原型

// IMSCreateConversation 创建会话
func (c *Client) IMSCreateConversation(req *IMSCreateConvReq) error

参数说明​

字段类型是否必填备注
req[IMSCreateConvReq](/docs/v3.5/即时通讯/服务端接入/服务端 API)是会话 ID
IMSCreateConvReq​
字段类型是否必填备注
ConversationIDstring是会话 ID
Optionint64否消息选项（位运算组合）
ConvTypeint32是会话类型
Creatorstring是会话创建者，即单聊的发起者或群的创建者。应为CP 侧 玩家 id
Members[][MemberInfo](/docs/v3.5/即时通讯/服务端接入/服务端 API)否会话的参与者，可以包括创建者
Extmap[string]string否该会话 CP 自定义扩展信息
memberinfo​
字段类型是否必填备注
UserIDstring是用户id。 应为CP 侧 玩家 id
Optionint64否用户的 会话选项（位运算组合）
Extmap[string]string否该用户在会话内的自定义扩展信息

调用示例

messages, err := ruixuego.GetDefaultClient().IMSCreateConversation(&IMSCreateConvReq{        
    ConversationID : "$1$testA:testB",        
    Option: 3,        
    ConvType: 1,        
    Creator: "creator",        
    Members: []*MemberInfo{            
        {                
            UserID: "CP 用户 userid",               
            Option: 3,               
            Ext: map[string]string{"自定义key" : "user 自定义参数"},           
        }       
    },        
    Ext: map[string]string{"自定义key" : "会话自定义参数"}    })
    
if err != nil {   panic(err)}

响应结构​

字段类型是否必填备注
errerror是成功时 nil, 其他为错误

IMSConversation​
字段类型是否必填备注

Attrint64否会话属性扩展值

UserAttrint64否用户在会话中的 属性扩展值

Members[]string否会话中所有用户
