基本功能​

同步消息​

拉取用户离线后收到的消息或者在全新设备上拉取当前账号的所有消息。

获取会话模块

SessionModule sessionModule = RXIMEngine.getInstance().catchModule(ProcessModuleInventory.SESSION);

接口原型

/**
 * 同步消息
 * @param observer 返回的消息列表回调函数
 */
public void syncMessage2(final IRXSendingObserver> observer)

调用示例

SessionModule sessionModule = RXIMEngine.getInstance().catchModule(ProcessModuleInventory.SESSION);
sessionModule.syncMessage2(new IRXSendingObserver>() {
    @Override
    public void onStart(List contentMessage) {

    }

    @Override
    public void complete(int code, List contentMessages) {
        for (RXIMMessage contentMessage : contentMessages) {
            mStatusTv.append(" --- " + contentMessage.getInboxID() + "\n");
            LG.e(" ===同步消息 = " + contentMessage.getInboxID());
        }
    }
});

发送消息​

获取消息模块

ConversationModule conversationModule = RXIMEngine.getInstance().catchModule(ProcessModuleInventory.CONVERSATION);

说明：发送消息时，使用Conversation#sendMessage()方法，传入不同的消息模型，发送不同消息。这些消息模型都实现 ISenderMessageEntity 接口。

接口原型

/**
 * 发送消息
 *
 * @param receiver 接收人，使用OpenID
 * @param entity   目标消息模型
 * @param extend   扩展字段
 * @param option   发送消息选项
 * @param type     聊天模式，单聊、群聊、自定义单聊、频道会话
 * @param moreReceivers @群成员，只有群聊生效
 * @param observer 发送消息状态回调
 */
public void sendMessage(String receiver, ISenderMessageEntity entity, String extend, int option, ConversationType type, List moreReceivers, IRXSendingObserver observer)

回调参数说明​

作为发送消息的回调接口，IRXSendingAttachmentObserver 接口继承自 IRXSendingObserver 接口，前者更多使用在带附件上传的场景中，比如：发送图片、视频、文件等，需要使用 IRXSendingAttachmentObserver 接口用于监听文件上传过程；而对于普通消息，如：发送文本、转发文本、撤回消息等，只需要使用 IRXSendingObserver 接口监听消息发送状态。 IRXSendingObserver 结构说明

public interface IRXSendingObserver{
    void onStart(T contentMessage);//消息发送开始
    //消息发送完成，注意只是代表消息发送完成，需要根据code值判断消息状态，具体值参考状态码部分
    void complete(int code, T contentMessage);
}

IRXSendingAttachmentObserver 结构说明

public interface IRXSendingAttachmentObserver extends IRXSendingObserver{
    void onUploadStart(RXIMMessage message);//附件上传开始
    void onUploadProgress(String percent, long currentSize);//进度，多附件回显示整体进度
    void onUploadComplete(RXIMMessage message);//上传完成
    void onUploadErrorOccur(RXIMMessage unSendMessage,String errorFromClient,String errorCodeFromRemote,String errorFromRemote);//上传出现错误
}

会话内提示消息发送​

此接口一般用于如进入群聊、更改信息等提示消息的发送。

SenderTipMessageEntity senderTipMessageEntity = new SenderTipMessageEntity("xxx 邀请 xxx加入群聊",true,Arrays.asList("userid"));

conversationModule.sendMessage(sessionID, senderTipMessageEntity, "", option, ConversationType.SINGLE, null, new IRXSendingObserver() {
    @Override
    public void onStart(RXIMMessage contentMessage) {
        LG.e("消息发送开始");
    }

    @Override
    public void complete(int code, RXIMMessage contentMessage) {
        if (contentMessage != null) {
            rximMessage = contentMessage;
            if (BaseMessage.MESSAGE_TRANSFORM_STATE_ERROR == contentMessage.getSendState()) {
                LG.e("消息发送失败 code:" + code);
                showMsg(contentMessage.getInboxID() + " --- 消息发送失败");
            } else {
                LG.e("消息发送成功 inboxid" + contentMessage.getInboxID() + " --- " + contentMessage.getContent() + "\n");
                showMsg("消息 inboxid=" + contentMessage.getInboxID() + "，text=" + contentMessage.getContent() + "");
            }
        }
    }
});

接收消息​

当收到服务器发来的消息时，可以通过此接口对其进行处理。

接口原型

/**
 * 消息接收监听
 */
void registerConversationObserver(IRXConversationObserver observer)

调用示例

RXIMEngine.getInstance().registerConversationObserver(new IRXConversationObserver() {
            @Override
            public void onReceive(ConversationType conversationType, RXIMMessage contentMessage) {
//                LG.e(contentMessage.toString());
                LG.e(contentMessage.getExtend());
                if(contentMessage.getMsgType() == MessageTypeInventory2.TEXT){
                    TextMessageEntity entity = contentMessage.getContentEntity();
                    LG.e(entity.toString());
                }else if(contentMessage.getMsgType() == MessageTypeInventory2.PIC){
                    PicMessageEntity entity = contentMessage.getContentEntity();
                    LG.e(entity.toString());
                }else if(contentMessage.getMsgType() == MessageTypeInventory2.AUDIO){
                    VoiceMessageEntity entity = contentMessage.getContentEntity();
                    LG.e(entity.toString());
                } else if(contentMessage.getMsgType() == MessageTypeInventory2.VIDEO){
                    VideoMessageEntity entity = contentMessage.getContentEntity();
                    LG.e(entity.toString());
                }else if(contentMessage.getMsgType() == MessageTypeInventory2.POSITION){
                    LocationMessageEntity entity = contentMessage.getContentEntity();
                    LG.e(entity.toString());
                }else if(contentMessage.getMsgType() == MessageTypeInventory2.FACE){
                    EmotionMessageEntity entity = contentMessage.getContentEntity();
                    LG.e(entity.toString());
                }else if(contentMessage.getMsgType() == MessageTypeInventory2.FILE){
                    FileMessageEntity entity = contentMessage.getContentEntity();
                    LG.e(entity.toString());
                }
                mStatusTv.append(contentMessage.getInboxID() + " --- " + contentMessage.getMsgType() + " ---- " + contentMessage.getContent() + "\n");
            }
        });

更新本地消息扩展字段​

当用户更新个人信息时，可以通过此接口通知本地数据库更新。在更新完成后，本地保存的个人信息将会得到更新。

接口原型

void updateLocalMessageExt(String messageID, String ext, String ims_ext)

参数说明​

字段类型是否必填备注
messageIDString是消息 id 数组（单次最多 20 条）
extString否扩展字段
ims_extString否ims 扩展字段

调用示例

ConversationModule conversationModule = RXIMEngine.getInstance().catchModule(ProcessModuleInventory.CONVERSATION);
conversationModule.updateLocalMessageExt("msgid","ext","imsext");
