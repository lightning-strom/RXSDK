基本功能​

同步消息​

拉取用户离线后收到的消息或者在全新设备上拉取当前账号的所有消息。消息会通过 RXIMMessageDelegate 协议回调函数 receiveMessage 通知客户端；同步完成会通过回调函数 syncMessageFinished 通知客户端。可以选择在登录成功之后的回调中触发。

接口原型

/**
 * 同步消息
 */
-(void)syncMessage;

调用示例

[[RXIMChatService sharedSDK] syncMessage];

发送消息​

生成RXIMMessage的对象之后，通过此接口进行发送消息操作。客户端需要通过 RXIMMessageDelegate 协议里的方法 sendMessageSuccess 和 sendMessageFailure 来进行消息发送结果的监听。

接口原型

/**
 * 发送消息
 * @param sendMessage 发送的消息对象
 * @param completionHandler 返回消息对象，处理本地逻辑用，发送成功以delegate方式回调。
 */
- (void)sendMessage:(RXIMSendMessage * _Nonnull)sendMessage
  completionHandler:(void (^)(RXIMMessage * message,RXIMError *error))completionHandler;
  
#param mark -- 发送结果监听
/**
 * 消息发送成功
 */
- (void)sendMessageSuccess:(RXIMMessage *)msgObj;
/**
 * 消息发送失败
 */
- (void)sendMessageFailure:(RXIMMessage *)msgObj error:(RXIMError *)error;

调用示例

#pragma mark - 
#pragma mark - 消息发送成功回执
- (void)sendMessageSuccess:(RXIMMessage *)msgObj
{
    NSLog(@"消息发送成功");
    self.msgObj = msgObj;
    [SVProgressHUD showSuccessWithStatus:[NSString stringWithFormat:@"%@ 发送成功",msgObj.msgId]];
}

#pragma mark - 消息发送失败回执
- (void)sendMessageFailure:(RXIMMessage *)msgObj error:(RXIMError *)error
{
    NSLog(@"消息发送失败");
    [SVProgressHUD showErrorWithStatus:[NSString stringWithFormat:@"code = %ld errMsg = %@",error.code,error.developerMessage]];
}

会话内提示消息发送​

此接口一般用于如进入群聊、更改信息等提示消息的发送。 调用示例

RXIMMsgConvTipsContent *content = [[RXIMMsgConvTipsContent alloc]init];
content.text = [NSString stringWithFormat:@"%@ 发起了群聊，并邀请 %@ 加入群聊",[JX_UserUtility sharedManager].openId,[members objectAtIndex:0]];
content.type = 1;
content.userids = members;
RXIMSendMessage *sendMsg = [[RXIMSendMessage alloc] init];
sendMsg.content = content;
sendMsg.msgType = RXIMMessageType_Tips;
sendMsg.sessionID = self.groupId.text;
sendMsg.sessionType = RXIMSessionType_group;
sendMsg.option = RXIMMsgOption_enableSync|RXIMMsgOption_saveHistory|RXIMMsgOption_readReceipt;
[[RXIMChatService sharedSDK] sendMessage:sendMsg completionHandler:^(RXIMMessage * _Nullable message,RXIMError *error){
      NSLog(@"");  
}];

#param mark -- 发送结果监听
#pragma mark - 消息发送成功回执
- (void)sendMessageSuccess:(RXIMMessage *)msgObj
{
    NSLog(@"消息发送成功");

}

{

回复消息发送​

此功能为针对某条已经发送成功的消息进行回复并展示。 调用示例

RXIMMsgReplyContent *replyContent = [[RXIMMsgReplyContent alloc]init];
RXIMReferenceMsg *referenceMsg = [[RXIMReferenceMsg alloc]init];
RXIMMessage *msgObj = self.selectModel.message;
referenceMsg.fromId = msgObj.fromId;
referenceMsg.msgType  = msgObj.msgType;
referenceMsg.msgId = msgObj.msgId;
referenceMsg.content = msgObj.content;
referenceMsg.timestamp = msgObj.timestamp;
referenceMsg.subType = msgObj.subType;

RXIMReplyMsg *replyMsg = [[RXIMReplyMsg alloc]init];
replyMsg.msgType = RXIMMessageType_Text;
RXIMMsgTextContent *textContent = [[RXIMMsgTextContent alloc]init];
textContent.text = text;
replyMsg.content = textContent;

replyContent.reference = referenceMsg;
replyContent.reply = replyMsg;
RXIMSendMessage *msg = [[RXIMSendMessage alloc] init];
msg.content = replyContent;
msg.sessionID = self.convModel.session.sessionID;;
msg.sessionType = self.convModel.session.type;
msg.msgType = RXIMMessageType_Reply;
msgObj.snapchatTimeout = [self getMsgSnapchatTimeout];
if (msgObj.snapchatTimeout > 0) {
msgObj.option = RXIMMsgOption_enableSync|RXIMMsgOption_saveHistory|RXIMMsgOption_readReceipt|RXIMMsgOption_snapchat;
}else{
    msgObj.option = RXIMMsgOption_enableSync|RXIMMsgOption_saveHistory|RXIMMsgOption_readReceipt;
}
[[RXIMChatService sharedSDK] sendMessage:msg completionHandler:^(RXIMMessage * _Nullable message,RXIMError *error){
    if (!error) {
        NSLog(@"消息处理成功");
    }else{
        [SVProgressHUD showErrorWithStatus:[NSString stringWithFormat:@"code = %ld,errMsg = %@",error.code,error.developerMessage]];
    }

接收消息​

当收到服务器发来的消息时，可以通过此接口对其进行处理，如您可以RXIMMessage中的RXIMMessageType来区分消息类型用于不同场景。接收消息会通过 RXIMMessageDelegate 协议回调函数 receiveMessage 通知客户端。

接口原型

/**
 * 消息接收
 */
- (void)receiveMessage:(NSArray *)msgs;

调用示例

#pragma mark - 
#pragma mark - 消息接收回执
- (void)receiveMessage:(NSArray *)msgs
{
    NSLog(@"接收消息");
    self.msgObj = msgs.lastObject;
    for (RXIMMessage *msg in msgs) {
        self.msgCount++;
        NSLog(@"%@", [NSString stringWithFormat:@"接收消息%ld成功",(long)self.msgCount]);
    }
    
}

/**

 */
- (void)resendMessage:(RXIMMessage * _Nonnull)message

    }

转发消息​

此功能可以将已经成功生成的消息进行转发，可选择转发类型，作为新消息发送。

接口原型

/**
 * 转发消息
 * @param mids 消息id数组
 * @param receives 会话id数组
 * @param type 转发类型 0：逐条转发 1：合并转发
 * @Param exts 扩展数组
 * @param option 消息选项
 * @param completionHandler 返回消息对象，处理本地逻辑用，发送成功以delegate方式回调。
 */
- (void)forwardMessage:(NSArray * _Nonnull)mids
              receives:(NSArray * _Nonnull)receives
                  type:(NSInteger)type
                   ext:(NSArray * _Nullable)exts
                option:(NSInteger)option
     completionHandler:(void (^)(NSArray *messages,RXIMError *error))completionHandler;

参数说明​

字段类型是否必填备注
midsNSArray是消息 id 数组
receivesNSArray是会话 id 数组
typeNSInteger是转发类型 0：逐条转发 1：合并转发
extsNSArray否扩展数组
optionNSInteger是消息选项

调用示例

[[RXIMChatService sharedSDK] forwardMessage:mids receives:sessionIds type:contactFrom ext:nil option:option completionHandler:^(NSArray * _Nonnull messages, RXIMError * _Nonnull error) {
    if (!error) {
        [SVProgressHUD showSuccessWithStatus:@"转发成功"];
    }else{
        [SVProgressHUD showErrorWithStatus:@"转发失败"];
    }
}];

更新本地消息扩展字段​

当用户更新个人信息时，可以通过此接口通知本地数据库更新。在更新完成后，本地保存的个人信息将会得到更新。

接口原型

/**
 * 更新本地消息扩展字段
 * @param msgIds 消息id数组
 * @param ext 扩展字段
 * @return 更新是否成功
 */
- (BOOL)updateLocalMessageExt:(NSArray * _Nonnull)msgIds
                          ext:(NSDictionary * _Nonnull)ext;

参数说明​

字段类型是否必填备注
msgIdsNSArray是消息 id 数组（单次最多 20 条）
extNSDictionary否扩展字段

调用示例

[[RXIMChatService sharedSDK] updateLocalMessageExt:@[] ext:@{}];
