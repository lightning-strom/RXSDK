服务端api

创建玩家反馈​

**POST: ** /v1/feedbackapi/player_feedback/create 认证方式： AccessToken

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/feedbackapi/player_feedback/create' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-accesstoken: {{登录token}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--data-raw '{    
    "content":"",    
    "phone":"",
    "attachments": [""],
    "tags": [""]
}'

请求参数（JSON）​

字段类型是否必填说明示例
contentString是反馈内容
phoneString否联系电话
attachments[]String否附件， 支持图片和视频
tags[]String否反馈标签

请求示例

{
    "content":"",    
    "phone":"",
    "attachments": [""],
    "tags": [""]
}

响应参数（JSON）​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码，0为成功，非0表示出错0
msgString否响应信息，仅在status为非0时不为空

响应示例

{"code": 0}

玩家反馈列表​

**GET: ** /v1/feedbackapi/player_feedback/list 认证方式： AccessToken

CURL 示例​

curl --location --request GET '{{接口域名}}/v1/feedbackapi/player_feedback/list?page=1&size=10' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-accesstoken: {{登录token}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}'

请求参数（JSON）​

字段类型是否必填说明示例
pageNumber是第几页
sizeNumber是每页的条数

响应参数（JSON）​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码，0为成功，非0表示出错0
msgString否响应信息，仅在status为非0时不为空
dataData否响应内容

Data​

字段类型是否必填说明示例
pageNumber是第几页0
sizeNumber否每页条数
totalNumber是总数量
list[]List否响应内容

List​

字段类型是否必填说明示例
idNumber是唯一标识0
contentString是反馈内容
created_atString是反馈时间
statusNumber是1待回复 1已回复
recover_atString是回复时间
is_propNumber是0无道具 1有道具

响应示例

{
    "data": {
        "page": 1,
        "size": 20,
        "total": 23,
        "list": [
            {
                "id": 11,
                "content": "测试",
                "created_at": "2024-09-12 18:40:58",
                "status": 2,
                "recover_at": "2024-09-12 19:04:26",
                "is_prop": 1
            },
        ],
    "code": 0
}

玩家反馈详情​

**GET: ** /v1/feedbackapi/player_feedback/detail 认证方式： AccessToken

CURL 示例​

curl --location --request GET '{{接口域名}}/v1/feedbackapi/player_feedback/detail?id=1' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-accesstoken: {{登录token}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}'

请求参数（JSON）​

字段类型是否必填说明示例
idNumber是唯一标识

响应参数（JSON）​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码，0为成功，非0表示出错0
msgString否响应信息，仅在status为非0时不为空
data[]Data否响应内容

Data​

字段类型是否必填说明示例
idNumber是唯一标识0
contentString是反馈内容
attachments[]String是反馈附件 支持图片和视频
created_atString是反馈时间
statusNumber是1待回复 1已回复
recover_atString是回复时间
recover_attachments[]String是回复附件 支持图片和视频
recover_contentString是回复内容
is_propNumber是0无道具 1有道具
get_propNumber是道具是否领取 0未领取 1已领取
prop[]Prop是道具信息

Prop​

字段类型是否必填说明示例
nameString是道具名称
tagString是道具标识
numString是道具数量
countString是道具显示数量
time_limitNumber是有效期（天） 0时为永久有效
iconString是道具图标
describeString是道具描述

响应示例

{
    "data": {
        "id": 11,
        "content": "测试",
        "attachments": [
            ""
        ],
        "created_at": "2024-09-12 18:40:58",
        "status": 2,
        "recover_at": "2024-09-12 19:04:26",
        "recover_attachments": [
            ""
        ],
        "recover_content": "回复",
        "is_prop": 1,
        "prop": [
            {
                "name": "1",
                "tag": "测试1",
                "num": "50",
                "time_limit": 0,
                "icon": "",
                "count": "50",
                "describe": ""
            }
        ],
        "get_prop": 0
    },
    "code": 0
}

CURL 示例​

curl --location --request POST '{{接口域名}}/v1/feedbackapi/player_feedback/getprop' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-accesstoken: {{登录token}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--data-raw '{    
    "id":1
}'

请求参数（JSON）​

字段类型是否必填说明示例
idNumber是反馈id

请求示例

{
    "id":1
}

响应参数（JSON）​

HTTP 状态码：200 OK

字段类型是否必填说明示例
codeNumber是响应状态码，0为成功，非0表示出错0
msgString否响应信息，仅在status为非0时不为空

响应示例

{"code": 0}
