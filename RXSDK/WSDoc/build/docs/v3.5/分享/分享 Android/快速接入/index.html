分享调度​

当埋点配置了分享调度后，诱导类分享会根据分享调度策略决定用户是分享还是广告， 分享成功或者失败， 返回值中会增加 scheduling 对象，值如下：

提示

scheduling_event 分享结果仅代表根据望舒后台设置的成功率计算的结果，不表示实际的分享结果。 scheduling_event 是在拉起分享前的预算的结果，三方平台的分享机制不同，建议根据平台处理实际结果。 例如：微信 的机制是用户点击 关闭、取消 都算 分享成功，而 Facebook 有真实的回调，用户点击 关闭、取消 会返回 取消分享 结果。

获取分享调度Scheduling​
字段类型说明
scheduling_typeString值为 ad 时为广告， share 时为分享。
scheduling_signString调度策略当前可分享看广告总数密文, 需用aes解密，使用cpkey作为key。
解出值转为字符串， 格式: "type=share&count=10&uuid=xxx&ts=1695796034&ddid=a" [详情](/docs/v3.5/三方服务/Android 渠道接入说明)
scheduling_eventNumber1 分享成功 -1 分享失败
scheduling_failed_msgString分享失败时的信息
scheduling_sign对应标识​
字段类型说明
typeString值为 ad 时为广告， share 时为分享。
countNumber调度策略当前可分享看广告总数
uuidString唯一标识
tsNumber时间戳
ddidString调度标识

错误码错误描述解决方法

305406今日分享次数已达上限该用户触发了 商业化基础配置=>分享广告配置=>分享广告次数配置=>次数限制
305407今日循环调度次数已达上限该用触发了 商业化基础配置=>分享广告配置=>分享广告调度策略=>循环次数限制
305408分享调度策略未命中商业化基础配置=>分享广告配置=>分享广告调度策略中的调度策略没有覆盖用户的条件
305409app有效用户界定不存在缺少配置信息： 商业化基础配置=>分享广告配置=>分享广告次数配置=>游戏&无效用界定=>APP

拉起分享​

接口原型

/** 
 * 一键分享
 * @param activity activity
 * @param config 分享配置
 * @param callback
 */
void share(Activity activity, RXShareConfig config, RXRequestCallback callback);

/** 
 * 自定义分享
 * @param activity activity
 * @param config 分享配置
 * @param callback
 */
void shareCustom(Activity activity, RXCustomShareConfig config, RXRequestCallback callback);

分享/广告结果上报​

提示

如果在望舒后台开启了分享调度功能，在上报时需要将调用 获取分享信息 时的 func、platform、region、transmits 传入。

接口原型

void shareSchedulingReport(String func, String platform, String region, boolean scheduling_event, String scheduling_type, String transmits, @NonNull Map properties, RXJSONCallback callback)

参数说明​

字段类型是否必填备注
funcString是埋点标识
platformString是分享平台
regionString否地区码
transmitsString否透传参数，原样返回， 请使用 key=value 形式，并使用 urlencode 编码，此数据在落地页中可以通过 key 获取到
scheduling_eventBool是上报结果 true 成功 false 失败
scheduling_typeString是上报类型 ad 广告 share 分享
propertiesMap否自定义属性， 上报区服和角色需要在 game_info 中传入属性，具体使用方式参考下方 game_info 字段说明

properties 结构说明

字段类型是否必填备注
game_infoMap否大数据预置事件透传参数
custom_extMap否自定义透传参数

custom_ext 结构说明

字段类型是否必填备注
bigdata_extMap否大数据预置属性透传参数

game_info 字段说明

字段类型是否必填备注
cp_game_character_idstring否角色 id
cp_game_area_idstring否区服 id

三方分享回调说明​

以下三方分享结果都是由三方机制控制，望舒只进行了回调包装，没有其他特殊处理。

平台成功失败取消
system非真实回调， 拉起分享后，取消、关闭、分享 都返回成功回调无失败回调无失败回调
wechat跳转到微信后点击 取消、关闭、分享 都返回成功回调无失败回调无取消回调
facebook真实回调真实回调真实回调
messenger无真实回调无真实回调无真实回调
line无成功回调无失败回调无取消回调

snapchat跳转到 snapchat 立刻返回成功回调，点击 关闭、分享 后无法返回 app，需要用户手动返回无失败回调无取消回调

获取自动重定向短链接​

如果拼接后的分享链接过长，可使用此接口获取自动重定向短链接。

接口原型

void getShortUrl(@NonNull Map hashMap, RXRequestCallback callback)

参数说明​

字段类型是否必填备注
urlString是要生成短链接的url
titleString否标题
contentString否描述
imageString否图片
extString否参数

调用示例

        Map m = new HashMap<>();
        m.put("url", "www.baidu.com");

        // 可传入 title、content、image 对短链接添加 og 标签
        // og 标签常用场景为三方平台通过链接中的 开放协议 解析展示的缩略图、标题、描述等，具体说明：https://cloud.tencent.com/developer/article/1820467        

        m.put("title", "getShortUrl 标题");
        m.put("content", "getShortUrl 内容");
        m.put("image", "https://rxfile-test.ruixuecloud.com/share/2024/07/06/1720252159611.png");
        Map ext = new HashMap<>();
        ext.put("exttest", "测试。。。");
        m.put("ext", ext);
        RXSdkApi.getInstance().getShortUrl(m, jsonCallback);
