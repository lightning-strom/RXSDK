小游戏

获取商业化窗口信息​

参数说明​

| 字段 | 类型 | 是否必填 | 备注 | | ------------ | ----------------- | ---------------- | ---------------- | | callback | IMethodParams | 是 | 回调函数集合 |

IMethodParams 说明

| 字段 | 备注 | | ------------ | ------------------------------------------------------------- | | complete | (data) => void complete：为函数且必传，data 为结果数据 |

调用示例

sdk.getOperationScene(
       {
    	 complete: res => {
    		console.log(res)
       }
})

响应结构​

字段类型备注
codeint状态 0: 成功, 其它失败
dataobject返回数据

data 结构说明

字段类型备注
listarray[object]场景列表

data.list 结构说明

字段类型备注
button_listarray[object]触发按钮配置列表
idint场景id
namestring场景名称，存在重复值
tagstring场景标识，项目内唯一

data.list.button_list 结构说明

字段类型备注
window_listarray[object]关联窗口列表
descriptionint按钮描述
tagstring按钮标识
namestring按钮名称
typestring按钮类型, 0点击按钮时，1自动触发

data.list.button_list.window_list 结构说明

字段类型备注
gift_listarray[object]礼包列表
idint窗口id
tagstring窗口标识
namestring窗口名称
versionstring窗口版本

data.list.button_list.window_list.gift_list 结构说明

字段类型备注
idint礼包id
tagstring礼包标识
namestring礼包名称
amountstring价格，购买介质=代币类道具（buy_type.id大于0），此时展示价格
buy_typeobject购买介质
goodsobject计费点，购买介质=法定货币（buy_type.id=-1），此时展示计费点
rx_giftobject望舒礼包信息, 购买介质=无需付费或代币类道具时使用此数据（buy_type.id=-2 或 buy_type.id大于0）

data.list.button_list.window_list.gift_list.buy_type 结构说明

字段类型备注
idint购买介质id， 0未知， -1法定货币， -2无需付费， 正整数为实际为道具id
namestring显示名称，列表接口会返回该字段， 创建、新增接口不需要

data.list.button_list.window_list.gift_list.goods 结构说明

字段类型备注
idint计费点id
goods_namestring计费点名称
goods_tagstring计费点标签
statusint'1启用 -1禁用'
propsarray[object]道具信息

data.list.button_list.window_list.gift_list.goods.props 结构说明

字段类型备注
aliasstring别名
default_imagestring默认图片
default_languagestring默认语言
iconstring列表展示图标
idint道具id
is_permanentint是否永久有效 0 永久 1 非永久
languagestring语言列表
maxstring操作的最大数量
namestring名称
numberint道具数量
tagstring标识
time_limitint非永久有效道具的有效期, 以天为单位
typeint道具类型，0普通道具， 1代币道具
buy_typeobject购买介质

data.list.button_list.window_list.gift_list.goods.props.buy_type 结构说明

字段类型备注
idint购买介质id， 0未知， -1法定货币， -2无需付费， 正整数为实际为道具id
namestring显示名称，列表接口会返回该字段， 创建、新增接口不需要

data.list.button_list.window_list.gift_list.rx_gift 结构说明

字段类型备注
idint望舒礼包id
namestring望舒礼包名称
tagstring望舒礼包标识
listarray[object]包含的望舒道具列表

data.list.button_list.window_list.gift_list.rx_gift.list 结构说明

字段类型备注
aliasstring别名
default_imagestring默认图片
default_languagestring默认语言
iconstring列表展示图标
idint道具id
is_permanentint是否永久有效 0 永久 1 非永久
languagestring语言列表
maxstring操作的最大数量
namestring名称
numberint道具数量
tagstring标识
time_limitint非永久有效道具的有效期, 以天为单位
typeint道具类型，0普通道具， 1代币道具
buy_typeobject购买介质

data.list.button_list.window_list.gift_list.rx_gift.list.buy_type 结构说明

字段类型备注
idint购买介质id， 0未知， -1法定货币， -2无需付费， 正整数为实际为道具id
namestring显示名称，列表接口会返回该字段， 创建、新增接口不需要

商业化信息上报​

参数说明​

| 字段 | 类型 | 是否必填 | 备注 | | ------------ | ----------------- | ---------------- | ---------------- | | params | Params | 是 | 参数 | | callback | IMethodParams | 是 | 回调函数集合 |

Params说明

| 字段 | 类型 | 是否必填 | 备注 | |------------------|-----------------------------------------| ---------------- |----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------| | scene_identifier | string | 否 | 场景标识，data.list[].tag | | scene_name | string | 否 | 场景名称，data.list[].name | | trigger_button_identifier | string | 否 | 场景名称，data.list[].button_list[].tag | | trigger_button_name | string | 否 | 触发按钮名称，data.list[].button_list[].name | | window_identifier | string | 否 | 窗口标识，data.list[].button_list[].window_list[].tag | | window_name | string | 否 | 窗口名称，data.list[].button_list[].window_list[].name | | window_sequence | string | 否 | 窗口展示顺序，data.list[].button_list[].window_list[] 中的数组的key（第几个窗口） | | gift_package | array[object] | 否 | 礼包，data.list[].button_list[].window_list[].gift_package[] |

gift_package 结构说明

字段类型是否必填备注
identifierstring否礼包标识，data.list[].button_list[].window_list[].gift_package[].tag
namestring否礼包名称，data.list[].button_list[].window_list[].gift_package[].name
purchase_mediumstring否购买礼包介质名称，data.list[].button_list[].window_list[].gift_package[].buy_type.name
trigger_button_namestring否触发按钮名称，data.list[].button_list[].name
priceint否礼包名称，data.list[].button_list[].window_list[].gift_package[].amount
billing_pointstring否礼包计费点，data.list[].button_list[].window_list[].gift_package[].goods.goods_tag

IMethodParams 说明

| 字段 | 备注 | | ------------ | ------------------------------------------------------------- | | complete | (data) => void complete：为函数且必传，data 为结果数据 |

调用示例

sdk.reportWindowExposure({
		scene_identifier: 'scene_identifier'，
		scene_name: 'scene_name'，
		trigger_button_identifier: 'trigger_button_identifier'，
		trigger_button_name: 'trigger_button_name'，
		window_identifier: 'window_identifier'，
		window_name: 'window_name'，
		window_sequence: 'window_sequence'，
		gift_package: {
            identifier: 'identifier',
            name: 'name',
            purchase_medium: 'purchase_medium',
            price: 100,
            billing_point: 'billing_point',
        }
	}, {
		complete(res) {
			console.log('reportWindowExposure complete:', res)
		}
})

道具兑换​

商业化窗口中非付费的道具兑换需要使用道具兑换接口。 通过支付接口中的参数区分付费还是道具兑换。

参数说明​

| 字段 | 类型 | 是否必填 | 备注 | | ------------ | ----------------- | ---------------- | ---------------- | | params | Params | 是 | 参数 | | callback | IMethodParams | 是 | 回调函数集合 |

Params说明

字段类型是否必填备注
modeint否扣除发放模式 1 一次性事务扣除, 默认1
scene_tagstring是场景标识
window_idint否扣除发放模式 1 一次性事务扣除, 默认1
window_versionstring是窗口版本
cp_gift_tagstring是cp侧礼包标识，校验道具是否一致
cp_prop_tagstring是cp侧待消费的 道具标识，校验道具是否一致
cp_prop_numberstring是cp侧待消费的 道具数量，校验道具是否一致
item_listarray[object]是待兑换道具列表

item_list 结构说明

字段类型是否必填备注
numberint是待发放的 道具数量
tagstring是待发放的 道具标识

IMethodParams 说明

| 字段 | 备注 | | ------------ | ------------------------------------------------------------- | | complete | (data) => void complete：为函数且必传，data 为结果数据 |

调用示例

sdk.exchangeItemProp({
      "mode": 1，
      "scene_tag": "string",
      "window_id": 0,
      "window_version": "string",
      "cp_gift_tag": "string",
      "cp_prop_tag": "string",
      "cp_prop_number": 0,
      "item_list": [
        {
          "number": 0,
          "tag": "string"
        }
      ]
    }, {
	    complete: (data) => {
			console.log(data)
	}
)

响应结构​

字段类型备注
order_nostring望舒订单号
trade_nostringCP 订单号
windowobject签名的窗口信息

window 结构说明

字段类型备注
window_keystring窗口唯一标识
buttonsarray按钮列表
paymentobject支付配置
rewardsarray奖励配置
signstring窗口签名，商业化道具兑换校验用

payment 结构说明

字段类型备注
typeint支付方式 1 无消耗 2 道具 3 计费点
billing_pointobject计费点配置
propsobject道具配置

payment.billing_point 结构说明

字段类型备注
billing_point_keystring计费点标识

payment.props 结构说明

字段类型备注

numint道具数量

rewards 结构说明

字段类型备注
