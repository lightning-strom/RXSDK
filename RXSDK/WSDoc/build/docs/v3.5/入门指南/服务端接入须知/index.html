服务端接入须知

v3.5 归档文档

此页为 v3.5 归档文档。新项目请查看 v4.x 对应文档。

提示

望舒的绝大部分接口皆采用 HTTP 方式进行通信，但在调用这些接口时需要附加指定的 HTTP Headers 和相关授权参数。

HTTP Headers 定义​

注意

望舒的自定义头并没有采用 "X-" 开头的公共前缀范例，而是以 "ruixue-" 开头。注意：为避免产生歧义，所有望舒头参数全部为"小写"字母。

客户端请求头​

Accesstoken

参数名说明是否必须示例
ruixue-traceid本次请求唯一标识，格式为 UUID v4，当接口出现错误时可将其提供给望舒团队对问题进行快速定位是0e2971af-823a-4298-b7d8-3ef38094b500
ruixue-cpid望舒 CPID，望舒为每个 CP 分配的一个唯一 ID，从 7 位数 1000000 开始递增是1000000
ruixue-productid产品标识，CP 望舒集群内部的产品 ID，由各 CP 自行在后台创建，字符串类型是test
ruixue-channelid渠道标识，CP 望舒集群内部某应用的渠道 ID，由各 CP 自行在后台创建，字符串类型是test
ruixue-platformid客户端类型（1: Android / 2: iOS / 3: H5 / 4: 微信小程序 / 5: web / 6: 鸿蒙 / 10: 望舒服务端 SDK）是2
ruixue-devicecode设备码，通过一系列策略推导/生成的 C 端设备唯一标识，但因各系统种种限制，可能无法获得或不 100% 唯一否abcdefghijklmnopqrstuvwxyz123456
ruixue-language系统语言标识否zh-CN
ruixue-versionSDK 版本号否ios-v2.0.0
ruixue-accesstoken望舒通行证授权令牌，C 端用户登录后由通行证分发，后续在访问需要鉴权的接口时必须携带否eyJhbGciOiJIUzI1NiIs...
ruixue-tzoffset基于 UTC 的时区偏移值，单位为：小时，不指定时默认为 8，表示北京时间的东 8 区否8
ruixue-area地区编码否CN

服务端请求头​

CPSign

参数名说明是否必须示例
ruixue-traceid本次请求唯一标识，格式为 UUID v4，当接口出现错误时可将其提供给望舒团队对问题进行快速定位是0e2971af-823a-4298-b7d8-3ef38094b500
ruixue-cpid望舒 CPID，望舒为每个 CP 分配的一个唯一 ID，从 7 位数 1000000 开始递增是1000000
ruixue-cpts时间戳，CP 服务端发起请求时的毫秒时间戳是1669619948739
ruixue-cpsign请求签名，签名规则：sha1(traceid+cpts+cpkey)是dc87e3db3ec7a0a8edbd470abd58107ae1b66268
ruixue-language语言标识，系统语言标识否zh-CN
ruixue-versiongosdk 的版本号，SDK 版本号（如果为直接调用不需要此字段）否go-v2.0.1
ruixue-tzoffset时区，基于 UTC 的时区偏移值，单位为：小时，不指定时默认为 8，表示北京时间的东 8 区否8
ruixue-productid产品标识，CP 望舒集群内部的产品 ID，由各 CP 自行在后台创建，字符串类型是test
ruixue-servicemark数据域标识，CP 游戏服的标识信息否default
ruixue-region数据域标识，CP 游戏服的分区信息否default
ruixue-cp-role-id数据域标识，CP 游戏服的角色信息否default

服务端回调接口​

注意

望舒系统接入前，请仔细阅读本条款。请确认要使用的功能，必须实现对应的接口！！！ 接口实现完成后，需要在望舒系统（产品管理 > 回调参数配置）调试与配置。
