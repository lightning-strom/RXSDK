版本：v3.5

概览

概述​

望舒开发者服务（Ruixue Developer Services，简称 RDS 服务）旨在帮助开发者降低游戏研发、运营维护等阶段投入的精力和成本。RDS 整合了各项服务，让开发者能够聚焦在游戏核心乐趣的创造上，创作更优秀的游戏，进而促进游戏行业生态的良性循环，最终让开发者与玩家双双受益。

适用范围​

  • 项目组的开发人员
  • 发行团队的相关成员（帮助了解望舒提供的能力与效果）

名词解释​

名词解释
CP项目组、游戏开发团队、内容提供商
CPID望舒为每个项目分配的一个唯一 ID，从 7 位数 1000000 开始递增；
CPKey与 CPID 对应，同 CPID 一起配置在 APIGate 和一些服务端接口上，用于与 CP 服务端相互通信时进行验签
ProductID望舒系统的产品标识，由各项目组自行在望舒后台创建产品，字符串类型
ChannelID望舒系统的渠道标识，由各项目组自行在望舒后台创建渠道，字符串类型
SubChannelID子渠道标识，由各项目组自行在望舒后台创建渠道时，添加子渠道标识，主要用于投放推广或导量的数据统计
DeviceCode设备码，通过一系列策略推导 / 生成的用户端设备唯一标识。但因各系统但种种限制，可能无法获得或不 100% 唯一
AccessToken请求绝大多数望舒接口所需要的访问令牌，该令牌会在通行证登录成功后返回
RefreshToken与 AccessToken 一同在通行证登录后返回，由于 AccessToken 的有效期较短（通常为 1 小时），临界过期或已过期时可通过该参数调用望舒接口刷新
TraceID每次调用望舒接口请求的唯一标识，格式为 UUID v4，当接口出现错误时可将其提供给望舒团队对问题进行快速定位
OpenID望舒通行证为每位玩家在该项目中的唯一标识符，注意：该值大小写敏感；长度为 [32,50] 个字符（建议为 varchar(64) 类型）

功能概览​

RDS 提供以下服务，开发者可以快速集成 Ruixue SDK 来使用：

  • 登录：望舒提供了丰富的、常用的三方登录方式，以及登录 UI 快速集成到游戏当中；查看三方登录方式
  • 支付：望舒提供了市场主流的、安全的三方支付方式；[查看三方支付方式](/docs/v3.5/三方服务/Android 渠道接入说明)
  • 推送：望舒提供了苹果、华为、小米、vivo、OPPO、魅族六种推送服务；
  • 分享：望舒支持让玩家把内容分享至微信或 QQ 等社交软件，从而激活更多玩家；
  • 客服：望舒提供完整的客服 UI ，接入后通过配置可获得常见问题（FAQ）和客服会话能力（机器人 + 人工）；
  • 社交：望舒提供添加好友、自定义好友关系、获取附近的人等社交能力；
  • 定位：目前国内仅支持高德定位，望舒已集成到 SDK 当中，项目组如需使用可以快速接入；
  • 防沉迷：基于望舒账号的实名认证功能，检测玩家行为是否满足中宣部网络游戏防沉迷合规要求；
  • 排行榜：基于望舒系统中设立排行榜功能，可以推动玩家之间的趣味性竞争，从而帮助提升游戏的玩家活跃度；
  • 商业化：可以基于不同人群配置“活动”，也可以为同一人群设置 A / B Test 快速验证活动方案，从而提升转化；
  • 内容安全：望舒提供敏感词过滤、图片审核能力，避免涉黄、涉政等不良场景的出现；
  • 即时通讯：可以快速实现单聊、群聊、频道等多种应用场景；
  • 版本检查：登录游戏前检查当前版本是否需要更新，支持大版本更新、热更等场景；
  • 法务条款：根据不同渠道要求，配置相关法务条款以及满足合规要求（未成年保护等）；
  • 广告投放：支持广点通、今日头条、快手等渠道的广告批量分发，以及投放策略定制与监控；
  • 数据分析：望舒提供大数据分析平台，运营人员可以通过常见模型快速分析数据辅助决策；
