RXUIKit

v3.7.4 更新时间 2025-05-26​

功能更新

  • 使用望舒登录 UI 支持配置是否自动弹出实名认证，通过 RXLoginUIModel.needRealAuth 或望舒后台发行渠道管理 配置，优先读取代码配置，RXUIKit -- 3.7.4，参考文档：登录 UI；
  • 实名认证可配置是否可关闭，RXLoginUIModel.canCloseRealAuth 配置，RXUIKit -- 3.7.4，参考文档：登录 UI；
    • 实名认证 UI 接口如有报错请将接口替换为：
    [[RXUIKitService sharedSDK] setRealauthViewWithCanClose:NO complete:^(NSDictionary * _Nonnull response, RX_CommonRequestError * _Nonnull error) {
        if (!error) {
            NSLog(@"%@",response);
        }else{
            NSLog(@"%@",error.responesObject);
        }
    }];

  • 实名认证新增快速认证模式，在同一企业下其他游戏已进行过实名认证的账号可以不传姓名、身份证号直接认证，该账号是否符合快速认证判定条件未：未实名（attr 首位不为 1）且 有脱敏身份信息（ext 中 realname、idcard），attr 和 ext 从登录返回数据获取，参考文档：[实名认证](/docs/v3.5/登录（通行证）/Android 登录API/快速接入)；
