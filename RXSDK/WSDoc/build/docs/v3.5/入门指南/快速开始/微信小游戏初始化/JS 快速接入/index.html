JS 快速接入

准备工作​

请登录望舒系统初始化相关服务，如果还没有望舒账号请查看准备工作说明。 望舒系统地址，可登录企业管理后台 > 已部署项目中查看。

环境要求​

  • 基础库最低版本：2.25.4，最高版本请选择稳定版本

SDK 集成​

提示

基础包与全量包区别，基础包不包含以下相关接口：

1、客服-帮助中心 2、排行榜 3、社交-除了定位相关接口

提示

对微信提供的wx API 进行统一的包装、扩展

外部代码可以通过Sdk类的实例方便地调用wx对象原本的功能，同时在函数属性存在冲突时进行了备份和处理逻辑，如Sdk与wx函数名存在冲突，分别在 wx对象和 Sdk 类的原型上以 ori 前缀加上原属性名创建新属性，其值为新函数，调用该新函数时会将调用传递给 wx 对象原始函数；若不存在同名属性，则直接将 Sdk 类的原型上对应属性设置为新函数，调用时同样传递给 wx 对象原始函数

const sdk = new Sdk();

// 例1：由于sdk内部存在与wx同名的方法login，所以存在sdk.orilogin与wx.login、wx.orilogin等价，sdk.login有另外的逻辑处理
sdk.orilogin()
wx.login()
wx.orilogin()

// 例2： 由于sdk内部没有与wx同名的方法decode，所以只存在sdk.decode与wx.decode等价
wx.decode()
sdk.decode()

点击下载 SDK 最新版本，下载微信小游戏 SDK

SDK 初始化​

提示

初始化为异步调用，失败将不能使用 SDK 功能，请注意处理调用逻辑。

初始化 SDK 时需传入httpDNSServiceId 参数则请求开启支持使用HttpDNS 处理请求。 当微信请求返回错误信息包含ERR_CONNECTION_TIMED_OUT ERR_NAME_NOT_RESOLVED时开启使用HttpDNS 处理重新进行请求。

初始化 SDK 时需传入 productId、channelId、cpid、baseUrlList 参数信息。

参数参数类型是否必传描述
productIdstring是产品 id，望舒游戏发行平台创建产品，查看使用说明。
channelIdstring是渠道 id，望舒游戏发行平台创建渠道，查看使用说明。
cpidstring是CP id，望舒企业管理后台创建项目，查看使用说明。
httpDNSServiceIdstring否HttpDNS 服务商 Id（为空代表不使用 HttpDNS，不为空则使用 HttpDNS 处理请求）
baseUrlListstring[]是请求域名队列，望舒企业管理后台创建项目，查看使用说明。
short_domainstring否短域名（长度要小于16位），当要使用小程序码跳转支付时该字段必填。
logSwitchboolean否望舒接口请求和响应日志打印
timeoutboolean否望舒接口请求超时时间(毫秒) 默认7000毫秒
isSupportGDTReportboolean否是否支持支付广点通上报，默认为true
completefunction是初始化回调函数

接口实例：

// 路径仅为示例，需要传入SDK在项目中的真实路径，如出现引用错误请检查路径是否正确
const channelSdk = require("your path/channelSDK/index.js")
//以下参数为测试参数，需要更换为接入方对应的参数
const sdk = new channelSdk({
    productId: 'test_productId', //产品 id  
    channelId: 'test_channelId', //渠道id
    cpid: 'test_cpId', //CP id
    httpDNSServiceId: 'wxa410372c837a5f26'，
    baseUrlList: ['https://xxxx.com'],//请求域名队列
    complete: (data) => {
        console.log('init complete: ', data)
        if (data.code === 0) {
            // 初始化成功
        }
    },
})

响应结构​

| 字段 | 类型 | 备注 | | ------------ | ------------ | ---------------- | | code | number | 0 : 表示成功，2001：初始化失败 |

接入功能​

SDK 提供了众多功能。请在初始化 SDK 后，根据项目需要，参考相应功能的文档，接入相应功能。 绝大多数游戏都会接入望舒登录，所以我们推荐从这一功能开始。

投放广点通上报​

官方文档：广点通

注意

使用 sdk 回传必须先进行 [配置窗口期参数](/docs/v3.5/入门指南/快速开始/微信小游戏初始化/JS 快速接入)

在微信后台配置安全域名:https://api.datanexus.qq.com 一定要在小游戏发布前配置好，避免缓存原 因导致安全域名不能及时生效,影响数据上报。

提示
  1. 望舒sdk使用腾讯广告小游戏SDK进行上报使用自动采集，自动采集行为说明
  2. 小游戏启动、注册、沉默唤起等非自动采集行为望舒sdk会自动上报无需cp上报
  3. 创角、游戏等级提升、收藏小游戏、分享小游戏、支付完成、浏览商城、浏览活动、完成新手引导等非自动采集行为需cp方自行上报
  4. 望舒sdk v3.9.54版本以上使用腾讯广告小游戏SDK进行上报需要额外引入tencent-sdk.js文件，tencent-sdk.js 在网盘目录中，用法实例如下
// 1、将tencent-sdk.js 放入打包后的游戏根目录下
// 2、在游戏引擎打包好后的game.js中顶部引用tencent-sdk.js

// 打包后的game.js

import { SDK } from './tencent-sdk'

// 是否打开调试模式, 建议仅在调试期间开启
SDK.setDebug(true)

wx.TencentSDK = SDK

收藏上报广点通​

提示

在用户收藏小游戏的时候上报，操作为点击右上角三个点拉起弹层 必须在初始化成功后调用。

调用示例

sdk = new Sdk(
		{
			productId: 'test',
			channelId: 'test',
			cpid: '114',
            baseUrlList: ['https://cn-api-test.ruixuecloud.com'],
			complete: (data) => {
			    // 右上角三个点
                wx.onAddToFavorites(() => {
                  sdk.reportAddToFavorites('default')
                })
            }
        }
)

分享上报广点通​

提示

在用户分享小游戏的时候上报， 仅右上角三个点分享（包括转发给朋友、分享到朋友圈），其他分享方式无需上报。必须在初始化成功后调用。

调用示例

sdk = new Sdk(
		{
			productId: 'test',
			channelId: 'test',
			cpid: '114',
            baseUrlList: ['https://cn-api-test.ruixuecloud.com'],
			complete: (data) => {
			    // 右上角三个点分享，type参数值：转发给朋友（APP_MESSAGE）/分享到朋友圈（TIME_LINE）
                wx.onShareAppMessage(() => {
                  sdk.reportShareAppMessage('APP_MESSAGE')
                })
    
                wx.onShareTimeline(() => {
                  sdk.reportShareAppMessage('TIME_LINE')
                })
            }
        }
)

支付上报广点通（废弃）​

提示

  • v3.10.13 以后版本望舒内部缓存公众号支付订单，在从客服支付界面返回游戏后查询缓存订单状态自动上报广点通，或者在用户支付完成后未返回游戏的情况下，在下次登录游戏后查询缓存订单及订单状态进行补报，无需游戏端额外处理 公众号支付发货后上报广点通

  • 注意:

    1. sdk.reportPurchase调用会报错，升级到v3.10.13 以上版本的游戏需要去掉原来在用户使用公众号支付发货后上报广点通的代码

    2. v3.10.13 以前版本在用户公众号支付发货后仍需调用sdk.reportPurchase上报广点通

调用示例

sdk._reportPurchase(600) // 金额（分）

广点通通用上报方法​

参数参数类型是否必传描述
action_typestring是行为名称, 查看行为枚举值。
action_paramobject否为用户行为事件添加自定义属性，类型：Object。

调用示例

提示
  1. 行为参数 action_param 是【Key-Value】类型；Key只可以为String类型，只能包含字母、数字和下划线，必须以字母开头，长度不能超过255；Value可以是String/Number/Boolean/Object其中一种，当Value为Object时，它的元素只能为String/Number/Boolean中的一种。
  2. action_param参数中支持传一个自定义行为ID，参考key为【outer_action_id】，仅付费行为担心重复上报才需要传此参数，值建议用订单id。

✧

sdk.reportGdt('QUEST',{
    outer_action_id: "pay_20240804_789",
    product_id: 101,
    amount: 9.9
})

接收红包​

参数说明​

| 字段 | 类型 | 是否必填 | 备注 | | ------------ | ------------------ | ---------------- | ---------------- | | params | IParams | 是 | 参数 | | callback | IMethodParams | 是 | 回调函数集合 |

IParams说明

| 字段 | 类型 | 是否必填 | 备注 | | ------------ | ------------ | ---------------- | ------------------------------------------------------------------------- | | mchId | string | 是 | 商户号，由微信支付生成 | | appId | string | 是 | 商户绑定的AppID（企业号corpid即为此AppID） | | package | string | 是 | 对应发起转账接口应答参数中的 package_info |

IMethodParams 说明

| 字段 | 备注 | | ------------ | ------------------------------------------------------------- | | complete | (data) => void complete：为函数且必传，data 为结果数据 |

调用示例

sdk.requestMerchantTransfer(
  {
   mchId: 'xxxx',
   appId: 'xxxxx',
   package: 'xxxx'
  },
  {
    complete: (res) => {
        console.log(res)
    },
  }
);

成功响应​

| 字段 | 类型 | 备注 | | ------------ | ------------------ | ---------------- | | code | number | 0 成功 | msg | string | 错误消息

订阅消息​

调起客户端订阅消息界面，返回用户订阅消息的操作结果。当用户勾选了订阅面板中的 “总是保持以上选择，不再询问” 时，或是点击了订阅面板中 “拒绝，不再询问” 时，模板消息会被添加到用户的小程序设置页，用户可以在设置页面进行管理。

参数说明​

| 字段 | 类型 | 是否必填 | 备注 | | ------------ | ------------------ | ---------------- | ---------------- | | params | IParams | 是 | 参数 | | callback | IMethodParams | 是 | 回调函数集合 |

IParams说明

| 字段 | 类型 | 是否必填 | 备注 | | ------------ | ------------ | ---------------- | ------------------------------------------------------------------------- | | tmplIds | string[] | 是 | 需要订阅的消息模板的 id 的集合，最多支持传入三个 tmplId |

IMethodParams 说明

| 字段 | 备注 | | ------------ | ------------------------------------------------------------- | | complete | (data) => void complete：为函数且必传，data 为结果数据 |

调用示例

const tmplIds = ["MSGxx", "MSGxx"]
sdk.requestSubscribeMessage(
  {
   tmplIds
  },
  {
    complete: (res) => {
        console.log(res)
    },
  }
);

成功响应​

| 字段 | 类型 | 备注 | | ------------ | ------------------ | ---------------- | | code | 0 | 0 代表订阅成功 | data | 订阅消息[TEMPLATE_ID]集合 | TEMPLATE_ID为模板 id

TEMPLATE_ID 说明

| 字段 | 说明 | | ------------ | ------------ | | accept | 用户同意订阅该条 id 对应的模板消息 | | reject | 用户拒绝订阅该条 id 对应的模板消息 | | ban | 表示已被后台封禁 | | fail | 表示该条 id 对应的模版消息授权失败 |

设置自定义返回错误消息​

提示

规则 1：根据错误码直接读取对应提示替换 msg；

规则 2：如果表中有 default 的 key，将未配置的错误码 msg 统一替换为 default 的 value；

规则 3：$code$ $thirdcode$ $thirdmsg$ 为模板占位符，分别代表sdk接口默认返回code thirdcode thirdmsg

以上规则仅适用于调用了 setErrorMsg 接口，未调用保持sdk原有规则默认返回，映射键值对中key 对应 value 不能为空字符串，否则该对映射不生效

调用示例

// 同步函数
sdk.setErrorMsg({
   4001: 'cancel pay $code$',
   2001: 'init fail',
   default: 'default $code$ $thirdcode$ $thirdmsg$'
})
// 返回示例 1

// sdk接口错误默认返回:
{
    code: 4001, // sdk接口返回错误码
    msg: '取消支付', // sdk接口返回错误信息
    thirdcode： -2, // 三方api返回错误码
    thirdmsg： '微信取消支付' // 三方api返回错误信息
}

// 设置setErrorMsg后cp接收sdk返回如下:
{
    code: 4001,
    msg: 'cancel pay 4001',
    thirdcode： -2,
    thirdmsg： '微信取消支付'
}
// 返回示例 2

// sdk接口错误默认返回:
{
    code: 4002,
    msg: '支付错误',
    thirdcode： -1,
    thirdmsg： '微信支付错误'
}

// 设置setErrorMsg后cp接收sdk返回如下:
{
    code: 4002,
    msg: 'default 4002 -1 微信支付错误',
    thirdcode： -2,
    thirdmsg： '微信支付错误'
}

// post 请求
sdk.requestInstance({
    url: '望舒接口',
    method: 'post',
    data: {},
  }).then(res => {
    console.log('requestInstance', res)
})

// get 请求
sdk.requestInstance({
    url: '望舒接口',
    method: 'get',
    params: {},
  }).then(res => {
    console.log('requestInstance', res)
})
