快速开始

准备工作​

请登录望舒系统初始化相关服务，如果还没有望舒账号请[查看准备工作说明]请登录望舒系统初始化相关服务，如果还没有望舒账号请查看准备工作说明。 望舒系统地址，可登录企业管理后台 > 已部署项目中查看。

环境要求​

  • 基础库 2.8.10 或更高版本； 且 支付宝客户端 10.3.90 或更高版本
  1. 点击下载 SDK 最新版本，下载 支付宝小游戏 SDK
  2. 把 SDK 导入项目工程中

SDK 初始化​

提示

初始化为异步调用，失败将不能使用 SDK 功能，请注意处理调用逻辑。

初始化 SDK 时需传入 productId、channelId、cpid、baseUrlList 参数信息。

参数参数类型是否必传描述
productIdstring是产品 id，望舒游戏发行平台创建产品，查看使用说明。
channelIdstring是渠道 id，望舒游戏发行平台创建渠道，查看使用说明。
cpidstring是CP id，望舒企业管理后台创建项目，查看使用说明。
baseUrlListstring[]是请求域名队列，望舒企业管理后台创建项目，查看使用说明。
completefunction是初始化回调函数

接口实例：

// 路径仅为示例，需要传入SDK在项目中的真实路径，如出现引用错误请检查路径是否正确
const channelSdk = require("your path/channelSDK/index.js")
//以下参数为测试参数，需要更换为接入方对应的参数
const sdk = new channelSdk({
  productId: '1', //产品 id  
  channelId: '818', //渠道id
  cpid: '1000049', //CP id
  baseUrlList: ['https://ruixue.weiletest.com'],//请求域名队列
  complete: (data) => {
    console.log('init complete: ', data)
    if (data.code === 0) {
      // 初始化成功
    }
  },
})

设置子渠道​

提示

通行证记录来源（分包）、子渠道参数。 必须在 登录 前调用。

参数说明​

| 字段 | 类型 | 是否必填 | 备注 | | ------------ | ------------ | ---------------- | ------------ | | params | string | 是 | 子渠道id |

调用示例

// 同步函数
const result = sdk.setSubChannelId('your sub_channel_id')
console.log('setSubChannelId res: ', result)

响应结构​

成功 code 为 0

设置自定义返回错误消息​

提示

规则 1：根据错误码直接读取对应提示替换 msg；

规则 2：如果表中有 default 的 key，将未配置的错误码 msg 统一替换为 default 的 value；

规则 3：$code$ $thirdcode$ $thirdmsg$ 为动态配置字段，如下所示，最终展示的信息为 支付错误4002

以上规则仅适用于调用了 setErrorMsg 接口，未调用保持原有规则

调用示例

// 同步函数
sdk.setErrorMsg({
   4001: 'cancel pay',
   4002: '支付错误$code$',
   2001: 'init fail',
   default: 'default$code$$thirdcode$'
})

清除自定义返回错误消息​

调用示例

// 同步函数
sdk.clearErrorMsg()

SDK 提供了众多功能。请在初始化 SDK 后，根据项目需要，参考相应功能的文档，接入相应功能。 绝大多数游戏都会接入望舒登录，所以我们推荐从这一功能开始。

接入望舒登录​

请根据开发者指南，登录（通行证） 完成操作。

订阅消息​

唤起客户端小游戏消息订阅界面

订阅界面是根据当前小游戏在 商家平台 配置的消息模板 id 来展示对应消息的订阅选项。

消息订阅分为一次性和长期性： 一次性：使用一次性消息模板订阅，每次向用户发送消息都需要用户在订阅界面点击同意后才可以发送。 长期性：使用长期性消息模板订阅，用户同意订阅后，可以多次向订阅用户发送消息。

参数说明​

| 字段 | 类型 | 是否必填 | 备注 | | ------------ | ------------------ | ---------------- | ---------------- | | params | IParams | 是 | 参数 | | callback | IMethodParams | 是 | 回调函数集合 |

IParams说明

| 字段 | 类型 | 是否必填 | 备注 | | ------------ | ------------ | ---------------- | ------------------------------------------------------------------------- | | entityIds | string[] | 是 | 需要订阅的消息模板的 id 的集合，最多支持传入三个 entityIds。 |

IMethodParams 说明

| 字段 | 备注 | | ------------ | ------------------------------------------------------------- | | complete | (data) => void complete：为函数且必传，data 为结果数据 |

调用示例

const entityIds= ["MSGxx", "MSGxx"]
sdk.requestSubscribeMessage(
  {
   entityIds
  },
  {
    complete: (res) => {
        console.log(res)
    },
  }
);

成功响应​

| 字段 | 类型 | 备注 | | ------------ | ------------------ | ---------------- | | code | 0 | 0 代表订阅成功 | data | 订阅消息[TEMPLATE_ID]集合 | TEMPLATE_ID为模板 id

TEMPLATE_ID 说明

| 字段 | 说明 | | ------------ | ------------ | | accept | 用户同意订阅该条 id 对应的模板消息 | | reject | 用户拒绝订阅该条 id 对应的模板消息 |
