快速接入

v3.5 归档文档

此页为 v3.5 归档文档。新项目请查看 v4.x 对应文档。

提示

区服项目必接：区服接入参考。

准备工作​

请登录望舒系统初始化相关服务，如果还没有望舒账号请查看准备工作说明。 望舒系统地址，可登录企业管理后台 > 已部署项目中查看。

环境要求​

  • Android 5.0（API level 21）或更高版本

隐私权限​

提示

SDK 会获取一些设备相关信息，有些信息会涉及到隐私权限。 部分渠道审核会有限制，请注意相关配置，并在审核模式下进行相关处理。

获取的设备相关信息在部分渠道可能会有审核问题，请根据情况进行审核模式的配置。

  • 设备相关：（imei、androidid、oaid、sn号、主板、系统 boot 版本号、系统定制商、abi、显示屏参数、无线固件版本号、硬件制造商、硬件序列号、硬件名称、主机名、系统用户名、系统编译类型） hash 32 位生成设备码和 oaid。 如需在审核模式下禁用隐私权限请查看 用户隐私协议初始化。 注意：禁用后生成的设备码将会有大概率重复！
  • 隐私相关：获取剪贴板内容、接入了定位功能需要获取定位权限。

用途​

名称备注
设备码设备唯一标识，用于生成游客账号、大数据筛选条件
oaid/caid广告标识，用于媒体平台投放归因

我们如何使用 Cookie 和同类技术​

登录前使用客服功能会随机生成了一个字符串用于标识匿名用户，以便该匿名用户下次再使用客服时获取之前的聊天记录。

SDK 集成​

自动化集成（推荐）​

  1. 配置 SDK 依赖：在 app/build.gradle 文件的 dependencies 块中引用望舒 SDK 依赖 implementation 'com.ruixue:库名称:${ version }'，此处的 ${version} 为对应的 SDK 版本号，最新${version}版本请从 更新日志 中查看。
  2. 渠道库 ，以下库单选 (必接一个) 参考 三方服务->渠道接入说明
  3. 组件库 库可多选(可接多个) 参考三方服务对应三方组件库。

混淆配置​

在应用级根目录下打开混淆配置文件proguard-rules.pro，加入排除 SDK 的混淆配置

-keep class com.ruixue.** { *; }

SDK设置​

设置用户隐私相关功能​

  • SDK 初始化会读取 AndroidID、OAID、IMEI、MAC 地址等敏感唯一标识信息。
  • 主要用途：设备码生成，游客登录，买量归因等接口。

设置 SDK敏感信息采集开关​

注意 ：默认为开启采集， 如需关闭采集，请在SDK 初始化接口前调用关闭敏感信息采集开关接口关闭采集

关闭敏感信息采集可能导致问题

  1. 设备码生成出现大概率重复，禁用后一旦生成设备码再次取消禁用也不会重新生成设备码，需要卸载重装。
  2. 因游客账号使用设备码生成，可能导致游客账号重复(不同设备生成同一账号)或卸载重装产生新游客。
  3. 因无法获取设备唯一标识，媒体买量归因成功率大大降低。
  4. 自 SDK v3.3.9 版本起 ，关闭敏感信息采集无法再使用游客登录。
/**
 * @param disabled 是否关闭敏感信息采集， imei mac 地址等，关闭后相关信息不再采集
 */
RuiXueSdk.disableReadSensitiveInfo(true);

通知 SDK 已同意隐私协议（必须）​

  • 使用自定义隐私时，请调用此接口通知 sdk 已同意隐私协议， 使用 sdk 内置隐私窗口时无需调用此接口。
  • 用户需要同意隐私弹窗后，才使用 SDK 权限，在用户同意自定义隐私协议之后调用此接口。
  • 接入三方渠道时，需要每次启动都要调用。
//通知 SDK 已同意隐私协议
RuiXueSdk.setPrivacyAgree(new PrivacyCallback() {
    @Override
    public void onPrivacyAgree(boolean userClick) {
       //如果使用 sdk 的隐私，需要在此后再初始化三方 sdk
    }
});

//调用示例

设置自定义错误消息提示​

提示

规则 1：根据设置的错误码直接读取对应提示替换 msg； 规则 2：如果设置中有 default 的 key，将未配置的错误码 msg 统一替换为 default 的 value； 规则 3：$code$ $msg$ $thirdcode$ $thirdmsg$ 为模板占位符，使用后将分别被替换为sdk接口默认返回code msg thirdcode thirdmsg

以上规则仅适用于调用了 setErrorMsg 方法，未调用此方法，则返回sdk默认提示信息，映射键值对中key 对应 value 不能为空字符串，否则该对映射不生效

接口原型

/**
*设置自定义错误码信息
* @param customErrorMsg 设置自定义错误码的字典
*/
public static void setErrorMsg(Map> customErrorMsg)

数据结构 错误码设置的参数形式，应按照语言进行分类设置，无需将提示的语言类型配置齐全，为方便未来扩展语言结构，设置的数据结构例如：

{
    en:{
            "3001":"error1",
            "3002":"error2"
        }
    zh:{
            "3001":"错误1",
            "3002":"错误2"
    }
}

调用示例

Map> map = new HashMap<>();
Map zh = new HashMap<>();
zh.put("2002", "自定义消息 $code$$thirdcode$$thirdmsg$");
zh.put("2000", "");
zh.put("default", "$msg$:$code$");

Map en = new HashMap<>();
en.put("2002", "custom error $code$$thirdcode$$thirdmsg$");
en.put("2000", "error demo ");
en.put("default", "$msg$:$code$");
map.put("zh", zh);
map.put("en", en);

RuiXueSdk.setErrorMsg(map);

SDK 初始化（必须）​

::: tip 初始化 SDK 时需传入 productId、channelId、cpid、baseUrlList 参数信息。

  • productId、channelId 在望舒游戏发行平台获取（创建产品或渠道），查看使用说明。
  • cpid、baseUrlList 在望舒企业管理后台获取（创建项目），查看使用说明。
  • 初始化为异步调用，失败将不能使用 SDK 功能，请注意处理调用逻辑。

客户端可单独设置初始化参数，不执行 激活、生成设备码、获取隐私权限、获取剪贴板 等操作，可用于调用某些不依赖于隐私的接口（如获取法务信息接口等），此方法为可选，为保证能够正常使用 SDK 功能，原有初始化接口仍需调用； :::

接口原型

* 使用配置初始化sdk

openRacing 说明​

baseUrlList 数量为 1 时 不生效。 开启竞速模式：当 baseUrlList 有多个时，根据网络请求响应速度对数组进行排序，后续 SDK 内部网络请求根据排序后的数组使用对应域名。 关闭竞速模式：当 baseUrlList 有多个时，SDK 内部网络请求根据数组顺序使用对应域名。

接入功能​

SDK 提供了众多功能。请在初始化 SDK 后，根据项目需要，参考相应功能的文档，接入相应功能。 绝大多数游戏都会接入望舒登录，所以我们推荐从这一功能开始。

SDK 通用回调说明​

所有接口 RXJSONCallback 类型回调提供额外RXRequestCallback扩展调用方式,可替换RXJSONCallback 使用。 RXRequestCallback回调不区分成功失败, 通过code 错误码自行判断成功失败，错误说明参照服务器错误表。

调用示例

RXRequestCallback rxcallback = new RXRequestCallback() {
    @Override
    public Map onClickHandle(Map params) {
        return params;
    }

    /**
     *
     * @param jsonObject code 错误码
     *                   msg  错误消息 为空时不返回
     *                   data 响应数据 为空时不返回
     */
    @Override
    public void onResponse(JSONObject jsonObject) {
            showLog(jsonObject.toString());
    }
    @Override
    public void onError(RXException e) {
        super.onError(e);
    }
};

自定义接口请求​

::: info 强烈建议 项目组实现该接口，可以处理一些紧急的线上事故（不依赖发版）。 :::

接口原型

public interface IRXRequest {
    IRXRequest addHeaders(Map headerMap);
    IRXRequest addHeaders(String key, String value);

    IRXRequest setBody(String jsonStr);
    IRXRequest setBody(JSONObject jsonObject);
    IRXRequest setBody(Map bodyMap);
    IRXRequest setRestfulData(boolean restfulData);
    //接口是否需要登录
    IRXRequest setNeedLoggedIn(boolean needLoggedIn);

    void getAsync(@NonNull RXRequestCallback callback);
    void postAsync(@NonNull RXRequestCallback callback);
}

/**
 * 自定义接口请求
 * @param api 接口路径 完整路径或相对路径,注意相对路径不能以/开头 例: v1/operationapi/legal
 * @param bodyMap 接口map参数
 * @return RXRequest 请求对象
 */
IRXRequest createRequest(String api, Map bodyMap);
