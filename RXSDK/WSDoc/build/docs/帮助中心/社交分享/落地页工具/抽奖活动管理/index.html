抽奖活动管理

一、功能介绍​

用于落地页建站工具中九宫格、转盘抽奖控件，提供抽奖相关活动信息管理，比如奖项、概率、抽奖次数等。

二、操作步骤​

点击「新增」按钮，进入新增页面​

点击左侧 社交分享工具 > 落地页工具> 抽奖活动管理 ，进入列表页面。

配置抽奖活动信息​

配置抽奖活动相关信息，主要是抽奖次数设置和奖项配置。 备注

  • 抽奖活动一旦创建则不可修改
  • 兑换码有效时间需要完全包含活动时间
  • 兑换码需要创建「抽奖动态兑换码」，专用于抽奖的一种兑换码类型
  • 各 CP 研发同学提供.该地址用来获取用户唯一标识（openid）。 流程： 1、落地页检查 url 上是否有用户唯一标识（openid） 2、如果没有用户唯一标识（openid）则会跳转到授权地址上，同时以 GET 形式将当前 url 携带过去(URL会经过 urlencode 处理)，例如：https://abc.com?url=urlencode(https://bcd.com/landing.html) 3、授权后，将用户唯一标识（openid）拼接到落地页地址上完成整体流程，例如https://bcd.com/landing.html?openid=xxx
  • 各控件奖项分布如下图

抽奖动态兑换码

登录系统后选择 基础运营工具 > 兑换码管理 点击新建，选择「抽奖动态兑换码」

自动扩充：考虑抽奖消耗兑换码数量较大，当消耗一定数值时系统将自动补充兑换码。
