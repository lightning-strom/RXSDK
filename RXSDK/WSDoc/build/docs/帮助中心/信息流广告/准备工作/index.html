准备工作

一、申请开放平台应用​

广点通​

广点通开放平台地址​

https://developers.e.qq.com/

申请开放平台账号​

进入页面后，点击右上角的注册按钮。

按照页面要求输入对应的信息。其中：

  1. 企业名称 ：需要与投放广告账户的主体名称一致。
  2. 账号类型：选择广告主

创建开放平台应用​

账户申请成功后，点击右上角头像，选择「新建应用」。

按照页面要求输入对应的信息。其中：

信息填写后，点击提交。提交后，该应用处于审核中状态。建议项目组主动联系广点通对接人员，说明情况，让对方帮忙过审。

开放平台应用信息​

点击后台应用，查看详情信息。其中：应用 ID、client_secret，以及 开放平台账户主体名称 需要同步给瑞雪对接人 如需使用 sdk 回传需要 配置窗口期

今日头条（巨量引擎）​

巨量引擎开放平台地址​

https://open.oceanengine.com/

申请开放平台账号​

进入页面后，点击右上角的注册按钮。可选择用邮箱或手机号进行注册。

注册成功后，进入「开发者管理后台」。

按照页面要求输入对应的信息，并最终完成全部 3 个步骤。其中：

  1. 企业主体 ：需要与投放广告账户的主体名称一致。
  2. 开发者类型：选择广告主

创建开放平台应用​

账户申请成功后，进入后台，点击「巨量广告」-【新建应用】。选择「提供第三方服务」-「独立三方站点」

按照页面要求输入对应的信息。其中：

信息填写后，点击提交。提交后，该应用处于审核中状态。建议项目组主动联系今日头条对接人员，说明情况，让对方帮忙过审。

开放平台应用信息​

点击后台应用，查看详情信息。其中：APP_ID、Secret、授权URL，以及 开放平台账户主体名称 需要同步给瑞雪对接人 如需使用 sdk 回传需要 配置窗口期

快手（磁力引擎）​

磁力引擎开放平台地址​

https://developers.e.kuaishou.com/welcome

申请开放平台账号​

进入页面后，点击右上角的登录按钮，使用快手 ID 登录。

登录后，点击右上角的注册为开发者按钮。

按照页面要求输入对应的信息，并最终完成全部 3 个步骤。其中：

  1. 企业主体 ：需要与投放广告账户的主体名称一致。
  2. 开发者角色：选择广告主

创建开放平台应用​

账户申请成功后，进入后台，点击【应用管理】-【添加应用】。

按照页面要求输入对应的信息。其中：

信息填写后，点击提交。提交后，该应用处于审核中状态。建议项目组主动联系快手对接人员，说明情况，让对方帮忙过审。

开放平台应用信息​

点击后台应用的设置按钮，查看详情信息。其中：APP_ID、Secret、授权URL，以及 开放平台账户主体名称 需要同步给瑞雪对接人

二、配置监测链接​

生成监测链接​

进入瑞雪系统后，选择「投放管理」-「基础配置」-「监测链接」

点击【新增监测链接】按钮。

其中：

  • 自投放：公司内部人员操作投放，选择自投放类型。
  • 代投放：让公司外部人员操作投放，选择代投放类型。代投放下，需要选择子渠道信息。子渠道可在「渠道管理」下增加。

新增监测链接后，可在列表中操作复制，直接获取对应投放场景下的链接。注意：小游戏特指微信小游戏。

配置监测链接​

广点通​

投放 APP（IOS&安卓）​
方式一：转化归因中添加监测链接​

配置的监测链接为瑞雪后台生成的链接。

投放微信小游戏​
方式一：转化归因中添加监测链接​

配置的监测链接为瑞雪后台生成的链接。

投放小游戏可使用监测链接的前提，需要投放账户支持选择转化 ID。此功能需要找广点通人员进行加白操作。

今日头条​

今日头条平台需要使用最新版本（即支持项目、广告 2 个层级）。可联系头条人员进行加白操作。

投放 APP（IOS&安卓）​
方式一：创建广告时添加监测链接​

在创建项目时，直接在「有效触点」下填写监测链接。

方式二：事件管理中添加监测链接​

投放微信小游戏​
方式一：创建广告时添加监测链接​

在创建项目时，直接在「有效触点」下填写监测链接。

快手​

投放 APP（IOS&安卓）​
方式一：创建广告时添加监测链接​
