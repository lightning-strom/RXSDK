评价与投诉

一、功能介绍​

支持查看客服会话记录、用户会话评分。可重新设定会话归类、用户评分和设定实际评分。

二、操作步骤​

点击左侧 客服服务管理 > 数据统计> 评价与投诉 进入列表页，可通过上方筛选条件过滤会话记录。 点击列表中的会话归类，可重新设定该会话的类型。 点击列表中的审核状态和评定状态，可审核会话、评定会话。 点击列表中的聊天记录按钮，可查看该会话的聊天记录。滚动可查看更多。一个是人工客服聊天记录，一个是机器人客服记录

AI评定​

1.右上角智能质检开启后支持选择对应的条件，筛选会话进入AI评定队列。同时支持选择历史会话是否进行评定。

提示

历史会话最多支持30天。如果没勾选历史会话则在开启后的会话进入质检队列。
开启智能质检并添加执行条件在关闭质检重新开启后，条件不清空，如需修改请注意。
