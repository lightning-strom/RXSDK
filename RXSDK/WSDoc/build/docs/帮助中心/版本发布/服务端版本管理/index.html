服务端版本管理

功能介绍​

针对棋牌服务端发版，基于瑞雪管理后台配置。

准备工作​

1.配置管理地址​

2.关联棋牌研发后台账号登录​

首次进入该页面需要将棋牌研发后台账号与瑞雪账号进行绑定。

提示

此账号密码为研发后台的账号以及密码，如密码错误请到研发后台去重置，如没有账号也到研发后台去开账号。绑定后无法修改，操作时请绑定自己的账号。

集群管理​

  1. 新建/编辑/删除已有集群。通过集群管理进入。进行集群相关配置并选择集群类型。

服务管理​

  1. 配置正式/测试 环境的服务信息。通过服务管理进入

命令管理​

  1. 新建/编辑/删除已有命令。通过命令管理进入。进行相关配置。新建时选择类型以及分组。
  2. 新建/编辑/删除 命令分组。供创建命令时使用。

通知管理​

  1. 选择指定事件 进行添加事件到通知列表。通过配置通知列表中的事件配置通知到个人或者 群。

配置管理​

  1. 配置所需使用的密钥和域名地址

游戏​

  1. 查看/编辑/删除 历史版本记录以及状态。通过查看记录可以查看版本流转。
  2. 热更新类型新建版本。可以仅执行命令或执行命令并上传。选择的命令是在命令管理中选择类型为游戏的命令。
  3. 重启类型新建版本。可以设置锁定时间。并选择是否有包。
  4. 导流维护类型新建版本。可以设置锁定时间。并选择是否有包。

核心​

  1. 查看/编辑/删除 历史版本记录以及状态。通过查看记录可以查看版本流转。
  2. 仅执行命令类型新建版本。选择的命令是在命令管理中选择类型为核心的命令，可配置等待时间。部署方式分为灰度、全量含灰度、全量三种。其中灰度需要选择服务清单，全量含灰度选择服务后设置灰度时间。
  3. 发布版本类型新建版本。选择的命令是在命令管理中选择类型为核心的命令，可配置等待时间。部署方式分为灰度、全量含灰度、全量三种。其中灰度需要选择服务清单，全量含灰度选择服务后设置灰度时间。
  4. 回退版本类型新建版本。选择服务的节点。并选择对应的部署方式。

web服务​

  1. 查看/编辑/删除 历史版本记录以及状态。通过查看记录可以查看版本流转。已发布的状态不能修改。web服务选择的是集群管理和服务管理的相关配置。
  2. 发布类型新建版本。选择版本和范围
  3. 回退类型新建版本。选择范围和版本
  4. 重启服务类型新建版本。选择服务范围。

测试​

  1. 查看进入到测试环节的版本发布。
  2. 新建/编辑/删除 问题类型
  3. BUG 管理。查看/新建 bug。输入bug详情。
