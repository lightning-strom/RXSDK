版本发布管理

产品介绍​

版本发布管理主要用于维护各个渠道包或模块功能的升级管理，直接影响瑞雪版本检查逻辑。

基本概念​

概念
说明
版本
功能每升级或发布一次，即会生成一个版本。

快速开始​

你可以参考该文档，快速上手 < 新建版本 >，整体流程为： 步骤一：新建版本 步骤二：版本流转

步骤一：新建版本​

里程碑和整包版本不能跳过，强制执行更新。选择时请注意。

步骤二：版本流转​

新建-待提交-开发中-自测/提交测试（可撤回版本）-测试中-通过/驳回-申请发布-立即/延时发布已锁定待发布-立即发布/延时发布-已发布 提交测试后由测试到版本测试管理认领任务

配置版本关联​

为应对不同情况。可以单独配置版本关联。入口：配置版本关联按钮。进入产品包列表 只有产品包，小程序包可配置相关子活动，子游戏，大厅组件的关联配置。

配置打包机​

根据实际使用情况可以相应的回调地址实现自动打包

透传参数配置​

提示

该功能为瑞雪通知CP开始自动打包时进行透传，如果未使用该功能无需关心。

参数名称和参数默认值为通知配置的自动打包的回调接口中的version_params字段中的key和value键值对，所以配置时请注意按照实际使用去配置 1.新建/编辑 透传参数。配置对应的展示名称、参数名称、数据类型、参数类型、参数默认值 2.自动打包时选择状态开启的透传参数列表。可切换透传参数的配置。透传参数中配置的数据类型为布尔或者参数类型为下拉框时可在本次配置中下拉选择需要透传的值

自定义字段​

1.配置自定义字段。根据实际情况配置字段名、和字段类型 2.根据自定义字段配置的 版本类型新建对应的版本更新。就会出现配置的自定义字段。勾选想要配置的自定义字段并进行填写值。配置完成后该版本发布后即可通过检查产品包接口中返回的ext字段进行核对。

H5版本检查​

  1. 瑞雪后台创建H5产品包 (H5大厅)的版本检查。配置版本检查信息。并上传最新的资源文件。
  2. 版本发布后可通过渠道包管理获取最新版本的游戏链接地址。或者通过请求瑞雪接口直接进行跳转，接口文档。
  3. 如果需要获取配置的登录地址或者临时维护公告请接入相关接口。
