子渠道管理

一、功能介绍​

子渠道是在发行渠道的基础上更具有定向性的推广方式。例如，在一个主要发行渠道上设立子渠道，可以根据不同子渠道的特征（地域、兴趣等）有针对性地进行推广。目前子渠道用于三种场景：导量、投放、分包。

导量：通过其它应用程序引流至本产品；
投放：通过监测链接区分投放数据；
分包：通过分包上架到合作媒体。
提示

如果用户是通过带有子渠道标识的用户分享进行注册的用户，也会被标记为该子渠道标识。

二、操作步骤​

点击左侧 渠道管理 > 子渠道管理 进入该功能页面。

新建渠道分组​

点击渠道分组管理按钮，进入渠道分组管理页面。可对已加的分组进行维护和管理。

点击新建按钮创建渠道分组，选择使用场景以及输入渠道分组名称之后保存即可。分组名称不能重复。

新建子渠道​

点击子渠道管理按钮，进入子渠道管理界面。可对已加的子渠道进行维护和管理。 点击 添加子渠道按钮 添加子渠道。目前子渠道用于三种场景：导量、投放、分包。选择对应的使用场景、分组、录入子渠道标识和子渠道名称保存即可。
