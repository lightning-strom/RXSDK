## 获取法务配置

**接口原型**

```java
    void legal(RXRequestCallback callback);
```

**调用示例**

```java
    RuiXueSdk.getRXSdkApi().legal(new RXRequestCallback() {
            @Override
            public void onResponse(JSONObject jsonObject) {
                int code = jsonObject.optInt("code", -1);
                if (code == 0) {
                    JSONObject data = jsonObject.optJSONObject("data");
                    // 根据 data 处理逻辑
                    if (data != null) {
                        LegalData legalData = new Gson().fromJson(data.toString(), LegalData.class);
                    }
                }
            }
        });
```

### 响应参数(JSON)

| **参数** | **类型**                                                                                          | **是否必须** | **说明**                          |
| -------- | ------------------------------------------------------------------------------------------------- | ------------ | --------------------------------- |
| code     | Number                                                                                            | 是           | 响应状态码，0为成功，非0表示出错  |
| msg      | String                                                                                            | 否           | 响应信息，仅在status为非0时不为空 |
| data     | [Data](/docs/v3.5/法务配置/功能介绍) | 否           | key 跟请求的keys对应              |

##### 获取法务信息Data

| **参数**    | **类型**                                                                                                 | **是否必须** | **说明**     |
| ----------- | -------------------------------------------------------------------------------------------------------- | ------------ | ------------ |
| terms       | [Terms](/docs/v3.5/法务配置/功能介绍)       | 是           | 文档类       |
| permissions | [Permissions](/docs/v3.5/法务配置/功能介绍) | 是           | 权限类       |
| minor       | [Minor](/docs/v3.5/法务配置/功能介绍)       | 是           | 未成年人保护 |
