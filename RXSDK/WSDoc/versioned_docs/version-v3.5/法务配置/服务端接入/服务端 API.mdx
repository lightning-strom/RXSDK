## 获取法务条款

> **GET: ** `/v1/operationapi/legal/terms`
> **认证方式: 无**

  

### CURL 示例

```bash
curl --location --request GET '{{接口域名}}/v1/operationapi/legal/terms?product_id=&channel_id=&keys=&position=' \
--header 'ruixue-language: {{语言}}'
```

  

### 请求参数

| **参数**   | **类型** | **是否必填** | **备注**                                           |
| ---------- | -------- | ------------ | -------------------------------------------------- |
| product_id | String   | 是           | 产品id                                             |
| channel_id | String   | 是           | 渠道ID                                             |
| keys       | String   | 是           | 法务条款key，多个使用【,】分隔； 例如：00001,00002 |
| position   | Number   | 是           | 1登录 2用户中心 4其他， 可keys二选一               |

  

**Key列表**

| **key**   | **备注**                  |
| --------- | ------------------------- |
| 00001     | 用户服务协议（预留）      |
| 00002     | 隐私保护指引（预留）      |
| ~~00003~~ | ~~第三方~~~~SDK~~~~目录~~ |
| ~~00004~~ | ~~健康游戏公告~~          |
| ~~00005~~ | ~~适龄提示~~              |
| ~~00006~~ | ~~绿色游戏公告~~          |
| ~~00007~~ | ~~版号信息~~              |
| 00008     | 游戏账号注销条件（预留）  |
| 00009     | 游戏账号注销协议（预留）  |
| ~~00010~~ | ~~其他~~                  |

  

**响应示例**

```json
{
    "data": {
        "00001": { // key 跟请求的keys对应
            "title": "",  // 标题
            "content": "",        // 内容        
        },
    },
    "code": 0
}
```

  

### 响应参数(JSON)

| **参数** | **类型**                                                                                                     | **是否必须** | **说明**                          |
| -------- | ------------------------------------------------------------------------------------------------------------ | ------------ | --------------------------------- |
| code     | Number                                                                                                       | 是           | 响应状态码，0为成功，非0表示出错  |
| msg      | String                                                                                                       | 否           | 响应信息，仅在status为非0时不为空 |
| data     | Map[String][Data](/docs/v3.5/法务配置/功能介绍) | 否           | key 跟请求的keys对应              |

##### 获取法务条款Data

| **参数** | **类型** | **是否必须** | **说明** |
| -------- | -------- | ------------ | -------- |
| title    | String   | 是           | 标题     |
| content  | String   | 是           | 内容     |
