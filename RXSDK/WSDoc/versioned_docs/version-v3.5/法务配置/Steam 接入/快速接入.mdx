## 获取法务信息

**接口原型**

```csharp
/// <summary>
/// 获取法务信息（条款+未成年保护）
/// </summary>
///  code 状态码0时成功 data 返回的数据 msg 错误消息 
void Legal(Action callback)；
```

### 参数说明

无

**调用示例**

```csharp
RuiXueSdk.Legal(callback);
```

### 响应结构

| **参数** | **类型**                                                                                          | **是否必须** | **说明**                          |
| -------- | ------------------------------------------------------------------------------------------------- | ------------ | --------------------------------- |
| code     | Number                                                                                            | 是           | 响应状态码，0为成功，非0表示出错  |
| msg      | String                                                                                            | 否           | 响应信息，仅在status为非0时不为空 |
| data     | [Data](/docs/v3.5/法务配置/功能介绍) | 否           | key 跟请求的keys对应              |

## 获取法务条款

**接口原型**

```csharp
/// <summary>
/// 获取法务条款
/// </summary>
/// 参照参数说明
/// 
void LegalTerms(LegalArgs args, Action callback)
```

**参数说明**

| **参数**   | **类型** | **是否必填** | **备注**                                           |
| ---------- | -------- | ------------ | -------------------------------------------------- |
| product_id | string   | 否           | 产品id                                             |
| channel_id | string   | 否           | 渠道ID                                             |
| keys       | string   | 是           | 法务条款key，多个使用【,】分隔； 例如：00001,00002 |
| position   | string   | 否           | 1登录 2用户中心 4其他， 可keys二选一               |

**调用示例**

```csharp
string[] k = { "00001", "00002", "00003" };
var data = new LegalArgs().SetKeys(k);
RuiXueSdk.LegalTerms(data，callback);
```

### 响应结构

| **参数** | **类型**                                                                                                     | **是否必须** | **说明**                          |
| -------- | ------------------------------------------------------------------------------------------------------------ | ------------ | --------------------------------- |
| code     | Number                                                                                                       | 是           | 响应状态码，0为成功，非0表示出错  |
| msg      | String                                                                                                       | 否           | 响应信息，仅在status为非0时不为空 |
| data     | Map[String][Data](/docs/v3.5/法务配置/功能介绍) | 否           | key 跟请求的keys对应              |

##### 获取法务条款Data

| **参数** | **类型** | **是否必须** | **说明** |
| -------- | -------- | ------------ | -------- |
| title    | String   | 是           | 标题     |
| content  | String   | 是           | 内容     |
