## 功能介绍

快速将即时通讯功能集成到你的游戏中去，借助丰富灵活的 API 轻松实现社交、互动、客服、游戏对战等场景。

## 实用功能

- 创建单聊、群聊、聊天室、频道消息等多种类型对话；
  
- 发送文本、表情、图片、视频、富文本以及其他自定义消息；
  
- 支持消息转发、已读、撤回、重发、阅后即焚、清空本地聊天记录等常用功能；
  
- 支持设置消息最大同步时长，以及黑名单 IP。
