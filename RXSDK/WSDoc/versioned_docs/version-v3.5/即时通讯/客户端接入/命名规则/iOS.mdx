## 命名规则

**用户 ID**

用户 ID 采用字符串类型，格式为 `^[a-zA-Z\d_-]{1,32}$`，即：只能由 `数字`、`大小写字母`、`_`、`-` 组成，长度为 `1-32` 个字符。

**会话 ID**

会话 ID 同样为字符串类型，以支持匿名和客服等多样需求，举例：

- 单聊：`$1$a:b`（用户 ID 为 `a` 的和用户 ID 为 `b` 的用户聊天）；
- 群聊：`$2$testgroup`；
- 自定义单聊：`$3$test`；
- 频道聊天： `$4$testchannel`；

会话 ID 拼接规则

| 会话类型 ID | 功能                                                                                   | 数据拼接规则                                                                                             | 数据拼接示例   |
| ----------- | -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | -------------- |
| 1           | 单聊                                                                                   | $1$ 小用户 ID:大用户 ID 两个用户 ID 之间用半角冒号 `:` 分隔；采用字典序比较两个用户 ID，较小的一方放在前面 | $1$a:b         |
| 2           | 群聊                                                                                   | $2$ 群 ID                                                                                                | $2$testgroup   |
| 3           | 自定义单聊                                                                             | $3$ 自定义标识符                                                                                         | $3$test        |
| 4           | 频道聊天（在线），用户离线时将自动离开所有频道。且，不存储离线消息，不存在于会话列表。 | $4$ 自定义标识符                                                                                         | $4$testchannel |

**注：** 服务器仅保存手动创建的会话，本地数据库保存所有会话。
