## 基本功能

### 同步消息

拉取用户离线后收到的消息或者在全新设备上拉取当前账号的所有消息。消息会通过 **RXIMMessageDelegate** 协议回调函数 `receiveMessage` 通知客户端；同步完成会通过回调函数 `syncMessageFinished` 通知客户端。可以选择在登录成功之后的回调中触发。

**接口原型**

```objectivec
/**
 * 同步消息
 */
-(void)syncMessage;
```

**调用示例**

```objectivec
[[RXIMChatService sharedSDK] syncMessage];
```

### 发送消息

生成RXIMMessage的对象之后，通过此接口进行发送消息操作。客户端需要通过 **RXIMMessageDelegate** 协议里的方法 `sendMessageSuccess` 和 `sendMessageFailure` 来进行消息发送结果的监听。

**接口原型**

```objectivec
/**
 * 发送消息
 * @param sendMessage 发送的消息对象
 * @param completionHandler 返回消息对象，处理本地逻辑用，发送成功以delegate方式回调。
 */
- (void)sendMessage:(RXIMSendMessage * _Nonnull)sendMessage
  completionHandler:(void (^)(RXIMMessage * message,RXIMError *error))completionHandler;
  
#param mark -- 发送结果监听
/**
 * 消息发送成功
 */
- (void)sendMessageSuccess:(RXIMMessage *)msgObj;
/**
 * 消息发送失败
 */
- (void)sendMessageFailure:(RXIMMessage *)msgObj error:(RXIMError *)error;
```

**调用示例**

```objectivec
#pragma mark - 
#pragma mark - 消息发送成功回执
- (void)sendMessageSuccess:(RXIMMessage *)msgObj
{
    NSLog(@"消息发送成功");
    self.msgObj = msgObj;
    [SVProgressHUD showSuccessWithStatus:[NSString stringWithFormat:@"%@ 发送成功",msgObj.msgId]];
}

#pragma mark - 消息发送失败回执
- (void)sendMessageFailure:(RXIMMessage *)msgObj error:(RXIMError *)error
{
    NSLog(@"消息发送失败");
    [SVProgressHUD showErrorWithStatus:[NSString stringWithFormat:@"code = %ld errMsg = %@",error.code,error.developerMessage]];
}
```

      NSLog(@"");

### 接收消息

当收到服务器发来的消息时，可以通过此接口对其进行处理，如您可以RXIMMessage中的RXIMMessageType来区分消息类型用于不同场景。接收消息会通过 **RXIMMessageDelegate** 协议回调函数 `receiveMessage` 通知客户端。

**接口原型**

```objectivec
/**
 * 消息接收
 */
- (void)receiveMessage:(NSArray *)msgs;
```

**调用示例**

```objectivec
#pragma mark - 
#pragma mark - 消息接收回执
- (void)receiveMessage:(NSArray *)msgs
{
    NSLog(@"接收消息");
    self.msgObj = msgs.lastObject;
    for (RXIMMessage *msg in msgs) {
        self.msgCount++;
        NSLog(@"%@", [NSString stringWithFormat:@"接收消息%ld成功",(long)self.msgCount]);
    }
    
}
```

### 转发消息

此功能可以将已经成功生成的消息进行转发，可选择转发类型，作为新消息发送。

**接口原型**

```objectivec
/**
 * 转发消息
 * @param mids 消息id数组
 * @param receives 会话id数组
 * @param type 转发类型 0：逐条转发 1：合并转发
 * @Param exts 扩展数组
 * @param option 消息选项
 * @param completionHandler 返回消息对象，处理本地逻辑用，发送成功以delegate方式回调。
 */
- (void)forwardMessage:(NSArray * _Nonnull)mids
              receives:(NSArray * _Nonnull)receives
                  type:(NSInteger)type
                   ext:(NSArray * _Nullable)exts
                option:(NSInteger)option
     completionHandler:(void (^)(NSArray *messages,RXIMError *error))completionHandler;
```

#### 参数说明

| **字段** | **类型**  | **是否必填** | **备注**                         |
| -------- | --------- | ------------ | -------------------------------- |
| mids     | NSArray   | 是           | 消息 id 数组                     |
| receives | NSArray   | 是           | 会话 id 数组                     |
| type     | NSInteger | 是           | 转发类型 0：逐条转发 1：合并转发 |
| exts     | NSArray   | 否           | 扩展数组                         |
| option   | NSInteger | 是           | 消息选项                         |

**调用示例**

```objectivec
[[RXIMChatService sharedSDK] forwardMessage:mids receives:sessionIds type:contactFrom ext:nil option:option completionHandler:^(NSArray * _Nonnull messages, RXIMError * _Nonnull error) {
    if (!error) {
        [SVProgressHUD showSuccessWithStatus:@"转发成功"];
    }else{
        [SVProgressHUD showErrorWithStatus:@"转发失败"];
    }
}];
```

### 更新本地消息扩展字段

当用户更新个人信息时，可以通过此接口通知本地数据库更新。在更新完成后，本地保存的个人信息将会得到更新。

**接口原型**

```objectivec
/**
 * 更新本地消息扩展字段
 * @param msgIds 消息id数组
 * @param ext 扩展字段
 * @return 更新是否成功
 */
- (BOOL)updateLocalMessageExt:(NSArray * _Nonnull)msgIds
                          ext:(NSDictionary * _Nonnull)ext;
```

#### 参数说明

| **字段** | **类型**     | **是否必填** | **备注**                       |
| -------- | ------------ | ------------ | ------------------------------ |
| msgIds   | NSArray      | 是           | 消息 id 数组（单次最多 20 条） |
| ext      | NSDictionary | 否           | 扩展字段                       |

**调用示例**

```objectivec
[[RXIMChatService sharedSDK] updateLocalMessageExt:@[] ext:@{}];
```
