## 准备工作

在使用 SDK 时，部分接口对设备权限有要求，因此需要使用者在调用涉及以下功能的接口时注意，动态申请权限：

- 具备读、写本地磁盘的接口，如：发送图片、文件等

```xml
android.permission.READ_EXTERNAL_STORAGE
android.permission.WRITE_EXTERNAL_STORAGE
```

- 具备录音的特性的接口，如：发送语音

```xml
android.permission.RECORD_AUDIO
```

注意：如果不使用读取磁盘和录音操作，可以不用集成这些权限

## SDK 集成

**手动依赖接入**

- 配置权限（必填）

```xml
 <!-- 网络相关 -->

```

- 下载 `RXSDK_IM-${version}.aar` 到 libs 路径下；
- 绑定 libs 的引用路径：app->build.gradle，android{'{'}...{'}'}中添加

```groovy
repositories {
    flatDir {
        dirs 'libs'
    }
}
```

- 依赖必要组件

```groovy
implementation fileTree(dir: "libs", include: ["*.jar"])
implementation 'com.squareup.okhttp3:okhttp:3.12.3'//网络请求
implementation 'com.aliyun.dpa:oss-android-sdk:2.9.5'//oss
implementation 'com.google.protobuf:protobuf-java:3.11.1'//PB
implementation 'com.google.code.gson:gson:2.8.6'//json解析
implementation 'org.java-websocket:Java-WebSocket:1.5.3'//websocket依赖

implementation(name: 'RXSDK_IM-${version}', ext: 'aar')//IMCore
```

**自动依赖接入（推荐）**

> gradle 配置参考[接入指南](/docs/v3.5/入门指南/快速开始/Android初始化/快速接入)

```groovy
implementation 'com.ruixue.im:rxsdk_im:$version'
```

### 退出

客户端在下线或者切换账号等情况下需要退出 IM，用来断开 socket 连接切断通信以及清理缓存；再次上线或登录新账户时需要重新调用登录接口来完成 socket 连接进行通信。

**调用示例**

```java
RXIMEngine.logout()
```
