## 基本功能

### 获取会话模块

```
SessionModule sessionModule = RXIMEngine.getInstance().catchModule(ProcessModuleInventory.SESSION);
```

### 创建会话

通过此接口您可以创建一对一/一对多的会话，并在其中发送消息。

**接口原型**

```java
/**
 * 创建会话
 * @param receiverID 接收人的id
 * @param entity 创建会话配置模型
 * @param conversationType 会话类型
 * @param members 成员
 * @param callback 回调
 */
public void createConversation(String receiverID, ConversationExtraEntity entity, ConversationType conversationType, List members, final ResponseCallback.OnCallback callback)
```

**调用示例**

```java
sessionModule.createConversation(ONEPLUS, null, ConversationType.SINGLE, null, new ResponseCallback.OnCallback() {
    @Override
    public void onSuccess(int code, SimpleResponseEntity simpleResponseEntity) {

    }

    @Override
    public void onFailure(int code, String error, Throwable exception) {
        Toast.makeText(SecondActivity.this, error, Toast.LENGTHSHORT).show();
    }
});
```

## 获取会话列表

### 获取服务器会话列表

只有在调用了创建会话接口后，服务器才会记录该数据。并可以通过获取会话列表接口查询。

**接口原型**

```java
/**
 * 获取服务器会话列表
 * @param callback 回调函数
 */
public void fetchConversationList(final ResponseCallback.OnCallback> callback)
```

**调用示例**

```java
sessionModule.fetchConversationList(new ResponseCallback.OnCallback>() {
    @Override
    public void onSuccess(int code, List conversationInfoResponseEntities) {
        if(conversationInfoResponseEntities == null){
            return;
        }
        for(RXSessionEntity entity : conversationInfoResponseEntities){
            LG.e("conversationid = "+entity.getConversationid());
        }
    }

    @Override
    public void onFailure(int code, String error, Throwable exception) {
        Toast.makeText(SecondActivity.this, error, Toast.LENGTH_SHORT).show();
    }
});
```

### 获取本地会话列表
