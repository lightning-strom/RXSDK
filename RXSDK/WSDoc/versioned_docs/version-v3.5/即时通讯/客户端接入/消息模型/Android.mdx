`接收到的消息体`：RXIMMessage，在使用 RXIMSSDK 的时候，产生的所有消息都是基于或是其子类，如：RXCommonNotifyMessage，RXSyncMessage 等

### 消息内容的包装类
发送消息时，需要将消息内容进行包装，然后再调用发送方法，这里以文本消息为例做出说明：
首先，文本消息的内容一定是一个字符串，我们需要将这个字符串作为参数构建出SenderTextMessageEntity的对象，然后再通过ConversationModule#sendMessage()方法进行发送
其他包装类同理，故不再赘述
#### 文本消息

```java
/**
 * @param text 文本内容
 */
public SenderTextMessageEntity(String text) {
    this.text = text;
}
```
