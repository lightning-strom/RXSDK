以下是 CP 服务端请求接口，需要准备好 `cp_id` `product_id` `channel_id` `cp_key` 等参数。
domain：为产品对外域名
请求头：[望舒服务端请求头](/docs/v3.5/入门指南/服务端接入须知)

## 用户登录（仅限服务端使用）

> **POST：**  `/v1/ims/server/login`
> **认证方式:** **[CPSign](/docs/v3.5/入门指南/服务端接入须知)**

### CURL 示例

```bash
curl --location --request POST '{{接口域名}}/v1/ims/server/login' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--header 'Content-Type: application/json' \
--data-raw '{    
    "user_id": "testuser_abc",    
    "product_id": "test",    
    "channel_id": "test",    
    "client_type": 26265
}'
```

### 请求参数（JSON）

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | ----|
| user_id | String | 是   | 用户在 CP 下的唯一标识符
注意：该参数要与 IMS SDK 初始化传入的一致 |     |
| product_id | String | 是   | 客户端产品 ID，即望舒产品管理中的对应值 |     |
| channel_id | String | 是   | 客户端渠道 ID，即望舒产品管理中的对应值 |     |
| device_code | String | 否   | 设备码 |     |
| client_type | Number | 是   | 客户端类型，其是一个位运算结果值 |     |

**请求示例**

```json
{    
    "user_id": "testuser_abc",    
    "product_id": "test",    
    "channel_id": "test",    
    "client_type": 26265
}
```

### 响应参数（JSON）

**HTTP 状态码：**`200 OK`

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | ----|
| code | Number                         | 是   | 响应状态码，0为成功，非0表示出错 | 0   |
| msg | String                         | 否   | 响应信息，仅在status为非0时不为空 |     |
| data | [Token](/docs/v3.5/即时通讯/服务端接入/服务端 API) | 否   | 返回数据对象 |     |

| access_token_expire | Number | 是   | Entry 连接令牌有效期（毫秒），默认为 24 小时 | 86400000 |

## 发送消息

> **POST：**  `/v1/ims/server/sendmessage`
> **认证方式:** **[CPSign](/docs/v3.5/入门指南/服务端接入须知)**

### CURL 示例

```bash
curl --location --request POST '{{接口域名}}/v1/ims/server/sendmessage' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--header 'Content-Type: application/json' \
--data-raw '{   
    "option": 3,   
    "client_type": 256,   
    "type": 2,   
    "uuid": "91a5ca77-ab9d-4dee-b5a6-ac440da22c4b",   
    "sender": "a",   
    "conversation_id": "$1$a:b",   
    "conv_type": 1,   
    "product_id": "test",   
    "channel_id": "test",   
    "content": "{\"text\":\"hahaha\"}",   
    "ext": null
}'
```

### 请求参数（JSON）

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | ----|
| option | Number | 否   | 消息选项（位运算组合 |     |
| client_type | Number | 是   | 客户端类型，其是一个位运算结果值 |     |
| type | Number | 是   | 消息类型 |     |
| sub_type | Number | 否   | 消息子类型，当 type 为 CP 自定义消息时有效， CP 请使用 [ 1 , 1亿 ] |     |
| uuid | String | 是   | 消息发送者在发送时生成的唯一ID，用于去重 |     |
| sender | String | 是   | 发送人 UserID
注意：服务端发送消息时，该值应尽量为空，否则对于群聊或频道聊天要保证其已加入会话 |     |
| receivers | []String | 否   | 接收人列表，单聊必须为空；群聊表示 @ 用户列表；自定义单聊表示实际接收人 UserID 清单； |     |
| conversation_id | String | 是   | 会话 ID |     |
| conv_type | Number | 是   | 会话类型，即会话 ID 两个 $ 中间的值 |     |
| product_id | String | 是   | 产品 ID |     |
| channel_id | String | 是   | 渠道 ID |     |
| content | String | 是   | 消息内容 JSON 字符串 |     |
| ext | Map[String]String | 否   | CP 扩展字段 |     |

**请求示例**

```json
{   
    "option": 3,   
    "client_type": 256,   
    "type": 2,   
    "uuid": "91a5ca77-ab9d-4dee-b5a6-ac440da22c4b",   
    "sender": "a",   
    "conversation_id": "$1$a:b",   
    "conv_type": 1,   
    "product_id": "test",   
    "channel_id": "test",   
    "content": "{\"text\":\"hahaha\"}",   
    "ext": null
}
```

### 响应参数（JSON）

**HTTP 状态码：**`200 OK`

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | ----|
| code | Number                       | 是   | 响应状态码，0为成功，非0表示出错 | 0   |
| msg | String                       | 否   | 响应信息，仅在status为非0时不为空 |     |
| data | [Send](/docs/v3.5/即时通讯/服务端接入/服务端 API) | 否   | 返回数据对象 |     |

##### Send

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | ----|
| msg_id | String | 是   | 消息唯一ID，发送成功后由服务端生成 |     |
| uuid | String | 是   | 发送者在发送时生成的唯一ID，原封不动带回 |     |
| inbox_id | Number | 是   | 当前用户信箱序列号 |     |
| milli_ts | Number | 是   | 毫秒时间戳 |     |

**响应示例**

```json
{    
    "data": {        
        "msg_id": "1552973976152571904.$1$a:b",        
        "uuid": "91a5ca77-ab9d-4dee-b5a6-ac440da22c4b",        
        "inbox_id": 123,        
        "milli_ts": 1659061339059    
    },    
    "code": 0
}
```


| msg | String | 否   | 响应信息，仅在status为非0时不为空 |     |
