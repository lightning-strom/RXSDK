## 激励广告

### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params
   | IAd
           | 是
           | 参数
         |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |

> IAd 说明

| **字段**
 | **类型**
 | **是否必填**
 | **备注**
                                                                                    |
| ------------ | ------------ | ---------------- | ----------------------------------------------------------------------------------------------- |
| adUnitId
 | string
   | 是
           | 广告单元 id
                                                                                 |
| isCheck
  | boolean
  | 否
           | 是否仅检测能否拉取广告, 而不显示
`ture` 表示仅检测能否拉取广告，返回结果包含激励广告实例
 |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**

```javascript
sdk.rewardedVideoAd(
  {
    adUnitId: "adunit-4de541945b96fxxx",
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);
```

**响应示例**

```javascript
{
    "code": 0,
    "isEnded": false
    "ad": {load: ƒ, show: ƒ, onClose: ƒ, offClose: ƒ, onError: ƒ, …},
    "adUnitId": "81d0635de0cabb5dc47447a2cea353f3",
    "isCheck": true
}
```

### 响应结构

| **字段**
 | **类型**
    | **备注**
                                                                                                                            |
| ------------ | --------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| code
     | number
      | 0，表示成功
                                                                                                                         |
| isEnded
  | boolean

 | 视频是否是在用户完整观看的情况下被关闭的，true 表示用户是在视频播放完以后关闭的视频，false 表示用户在视频播放过程中关闭了视频
       |
| ad
       | object
      |  激励视频广告组件
请参考 [QQ 小游戏激励视频广告 API ](https://q.qq.com/wiki/develop/game/API/ad/RewardedVideoAd.html)
      |
| adUnitId
 | string
      | 请求的参数，如果传了，原样返回，否则字段不存在
                                                                                      |
| isCheck
  | boolean
     | 请求的参数，如果传了，原样返回，否则字段不存在
                                                                                      |

## banner 广告

::: tip
创建 banner 广告组件。首次调用需填写 left 和 top 值才能正确展示，如需改变位置可再动态调整。传入 adIntervals 可支持自动刷新。

:::

### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params
   | IBannerAd
     | 是
           | 参数
         |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |

> IBannerAd 说明

| **字段**
    | **类型**
   | **是否必填**
 | **备注**
                                                                                                                                                   |
| --------------- | -------------- | ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| adUnitId
    | string
     | 是
           | 广告单元 id
                                                                                                                                                |
| style
       | object
     | 是
           | Banner 广告组件的样式
                                                                                                                                      |
| adIntervals
 | number

 | 否
           | 广告自动刷新的间隔时间，单位为秒，参数值必须大于等于 30（该参数不传入时 Banner 广告不会自动刷新）。
==适用于安卓端 8.6.0 及以上版本，IOS 端能力规划中==
 |
| isCheck
     | boolean
    | 否
           | 是否仅检测能否拉取广告, 而不显示
`ture` 表示仅检测能否拉取广告，返回结果包含 banner 广告实例
                                                            |

> style 说明

| **字段**
 | **备注**
                                                           |
| ------------ | ---------------------------------------------------------------------- |
| left
     | Banner 广告组件的左上角横坐标
                                      |
| top
      | Banner 广告组件的左上角纵坐标
                                      |
| width
    | Banner 广告组件的宽度（横屏情况下该宽度设置不能超过 1/2 屏幕宽度）
 |
| height
   | Banner 广告组件的高度
                                              |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**

```javascript
sdk.bannerAd(
    {
        adUnitId: 'adunit-4de541945b96fxxx',
        style:{
            height: 100
            left: 100
            top: 100
            width: 100
        },
        adIntervals:31
    },
    {
        complete: (data) => {
          console.log(data)
        },
    },
)
```

**响应示例**

```javascript
{
    "code": 0,
    "ad": {load: ƒ, show: ƒ, onError: ƒ, …},
    "adUnitId": "81d0635de0cabb5dc47447a2cea353f3",
    "isCheck": true
}
```

### 响应结构

| **字段**
    | **类型**
 | **备注**
                                                                                                         |
| --------------- | ------------ | -------------------------------------------------------------------------------------------------------------------- |
| code
        | number
   | 0，表示成功
                                                                                                      |
| ad
          | object
   | 激励视频广告组件
请参考 [QQ 小游戏 Banner 广告 API ](https://q.qq.com/wiki/develop/game/API/ad/BannerAd.html)
 |
| adUnitId
    | string
   | 请求的参数，如果传了，原样返回，否则字段不存在
                                                                   |
| isCheck
     | boolean
  | 请求的参数，如果传了，原样返回，否则字段不存在
                                                                   |
| adIntervals
 | number
   | 请求的参数，如果传了，原样返回，否则字段不存在
                                                                   |
| style
       | object
   | 请求的参数，如果传了，原样返回，否则字段不存在
                                                                   |

## 常见错误码(第三方平台侧)

| 错误 code
 | 说明
 |
| ------------------- | -------------------- |
| **1000**
 | 后端接口调用失败
 |
| **1001**
 | 参数错误
 |
| **1002**
 | 广告单元无效
 |
| **1003**
 | 内部错误
 |
| **1004**
 | 无合适的广告
 |
| **1005**
 | 广告组件审核中
 |
| **1006**
 | 广告组件被驳回
 |
| **1007**
 | 广告组件被封禁
 |
| **1008**
 | 广告单元已关闭
 |
