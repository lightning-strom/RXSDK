## 激励广告

### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params
   | IAd
           | 是
           | 参数
         |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |

> IAd 说明

| **字段**
 | **类型**
 | **是否必填**
 | **备注**
                                                                                    |
| ------------ | ------------ | ---------------- | ----------------------------------------------------------------------------------------------- |
| adUnitId
 | string
   | 否
           | 广告单元 id，若传则使用此id，若不传则取埋点对应配置广告单元id
                                                                                 |
| func
 | string
   | 否
           | 埋点标记，可在望舒社交分享-广告管理工具配置
                                                                                 |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**

```javascript
  sdk.rewardedVideoAd(
  {
    adUnitId: "adUnitId-4de541945b96fxxx",
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);
```
**响应示例**

```javascript
{
    "code": 0,
    "isEnded": false
    "adUnitId": "81d0635de0cabb5dc47447a2cea353f3"
}
```
### 响应结构

| **字段**
 | **类型**
    | **备注**
                                                                                            |
| ------------ | --------------- |-------------------------------------------------------------------------------------------------------|
| code
     | number
      | 0，表示成功
                                                                                            |
| isEnded
  | boolean

 | 视频是否是在用户完整观看的情况下被关闭的，true 表示用户是在视频播放完以后关闭的视频，false 表示用户在视频播放过程中关闭了视频
                              |

## 常见错误码(第三方平台侧)

| 错误 code
 | 说明
 |
| ------------------- | -------------------- |
| **200**
 | 通用错误
 |
| **202**
 | 参数错误
 |
| **1001**
 | 无效的广告请求，如未设置广告位ID、Banner广告尺寸无效等
 |
| **1003**
 | 内部错误
 |
| **1004**
 | 广告请求成功，但是服务器没有返回可用的广告素材
 |
| **1100**
 | 广告正在请求中，不能重复发起请求
 |
| **1102**
 | API版本不在广告服务支持范围内
 |
| **1104**
 | 由于网络连接错误导致广告请求失败
 |
| **2000**
 | HMS Core版本过低，不支持设置AppInfo
 |
