## 激励广告

### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params
   | IAd
           | 是
           | 参数
         |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |

> IAd 说明

| **字段**
 | **类型**
 | **是否必填**
 | **备注**
                                                                                    |
| ------------ | ------------ | ---------------- | ----------------------------------------------------------------------------------------------- |
| adUnitId
 | string
   | 否
           | 广告单元 id，若传则使用此id，若不传则取埋点对应配置广告单元id
                                                                                 |
| func
 | string
   | 否
           | 埋点标记，可在望舒社交分享-广告管理工具配置
                                                                                 |
| isCheck
  | boolean
  | 否
           | 是否仅检测能否拉取广告, 而不显示
`ture` 表示仅检测能否拉取广告，返回结果包含激励广告实例
 |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**

```javascript
sdk.rewardedVideoAd(
  {
    adUnitId: "adUnitId-4de541945b96fxxx",
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);
```

**响应示例**

```javascript
{
  "code": 0,
    "isEnded": false
  "ad": {load: ƒ, show: ƒ, onClose: ƒ, offClose: ƒ, onError: ƒ, …},
  "adUnitId": "81d0635de0cabb5dc47447a2cea353f3",
    "isCheck": true
}
```

### 响应结构

| **字段**
 | **类型**
    | **备注**
                                                                                                |
| ------------ | --------------- |-----------------------------------------------------------------------------------------------------------|
| code
     | number
      | 0，表示成功
                                                                                                |
| isEnded
  | boolean

 | 视频是否是在用户完整观看的情况下被关闭的，true 表示用户是在视频播放完以后关闭的视频，false 表示用户在视频播放过程中关闭了视频
                                  |
| ad
       | object
      | 激励视频广告组件
请参考 [vivo 小游戏激励视频广告 API ](https://minigame.vivo.com.cn/documents/#/api/ad/incentive-video-ad)
 |
| adUnitId
 | string
      | 请求的参数，如果传了，原样返回，否则字段不存在
                                                                               |
| isCheck
  | boolean
     | 请求的参数，如果传了，原样返回，否则字段不存在
                                                                               |

## 常见错误码(第三方平台侧)

| 错误 code
    | 说明
                |
|----------------|-----------------------|
| **-1**
     | 未知原因
              |
| **-2**
     | 外部SDK错误
           |
| **-3**
     | 广告拉取太频繁 广告拉取时间间隔建议在1s以上
          |
| **1**
      | 应用id或者广告位id配置信息不存在
          |
| **2**
      | 无效的广告位id
          |
| **3**
      | 广告位被冻结
              |
| **4**
      | 没有对应的广告
              |
