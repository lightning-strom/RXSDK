## 激励广告
:::tip
由于 4399 激励广告默认是打开后不可关闭，如果想要看广告时可提前关闭，需要联系 4399 对接人来修改，因为这个配置在 4399 自己的后台中，并没有暴露给开发者
:::

### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**

```javascript
sdk.rewardedVideoAd(
  {
    complete: (data) => {
      console.log(data);
    },
  }
);
```

**响应示例**

```javascript
{
  "code": 0,
  "isEnded": false
  "msg": 'error message',
}
```

### 响应结构

| **字段**
 | **类型**
    | **备注**
                                                                                                |
| ------------ | --------------- |-----------------------------------------------------------------------------------------------------------|
| code
     | number
      | 0，表示成功
 -1, 失败
                                                                                                |
| isEnded
  | boolean

 | 视频是否是在用户完整观看的情况下被关闭的，true 表示用户是在视频播放完以后关闭的视频，false 表示用户在视频播放过程中关闭了视频
                                  |
| msg
 | string
      | 失败的原因
   |
