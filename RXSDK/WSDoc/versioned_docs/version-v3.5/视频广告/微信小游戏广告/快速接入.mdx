## 激励广告

* ( ) js::init1
* ( ) Unity::init2

**响应示例**

```javascript
{
    "code": 0,
    "isEnded": false
    "ad": {load: ƒ, show: ƒ, onClose: ƒ, offClose: ƒ, onError: ƒ, …},
    "adUnitId": "81d0635de0cabb5dc47447a2cea353f3",
    "isCheck": true
}
```

### 响应结构

| **字段**
 | **类型**
    | **备注**
                                                                                                                            |
| ------------ | --------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| code
     | number
      | 0，表示成功
                                                                                                                         |
| isEnded
  | boolean

 | 视频是否是在用户完整观看的情况下被关闭的，true 表示用户是在视频播放完以后关闭的视频，false 表示用户在视频播放过程中关闭了视频
       |
| ad
       | object
      | 激励视频广告组件
请参考 [微信小游戏激励视频广告 API ](https://developers.weixin.qq.com/minigame/dev/api/ad/RewardedVideoAd.html)
 |
| adUnitId
 | string
      | 请求的参数，如果传了，原样返回，否则字段不存在
                                                                                      |
| isCheck
  | boolean
     | 请求的参数，如果传了，原样返回，否则字段不存在
                                                                                      |

## 常见错误码(第三方平台侧)

| 错误 code
 | 说明
 |
| ------------------- | -------------------- |
| **1000**
 | 后端接口调用失败
 |
| **1001**
 | 参数错误
 |
| **1002**
 | 广告单元无效
 |
| **1003**
 | 内部错误
 |
| **1004**
 | 无合适的广告
 |
| **1005**
 | 广告组件审核中
 |
| **1006**
 | 广告组件被驳回
 |
| **1007**
 | 广告组件被封禁
 |
| **1008**
 | 广告单元已关闭
 |
