## 激励广告

### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params
   | IAd
           | 是
           | 参数
         |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |

> IAd 说明

| **字段**
    | **类型**
 | **是否必填**
 | **备注**
                                               |
|---------------| ------------ | ---------------- |----------------------------------------------------------|
| posId
 | string
   | 是
           | 广告单元 id
                                                                                 |
| cid
 | string
   | 是
           | 渠道cid，由渠道提供
                                                                                 |
| bid
 | string
   | 是
           |渠道bid，由渠道提供 
                                                                                 |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**

```javascript
sdk.advertisingVideo(
  {
    posId: "广告单元id",
    cid: "渠道cid",
    bid: "渠道bid"
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);
```

**响应示例**

```javascript
{
    "code": 0,
    "msg": "正常播放结束，可以下发游戏奖励",
    "data": {},
}
```

### 响应结构

| **字段**
 | **类型**
    | **备注**
                                                                                                                                                  |
| ------------ | --------------- |-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| code
     | number
      | 0，表示成功
                                                                                                                                                                                                                 |
| msg
     | string
      | 返回信息描述
                                                                                                                                                                                                                 |
| data
     | object
      | 返回相第三方平台侧相关信息,data中包含adType并且adType等于defaultLink时，是兜底广告
                                                                                                                                                                                                                 |

## 常见错误码(第三方平台侧)

| 错误 code
 | 说明
 |
| ------------------- | -------------------- |
| **-1**
 | 未知错误
 |
| **1002**
 | 广告单元失效或过期
 |
| **1003**
 | 三方 SDK 内部错误
 |
| **1004**
 | 广告已被销毁
 |
| **1005**
 | 广告无填充
 |
| **1006**
 | 广告位信息解析失败或限流
 |
| **1007**
 | 广告请求失败
 |
| **1008**
 | 广告数据转换失败
 |
| **1009**
 | 广告创建失败，参数错误
 |
| **1010**
 | 广告展示失败
 |
