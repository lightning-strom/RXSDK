## 激励广告

### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params
   | IAd
           | 是
           | 参数
         |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |

> IAd 说明

| **字段**
    | **类型**
 | **是否必填**
 | **备注**
                                               |
|---------------| ------------ | ---------------- |----------------------------------------------------------|
| adUnitId
 | string
   | 否
           | 广告单元 id，若传则使用此id，若不传则取埋点对应配置广告单元id
                                                                                 |
| func
 | string
   | 否
           | 埋点标记，可在望舒社交分享-广告管理工具配置
                                                                                 |
| isCheck
   | boolean
  | 否
           | 是否仅检测能否拉取广告, 而不显示
`ture` 表示仅检测能否拉取广告，返回结果包含激励广告实例
 |
| destroyAd
 | boolean
  | 否
           | 是否关闭广告时销毁广告组件
`ture` 表示销毁广告组件
        |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**

```javascript
sdk.rewardedVideoAd(
  {
    adUnitId: "adUnitId-4de541945b96fxxx"
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);
```

**响应示例**

```javascript
{
    "code": 0,
    "isEnded": false
    "ad": {load: ƒ, show: ƒ, onClose: ƒ, offClose: ƒ, onError: ƒ, …},
    "adUnitId": "81d0635de0cabb5dc47447a2cea353f3",
    "isCheck": true
}
```

### 响应结构

| **字段**
 | **类型**
    | **备注**
                                                                                                                                                  |
| ------------ | --------------- |-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| code
     | number
      | 0，表示成功
                                                                                                                                                  |
| isEnded
  | boolean

 | 视频是否是在用户完整观看的情况下被关闭的，true 表示用户是在视频播放完以后关闭的视频，false 表示用户在视频播放过程中关闭了视频
                                                                                    |
| ad
       | object
      | 激励视频广告组件
请参考 [抖音小游戏激励视频广告 API ](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/api/ads/rewarded-video-ad/rewarded-video-ad)
 |
| adUnitId
 | string
      | 请求的参数，如果传了，原样返回，否则字段不存在
                                                                                                                                 |
| isCheck
  | boolean
     | 请求的参数，如果传了，原样返回，否则字段不存在
                                                                                                                                 |

## 常见错误码(第三方平台侧)

| 错误 code
 | 说明
 |
| ------------------- | -------------------- |
| **1000**
 | 后端接口调用失败
 |
| **1001**
 | 参数错误
 |
| **1002**
 | 广告单元无效
 |
| **1003**
 | 内部错误
 |
| **1004**
 | 无合适的广告
 |
| **1005**
 | 广告组件审核中
 |
| **1006**
 | 广告组件被驳回
 |
| **1007**
 | 广告能力被禁用
 |
| **1008**
 | 广告单元已关闭
 |
| **20002**
 | 不支持 banner 广告 API
 |
| **120002**
 | 广告发送的次数已达当日上限
 |
