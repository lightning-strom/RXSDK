## 激励广告

### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params
   | IAd
           | 是
           | 参数
         |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |

> IAd 说明

| **字段**
 | **类型**
 | **是否必填**
 | **备注**
                                                                                    |
| ------------ | ------------ | ---------------- | ----------------------------------------------------------------------------------------------- |
| func
 | string
   | 否
           | 埋点标记，可在望舒社交分享-广告管理工具配置，同一埋点只能关联一种广告类型，如需关联多种广告类型请使用[调度方式](/docs/v3.5/分享/分享调度/Android)&tab=&index=1) 
                                                                                 |
| adUnitId
 | string
   | 否
           | 广告单元 id，若传则使用此id，若不传则取埋点对应配置广告单元id
                                                                                 |
| appSid
 | string
   | 是
           | 应用 id
                                                                                 |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**

```javascript
  sdk.rewardedVideoAd(
  {
    adUnitId: "adUnitId-4de541945b96fxxx",
    appSid: "appSid-4de541945b96fxxx",
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);
```
**响应示例**

```javascript
{
    "code": 0,
    "isEnded": false，
    "msg": "正常播放结束，可以下发游戏奖励"
}
```
### 响应结构

| **字段**
 | **类型**
    | **备注**
                                                                                            |
| ------------ | --------------- |-------------------------------------------------------------------------------------------------------|
| code
     | number
      | 0，表示成功
                                                                                            |
| isEnded
  | boolean

 | 视频是否是在用户完整观看的情况下被关闭的，true 表示用户是在视频播放完以后关闭的视频，false 表示用户在视频播放过程中关闭了视频
                              |                                                                      |
## 百度平台获取广告位ID

1.登录[百青藤平台](https://union.baidu.com/bqt/appco.html#/union/slot)。**菜单:应用合作>合作管理>网盟推广>代码位管理**。获取`广告位ID`,`所属应用ID`。
:::tip
如果没有应用需要先在平台建立应用。在创建广告位ID时进行关联。
:::
