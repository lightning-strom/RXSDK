## SDK 集成

**接口原型**

```csharp
/** 增加用户分数
* @param rank_id  字符串本身带有类型信息，格式为：Flag_榜单容量_重置周期_自定义标识（flag是一个int64位标记，用以扩展和规定绑定属性）
* @param score    增加的分数值
* @param callback callback
*/
void AddScore(string rank_id, int score, Action callback);
```

### 参数说明

| **字段** | **类型** | **是否必填** | **备注**        |
| -------- | -------- | ------------ | --------------- |
| rank_id  | string   | 是           | 排行榜 ID       |
| score    | int      | 是           | 增加的分数值    |

**调用示例**

```csharp
string rank_id = "diddd";
int score = 100;
RuiXueSdk.RankingAPI.AddScore(rank_id, score, RXCallback);
```

### 响应结构

**HTTP 状态码：**`200 OK`

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | --- |
| code | Number | 是   | 响应状态码，0为成功，非0表示出错 | 0   |
| msg | String | 否   | 响应信息，仅在status为非0时不为空 |     |

## 获取排行榜列表

**接口原型**

```csharp
/** 获取排行榜列表
* @param rank_id    字符串本身带有类型信息，格式为：Flag_榜单容量_重置周期_自定义标识（flag是一个int64位标记，用以扩展和规定绑定属性）
* @param start_rank 获取排行榜开始排名。取值[1,榜单容量)。可以用于分页加载 1
* @param end_rank   获取排行榜结束排名。取值[1,榜单容量]。可以用于分页加载 2
* @param callback   callback
*/
void GetRankList(string rank_id, int start_rank, int end_rank, Action callback);
```

### 参数说明

| **字段**   | **类型** | **是否必填** | **备注**                                                                                                              |
| ---------- | -------- | ------------ | --------------------------------------------------------------------------------------------------------------------- |
| rank_id    | string   | 是           | 字符串本身带有类型信息，格式为：Flag_榜单容量_重置周期_自定义标识（flag 是一个 int64 位标记，用以扩展和规定绑定属性） |
| start_rank | int      | 是           | 获取排行榜开始排名。取值[1,榜单容量)。可以用于分页加载                                                                |
| end_rank   | int      | 是           | 获取排行榜结束排名。取值[1,榜单容量]。可以用于分页加载                                                                |

**调用示例**

```csharp
string rank_id = "idxxx";
int start_rank = 0;
int end_rank = 20;

RuiXueSdk.RankingAPI.GetRankList(rank_id, start_rank, end_rank, RXCallback);
```

### 响应结构

**HTTP 状态码：**`200 OK`

| **字段** | **类型**                         | **是否必填** | **说明** | **示例** |

| msg | String                         | 否   | 响应信息，仅在status为非0时不为空 |     |
