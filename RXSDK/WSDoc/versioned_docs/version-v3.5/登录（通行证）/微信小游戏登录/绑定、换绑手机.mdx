## 绑定换绑手机

### 获取验证码

#### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params
   | ISendCaptcha
  | 是
           | 参数
         |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |

> ISendCaptcha 说明

| **字段**
 | **类型**
 | **是否必填**
 | **备注**
             |
| ------------ | ------------ | ---------------- | ------------------------ |
| phone
    | string
   | 否
           | 接收验证码的手机号
   |
| purpose
  | string
   | 是
           | 验证码的用途
         |
| auth
  | string
   | 否
           | 是否使用小游戏登录鉴权，默认false，建议设置为true
         |

> purpose 说明

| **字段**
    | **备注**
 |
| --------------- | ------------ |
| bindphone
   | 绑定手机
 |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

#### 调用示例
```javascript
sdk.sendCaptcha(
  {
    phone: "18626656376",
    purpose: "bindphone",
    auth: true
  },
  {
    complete: (data) => {
      console.log(data);
    }
  }
);
```

### 换绑手机号

| **字段**

 |

```javascript

  {
    newphone: "13439093838",
    oldphone_captcha: "1234",
    newphone_captcha: "1234"
  },
  {
    complete: (data) => {
      console.log(data);
    }
  }
);
```

### 获取并绑定手机号（暂时只支持ios）

#### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params
   | IParams
 | 是
           | 参数
         |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |

> IParams说明

| **字段**
 | **类型**
 | **是否必填**
 | **备注**
 |
| ------------ | ------------ | ---------------- | ------------ |
| isRealtime
   | string
 | 否
           | 手机号实时验证，向用户申请，并在用户同意后，快速填写和实时验证手机号，默认false
     |
| phoneNumberNoQuotaToast
   | string
 | 否
           |当手机号快速验证或手机号实时验证额度用尽时，是否对用户展示“申请获取你的手机号，但该功能使用次数已达当前小程序上限，暂时无法使用”的提示，默认展示。默认true
     |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

#### 调用示例

```javascript
sdk.getPhoneNumber({
    isRealtime: false,
    phoneNumberNoQuotaToast: true
  }, {
    complete: (res) => {
      console.log(res);
    }
})
```
