## 望舒通行证API
### 注册

**接口原型**

```csharp
void Register(RegisterArgs args, Action callback)
```

**参数说明**

| **字段** | **类型** | **是否必填** | **说明** |
| --- | --- | ---- | --- |
| username | string | 是 | 用户名 |
| password | string | 是 | 密码 |
| nickname | string | 否 | 昵称 |
| captcha\_code | string | 否 | 使用 `sendCaptcha` 接口获取 |
| avatarUrl | string | 否 | 头像地址 |
| user\_attrs | object | 否 | 设置大数据用户属性，仅对本次登录新注册的用户有效 |
| sex | integer | 否 | 性别,1:男,0:女 |
| migrate\_args | 任意合法的 json 类型, 比如 string, number, array, object | 否 | 账号迁移用的参数, 调用 CP account-query 及 account-queryandbind 接口时透传给 CP. |

**调用示例**

```csharp
    RegisterArgs registerArgs = new()
    {
        type = AccountType.Phone,//手机号类型
        username = usernameFiled.text,// 用户名
        password = passwordFiled.text,//密码
    };

    RuiXueSdk.Register(registerArgs, (code, data, msg) =>
    {
        if (data != null)
        {
            Debug.Log("data= " + data);
            mText.text = data.Tostring();
        }
        else
        {
            Debug.Log("code:" + code + ", msg:" + msg);
            mText.text = "code:" + code + ", msg:" + msg;
        }
    });
```

###  登录
**接口原型**

```csharp
/// <summary>
/// 登录
/// </summary>
/// 登录方式
/// 登录参数
/// 回调
void Login(LoginMethod method, Dictionary keyValuePairs, Action callback)
```

#### 参数说明

| **字段** | **类型** | **是否必填** | **说明** |
| --- | --- | ---- | --- |
| method | string | 否 | 登录方式 （默认 harmony） |
| login\_openid | string | 否 | 上次登录返回的 login\_openid 数据，同时 method 也要使用上次登录获取 login\_openid 时使用的登录方式 |
| user\_attrs | object | 否 | 设置大数据用户属性，仅对本次登录新注册的用户有效 |
| sign\_fields | []string | 否 | 指定对登录成功后返回的特定字段, 使用 CPKEY 计算签名. CP 服务器可重新计算签名并与登录返回的签名比对, 作为对望舒登录数据的校验. 支持的字段包括: nickname, avatar, openid, region, sex, age, 计算签名的逻辑会对指定字段进行排序, 此处传参与顺序无关. |
| migrate\_args | 任意合法的 json 类型, 比如 string, number, array, object | 否 | 账号迁移用的参数, 调用 CP account-query 及 account-queryandbind 接口时透传给 CP. |

**调用示例**

```
string method="hwjos";
Dictionary parm = new()
{
    {"sign_fields",new string[]{"openid"}}
};
RuiXueSdk.Login(method, parm, (code, data, msg) =>
{
    if (data != null)
    {
        Debug.Log("data= " + data.ToJson());
        mText.text = data.ToJson();
    }
    else
    {
        Debug.Log("code:" + code + ", msg:" + msg);
        mText.text = "code:" + code + ", msg:" + msg;
    }
});

```
