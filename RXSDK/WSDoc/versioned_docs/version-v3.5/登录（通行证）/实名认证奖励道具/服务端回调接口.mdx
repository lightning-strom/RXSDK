## 实名奖励

> 类型：同步
> Action: reward_real_auth
> **认证方式：** [CPSign](/docs/v3.5/入门指南/服务端接入须知#服务端请求头)

### 请求参数

| <strong>字段</strong>
 | <strong>类型</strong>
 | <strong>是否必填</strong>
 | <strong>说明</strong>
 |
|-------------------------|-------------------------|---------------------------|-------------------------|
| cp_user_id                | String              | 是                    | 用户游戏 ID     |
| awards                | []Awards              | 是                    | 奖励      |

#### Awards
| <strong>字段</strong>
 | <strong>类型</strong>
 | <strong>是否必填</strong>
 | <strong>说明</strong>
 |
|-------------------------|-------------------------|---------------------------|-------------------------|
| tag                | String              | 是                    | 道具标识     |
| count                | Number              | 是                    | 道具数量     |
| time_limit                | Number              | 是                    | 非永久有效道具的有效期, 以天为单位， 0:永久有效     |

### 请求案例
```res
{
  "cp_user_id":"用户游戏ID",
  "awards":[
    {
      "tag":"RealAuthReward", // 道具标识
      "count":100, // 数量
      "time_limit":1 // 非永久有效道具的有效期, 以天为单位 0:永久有效
    }
  ]
}
```

### 响应参数
| <strong>字段</strong>
 | <strong>类型</strong>
 | <strong>是否必填</strong>
 | <strong>说明</strong>
 |
|-------------------------|-------------------------|---------------------------|-------------------------|
| code          | Number             | 是                    | 响应状态码0为正常，其他为异常              |
| msg          | String              | 是                    |  描述              |
