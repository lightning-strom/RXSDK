## 获取福利码

### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |
| autoRefresh
   | Boolean
    | 否
           | 默认false，是否自动刷新，true自动刷新并在complete回调中返回福利码数据，false不自动刷新
         |
> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**

```javascript
sdk.getPromoDisplayKEY({
  complete: (res) => {
      if (res.code == 0) {
         console.log(res.data.promo_code)
      } else {
         console.log(res.msg)
      }
}}, true)
```

### 响应结构(JSON)

| **参数** | **类型**                                             | **备注** |
| -------- | ---------------------------------------------------- | -------- |
| code     | Number                                               | 0 为成功 |
| msg      | String                                               | 失败信息 |
| data     | [][Data](/docs/v3.5/登录（通行证）/服务端接入/服务端 API)            |          |

##### data

| **参数**   | **类型**  | **说明** |
| ---------- | ----------| -------- |
| refresh_period | Number    | 刷新周期 单位分钟|
| promo_name      | String    | 福利码名称 |
| gift_name    | String    | 礼包名称|
| promo_valid_start    | String    | 福利码创建时间|
| promo_valid_end    | String    | 福利码有效期结束时间|
| promo_code    | String    | 游戏内显示福利码|
| refresh_period_exp    | Number    | 刷新周期过期时间，小于1时轮询|
| polling    | Number    | 轮询间隔时间 秒|

## 兑换福利码

### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| cdkey
   | Boolean
    | 是
           | 福利码
         || callback
 | IMethodParams
 | 是
           | 回调函数集合
 |
> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**

```javascript
sdk.exchangePromoCDKEY('cdkey', {
  complete: (res) => {
      console.log(res)
  }
}}, true)
```

### 响应结构(JSON)

| **参数** | **类型**                                             | **备注** |
| -------- | ---------------------------------------------------- | -------- |
| code     | Number                                               | 0 为成功 |
| msg      | String                                               | 失败信息 |
| data     | [][Data](/docs/v3.5/登录（通行证）/服务端接入/服务端 API)            |          |

##### data

| **参数**   | **类型**  | **说明** |
| ---------- | ----------| -------- |
| prop_id | String    | 道具标识|
| prop_name      | String    | 道具名称 |
| prop_num    | String    | 道具数量|
