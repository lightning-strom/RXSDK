## 获取福利码

**接口原型**

```csharp
/**
 * 获取达人游戏内显示福利码
 * @param callback callback
  * @param authRefresh 是否自动刷新,默认非自动刷新
 */
void GetPromoDisplayKEY(Action callback, bool autoRefresh = false)
```

**调用示例**

```csharp
        RuiXueSdk.GetPromoDisplayKEY((code, promo, msg) =>
        {
            if (code == 0)
            {
                cdkey = promo.promo_code;
            }
            Debug.Log("RXCallback code:" + code + ", msg:" + msg);
            mText.text = "code:" + code + ", msg:" + msg + ", promo:" + RXUtility.ObjectToJson(promo);
        }, true);
```

### 响应结构(JSON)

| **参数** | **类型**                                             | **备注** |
| -------- | ---------------------------------------------------- | -------- |
| code     | Number                                               | 0 为成功 |
| msg      | String                                               | 失败信息 |
| data     | [Data](/docs/v3.5/入门指南/服务端接入须知)            |          |

##### data

| **参数**   | **类型**  | **说明** |
| ---------- | ----------| -------- |
| refresh_period | Number    | 刷新周期 单位分钟|
| promo_name      | String    | 福利码名称 |
| gift_name    | String    | 礼包名称|
| promo_valid_start    | String    | 福利码创建时间|
| promo_valid_end    | String    | 福利码有效期结束时间|
| promo_code    | String    | 游戏内显示福利码|
| refresh_period_exp    | Number    | 刷新周期过期时间，小于1时轮询|
| polling    | Number    | 轮询间隔时间 秒|

## 兑换福利码

**接口原型**

```csharp
/**
 * 兑换达人福利码
 *
 * @param cdKey
 */
 void ExchangePromoCDKEY(string cdKey, Action callback)

```

**调用示例**

```csharp
    public void RXCallback(int code, object data, string msg)
    {
        Debug.Log("RXCallback code:" + code + ", msg:" + msg);

        mText.text = "code:" + code + ", msg:" + msg + ", data:" + data.ToString().Substring("");
        if (data != null)
        {
            Debug.Log("RXCallback data= " + data);
        }
    }
    RuiXueSdk.ExchangePromoCDKEY(cdkey, RXCallback);
   
 ```

### 响应结构(JSON)

| **参数** | **类型**                                             | **备注** |
| -------- | ---------------------------------------------------- | -------- |
| code     | Number                                               | 0 为成功 |
| msg      | String                                               | 失败信息 |
| data     | [][Data](/docs/v3.5/入门指南/服务端接入须知)            |          |

##### data

| **参数**   | **类型**  | **说明** |
| ---------- | ----------| -------- |
| prop_id | String    | 道具标识|
| prop_name      | String    | 道具名称 |
| prop_num    | String    | 道具数量|
