## SDK 集成

- 编辑 build.gradle 文件，添加如下配置，并注意安装**3.5.25及以上版本**：

```groovy
implementation 'com.ruixue:rxsdk_base:${version}'
```

## 获取福利码

**接口原型**

```java
/**
 * 获取达人游戏内显示福利码
 *
 * @param authRefresh 是否自动刷新
 * @param callback callback
 */
void getPromoDisplayKEY(boolean authRefresh, RXRequestCallback callback);
```

**调用示例**

```java
RuiXueSdk.getRXSdkApi().getPromoDisplayKEY(false, new RXRequestCallback() {
            @Override
            public void onResponse(JSONObject jsonObject) {
                int code = jsonObject.optInt("code", -1);
                if (code == 0) {
                }
            }
        })
```

### 响应结构(JSON)

| **参数** | **类型**                                             | **备注** |
| -------- | ---------------------------------------------------- | -------- |
| code     | Number                                               | 0 为成功 |
| msg      | String                                               | 失败信息 |
| data     | [Data](/docs/v3.5/入门指南/服务端接入须知)            |          |

##### data

| **参数**   | **类型**  | **说明** |
| ---------- | ----------| -------- |
| refresh_period | Number    | 刷新周期 单位分钟|
| promo_name      | String    | 福利码名称 |
| gift_name    | String    | 礼包名称|
| promo_valid_start    | String    | 福利码创建时间|
| promo_valid_end    | String    | 福利码有效期结束时间|
| promo_code    | String    | 游戏内显示福利码|
| refresh_period_exp    | Number    | 刷新周期过期时间，小于1时轮询|
| polling    | Number    | 轮询间隔时间 秒|

## 兑换福利码

**接口原型**

```java
/**
 * 兑换达人福利码
 *
 * @param cdKey
 */
void exchangePromoCDKEY(String cdKey, RXRequestCallback callback);

```

**调用示例**

```java
RuiXueSdk.getRXSdkApi().exchangePromoCDKEY(code, new RXRequestCallback() {

    @Override
    public void onResponse(JSONObject jsonObject) {
        tvPromoExchangeInfo.setText(jsonObject.toString());
    }
});
```

### 响应结构(JSON)

| **参数** | **类型**                                             | **备注** |
| -------- | ---------------------------------------------------- | -------- |
| code     | Number                                               | 0 为成功 |
| msg      | String                                               | 失败信息 |
| data     | [][Data](/docs/v3.5/入门指南/服务端接入须知)            |          |

##### data

| **参数**   | **类型**  | **说明** |
| ---------- | ----------| -------- |
| prop_id | String    | 道具标识|
| prop_name      | String    | 道具名称 |
| prop_num    | String    | 道具数量|
