## 准备工作

::: tip
接入请前先做好准备工作。
已经接入过**RXSDK_Pure**组件，无需重复接入，只需要更新到**3.5.25及以上版本**即可。
未接入过，则可通过 **pod** 方式接入 **RXSDK_Pure** 组件，安装**3.5.25及以上版本**，并使用 **RXSDK_Pure** 福利码相关功能。
在需要使用功能的类中引用头文件 <code>#import </code>
:::

## SDK 集成

- 编辑 Podfile 文件，添加如下配置，并注意安装**3.5.25及以上版本**：

```objectivec
pod 'RXSDK_Pure'
```

## 获取福利码

**接口原型**

```objectivec
/**
 * 请求福利码
 * autoRefresh 是否自动刷新，YES自动刷新并返回福利码，NO不自动刷新
 */
- (void)getPromoDisplayKeyWithAutoRefresh:(BOOL)autoRefresh complete:(void(^)(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error))complete;
```

**调用示例**

```objectivec
[[RXApiService sharedSDK] getPromoDisplayKeyWithAutoRefresh:NO complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
            if (error == nil) {
                NSLog(@"福利码结果：%@", response);

            }else{
                NSLog(@"福利码失败结果：%@", error.responesObject);

            }
}];
```

### 响应结构(JSON)

| **参数** | **类型**                                             | **备注** |
| -------- | ---------------------------------------------------- | -------- |
| code     | Number                                               | 0 为成功 |
| msg      | String                                               | 失败信息 |
| data     | [Data](/docs/v3.5/登录（通行证）/服务端接入/服务端 API)            |          |

##### data

| **参数**   | **类型**  | **说明** |
| ---------- | ----------| -------- |
| refresh_period | Number    | 刷新周期 单位分钟|
| promo_name      | String    | 福利码名称 |
| gift_name    | String    | 礼包名称|
| promo_valid_start    | String    | 福利码创建时间|
| promo_valid_end    | String    | 福利码有效期结束时间|
| promo_code    | String    | 游戏内显示福利码|
| refresh_period_exp    | Number    | 刷新周期过期时间，小于1时轮询|
| polling    | Number    | 轮询间隔时间 秒|

## 兑换福利码

**接口原型**

```objectivec
/**
 * 获取福利码
 * cdkey 福利码
 */
- (void)exchangePromoCDKEY:(NSString *)cdkey complete:(void(^)(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error))complete;
```

**调用示例**

```objectivec
[[RXApiService sharedSDK] exchangePromoCDKEY:@"your promo_code" complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
            if (error == nil) {
                NSLog(@"兑换结果：%@",response);
            }else{
                NSLog(@"兑换失败：%@",error.responesObject);
            }
}];
```

### 响应结构(JSON)

| **参数** | **类型**                                             | **备注** |
| -------- | ---------------------------------------------------- | -------- |
| code     | Number                                               | 0 为成功 |
| msg      | String                                               | 失败信息 |
| data     | [][Data](/docs/v3.5/登录（通行证）/服务端接入/服务端 API)            |          |

##### data

| **参数**   | **类型**  | **说明** |
| ---------- | ----------| -------- |
| prop_id | String    | 道具标识|
| prop_name      | String    | 道具名称 |
| prop_num    | String    | 道具数量|
