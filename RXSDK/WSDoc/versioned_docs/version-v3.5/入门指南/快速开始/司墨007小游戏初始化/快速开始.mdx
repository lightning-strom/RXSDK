## SDK 初始化

:::tip
初始化为异步调用，失败将不能使用 SDK 功能，请注意处理调用逻辑

:::

初始化 SDK 时需传入 `productId`、`channelId`、`cpid`、`baseUrlList` 参数信息。

| **参数**          | **参数类型** | **是否必传** | **描述**                                                                      |
|-----------------| ------------ |----------|-----------------------------------------------------------------------------|
| **productId**   | string       | 是        | 产品 id，望舒游戏发行平台创建产品，[查看使用说明](/docs/v3.5/入门指南/准备工作)。    |
| **channelId**   | string       | 是        | 渠道 id，望舒游戏发行平台创建渠道，[查看使用说明](/docs/v3.5/入门指南/准备工作)。    |
| **cpid**        | string       | 是        | CP id，望舒企业管理后台创建项目，[查看使用说明](/docs/v3.5/入门指南/准备工作)。  |
| **baseUrlList** | string[]     | 是        | 请求域名队列，望舒企业管理后台创建项目，[查看使用说明](/docs/v3.5/入门指南/准备工作)。 |
| **complete**    | function     | 是        | 初始化回调函数                                                                     |

接口实例：

```javascript
// 路径仅为示例，需要传入SDK在项目中的真实路径，如出现引用错误请检查路径是否正确
const channelSdk = require("your path/channelSDK/index.js")
//以下参数为测试参数，需要更换为接入方对应的参数
const sdk = new channelSdk({
  productId: '1', //产品 id  
  channelId: '818', //渠道id
  cpid: '1000049', //CP id
  baseUrlList: ['https://ruixue.weiletest.com'],//请求域名队列
  complete: (data) => {
    console.log('init complete: ', data)
    if (data.code === 0) {
      // 初始化成功
    }
  },
})
```

### 设置子渠道

:::tip
通行证记录来源（分包）、子渠道参数。
必须在 登录 前调用。
:::

#### 参数说明

| **字段**
 | **类型**
 | **是否必填**
 | **备注**
 |
| ------------ | ------------ | ---------------- | ------------ |
| params
   | string
 | 是
           | 子渠道id
     |

**调用示例**

```javascript
// 同步函数
const result = sdk.setSubChannelId('your sub_channel_id')

```

#### 响应结构

成功 code 为 0

### 设置自定义返回错误消息

:::tip
规则 1：根据错误码直接读取对应提示替换 msg；

规则 2：如果表中有 default 的 key，将未配置的错误码 msg 统一替换为 default 的 value；

规则 3：$code$ $thirdcode$ $thirdmsg$ 为动态配置字段，如下所示，最终展示的信息为 支付错误4002 

以上规则仅适用于调用了 setErrorMsg 接口，未调用保持原有规则
:::

**调用示例**

```javascript
// 同步函数
sdk.setErrorMsg({
   4001: 'cancel pay',
   4002: '支付错误$code$',
   2001: 'init fail',
   default: 'default$code$$thirdcode$'
})
```

### 清除自定义返回错误消息

**调用示例**

```javascript
// 同步函数
sdk.clearErrorMsg()
```

### 角色数据上报

#### 参数说明

| **字段**
 | **类型**
 | **是否必填**
 | **备注**
 |
| ------------ | ------------ | ---------------- | ------------ |
| server_id
   | string
 | 是
           | 区服id
     |
| server_name
   | string
 | 是
           | 区服名称
     |
| role_action
   | string
 | 是
           | 事件 (create：创角,enter：进入服务器,up_level：角色升级)
     |
| role_id
   | string
 | 是
           | 角色id
     |
| role_name
   | string
 | 是
           | 角色名
     |
| role_level
   | string
 | 是
           | 角色等级(没有传0)
     |
| combat_number
   | string
 | 是
           | 角色战力(没有传0)
     |
| vip
   | string
 | 是
           | vip等级(没有传0)
     |
| timestamp
   | string
 | 是
           |角色创建时间戳(没有传0)
     |
| sign
   | string
 | 是
           |验证签名
     |

**调用示例**

```javascript
// 同步函数
sdk.upRole({
  server_id: '1',
  server_name: '1',
  role_action: 'create',
  role_id: '2',
  role_name: 'role_name',
  role_level: 0,
  combat_number: '0',
  vip: 0,
  timestamp: 1733103358144,
  sign: 'xxx'
})
console.log('setSubChannelId res: ', result)
```

## 接入功能

SDK 提供了众多功能。请在初始化 SDK 后，根据项目需要，参考相应功能的文档，接入相应功能。 绝大多数游戏都会接入望舒登录，所以我们推荐从这一功能开始。

### 接入望舒登录

请根据开发者指南，[登录（通行证）](/docs/v3.5/入门指南/快速开始/Android初始化/快速接入) 完成操作。
