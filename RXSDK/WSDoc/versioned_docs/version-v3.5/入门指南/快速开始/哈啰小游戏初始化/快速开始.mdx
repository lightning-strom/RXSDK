初始化 SDK 时需传入 `productId`、`channelId`、`cpid`、`baseUrlList`、`gameId` 参数信息。

| **参数**          | **参数类型** | **是否必传** | **描述**                                                                      |
|-----------------| ------------ |----------|-----------------------------------------------------------------------------|
| **productId**   | string       | 是        | 产品 id，望舒游戏发行平台创建产品，[查看使用说明](/docs/v3.5/入门指南/准备工作)。    |
| **channelId**   | string       | 是        | 渠道 id，望舒游戏发行平台创建渠道，[查看使用说明](/docs/v3.5/入门指南/准备工作)。    |
| **cpid**        | string       | 是        | CP id，望舒企业管理后台创建项目，[查看使用说明](/docs/v3.5/入门指南/准备工作)。  |
| **baseUrlList** | string[]     | 是        | 请求域名队列，望舒企业管理后台创建项目，[查看使用说明](/docs/v3.5/入门指南/准备工作)。 |
| **gameId**        | string       | 是        | 当前小游戏gameId  |
| **complete**    | function     | 是        | 初始化回调函数                                                                     |

接口实例：

```javascript
// 路径仅为示例，需要传入SDK在项目中的真实路径，如出现引用错误请检查路径是否正确
const channelSdk = require("your path/channelSDK/index.js")
//以下参数为测试参数，需要更换为接入方对应的参数
const sdk = new channelSdk({
  productId: '1', //产品 id  
  channelId: '818', //渠道id
  cpid: '1000049', //CP id
  gameId: 'xxxx', // 小游戏gameId
  baseUrlList: ['https://ruixue.weiletest.com'],//请求域名队列
  complete: (data) => {
    console.log('init complete: ', data)
    if (data.code === 0) {
      // 初始化成功
    }
  },
})
```

### 设置自定义返回错误消息

:::tip
规则 1：根据错误码直接读取对应提示替换 msg；

规则 2：如果表中有 default 的 key，将未配置的错误码 msg 统一替换为 default 的 value；

规则 3：$code$ $thirdcode$ $thirdmsg$ 为动态配置字段，如下所示，最终展示的信息为 支付错误4002 

以上规则仅适用于调用了 setErrorMsg 接口，未调用保持原有规则
:::

**调用示例**

```javascript
// 同步函数
sdk.setErrorMsg({
   4001: 'cancel pay',
   4002: '支付错误$code$',
   2001: 'init fail',
   default: 'default$code$$thirdcode$'
})
```

### 清除自定义返回错误消息

**调用示例**

```javascript
// 同步函数
sdk.clearErrorMsg()
```

## 接入功能

SDK 提供了众多功能。请在初始化 SDK 后，根据项目需要，参考相应功能的文档，接入相应功能。 绝大多数游戏都会接入望舒登录，所以我们推荐从这一功能开始。

### 接入望舒登录

请根据开发者指南，[登录（通行证）](/docs/v3.5/入门指南/快速开始/Android初始化/快速接入) 完成操作。

### 事件上报

#### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params
   | IEventReport
        | 是
           | 参数
         |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |

> IEventReport 说明

| **字段**
 | **类型**
 | **是否必填**
 | **备注**
                     |
| ------------ | ------------ | ---------------- | -------------------------------- |
| eventName
   | string
   | 是
           | 用户主动触发，事件名称
 活动：ACTIVITY
 注册（创角）：REGISTER
 礼包核销：GIFT_WRITE_OFF
 充值兑换：EXCHANGE
 等级变更：LEVEL
 登录成功：LOGIN
 添加家居：ADD_HOME_FURN
 网络异常：SOCKET_EXCEPTION
| eventInfo
   | object
   | 是
           | 事件上报信息
   |
> eventInfo 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| roleId
 | 角色ID
 |
| gameZoneId
 | 区服ID
 |
| gameZoneName
 | 区服名称
 |
| roleName
 | 角色名称
 |
> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

#### 调用示例

```javascript
sdk.eventReport(
  {
    eventName: 'REGISTER',
    eventInfo: {
        roleId: '角色ID',
        gameZoneId: '区服ID',
        gameZoneName: '区服名称',
        roleName: '角色名称',
    }
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);
```

#### 响应结构
成功 code 为 0
