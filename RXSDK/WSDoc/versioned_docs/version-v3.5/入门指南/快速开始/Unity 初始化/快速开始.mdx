## 接入 Unity Package

1. 添加望舒 UnitySdk 包管理服务器地址, 如下图打开 Edit > ProjectSettings > PackageManager 界面，填入望舒UnitySdk包管理服务器地址
::: tip
  Name: RuiXueUnitySdk

  URL: http://60.205.123.114:4873
  
Scope: com.ruixue
:::

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/20240715-093915.png)

2. 在PackageManager中引入所需包
   如下图打开Window > PackageManager界面，切换标签页至My Registries界面（ 如没有My Registries标签可能网络慢，稍等刷新，或可能地址填写有误）即可看到望舒所有包列表，选中所需包点击Install即可。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/20240715-093905.png)

3. 特别注意：关于LitJson.dll冲突问题
   RuiXue.Base 包内Plugins 包含LitJson.dll，有可能和项目内已经有的LitJson库冲突，比如接入微信小游戏的时候，微信导出小游戏插件里也包含LitJson.dll,  那么删除其LitJson保留一个即可。

## SDK 初始化

### 接口传参初始化

::: tip
初始化 SDK 时需传入 `productId`、`channelId`、`cpid`、`baseUrlList` 参数信息。

- `productId`、`channelId` 在望舒游戏发行平台获取（创建产品或渠道），[查看使用说明]](/docs/v3.5/入门指南/准备工作#创建产品)。
- `cpid`、`baseUrlList` 在望舒企业管理后台获取（创建项目），[查看使用说明]](/docs/v3.5/入门指南/准备工作)。
- 初始化为异步调用，失败将不能使用 SDK 功能，请注意处理调用逻辑。

:::

**接口原型**

```csharp
void Initialize(string cpid, string productid, string channelid, List urls, 
        RequestResponseDelegate onSuccess, RequestErrorDelegate onFail);
```

#### 参数说明

| **字段**    | **类型** | **是否必填** | **备注**                               |
| ----------- | -------- | ------------ | -------------------------------------- |
| cpid        | String | 是           | cpid                                   |
| productId   | String | 是           | 产品 id                                |
| channelId   | String | 是           | 渠道 id                                |
| baseUrlList | Array  | 是           | 请求域名队列

**调用示例**

```csharp
    private void OnBtnInit()
    {
        string cpId = "114";
        string channelId = "100";
        string productId = "1002";
        List list = new()
        {
            "http://cn-api-test.ruixuecloud.com"
        };
        
        RuiXueSdk.Initialize(cpId,productId, channelId, list, RequestResponseDelegate, RequestErrorDelegate);
    }

    private void RequestResponseDelegate(string data)
    {
        LogUtil.Log("EventManager", $"RequestResponseDelegate: {data}");
    }

    private void RequestErrorDelegate(string error)
    {
        LogUtil.Log("EventManager", $"RequestErrorDelegate: {error}");
    }
```

### 设置自定义错误消息提示
:::tip
规则 1：根据设置的错误码直接读取对应提示替换 msg；

规则 2：如果设置中有 default 的 key，将未配置的错误码 msg 统一替换为 default 的 value；
规则 3：$code$ $msg$ $thirdcode$ $thirdmsg$ 为模板占位符，使用后将分别被替换为sdk接口默认返回code msg thirdcode thirdmsg

以上规则仅适用于调用了 ***- (void)configErrorMsg:(NSDictionary *)msgDic**** 方法，未调用此方法，则返回sdk默认提示信息，映射键值对中key 对应 value 不能为空字符串，否则该对映射不生效
:::

**接口原型**

```csharp
/**
/// <summary>
/// 设置自定义错误消息提示
/// </summary>
/// 错误消息字典
public void configErrorMsg(Dictionary errorMsgMap);
```

**数据结构**
错误码设置的参数形式，应按照语言进行分类设置，无需将提示的语言类型配置齐全，为方便未来扩展语言结构，设置的数据结构例如：
```csharp
{
    en:{
            "3001":"error1",
            "3002":"error2"
        }
    zh:{
            "3001":"错误1",
            "3002":"错误2"
    }
}
```

**调用示例**
```csharp
private void customErrorMsg()
    {
        Dictionary zhDic = new()
        {
            { "3001", "错误码信息1" },
            { "3002", "错误码信息2" },
            { "default","测试66666  $msg$ $code$ $thirdcode$ $thirdmsg$"}
        };
        Dictionary enDic = new()
        {
            { "3001", "error1" },
            { "3002", "error2" },
            { "default","测试77777  $msg$ $code$ $thirdcode$ $thirdmsg$"}
        };
        Dictionary errorDic = new();
        errorDic.Add("zh",zhDic);
        errorDic.Add("en",enDic);
        
        RuiXueSdk.configErrorMsg(errorDic);
    }
```

### 全局通用回调

:::tip
一些需要特定条件触发的事件会通过全局通用回调将事件通知给客户端，通过回调的 type 区分事件类型，并处理相应的业务逻辑。
:::

**接口原型**

```csharp
public void SetSdkCallback(PublicDelegate publicDelegate, LogoutDelegate onLogout, 
        SwitchAccountDelegate onSwitchAccount);
```

**调用示例**

```csharp
    private void SetRuiXueSdkCallback()
    {
        RuiXueSdk.SetSdkCallback(PublicDelegate, LogOut, SwitchAccountDelegate);
    }

    public void PublicDelegate(int type, string jsonDicData)
    {
        if (type == 10001)
        {
            /*
            RXFeedback.ReportFeedbackLog();
            */
        }

        LogUtil.Log("EventManager", $"type: {type}, jsonDicData: {jsonDicData}");
    }

    private void LogOut(int code, string msg)
    {
        LogUtil.Log("EventManager", $"code: {code}, msg: {msg}");
    }

    public bool SwitchAccountDelegate(int code, string data)
    {
        LogUtil.Log("EventManager", $"code: {code}, data: {data}");
        return true;
    }
```

#### type说明

| **type** | **备注** |
| ------- | -------- |
| 10001   | 上报用户反馈日志                            |
