# 平台插件
由于 微信 SDK 和 抖音 SDK 同时接入存在冲突，可以通过如下方式切换对应平台。

1. 插件方式切换
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/%E5%88%9D%E5%A7%8B%E5%8C%96/WechatIMG324.jpg)

2. 代码方式切换
```
// 切换至抖音
RuiXueMiniGamePluginSwitch.EnableDouYin()

// 切换至微信
RuiXueMiniGamePluginSwitch.EnableWeiXin()
```
