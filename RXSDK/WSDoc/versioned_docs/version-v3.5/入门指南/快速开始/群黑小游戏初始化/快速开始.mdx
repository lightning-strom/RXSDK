## SDK 初始化

:::tip
初始化为异步调用，失败将不能使用 SDK 功能，请注意处理调用逻辑

:::

初始化 SDK 时需传入 `productId`、`channelId`、`cpid`、`baseUrlList` 参数信息。

| **参数**          | **参数类型** | **是否必传** | **描述**                                                                      |
|-----------------| ------------ |----------|-----------------------------------------------------------------------------|
| **productId**   | string       | 是        | 产品 id，望舒游戏发行平台创建产品，[查看使用说明](/docs/v3.5/入门指南/准备工作)。    |
| **channelId**   | string       | 是        | 渠道 id，望舒游戏发行平台创建渠道，[查看使用说明](/docs/v3.5/入门指南/准备工作)。    |
| **cpid**        | string       | 是        | CP id，望舒企业管理后台创建项目，[查看使用说明](/docs/v3.5/入门指南/准备工作)。  |
| **baseUrlList** | string[]     | 是        | 请求域名队列，望舒企业管理后台创建项目，[查看使用说明](/docs/v3.5/入门指南/准备工作)。 |
| **complete**    | function     | 是        | 初始化回调函数                                                                     |

接口实例：

```javascript
// 路径仅为示例，需要传入SDK在项目中的真实路径，如出现引用错误请检查路径是否正确
const channelSdk = require("your path/channelSDK/index.js")
//以下参数为测试参数，需要更换为接入方对应的参数
const sdk = new channelSdk({
  productId: '1', //产品 id  
  channelId: '818', //渠道id
  cpid: '1000049', //CP id
  baseUrlList: ['https://ruixue.weiletest.com'],//请求域名队列
  complete: (data) => {
    console.log('init complete: ', data)
    if (data.code === 0) {
      // 初始化成功
    }
  },
})
```

### 设置自定义返回错误消息

:::tip
规则 1：根据错误码直接读取对应提示替换 msg；

规则 2：如果表中有 default 的 key，将未配置的错误码 msg 统一替换为 default 的 value；

规则 3：$code$ $thirdcode$ $thirdmsg$ 为动态配置字段，如下所示，最终展示的信息为 支付错误4002 

以上规则仅适用于调用了 setErrorMsg 接口，未调用保持原有规则
:::

**调用示例**

```javascript
// 同步函数
sdk.setErrorMsg({
   4001: 'cancel pay',
   4002: '支付错误$code$',
   2001: 'init fail',
   default: 'default$code$$thirdcode$'
})
```

### 清除自定义返回错误消息

**调用示例**

```javascript
// 同步函数
sdk.clearErrorMsg()
```

### 实名认证

#### 参数说明

| **字段**
 | **类型**
 | **是否必填**
 | **备注**
 |
| ------------ | ------------ | ---------------- | ------------ |
| type
   | number
 | 是
           | 1 - 检查是否开启验证接口 2 - 获取是否验证成功接口 3 - 拉起验证弹窗接口
     |

**调用示例**

```javascript
sdk.userVerify(1, {
    complete: (res: any) => {
       console.log('检查是否开启验证:', res)
       // res.code(1开启验证，2关闭验证))
    }
})

sdk.userVerify(2, {
    complete: (res: any) => {
       console.log('获取是否验证成功:', res)
       // res.code(1成功，2失败)，res.state(1成年，2未成年),res.age(年龄),res.cardmd5(身份证MD5值)
    }
})

sdk.userVerify(3, {
    complete: (res: any) => {
       console.log('拉起验证弹窗:', res)
       // res.code(1成功，2失败)，res.state(1成年，2未成年),res.age(年龄),res.cardmd5(身份证MD5值)
    }
})
```

### 角色上报接口

:::tip
签名sign由游戏服务端调望舒服务端生成，再下发给客户端调用望舒sdk传入

:::
#### 参数说明

| **字段**
 | **类型**
 | **是否必填**
 | **备注**
 |
| ------------ | ------------ | ---------------- | ------------ |
| act
   | number
 | 是
           | 1=创建角色，2=登录角色，3=角色升级
     |
| username
   | string
 | 是
           | 登录账号(登录接口username)
     |
| serverid
   | number
 | 是
           | 区服id
     |
| servername
   | string
 | 是
           | 区服名称
     |
| rolename
   | string
 | 是
           | 角色名称
     |
| roleid
   | number
 | 是
           | 角色id
     |
| level
   | number
 | 是
           | 角色等级(没有传0)
     |
| power
   | number
 | 是
           | 角色战力(没有传0)
     |
| ver
   | number
 | 是
           | 版本号固定值1
     |
| sign
   | string
 | 是
           | 验证签名(需要在后端计算签名)，md5(act_username_serverid_roleid_level_power_vip_rolecreatetime_ver_key) 这里传递的md5字串为小写字母,_需算入加密, 这里的key是提交到后台的登录key
     |

**调用示例**

```javascript
 sdk.upRole({
    act: '1',
    username: 'xxxssss',
    serverid: '123',
    rolename: '测试123',
    roleid: '111',
    level: '1',
    power: '1',
    rolecreatetime: 'xxxx',
    sign: 'xxxxx',
    ver: '2'
 })
```

## 接入功能

SDK 提供了众多功能。请在初始化 SDK 后，根据项目需要，参考相应功能的文档，接入相应功能。 绝大多数游戏都会接入望舒登录，所以我们推荐从这一功能开始。

请根据开发者指南，[登录（通行证）](/docs/v3.5/入门指南/快速开始/Android初始化/快速接入) 完成操作。
