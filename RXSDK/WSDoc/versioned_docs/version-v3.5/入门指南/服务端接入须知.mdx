:::tip
望舒的绝大部分接口皆采用 HTTP 方式进行通信，但在调用这些接口时需要附加指定的 HTTP Headers 和相关授权参数。
:::

## HTTP Headers 定义

:::warning
望舒的自定义头并没有采用 "X-" 开头的公共前缀范例，而是以 "ruixue-" 开头。**注意：为避免产生歧义，所有望舒头参数全部为"小写"字母。**
:::

### 客户端请求头

> Accesstoken

| 参数名 | 说明 | 是否必须 | 示例 |
| --- | --- | --- | --- |
| ruixue-traceid | 本次请求唯一标识，格式为 UUID v4，当接口出现错误时可将其提供给望舒团队对问题进行快速定位 | 是 | 0e2971af-823a-4298-b7d8-3ef38094b500 |
| ruixue-cpid | 望舒 CPID，望舒为每个 CP 分配的一个唯一 ID，从 7 位数 1000000 开始递增 | 是 | 1000000 |
| ruixue-productid | 产品标识，CP 望舒集群内部的产品 ID，由各 CP 自行在后台创建，字符串类型 | 是 | test |
| ruixue-channelid | 渠道标识，CP 望舒集群内部某应用的渠道 ID，由各 CP 自行在后台创建，字符串类型 | 是 | test |
| ruixue-platformid | 客户端类型（1: Android / 2: iOS / 3: H5 / 4: 微信小程序 / 5: web / 6: 鸿蒙 / 10: 望舒服务端 SDK） | 是 | 2 |
| ruixue-devicecode | 设备码，通过一系列策略推导/生成的 C 端设备唯一标识，但因各系统种种限制，可能无法获得或不 100% 唯一 | 否 | abcdefghijklmnopqrstuvwxyz123456 |
| ruixue-language | 系统语言标识 | 否 | zh-CN |
| ruixue-version | SDK 版本号 | 否 | ios-v2.0.0 |
| ruixue-accesstoken | 望舒通行证授权令牌，C 端用户登录后由通行证分发，后续在访问需要鉴权的接口时必须携带 | 否 | eyJhbGciOiJIUzI1NiIs... |
| ruixue-tzoffset | 基于 UTC 的时区偏移值，单位为：小时，不指定时默认为 8，表示北京时间的东 8 区 | 否 | 8 |
| ruixue-area | 地区编码 | 否 | CN |

### 服务端请求头

> CPSign

| 参数名 | 说明 | 是否必须 | 示例 |
| --- | --- | --- | --- |
| ruixue-traceid | 本次请求唯一标识，格式为 UUID v4，当接口出现错误时可将其提供给望舒团队对问题进行快速定位 | 是 | 0e2971af-823a-4298-b7d8-3ef38094b500 |
| ruixue-cpid | 望舒 CPID，望舒为每个 CP 分配的一个唯一 ID，从 7 位数 1000000 开始递增 | 是 | 1000000 |
| ruixue-cpts | 时间戳，CP 服务端发起请求时的毫秒时间戳 | 是 | 1669619948739 |
| ruixue-cpsign | 请求签名，签名规则：`sha1(traceid+cpts+cpkey)` | 是 | dc87e3db3ec7a0a8edbd470abd58107ae1b66268 |
| ruixue-language | 语言标识，系统语言标识 | 否 | zh-CN |
| ruixue-version | gosdk 的版本号，SDK 版本号（如果为直接调用不需要此字段） | 否 | go-v2.0.1 |
| ruixue-tzoffset | 时区，基于 UTC 的时区偏移值，单位为：小时，不指定时默认为 8，表示北京时间的东 8 区 | 否 | 8 |
| ruixue-productid | 产品标识，CP 望舒集群内部的产品 ID，由各 CP 自行在后台创建，字符串类型 | 是 | test |
| ruixue-servicemark | 数据域标识，CP 游戏服的标识信息 | 否 | default |
| ruixue-region | 数据域标识，CP 游戏服的分区信息 | 否 | default |
| ruixue-cp-role-id | 数据域标识，CP 游戏服的角色信息 | 否 | default |

## 服务端回调接口

:::warning
望舒系统接入前，请仔细阅读本条款。**请确认要使用的功能，必须实现对应的接口！！！** 接口实现完成后，需要在望舒系统（产品管理 > 回调参数配置）调试与配置。
:::
