::: tip
SDK 3.2.x 以后版本错误码重新规范，使用下面格式返回。
原渠道原始错误码通过 thirdcode、thirdmsg 字段返回。
:::

- 返回数据结构为 json： 如果三方 SDK ，具体三方信息通过扩展信息返回。
  

```json
{    
    "code" : 望舒错误码,    
    "msg" : "望舒错误描述",    
    "thirdmsg" : "三方原始错误描述"，
    //无三方错误码时候不返回字段    "thirdcode" : 三方原始错误码,   
    //无三方错误消息时候不返回字段    "data" : {}
}
```

## 错误码说明
  

> 1000 &lt;= x &lt; 2000 为网络相关错误
> 2000 &lt;= x &lt; 3000 为初始化相关错误
> 3000 &lt;= x &lt; 4000 为登录相关错误
> 4000 &lt;= x &lt; 5000 为支付相关错误
> 5000 &lt;= x &lt; 6000 为分享相关错误
> 6000 &lt;= x &lt; 7000 为权限和应用未安装相关错误
