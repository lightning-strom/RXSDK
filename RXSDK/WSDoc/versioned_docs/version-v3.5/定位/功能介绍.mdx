## 功能介绍

用于需要定位、获取附近的人等场景使用。玩家授权应用位置使用权限后，通过玩家当前经度、维度，获取定位结果和附近的玩家。

## 准备工作

### 高德开放平台获取 Key

1. **注册高德开发者**

在 [高德开放平台](https://console.amap.com/dev/id/phone)，注册成为开发者。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/positioning/Sviwb93hDo0GraxzJPbcKwvWnib.png)

2. **创建应用**

进入 [控制台](https://lbs.amap.com/dev/)，创建一个新应用。如果您之前已经创建过应用，可直接跳过这个步骤。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/positioning/Kg8TbaixWoMbolxUtcPclJS3nzh.png)

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/positioning/FKfRbFIuGoGnfKxNqqAcVrphnug.png)

3. **添加 Key**

在创建的应用上点击"添加新 Key "按钮，在弹出的对话框中，依次：输入应用名名称，选择绑定的服务为“ Android 平台 SDK ”，输入发布版安全码  SHA1 、调试版安全码 SHA1 、以及 Package ，如下图所示：

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/positioning/Vqb8bFsoboWQ6ExRFCvcTCeyn0g.png)

在阅读完高德地图 API 服务条款后，勾选此选项，点击“提交”，完成 Key 的申请，此时您可以在所创建的应用下面看到刚申请的 Key 了。

### 望舒系统中配置定位信息

1. 从 [高德开放平台](https://console.amap.com/dev/id/phone) 获取 Key。
2. 复制到望舒系统，位置**企业管理后台 > 商务管理  > 渠道包管理 > 定位配置** 。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/gaode/gaode.jpg)
