#### 1.支付类型不存在
望舒后台渠道包确认是否已关联该支付方式，检查下单参数的pay_type是否与关联的支付方式一致。

#### 2.支付返回商品不存在
苹果支付，华为支付，荣耀支付，百度网讯支付等支付方式，需要在相关后台配置对应商品信息，并在望舒游戏发行平台需要使用三方计费点关联商品标识。

#### 3.支付返回goods_tag不存在
确认望舒游戏发行平台是否已配置参数中的计费点标识

#### 4.小游戏iOS支付返回链接参数替换
望舒游戏发行平台可以支持回复的图文标题，描述等信息配置为{'{'}字段{'}'}的形式，望舒会根据CP下单的时候在sessionFrom传递的字段进行匹配。

#### 5.公众号支付提示redirect_uri域名与后台配置不一致,错误码:10003。或者提示当前页面url未注册
微信公众平台需要把初始化的域名参数全部配置到公众号和商户号的JSAPI支付授权域名、js安全域名列表和网页授权域名中。

#### 6.微信小游戏公众号支付下单返回埋点不存在
确认望舒游戏发行平台是否已配置埋点信息。并配置对应的卡片素材和分享策略。
注意：策略关联埋点时要是同一类型。

#### 7.微信小游戏公众号支付没反应
1.确认望舒游戏发行平台是否已配置微信客服回复信息。
2.微信后台需要进行消息推送地址绑定。复制时注意空格。
绑定规则 ：API 域名 +v1/servicewechat/notify/ProductID/ChannelID
Token : 固定值 ruixue
ProductID : 望舒产品 ID
ChannelID :望舒渠道 ID
消息加密方式:明文
数据格式:JSON

#### 8.支付宝APP支付，提示4002支付取消
检查后台配置的公钥，私钥是否正确。
注意：私钥在后台无法查看，第一次生成后请妥善保管。如无法确认需要重置密钥。

#### 9.抖音小游戏支付未到账
请检查CP是否有调用抖音的接口获取access_token。需要获取access_token时请使用望舒提供的接口。

#### 10.微信小游戏虚拟支付未到账
用户下单后没有正常发货，可以让用户在点击同个计费点。米大师为钱包形式，可能有时用户支付成功只是存到了钱包中，需要再次发起消耗。

#### 11.尝试下单提示request paytype invalid
1.检查望舒后台渠道包是否已关联需要使用的支付方式。
2.检查pay_type传的字段与望舒文档提供的是否一致。

#### 12.oppo小游戏确认私钥无误后还是返回no timestamp
oppo开发者私钥由开发者生成，生成为pkcs1格式，需要使用openssl转换为pkcs8格式。
命令执行：openssl pkcs8 -topk8 -inform PEM -in test.pem -outform pem -nocrypt -out test2.pem。其中 test.pem为pkcs1格式密钥文件。输出为test2.pem文件

#### 13.需要填写服务端回调的回调地址
1.OPPO，VIVO，淘宝小游戏， 抖音小游戏， 无客户端支付回调 需要填写服务端回调地址。或者个别平台想使用服务端回调时。
2.如果您需要配置回调地址，按照此格式：
API域名/v1/ke/callback/产品ID@渠道ID/honor(渠道)
个别渠道如果提示@为非法字符那就使用：API域名/v1/ke/callback/f_channel/产品ID/渠道ID/honor(渠道)
API域名,产品ID,渠道ID：望舒游戏平台首页信息有展示。
渠道：是哪个平台就配置哪个平台(例：honor，oppo，hwjos 等。也就是下单使用的pay_type)

#### 14.微信app支付提示下单失败
1.查看微信app配置说明，确认获取的商户号证书文件和证书序列号无误，并配置V3key。商户号和绑定的AppId已开通app支付。[微信app支付配置说明](/docs/v3.5/常见问题/支付相关)
2.确认商户号是否因长时间不使用导致限制收款被封禁。

#### 15.微信小游戏虚拟支付未到账
米大师支付为钱包形式，用户购买礼包表现是充值成功了并已支付。 实际是到了钱包并没有扣除余额。如果用户又继续点击同价位的礼包是刚好可以扣除余额。如果点击了其他价位的礼包则会对应扣除，剩下的余额可以引导用户花费掉。再根据实际凭证进行补单发放礼包等操作。

#### 16.OPPO，VIVO，淘宝小游戏，抖音小游戏，无客户端支付回调 需要填写服务端回调地址
回调地址:API域名/v1/ke/callback/产品ID@渠道ID/平台
平台分别为：douyinh5,minigame_vivo,minigame_oppo,minigame_taobao

#### 17.Bilibili渠道支付无法拉起渠道支付页面
请检查使用sdk下单的参数是否正确，Bilibbili要求客户端下单在ext传入game_money属性。[详情查看](/docs/v3.5/三方服务/Bilibili/客户端/客户端接入)

#### 18.不想使用sdk支付并且需要上报支付事件到大数据
相关上报参数与大数据埋点事件属性一一对应。其中pay_money自己上报上报成分即可，大数据会自动处理为元进行展示。

#### 19.华为渠道内购支付返回4002 错误码
1. 如果用户使用的是华为系统手机时出现支付错误，请核查华为后台配置商品和望舒配置计费点以及配置的支付参数。
2. 如果使用的是非华为系统手机。让用户更新手机内的HMS Core版本至最新。在尝试进行拉起支付。如果发现已经是最新版本但不能支付，引导回退后再重试，操作路径：手机 > 设置 > 应用/应用和服务 > 应用管理 > HMS Core > 右上角三/四点 > 卸载更新 > 卸载更新

#### 20.iOS支付提示错误码4202 ，没有商品/商品不存在 的情况
1. 确认望舒后台配置的三方计费点和苹果后台配置的商品id保持一致。并且商品是消耗性和生效的。
2. 确认用户的苹果账号是否和苹果后台配置的商品发售区域保持一致。例如：用户在请求支付的时候是外国地区，可能就会出现上述情况。具体商品策略以IOS返回信息为准。
3. 确认配置的bundleid和App Store 是否一致。

#### 20.iOS支付提示错误码4202 ，没有商品/商品不存在 的情况
1. 确认望舒后台配置的三方计费点和苹果后台配置的商品id保持一致。并且商品是消耗性和生效的。
2. 确认用户的苹果账号是否和苹果后台配置的商品发售区域保持一致。例如：用户在请求支付的时候是外国地区，可能就会出现上述情况。具体商品策略以IOS返回信息为准。
3. 确认配置的bundleid和App Store 是否一致。

#### 21.iOS支付未到账
以下情况是苹果回调错误或触发风控拦截导致订单验证失败，真实付款状态无法查询，CP 可根据用户提供的付款凭证自行处理补发或引导用户退款。
> 风控策略：
> 1. 凭证缺失
> 2. 付款时间早于下单时间
> 3. 付款凭证解析后 in_app 缺失
1. 苹果订单查询提示 “由于苹果服务器回调时未返回 TransactionID 数据，该订单不支持查询望舒订单”。
2. 支付时间、订单状态、回调状态 为空。
