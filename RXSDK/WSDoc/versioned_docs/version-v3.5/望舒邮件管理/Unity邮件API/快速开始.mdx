## 获取望舒邮件-列表

**接口原型**

```csharp
/// <summary>
/// 获取邮件列表
/// </summary>
/// 
/// 
public void GetEmailList(string userId, RequestResponseDelegate onResponse, RequestErrorDelegate onError);
```

**调用示例**

```csharp

RuiXueSdk.GetEmailList("442099939", MailResponseDelegate, MailErrorDelegate);

private void MailResponseDelegate(string data)
{
    LogUtil.Log("EventManager", $"mail: {data}");
}

private void MailErrorDelegate(string error)
{
    LogUtil.Log("EventManager", $"mail: {error}");
}
```

### 响应结构（JSON）

| **参数** | **类型** | **约束** |
| --- | --- | --- |
| list| Array| 邮件列表 |
| all_count | Number | 列表邮件总数 |
| not_received_count | Number | 列表中未领取附件的邮件数量 |

**list**

| **参数** | **类型** | **约束** |
| --- | --- | --- |
| rx_mail_id| Number | 邮件ID |
| title | String  | 邮件标题 |
| send_at | String | 邮件发送时间，格式为 MM-dd HH:ii:ss，不包含年份 |
| status | Number | 邮件状态：1-已读 2-已领 3-已发送 |

## 获取望舒邮件-详情

**接口原型**

```csharp
/// <summary>
/// 获取邮件详情
/// </summary>
/// 
/// 
/// 
/// 
public void GetEmailDetail(string userId, int mailId,
    RequestResponseDelegate onResponse, RequestErrorDelegate onError);
```

**调用示例**

```csharp
RuiXueSdk.GetEmailDetail("442099939",546, MailResponseDelegate, MailErrorDelegate);

private void MailResponseDelegate(string data)
    {
        LogUtil.Log("EventManager", $"mail: {data}");
    }

    private void MailErrorDelegate(string error)
    {
        LogUtil.Log("EventManager", $"mail: {error}");
    }
```

### 响应结构（JSON）

| **参数** | **类型** | **约束** |
| --- | --- | --- |
| title | String | 邮件标题 |
| content | String | 邮件内容 |
| sign | String | 邮件落款 |
| props | Array | 邮件附件列表 |
| status | Number | 邮件状态：1-已读 2-已领 3-已发送 |

**props**

| **参数** | **类型** | **约束** |
| --- | --- | --- |
| name| String | 道具名称 |
| describe | Number | 道具描述 |
| icon | Number | 道具图标url |
| tag | Number | 道具唯一标识 |
| count | Number | 道具数量 |
| count_format | String | 道具数量单位换算，支持简繁体中文、英文和越南文的单位换算，其他语言默认使用英文单位换算 |
| is_permanent | Number | 道具是否永久有效，0：永久有效 1：非永久有效 |
| time_limit | Number | 道具有效期，以天为单位 |

## 望舒邮件-领取

**接口原型**

```csharp
/// <summary>
/// 获取附件
/// </summary>
/// 
/// 
/// 
/// 
/// 
public void GetEmailAward(string userId, int type, int mailId,
    RequestResponseDelegate onResponse, RequestErrorDelegate onError);
```

:::tip
当type为2时， mailId 为0即可。此时maiId不会传递给服务端
:::

**调用示例**

```csharp
RuiXueSdk.GetEmailAward("442099939", 1, 546, MailResponseDelegate, MailErrorDelegate);

private void MailResponseDelegate(string data)
    {
        LogUtil.Log("EventManager", $"mail: {data}");
    }

    private void MailErrorDelegate(string error)
    {
        LogUtil.Log("EventManager", $"mail: {error}");
    }
```

**响应示例**

```json
{
  "code": 0,
  "msg": "",
  "data": ""
}
```
