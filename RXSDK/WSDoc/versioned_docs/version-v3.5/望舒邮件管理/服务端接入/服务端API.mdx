## 望舒邮件-列表

> **POST:** `/v1/operationtoolsapi/rxmail/cpuser/list`
> **认证方式：** [Accesstoken](/docs/v3.5/入门指南/服务端接入须知) PUT时为 [CPSign](/docs/v3.5/入门指南/服务端接入须知)

:::warning
1、该接口无分页，仅返回最后1000条数据。2、当后台望舒邮件任务配置多语言时，会根据请求语言返回相应语言的内容，如果语言内容不存在，则返回配置的默认语言内容。3、过期邮件无法在列表中查看，未读邮件过期时间为 60 天，已读邮件过期时间为 7 天。
:::

### CURL 示例

```bash
curl --location --request POST '{{接口域名}}/v1/operationtoolsapi/rxmail/cpuser/list' \
--header 'ruixue-productid: {{产品id}}' \
--header 'ruixue-channelid: {{渠道id}}' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-accesstoken: {{登录token}}' \
--data-raw '{
    "cp_user_id": "442099939",
    "language_able": "zh"
}'
```

### header参数

| **参数** | **类型** | **是否必填** | **约束** |
| --- | --- | ---- | --- |
| ruixue-productid | String | 是 | 望舒产品 ID |
| ruixue-channelid | String | 是 | 望舒渠道 ID |
| ruixue-language | String | 否 | [用户语言](/docs/v3.5/登录（通行证）/Android 登录API/快速接入) |

### body请求参数

| **参数** | **类型** | **是否必填** | **约束** |
| --- | --- | ---- | --- |
| cp_user_id| String | 是 | 游戏用户ID |
| language_able | String | 是 | 用户语言（非必须，与请求头中的 ruixue-language 有一个即可 ）|
| region_tag| String | 是 | 区服 |
| role_id| String | 是 | 角色 |
| return_prop| Bool | 否 | 是否返回道具信息 |
| return_content| Bool | 否 | 是否返回内容信息 |
| page| int | 否 | 默认1 |
| size| int | 否 | 默认1000 |

**响应示例**

```json
{
	"code": 0,
	"msg": "",
	"data": {
		"list": [{
			"rx_mail_id": 2,
			"title": "邮件标题",
			"send_at": "2024-01-01 08:00:00",
			"status": 1,
			"has_reward": 0
		}, {
			"rx_mail_id": 1,
			"title": "邮件标题",
			"send_at": "2024-01-01 08:00:00",
			"status": 2,
			"has_reward": 1
		}],
		"all_count": 2,
		"not_received_count": 1,
		"not_read_count": 1
	}
}
```

### 响应结构（JSON）

| **参数** | **类型** | **约束** |
| --- | --- | --- |
| list| Array| 邮件列表 |
| all_count | Number | 列表邮件总数 |
| not_received_count | Number | 列表中未领取附件的邮件数量 |
| not_read_count| Number | 列表中未读的邮件数量 |

**list**

| **参数** | **类型** | **约束** |
| --- | --- | --- |
| rx_mail_id| Number | 邮件ID |

## 望舒邮件-详情

```bash
--header 'ruixue-productid: {{产品id}}' \

}'
```

| **参数** | **类型** | **是否必填** | **约束** |
| --- | --- | ---- | --- |

### body请求参数

**响应示例**


**props**

| **参数** | **类型** | **约束** |

## 望舒邮件-领取（回调发放）

> **POST:** `/v1/operationtoolsapi/rxmail/cpuser/receive`
> **认证方式：** [Accesstoken](/docs/v3.5/入门指南/服务端接入须知)  PUT时为 [CPSign](/docs/v3.5/入门指南/服务端接入须知)

:::warning
1、道具领取成功后会通过后台配置的回调发送给服务端。2、一键领取时，无附件的未读邮件会变为已读状态。
:::

### CURL 示例

```bash
curl --location --request POST '{{接口域名}}/v1/operationtoolsapi/rxmail/cpuser/receive' \
--header 'ruixue-productid: {{产品id}}' \
--header 'ruixue-channelid: {{渠道id}}' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-accesstoken: {{登录token}}' \
--data-raw '{
    "rx_mail_id": 1,
    "cp_user_id": "442099939",
    "type": 1
}'
```

### header参数

| **参数** | **类型** | **是否必填** | **约束** |
| --- | --- | ---- | --- |
| ruixue-productid | String | 是 | 望舒产品 ID |
| ruixue-channelid | String | 是 | 望舒渠道 ID |
| ruixue-language | String | 否 | 用户语言 |

### body请求参数

| **参数** | **类型** | **是否必填** | **约束** |
| --- | --- | ---- | --- |
| rx_mail_id| Number | 否 | 望舒邮件ID（type 字段等于 1 时为必填项） |
| cp_user_id| String | 是 | 游戏用户ID |
| type| Number| 是 | 操作类型：1-领取单封邮件 2-一键领取 |
| region_tag| String | 是 | 区服 |
| role_id| String | 是 | 角色 |

**响应示例**

```json
{
  "code": 0,
  "msg": "",
  "data": {
        "cp_user_id": "442099939",
        "rx_mail_ids": [
            1,
            2
        ]
    }

```
### 响应结构（JSON）

| **参数** | **类型** | **约束** |
| --- | --- | --- |
| cp_user_id | String | 游戏用户ID |
| rx_mail_ids | Array | 领取附件的邮件ID集合，仅在一键领取时有值 |

## 望舒邮件-删除

> **POST:** `/v1/operationtoolsapi/rxmail/cpuser/delete`
> **认证方式：** [Accesstoken](/docs/v3.5/入门指南/服务端接入须知)  PUT时为 [CPSign](/docs/v3.5/入门指南/服务端接入须知)

```bash
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-accesstoken: {{登录token}}' \
--data-raw '{
    "rx_mail_ids": [1],
    "cp_user_id": "442099939",
    "type": 1
}'
```

### header参数

| **参数** | **类型** | **是否必填** | **约束** |
| --- | --- | ---- | --- |
| ruixue-productid | String | 是 | 望舒产品 ID |
| ruixue-channelid | String | 是 | 望舒渠道 ID |
| ruixue-language | String | 否 | 用户语言 |

### body请求参数

| **参数** | **类型** | **是否必填** | **约束** |

## 批量创建望舒邮件

> **PUT:** `/v1/operationtoolsapi/rxmail/batch_send`
> **认证方式：** [CPSign](/docs/v3.5/入门指南/服务端接入须知)

:::warning
只支持服务端调用。
:::

### CURL 示例

```bash
curl --location --request PUT '{{接口域名}}/v1/operationtoolsapi/rxmail/batch_send' \
--header 'ruixue-productid: {{产品id}}' \
--header 'ruixue-channelid: {{渠道id}}' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-accesstoken: {{登录token}}' \
--header 'Content-Type: application/json' \
--data-raw '{
    "user_info":{
        "products":[],
        "channels":[],
        "cp_user_ids":["441450857"]
    },
    "role_info": {
        "region_tag": "ceshi",
        "role_ids": ["3"]
    },
    "prop_info":[{
        "name": "name",
        "tag":"tag",
        "count":1
    }],
    "mail_info": {
        "zh": {
            "title": "title",
            "content":"content",
            "sign":"sign"
        }
    },
    "mail_default_language": "zh"
}'
```

### body请求参数

| **参数** | **类型** | **是否必填** | **约束** |
| --- | --- | ---- | --- |
| user_info| Object | 否 | 用户信息（非区服游戏为必填项） |
| role_info| Object | 否 | 角色信息（区服游戏为必填项） |
| prop_info| Array| 否 | 道具信息 |
| mail_info| Object | 是 | 邮件信息 |
| mail_default_language| String | 是 | 邮件默认语言,支持 "中文简体:zh","中文繁体:tc","英语:en","日文:ja","泰文:th","越南文:vi","菲律宾语:tl","印尼语:id","阿拉伯语:ar" |

#### user_info

| **参数** | **类型** | **是否必填** | **约束** |
| --- | --- | ---- | --- |
| products| Array | 否 | 产品范围，不填为不限制 |
| channels| Array | 否 | 渠道范围，不填为不限制 |
| cp_user_ids| Array| 是 | 游戏id， 最多2000人 |

#### role_info

| --- | --- | ---- | --- |

| role_ids| Array | 是 | 角色id，最多2000人 |

#### prop_info

| **参数** | **类型** | **是否必填** | **约束** |

| is_permanent| Number | 否 | 是否永久有效 0永久1非永久 |
| time_limit| Number| 否 | 非永久有效道具的有效期（天） |

#### mail_info

| **参数** | **类型** | **是否必填** | **约束** |
