:::tip
3.7.33 以上支持，引入 SDK 即可。
:::

## SDK集成(国内)
```groovy
  implementation 'com.ruixue:rxsdk_openinstall:${version}'
```

## SDK集成(海外)
```groovy
  implementation 'com.ruixue:rxsdk_openinstall_os:${version}'
  // 如果“下载配置”中的下载地址配置的是应用的Google Play地址，则可以添加以下依赖，用于提升 Google Play 商店下载时参数还原精度
  implementation "com.android.installreferrer:installreferrer:2.2"
```

## 配置说明
- 在 AndroidManifest.xml 配置
    - meta-data 配置 appkey
    - 一键拉起配置，一般为 MainActivity 中配置 scheme
```xml

    <!-- meta-data 配置 appkey -->
    

    
        
            
            ...
            <!-- 追加一个 intent-filter 并配置scheme -->
            
                
                
                
                
            
            

```
