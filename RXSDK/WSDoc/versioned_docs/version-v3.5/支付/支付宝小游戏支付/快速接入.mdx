## 望舒支付配置

[支付宝小游戏支付配置](/docs/v3.5/支付/支付宝小游戏支付/快速接入)

## 下单支付

### 参数说明

| **字段** | **类型** | **是否必填** | **备注** |
| --- | --- | ---- | --- |
| params | IPay | 是 | 参数 |
| callback | IMethodParams | 是 | 回调函数集合 |

> IPay 说明

| **字段** | **类型** | **是否必填** | **备注** |
| --- | --- | ---- | --- |
| pay\_type | string | 是 | 支付的类型 |
| goods\_tag | string | 是 | 计费点标识 |
| count | number | 是 | 数量 |
| zoneId | number | 否 | **(pay\_type为minigame\_alipay\_virtual的时候必传)** 游戏服务区 id，自定义。游戏不分大区则默认填写"1"。如果游戏支持多角色，“分区ID\_角色ID”，必须用“\_”连接。 |
| trade\_no | string | 是 | CP 订单号 |
| currency | string | 否 | 币种 默认传: CNY 根据支付币种传递[国家编码 币种字典](/docs/v3.5/支付/功能介绍) |
| indulge\_auth | number | 是 | 是否进行防沉迷支付验证 ，0 不验证 1 验证，默认不验证
如果为 1 age 必传 |
| notify\_url | string | 否 | 支付成功通知 CP 发货地址 |
| age | number | 否 | 用户年龄
indulge\_auth 为 1 时必传该字段 |
| transmit\_args | string | 否 | 客户端透传参数，key1=val1&key2=val2 的格式 |
| is\_debug | number | 否 | 是否测试订单，0 正式 1 为测试订单，默认为 0 |
| env | number | 否 | 是否使用沙盒环境支付，0 正式 1 沙盒，默认为 0 |
| game\_info | object | 否 | 游戏自定义数据， 上报区服和角色需要在 game\_info 中传入属性，具体使用方式参考下方 game\_info 字段说明  |
| bigdata\_report | object | 否 | 商业化支付参数， 通过商业化触发的支付行为要传以下参数，否则数据统计会有丢失，具体使用方式参考下方 bigdata\_report 字段说明  |

> `bigdata_report` 字段说明

| **字段** | **类型** | **是否必填** | **备注** |
| --- | --- | ---- | --- |
| scene\_identifier | string | 否 | 场景标识 |
| scene\_name | string | 否 | 场景名称 |
| trigger\_button\_identifier | string | 否 | 触发按钮标识 |
| trigger\_button\_name | string | 否 | 触发按钮名称 |
| window\_identifier | string | 否 | 窗口标识 |
| window\_name | string | 否 | 窗口名称 |
| window\_sequence | string | 否 | 窗口展示顺序 |
| gift\_package | object | 否 | 礼包 |

> `gift_package` 字段说明

| **字段** | **类型** | **是否必填** | **备注** |
| --- | --- | ---- | --- |
| identifier | string | 否 | 礼包标识 |
| name | string | 否 | 礼包名称 |
| purchase\_medium | string | 否 | 购买礼包介质 |
| price | number | 否 | 礼包价格 |
| billing\_point | string | 否 | 礼包计费点 |

> `game_info` 字段说明

| **字段** | **类型** | **是否必填** | **备注** |
| --- | --- | ---- | --- |
| cp\_game\_character\_id | string | 否 | 角色 id |
| cp\_game\_area\_id | string | 否 | 区服 id |

> pay\_type 说明

| **字段** | **备注** |
| --- | --- |
| minigame\_alipay | 支付宝小游戏支付 |
| minigame\_alipay\_virtual | 支付宝小游戏虚拟币支付（iOS） |

> IMethodParams 说明

| **字段** | **备注** |
| --- | --- |
| complete | (data) => void
complete：为函数且必传，data 为结果数据 |

**调用示例**

```javascript
sdk.pay(
  {
    pay_type: "minigame_alipay",
    goods_tag: "minigame_tag",
    trade_no: "" + new Date().getTime(),
    transmit_args: "a=1&b=2",
    indulge_auth: 1,
    age: 18,
    zoneId: "1"
    
    // 商业化下单参数示例
    // 'bigdata_report': {
    //   'scene_identifier': 'xxx',
    //   'scene_name': 'xxx',
    //   'trigger_button_identifier': 'xxx',
    //   'trigger_button_name': 'xxx',
    //   'window_identifier': 'xxx',
    //   'window_name': 'xxx',
    //   'window_sequence': 'xxx',
    //   'gift_package': {
    //     'identifier': 'xxx',
    //     'name': 'xxx',
    //     'purchase_medium': 'xxx',
    //     'price': 100,
    //     'billing_point': 'xxx',
    //   },
    // }
           
    // 游戏自定义数据示例
    // 'game_info': {
    //   'cp_game_character_id': 'test',
    //   'cp_game_area_id': 'testarea',
    // }
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);
```

### 响应结构

| **字段** | **类型** | **备注** |
| --- | --- | --- |
| code | number | 0 : 表示成功
 4001 : 取消支付 |

## 补单

### 查询是否需要补单

**调用示例**

```javascript
// 同步函数
const compensateOrderInfo = sdk.checkHasCompensatePayOrder();
```

#### 响应结构

| **字段** | **类型** | **备注** |
| --- | --- | --- |
| code | number | 0 : 表示成功，需要补单 
-1：不需要补单 |
| msg | string | 'had': 需要补单 ，'null'：不需要补单 |
| check | object | 补单信息，需要补单时有此字段 |
| data | object | null，不需要补单时有此字段 |

> check 补单信息

| **字段** | **类型** | **备注** |
| --- | --- | --- |
| notify\_url | string | 回调的地址 |
| order\_no | string | 订单号 |

### 补单

:::tip
参数从查询是否需要补单接口获取

:::

#### 参数说明

| **字段** | **类型** | **是否必填** | **备注** |
| --- | --- | ---- | --- |
| params | ICheckOrder | 是 | 参数 |
| callback | IMethodParams | 是 | 回调函数集合 |

> ICheckOrder 说明

| **字段** | **类型** | **是否必填** | **备注** |
| --- | --- | ---- | --- |
| notify\_url | string | 是 | 回调的地址 |
| order\_no | string | 是 | 订单号 |

> IMethodParams 说明

| **字段** | **备注** |
| --- | --- |
| complete | (data) => void
complete：为函数且必传，data 为结果数据 |

**调用示例**

```javascript
sdk.compensatePayOrder(
  {
    notify_url, //回调的地址
    order_no, //订单号
  },
  {
    complete: (data) => {
      console.log(data); //code为0即为补单成功其他均为失败
    },
  }
);
```
