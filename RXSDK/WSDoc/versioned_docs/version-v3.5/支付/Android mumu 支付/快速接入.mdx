#### 望舒支付配置
[mumu支付配置](/docs/v3.5/三方服务/mumu模拟器/Android)
#### 接口原型

```java
/**
 * 支付
 * @param activity 应用上下文对象
 * @param hashMap  PayParams 参数，参照参数说明
 * @param callback 回调函数
 */
pay(Activity activity, @NonNull Map map, RXJSONCallback callback)
```

#### 参数说明

> Map 结构说明

| **字段**      | **类型** | **是否必填** | **说明**                                                                                                                                         |
| ------------- | -------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| hq_type      | string   | 否           | 支付类型                                                                                      |
| goods_tag     | string   | 是           | 望舒计费点标识                                                                                                                     |
| trade_no      | string   | 是           | 商户订单号                                                                                                                                       |
| transmit_args | string   | 否           | 透传参数                                                                                                                                         |
| notify_url    | string   | 否           | 支付成功通知 CP 发货地址                                                                                                                         |
| currency      | string   | 是           | 币种 全大写 国内传: CNY，参考 [国家编码 币种字典](/docs/v3.5/支付/功能介绍)|
| ext           | object   | 否           | 支付下单扩展信息，不同渠道具体对接                                                                                                               |
| indulge_auth  | int      | 否           | 默认(自运营渠道默认值 1 ,三方渠道默认值 0 )， 是否进行防沉迷验证 ，0 不验证、1 验证。                                                            |
| age           | int      | 否           | 默认取登录返回 age 字段                                                                                                                          |
| game_info     | object    | 否           | 游戏自定义数据， 上报区服和角色需要在 game_info 中传入属性，具体使用方式参考下方 game_info 字段说明  |
| bigdata_report     | HashMap    | 否           | 商业化支付参数， 通过商业化触发的支付行为要传以下参数，否则数据统计会有丢失，具体使用方式参考下方 bigdata_report 字段说明  |
| custom_ext          | Map  | 否           | 自定义透传参数
      
> custom_ext 结构说明

| **字段**     | **类型** | **是否必填** | **备注**                                                                                                                                             |
| ------------ | -------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| bigdata_ext     | Map | 否           | 大数据预置事件透传参数                                                                       |

> `bigdata_report` 字段说明

| **字段**  | **类型** | **是否必填** | **备注** |
| --------- | ------  | ----------- |---------|
| scene_identifier| string| 否             | 场景标识                           |
| scene_name     | string| 否            | 场景名称                          |
| trigger_button_identifier     | string| 否            | 触发按钮标识                         |
| trigger_button_name     | string| 否            | 触发按钮名称                         |
| window_identifier     | string| 否            | 窗口标识                         |
| window_name     | string| 否            | 窗口名称                         |
| window_sequence     | string| 否            | 窗口展示顺序                         |
| gift_package     | HashMap| 否            | 礼包	                         |

> `gift_package` 字段说明

| **字段**  | **类型** | **是否必填** | **备注** |
| --------- | ------  | ----------- |---------|
| identifier| string| 否             | 礼包标识                           |
| name     | string| 否            | 礼包名称                          |
| purchase_medium     | string| 否            | 购买礼包介质                         |
| price     | int| 否            | 礼包价格                         |
| billing_point     | string| 否            | 礼包计费点                         |

> `game_info` 字段说明

| **字段**  | **类型** | **是否必填** | **备注** |
| --------- | ------  | ----------- |---------|
| cp_game_character_id| string| 否             | 角色 id                           |
| cp_game_area_id     | string| 否            | 区服 id                           |

> `hq_type值` 说明

| **hq_type值** | **备注**                                                             |
|---------------|--------------------------------------------------------------------|
| mumu          | mumu 渠道支付，请先参考三方渠道接入说明！[快速入口](/docs/v3.5/三方服务/Android 渠道接入说明) |
