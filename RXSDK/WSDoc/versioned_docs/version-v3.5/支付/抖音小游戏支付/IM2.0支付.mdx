# 准备
## 绑定抖音IM客服
## 
操作路径：访问 [指定链接 ](https://microapp.bytedance.com/game/tt05f973449ac0036302/traffic-other/customer)→ 运营 → 功能 → 客服管理 → 抖音IM客服。

作用：用户充值相关问题将统一通过此客服咨询。

注意：请勿用绑定的抖音号进行支付测试，否则无法拉起客服界面。

未配置报错：fail im disable。

## 测试账号与环境

测试账号：用户已全量，无需加白测试UID。建议使用有历史游玩记录的账号。

新账号规则：若使用新账号，需先游玩20分钟以上，次日再进行测试。

进入方式：使用侧边栏等入口进入，不要使用搜索功能进入。

测试设备：建议使用手机或平板，Mac/PC端暂无此功能。

### 问题原因及处理
**报错 fail im disable：**  未完成抖音IM客服的绑定配置。	按照【一、配置】中的步骤完成客服绑定。
**出现“苹果系统支付不可用”或“钻石支付收银台”提示：**	该用户UID被策略排除。	1. 不从搜索场景进入，改用常规复访场景（如侧边栏）进入测试。
2. 若钻石余额充足，展示钻石支付是正常现象，可尝试更换更大金额的订单测试。
3. 请勿使用VPN等网络代理工具访问。
**无法拉起客服界面：**	使用了绑定的抖音号进行支付测试。	更换其他非绑定的抖音号进行测试。
**支付后游戏币未到账：**	充值存在延迟到账情况。	按照【一、配置】中的“延迟到账处理”方法，轮询查询余额直至确认到账。
**支付回调成功但实际未充值：**	回调仅表示拉起客服界面成功，与实际支付结果无关。	支付是否成功，需通过服务端接口查询余额自行确认。

### 支付逻辑
#### 1、支持IM2.0
    当支付金额大于0.6元时
    开启后符合条件的账号走客服支付， 否则走钻石支付
    未开启走钻石支付
#### 2、小额支持IM2.0
    当支付金额小于0.6元时
    开启后符合条件的账号走客服支付， 否则走小额支付
    未开启走小额支付
