> 使用 wxpub h5 支付方式必须在望舒后台 [运营管理]>[微信客服回复] 配置对应的卡片模版

# 创建微信公众号 H5 自动回复卡片

<strong>Step1：</strong>进入望舒平台首页，点击左侧菜单【运营管理】-【微信客服回复】。

<strong>Step2：</strong>在页面上方，选择产品。

<strong>Step3:</strong> 点击【添加回复】按钮

<strong>Step4：</strong>输入信息后，点击右下角的【保存】按钮，保存已填写的信息。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/zz/YTfBbQKNoovo7mx5dsmcreTenMf.png)

<strong>Tips：</strong>

1. 带\*的字段为必填字段。
2. 匹配关键字固定为 `ruixue_pay_wxpub`
3. sdk 内置参数 {'{'}priceYuan{'}'} 在展示充值图文链接时 会替换为用户的充值金额
4. sdk 内置参数 {'{'}order\_no{'}'} 在展示充值图文链接时 会替换为用户的订单号
5. sdk 内置参数{'{'}url{'}'}为卡片跳转地址 请勿修改
