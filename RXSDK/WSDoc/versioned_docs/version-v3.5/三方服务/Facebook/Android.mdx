```json
//海外渠道引用此库
  implementation 'com.ruixue:rxsdk_overseas:${version}'
```

## 参数说明

| 参数                    | 类型   | 说明                                    |
| ----------------------- | ------ | --------------------------------------- |
| facebook_app_id       | Long   | strings.xml 内配置　FACEBOOK_APP_ID　值 |
| facebook_client_token | String | strings.xml 内配置                      |

## 配置说明

- 在 `src/mian/res/values/strings` 文件下

```xml
268619981955495
0799c45bcb03a3153cbfba1920dee0e8
```

- 在 AndroidManifest.xml 配置

```xml

    
    

```

`注`：由于 meta-data 不支持 long 数据类型，如果配置的值为数字类型，则默认为 int 值，导致无法参数错误，所以参数需要配置在 `strings.xml` 文件内。

- 在您的项目中，打开 your_app | Gradle Scripts | build.gradle (Module: app) 并将以下语句添加到 defaultConfig{'{'}{'}'} 部分：

```groovy
manifestPlaceholders = [
    FACEBOOK_APP_ID    : "xxxxxxx"
]
```
