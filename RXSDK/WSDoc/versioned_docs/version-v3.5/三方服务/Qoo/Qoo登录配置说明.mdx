## 准备工作

::: tip
Qoo开发者中心：[https://open.qoo-app.com/](https://open.qoo-app.com/)

望舒系统地址：[企业管理后台中获取望舒地址](/docs/v3.5/入门指南/准备工作)。
:::

## 登录配置

### Qoo 获取公钥

1. 登录 [Qoo开发者中心](https://open.qoo-app.com/)，位置：**Qoo开发者中心 > 我的应用> 开发工具**。
2. 获取关键配置：`公钥`。
:::tip
应用未发布上线之前只能使用沙盒参数进行配置以及客户端初始化。发布后切换到正式参数。
:::
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1761102246550.png)

### 望舒系统中配置登录信息

1. 从 [Qoo开发者中心](https://open.qoo-app.com/)获取 `公钥` 信息。
2. 复制到望舒系统，位置：**渠道管理管理  > 渠道包管理 > 添加Qoo登录方式**。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1761102411602.png)
