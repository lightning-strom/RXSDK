## SDK 集成
```
implementation 'com.ruixue:rxsdk_snapchat:${version}'
```
## 参数说明
| 参数 | 类型 | 说明 |
| ---- | ---- | ---- |
| clientId | String | 在开发者后台查看，配置到下面 meta-data com.snap.kit.clientId |
| redirectUrl | String | 在开发者后台查看，配置到下面 com.snap.kit.redirectUrl |

## 配置说明
- 在 AndroidManifest.xml 配置
```

    

    
    
    
        
            
            
            
            <!--
                Enter the parts of your redirect url below
                e.g., if your redirect url is myapp://snap-kit/oauth2
                    android:scheme="myapp"
                    android:host="snap-kit"
                    android:path="oauth2"
            !-->
            
        

    
           
 
```
