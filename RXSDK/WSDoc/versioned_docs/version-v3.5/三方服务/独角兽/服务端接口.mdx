## 数据上报

> **POST：** /v1/thirdparty/unicorn/report

### 服务端请求头

| **参数名** | **说明** | **是否必须** | **示例** |
| --- | --- | ---- | --- |
| ruixue-traceid | 本次请求唯一标识
格式为 UUID v4，当接口出现错误时可将其提供给望舒团队对问题进行快速定位 | 是 | 0e2971af-823a-4298-b7d8-3ef38094b500 |
| ruixue-cpid | 望舒 CPID
望舒为每个 CP 分配的一个唯一 ID，从 7 位数 1000000 开始递增 | 是 | 1000000 |
| ruixue-cpts | 时间戳
CP 服务端发起请求时的毫秒时间戳 | 是 | 1669619948739 |
| ruixue-language | 语言标识
系统语言标识 | 否 | zh-CN |
| ruixue-productid | 产品标识
CP 望舒集群内部的产品 ID，由各 CP 自行在后台创建，字符串类型 | 是 | test |
| ruixue-region | 数据域标识
CP 游戏服的分区信息 | 否 | default |
| ruixue-cp-role-id | 数据域标识
CP 游戏服的角色信息 | 否 | default |

### 请求参数（JSON）

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | ---- | --- | --- |
| action | String | 是 | 上报动作 | 登录：login
创角：register
支付：payment
退出：login\_out |
| data | DataObject | 是 | 上报数据 |  |

#### DataObject（action=login ）

<a href="https://www.showdoc.com.cn/aliujunx/4108954101393461">链接文本</a>

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | ---- | --- | --- |
| who | string | 是 | 用户角色ID：该ID由CP自定义 , 保证每个区的who为唯一值。 |  |
| deviceid | string | 是 | 各渠道的UID（用户身份标识）。 |
| appid | string | 是 | APPID：该ID由独角兽在游戏接入前分配，是游戏的唯一标识。 |
| serverid | string | 是 | 区服ID：该ID由CP自定义，一般是指角色所在的区服标识。 |
| level | string | 是 | 角色等级：数据上报时的角色等级。 |
| channelid | string | 是 | 渠道ID |
| subchid | string | 是 | 子渠道 ID |  |
| system | string | 是 | 操作系统 （android，ios ，pc） |  |
| si | string | 否 |  |  |
| power | string | 是 | 战斗力数据（或其他等价数据） |  |
| rolename | string | 是 | 角色昵称 |  |
| server\_name | string | 否 | 区服 |  |
| vip | string | 是 | VIP等级 |  |
| extInfo | string | 否 | 获取登录url上面extInfo透传参数，没有为“” |  |

**请求示例**

```bash
curl --location --request POST '{{接口域名}}/ /v1/thirdparty/unicorn/report' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--data-raw '{
    "action":"login",
    "data":{
        "who": "xxx",
        "deviceid": "xxx",
        "appid" : "xxx",
        "serverid" : "xxx",
        "level" : "xxx",
        "system": "xxx",
        "power" : "xxx",
        "rolename" : "xxx",
        "server_name" : "xxx"
    }
}'
```

### 响应参数（JSON)

**HTTP 状态码：**`200 OK`

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | ---- | --- | --- |
| code | Number | 是 | 响应状态码，0为成功，非0表示出错 | 0 |
| msg | String | 否 | 响应信息，仅在code为非0时不为空 |  |

**响应示例**

```json
{
    "msg":"",
    "code": 0
}
```
