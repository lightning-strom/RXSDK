## 支付

```java

    Map hashMap = new HashMap<>();
    // 计费点
    hashMap.put("goods_tag", "计费点");
    // 米大师支付方式
    hashMap.put("type", "aptoide");
    // 订单号
    hashMap.put("trade_no", String.valueOf(System.currentTimeMillis()));
    RXSdkApi.getInstance().pay(this, hashMap, new RXRequestCallback() {
        @Override
        public void onResponse(JSONObject jsonObject) {
            Log.d("ChannelDemoActivity", "支付：" +jsonObject.toString());
        }
    })
```
