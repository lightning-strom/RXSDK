## 检测用户社媒建联状态

> **POST：**  `/v1/thirdparty/service_api/check_social_bind`
> **认证方式：** [CPSign](/docs/v3.5/入门指南/服务端接入须知)

### CURL 示例

```bash
curl --location --request POST '{{接口域名}}/v1/thirdparty/service_api/check_social_bind' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--data-raw '{
    "open_id" : "rxu1234567890"
}'
```

### 请求参数（JSON）

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | --- |
| open_id | String | 是   | 望舒 openid  |     |
| language | String | 否   | 语言  |     |
| accounts | []String | 否   | 媒体账号  |     |

### 枚举值（language）
| **code**  | **说明** |
| --- | --- |
| zh | 中文简体 | 
| tc | 中文繁体 | 
| en| 英语| 
| ja| 日文| 
| th| 泰文| 
| vi| 越南文| 
| tl| 菲律宾语| 
| id| 印尼语| 
| ar| 阿拉伯语| 

**请求示例**

```json
{
    "open_id" : "rux***********",
    "language": "zh",
    "accounts": ["line***", "whatsapp***"]
}
```

### 响应参数（JSON)

**HTTP 状态码：**`200 OK`

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | --- |
| code | Number | 是   | 响应状态码，0为成功，非0表示出错 | 0   |
| msg | String | 否   | 响应信息，仅在status为非0时不为空 |     |
| data | [Node](/docs/v3.5/三方服务/人群包/服务端接口) | 否   | 响应信息，仅在status为非0时不为空 |     |

##### Node

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | --- |
| open_id | String | 是   |  望舒openid  |     |
| cpid | Number | 是   |  cpid  |     |
| bind_status | [][Bind](/docs/v3.5/三方服务/智齿/服务端接口)  | 否   | 建联状态  |     |
| redirect_urls | [][Redirect](/docs/v3.5/三方服务/智齿/服务端接口)  | 是   | 跳转链接 |   |

##### Bind

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | --- |
| account | String | 是   |  媒体账号  |     |
| bind_status | Number | 是   |  建联状态  |  1:建联   |

##### Redirect

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | --- |
| source | String | 是   |  媒体  |  LINE / WhatsApp / Messenger   |
| account | String | 是   |  媒体账号  |     |
| link | String | 是   |  跳转链接  |    |
| language | String | 是   |  语言  |     |
