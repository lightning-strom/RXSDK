## 登录配置
### 苹果开发者后台配置
1. 在“证书、标识符和描述文件” 中，点按边栏中的“Identifiers”(标识符)，然后点按左上方的添加按钮 (+)。

2. 选择“Services ID”(服务 ID)，然后点按“Continue”(继续)。
![img_v3_02l1_c050640f-216f-42d9-841a-a01c6939257g.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/img_v3_02l1_c050640f-216f-42d9-841a-a01c6939257g-1743749967883.png)
3. 输入服务 ID 说明并提供唯一标识符。
4. 注册服务 ID，并从列表中选择它以开始配置。
5. 选择“Sign in with Apple”(通过 Apple 登录)，然后点按“Configure”(配置)。
![img_v3_02l1_fb001afb-e4c8-490b-bff1-79ca07325f3g.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/img_v3_02l1_fb001afb-e4c8-490b-bff1-79ca07325f3g-1743749983706.png)
6. 在出现的模式中，从主要 App ID 列表中选择与你网站相关的 App。

7. 在“Website URLs”(网站 URL) 下，以逗号分隔的列表形式提供你的域名、子域名或返回 URL。你必须提供至少一个域或子域。
:::tip
Domains and Subdomains 不需要添加 **https://**

图中配置为示例，请填写实际配置
:::
