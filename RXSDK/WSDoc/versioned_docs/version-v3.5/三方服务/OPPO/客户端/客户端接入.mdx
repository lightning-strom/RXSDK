## SDK集成

```json
//oppo渠道库
  implementation 'com.ruixue:rxsdk_oppo:${version}'
```

## 参数说明

| **参数**  | **类型** | **说明**              |
| --------- | -------- | --------------------- |
| appSecret | String   | initThirdSdk 接口传入 |
| appkey    | String   | OPPO_APP_KEY 值       |

## 配置说明

- 在您的项目中，`打开 your_app | Gradle Scripts | build.gradle (Module: app)` 并将以下语句添加到 `defaultConfig{}` 部分：

```groovy
manifestPlaceholders = [
    OPPO_APP_KEY    : "xxxxxxx"
]
```

- 在 `build.gradle` 文件的 `allprojects{repositories{}}` 块中引用中需要添加配置

```groovy
//oppo
  maven {
      url 'https://maven.columbus.heytapmobi.com/repository/releases/'
      credentials {
          username 'nexus'
          password 'c0b08da17e3ec36c3870fed674a0bcb36abc2e23'
      }
  }
```

## 初始化
[参考这里](/docs/v3.5/入门指南/快速开始/Android初始化/快速接入)
```java
Map params = new HashMap<>();

// 这里填写使用方自己对应的参数
params.put("appSecret", "");
RuiXueSdk.getApi().initThirdSdk(this, params, new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject jsonObject) {
        Log.d(TAG, "init third sdk success");
    }

    @Override
    public void onFailed(@NonNull JSONObject jsonObject) {
        Log.d(TAG, "init third sdk failed " + jsonObject);
    }
});
```

## 登录 (必须接入) 请一定确保要初始化成功再调用登录
请参考 [Android端登录API](/docs/v3.5/登录（通行证）/Android 登录API/快速接入)
参考代码
```java
String username = null;
String loginType = LoginMethod.OPPO;
String captchaCode = null;
String loginOpenId = null;
Map ext = null;
String[] signFields = null;
Object migrateArgs = null;
RuiXueSdk.getApi().login(DemoActivity.this, loginType, username, password, captchaCode, loginOpenId, ext, signFields, migrateArgs, new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject data) {
        Toast.makeText(DemoActivity.this, "登录成功", Toast.LENGTH_SHORT).show();
    }

    @Override
    public void onFailed(@NonNull JSONObject cause) {
        Toast.makeText(DemoActivity.this, "登录失败", Toast.LENGTH_SHORT).show();
    }
});
```

## 退出(在游戏主页面退出时需要添加)
[参考这里](/docs/v3.5/入门指南/快速开始/Android初始化/快速接入)
参考代码
```java
 RuiXueSdk.exitApp(this, new OnAppExitCallback() {
    @Override
    public void onExitConfirm(@Nullable String res) {
        Toast.makeText(QuickDemoActivity.this, "退出游戏成功", Toast.LENGTH_SHORT).show();
    }

    @Override
    public void onExitCancel() {
        Toast.makeText(QuickDemoActivity.this, "退出游戏取消", Toast.LENGTH_SHORT).show();
    }
});
```
