## SDK 集成

```gradle
  implementation 'com.ruixue:rxsdk_topon:${version}'
```

## AndroidManifest.xml 配置

- 如果聚合了Admob，则必须在AndroidManifest.xml中添加以下配置（value值需配置Admob后台创建的应用的ID）：

```xml
    
        
            <!-- Sample AdMob App ID: ca-app-pub-3940256099942544~3347511713 -->
            
        
    
```

## 初始化TopOn 

```java
    HashMap map = new HashMap<>();
    map.put("topon_app_id", "xxx");
    map.put("topon_app_key", "xxx");

    RuiXueSdk.getApi().initThirdSdk(activity, map, new RXJSONCallback() {
        @Override
        public void onSuccess(@Nullable JSONObject data) {
            RXLogger.e("demo rx third init success: " + data.toString());
        }

        @Override
        public void onFailed(@NonNull JSONObject cause) {
            RXLogger.e("rx third init failed :" + cause);
        }
    });
```

## 其它方法

```java
    //SDK日志功能，集成测试阶段建议开启，上线前必须关闭
    TopOnHelper.setNetworkLogDebug(true);
    //SDK版本
    Log.i("TopOnSDkWrapper", "TopOn SDK version: " + TopOnHelper.getSDKVersionName());
    //检查广告平台的集成状态，提交审核时需注释此API
    TopOnHelper.integrationChecking(activity);
    //(v5.7.77新增) 打印当前设备的设备信息(IMEI、OAID、GAID、AndroidID等)
    TopOnHelper.testModeDeviceInfo(activity, new DeviceInfoCallback() {
        @Override
        public void deviceInfo(String deviceInfo) {
            Log.i("TopOnSDkWrapper", "deviceInfo: " + deviceInfo);
        }
    });
```
