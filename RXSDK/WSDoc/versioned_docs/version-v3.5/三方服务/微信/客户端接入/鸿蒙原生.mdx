## 商家转账
**接口原型**
``` typescript
  /**
   * 调起微信客户端指定业务视图（适配微信Open SDK商家转账等业务场景）
   * 功能说明：异步调起微信客户端对应的业务页面（如商家转账用户确认页），通过Promise返回业务交互结果
   * 官方文档：https://pay.weixin.qq.com/doc/v3/merchant/4012719576
   * @param params 业务调起参数集合，键值对格式，所有可选参数需与微信SDK业务要求一致
   * @param params.wx_appid 微信 appid
   * @param params.businessType 业务类型标识（可选）默认"requestMerchantTransfer" ，固定值需遵循微信SDK约定（如商家转账传"requestMerchantTransfer"）
   * @param params.query 业务查询参数（必填），格式为key=value&key2=value2（value需做UrlEncode处理）
   *                     商家转账场景必传字段：mchId（商户号）、appId（应用ID）、package（转账单package_info）
   * @param params.extInfo 业务扩展信息（可选），额外补充的业务参数，根据具体业务场景传入
   * @param callback 可选同步回调函数，用于额外的结果通知（优先级低于Promise返回值，可按需传入）
   * @returns Promise 异步返回结果Promise，RXResult包含业务交互状态（成功/失败/取消）及扩展信息
   * @注意事项：
   * 1. 返回结果仅代表微信页面交互状态，不代表业务最终执行结果（如转账成功需调用微信查询接口核实）
   * 2. 若微信未安装、版本过低或参数非法，Promise会返回失败状态及对应错误码/错误信息
   * 3. query参数中的特殊字符需进行UrlEncode处理，避免解析失败导致调起异常
   */
openBusinessView(params: Record, callback?: RCallback): Promise

```

### 参数说明

| **参数** | **类型** | **说明**     |
| -------- | -------- | ------------ |
| wx_appid | String |  微信 appid |
| businessType | String | 【业务类型】固定配置：requestMerchantTransfer |
| query | String | 【查询参数】使用URL的query string方式传递参数，格式为key=value&key2=value2，其中value、value2需要进行UrlEncode处理。 |

> query 说明

| **参数** | **类型** | **说明**     |
| -------- | -------- | ------------ |
| mchId | String | 【商户号】商户号，由微信支付生成并下发，和发起转账传入的mchid必须是同一个 |
| appId | String | 【商户AppID】微信开放平台审核通过的移动应用appid，和发起转账传入的appid必须是同一个 |
| package | String | 【package信息】对应发起转账接口应答参数中的package_info（仅当转账单据状态为WAIT_USER_CONFIRM: 待收款用户确认时才返回），用于唤起用户确认收款页面。|

**调用示例**
``` typescript
let appId = "wx8888888888888888"
let query = "mchId=1230000000&appId=wx8888888888888888&package=affffddafdfafddffda%3D%3D"
RXApi.getInstance().wechat().openBusinessView({ "wx_appid": appId, "query": query }, (ret) => {
  this.showText(ret)
})

```
