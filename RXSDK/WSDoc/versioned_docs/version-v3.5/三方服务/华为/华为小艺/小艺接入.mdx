## 使用华为小艺前提
- 接入华为渠道 [链接](/docs/v3.5/三方服务/Android 渠道接入说明)
- 登录成功后

## 绑定设备API
```java
 HmsSdkHelper.bindDeviceForXiaoYi(new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject data) {
        // 绑定成功
    }

    @Override
    public void onFailed(@NonNull JSONObject cause) {
        // 绑定失败
    }
});
```
