## 配置说明

- 需要在华为开发者平台 AppGallery Connect 中在 `项目设置>常规>` 下载 `agconnect-services.json` 文件并将其放在 app 根目录下。
- 在 app 根目录下 `build.gradle` 添加AGC插件配置,请根据实际情况选择.

```groovy
//方式一：在文件头部声明下一行添加
apply plugin: 'com.huawei.agconnect'

//方式二：在 `plugins` 添加
plugins {
    id 'com.android.application'
    id 'com.huawei.agconnect'
}
```

- 在您的项目根目录中，打开 `your_app | Gradle Scripts | build.gradle (Project)` 并添加以下存储库：

```groovy
buildscript {   
   dependencies {
         //华为
        classpath 'com.huawei.agconnect:agcp:1.9.1.300'
    }
}

allprojects {
    repositories {
        // 华为的库的仓库地址
        maven { url 'https://developer.huawei.com/repo/' }
    }
}
```

**为满足监管要求，集成SDK后要求用户在未同意访问网络前不能发送任何网络请求，如何处理？**

- 用户在未同意访问网络前请不要调用 initThirdSdk 接口初始化三方SDK
- 提供了设置能否发送网络请求的能力，在AndroidManifest.xml的Application中增加如下meta-data配置，value配置为false，表示未同意协议前不发送网络请求。

## 初始化 SDK（必接）
```java
Map params = new HashMap<>();

// 这里填写使用方自己对应的参数
params.put("force_update", false);
RuiXueSdk.getApi().initThirdSdk(this, params, new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject jsonObject) {
        Log.d(TAG, "init third sdk success");
    }

    @Override
    public void onFailed(@NonNull JSONObject jsonObject) {
        Log.d(TAG, "init third sdk failed " + jsonObject);
    }
});
```

## 登录 (必须接入) 
请参考 [Android端登录API](/docs/v3.5/登录（通行证）/Android 登录API/快速接入)
参考代码
```java
String username = null;
String loginType = LoginMethod.HUAWEI;
String password = null;
String captchaCode = null;
String loginOpenId = null;
Map ext = null;
String[] signFields = null;
Object migrateArgs = null;
RuiXueSdk.getApi().login(DemoActivity.this, loginType, username, password, captchaCode, loginOpenId, ext, signFields, migrateArgs, new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject data) {
        Toast.makeText(DemoActivity.this, "登录成功", Toast.LENGTH_SHORT).show();
    }

    @Override
    public void onFailed(@NonNull JSONObject cause) {
        Toast.makeText(DemoActivity.this, "登录失败", Toast.LENGTH_SHORT).show();
    }
});
```

    }

    @Override
    public void onExitCancel() {
        Toast.makeText(DemoActivity.this, "退出游戏取消", Toast.LENGTH_SHORT).show();
    }
});
