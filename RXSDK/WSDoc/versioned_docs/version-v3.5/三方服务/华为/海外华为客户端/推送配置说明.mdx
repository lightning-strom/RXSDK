## 推送配置

### AppGallery Connect 配置推送服务

1. 登录[AppGallery Connect](https://developer.huawei.com/consumer/cn/)，位置：**AppGallery Connect >Project settings> App information**。
2. 复制 `Client ID` 、`Client Secret` 信息。
![38d7f74bc77b0c2656d82ea72712536.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/38d7f74bc77b0c2656d82ea72712536-1732668028051.png)

4. 位置：**AppGallery Connect > Push Kit > Settings>APP**。

![04235e2a78612f28106f4b873ae8fdc.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/04235e2a78612f28106f4b873ae8fdc-1732668125222.png)
4. 点击「modify」修改回执信息。
5. 复制「 ID」信息。
::: tip
api域名/v1/pusher/notify/huawei?product_id=产品ID&channel_id=渠道ID

回执版本V1
:::

6. 确定应用分类信息，[具体参考](https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/faq-0000001050042183)。

### 望舒系统中配置推送信息

1. 从 [AppGallery Connect](https://developer.huawei.com/consumer/cn/)，获取 `Client ID`、`Client Secret`、「回执配置 ID」信息。
2. 复制到望舒系统，位置：**企业管理后台 > 商务管理  > 渠道包管理 > 添加推送方式**。
3. 月活跃用户人数：根据该产品月活评估大致人数填写。具体影响请[参考华为官方文档]![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1732668309013.png)
