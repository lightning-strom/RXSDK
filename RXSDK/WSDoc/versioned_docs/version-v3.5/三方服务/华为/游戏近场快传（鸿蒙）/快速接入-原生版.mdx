本模块提供接入鸿蒙 Nex的游戏近场快传能力。
**系统版本要求**
- 鸿蒙系统起始版本：5.1.0(API Level 18)
- 兼容性校验：可通过 NearbyTransferService.isSupport() 方法检测当前设备是否满足版本要求
- 更多功能说明 ：参照[华为官方文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/gameservice-nearbytransfer-introduction)

# 导入模块
```typescript
import { NearbyTransferService, NearbyEventType } from 'hmssdk';
```
# 开发准备
在工程的entry模块module.json5文件中，新增metadata并配置app_id，同时新增requestPermissions并配置如下权限。

enum NearbyEventType {
  /** 初始化事件：服务初始化完成/失败时触发 */
  init = "init",
  /** 连接通知事件：设备连接状态变化时触发（如连接成功、断开等） */
  connectNotify = "connectNotify",
  /** 发现事件：发送端执行附近设备发现操作时触发 */
  discovery = "discovery",
  /** 错误事件：服务运行过程中出现错误时触发 */
  error = "error",
  /** 传输通知事件：数据传输状态变化时触发（如开始传输、传输完成等） */
  transferNotify = "transferNotify",
  /** 传输数据包事件：接收到或发送数据包时触发 */
  transferPackageData = "transferPackageData",
  /** 接收包信息事件：收到其他设备发送的包信息时触发 */

  /** 回复包信息结果事件：回复包信息后的结果回调 */

  destroy = "destroy",
  /** 自动绑定附近游戏事件：触发自动绑定附近游戏逻辑时回调 */

public registerCallback(event?: NearbyEvent)

 # 注销事件监听
- API 定义
```typescript
  /**
   * 注销附近传输服务的所有事件监听
   * @description 移除底层 `gameNearbyTransfer` 相关原生事件（如连接通知、传输通知、错误等）的监听函数，
   *              停止接收各类事件回调，避免内存泄漏或无效的事件处理

   *       若需重新接收事件，需再次调用 `registerCallback`
   * @throws 内部捕获事件注销过程中的异常并记录日志，不会向外抛出错误
   */
  public unregisterCallback()
```

- 示例代码
```typescript
NearbyTransferService.getInstance().unregisterCallback()
```

   * 手动触发附近设备发现操作
   * @param event - 事件回调函数，用于接收发现过程中的状态通知（如发现结果、错误信息等）
