## 游戏消息同步

> **POST：** `/v1/thirdparty/api/channel_gateway/minigame_xunlei/message.v1.sync`
> **认证方式：** [CPSign](/docs/v3.5/入门指南/服务端接入须知)

### CURL 示例

```bash
curl --location --request POST '{{接口域名}}/v1/thirdparty/api/channel_gateway/minigame_xunlei/message.v1.sync' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
```

### 请求参数（POST）

| <strong>字段</strong> | <strong>类型</strong> | <strong>是否必填</strong> | <strong>说明</strong> | <strong>示例</strong> |
| --- | --- | ---- | --- | --- |
| name | string | 是 | 区服名称 | a1234567 |
| rx\_openid | string | 是 | 望舒openid | xxxxxx |
| server\_id | string | 是 | 区服 ID | s101 |
| server\_create\_time | string | 是 | 开服时间 | 2023-10-01 10:00:00 |
| role\_id | string | 是 | 角色 ID | r920922 |
| role\_name | string | 是 | 角色名称 | 愤怒的小鸟 |
| msg | string | 是 | 消息内容 | xxxx |
| msg\_type | int32 | 是 | 消息类型 ，1 - 世界 、 2 - 私聊、 3 - 其它 | 1 |
| ts | int64 | 是 | 时间戳（unix timestamp） | 1702957771 |

<strong>响应示例</strong>

```json
{
        "code": 0,
        "data": {
            "code":0,
            "message":"success"
        }
}
```

### 响应结构（JSON）

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| code | Number | 望舒错误码 |
| data.code | Number | 业务错误码 |
| data.message | String | 业务信息 |

<strong>返回示例</strong>

```json
{
        "code": 0,
        "data": {
            "code":0,
            "message":"success"
        }
}
```
