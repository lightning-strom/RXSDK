---
title: "阿里一键登录配置"
---

### SDK集成
```
  implementation 'com.ruixue:rxsdk_alimobile:${version}'
```

### 准备工作
1.登录[阿里云](https://www.aliyun.com/)平台
2.查看所需`AccessKey ID`,`AccessKey Secret`信息
![image.png](http://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/1720575300634-image.png)
3.进入**号码认证服务-号码认证方案管理-密钥-复制密钥**该密钥为望舒后台配置需要的`client key`。
![img_v3_02cl_3d2e5168-ba59-4df0-a390-2dde48575e9g.png](http://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/1720575061729-img_v3_02cl_3d2e5168-ba59-4df0-a390-2dde48575e9g.png)
:::tip
相同包名可以使用同一个密钥。包名不同需要重新申请。
:::
### 登录配置
根据获取到的配置信息`AccessKey ID`,`AccessKey Secret`,`client key`添加到望舒。位置：**企业管理后台 > 商务管理  > 渠道包管理 > 添加登录方式> 一键登录**
![image.png](http://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/1720575966861-image.png)
