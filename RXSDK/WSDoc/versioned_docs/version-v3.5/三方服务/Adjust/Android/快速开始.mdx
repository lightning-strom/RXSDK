## 集成 SDK 至您的应用

:::tip
为了增加 Adjust 归因的准确性，需要先调用 望舒设置初始化参数接口，再调用 RXAdust 初始化，否则数据可能会有一定丢失。
:::

**接口原型**

```java
    /**
     * 实例化配置
     * @param context Context上下文
     * @param appToken appToken
     * @param environment 当前环境
     */
    public RxAdjustConfig(Context context, String appToken, String environment);

    /**
     * 初始化 Adjust
     * @param context Context上下文
     * @param rxAdjustConfig 相关配置参数
     */
    public void init(Context context, RxAdjustConfig rxAdjustConfig);
```

**参数说明**
> RxAdjustConfig 说明

| 参数     | 类型   | 说明              |
| -------- | ------ | ----------------- |
| context | Context | 实例化RxAdjustConfig传入 |
| appToken | String | 您可以在 Adjust 控制面板上找到自己的应用识别码。 |
| environment | String | RxAdjustConfig.ENVIRONMENT_SANDBOX 测试环境 
 RxAdjustConfig.ENVIRONMENT_PRODUCTION 生产环境|

::: tip
在进行测试时，应当确保将环境设置为 RxAdjustConfig.ENVIRONMENT_SANDBOX 。请在向 App Store 提交应用程序前将此设为 AdjustConfig.ENVIRONMENT_PRODUCTION 。
:::

**调用示例**

我们建议您使用全局安卓Application类进行 SDK 初始化。如果您的应用中还没有此类，请按照下列步骤操作：

- 创建一个扩展 Application的类。
- 打开 AndroidManifest.xml 文件，找到 \ 元素。
- 添加 android:name 属性，并将其设置为 Application 类的名称。例如，如果您的 Application 类名称为 GlobalApplication：

```xml
 
 
```

- 在 Application 类中找到或添加 onCreate 方法。添加下列代码初始化 Adjust SDK：

```java
public class GlobalApplication extends Application {
    @Override
    public void onCreate() {
        super.onCreate();

        // 为了增加 Adjust 归因的准确性，需要先调用 望舒设置初始化参数接口，再调用 RXAdust 初始化，否则数据可能会有一定丢失。
        RuiXueSdk.setInitParams(cpid, productid, channelid, baseUrl);

        // 可设置 沙盒模式：ENVIRONMENT_SANDBOX  正式模式：ENVIRONMENT_PRODUCTION
        String environment = RxAdjustConfig.ENVIRONMENT_PRODUCTION;
        RxAdjustConfig config = new RxAdjustConfig(this, "{YourAppToken}", environment);
        AdjustSdkWrapper.getInstance().init(this, config);
    }
}
```

## 设置会话跟踪

您需要设置会话跟踪，SDK 才能向 Adjust 后端传送会话信息。请按照下列说明操作，在应用中进行会话跟踪设置。

- 添加一个私有类 (private class) ，以部署 ActivityLifecycleCallbacks 接口。如果您不能访问该接口，则表示应用仅支持安卓 API level 14 以下版本。您需要按照以下 说明更新每个活动。如果您的应用活动中有 Adjust.onResume 和 Adjust.onPause 调用，请将其移除。
- 编辑 onActivityResumed(Activity activity) 方法，添加 Adjust.onResume()调用。编辑 onActivityPaused(Activity activity) 方法，添加 Adjust.onPause()调用。
- 将 onCreate() 方法添加至您的 Adjust SDK 配置步骤。使用已创建 ActivityLifecycleCallbacks 类的实例调用 registerActivityLifecycleCallbacks.

**接口原型**

```java

    /**
     * 通知Adjust页面处于可见
     * @param activity
     */
    @Override
    public void onResume(Activity activity);

    /**
     * 通知Adjust页面不可见
     * @param activity
     */
    @Override
    public void onPause(Activity activity);

```

**调用示例**

**API level 14 及更高**

```java

public class GlobalApplication extends Application {
    @Override
    public void onCreate() {
        super.onCreate();

        String environment = RxAdjustConfig.ENVIRONMENT_SANDBOX;
        RxAdjustConfig config = new RxAdjustConfig(this, "{YourAppToken}", environment);
        AdjustSdkWrapper.getInstance().init(this, config);

        registerActivityLifecycleCallbacks(new AdjustLifecycleCallbacks());
    }
}

    private static final class AdjustLifecycleCallbacks implements ActivityLifecycleCallbacks {

        @Override
        public void onActivityResumed(@NonNull Activity activity) {
            AdjustSdkWrapper.getInstance().onResume(activity);
        }

        @Override
        public void onActivityPaused(@NonNull Activity activity) {
            AdjustSdkWrapper.getInstance().onPause(activity);
        }

        // ...

    }

```

**API level 9 至 13**

如果 gradle 文件中的 minSdkVersion 在 9 - 13 之间，请考虑将其变更为 14 或更高，这样可以简化集成流程。请查看 安卓控制面板 了解目前市场上各主要版本的占比。
在暂停或恢复 Activity 时，您需要调用特定方法。这样，Adjust SDK 才不会错过会话的开始或结束。为此，请针对应用中的每个 Activity 进行下列步骤操作：

- 在活动的 onResume 方法中调用 AdjustSdkWrapper.getInstance().onResume(activity) 。如有必要请创建该方法。
- 在活动的 onPause 方法中调用 AdjustSdkWrapper.getInstance().onPause(activity) 。如有必要请创建该方法。

```java
public class YourActivity extends Activity {
    protected void onResume() {
        super.onResume();
        AdjustSdkWrapper.getInstance().onResume(activity);
    }
    protected void onPause() {
        super.onPause();
        AdjustSdkWrapper.getInstance().onPause(activity);
    }
}
```

对您的应用中的每个 Activity 重复以上步骤。取决于编码方式，您也可通过添加所有 Activitiy 的通用超类来实现它。

## 设置日志

**接口原型**

```java
    /**
     * 设置显示日志级别
     * @param logLevel 日志级别
     */
    public void setLogLevel(RxLogLevel logLevel) {
        this.logLevel = logLevel;
    }
```

**参数说明**

```java
    VERBOSE(Log.VERBOSE),
    DEBUG(Log.DEBUG),
    INFO(Log.INFO),
    WARN(Log.WARN),
    ERROR(Log.ERROR),
    ASSERT(Log.ASSERT),
    SUPRESS(8);
```

**调用示例**

```java
public class GlobalApplication extends Application {
    @Override
    public void onCreate() {
        super.onCreate();

        String environment = RxAdjustConfig.ENVIRONMENT_SANDBOX;
        RxAdjustConfig config = new RxAdjustConfig(this, "{YourAppToken}", environment);
        config.setLogLevel(RxLogLevel.WARN);
        AdjustSdkWrapper.getInstance().init(this, config);
    }
}
```

如果您想禁用所有日志，请将日志级别设置为 suppress:

```java
public class GlobalApplication extends Application {
    @Override
    public void onCreate() {
        super.onCreate();

        String environment = RxAdjustConfig.ENVIRONMENT_SANDBOX;
        RxAdjustConfig config = new RxAdjustConfig(this, "{YourAppToken}", environment);
        config.setLogLevel(RxLogLevel.SUPRESS);
        AdjustSdkWrapper.getInstance().init(this, config);
    }
}
```
