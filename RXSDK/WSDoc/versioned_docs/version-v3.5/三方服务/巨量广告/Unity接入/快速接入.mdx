### 接入方式
* Package Manager 导入 RuiXue.Bytedance

## SDK概述 

只需接入 SDK 即可，上报条件通过望舒投放模块中的窗口期进行配置。

**主要功能**

- 通过在望舒投放模块中的窗口期配置进行动态上报（假回传）；

**接入准备**

- 正式接入前请务必仔细阅读商业开放平台关于SDK接入流程的介绍，并且在巨量引擎广告投放平台官网成功申请真实可用的appid之后再进行接入动作。
- 申请appid时请务必仔细阅读申请页关于申请appid的细则要求，并保证接入时写入的appname、package等字段信息与申请appid时填入的一致，否则后续测试无法通过。
- 申请appid流程：上传真实在投包体至应用管理平台，完成app相关信息和资质填写后，即可获取到对应的appid，用于后续SDK对接。
- 窗口期配置：在望舒投放模块中的窗口期配置appid和上报条件，目前只支持安卓，请注意应用选择的产品渠道；

## 快速集成

- 打开 settingsTemplate.gradle 文件，在 dependencyResolutionManagement{'{'}repositories{'{'}{'}'}{'}'} 中新增：

```groovy
    maven {
            url 'https://artifact.bytedance.com/repository/Volcengine/'
    }
```

- 打开 mainTemplate.gradle 文件，在 dependencies 下新增

```groovy
    implementation 'com.ruixue:rxsdk_bytedance_log:5.2.2'
    // 调试工具（可选）
    debugImplementation 'com.bytedance.applog:RangersAppLog-DevTools:3.0.0'
```

## 方法API

**接口原型**

```csharp
    public void SetContext();
```

**调用示例**

```csharp
    public void OnSetContext()
    {
        RXBytedance.SetContext();
    }
```

::: info 注意
在登录之前调用。
