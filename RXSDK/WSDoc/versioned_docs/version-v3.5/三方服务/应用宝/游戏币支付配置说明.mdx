## 准备工作

::: tip
腾讯开放平台：[http://op.open.qq.com/](http://op.open.qq.com/)
望舒系统地址：[企业管理后台中获取望舒地址](/docs/v3.5/入门指南/准备工作)。
:::

### 腾讯开放平台获取信息

1. 登录 [腾讯开放平台](http://op.open.qq.com/) ，位置：**我的应用** **> 点击对应应用 > 首页** 。
  
2. 获取关键配置：`AppID`、`AppKey`。
  

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/yingyongbao/pay/pay_param.png)

### 望舒系统中配置支付信息
通过获取的`AppID`、`AppKey`复制到望舒系统，位置：**企业管理后台 > 商务管理> 三方账号管理 > 支付账号管理 > 新建支付账号**。
  

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/yingyongbao/pay/pay_ruixue_coin.jpg)
