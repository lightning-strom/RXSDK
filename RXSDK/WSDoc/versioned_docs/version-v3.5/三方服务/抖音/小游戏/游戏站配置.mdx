## 功能介绍
面向玩家的基础社区工具，通过社区内容实现不同场景用户留存和转化。提供小游戏玩家社区能力，提供玩家交流和互动场域，支持官方通过发帖、发福利、发任务方式，提升用户留存。

## 游戏站配置
1. 开通游戏站能力
![img_v3_02t3_600b87e5-5e91-4d6d-8801-7b2a49811e2g.jpg](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/img_v3_02t3_600b87e5-5e91-4d6d-8801-7b2a49811e2g-1766051478384.jpg)
2. 配置游戏站使用的礼包。通过**能力中心>游戏站能力>运营管理>礼包配置**或者通过**能力中心>道具&礼包营销>新建礼包** 配置礼包类型为**游戏站礼包**

## 配置抖音消息推送地址
:::tip
如果之前使用了望舒提供的抖音小游戏的客服功能，配置过该推送地址，该地址为同一个，不需要再去修改相关配置。略过此步骤即可。
:::
进入[抖音小游戏详情页](https://developer.open-douyin.com/)，开发-开发设置-消息推送配置
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1750382147230.png)
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1750382171420.png)
启用消息推送，并按提示填写相关信息，具体如下：
:::tip
URL(服务器地址):望舒首页域名/v1/servicedouyin/notify_v2/产品id/渠道id

TOKEN:**通过望舒游戏发行平台首页选择微信小游戏渠道包-客服参数-进行参数复制获取**。如下图所示 

数据格式：JSON
:::
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1750406631832.png)
