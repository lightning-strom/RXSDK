## 功能介绍
帮助游戏挖掘付费潜力用户，通过推荐高性价比付费礼包的方式，实现未付费用户破冰、付费用户跃迁，从而提升游戏付费流水规模。[抖音道具礼包营销能力指南](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/open-ability/prop-marketing-guide#8f251d79)
## 准备工作
::: tip
字节小程序开发者平台：[https://microapp.bytedance.com/](https://microapp.bytedance.com/)

望舒系统地址：[企业管理后台中获取望舒地址](/docs/v3.5/入门指南/准备工作)。
:::
### 抖音开放平台配置付费礼包
1. 登录[字节小程序开发者平台](https://microapp.bytedance.com/)，位置：**字节小程序 >小游戏 > 运营 > 运营能力> 道具&礼包营销**。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1739754871636.png)
2. 新建付费礼包。**步骤：1.新建道具>2.新建礼包>3.等待审核成功**
:::tip
使用过程中，确保道具和付费礼包都是审核通过生效状态。并且在其有效期。
:::

![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1739754941088.png)
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1739755049905.png)
3. 获取创建的礼包ID
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1740017612680.png)
