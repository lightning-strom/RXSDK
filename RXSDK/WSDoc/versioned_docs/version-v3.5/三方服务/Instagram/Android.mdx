## SDK 集成
```
//海外渠道引用此库
```

| 参数 | 类型 | 说明 |

| clientId | Long | string.xml 中配置 instagram_client_id 值 |
| redirectUrl | String | 在开发者后台查看，配置到下面 com.snap.kit.redirectUrl |
