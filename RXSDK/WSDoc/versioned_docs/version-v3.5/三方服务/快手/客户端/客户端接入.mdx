
## 接入三方sdk版本信息

使用快手sdk 1.3.3.143 版本.
望舒sdk v3.4.18 后使用 1.4.3.209 版本，兼容targetSdk 30
SDK v3.6.15 后 使用 1.4.3.218 版本

## 依赖信息

使用 aar 接入方式的的请添加下面依赖配置，否则无需添加

```groovy
    implementation "androidx.appcompat:appcompat:${libs.appcompat}"
    //noinspection GradleDependency
    implementation "com.google.code.gson:gson:${libs.gson}"

    implementation('com.kwai.sdk:kwaisdk-base:1.3.3.143') 

    implementation('com.kwai.sdk:kwaisdk-base:1.4.3.209')// 2024年01月15日16:53:42 v3.4.18 后版本使用   
    
    implementation('com.kwai.sdk:kwaisdk-base:1.4.3.218')// 2024年12月10日 v3.6.15 后版本使用  

    //noinspection GradleDependency
    implementation 'com.alipay.sdk:AlipaySdk:15.8.01.20210112203525'
```

## 常见问题

1. 如遇冲突 Duplicate class com.google.common.util.concurrent.ListenableFuture found in modules jetified-guava-24.0-android (com.google.guava:guava:24.0-android) and jetified-listenablefuture-1.0 (com.google.guava:listenablefuture:1.0)

在 app build.gradle 中添加下面配置

```groovy
    configurations {
        all*.exclude group: 'com.google.guava', module: 'listenablefuture'
    }
```

2. 如微信组件出现冲突，请使用下面方式可以排除冲突。

```groovy
    api ("com.ruixue:rxsdk_weixin:+" ){
        exclude group: 'com.tencent.mm.opensdk', module: 'wechat-sdk-android'
    }
```

3. 如遇错误

```
java.lang.NoClassDefFoundError: Failed resolution of: Lcom/google/common/base/Optional; Caused by: java.lang.ClassNotFoundException: Didn't find class "com.google.common.base.Optional"

```

请添加  ('com.google.guava:guava:24.0-android') 库

4. 如遇编译错误错误

``` groovy
Duplicate class androidx.core.util.Supplier found in modules core-1.8.0-runtime (androidx.core:core:1.8.0) and jetified-kwaisdk-base-1.4.3.209-runtime (com.kwai.sdk:kwaisdk-base:1.4.3.209)
Duplicate class androidx.lifecycle.DefaultLifecycleObserver found in modules jetified-kwaisdk-base-1.4.3.209-runtime (com.kwai.sdk:kwaisdk-base:1.4.3.209) and lifecycle-common-2.5.1 (androidx.lifecycle:lifecycle-common:2.5.1)

Go to the documentation to learn how to Fix dependency resolution errors.
```

请在 gradle.properties 中添加

``` groovy
android.useAndroidX=true
android.enableJetifier=true
android.jetifier.blacklist=kwaisdk-base-1.4.3.209.aar
android.jetifier.ignorelist=kwaisdk-base-1.4.3.209.aar

#注意 1.4.3.209 为版本号，要使用最新的，目前为 1.4.3.218

```

## 初始化 SDK（必接）
```java
Map params = new HashMap<>();
RuiXueSdk.getApi().initThirdSdk(this, params, new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject jsonObject) {
        Log.d(TAG, "init third sdk success");
    }

    @Override
    public void onFailed(@NonNull JSONObject jsonObject) {
        Log.d(TAG, "init third sdk failed " + jsonObject);
    }
});
```

## 登录 (必须接入) 
请参考 [Android端登录API](/docs/v3.5/登录（通行证）/Android 登录API/快速接入)
参考代码
```java
String username = null;
String loginType = LoginMethod.KUAISHOU;
String password = null;
String captchaCode = null;
String loginOpenId = null;
Map ext = null;
String[] signFields = null;
Object migrateArgs = null;
RuiXueSdk.getApi().login(DemoActivity.this, loginType, username, password, captchaCode, loginOpenId, ext, signFields, migrateArgs, new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject data) {
        Toast.makeText(DemoActivity.this, "登录成功", Toast.LENGTH_SHORT).show();
    }

    @Override
    public void onFailed(@NonNull JSONObject cause) {
        Toast.makeText(DemoActivity.this, "登录失败", Toast.LENGTH_SHORT).show();
    }
});
```

```java
    @Override
```

```java
    }

    @Override
    public void onExitCancel() {
        Toast.makeText(DemoActivity.this, "退出游戏取消", Toast.LENGTH_SHORT).show();
    }
});
```
