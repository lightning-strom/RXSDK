### 请求参数（POST）

| <strong>字段</strong> | <strong>类型</strong> | <strong>是否必填</strong> | <strong>说明</strong> | <strong>示例</strong> |
| --- | --- | ---- | --- | --- |
| token | string | 是 | 获取平台用户信息处（getUserInfo接口）获得的用户身份 token 串（该 token 非永久有效，请务必每次均使用最后一次 getUserInfo 接口请求获得的最新 token 值 |  |
| role\_data.game\_uid | string | 是 | 游戏方用户ID（string，最大长度：36） | 1001 |
| role\_data.server\_id | int | 否 | 区服ID：无区服划分时区服可固定传入0（int，最小值：0，最大值：2147483647） | 1234 |
| role\_data.server\_name | string | 否 | 区服名称（string，最大长度：36） | 测试区服01 |
| role\_data.role\_id | string | 否 | 角色ID：必须保证在整个游戏系统内始终唯一（string，最大长度：36） | 1111 |
| role\_data.role\_name | string | 否 | 角色名称（string，最大长度：36） | 测试角色01 |
| role\_data.role\_level | int | 否 | 角色等级（int，最小值：0，最大值：2147483647） | 66 |
| role\_data.role\_revival | int | 否 | 角色转生数：无转生系统时转生数可固定传入0（int，最小值：0，最大值：2147483647） | 1 |
| role\_data.role\_power | int | 否 | 角色战力值（bigint，最小值：0，最大值：9223372036854775807） | 666 |
| role\_data.vip | int | 否 | VIP等级（int，最小值：0，最大值：2147483647） | 0 |
| role\_data.ext | string | 否 | 拓展参数，JSON字符串，用于功能拓展，没有内容时直接传空（text） |  |

<strong>响应示例</strong>

```json
{
        "code": 0,
        "data": {
            "code":0,
            "msg":"success"
        }
}
```

### 响应结构（JSON）

| 字段名 | 类型 | 描述 |
| --- | --- | --- |
| code | Number | 望舒错误码 |
| data.code | Number | 业务错误码 |
| data.msg | String | 业务信息 |

<strong>返回示例</strong>

```json
{
        "code": 0,
        "data": {
            "code":0,
            "msg":"success"
        }
}
```
