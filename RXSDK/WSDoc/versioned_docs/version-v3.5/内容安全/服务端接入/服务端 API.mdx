## 文本检测（增强）

> **POST: **  `/v1/risk/content/text/scan`
> **认证方式:** [CPSign](/docs/v3.5/入门指南/服务端接入须知)

### CURL 示例

```bash
curl --location --request POST '{{接口域名}}/v1/risk/content/text/scan' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--data-raw '{
    "open_id": "xyz_S5HwLxeRIkTEMBuwh6oYwULM",
    "scene": "public_chat",
    "content": "文本内容"
}'
```

**请求头 Header 参数**

| **参数**          | **类型** | **备注**         |
| ----------------- | -------- | ---------------- |
| ruixue-language   | String   | zh-CN            |
| Content-Type      | String   | application/json |
| ruixue-cpid       | String   | 内容提供商 CPID  |
| ruixue-productid  | String   | 产品 ID          |
| ruixue-channelid  | String   | 渠道 ID          |
| ruixue-platformid | String   | 平台 platformid  |
| ruixue-devicecode | String   | 设备码           |
| ruixue-cpsign     | String   | CP 签名          |
| ruixue-cpts       | String   | CP 签名时间戳    |
| ruixue-traceid    | String   | TraceID          |

**请求示例**

```json
{
     "open_id": "xyz_S5HwLxeRIkTEMBuwh6oYwULM",
     "scene": "public_chat",
     "content": "文本内容",
     "data_id":"rxuRKdm68wYPAV3DJv0t4mC-XtEjJZoxpeNlkQ4M"
 }
```

### 请求参数（JSON）

| **参数** | **类型** | **是否必填** | **备注**   |
| -------- | -------- | ------------ | ---------- |
| open_id  | String   | 否           | 微信小程序openid（如果开启了小游戏检测，需要传递） |
| scene    | String   | 是           | 场景与产品内容检测对应
 nick_name（昵称）
private_chat（私聊）
public_chat（公聊） |
| content  | String   | 是           | 文本内容 |
| data_id  | String   | 否           | 唯一标识， 最好是望舒OpenID |

**响应示例**

```json
{
    "data": {
        "suggestion": "pass",
        "words": ["abc"],
        "content": "**x**"
    },
    "msg": "success",
    "code": 0
}
```

### 响应结构(JSON)

| **参数** | **类型**                                             | **备注** |
| -------- | ---------------------------------------------------- | -------- |
| code     | Number                                               | 0 为成功 |
| msg      | String                                               | 失败信息 |
| data     | [][Data](/docs/v3.5/内容安全/功能介绍)            |          |

##### 文本检测增强data

| **参数**   | **类型**  | **说明** |
| ---------- | ----------| -------- |
| suggestion | String    | 审核结果 pass: 通过；risky: 风险|
| words      | []String    | 敏感词 |
| content    | String    | 替换后的文本内容|

| **参数** | **类型**                                             | **备注** |
| -------- | ---------------------------------------------------- | -------- |
| code     | Number                                               | 0 为成功，返回 152920 时为三方接口限流 |
| msg      | String                                               | 失败信息 |
| data     | [][Data](/docs/v3.5/内容安全/功能介绍)            |          |

##### 图片检测增强data

| **参数**   | **类型**                                                         | **说明** |
| ---------- | -----------------------------------------------------------------| -------- |
| suggestion | String                                                           | 审核结果 pass: 通过；risky: 风险|
| url        | String                                                           | 图片地址 |
| results    | [][ScanImageDetail](/docs/v3.5/内容安全/功能介绍) | 检测结果详情|

##### 图片检测增强详情数据ScanImageDetail

| **参数**   | **类型**                        | **说明** |
| ---------- | --------------------------------| -------- |
| label      | String                          | 标签     |
| confidence | Float                           | 置信分值，0到100分; 部分标签无置信分，仅支持腾讯和阿里 |
