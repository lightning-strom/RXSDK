# 区服
## 创建游戏区服

> **POST:**  `/v1/report/cp/game_area`
> **认证方式：** [CPSign](/docs/v3.5/入门指南/服务端接入须知)

### CURL 示例

```bash
curl --location --request POST '{{接口域名}}/v1/report/cp/game_area' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{cpid}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{签名}}' 
--data-raw '{
    "area_id": "ut labore",
    "area_name": "ipsum quis Duis cillum in"
}'
```

### 请求参数（JSON）

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | ---- | --- | --- |
| area_id | String | 是 | 区服id |  |
| area_name | String | 是 | 区服名 |  |
| extension | json | 否 | 符合json格式的数据 |  |

### 响应参数（JSON）

**HTTP 状态码：**`200 OK`

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | ---- | --- | --- |
| code | Number | 是 | 响应状态码，0为成功，非0表示出错 | 0 |
| msg | String | 否 | 响应信息，仅在code为非0时不为空 |  |
| data | Data | 否 | 响应内容 |  |

**响应示例**

```json
{
    "code": 0,
    "msg": "string"
}
```
