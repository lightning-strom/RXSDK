## 上报区服角色

**接口原型**

```java
/**
 * 上报区服角色
 */
void setGameInfo(String roleId, String regionTag);
```

**调用示例**

```java
RuiXueSdk.getApi().setGameInfo("游戏角色 ID", "区服标识");
```

## 查询角色信息
:::tip
登录后调用
:::

**接口原型**

```java
/**
 * 查询游戏角色信息
 */
void searchGameAccount(RXRequestCallback callback);
```

**调用示例**

```java
RuiXueSdk.getApi().searchGameAccount(new RXRequestCallback() {
    @Override
    public void onResponse(JSONObject jsonObject) {
        ToastUtils.showToast(MainActivity.this, jsonObject.toString());
    }
});
```

### 响应参数（JSON）

**HTTP 状态码：**`200 OK`

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | ---- | --- | --- |
| code | Number | 是 | 响应状态码，0为成功，非0表示出错 | 0 |
| msg | String | 否 | 响应信息，仅在code为非0时不为空 |  |
| data | Data | 否 | 响应内容 |  |

#### Data
| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | ---- | --- | --- |
| list | []Item | 是 | 角色列表|  |

#### Item
| **字段** | **类型** | **是否必填** | **说明** | **示例** |~~~~
| --- | --- | ---- | --- | --- |
| region_tag | String | 是 | 区服 |  |
| cp_role_id | String | 是 | 角色id|  |
| extension | json | 否 | 扩展信息符合json格式的数据 |
