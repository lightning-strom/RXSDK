根据苹果公司发布的 [App Store 提交的隐私更新](https://developer.apple.com/news/?id=r1henawx)，自 2024 年 5 月 1 日起，上架 App Store 的应用需要同时提供一份 App 的<strong>隐私清单文件。
当你准备分发 App 时，Xcode 会将 App 使用的所有第三方 SDK 的隐私清单合并为一个简单易用的报告。</strong>
这个报告内容全面，总结了 App 中的所有第三方 SDK，让你能够更轻松地创建更准确的隐私标签。
因此嵌入 App 的 SDK 和三方库都需要包含 <strong>PrivacyInfo.xcprivacy 。</strong>

简单总结， Apple <strong>「想通过隐私清单来进一步提升用户数据收集和使用的透明度」</strong>，包括 required reason API 也是算是属于隐私清单里的内容。

## SDK 适配

- 当您使用 CocoaPod 集成时，我们会通过 Pod 为您添加 <strong>PrivacyInfo.xcprivacy</strong> 到工程内，<strong>您无需为此做额外工作。 </strong>
- 当您手动集成时，请注意需要将源代码目录下的 <strong>PrivacyInfo.xcprivacy 拷贝进您的代码工程里。</strong>

:::tip
由于三方 SDK 升级需要将 pod 版本支持要改成 iOS12 以上，否则将无法更新到以下版本。
:::

## 手动集成

[Describing use of required reason API 原文](https://developer.apple.com/documentation/bundleresources/privacy_manifest_files/describing_use_of_required_reason_api?language=objc) 

### SDK 使用的 required reason API

| **组件库** | **使用权限** |
| -------- | -------- |
| RXSDK_Pure   | File timestamp、System boot time、Disk space、User defaults |
| RXIMSDK-iOS | File timestamp、User defaults | 
| RXUIKit   | User defaults |
| RXOSUIKit   | User defaults |
| RXWXSDK   | User defaults |
| RXASAKit   | User defaults |
| RXContactSDK   | User defaults |
| RXFacebookSDK   | User defaults |
| RXLBSKit   | User defaults |
| RXLineSDK   | User defaults |
| RXNetworkingKit   | User defaults |
| RXPushSDK   | User defaults |

除了通过 CocoaPod 自动导入 PrivacyInfo 外，开发者还可以直接将 IM SDK的 <strong>PrivacyInfo.xcprivacy</strong> 中的条款补全到自身 App 的 <strong>PrivacyInfo.xcprivacy</strong> 中。具体补全方式可以参见以下内容：
- 使用 Source Code 方式添加
Xcode 中使用 Source Code方式打开 app 项目下的 <strong>PrivacyInfo.xcprivacy</strong>。复制 <strong>PrivacyInfo.xcprivacy</strong> 中的条目，注意不要重复添加或错行。
- 使用 Property List 的方式添加
在 Xcode 中双击打开 <strong>PrivacyInfo.xcprivacy</strong> 文件，在其中点击+，Xcode会提示可选的条款和可设置项，按照需求进行增补即可。
