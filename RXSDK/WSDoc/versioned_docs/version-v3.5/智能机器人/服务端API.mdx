## 辱骂检测

> **POST:**  `/v1/smarts/abuse/check`
> **认证方式：** [CPSign](/docs/v3.5/入门指南/服务端接入须知)

### CURL 示例

```bash
curl --location --request POST '{{接口域名}}/v1/smarts/abuse/check' \
--header 'x-robot-schemas: {{机器人}}' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{APPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{签名}}' 
```

### 请求参数（JSON）

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | ---- | --- | --- |
| message | String | 是 | 检测内容 |  |

### 响应参数（JSON）

**HTTP 状态码：**`200 OK`

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | ---- | --- | --- |
| code | Number | 是 | 响应状态码，0为成功，非0表示出错 | 0 |
| msg | String | 否 | 响应信息，仅在code为非0时不为空 |  |
| data | Data | 否 | 响应内容 |  |

#### Data

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | ---- | --- | --- |
| is_abuse | string | 是 | 是否辱骂 |  |

**响应示例**

```json
{
    "code": 0,
    "data": {
        "is_abuse": true
    },
    "msg": "string"
}
```

### CURL 示例

```bash

--header 'x-robot-schemas: {{机器人}}' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{APPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{签名}}' 
```

### 请求参数（JSON）

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
