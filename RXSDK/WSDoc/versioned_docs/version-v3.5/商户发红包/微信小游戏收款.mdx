### 接收红包

#### 参数说明

| **字段**
 | **类型**
       | **是否必填**
 | **备注**
     |
| ------------ | ------------------ | ---------------- | ---------------- |
| params
   | IParams
 | 是
           | 参数
         |
| callback
 | IMethodParams
  | 是
           | 回调函数集合
 |

> IParams说明

| **字段**
 | **类型**
 | **是否必填**
 | **备注**
                                                              |
| ------------ | ------------ | ---------------- | ------------------------------------------------------------------------- |
| mchId
     | string
   | 是
           | 商户号，由微信支付生成 
 |
| appId
     | string
   | 是
           | 商户绑定的AppID（企业号corpid即为此AppID）
 |
| package
     | string
   | 是
           | 对应发起转账接口应答参数中的 package_info
 |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**

```javascript
sdk.requestMerchantTransfer(
  {
   mchId: 'xxxx',
   appId: 'xxxxx',
   package: 'xxxx'
  },
  {
    complete: (res) => {
        console.log(res)
    },
  }
);
```

#### 成功响应

| **字段**
 | **类型**
       |  **备注**
     |
| ------------ | ------------------ |  ---------------- |
| code
 | number
  | 0 成功
| msg
   | string
 | 错误消息
