## 创建玩家反馈

### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params
   | ICreateData
    | 是
           | 参数
         |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |> IMethodParams 说明

> ICreateData说明

| **字段**
  | **类型**
 | **是否必填**
 | **备注**
                                                            |
| ------------- | ------------ | ---------------- | ----------------------------------------------------------------------- |
| content
      | String
   | 是
           | 反馈内容
                                                            |
| attachments
 | String[]
   | 是
           |  反馈附件
 |
| phone
    | String
   | 是
           | 手机号
                              |
| tags
     | String[]
   | 是
           | 标签标识， 游戏透传 |

> IMethodParams说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**

```javascript
sdk.addFeedback({
   content: '123',
   attachments: ['12312313'],
   phone: '13439093625',
   tags: ['11111']
}, {
   complete(res) {
      console.log(res)
   }
})
```

### 响应结构(JSON)

| **参数** | **类型**                                             | **备注** |
| -------- | ---------------------------------------------------- | -------- |
| code     | Number                                               | 0 为成功 |
| msg| String | 失败提示 |
