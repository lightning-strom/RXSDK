## 创建反馈

**接口原型**
```java
    /**
/**
 * 创建意见反馈
 * @param content 返回内容
 * @param attachments 上传附件
 * @param phone 电话号，非必填
 * @param tags 标签标识， 游戏透传
 * @param callback 回调
 */
public void feedbackCreate(String content, String[] attachments, String phone, String[] tags,
                           RXRequestCallback callback)
```

**调用示例**

```java
String content = "测试测试测试";
String[] attachments =["https://rxfile-test.ruixuecloud.com/feed_log/rxu7nr2QPwbvkDpX33tm5F_OHl2RX6-WZjeKJyL4_160"];
String phone = "1232323232";
String[] tags = ["tag1", "tag2", "tag3"];

RuiXueSdk.getRXSdkApi().feedbackCreate(content, attachments, phone, tags, new RXRequestCallback() {
    @Override
    public void onResponse(JSONObject jsonObject) {
        Log.d("feedback_test", "创建反馈： " + jsonObject.toString());
    }
});

```

### 响应结构（JSON）

**HTTP 状态码：**`200 OK`

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | --- |
| code | Number | 是   | 响应状态码，0为成功，非0表示出错 | 0   |
| msg | String | 否   | 响应信息，仅在status为非0时不为空 |     |

**响应示例**

```json
{"code": 0}
```

## 获取反馈列表

**接口原型**
```java
/**
 * 获取列表
 * @param page 页数， 从1开始
 * @param size 每页大小
 * @param status 默认传0即可
 * @param callback 回调
 */
public void getFeedbackList(int page, int size, int status, RXRequestCallback callback)
```

**调用示例**

```java
RuiXueSdk.getRXSdkApi().getFeedbackList(1, 10, 0, new RXRequestCallback() {
    @Override
    public void onResponse(JSONObject jsonObject) {
        Log.d("feedback_test", "意见反馈列表：" + jsonObject);

});
```
