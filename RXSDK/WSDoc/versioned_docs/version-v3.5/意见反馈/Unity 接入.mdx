### 接入方式
* Package Manager 导入 RuiXue.Feedback

## 获取意见反馈类型

**接口原型**

```csharp
    public void GetFeedbackKindList(RequestResponseDelegate onResponse, RequestErrorDelegate onError);
```

**调用示例**

```csharp
    public void OnGetFeedbackKindList()
    {
        RXFeedback.GetFeedbackKindList(FeedbackResponseDelegate, FeedbackErrorDelegate);
    }
```

**响应结构**

**HTTP 状态码：**`200 OK`

| **字段** | **类型**                               | **是否必填** | **说明** | **示例** |
|--------|--------------------------------------| --- | --- | --- |
| code   | Number                               | 是   | 响应状态码，0为成功，非0表示出错 | 0   |
| msg    | String                               | 否   | 响应信息，仅在status为非0时不为空 |     |
| data | [PageData](/docs/v3.5/意见反馈/Unity 接入) | 否   | 结果  |     |

##### **PageData**

| **字段** | **类型**                         | **是否必填** | **说明** | **示例** |
| --- |--------------------------------| --- |--------| --- |
| page | Number                         | 是   | 第几页    |     |
| size | Number                         | 是   | 每页大小   |     |
| total | Number                         | 是   | 总数量    |     |
| list | [][Kind](/docs/v3.5/意见反馈/Unity 接入) | 是   | 意见反馈数据 |     |

##### **Kind**
| **字段** | **类型**                         | **是否必填** | **说明** | **示例** |
| --- |--------------------------------| --- |--------| --- |
| id | Number                         | 是   | 唯一ID   |     |
| name | string                         | 是   | 意见反馈类型 |     |
| email_reply | Number                         | 是   | 是否邮件回复 |     |
| is_accident | Number                         | 是   | 是否产生事故 |     |
| kind_desc | Number                         | 是   | 描述     |     |

## 创建意见反馈

**接口原型**

```csharp
    public void CreateFeedback(Dictionary hashMap, 
                RequestResponseDelegate onResponse, RequestErrorDelegate onError);
```

### 参数说明

| **字段**  | **类型**     | **是否必填** | **备注**                                                                           |
| --------- | ------------ | ------------ | ---------------------------------------------------------------------------------- |
| game_id      | int      | 是           | 游戏ID                                                                          |
| kind_id      | int      | 是           | 意见反馈ID                                                                         |
| kind_name    | string       | 是           | 意见反馈类型                                                                      |
| priority     | int      | 是           | 紧急程度 1:紧急 2:不紧急 |
| content      | string       | 是           | 反馈内容                |
| picture      | string       | 是           | 图片url                  |
| player_gameid | string      | 是           | 玩家游戏id                  |
| send_voided_mails | int | 是           | 作废是否发邮件 1:发 2:不发              |

**调用示例**

```csharp
    public void OnCreateFeedback()
    {
        Dictionary dic = new()
        {
            { "game_id", 100 },
            { "kind_id", 1 },
            { "kind_name", "意见反馈类型" },
            { "priority", 1 },
            { "content", "说明" },
            { "picture", "图片url" },
            { "player_gameid", "玩家游戏id" },
            { "send_voided_mails", 1 }
        };

        RXFeedback.CreateFeedback(dic, FeedbackResponseDelegate, FeedbackErrorDelegate);
        
    }
```

**响应结构**

**HTTP 状态码：**`200 OK`

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | --- |
| code | Number | 是   | 响应状态码，0为成功，非0表示出错 | 0   |
| msg | String | 否   | 响应信息，仅在status为非0时不为空 |     |

```csharp
                RequestResponseDelegate onResponse, RequestErrorDelegate onError);
```

### 参数说明

| **字段**  | **类型**     | **是否必填** | **备注**                                                                           |
| --------- | ------------ | ------------ | ---------------------------------------------------------------------------------- |
| key_number     | int      | 是           | 创建意见反馈的ID                                                                     |
| pleased_status | int      | 是           | 满意度 1:满意 2:不满意                                     |
| reason         | string   | 是           | 理由                                         |

**调用示例**

