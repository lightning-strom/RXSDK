## 获取意见反馈类型

**接口原型**

```java
    void getFeedbackKindList(RXJSONCallback callback);
```

**调用示例**

```java
    RuiXueSdk.getRXSdkApi().getFeedbackKindList(jsonCallback);
```

**响应结构**

| **字段** | **类型**                             | **是否必填** | **说明** | **示例** |
|--------|------------------------------------| --- | --- | --- |
| code   | Number                             | 是   | 响应状态码，0为成功，非0表示出错 | 0   |
| msg    | String                             | 否   | 响应信息，仅在status为非0时不为空 |     |
| data | [PageData](/docs/v3.5/意见反馈/客户端接入/Android) | 否   | 结果  |     |

##### PageData

| **字段** | **类型**                         | **是否必填** | **说明** | **示例** |
| --- |--------------------------------| --- |--------| --- |
| page | Number                         | 是   | 第几页    |     |
| size | Number                         | 是   | 每页大小   |     |
| total | Number                         | 是   | 总数量    |     |
| list | [][Kind](/docs/v3.5/意见反馈/客户端接入/Android) | 是   | 意见反馈数据 |     |

##### Kind
| **字段** | **类型**                         | **是否必填** | **说明** | **示例** |
| --- |--------------------------------| --- |--------| --- |
| id | Number                         | 是   | 唯一ID   |     |
| name | string                         | 是   | 意见反馈类型 |     |
| email_reply | Number                         | 是   | 是否邮件回复 |     |
| is_accident | Number                         | 是   | 是否产生事故 |     |
| kind_desc | Number                         | 是   | 描述     |     |

## 创建意见反馈

**接口原型**

```java
    void createFeedback(Map map, RXJSONCallback callback)
```

### 参数说明

| **字段**  | **类型**     | **是否必填** | **备注**                                                                           |
| --------- | ------------ | ------------ | ---------------------------------------------------------------------------------- |
| game_id      | int      | 是           | 游戏ID                                                                          |
| kind_id      | int      | 是           | 意见反馈ID                                                                         |
| kind_name    | string       | 是           | 意见反馈类型                                                                      |
| priority     | int      | 是           | 紧急程度 1:紧急 2:不紧急 |
| content      | string       | 是           | 反馈内容                |
| picture      | string       | 是           | 图片url                  |
| player_gameid | string      | 是           | 玩家游戏id                  |
| send_voided_mails | int | 是           | 作废是否发邮件 1:发 2:不发              |

**调用示例**

```java
    Map map = new HashMap<>();
    map.put("game_id", 100);
    map.put("kind_id", 1);
    map.put("kind_name", "意见反馈类型");
    map.put("priority", 1);
    map.put("content", "说明");
    map.put("picture", "图片url");
    map.put("player_gameid", "玩家游戏id");
    map.put("send_voided_mails", 1);
    RuiXueSdk.getRXSdkApi().createFeedback(map, jsonCallback);
```

**响应结构**

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | --- |
| code | Number | 是   | 响应状态码，0为成功，非0表示出错 | 0   |
| msg | String | 否   | 响应信息，仅在status为非0时不为空 |     |

## 上报反馈日志

:::tip
需要在全局通用回调中监听上报时机。
:::

**接口原型**

```java
    void reportFeedbackLog(Context context, byte[] data,RXJSONCallback callback)
```

**调用示例**

```java

    File file = new File("your_log.json");
    
    FileInputStream fis = new FileInputStream(file);
    byte[] byteArr = new byte[(int) file.length()];
    fis.read(byteArr);
    fis.close();
    RuiXueSdk.reportFeedbackLog(activity, byteArr, new RXJSONCallback() {
        @Override
        public void onSuccess(@Nullable JSONObject data) {
            //上报成功
        }
    
        @Override
        public void onFailed(@NonNull JSONObject cause) {
            //上报失败
        }
    });
 
```
