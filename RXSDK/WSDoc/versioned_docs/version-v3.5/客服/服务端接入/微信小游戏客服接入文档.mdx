>如何接入小游戏客服？
> 答：CP 游戏通过小游戏的客服会话按钮，在 sessionfrom 中用 JSON 格式拼接参数，通过微信官方服务器或 CP 服务器转发的形式 推送 JSON 格式通知到望舒服务器

## 接口信息

###  跳转小游戏客服

:::tip
**SessionFrom**  腾讯要求最长不得超过 1000 个字节（不是字符串长度），超过将被截断。尽量在传递时控制好字节数。望舒会默认把 **access_token ** 拼接到 ** SessionFrom** 中。所以不要额外传递无用字段。最好控制在700字节以内。
:::
- 跳转按钮 <strong>：客服会话</strong>
- 跳转方式 <strong>：</strong><strong>SessionFrom</strong>
- 传参方式 <strong>：</strong><strong>JSON</strong>
