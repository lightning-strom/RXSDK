## 接入定义

### 引入客服面板内嵌页

- 引入地址 <strong>：CP 在望舒后台定义的面板内嵌页地址</strong>
- 引入方式 <strong>：Iframe</strong>
- 传参方式 <strong>：GET</strong>

## FAQ

### 如何进行验签

1. sha1(trace_id+timestamp+cpKey)

#### GO 示例

```go
package example
import (
  
    "crypto/sha1"
    "encoding/hex"
   
)
func Sign(traceID, timestamp, cpKey string) string {
   h := sha1.New()
   _, _ = h.Write([]byte(traceID + timestamp + cpKey))
   ret := hex.EncodeToString(h.Sum(nil))
   h.Reset()
   return ret
}
```

#### PHP 示例

```php
<?php
$name = $_GET["name"];
$username = $_GET["username"];
$trace_id = $_GET["trace_id"];
$timestamp = $_GET["timestamp"];
$sign = $_GET["sign"];
$cpkey ="cpkey";
function VerifySign($trace_id,$time,$sign){
    global $cpkey;
    return sha1($trace_id.$time.$cpkey) == $sign;
}

if(!VerifySign($trace_id,$timestamp,$sign)){
    echo "签名错误";
    exit;
}
echo $username." 登陆成功";
?>
```
