> 如何接入 APP 网页客服？
> 答：CP 客户端请求 CP 服务器拉取参数以及签名后，拼接参数跳转到望舒的客服系统网页端

## 接口信息

### 跳转网页客服地址信息

- 跳转地址 <strong>：</strong><strong>API 域名 +</strong><strong>/static/service#/welcome</strong>
- 跳转方式 <strong>：</strong><strong>URL</strong><strong>跳转</strong>
- 传参方式 <strong>：</strong><strong>GET</strong>

## FAQ

### 如何进行签名

1. 将参数按照参数名字符的 ASCII 递增排序
2. 将排序后的参数用参数<strong>=</strong>参数值的格式连接，两个参数之间用<strong>&</strong>字符拼接
3. 在拼接后的字符后面追加 cpkey
4. 将上面的字符串进行 32 位 md5 加密并且转换为小写
5. 例 lower(md5_32("game_user_id=&head_img_url=&nickname=&param_ui&queue_name=&ruixue-accesstoken=&ruixue-channelid=&ruixue-cpid=&ruixue-productid="))

#### GO 示例

```go
package example
import (
  
   "sort"
   "strings"
   
   "git.jiaxianghudong.com/go/util"
  
)
func Sign(param map[string]string, cpKey string) (sign string) {
   keys := make([]string, 0, len(param))
   signParams := make([]string, 0, len(param))

   for key, _ := range param {
      keys = append(keys, key)
   }
   sort.Strings(keys) // 1.将参数按照参数名字符的ASCII递增排序
   for _, key := range keys {
      signParams = append(signParams, key+"="+param[key]) // 2.将排序后的参数 用参数<strong>=</strong>参数值的格式连接
   }
   signStr := strings.Join(signParams, "&") // 3.两个参数之间用<strong>&</strong>字符拼接
   signStr += cpKey // 4.在拼接后的字符后面追加cpkey
   return strings.ToLower(util.StringMD5(signStr)) // 5.将上面的字符串进行32位md5加密并且转换为小写
}
```
