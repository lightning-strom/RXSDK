:::tip
客服接待时尽量使用chrome浏览器进行接待，避免一些操作的兼容问题
:::
### 设置方法
可以打开chrome的设置页面
浏览器内输入 chrome://settings/performance 。
把客服面板的域名输入进去 可以避免一部分情况的的浏览器标签在后台导致的掉线

### 域名获取方式
例如打开工作台的页面是红色框。其中绿色框为域名
