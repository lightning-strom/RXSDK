## 获取分享信息

::: tip
此接口用于根据入参获取分享的具体数据，然后使用数据将配置的内容分享到各大媒体平台，以达到用户裂变的效果。数据内容与后台的埋点配置，策略配置相关

:::

### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params
   | IGetShareData
 | 是
           | 参数
         |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |

> IGetShareData 说明

| **字段**
  | **类型**
 | **是否必填**
 | **备注**
                                                            |
| ------------- | ------------ | ---------------- | ----------------------------------------------------------------------- |
| func
      | string
   | 是
           | 埋点标记
                                                            |
| transmits
 | string
   | 否
           | 透传参数，原样返回， 请使用 key1=val1&key2=val2 的形式(querystring)，传入 use_url_param=true 时， 将不使用短链接返回，而是将所有参数拼接到 url 中
 |
| region
    | string
   | 否
           | 地区码，没有则不传，会取全国地区的数据。 [望舒地区码列表](https://pan.jiaxianghudong.com/s/pdEzbPRkDS9)
                              |
| readCache
     | boolean
   | 否
           | 是否读取缓存 |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**

```javascript
sdk.getShareData(
  {
    func: "jssdkfunc",
    transmits: "a=1&b=2",
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);
```

## 拉起分享

::: tip
因为小游戏分享 API 回调只有成功状态，所以 SDK 无法区分是否真正分享成功，只能证明成功调起分享

:::

### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params
   | IShareData
    | 是
           | 参数
         |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |

> IShareData 说明

| **字段**
     | **类型**
 | **是否必填**
 | **备注**
                                                                                                                  |
| ---------------- | ------------ | ---------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| func
         | string
   | 是
           | 埋点标记
                                                                                                                  |
| transmits
 | string
   | 否
           | 透传参数，原样返回， 请使用 key1=val1&key2=val2 的形式(querystring)，并对值使用 urlencode，返回时会原样返回。当key为use_url_param=true时， 将不使用短链接返回，而是将所有参数拼接到url中。
==💡：sdk 内部会对 transmits 字段的值整体做 encodeURIComponent 处理后拼接在分享卡片的路径上，如果需要获取 transmits 字段进行定制化需求，从小游戏启动参数获取到transmits 的值后需要 decodeURIComponent 处理下才能拿到原始分享传入的值==

 例如：transmits: 'uId=1&shareType=2' 
 分享卡片query：user_source=share&transmits=uId%3D1%26shareType%3D2 
 小游戏启动参数query：{'{'} user_source: "share", transmits: "uId%3D1%26shareType%3D2" {'}'} 
            |
| title
        | string
   | 否
           | 分享卡片标题
                                                                                                              |
| imageUrl
     | string
   | 否
           | 分享卡片图片的路径
                                                                                                        |
| query
     | string
   | 否
           | 自定义分享页面路径的参数,请使用 key1=val1&key2=val2 形式(querystring)，SDK 会将其拼接在主动拉起分享 API 的 query 字段中。

 例如：query: 'uId=1&shareType=2' 
 分享卡片query：user_source=share&uId=1&shareType=2 
 小游戏启动参数query：{'{'} user_source: "share", uId: "1", shareType: "2" {'}'} 
 |
| shareAppType
 | string
   | 否
           | 转发目标类型， 不设该属性默认 qq ，拉起手 q 通讯录
        |
| readCache
     | boolean
   | 否
           | 是否读取缓存 |                                                                |

> shareAppType 说明

| **字段**
        | **备注**
          |
| ------------------- | --------------------- |
| qq
              | 转发到手 q 通讯录
 |
| qqFastShareList
 | 快速转发列表
      |
| qzone
           | 转发到空间
        |
| wechatFriends
   | 转发到微信好友
    |
| wechatFriends
   | 转发到微信朋友圈
  |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**

```javascript
sdk.share(
  {
    func: "jssdkfunc",
    transmits: "a=1&b=2",
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);
```

### 分享调度初始化

:::tip
如果在望舒后台开启了分享调度功能必须调用 分享调度初始化 接口，否则将无法正常使用分享调度功能
:::

#### 参数说明

| **字段**
 | **类型**
              | **是否必填**
 | **备注**
     |
| ------------ | ------------------------- | ---------------- | ---------------- |
| params
   | IReqShareScheduleInit
 | 是
           | 参数
         |
| callback
 | IMethodParams
         | 是
           | 回调函数集合
 |

> IReqShareScheduleInit 说明

| **字段**
 | **类型**
 | **是否必填**
 | **备注**
     |
| ------------ | ------------ | ---------------- | ---------------- |
| funcs
    | string[]
 | 否
           | 埋点标识数组，传空获取所有埋点调度
 |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**

```javascript
sdk.shareSchedulingInit(
      {
        funcs: ['maidian'],
      },
      {
        complete: (data: any) => {
          console.log('shareSchedulingInit: ', data)
        },
      }
    )
```

#### 响应结构

**响应示例**：

```json
{
    "code": 0,
    "msg":"",
    "data": "func1": {
        "scheduling_sign": "xx",
        "scheduling_type": "ad",
        "user_type": 1, // 1有效用户 2无效用户
    }
}
```

**响应参数（JSON）**
::: warning
未命中策略的埋点不返回
:::

| **参数**               | **类型** | **是否必填** | **备注**                                  |
| ---------------------- | -------- | ------------ | ----------------------------------------- |
| scheduling_sign    | String   | 是           | 调度分享看广告总次数                           |
| scheduling_type | String   | 是           | 分享 share 广告 ad |  
| user_type | Number   | 是           | 用户状态 1有效用户 2无效用户 |  

### 获取埋点调度
:::tip
分享调度初始化后 SDK 会将数据缓存，客户端需要使用时可以调用 获取埋点调度 来获取需要的埋点调度数据，无需再次初始化。
需要在登录后调用。
:::
#### 参数说明

| **字段**
 | **类型**
          | **是否必填**
 | **备注**
     |
| ------------ | --------------------- | ---------------- | ---------------- |
| params
   | IReqShareSchedule
 | 是
           | 参数
         |
| callback
 | IMethodParams
     | 是
           | 回调函数集合
 |

> IReqShareSchedule 说明

| **字段**
 | **类型**
 | **是否必填**
 | **备注**
     |
| ------------ | ------------ | ---------------- | ---------------- |
| funcs
    | string[]
 | 否
           | 埋点标识数组，传空获取所有埋点调度
 |

**调用示例**

```javascript
// 同步函数
const data = sdk.getShareScheduling()
```

#### 响应结构

**响应示例**：

```json
{
    "code": 0,
    "msg":"",
    "data": "func1": {
        "scheduling_sign": "xx",
        "scheduling_type": "ad",
        "user_type": 1, // 1有效用户 2无效用户
    }
}
```

**响应参数（JSON）**
::: warning
未命中策略的埋点不返回
:::

| **参数**               | **类型** | **是否必填** | **备注**                                  |
| ---------------------- | -------- | ------------ | ----------------------------------------- |
| scheduling_sign    | String   | 是           | 调度分享看广告总次数                           |
| scheduling_type | String   | 是           | 分享 share 广告 ad |  
| user_type | Number   | 是           | 用户状态 1有效用户 2无效用户 |
