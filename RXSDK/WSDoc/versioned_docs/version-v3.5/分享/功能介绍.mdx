# 功能介绍

## 功能介绍

分享功能，主要是借助社交产品的流量，让用户主动把应用程序中的内容分享到社交平台，从而达到拉新、促活、提高留存的目的。望舒系统整合了微信、QQ、Facebook 等主流的社交工具，帮助运营制定营销活动策略和管理分享内容，大大降低了运营成本。

## 前期工作

1. 针对微信通路分享，请确认已经在 **微信开放平台** 和 **望舒管理平台** 完成了以下操作：

   在**微信开放平台**，注册并添加 APP，获取微信 APP ID。
     将微信 APP ID 录入到望舒开发平台的**商务管理** > **三方账号管理**> **分享账号管理** > **新建微信分享账号** 中。
     ![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/share/FcohbWmCfosUsLx8AZMcOZWRn9d.png)
2. 针对APP或者小游戏分享，请确认已经在**望舒管理平台**完成了以下操作：

    在**商务管理** > **产品管理** > **编辑** 中配置小游戏域名。
      ![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/share/share_domain.jpg)
3. 针对针对成就类策略和特殊埋点策略，请确认已经在 **望舒开放平台** 完成了以下操作：

   a. 在 APP 或小游戏前端，配置好分享触发埋点；
   b. 将此埋点在望舒后台 **社交分享工具** > **分享埋点配置** ，提前配置完毕。

## 分享功能

### 支持多种分享渠道

- 微信：好友、朋友圈、卡片（小游戏）
- QQ：QQ 通讯录、快速转发列表、QQ 空间、微信好友、微信朋友圈
- Facebook：动态
- Messenger：好友
- TikTok：好友
- Twitter：动态
- Line：好友

    ![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/share/fenxiang1.png)

### 支持多种分享场景
 
  ![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/share/fenxiang2.png)

### 支持多种分享策略

- **诱导分享类**：根据绑定产品、选择地区，满足规则条件后，即向 APP、小游戏传输分享内容；
- **成就分享类**：自定义触发分享埋点，同埋点支持维护多分享内容，并支持不同分享内容配置展示权重；
- **特殊埋点分享类**：自定义触发分享埋点，同埋点支持维护多分享内容，并支持不同分享内容配置展示权重，并可灵活设置触发分享用户的所在地区，实现精准性分享，提高分享物料的有效性。
:::tip
如果在策略中配置指定地区分享。需要在拉起分享时，传递对应的region参数。
望舒使用的地区码列表:[望舒地区码](https://pan.jiaxianghudong.com/s/pdEzbPRkDS9)
:::
