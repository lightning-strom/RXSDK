## 获取分享信息

::: tip
此接口用于根据入参获取分享的具体数据，然后使用数据将配置的内容分享到各大媒体平台，以达到用户裂变的效果。数据内容与后台的埋点配置，策略配置相关

:::

### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params
   | IGetShareData
 | 是
           | 参数
         |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |

> IGetShareData 说明

| **字段**
  | **类型**
 | **是否必填**
 | **备注**
                                                            |
| ------------- | ------------ | ---------------- | ----------------------------------------------------------------------- |
| func
      | string
   | 是
           | 埋点标记
                                                            |
| transmits
 | string
   | 否
           | 透传参数，原样返回， 请使用 key1=val1&key2=val2 的形式(querystring)，传入 use_url_param=true 时， 将不使用短链接返回，而是将所有参数拼接到 url 中
 |
| region
    | string
   | 否
           | 地区码，没有则不传，会取全国地区的数据。 [望舒地区码列表](https://pan.jiaxianghudong.com/s/pdEzbPRkDS9)
                              |
| readCache
     | boolean
   | 否
           | 是否读取缓存 |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**

```javascript
sdk.getShareData(
  {
    func: "jssdkfunc",
    transmits: "a=1&b=2",
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);
```

## 录屏结合分享

基础分享功能参考调用示例，高光时刻等高级功能查看 [录屏管理器 GameRecorderManager](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/api/media/screen-recording/game-recorder-manager/game-recorder-manager)。

**调用示例**

```javascript

let recorder
let videoPath = ''

// 创建录屏管理器
function getGameRecorderManager() {
	sdk.getGameRecorderManager(
		{
			complete: (res) => {
				recorder = res.data
				// 录屏开始示例
				recorder.start({
					duration: 30 // 录屏的时长，单位 s，必须大于 3s，最大值 300s（5 分钟）
				})
				recorder.onStart((res) => {
					console.log('录制开始')
				})
				recorder.onStop((res) => {
					console.log('录制结束')
					videoPath = res.videoPath
				})
			}
		}
	)
}

// 发起分享
// 必须由用户点击触发
function shareVideo() {
	sdk.share({
		channel: 'video',
		func: 'test', // 埋点必传
		extra: {
		  videoPath
		}
	  },
		{
		  complete: (data) => {
			console.log(data);
		}
	})
}
```
