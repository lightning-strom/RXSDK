## 拉起分享

### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params
   | IShareData
    | 是
           | 参数
         |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |

> IShareData 说明

| **字段**
       | **类型**
                              | **是否必填**
 | **备注**
                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|------------------|-----------------------------------------| ---------------- |----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| func
      | string
   | 是
           | 埋点标记
                                                            |
| title
        | string
                              | 否
           | 转发标题，不传则默认使用当前小游戏的昵称。
                                                                                                                                                                                                                    |
| imageUrl
        | string
                              | 否
           | 转发显示图片的链接，只支持网络图片路径
 |
| content
        | string
                              | 否
           | 转发内容
                                                                                                                                                                                                                   |
| query
        | string
                              | 否
           | 查询字符串，必须是 key1=val1&key2=val2 的格式。
                                                                                                                                                                                                                    |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**

```javascript
sdk.share({
  func: 'test',
  title: '标题',
  imageUrl: 'https:/a.b.com/image.pne',
  content: '标题内容 #话题 xxx# 标题内容',
  query: 'a=1&b=2'
}, {
  complete(data) {
    console.log(data)
  }
})
```

## 获取分享信息

::: tip
此接口用于根据入参获取分享的具体数据，然后使用数据将配置的内容分享到各大媒体平台，以达到用户裂变的效果。数据内容与后台的埋点配置，策略配置相关

:::

### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params
   | IGetShareData
 | 是
           | 参数
         |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |

> IGetShareData 说明

| **字段**
  | **类型**
 | **是否必填**
 | **备注**
                                                            |
| ------------- | ------------ | ---------------- | ----------------------------------------------------------------------- |
| func
      | string
   | 是
           | 埋点标记
                                                            |
| transmits
 | string
   | 否
           | 透传参数，原样返回， 请使用 key1=val1&key2=val2 的形式(querystring)，传入 use_url_param=true 时， 将不使用短链接返回，而是将所有参数拼接到 url 中
 |
| region
    | string
   | 否
           | 地区码，没有则不传，会取全国地区的数据。 [望舒地区码列表](https://pan.jiaxianghudong.com/s/pdEzbPRkDS9)
                              |
| readCache
     | boolean
   | 否
           | 是否读取缓存， 默认为true |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**
```javascript
sdk.getShareData(
  {
    func: "jssdkfunc",
    transmits: "a=1&b=2",
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);
```

**响应示例**

```json
{
    "data": {
        "trigger": {    // 埋点数据
            "id": 2,    // 埋点ID
            "tag" : "youdao", // 埋点标识
            "title": "诱导类埋点", // 埋点标题
            "failed_msg": "诱导类失败", // 错误提示
            "type": 1 // 埋点类型 1 诱导类 3成就类  5特殊分享埋点类
        },
        "strategy": { // 策略数据
            "id": 16,    // 策略 ID
            "platform": "wechat",    // 平台
            "share_type": 1,    // 分享类型   1:app分享; 2:小游戏分享
            "type": 2,    //  策略类型：1 诱导类 3成就类  5特殊分享埋点类
            "name": "拼图活动的分享任务策略",  // 名称
            "region": "-1", // 地区码
            "channel_id": "-1", // 渠道 id
            "status": 1
        },
        "content": { // 分享素材数据
            "title": "标题",
            "content": "转发描述",
            "image_url": "定义分享图片"
        },
        "platforms": { // 平台信息，代表某个平台可用的分享方式 -1代表不限制 用于CP方不接sdk的情况。sdk方式通过分享通路配置获取此项配置。
            "wechat": -1 // 微信， 1:好友 2:朋友圈 -1:不限制
        },
        "platform": "wechat", // 当前分享的平台，即客户端传啥 给返回啥
        "example_platforms": { // 正式时不返回，此项用于验证平台信息是否正确
            "wechat": {
                "lure": -1, // 诱导类
                "achievement": 1, // 成就类
                "special": 2 // 特殊类
            }
        },
        "identity": "wx", // 平台标识，如果是微信时返回的为微信ID
        "transmits": "a=2&b=3"
    },
    "code": 0
}
```

## 分享调度

### 分享调度初始化

:::tip
如果在望舒后台开启了分享调度功能必须调用 分享调度初始化 接口，否则将无法正常使用分享调度功能
:::

#### 参数说明

| **字段**
 | **类型**
              | **是否必填**
 | **备注**
     |
| ------------ | ------------------------- | ---------------- | ---------------- |
| params
   | IReqShareScheduleInit
 | 是
           | 参数
         |
| callback
 | IMethodParams
         | 是
           | 回调函数集合
 |

> IReqShareScheduleInit 说明

| **字段**
 | **类型**
 | **是否必填**
 | **备注**
     |
| ------------ | ------------ | ---------------- | ---------------- |
| funcs
    | string[]
 | 否
           | 埋点标识数组，传空获取所有埋点调度
 |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**
```javascript
sdk.shareSchedulingInit(
  {
    funcs: ['maidian'],
  },
  {
    complete: (data: any) => {
      console.log('shareSchedulingInit: ', data)
    },
  }
)
```

#### **响应结构**

**响应示例**：

```json
{
    "code": 0,
    "msg":"",
    "data": "func1": {
        "scheduling_sign": "xx",
        "scheduling_type": "ad",
        "user_type": 1, // 1有效用户 2无效用户
    }
}
```

**响应参数（JSON）**
::: warning
未命中策略的埋点不返回
:::

| **参数**               | **类型** | **是否必填** | **备注**                                  |
| ---------------------- | -------- | ------------ | ----------------------------------------- |
| scheduling_sign    | String   | 是           | 调度分享看广告总次数                           |
| scheduling_type | String   | 是           | 分享 share 广告 ad |  
| user_type | Number   | 是           | 用户状态 1有效用户 2无效用户 |  

### 获取埋点调度
:::tip
分享调度初始化后 SDK 会将数据缓存，客户端需要使用时可以调用 获取埋点调度 来获取需要的埋点调度数据，无需再次初始化。
需要在登录后调用。
:::

#### 参数说明

| **字段**
 | **类型**
          | **是否必填**
 | **备注**
     |
| ------------ | --------------------- | ---------------- | ---------------- |
| params
   | IReqShareSchedule
 | 是
           | 参数
         |
| callback
 | IMethodParams
     | 是
           | 回调函数集合
 |

> IReqShareSchedule 说明

| **字段**
 | **类型**
 | **是否必填**
 | **备注**
     |
| ------------ | ------------ | ---------------- | ---------------- |
| funcs
    | string[]
 | 否
           | 埋点标识数组，传空获取所有埋点调度
 |

**调用示例**
```javascript
// 同步函数
const data = sdk.getShareScheduling()
```

## 分享/广告结果上报

::: tip
如果在望舒后台开启了分享调度功能，在上报时需要将调用 获取分享信息 时的 func、platform、region、transmits 传入。
:::

### 参数说明

| **字段**
 | **类型**
                | **是否必填**
 | **备注**
     |
| ------------ | --------------------------- | ---------------- | ---------------- |
| params
   | IReqShareScheduleReport
 | 是
           | 参数
         |
| callback
 | IMethodParams
           | 是
           | 回调函数集合
 |

> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

> IReqShareScheduleReport 说明

| **字段**
                | **类型**
 | **是否必填**
 | **备注**
                                                            |
| --------------------------- | ------------ | ---------------- | ----------------------------------------------------------------------- |
| func
                    | string
   | 是
           | 埋点
                                                                |
| scheduling_type
         | string
   | 是
           | 调度类型， 'share' ｜ 'ad'
                                          |
| scheduling_event
 | boolean
  | 是
           | 结果状态，true：成功，false：失败 只有成功时，才会进入下一步骤；例如循环为广告->分享->广告 只有这个参数为true时，才会进入分享
                                   |
| region
                  | string
   | 否
           | 地区码
                                                          |
| transmits
               | string
   | 否
           | 透传参数，原样返回， 请使用 key1=val1&key2=val2 的形式(querystring)
 |
| properties
              | object
   | 否
           | 自定义属性
， 上报区服和角色需要在 game_info 中传入属性，具体使用方式参考下方 game_info 字段说明              |

> `properties` 字段说明

| **字段**  | **类型** | **是否必填** | **备注** |
| --------- | ------  | ----------- |---------|
| game_info | object| 否          | 游戏自定义数据                          |

> `game_info` 字段说明

| **字段**  | **类型** | **是否必填** | **备注** |
| --------- | ------  | ----------- |---------|
| cp_game_character_id| string| 否             | 角色 id                           |
| cp_game_area_id     | string| 否            | 区服 id                           |

**调用示例**
```javascript
sdk.shareSchedulingReport(
  {
    func: 'maidian',
    scheduling_type: 'share',
    scheduling_event: true,
    properties: {
      region: 'en',
    }
  },
  {
    complete: (data: any) => {
      console.log('schedulingReport complete: ', data)
    },
  }
)
```

## 调度分享(分享、广告)

### 参数说明

| **字段**
 | **类型**
      | **是否必填**
 | **备注**
     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params
   | IShareData
    | 是
           | 参数
         |
| callback
 | IMethodParams
 | 是
           | 回调函数集合
 |

> IShareData 说明

| **字段**
       | **类型**
                              | **是否必填**
 | **备注**
                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|------------------|-----------------------------------------| ---------------- |------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| func
         | string
                              | 是
           | 埋点标记
                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| adUnitId
      | string
   | 否
           | 调度分享类型为ad时，广告单元 id，若传则使用此id，若不传则取埋点对应配置广告单元id
                                                                                                                  |
| appSid
      | string
   | 否
           | 调度分享类型为ad时，广告平台id
                                                                                                                  |
| title
        | string
                              | 否
           | 调度分享类型为share时，转发标题，不传则默认使用当前小游戏的昵称。
                                                                                                                                                                                                                    |
| imageUrl
        | string
                              | 否
           | 调度分享类型为share时，转发显示图片的链接，只支持网络图片路径
 |
| content
        | string
                              | 否
           |调度分享类型为share时， 转发内容
                                                                                                                                                                                                                   |
| query
        | string
                              | 否
           |调度分享类型为share时， 查询字符串，必须是 key1=val1&key2=val2 的格式。
                                                                                                                                                                                                                    |
> IMethodParams 说明

| **字段**
 | **备注**
                                                  |
| ------------ | ------------------------------------------------------------- |
| complete
 | (data) => void
complete：为函数且必传，data 为结果数据
 |

**调用示例**

```javascript
sdk.schedulingAction({
  func:'haoyou',
},
  {
    complete: (data) => {
      console.log(data);
    },
  })
```

### 响应结构

| **字段** | **类型**                                                                                          | **说明**         |
| -------- | ------------------------------------------------------------------------------------------------- | ---------------- |
| code     | Number                                                                                            | 状态码 0 为成功  |
| msg      | String                                                                                            | 失败时的错误信息 |
| scheduling_type| String                                                                                            | share / ad |
