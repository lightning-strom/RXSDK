# 事件填报
:::tip
本章节为您介绍在该页面对事件进行相关操作。
包括事件信息修改、状态修改。以下将分别为您介绍相应的设置步骤和需要注意信息点。
请注意重点关注文档中加粗、标注部分的描述。
:::

:::tip
事件填报是什么？
事件填报功能为用户提供了手动上报数据的入口。例如 用户在第三方平台的广告花费，无法通过接口直接上报数据，可通过数据填报功能每日手动更新数据。
:::

## 新增数据填报

1. 进入望舒平台首页，点击左侧菜单：**大数据分析平台**。
2. 在页面右上方，点击**数据管理 > 元数据管理 > 数据填报**。
3. 点击页面左上方【新建】，填写相关信息。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/AditbKvT8okBNXxFdqNcWd0In3c.png)

:::tip
1. 带*的字段为必填字段。
2. 事件名和属性名只能是字母开头，可以包含数字和下划线的组合，其他特殊字符不能输入。事件名是标识事件的唯一标识，属性名是标识属性的唯一标识。
3. 属性名输入时，会自动建议已经存在的事件属性，选择后，自动带入所有的信息，并不可修改。
4. 初始化时，维度属性默认展示预置属性：#days。不可操作删除。
5. 维度属性可选择系统中已存在的预置属性、系统属性、自定义属性（禁用状态、布尔、列表属性不可选择，直接不展示），属性名、数据类型、属性说明自动带过来，不可修改。
6. 指标属性的数据类型只能选择数值一种。
:::

## 编辑数据填报

1. 进入望舒平台首页，点击左侧菜单：**大数据分析平台**。
2. 在页面右上方，点击**数据管理 > **元数据管理 > 数据填报**。
3. 点击列表右侧【编辑】，填写相关信息。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/GqqEbPQuhoAMmmxvxkJcelQknte.png)

:::tip
1. 事件名、维度属性、指标属性均不可修改。
2. 指标属性可以添加新属性。
:::

## 设置数据

1. 进入望舒平台首页，点击左侧菜单：**大数据分析平台**。
2. 在页面右上方，点击**数据管理 > 元数据管理 > 数据填报**。
3. 点击列表右侧【设置数据】，进入到设置数据页面。
4. 点击页面上方【添加】，填写相关信息。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/QFVqbQFqCo0Hv6xGefWcF77Anee.png)

:::tip
1. 带*的字段为必填字段。
2. 弹窗中展示的字段，为数据填报中设置的字段。
:::

## 编辑数据

1. 进入望舒平台首页，点击左侧菜单：**大数据分析平台**。
2. 在页面右上方，点击**数据管理 > 元数据管理> 数据填报**。
3. 点击列表右侧【设置数据】，进入到设置数据页面。
4. 点击列表右侧【编辑】，填写相关信息。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/VuybbJ56yoNlOPxhqNjcp1nbnQY.png)

:::tip
只有指标属性的数据可修改。
:::
