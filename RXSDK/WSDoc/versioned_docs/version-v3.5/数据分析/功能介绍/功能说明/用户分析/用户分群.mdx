# 用户分群

## 分群说明

将具有共同特征的人组成用户群，可以宏观了解各种人群的群体特征及微观地洞察具体用户信息，并方便在各种模型中对用户样本进行细分分析。

| 分群类别 | 说明                                     |
| -------- | ---------------------------------------- |
| 条件分群 | 筛选特定行为条件或用户属性得到的用户分群 |
| 结果分群 | 利用分析模型的结果得到的用户分群         |
| SQL 分群 | 使用 SQL 语句查询结果创建用户分群        |

## 如何创建条件分群

1. 在页面顶部选择 **用户分析 > 用户分群** ，之后点击【创建分群】按钮，选择“条件分群”。
2. 可以添加两种类型的分群条件：分别为做过事件、没做过事件或用户属性满足，可以任选一项进行添加。

## 如何创建 SQL 分群

1. 在页面顶部选择 **用户分析 > 用户分群** ，之后点击【创建分群】按钮，选择“ SQL 分群 ”。
2. 创建 SQL 规则

根据需要的逻辑，在 SQL 语句输入框写下对应的语句，SQL 分群将基于 SQL 规则查询结果生成，查询结果仅需要分析主体 ID 一列。

如果语句涉及到事件发生的时间范围，可添加时间参数 `$Part_date`，分群每次更新时都会基于当前的日期确定时间范围。

## 如何创建结果分群

1. 事件分析模型中，如果计算的是触发用户数，则在结果表中可以点击【创建结果分群】来创建分群。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/share/yonghufenqun2.png)

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/OO5dbinYwoOkbhx5TG1cfpnwngh.png)

2. 如果是路径分析模型，需要点击进入查看节点详情才会出现创建结果分群按钮。
   ![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/TbtibGljzofVn2xMH5Hcor4bnge.png)
   a. 如果是留存分析等其他模型，在表格内出现按钮的地方都可以点击创建结果分群
   b. 创建分群时，可设置结果分群的名称以及备注，形成对结果分群的描述
      ![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/F32WboqgHooUdOx0JM7c9cVRnd1.png)

## 如何使用用户分群

1. 在使用模型分析时，添加条件或分组项时，可选择用户分群。
