## 标签说明

用户标签是具有某一系列特征的人群集合，标签值是“一组相似人群”的集合，通过标签和标签值可以方便将人群结构化。

如：用户标签为“充值用户”，标签下有标签值可以分别为“零充”、“低充”、“中充”、“高冲” 的 4 种群体。

通过某种创建方式，将相似特征用户按特征值汇总后组成标签，方便在各种模型中进行细分分析；同时，可以在看板内添加标签，日常数据监控更加方便。

| 分群类别   | 说明                                                                                                                                                                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 条件标签   | 筛选特定行为条件或用户属性的用户，并赋予标签值；用户优先匹配至满足条件且顺序靠前的标签值中。例如：可以创建“付费用户标签”，再通过自定义条件将用户分为高消费用户、中消费用户、低消费用户。后续可将该标签作为分组项，同时分析三种类型用户。 |
| 首末次标签 | 指定时段内，用户完成首/末次事件的属性，作为标签值。例如：埋点层面没有记录用户的首次登录时间，但又需要通过首登日期去做分组或筛选条件。可以选取从开服日至今作为分析时段，以首次登录的时间作为用户的标签值。                                  |
| 指标值标签 | 指定时段内，用户完成事件的聚合指标，作为标签值。例如：需要记录用户在一段时间内的累计付费数据，通过这个数据为用户分层。                                                                                                                     |
| SQL 标签   | 基于 SQL 规则生成分析主体的标签值。                                                                                                                                                                                                        |

## 如何创建条件标签

1. 在页面顶部选择 **用户分析 > 用户分群 **，之后点击【创建标签】按钮，选择“条件标签”。
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/share/yhbq1.png)
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/share/yhbq2.png)
   a. 自定义条件时，所有用户将按照标签值的先后顺序依次判断组成。即同一用户满足上层标签值后，将不再参与下层标签值筛选。
   b. 所有标签值中的用户共同组成了标签用户。
   c. 新增标签值始终在最后一个标签值后。创建时一个标签最多设置 20 组标签值。达到 20 时，无法新增。

## 如何创建首末次标签

1. 在页面顶部选择 **用户分析 > 用户分群 **，之后点击【创建标签】按钮，选择“首末次标签”。
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/share/yhbq3.png)
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/share/yhbq4.png)
2. 分析时段：默认选中动态的「过去 7 天」，可选择动态或静态时间。
3. 首末次信息：可选择首次或者末次。
4. 完成事件：可选择任意一个物理事件或虚拟事件，可以筛选事件属性或用户属性。

| **事件类型** | **可筛选的事件属性** |
| ------------ | -------------------- |
| 物理事件     | 事件属性             |
| 虚拟事件     | 虚拟事件的事件属性   |

5. 分析属性(标签值)：可选发生时间或事件属性，元属性、虚拟属性、维度表属性都可以进行选择，但不包括对象、对象组、对象组的子属性。
6. 数据类型将决定标签的数据类型，及使用标签时的关键字。

| **类型**     | **属性**   | **数据类型** |
| ------------ | ---------- | ------------ |
| 预置指标     | 时间       | 时间         |
| 事件属性指标 | 数值型属性 | 数值         |
|              | 列表型属性 | 列表         |
|              | 布尔型属性 | 布尔         |
|              | 时间型属性 | 时间         |
|              | 文本型属性 | 文本         |

## 如何创建指标值标签

1. 在页面顶部选择 **用户分析 > 用户分群**，之后点击【创建标签】按钮，选择“指标标签”
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/share/yhbq5.png)
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/share/yhbq6.png)
2. 分析时段：默认选中动态的「过去 7 天」，可选择动态或静态时间。
3. 事件：可选择任意一个物理事件或虚拟事件。
4. 筛选条件：可以筛选事件属性或用户属性。

| **事件类型** | **可筛选的事件属性** |
| ------------ | -------------------- |
| 物理事件     | 事件属性             |
| 虚拟事件     | 虚拟事件的事件属性   |

5. 创建指标值标签：通过分析指标确定用户的标签值，即「事件」+「属性」+「计算方法」或直接「事件」+「计算方法」。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/R8RUbT8cgowkxGx0qNwcB2K6ndd.png)

| **属性**   | **计算方法**                               |
| ---------- | ------------------------------------------ |
| 全部属性   | 总次数                                     |
| 数值型属性 | 总和、均值、中位数、最大值、最小值、去重数 |
| 列表型属性 | 列表去重数、元素去重数、集合去重数         |
| 布尔型属性 | 为真数、为假数、为空数、不为空数、去重数   |
| 时间型属性 | 去重数                                     |
| 文本型属性 | 去重数                                     |

6. 编辑公式
   ![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/KWXIbzJO1oGdhGxC10kcRaM1nCg.png)
   a. 整体筛选条件与细分筛选条件
      ![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/HGw3bYkd7oS1CnxbdDKc8JbqnQ9.png)
   b. 整体筛选条件的可选属性为：公式所有组成部分的公有事件属性或全部用户属性。
   c. 属性的筛选逻辑与事件分析一致。

## 如何创建  SQL 标签

1. 在页面顶部选择 **用户分析 > 用户分群 **，之后点击【创建标签】按钮，选择“ SQL 标签”。
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/share/yhbq7.png)
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/share/yhbq8.png)
2. 根据需要的逻辑，在 SQL 语句输入框写下对应的语句，查询结果需要两列，第一列为不重复的分析主体 ID ，第二列为标签值。
3. 如果语句涉及到事件发生的时间范围，可添加时间参数 `$Part_date`，标签每次更新时都会基于当前的日期确定时间范围。
4. SQL 字典：在创建界面右侧，望舒提供了 SQL 字典，方便查看当前可用的表结构。

## 如何使用用户标签

在使用模型分析时，添加条件或分组项时，可选择用户标签。
