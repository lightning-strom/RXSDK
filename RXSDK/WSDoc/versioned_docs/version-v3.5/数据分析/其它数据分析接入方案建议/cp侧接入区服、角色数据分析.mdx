# 1. 上报事件
需要通过区服信息进行统计的事件里需要上报区服、角色id，用于后续统计。
分享、下单支付等事件是望舒侧上报，因此需要在对应的接口或sdk中增加区服、角色id信息。
## 1.1 分享
当cp侧需要对分享事件#share做区服、角色分析统计时，需要在调用sdk时传递对应的区服、角色id信息
[文档示例](/docs/v3.5/三方服务/Android 渠道接入说明)

## 1.2 下单支付
当cp侧需要对支付事件#order订单、#paid付款事件做区服、角色分析统计时，需要再调用sdk时传递对应的区服、角色id信息

接口文档地址：请参照不同支付协议文档固定结构game_info所需参数传值
