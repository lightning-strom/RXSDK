## 上报事件

可使用此功能将事件上报到望舒大数据后台中。
:::tip
需要在SDK初始化后调用！！！
SDK只支持上报事件属性，用户属性请使用 [Go SDK](/docs/v3.5/数据分析/功能介绍/产品说明) 进行上报
:::

**接口原型**

```typescript
/**
 * 埋点数据上报接口，用于收集用户行为和业务数据
 * 
 * @param data - 埋点数据
 * @param data.event_name - 事件名称（必填）
 *                          建议使用小写字母和下划线组合（如 "user_login"）
 * @param data.properties - 事件属性（必填）
 *                          包含事件的详细信息，如 { page: "home", button: "buy" }
 * @param data.distinct_id - 用户唯一标识（可选）
 *                          用于标识具体用户，未提供时使用默认标识
 * 
 * @returns 返回上报结果（同步）
 *          true - 数据已成功加入上报队列
 *          false - 数据格式错误，未进行上报
 */
trackData(data: TrackData): boolean

```
                                                           

**调用示例**

```typescript
RXApi.getInstance().trackData({
  event_name: "test",
  properties: { now: Date.now() }
})

```

## 用户行为统计
:::tip
SDK 会自动收集从 初始化->登录-> 实名认证 产生的用户行为，可在大数据中查看具体行为数据 [用户行为统计](https://nctpoatgf0.feishu.cn/wiki/SqKswRM22ipDKOkvLxCc7jQ5nhb)，客户端可以在望舒预置事件中插入游戏行为统计。
:::

**接口原型**

```typescript
/**
 * 用户行为统计
 */
trackUserAction(properties: Record) 

/**
 * 终止用户行为统计
 */
stopTrackUserAction()
```

**调用示例**

```typescript
// 插入行为统计

RXApi.getInstance().trackUserAction(自定义用户行为字典数据);
    
// 终止行为统计
RXApi.getInstance().stopTrackUserAction();
```
