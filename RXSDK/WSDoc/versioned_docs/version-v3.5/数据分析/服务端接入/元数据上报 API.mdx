# 埋点事件接口文档

## 接口1：创建事件
- **接口地址**：POST /v1/data/api/upload/event
- **接口说明**：创建事件。用于向系统中批量新增或更新用户行为事件，需传入事件列表（包含事件基本信息及关联属性）、处理逻辑（丢弃/新增/覆盖）及上传用户信息。处理逻辑为"丢弃"时，若事件已存在则不做操作；"新增"时仅添加新事件，不覆盖原有事件；"覆盖"时将替换已存在的同名事件。适用于初始化事件定义、批量更新事件信息等场景。
- **请求参数**：
  | 参数名 | 类型 | 位置 | 必填 | 说明 |
  | --- | --- | --- | --- | --- |
  | data | pb.UploadEvent | body | 是 | 包含事件列表、处理逻辑及上传用户信息等 |
- **请求格式**：application/json
- **响应**：

    | 状态码 | 说明                  | 引用类型                          |
    |--------|-----------------------|-----------------------------------|
    | 0      | success 成功                  | domain.Response\ |
    | 500    | Internal Server Error | domain.Response                   |
    - **响应格式**：application/json
    - **认证方式:** [CPSign](/docs/v3.5/入门指南/服务端接入须知)

## 接口2：创建用户属性
- **接口地址**：POST /v1/data/api/upload/user/attr
- **接口说明**：上传用户属性。用于向系统中批量新增全局用户属性，需传入属性列表（包含属性数据类型、名称、描述等）及上传用户信息。新增的用户属性将适用于所有用户，支持后续用户数据的收集与分析。适用于初始化用户属性体系、补充新增用户信息维度等场景。
- **请求参数**：
  | 参数名 | 类型 | 位置 | 必填 | 说明 |
  | --- | --- | --- | --- | --- |
  | data | pb.UploadUserAttr | body | 是 | 包含用户属性列表及上传用户信息等 |
- **请求格式**：application/json
- **响应**：

    | 状态码 | 说明                  | 引用类型                          |
    |--------|-----------------------|-----------------------------------|
    | 0      | success 成功                  | domain.Response\ |
    | 500    | Internal Server Error | domain.Response                   |
    - **响应格式**：application/json
    - **认证方式:** [CPSign](/docs/v3.5/入门指南/服务端接入须知)

## 接口3：创建维度表
- **接口地址**：POST /v1/data/api/upload/dimension
- **接口说明**：上传维度。用于向系统中新增数据表（维度），需传入维度的基本信息（名称、Key）、属性定义（字段名、数据类型等）及初始数据值。支持批量上传维度数据，上传成功后系统将生成唯一的维度ID和UUID，用于后续的关联、查询等操作。适用于新建数据维度、导入外部数据表等场景。
- **请求参数**：
  | 参数名 | 类型 | 位置 | 必填 | 说明 |
  | --- | --- | --- | --- | --- |
  | data | pb.UploadDimensionAttr | body | 是 | 包含维度基本信息、属性列表、初始数据值及上传用户信息等 |
- **请求格式**：application/json
    - **响应**：
    
    | 状态码 | 说明                  | 引用类型                          |
    |--------|-----------------------|-----------------------------------|
    | 0      | success 成功                  | domain.Response\ |
    | 500    | Internal Server Error | domain.Response                   |
    - **响应格式**：application/json
    - **认证方式:** [CPSign](/docs/v3.5/入门指南/服务端接入须知)

## 接口4：创建维度关联属性
- **接口地址**：POST /v1/data/api/dimension/relation/attr
- **接口说明**：维度关联属性。用于建立数据表（维度）与事件属性或用户属性的关联关系，实现维度数据与属性数据的联动查询分析。支持批量关联多个属性，关联后可通过维度快速筛选、统计关联属性的相关数据。适用于数据建模、多维度分析等业务场景。
- **请求参数**：
  | 参数名 | 类型 | 位置 | 必填 | 说明 |
  | --- | --- | --- | --- | --- |
  | data | pb.DimensionRelationAttr | body | 是 | 包含维度ID、维度UUID及待关联的属性列表等信息 |
- **请求格式**：application/json
- **响应**：

    | 状态码 | 说明                  | 引用类型                          |
    |--------|-----------------------|-----------------------------------|
    | 0      | success 成功                  | domain.Response\ |
    | 500    | Internal Server Error | domain.Response                   |
    - **响应格式**：application/json
    - **认证方式:** [CPSign](/docs/v3.5/入门指南/服务端接入须知)
