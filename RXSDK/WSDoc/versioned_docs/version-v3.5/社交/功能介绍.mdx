## 业务介绍

望舒友乐社交 - Social 社交服务为游戏提供了完整的好友解决方案，支持游戏灵活调用各类功能接口，帮助游戏快速形成社交网络，助力游戏运营。

## 产品优势

- **一站式接入好友能力，提升开发效率**：好友产品为游戏开发者提供完整的添加、删除、查找好友的功能接口，游戏无需自建好友系统，大大降低开发成本。
  
- **数据实时追踪，精细化运营提升体验**：开发者后台提供丰富的管理功能，支持开发者查询玩家的好友关系、接口调用等数据，帮助开发者实时管理玩家数据，跟踪好友接口使用情况。
  

## 概念解释

游戏好友关系模型分为「关注模式」和「好友模式」。

- 关注模式：玩家 A 可自主关注玩家 B，此时 A 为 B 的粉丝，B 为 A 的关注。此时如果 B 回关了 A，那么 A 和 B 称为互相关注关系。
  
- 好友模式：当玩家 A 添加玩家 B 为好友时，AB 即为好友关系。好友申请和同意由项目组完成。
  

## 能力说明

|   **描述**  |  **应用场景**  |
| --- | --- |
| 获取自定义关系列表 | 一般用于玩家把好友分组设置与管理。 |
| 添加自定义关系 | 例如：玩家 A 定义“我的男朋友们”好友分组，把玩家 C、B、D 放到该组里。 |
| 删除自定义关系 | 例如：把“我的男朋友们”好友分组里的玩家 B 删除掉，则对应的关系就不存在了。 |
| 更新自定关系备注 | 例如：玩家 A 为“我的男朋友们”好友分组，添加个备注“这些都是我的男朋友们”。 |
| 判断两用户是否存在自定义关系 | 判断两个人是否为自定义关系。 |
| 获取好友列表 | 获取好友关系列表。 |
| 添加好友关系 | 添加好友时，可自定义「关注模式」或「好友模式」，既单向关注还是双向好友。 |
| 删除好友关系 | 删除某个好友关系。 |
| 更新好友关系备注 | 为某个好友添加备注信息。 |
| 判断两用户是否为好友 | 判断两个人是否为好友关系。 |
| 获取位置信息 | 获取玩家当前位置信息。 |
| 开启定位上报 | 开启玩家位置上报服务。 |
| 关闭定位上报 | 关闭玩家位置上报服务。 |
| 删除位置信息 | 删除玩家位置信息。 |
| 获取附近的人 | 通过玩家位置获取半径内其它玩家。 |
