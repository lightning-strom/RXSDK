**接口原型**

```csharp
/// <summary>
/// 上报/更新经纬度坐标
/// </summary>
/// 坐标分组，由 CP 自定义
/// WGS84 经度
/// WGS84 纬度
/// 限定半径距离，单位：米
/// 获取数量，0 表示获取全部
/// 获取第几页的数据 从 1 开始
/// 每页数量
/// 
void LbsRadius(string types, float lon, float lat, float radius, int count, int page, int page_size, Action callback);
```

#### 参数说明

| **字段**  | **类型** | **是否必填** | **备注**                   | **其他信息**               |
| --------- | -------- | ------------ | -------------------------- | -------------------------- |
| lon       | number   | 是           | WGS84 经度                 | mock: 125.36970905364038   |
| lat       | number   | 是           | WGS84 纬度                 | mock: 43.814125235156496   |
| radius    | integer  | 是           | 限定半径距离，单位：米     | mock: @integer(100, 10000) |
| count     | integer  | 否           | 获取数量，0 表示获取全部   | mock: @integer(1, 100)     |
| page      | integer  | 是           | 获取第几页的数据 从 1 开始 | mock: 1                    |
| page_size | integer  | 是           | 每页数量                   | mock: 10                   |
| type      | string   | 是           | 坐标分组，由 CP 自定义     |                            |

**调用示例**

```csharp
float lon = 118.19646377354036f;
float lat = 24.4837108022851f;
var radius = 20000;
var count = 0;
var page = 1;
var page_size = 10;
var type = "friend";
RuiXueSdk.SocialAPI.LbsRadius(type, lon, lat, radius, count, page, page_size, RXCallback);
```

#### 响应结构

**HTTP 状态码：**`200 OK`

| **字段** | **类型**                                  | **是否必填** | **说明** | **示例** |
| --- |-----------------------------------------| --- | --- | --- |
| code | Number                                  | 是   | 响应状态码，0为成功，非0表示出错 | 0   |
| msg | String                                  | 否   | 响应信息，仅在status为非0时不为空 |     |
| data | [DataNode](/docs/v3.5/社交/功能介绍) | 否   | 结果数据集 |     |

##### DataNode

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | --- |
| openid | String | 是   | 用户望舒 OpenID |     |
| nickname | String | 否   | 用户昵称 |     |
| birthday | String | 否   | 用户生日日期 |     |
| remarks | String | 否   | 当前用户对其的备注 |     |
| avatar | String | 否   | 用户头像 |     |
| custom | String | 否   | CP 自定义信息 |     |
| dist | Float64 | 是   | 距离当前用户的距离（米） |     |
| sex | Number | 否   | 用户性别，1:男；0:女 |     |
| cp_userid | Number | 否   | CP侧 用户id |     |

**响应示例**

```json
{    
    "data": [       
        {            
            "openid": "rxuSl4QZoNk0G1HY2-Za6GlO7wO-p_ej",            
            "nickname": "xdh"        
        }    
     ],    
     "code": 0
}
```
