## 设置用户信息

**接口原型**

```go
// SetUserInfo 设置用户信息
func (c *Client)SetUserInfo(appID, openID string, userinfo *UserInfo) error 
```

### 参数说明

| **字段** | **类型**                            | **是否必填** | **备注** |
| --- |-----------------------------------| --- | --- |
| openID | string                            | 是   | 望舒 open id |
| userinfo | *[UserInfo](Go SDK#userinfo) | 是   |     |

##### userinfo

| **字段** | **类型** | **是否必填** | **备注** |
| --- | --- | --- | --- |
| AppID | string | 是   | CP 侧 APPID |
| OpenID | string | 是   | 望舒 open id |
| Nickname | string | 否   | 用户昵称 |
| Avatar | string | 否   | 用户头像 |
| Region | string | 否   | 用户所在地区 例如 220101 |

**调用示例**

```go
err := ruixuego.GetDefaultClient().SetUserInfo("{{APPID}}", "openID", &UserInfo{    AppID: "{{APPID}}",    OpenID: "openID"})
if err != nil { panic(err) }
```

### 响应结构

| **字段** | **类型** | **是否必填** | **备注** |
| --- | --- | --- | --- |
| err | error | 是   | 成功时 nil, 其他为错误 |

## 添加自定义好友关系

**接口原型**

```go
// AddRelation 添加自定义关系
// remarks[0] openID 用户给 targetOpenID 用户设置的备注
// remarks[1] targetOpenID 用户给 openID 用户设置的备注
func (c *Client) AddRelation(  types RelationTypes, openID, userID, targetOpenID, targetUserID string, remarks ...string) error
```

### 参数说明

| **字段** | **类型** | **是否必填** | **备注** |
| --- | --- | --- | --- |
| types | map[string]bool | 是   | 自定义关系类型对应的是否为双向好友 例如 {'{'}"friend" : true{'}'} |
| openID | string | 是   | 望舒 open id, 和userID 任写一个即可|
| userID | string | 是   |  cp侧 user_id  和openID任写一个即可 |
| targetOpenID | string | 是   | 给用户设置的自定义信息 和targetUserID任写一个即可  |
| targetUserID | string | 是   |  cp侧 user_id 和targetOpenID任写一个即可 |
| remarks | slice(string) | 否   | 数组切片。仅支持两个元素，第一个元素为 targetOpenID 设置的 mark, 第二个元素为openID 设置的mark |

**调用示例**

```go
err := ruixuego.GetDefaultClient().AddRelation(    
    map[string]bool{"friend" : true},     
    "openID",
    "userID",     
    "targetOpenID",
    "targetUserID",    
    "targetRemark",    
    "openIDRemark")
if err != nil { panic(err) }
```

### 响应结构

| **字段** | **类型** | **是否必填** | **备注** |
| --- | --- | --- | --- |
| err | error | 是   | 成功时 nil, 其他为错误 |

## 获取附近的人列表
:::info
先更新 openID 位置为参数中 lon lat 位置上， 然后查找这个位置 radius 半径内的其他玩家
:::

**接口原型**

```go
// LBSRadius 获取附近的人列表
func (c *Client) LBSRadius(   openID, userID, typ string,   lon, lat, radius float64,   page, pageSize int,   count ...int) ([]*RelationUser, error) 
```

### 参数说明

| **字段** | **类型** | **是否必填**  | **备注** |
| --- | --- | --- | --- |
| openID | string | 是   | 望舒 open id, 和userID 任写一个即可|
| userID | string | 是   |  cp侧 user_id  和openID任写一个即可 |
| types | string | 是   | 分组类型。需要在望舒后台先创建对应的分组 |
| lon | float64 | 是   | 坐标 经度。 需满足 WGS84 标准 |
| lat | float64 | 是   | 坐标 纬度。需满足 WGS84 标准 |
| radius | float64 | 是   | 查询半径。单位 m |
| page | int | 是   | 分页请求，第几页。 |
| pageSize | int | 是   | 分页请求，每页数量 |
| count | int | 是   | 最多查询多少玩家 |

**调用示例**

```go
users, err := ruixuego.GetDefaultClient().LBSRadius(    "openID", "userID", "test", 10.1, 100.1, 100, 1, 20, 1000)
if err != nil {   panic(err)}
```

### 响应结构

| **字段** | **类型**                                      | **是否必填**  | **备注** |
| --- |---------------------------------------------| --- | --- |
| users | []*[RelationUser](Go SDK#relationuser) | 否   | 返回的好友信息列表 |
| err | error                                       | 是   | 成功时 nil, 其他为错误 |
