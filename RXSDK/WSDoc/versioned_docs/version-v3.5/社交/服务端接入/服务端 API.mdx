## 准备工作

以下是 CP 服务端请求接口，需要准备好 `cp_id` 、 `product_id` 、`channel_id` 、`cp_key` 等参数。
domain：为产品对外域名
请求头：[望舒服务端请求头](/docs/v3.5/入门指南/服务端接入须知)

## 添加自定义关系

> **POST：**  `/v1/social/serverapi/addrelation`
> **认证方式：** [CPSign](/docs/v3.5/入门指南/服务端接入须知)

### CURL 示例

```bash
curl --location --request POST '{{接口域名}}/v1/social/serverapi/addrelation' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--data-raw '{    
    "types":{"pp":true},    
    "target":"rxufb2GKDBm5n4u7gYkcOLbOv7J4RrVP",    
    "openid":"rxuSl4QZoNk0G1HY2-Za6GlO7wO-p_ej",    
    "user_remarks":"",    
    "target_remarks":""
}'
```

### 请求参数（JSON）

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | --- |
| openid | String | 是   | 已方 望舒 openid。和 cp_user_id 任传一个即可  |     |
| cp_user_id | String | 是   | cp 侧 userid。和望舒 openid 任传一个即可 |     |
| target | String | 是   | 对方 望舒 OpenID 。和 target_cp_user_id 任传一个即可| test |
| target_cp_user_id | String | 是   | cp 侧 userid。和 target 任传一个即可 | test |
| types | Map[String]Bool | 是   | CP 自定义关系类型列表，其值是一个 map 简直对列表，格式为：
{'{'}
 类型标识符(String):是否为双向关系
{'}'} | {'{'}
 "test":true,
 "aaa":false
{'}'} |
| target_remarks | String | 否   | 用户给Target设置的备注信息（最长512字符） | aaaa |
| user_remarks | String | 否   | Target给用户设置的备注信息（最长512字符） | bbbb |

**请求示例**

```json
{    
    "types":{"pp":true},    
    "target":"rxufb2GKDBm5n4u7gYkcOLbOv7J4RrVP",    
    "openid":"rxuSl4QZoNk0G1HY2-Za6GlO7wO-p_ej",    
    "user_remarks":"",    
    "target_remarks":""
}

或者

{    
    "types":{"pp":true},    
    "target_cp_user_id":"10000",    
    "cp_user_id":"10001",    
    "user_remarks":"",    
    "target_remarks":""
}

```

### 响应参数（JSON)

**HTTP 状态码：**`200 OK`

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | --- |
| code | Number | 是   | 响应状态码，0为成功，非0表示出错 | 0   |
| msg | String | 否   | 响应信息，仅在status为非0时不为空 |     |

**响应示例**

```json
{"code": 0}
```
