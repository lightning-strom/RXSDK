
## 定位

### 获取附近的人

**接口原型**

```objectivec
/**
 * 获取附近的人
 * @param radius 半径（米）
 * @param count 查询数量，（默认0，0为全部）非必传
 * @param page 页数，从1开始
 * @param page_size 每页数量
 * @param type 查询类型
 */
- (void)getRadiusAccount:(NSInteger)radius
                   count:(NSInteger)count
                    page:(NSInteger)page
               page_size:(NSInteger)page_size
                    type:(NSString *)type
                complete:(RequestComplete)complete;
```

#### 参数说明

| **字段**  | **类型**  | **是否必填** | **备注**                       |
| --------- | --------- | ------------ | ------------------------------ |
| radius    | NSInteger | 是           | 半径（米）                     |
| count     | NSInteger | 否           | 查询数量，（默认 0，0 为全部） |
| page      | NSInteger | 是           | 页数，从 1 开始                |
| page_size | NSInteger | 是           | 每页数量                       |
| type      | NSString  | 是           | 查询类型                       |

**调用示例**

```objectivec
[[RXContactService sharedSDK] getRadiusAccount:1000 count:100 page:1 page_size:10 type:@"boy" complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
        
}];
```
#### 响应参数（JSON)

**HTTP 状态码：**`200 OK`

| **字段** | **类型**                                  | **是否必填** | **说明** | **示例** |
| --- |-----------------------------------------| --- | --- | --- |
| code | Number                                  | 是   | 响应状态码，0为成功，非0表示出错 | 0   |
| msg | String                                  | 否   | 响应信息，仅在status为非0时不为空 |     |
| data | [DataNode](/docs/v3.5/社交/功能介绍) | 否   | 结果数据集 |     |

##### DataNode

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | --- |
| openid | String | 是   | 用户望舒 OpenID |     |
| nickname | String | 否   | 用户昵称 |     |
| birthday | String | 否   | 用户生日日期 |     |
| remarks | String | 否   | 当前用户对其的备注 |     |
| avatar | String | 否   | 用户头像 |     |
| custom | String | 否   | CP 自定义信息 |     |
| dist | Float64 | 是   | 距离当前用户的距离（米） |     |
| sex | Number | 否   | 用户性别，1:男；0:女 |     |
| cp_userid | Number | 否   | CP侧 用户id |     |

**响应示例**

```json
{    
    "data": [       
        {            
            "openid": "rxuSl4QZoNk0G1HY2-Za6GlO7wO-p_ej",            
            "nickname": "xdh"        
        }    
     ],    
     "code": 0
}
```
