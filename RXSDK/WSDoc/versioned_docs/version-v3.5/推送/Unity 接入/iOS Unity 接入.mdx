## 推送配置

### 创建推送证书

在 [Apple Developer](https://developer.apple.com/account/#!/overview/W6R94596BT) 中创建推送证书

- 点击 **Certificates**

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/push/IZL4bX0RroKks3xwPEncIAF9nDo.png)

- 选择 **Apple ****Push**** Notification service ****SSL**** (Sandbox & Production)**

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/push/KvuFbYfL3oOVhvxNaX7cCg87nLc.png)

- 选择项目对应的 **App ID**

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/push/D7fcb3WpJoUH6DxrJWMcZXH9nUb.png)

- 选择从证书颁发机构请求的证书

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/push/VsdgbqMXSoD1KSx0g8PcwgbYnFc.png)

- 将生成的证书下载到本地并双击安装

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/push/WvWwbBOoco2bfXxQmAxcCIf1n0c.png)

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/push/Y4ufb6zfDoEv6xxHBqAcCiYKn0f.png)

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/push/DHGqbduQMoTTwAxh5J3c7DLmn5c.png)

### 创建 Notification Service Extension

::: tip
如不需要推送统计可忽略此配置。
**Notification Service Extension** 支持的系统版本需要与主工程target一致，并将 **Build Setting 中的 Bitcode 设置为 NO**。
:::

- 通过 **Xcode > File > New > Target** 创建 **Notification Service Extension**

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/push/DMSZbKiSHoLNAaxSjcOcHDtwnFf.png)

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/push/LwNGbCXfaoLPHBxcfejc06Ypnrd.png)

### 工程配置

- 在 **Xcode > General > Signing & Capabilities** 中添加 **Push Notifications**

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/push/CmyCbO43YoNL7fxK5Dlc1Eb9nme.png)

- 在 **Xcode > General > Signing & Capabilities** 中添加 **Keychanin Sharing** 并将主工程 target 和 NotificationService 的 target 的 bundleId 填入。

::: tip
持有数据的target和NotificationService target都需要操作此流程，否则数据统计会有异常。
:::

### 推送初始化

打开 `UnityPlayerActivity.java` 文件，在 onCreate，onNewIntent 放下下新增

```csharp

    private void Init()
    {
        string cpId = "1000101";
        string channelId = "100";
        string productId = "1002";
        List list = new()
        {
            "https://anhvcpo.weilekuiming.com"
        };
        
        RuiXueSdk.Initialize(cpId, productId, channelId, list, InitResponseDelegate, InitErrorDelegate);
    }

    public void InitResponseDelegate(string data)
    {
        LogUtil.Log("EventManager", $"InitResponseDelegate RequestResponseDelegate: {data}");
        
    }
    public void InitErrorDelegate(string data)
    {
        LogUtil.Log("EventManager", $" InitErrorDelegate RequestErrorDelegate: {data}");
    }

```

## 注册望舒推送服务

**接口原型**

```csharp
    /// <summary>
    /// 注册望舒推送服务（建议望舒登录成功后调用一次，不切换账号不用重复调用）
    /// 由于registerToken和望舒账号关联绑定，所以请不要在登录前调用
    /// </summary>
    public void RegisterToken();
```

**调用示例**

```csharp

    public void OnRegisterToken()
    {
        RXPush.RegisterToken();
    }

```

## 反注册望舒推送服务

**接口原型**

```csharp
        /// <summary>
        /// 反注册望舒推送服务（建议在登出账号时调用）
        /// </summary>
        public void UnRegisterToken();
```

**调用示例**

```csharp

    public void OnUnRegisterToken()
    {
        RXPush.UnRegisterToken();
    }

```

## 其它方法

**接口原型**

```csharp

        /// <summary>
        /// 服务器生成的推送 token/regId
        /// </summary>
        public string GetDeviceToken();

        /// <summary>
        /// 当前设备是否支持推送 init（）后调用
        /// </summary>
        public bool IsSupport();

        /// <summary>
        /// 当前推送的厂商平台 BRAND
        /// </summary>
        public string  GetBrandName();

        /// <summary>
        /// 开发者可以为指定用户设置别名，然后给这个别名推送消息，效果等同于给RegId推送消息
        /// </summary>
        /// 
        public void BindAlias(string alias);

        /// <summary>
        /// 开发者可以取消指定用户的某个别名，服务器就不会给这个别名推送消息了
        /// </summary>
        /// 
        public void UnBindAlias(string alias);

```

**调用示例**

```csharp

    public void OnGetDeviceToken()
    {
       LogUtil.Log("EventManager",  "GetDeviceToken " + RXPush.GetDeviceToken());
    }

    public void OnIsSupport()
    {
        LogUtil.Log("EventManager",  "IsSupport " + RXPush.IsSupport());
    }

    public void OnGetBrandName()
    {
        LogUtil.Log("EventManager",  "GetBrandName " + RXPush.GetBrandName());
    }

    public void OnBindAlias()
    {
        RXPush.BindAlias("unity-test");
    }

    public void OnUnBindAlias()
    {
        RXPush.UnBindAlias("unity-test");
    }

```
