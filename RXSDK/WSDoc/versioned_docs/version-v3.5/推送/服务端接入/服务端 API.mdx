## 发送推送消息

> **POST：** `/v1/pusher/push/push`
> **认证方式：** [CPSign](/docs/v3.5/入门指南/服务端接入须知)

### CURL 示例

```bash
curl --location --request POST '{{接口域名}}/v1/pusher/push/push' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
 -d '{"target":{"type":0,"openid":[],"tag":"","alias":[]},"push_info":{"title":"有人抱走了你的猫咪","content":"球球被别人抱走了，快去领回来吧","action":0,"payload":"","classification":0}}' \
```

<strong>请求示例</strong>

```json
{
    "target":{
        "type":0,
        "openid":[

        ]
     },
    "push_info":{
        "title":"有人抱走了你的猫咪",
        "content":"球球被别人抱走了，快去领回来吧",
        "action":0,
        "payload":"",
        "classification":0
    },
    "target_user_type":0
}
```

### 请求参数（JSON）

| <strong>字段</strong> | <strong>类型</strong> | <strong>是否必填</strong> | <strong>说明</strong> | <strong>示例</strong> |
| --- | --- | ---- | --- | --- |
| target | [Target Object](/docs/v3.5/入门指南/服务端接入须知) | 是 | 推送目标信息 |  |
| push\_info | [PushInfo Object](/docs/v3.5/入门指南/服务端接入须知) | 是 | 推送内容 |  |
| target\_user\_type | Number | 否 | 通道类型 0 正式通道 1 测试通道(目前华为、荣耀、[vivo](/docs/v3.5/入门指南/服务端接入须知)、苹果支持) 
 如果是测试通道 target.type只允许为 1 类型，以一个 openid 作为标识发送 |

##### Target

| <strong>字段</strong> | <strong>类型</strong> | <strong>是否必填</strong> | <strong>说明</strong> | <strong>示例</strong> |
| --- | --- | ---- | --- | --- |
| type | Number | 是 | 推送目标类型可选值有：
0：向全部用户推送
1：以一个用户望舒 openid 作为身份标识向单个用户推送
2：以一群用户望舒 openid 作为身份标识向一群用户推送 | 0 |
| openid | []String | 否 | 望舒 openid，target.type = 1/2 时(与cp\_user\_id传其中一个即可) | ["openid1"]
["openid1","openid2"] |
| cp\_user\_id | []String | 否 | 游戏 id，target.type = 1/2 时（与openid传其中一个即可） | ["cp\_user\_id"] |

##### PushInfo

| <strong>字段</strong> | <strong>类型</strong> | <strong>是否必填</strong> | <strong>说明</strong> | <strong>示例</strong> |
| --- | --- | ---- | --- | --- |
| title | String | 是 | 推送消息的标题 | "有人抱走了你的猫咪" |
| content | String | 是 | 推送消息的内容 | "球球被别人抱走了，快去领回来吧" |
| action | Number | 是 | 推送消息点击后的动作：
0：打开 APP 首页
1：打开网页
2：带参数打开 APP | 0 |
| payload | String | 否 | 推送消息的参数
根据 push\_info.action 的值，填写对应参数
push\_info.action =1 时填写 打开网页的 url 地址
push\_info.action =2 时填写 所携带的参数 | "[http://www.4399.com](http://www.4399.com)"
"roomid=333245" |
| classification | Number | 是 | 消息类型
0 营销类消息
1 系统类消息 | 0 |

<strong>响应示例</strong>

```json
{
   "data":{
       "task_id":123456789,
       "device_type_map":{
           "apnspush":"success"
       }
   },
   "code": 0
}
```

| --- | --- | --- |
