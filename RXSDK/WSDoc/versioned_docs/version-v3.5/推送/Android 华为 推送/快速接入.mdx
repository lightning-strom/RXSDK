#### SDK 集成

```groovy
implementation "com.ruixue.push:rxsdk_push_huawei:${version}"
```

#### 接入配置

进入 [华为 AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html#/)，[请查看配置说明文档](/docs/v3.5/三方服务/Android 渠道接入说明)。
开通华为推送服务，项目设置 > 常规 > 下载 SDK 配置 `agconnect-services.json` 配置文件，放在 app 根目录下。

**添加应用的 AppGallery Connect 配置文件**
登录 AppGallery Connect，选择 `我的应用`。找到应用所在的产品，点击应用名称。
选择“开发 > 概览”，单击 `应用` 栏下的 `agconnect-services.json` 下载配置文件。
将 `agconnect-services.json` 文件拷贝到 app 目录下。如下：

```
RuiXuePushDemo/
  |- app/ （项目app模块）
  |    |- agconnect-services.json
  |- gradle/
  |- build.gradle （根目录 gradle 文件）
  |- settings.gradle
  | ......
```

**依赖配置**
在项目根目录下 `build.gradle` 文件的 `buildscript.repositories` 和 `allprojects.repositories` 中，添加 HMS SDK 的 maven 地址。在 `buildscript.dependencies` 添加 `classpath "com.huawei.agconnect:agcp:${version}"` 如下所示：

```groovy
buildscript {
    repositories {
        jcenter()
        google()
        maven {url 'http://developer.huawei.com/repo/'}
    }
    dependencies {
        ...
        classpath 'com.huawei.agconnect:agcp:1.6.0.300' }
}

allprojects {
    repositories {
        ...
        maven {url 'http://developer.huawei.com/repo/'}
    }
}
```

在模块级别 `app/build.gradle` 中文件头配置 `apply plugin: "com.huawei.agconnect"`
**注意 app 签名要与华为推送后台配置保持一致**

## 混淆配置

在应用级根目录下打开混淆配置文件`proguard-rules.pro`，加入排除SDK的混淆配置

```groovy
#ruixue PUSH sdk混淆
-dontwarn com.ruixue.push.**
-keep class com.ruixue.push.** { *; }

#华为混淆(可选 接入华为推送配置)
-ignorewarnings
-keepattributes *Annotation*
-keepattributes Exceptions
-keepattributes InnerClasses
-keepattributes Signature
-keepattributes SourceFile,LineNumberTable
-keep class com.huawei.hianalytics.**{*;}
-keep class com.huawei.updatesdk.**{*;}
-keep class com.huawei.hms.**{*;}

```

## 推送接口说明

`RxPushManager` 是望舒推送在 Android 平台的接口类。该类提供了一系列静态方法（static）接口，无需实例化直接调用。

:::tip
使用望舒 **推送自定义透传参数（deeplink）** 功能获取参数参考下方 `parseDeeplink` 示例函数。
:::

**接口原型**

```java

/**
 * 处理打开app回调，用于统计通知点击
 * 在带有  标记的，
 * 启动 Activity 中 onCreate 和  onNewIntent 函数中调用此函数,否则可能影响统计。
 * @param intent 传入getIntent()
 */
public static void openAppCallback(Intent intent) ;

/**
 * @param context Android平台上app的上下文
 * @return 是否初始化成功，true 初始化成功当前平台支持推送， false 不支持
 */
public static boolean init(@NonNull Context context) ;

/**
 * 注册望舒推送服务（建议望舒登录成功后调用一次，不切换账号不用重复调用）
   由于registerToken和望舒账号关联绑定，所以请不要在登录前调用
 */
public static void registerToken() ;

/**
 * 反注册望舒推送服务（建议在登出账号时调用）
 */
public static void unRegisterToken(;
/**
 * @return 服务器生成的推送 token/regId
 */
public static String getDeviceToken();

/**
 * @return 当前设备是否支持推送 init（）后调用
 */
public static boolean isSupport();

/**
 * @return 当前推送的厂商平台 BRAND
 */
public static String getBrandName();

/**
 * 开发者可以为指定用户设置别名，然后给这个别名推送消息，效果等同于给RegId推送消息。
 *
 * @param alias 要绑定的别名
 */
public static void bindAlias(@NonNull String alias) ;

/**
 * 开发者可以取消指定用户的某个别名，服务器就不会给这个别名推送消息了。
 *
 * @param alias 要取消的别名 ，空取消所有别名
 */
public static void unBindAlias(String alias);
```
