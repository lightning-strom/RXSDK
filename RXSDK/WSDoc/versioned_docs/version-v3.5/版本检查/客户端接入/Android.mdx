## 产品包版本检查（已废弃）
:::warning
已废弃，请使用 检查产品包（通用）接口。
:::

**接口原型**

```java
    /**
     * @param version  客户端版本号，3段或4段
     * @param region   地区码
     * @param queryMap type 脚本类型 默认json， 可选 lua， u3d
     *                 format 输出文件后缀，默认json，可选lua
     * @param callback callback
     */
    void updateApp(String version, String region, Map queryMap, RXStringCallback callback);
```

### 参数说明

> Map 结构说明

| **字段** | **类型** | **是否必填** | **说明**                          |
| -------- | -------- | ------------ | --------------------------------- |
| type     | int      | 否           | 脚本类型 默认 js， 可选 lua， u3d |

**调用示例**

```java
    String version="1.0.1";
    String region="150000";
    RuiXueSdk.getRXSdkApi().updateApp(version,region, callback);
```

| ---------- |-------------------------------------------| --------------------------------------- |

##### LoginConfig
::: tip
数据会根据后台配置决定  
如果登录配置类型为“默认配置”，则由服务端进行匹配，优先级如下
- 商店账户归属地区优先：（指定地区>商店账户归属地区>IP归属地区>用户设备系统地区>默认地区），仅限 iOS，安卓无法使用
- IP归属地区优先：（指定地区>IP归属地区>商店账户归属地区>用户设备系统地区>默认地区）

如果登录配置类型为“多付首选”，则将配置直接下发
:::

## 产品包版本检查（通用）
:::tip
用户选择分区后要调用 [设置游戏登录配置](/docs/v3.5/入门指南/快速开始/Android初始化/快速接入) 接口，将所选的登录配置对象传入，该接口不调用会导致区服相关数据统计丢失。
:::

**接口原型**

```java
    /**
     * @param version  客户端版本号， 3段或4段
     * @param region   地区码， 默认0
     * @param type     脚本类型 默认js， 可选lua， u3d
     * @param queryMap games {"games:{"游戏id": 客户端游戏版本}"}
     *                 activities {"activities":{"活动别名": 客户端活动版本}}
     * @param callback 回调函数
     */
    public void checkUpdateApp(String version, String region, String type, Map queryMap, RXStringCallback callback);
```

### 参数说明

> Map 结构说明

| **字段**   | **类型**           | **是否必填** | **说明**                      |
| ---------- | ------------------ | ------------ | ----------------------------- |
| activities | Map | 否           | key 客户端活动别名 value 版本 |
| games      | Map | 否           | key 客户端游戏 id value 版本  |

## 游戏更新检查

**接口原型**

```java
    /**
     * 游戏版本检查
     * @param gameId           游戏id
     * @param gameVersion      客户端版本号
     * @param gameCheckVersion 优先检查这个版本，没用再返回最新版本
     * @param queryMap         type 脚本类型 默认json， 可选 lua， u3d
     *                         format 输出文件后缀，默认json，可选lua
     * @param callback         callback
     */
    void updateGame(String gameId, String gameVersion, String gameCheckVersion, Map queryMap, RXStringCallback callback);
```

### 参数说明

> Map 结构说明

| **字段** | **类型** | **是否必填** | **说明**                          |
| -------- | -------- | ------------ | --------------------------------- |
| type     | int      | 否           | 脚本类型 默认 lua， 可选 js， u3d |

**调用示例**

```java
    RuiXueSdk.getRXSdkApi().updateGame("123", "1", "0", callback);
```

### 响应结构

| **参数** | **类型** | **约束**         |
| -------- | -------- | ---------------- |
| uri      | String   | 游戏热更地址路径 |
| version  | String   | 最新版本         |
| game_id  | Number   | 游戏 id          |

返回参数有也会有“url”字段，是为兼容 js 而返回的， 全部升级后会废弃掉
