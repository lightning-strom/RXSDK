#### 使用雷电模拟器测试荣耀渠道包支付时，如果出现参数错误/不能调起支付 的情况？
如果您遇到这类问题，请尝试以下操作：
1. 确认瑞雪后台计费点信息是否配置，三方计费点信息是否和后台商品ID配置一致。
2. 支付参数核查是否与荣耀后台一致。
3. 上述条件都无问题,请切换mumu模拟器/荣耀手机进行支付调试。
<br/>

#### 接入瑞雪客户端sdk或渠道sdk时出现相关错误
请检查控制台输出错误信息，如果有rxsdk标识则为瑞雪sdk相关错误，如果没有标识可能非瑞雪错误，瑞雪无法排查，接入方可以根据错误提示，检查工程项目或者代码错误。

#### 微信unionId和openId说明
在小程序中，openID是小程序的普通用户的一个唯一的标识，只针对当前的小程序有效。公众号同理。即同一个应用（App、公众号、小程序）的同一个用户有唯一的openid。
同一个微信开放平台帐号下的移动应用、网站应用和公众帐号（包括小程序），用户的 UnionID 是唯一的。换句话说，同一用户，对同一个微信开放平台下的不同应用，unionid是相同的。

#### Android 包冲突解决办法

由于瑞雪SDK包含很多第三方 SDK，接入不同库，可能会造成包引入重复
如果出现类似于 
```
Duplicate class com.ta.utdid2.a.a.a found in modules jetified-AlipaySdk-15.8.01.20210112203525-runtime (com.alipay.sdk:AlipaySdk:15.8.01.20210112203525) and jetified-alicloud-android-utdid-2.6.0 (com.aliyun.ams:alicloud-android-utdid:2.6.0)
```
在 build.gradle 下新增
```
configurations {
    all*.exclude group: 'com.aliyun.ams', module: 'alicloud-android-utdid'
}
```
解决冲突通用规则，all*.exclude 按此修改
com.aliyun.ams:alicloud-android-utdid:2.6.0
group： com.aliyun.ams
module： alicloud-android-utdid
