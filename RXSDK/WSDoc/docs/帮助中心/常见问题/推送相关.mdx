#### 1.使用开发者后台配置推送回执地址
如果您需要配置推送回执地址，按照此格式：
api域名/v1/pusher/notify/honor(渠道)?product_id=产品ID&channel_id=渠道ID
API域名,产品ID,渠道ID：瑞雪游戏平台首页信息有展示。
渠道：是哪个平台就配置哪个平台(例：huawei harmony oppo xiaomi vivo flyme honor )
<br/>

#### 3.创建推送选择指定人群时，收不到推送消息
1.首先排查上面问题的情况。
2.选择人群标签后，请点击预计发送设备/人数，查看预计发送是不是不为0.
3.如果预计发送设备为0，到大数据后台确认选择的人群标签是否有数据并且为自动更新标签。如果是手动更新的标签，需要点击一下更新，刷新标签后在查看预计发送设备数据。
<br/>
#### 4.大数据查看推送数据时只有发送总量，没有发送成功数等数据（其余数据都是0）的情况。
1.检查对应渠道包在企业后台是否配置了推送功能所需的参数。
2.如果配置了参数核查参数是否正确。在对应的渠道开放平台是否正确配置推送回执地址。
3.都无问题联系瑞雪排查。
<br/>

#### 5.语言匹配情况
1.相关数据均由大数据侧进行推送，不同CP的数据同步时间不同，海外项目可能会导致语言个别存在差异。例如：用户语言当前为10:48英语，调整了为泰语，数据同步时间为整点更新。那么11:00之前的推送还是会按照用户当前语言为英语进行匹配推送。
2.同产品，同渠道下如果一个设备有多个用户不同语言，可能会收到多条推送消息。同产品，同渠道下同语言的多用户是收到一条推送信息。
3.不同产品、渠道在同一设备也会收到多条推送信息。
4.如果获取语言为空的时候会根据配置的默认语言进行发送。其余的按照用户匹配语言进行推送。
