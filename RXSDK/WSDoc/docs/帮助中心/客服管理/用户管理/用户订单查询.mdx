## 一、功能介绍
用户订单查询，支持用户Open ID、支付方式，查询某日用户订单信息。

## 二、操作步骤

1.菜单位置：基础 > 用户管理 > 用户订单查询
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1768185787348.png)
2.如果有用户反馈并且提供支付凭证。CP支付回调失败的时候，可以在瑞雪后台处理补单，重新通知CP发货。（只通知一次）
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1768185799837.png)
```tip
1.可输入项目订单、流水号，或用户 Open ID 进行查询，可查询到订单下单时间，订单状态（退订状态）等信息。
2.查询结果支持按日查询。
3.订单回调/支付 错误可以从后面的订单日志查看
```

## 三、苹果订单查询
1.菜单位置：基础客服 > 用户管理 > 用户订单查询 > 苹果订单查询
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1768185820921.png)
2.通过选择产品、渠道以及输入苹果支付的对应订单号进行查询苹果订单的结果以及信息。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1768185829077.png)
所需订单号必须为苹果商店中的订单号（支付截图中的商户单号不支持查询）。例如：
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1727079184200.png)

:::tip
需要使用该功能需要现在企业后台-支付账号管理中配置苹果相关参数。[配置参考](https://doc.ruixueyun.com/#/view?viewPath=99780fe6-0bff-492b-a3e5-cd2552648265&title=%E8%AE%A2%E5%8D%95%E6%9F%A5%E8%AF%A2%E9%85%8D%E7%BD%AE&tab=&index=1)
