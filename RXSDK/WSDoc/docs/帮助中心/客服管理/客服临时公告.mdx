## 一、功能介绍

如果出现紧急情况，如服务器故障、网络攻击或其他技术问题时。用户大量咨询人工客服时，可以通过客服临时公告减轻客服人工压力。让用户知晓问题发生原因以及处理进展。

## 三、操作步骤

### 步骤一：创建客服临时公告

| 菜单<br/>     | 游戏发行平台 / 客服服务管理 / 客服临时公告<br/>                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 操作示意<br/> |![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1768185514532.png)<br/>操作步骤：<br/>1. 客服临时公告列表，点击「新建」按钮；<br/>2. 选择发布产品和渠道；<br/>3. 选择公告显示的位置，帮助中心或客服会话中；<br/>4. 是否强制弹出弹框，如果是则进入帮助中心立即弹出，否则不弹出；<br/>5. 输入公告内容，注意：会根据产品配置的语言，要求输入不同语言的公告内容；<br/>6. 发布时间：立即发布还是定时发布；<br/>7. 结束时间：相对发布时间多久后结束显示公告；<br/> |

```tip
相同产品和渠道、相同时间段内只能展示一条有效的公告；
```
