## 一、功能介绍

活动包含监测链接和媒体回传映射两部分内容。瑞雪针对每个媒体、不同投放目标创建对应的活动。创建活动后，可使用活动中的监测链接归因广告数据，并且通过活动中的映射，灵活管理回传媒体的事件（激活、注册、次留、付费）。

## 二、操作步骤

### 创建一个活动
![image.png](http://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/1720061545559-image.png)
```tip
1. 支持可对不同的媒体、以及投放目标（APP or 小游戏）创建不同的活动。
2. 创建活动后，会根据媒体和投放目标，自动生成媒体归因监测链接。
```
### 复制监测链接到广告计划中
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/helpcenter/HDA2bHqIto5Pv9x6bYUcJDkonvd.gif)
可将监测链接手动复制到广告中也可在广告中选择推广活动的监测链接。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1754549006056.png)
```tip
1. 监测链接是归因的重要工具，请务必准确无误。
```
### 媒体回传映射
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/helpcenter/NOCzb5GqSobnvtxfdotcWvp0nlc.gif)
```tip
1. 在创建活动时，会默认创建 4 条映射事件：激活、注册、次留、付费。默认创建的映射将实现 100% 真实回传。
2. 目前瑞雪仅支持 API 数据回传。
3. 其他媒体回传事件，例如广点通-创角事件，需要手动创建，如果未创建，则默认不回传该事件。
4. 关于如何调整回传映射规则，请详见映射管理
```
