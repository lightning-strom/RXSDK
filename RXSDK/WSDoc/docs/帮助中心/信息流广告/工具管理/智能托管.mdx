## 一、功能介绍
瑞雪对账户、计划、广告、创意进行实时智能监控。可配置组合条件，当满足条件时，系统将自动发送预警消息。
## 二、操作步骤
#### 1.账户授权 1.新建一条托管规则
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/helpcenter/BNgobULofow6fwx4mh4cTCr2nSd.gif)
::: tip
1. 支持多指标条件组合
2. 检查时间支持每天、每半小时、每小时以及自定义
3. 通知内容支持自定义
4. 通知方式支持企业微信和飞书。
:::
