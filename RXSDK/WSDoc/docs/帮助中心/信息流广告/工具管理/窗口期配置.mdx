## 一、功能说明

管理投放渠道包的归因、回流、回传窗口期时间。

## 二、快速开始

:::tip
sdk 回传必须配置窗口期参数，以及`数据源ID`,`secret_key`,`APPID`等信息。sdk会根据配置进行三方广告平台初始化。<br/>
有些媒体回传注册的时候会要求必须有激活才可以。所以配置时注意在**回传配置中开启漏斗模型**并且配置回传映射事件的时候媒体侧的激活需要对应瑞雪的通行证注册事件。<br/>
回流开关是设置渠道包的，  不是针对某一个应用，  设置一个应用的渠道包就代表设置所有同渠道包的应用了。
:::
1.切换应用与媒体，可调整其归因、回流、回传窗口期时间，选择之后，立即保存成功。
