## 一、功能介绍

映射管理，支持按用户发生事件灵活对应媒体回传事件、并可通过条件筛选来配置不同场景的回传策略。
## 二、操作步骤
### 什么是默认创建的映射？
支持快速生成默认映射
![image.png](http://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/1720061712235-image.png)

```tip
1. 在创建活动时，会默认创建 4 条映射事件：激活、注册、次留、付费。默认创建的映射将实现 100% 真实回传。
2. 其他媒体回传事件，例如广点通-创角事件，需要手动创建，如果未创建，则默认不回传该事件。
3. 目前瑞雪仅支持 API 数据回传。
```


### 如何手动创建一条映射？
![image.png](http://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/1720061768647-image.png)

```tip
1. 首先需要选择一个活动，在活动下创建映射。
2. 每个媒体回传事件，仅支持选择一次，所以如需改动，请编辑已有映射。
3. 当用户行为不满足任何一条映射时，将默认不回传给媒体，所以映射配置一定要全面，目前支持添加多组映射。
```

### 什么是快速生成映射？

![image.png](http://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/1720061712235-image.png)

```tip
1. 选择活动，在活动下，重新生成 4 条映射事件：激活、注册、次留、付费。默认创建的映射将实现 100% 真实回传。原活动下的激活/注册/次留/付费映射将被替换。
2. 快速生成，只影响激活、注册、次留、付费，其他媒体事件不影响。
```

## 三、常见问题

1. 如何使用映射？
映射无需使用，只要将活动下对应的监测链接粘贴到对应的计划下，则此计划在归因的同时，将会按照此活动下的映射规则进行回传。
1. 我创建或修改映射规则后，是否需要用新的监测链接？
<strong>无需使用新的监测链接</strong>，在创建或修改映射规则后产生的新的买量用户行为，将根据新的映射规则进行回传。
