## 一、功能介绍
今日头条（巨量）媒体平台目前仅支持在同一个账户下单独创建项目及广告。瑞雪投放支持多选账户，定向包、素材、标题组的混合搭配下，快速创建多个项目及广告，极大的提高项目创建速度。
## 二、准备工作
<strong>使用 今日头条 - 投放管理 - 批量创建功能前，请确保以下内容已配置完毕：</strong>
1.确认已完成今日头条接入流程；
2.确认已授权完毕头条媒体账户，否则监测不到具体账户下的广告信息。
3.确认在瑞雪平台已配置完毕：监测链接。监测链接是实现数据归因的唯一依据。
4.今日头条媒体平台已在对应账户下配置完毕以下资产：小游戏/APP、定向包、落地页。
5.素材库已上传完毕相应素材。

## 三、操作步骤

### 1.在广告投放管理 > 今日头条 > 投放管理 点击【批量创建】按钮；
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/image-1722500115913.png)

### 2.多选媒体账户、选择推广目的、选择应用
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/image-1722500145794.png)
1.支持最多同时选择 10 个媒体账户；
2.当推广目的为安卓，自动读取媒体账户的应用信息，多账户取应用交集；
3.当推广目的为 iOS，需手动录入应用下载地址；
4.当推广目的为小程序，无需选择小程序；
::: tip
账户、推广目的、应用选择完毕后，可点击配置项目基本信息
:::
### 3.录入项目基本信息、广告基本信息、选择落地页、监测链接

1.录入项目基本信息
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/image-1722500191497.png)
2.录入广告基本信息
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/image-1722500216555.png)
3.录入落地页与监测链接
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/image-1722500264649.png)
::: tip
1.需先配置外项目信息后，方可配置广告基本信息、落地页监测链接信息；
2.广告位仅支持 6 种组合：仅抖音短视频；仅穿山甲；仅 ohayoo；头条 + 抖音短视频；头条 + 西瓜视频；头条 + 西瓜视频 + 抖音短视频 + 番茄 +ohayoo；
3.搜索关键词：仅穿山甲和小游戏场景，不支持关键词；
4.推广身份与原生锚点：仅包含抖音广告位时，支持推广身份与原生锚点；
5.出价、深度出价、深度 ROI：支持固定出价、随机出价、阶梯出价三种出价形式；
6.APP 仅支持自建落地页，不支持共享落地页；
7.由于广告归因要求，请务必填写监测链接；
:::
### 4.选择广告生成方式、多选定向包、创意组、标题组

1.选择广告生成方式
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/image-1722500313296.png)
2.多选定向包、创意组、标题组
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/image-1722500352995.png)
::: tip
1.广告生成支持：叉乘组合与按素材生成；
2.创意组，支持批量选择素材，自动生成创意组
3.标题支持直接选择标题组、自动生成、支持手动上传标题；
4.全部信息配置完毕后，方可点击下一步。
:::

### 5.录入项目和广告的名字
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/image-1722500390436.png)
1.支持输入通配符；
2.支持关闭项目或广告状态下提交；
3.支持保存默认设置；
::: tip
1.由于媒体平台要求，项目名称与广告名称不可重复，请踊跃填入序号与日期时间等通配符；
2.由于媒体要求项目和广告名称不可超过 50 个字，因此在预览时，会自动截断，保留前 50 字。
:::
### 6.预览预计生成的广告，并提交
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/image-1722501003349.png)
::: tip
支持预约提交与立即提交；
:::

### 7.点击跳转到批量任务列表页，查看提交是否成功

![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/image-1722501065043.png)
::: tip
1.如提交失败，可查看失败原因；
2.针对网络问题导致的提交失败，可手动重复提交；
3.预约提交的广告，可批量选择后立即提交
:::
