# 隐私保护政策
&nbsp;&nbsp;&nbsp;&nbsp;瑞雪SDK是由吉林省海奇网络科技有限公司（以下简称“我们”）面向应用开发者（以下简称“开发者”）提供的快速、安全、便捷地实现游戏快速上架发行服务。开发者在其应用中集成了瑞雪SDK后，我们将通过被集成的瑞雪SDK向开发者的最终用户（以下简称“您”或“用户”）提供相关服务，处理开发者应用相关的数据，相关数据中可能包含您的个人信息。我们非常重视您的个人信息和隐私保护，我们将会按照法律要求为您的个人信息提供相应的安全保护措施。我们将通过本政策向您说明我们如何收集、使用、披露、保护、存储及传输您的个人信息。
&nbsp;&nbsp;&nbsp;&nbsp;**若您是开发者，请注意**：我们要求集成瑞雪SDK的所有开发者严格遵循法律法规和本政策的要求处理终端用户的个人信息；在接入、使用各开放能力前，我们要求开发者在其产品应用的隐私政策中向终端用户告知其集成SDK处理个人信息的基本情况，并获取终端用户的同意或取得其他合法性基础。
&nbsp;&nbsp;&nbsp;&nbsp;**若您是终端用户，请注意**：我们建议您认真阅读开发者应用相关隐私政策及本隐私保护政策，在确认充分了解并同意上述隐私政策后再使用开发者应用。您同意上述隐私政策或开始使用开发者应用，即代表您已知悉并同意上述隐私政策内容。

### 1.我们如何收集和使用您的个人信息
&nbsp;&nbsp;&nbsp;&nbsp;我们仅会根据本政策以下所述目的和方式收集和使用您的个人信息，如果我们要将收集的您的个人信息用于本政策未载明的其他目的，我们会以合理的方式自行或通过开发者明确向您告知，并再次获取您的同意或取得其他合法性基础。
**1.1 瑞雪SDK基础功能**
&nbsp;&nbsp;&nbsp;&nbsp;为实现瑞雪SDK产品的基本业务功能所必须，瑞雪SDK将向终端用户或开发者收集终端用户在使用与SDK产品相关的功能时产生的相关个人信息，具体收集的信息类型及使用目的如下：
**（1）功能类型**：实名认证
**涉及用户信息类型：实名认证信息（姓名、身份证号码）；**
**收集/共享方式**：用户主动输入；
**使用目的和场景**：按照相关法律法规，用于用户注册/登录游戏时完成实名认证及防沉迷需要。
**（2）功能类型**：登录
**涉及用户信息类型：手机号、邮箱；**
**收集/共享方式**：用户主动输入；
**使用目的和场景**：用于用户登录/注册游戏或对游戏账号进行绑定。
**（3）功能类型**：性能优化
**涉及用户信息类型：设备信息（占用的运行内存、CPU核数量、GPU名称、GPU型号、总运行内存大小、总存储内存大小）、运行时的信息（GPU温度、CPU使用率、设备是否Root、剩余电量）；**
**收集/共享方式**：用户授权后调用系统相关接口采集；
**使用目的和场景**：用于性能分析、进行产品优化，更好地为用户提供产品和服务。
**（4）功能类型**：安全风控
**涉及用户信息类型：设备信息（硬件制造商、主板名称、传感器数量、闪光灯信息、蓝牙信息、光线传感器信息、进程组信息、基带信息、CPU信息、操作系统架构、拨打电话检测、硬件名称、设备型号）；**
**收集/共享方式**：用户授权后调用系统相关接口采集；
**使用目的和场景**：内容及系统安全检查，反外挂和黑灰产，更好地维护系统健康生态。
**（5）功能类型**：广告监测 iOS
**涉及用户信息类型：设备启动时间、国家、语言、设备名称、系统版本、设备型号（Machine）、运营商、物理内存容量、硬盘内存容量、系统更新时间、设备 Model、设备时区、设备挂载 id（mnt_id） 、设备初始化时间；**
**收集/共享方式**：用户授权后调用系统相关接口采集；
**使用目的和场景**：用于生成 CAID 识别广告投放来源，监测广告效果，更好地为用户提供产品和服务。
**（6）功能类型**：广告监测 Android
**涉及用户信息类型：设备唯一标识信息（IMEI）、序列号（SN 码）、Android ID、MAC地址、主板、系统 boot 版本号、系统定制商、abi、显示屏参数、硬件制造商、硬件名称、主机名、系统用户名、系统编译类型、OAID、剪贴板信息；**
**收集/共享方式**：用户授权后调用系统相关接口采集；
**使用目的和场景**：用于生成设备唯一标识，识别广告投放来源，监测广告效果，更好地为用户提供产品和服务。
**（7）功能类型**：数据分析
**涉及用户信息类型：IP、浏览器UA、网络状态、设备型号、系统版本；**
**收集/共享方式**：用户授权后调用系统相关接口采集；
**使用目的和场景**：用于数据分析，更好地为用户提供产品和服务。
**（8）功能类型**：图片分享
**涉及用户信息类型：读写外部存储器；**
**收集/共享方式**：调用系统相关接口采集；
**使用目的和场景**：用于用户自主分享非相册内的本地图片。
**（9）功能类型**：联系客服
**涉及用户信息类型：相机权限、相册权限、麦克风权限；**
**收集/共享方式**：用户单独授权；
**使用目的和场景**：用于用户自主与客服人员沟通时发送图片、视频描述其遇到的问题。
**（10）功能类型**：定位
**涉及用户信息类型：定位权限（地理位置信息）；**
**收集/共享方式**：用户单独授权；
**使用目的和场景**：用于实现附近的人功能。
**（11）功能类型**：通知
**涉及用户信息类型：推送通知；**
**收集/共享方式**：用户单独授权；
**使用目的和场景**：用于向用户设备推送信息。
**1.2 瑞雪SDK其他功能**
**（12）功能类型**：游戏联运
**涉及用户信息类型：用户唯一标识（User id、Open id）、用户头像、用户昵称、邮箱、Union id（同一个用户在同一个企业开发者账号内不同游戏的通用标识符）、三方授权凭证(Token、ServerAuth Code、Auth Token、Session、access Token)、用户凭证、Ad id(广告标识）、Channel（游戏的限制条件，通道标识）、手机号码；**
**收集/共享方式**：调用系统相关接口采集；
**使用目的和场景**：用于为不同渠道的用户提供账号注册登录的联运服务。
**1.3 设备权限调用**
&nbsp;&nbsp;&nbsp;&nbsp;当您使用相应功能及服务时，我们会通过开发者应用向系统申请您设备的相应权限，**如相机权限、定位权限、相册权限、麦克风权限、通讯录权限**。您可以在设备的设置功能或“隐私设置”中查看权限状态，并可自行选择开启或关闭部分或全部权限。
&nbsp;&nbsp;&nbsp;&nbsp;在初始化和登录/注册时，我们会读取您的剪贴板内容以判断是否有符合条件的相关口令码（包括邀请人、用户来源）信息，仅当剪贴板有前述口令码信息时，我们才会收集该口令码以向您提供您所需的内容，我们不会存储您的剪贴板其他信息，其中口令码属于个人敏感信息，请您谨慎提供。如您拒绝提供仅会使您无法使用该功能，但不会影响您使用基本业务功能。
&nbsp;&nbsp;&nbsp;&nbsp;开发者在集成、使用相应开放能力时，将自行决定权限的调用范围，因此开发者应对权限的调用及用途向您进行说明。**您根据开发者应用的请求开启任一权限即代表授权我们可以处理相关个人信息来为您提供对应服务；一旦您关闭任一权限即代表您取消了授权，我们将不再基于对应权限继续处理相关个人信息，可能无法继续为您提供该权限所对应的服务**。请注意，您关闭权限的决定不会影响此前基于您授权所进行的个人信息处理活动的效力。
**1.4 根据法律法规的规定，以下是共享、转让、公开披露个人信息时事先征得用户同意的例外情形:**
（1）为订立、履行与终端用户的合同所必需;
（2）为履行我们的法定义务所必需;
（3）为应对突发公共卫生事件, 或者紧急情况下为保护终端用户的生命健康和财产安全所必须；
（4）为公共利益实施新闻报道、舆论监督等行为, 在合理的范围内处理终端用户的个人信息;
（5）依照本法规定在合理的范围内处理终端用户自行公开或者其他已经合法公开的个人信息;
（6）法律行政法规规定的其他情形。
特别提示:如我们收集的信息无法单独或结合其他信息识别到终端用户的个人身份,其不属于法律意义上的个人信息。
1.5为保障瑞雪SDK产品相关功能的实现及安全稳定运行，部分服务可能会接入第三方开发的软件工具开发包（SDK）或其他类似的应用程序的方式。我们会对瑞雪SDK产品接入的涉及个人信息收集的SDK进行安全监测，以保护您的个人信息安全。请您根据需要查看以下目录中列明的瑞雪SDK产品接入的第三方SDK情况，详见附件《**第三方SDK清单**》。您还可以通过第三方SDK服务商官方网站链接查看第三方SDK服务商收集使用个人信息的规则。第三方SDK服务商可能由于版本或功能升级等原因改变其个人信息收集处理规则，请以其公示的官方说明为准。如您发现第三方SDK服务商提供的服务存在风险时，建议您立即终止相关操作并及时与我们取得联系。
### 2.对未成年人的保护
我们非常重视对未成年人个人信息的保护，我们将严格按照国家法律法规要求对未成年人提供服务并对未成年人提供保护。**如果您是未成年人，需要您的父母或其他监护人同意您使用开发者应用并同意相关应用的服务条款。父母或其他监护人也应采取适当的预防措施来保护未成年人，包括监督其对开发者应用的使用**。
### 3.管理您的个人信息
3.1 我们非常尊重您对个人信息的关注，我们将遵照相关法律法规的要求，协调、支持并保障您行使访问、复制、更正、删除等个人信息主体权利。
&nbsp;&nbsp;&nbsp;&nbsp;由于您是通过开发者应用使用瑞雪SDK和服务，如果您希望访问、复制或更正与瑞雪SDK和服务相关的个人信息，您应通过开发者应用提供的路径实现您的个人信息主体权利。为保障您访问、复制、更正和删除个人信息的权利实现，我们要求开发者在开发者的《用户服务协议》和《隐私保护政策》中，明确要求开发者承诺根据法律法规要求向您提供便捷的权利实现方式。同时，您也可以与我们取得联系，我们将尽力协调、支持并保障您的上述权利实现。
&nbsp;&nbsp;&nbsp;&nbsp;当您直接向我们提出个人信息主体权利时，为了保障您的数据安全和其他合法权益，我们可能会对您的身份进行验证并要求您提供验证身份所必要的个人信息，同时我们也可能会向开发者提供收集的身份验证信息以核实您的身份。在验证确认您的身份后，我们会根据法律法规要求及时响应您的相关请求。
&nbsp;&nbsp;&nbsp;&nbsp;**请您理解，特定的业务功能和服务将需要您的信息才能得以完成，当您撤回同意或授权后，我们无法继续为您提供对应的功能和服务，也不再处理您相应的个人信息。但您撤回同意或授权的决定，不会影响我们此前基于您的授权而开展的个人信息处理。**
**3.2按照法律法规要求，很抱歉以下情形中我们将无法响应您的请求：**
（1）与本公司履行法律法规规定的义务相关的；
（2）与国家安全、国防安全直接相关的；
（3）与公共安全、公共卫生、重大公共利益直接相关的；
（4）与刑事侦查、起诉、审判和判决执行等直接相关的；
（5）有充分证据表明您存在主观恶意或滥用权利的；
（6）出于维护您或其他个人的生命、财产等重大合法权益但又很难得到您本人同意的；
（7）响应您的请求将导致您或其他个人、组织的合法权益受到严重损害的；
（8）涉及商业秘密的。
### 4.信息存储地点及期限
&nbsp;&nbsp;&nbsp;&nbsp;我们所收集的用户信息将会传输并保存至中华人民共和国境内的服务器。我们仅在实现本政策所述目的所必需的时间内保留您的个人信息，并在超出下述保留时间后删除或匿名化处理您的个人信息，除非法律法规另有要求。此外，当我们的产品或服务发生停止运营的情形时，我们将以推送通知、公告等形式通知开发者，并在合理的期限内删除您的个人信息或进行匿名化处理。
### 5.信息安全
&nbsp;&nbsp;&nbsp;&nbsp;我们为终端用户的个人信息提供相应的安全保障，以防止信息的丢失、不当使用、未经授权访问或披露。
&nbsp;&nbsp;&nbsp;&nbsp;我们严格遵守法律法规保护终端用户的个人信息。
&nbsp;&nbsp;&nbsp;&nbsp;我们将在合理的安全水平内使用各种安全保护措施以保障信息的安全。
&nbsp;&nbsp;&nbsp;&nbsp;例如，我们使用加密技术、匿名化处理等手段来保护终端用户的个人信息。
&nbsp;&nbsp;&nbsp;&nbsp;我们建立专门的管理制度、流程和组织确保信息安全。
&nbsp;&nbsp;&nbsp;&nbsp;例如，我们严格限制访问信息的人员范围，要求他们遵守保密义务，并进行审查。
&nbsp;&nbsp;&nbsp;&nbsp;若发生个人信息泄露等安全事件，我们会启动应急预案，阻止安全事件扩大，并以推送通知、公告等形式告知开发者。
### 6.变更
&nbsp;&nbsp;&nbsp;&nbsp;我们可能适时修订本规则的内容。
&nbsp;&nbsp;&nbsp;&nbsp;如该等变更会导致终端用户在本规则项下权利的实质减损，我们将在变更生效前，通过网站公告等方式进行提示。如您是开发者，当更新后的本规则对处理终端用户的个人信息情况有重大变化的，您应当适时更新隐私政策，并以弹框形式通知终端用户并且获得其同意，如果终端用户不同意接受本规则, 请停止集成SDK产品。
