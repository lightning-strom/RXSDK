## 功能介绍
针对棋牌服务端发版，基于瑞雪管理后台配置。
## 准备工作
#### 1.配置管理地址
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1746491602735.png)
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1746491523970.png)
#### 2.关联棋牌研发后台账号登录
首次进入该页面需要将棋牌研发后台账号与瑞雪账号进行绑定。
:::tip
此账号密码为研发后台的账号以及密码，如密码错误请到研发后台去重置，如没有账号也到研发后台去开账号。绑定后无法修改，操作时请绑定自己的账号。
:::
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1746491505096.png)

## 游戏
1. 查看/编辑/删除 历史版本记录以及状态。通过`查看记录`可以查看版本流转。
 ![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1747118992361.png)
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1747118981388.png)
2. 热更新类型新建版本。可以`仅执行命令`或`执行命令并上传`。选择的命令是在`命令管理`中选择类型为`游戏`的命令。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1747118759811.png)
3. 重启类型新建版本。可以设置锁定时间。并选择是否有包。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1747119028323.png)
4. 导流维护类型新建版本。可以设置锁定时间。并选择是否有包。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1747119068550.png)
## 核心
1. 查看/编辑/删除 历史版本记录以及状态。通过`查看记录`可以查看版本流转。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1747120828882.png)
2. 仅执行命令类型新建版本。选择的命令是在`命令管理`中选择类型为`核心`的命令，可配置等待时间。`部署方式`分为`灰度`、`全量含灰度`、`全量`三种。其中`灰度`需要选择服务清单，`全量含灰度`选择服务后设置`灰度时间`。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1747120960870.png)
3. 发布版本类型新建版本。选择的命令是在`命令管理`中选择类型为`核心`的命令，可配置等待时间。`部署方式`分为`灰度`、`全量含灰度`、`全量`三种。其中`灰度`需要选择服务清单，`全量含灰度`选择服务后设置`灰度时间`。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1747121279936.png)
4. 回退版本类型新建版本。选择服务的节点。并选择对应的`部署方式`。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1747121378124.png)

## web服务
1. 查看/编辑/删除 历史版本记录以及状态。通过`查看记录`可以查看版本流转。`已发布`的状态不能修改。web服务选择的是`集群管理`和`服务管理`的相关配置。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1747121590054.png)
2. 发布类型新建版本。选择`版本`和`范围`
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1747121663181.png)
3. 回退类型新建版本。选择`范围`和`版本`
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1747121715674.png)
4. 重启服务类型新建版本。选择服务范围。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1747121726153.png)
