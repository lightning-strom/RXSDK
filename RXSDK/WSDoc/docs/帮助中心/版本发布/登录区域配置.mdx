## 登录配置
菜单：**版本发布>登录配置**。可编辑修改已有的登录配置。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1745571976162.png)
新建登录配置：可根据自己实际需求配置识别匹配优先级。其中添加登录项选择的是区域配置中的配置。也可针对特定IP进行配置。支持3种配置类型。
#### 单服默认
此种模式适用于无区服的产品，选择后添加一个正式配置一个测试配置即可。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1748931499407.png)
#### 多服匹配
此种模式适用于有多个区服，由服务器根据用户情况去匹配下发哪个区服配置。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1748931517065.png)
#### 多服手选
此种模式会下发多个区服标记给客户端，然后客户端根据情况展示给用户，由用户手动选择区服
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1748931536154.png)

## 区服配置
菜单：**版本发布>区服配置**。可编辑修改已有的区域配置。系统默认有一个默认地区default
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1748931033242.png)
新建区服：根据实际地区和业务所需标识创建地区/IP。
:::tip
如填写 IP 后，此配置则仅对指定 IP 生效，一般用于测试服.
:::
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1748930983458.png)
回调配置：区域配置的回调优先执行。如果各个区域回调不同可选择不同的回调事件进行配置。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1745572380357.png)

:::
