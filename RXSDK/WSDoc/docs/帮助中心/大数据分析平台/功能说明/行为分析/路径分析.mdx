## 路径分析

```tip
1. 路径分析是分析行为顺序、行为偏好、关键节点、转化效率的探索型模型。
2. 路径分析可以通过桑基图直观查看关键节点前后的行为流入流出，比如用户每天登录后最先参与的是哪种活动，或者用户付费前最后的行为是否存在共性。
```
## 路径分析的意义
路径分析是一种分析行为顺序、行为偏好、关键节点、转化效率的探索型模型
路径分析将用户每次会话时的访问顺序进行记录，再整合得到用户行为路径的桑基图，直观查看在每一关键节点前后的行为流入、流出情况。
可以直观掌握用户行为扩展路线，以供优化节点内容、提升整体转化效率。利用路径分析模型，可以快速了解影响转化的主次因素，从而有目的的改进产品。
## 路径的概念
路径：以分析对象为基准，向前后或向后（由分析初始或结束决定）展开的路径。路径将确保相互独立与完全穷尽。
1. 下一步路径应当是上一步的子集，且数量相同。此时会出现流失、起始概念，即没有下一步或第一步的概念。
2. 分析对象为起始事件 A 时，当路径中反复出现 A 时，只以第一个 A 作为起始点，一个会话不会反复计算成多条路径。
3. 分析对象为结束事件 A 时，当路径中反复出现 A 时，只以最后一个 A 作为结束点，一个会话不会反复计算成多条路径。
4. 按照会话中的顺序依次判断为第一步、第二步、第三步等或倒数第一步、倒数第二步、倒数第三步等等。
## 路径分析的计算逻辑
1. 一个会话中，将**起始点（结束点）**开始的事件记为第一步（即分析对象），向后（向前）的每一个事件记为下一步，类推行为路径上的每一个节点。
2. 以分析某事件 A 为初始事件为例，行为序列为 A，B，C，流失（会话内无新事件），则 A 为第一步，B 为第二步，C 为第三步，流失为第四步。
3. 以分析某事件 L 为结束事件为例，行为序列为起始（会话前无新事件），B，C，L，则 L 为第一步，C 为第二步，B 为第三步，起始为第四步。
4. 起始点（结束点）规则参考名词定义。且流失或起始只会是分析序列中的最后一步.
关于步骤的实例
| **序号** | **分析对象** | **行为序列** | **第一步** | **第二步** | **第三步** | **第四步** | **第五步** |
| -------- | ------------ | ------------ | ---------- | ---------- | ---------- | ---------- | ---------- |
| 1        | 起始事件 A   | A-B-C-D      | A          | B          | C          | D          | 流失       |
| 2        | 起始事件 A   | A-B-A        | A          | B          | A          | 流失       |            |
| 3        | 起始事件 A   | A-A-C-D      | A          | A          | C          | D          | 流失       |
| 4        | 起始事件 A   | A-C-D        | A          | C          | D          | 流失       |            |
| 5        | 结束事件 L   | B-L-D-L      | L          | D          | L          | B          | 起始       |
| 6        | 结束事件 L   | A-L          | L          | A          | 起始       |            |            |
| 7        | 结束事件 L   | L-C-D-L      | L          | D          | C          | L          | 起始       |
| 8        | 结束事件 L   | C-D-L        | L          | D          | C          | 起始       |            |

## 路径分析使用方法
1. 进入瑞雪平台首页，点击左侧菜单：**大数据分析平台**。
2. 点击页面上方「行为分析」，选择「路径分析」后点击进入。
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/CdggbJqP2oUmwJxqzMZct1f2nCd.png)
### 参与分析的事件
1. 参与路径分析的事件范围，默认 1 项，最多可选 10 项。
2. 未选事件为无效事件，不参与路径分析的计算和展示。
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/Jq5yb8qxOoh7w4xIUPIczeQ6n7d.png)
### 分析路径以【某事件】为结束/开始事件
1. 选择分析事件组中的 1 项作为分析基础，可以指定它为初始或结束事件进行分析。
2. 默认选中第一项为起始事件。
3. 支持添加限制条件
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/QLHwbXmq5o3mJ8xSQDScrOlhnFb.png)
### 且用户符合
1. 点击【添加条件】可对当前参与分析事件增加限制条件。
2. 添加多个条件时，条件之间可设置且和或的逻辑关系。最多支持 2 层逻辑嵌套
3. 筛选项目与筛选逻辑间关系
| **数据类型** | **举例**               | **可支持的筛选逻辑关键字**                                               |
| ------------ | ---------------------- | ------------------------------------------------------------------------ |
| 数值         | 消费金额               | 等于、不等于、小于、小于等于、大于、大于等于、有值、无值、区间           |
| 文本         | 省份                   | 等于、不等于、包含、不包含、有值、无值                                   |
| 列表         | ID 名单                | 存在元素、不存在元素、元素位置、有值、无值                               |
| 时间         | 注册时间、最后活跃日期 | 位于区间、小于等于、大于等于、相对当前日期、相对事件发生时刻、有值、无值 |
| 布尔         | Wifi 使用              | 为真、为假、有值、无值                                                   |
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/S4eUb0dHCoVBA7x3CWxcLMT5nzd.png)
### 会话时间间隔
1. 会话间隔的含义为： 选取时，相邻事件的最大间隔时间。两连续的有效事件（属于分析事件组）间的触发间隔在设置时间内时，视为两者属于同一会话。
2. 修改这个值可以调整相邻事件是否在同一个会话中。
3. 默认设置为“ 30  分钟”。
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/Q3UEbLHO6ofp08xYNWccBMOJnSh.png)
