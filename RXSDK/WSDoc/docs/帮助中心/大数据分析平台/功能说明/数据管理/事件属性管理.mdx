# 事件属性管理
> 本章节为您介绍在该页面对事件属性进行相关操作。
> 包括事件属性信息修改、状态修改。以下将分别为您介绍相应的设置步骤和需要注意信息点。
> 请注意重点关注文档中加粗、标注部分的描述。
## 修改事件属性信息
1. 进入瑞雪平台首页，点击左侧菜单：**大数据分析平台**。
2. 在页面右上方，点击**数据管理 > 元数据管理 > 事件属性**。
3. 点击列表页右侧的编辑按钮。输入信息后，点击【保存】。
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/RJvNbwS7Mou2Yqx1RDWccuiQnXb.png)
```tip
1. 只有自定义属性可修改。
2. 只能修改显示名和属性说明。
3. 点击自定义属性名，可弹窗展示绑定该属性的事件。
4. 显示状态可点击关闭。关闭后，在新建看板时，将无法选择该事件属性。
5. 如果该事件属性已经被看板使用，则不能操作状态关闭。
```
## 添加维度表
1. 进入瑞雪平台首页，点击左侧菜单：**大数据分析平台**。
2. 在页面右上方，点击**数据管理 > 元数据管理 > 元事件**。
3. 点击列表页右侧的维度表按钮，选择新建或替换。
4. 在弹窗中设置维度表属性后，上传文件。点击下一步，解析成功后，维度表属性设置完成。
