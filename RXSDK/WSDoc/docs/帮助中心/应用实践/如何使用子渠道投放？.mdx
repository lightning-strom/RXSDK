## 一、功能介绍

一般在游戏推广阶段，为了降低投资风险控制成本。往往会与第三方组织合作，代理投放利润分账。这种业务场景，需要瑞雪统计不同代投合作公司的投放数据。

## 三、操作流程

### 步骤一：创建子渠道参数

| 菜单<br/>     | 企业管理后台 / 商务管理 /  子渠道管理<br/>                                                                                                                                                                                                                                                                                                                  |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 操作示意<br/> | ![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/helpcenter/Kbiobw4hkoR3ZOxHj5scmliInSf.png)<br/>操作步骤：<br/>1. 使用场景：选择【投放】；<br/>2. 渠道分组：可自定义分组名称，主要用于数据统计；<br/>3. 子渠道标识：输入英文数字组合，子渠道参数（唯一不可重复）；<br/>4. 结算规则：裂变前（广告投放获取原始用户）裂变后（广告投放获取原始用户加分享获得用户）；<br/> |

### 步骤二：推广活动中添加参数

::: info 如何操作？
菜单位置：游戏发行平台 / 广告投放工具 / 工具 / 推广活动
1. 新建推广活动；
2. 选择应用后，选择子渠道；
:::
| 菜单<br/>     | 游戏发行平台 / 广告投放工具 / 工具 / 推广活动<br/>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 操作示意<br/> | ![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/helpcenter/AQwXbDkIYocBF5xRcOtchkW0nxg.png)<br/>操作步骤：<br/>1. 子渠道选择非默认的值（选刚创建的子渠道参数）；<br/>2. 复制监测链接<br/> |

| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 操作示意<br/> | ![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/helpcenter/EFQcbepFdoK9ejxTiVocuvaRnEe.png)<br/>以今日头条批量创建为例，具体操作步骤如下：<br/>1. 选择投放账户、推广目的；<br/>2. 输入项目基本信息；<br/>3. 输入广告基本信息；<br/>4. 监测链接输入刚才创建的监测链接；<br/> |
