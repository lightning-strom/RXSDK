## 一.功能介绍

分享功能，主要是借助社交产品的流量，让用户主动把应用程序中的内容分享到社交平台，从而达到拉新、促活、提高留存的目的。瑞雪系统整合了微信、QQ、Facebook 等主流的社交工具，帮助运营制定营销活动策略和管理分享内容，大大降低了运营成本。

<strong>1.支持国内外多社交 APP</strong>

| <strong>国内</strong><br/>                                     | <strong>海外</strong><br/>                                                                                                            |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| - 微信：APP&小游戏<br/>- QQ：小游戏<br/>- 抖音：小游戏<br/>- 系统分享：APP<br/> | <br/>- Facebook：APP<br/>- Messenger：APP<br/>- TikTok：APP<br/>- Line：APP<br/>- Zalo：APP<br/>- Snapchat：APP<br/>- Reddit：APP<br/>- 系统分享：APP<br/> |

<strong>2.支持多分享策略，全面提高裂变能力</strong>

- <strong>诱导分享类：</strong>根据绑定产品、选择地区，满足规则条件后，即向 APP、小游戏传输分享内容；
- <strong>成就分享类：</strong>自定义触发分享埋点，同埋点支持维护多分享内容，并支持不同分享内容配置展示权重；
- <strong>特殊</strong><strong>埋点</strong><strong>分享类：</strong>自定义触发分享埋点，同埋点支持维护多分享内容，并支持不同分享内容配置展示权重，并可灵活设置触发分享用户的所在地区，实现精准性分享，提高分享物料的有效性。

## 四.常见问题

1. 诱导分享类策略，触发用户分享规则？

   1. 诱导分享，需要填写产品及地区。
   2. 具体策略规则：产品 + 渠道 + 地区（省/市）全匹配 > 产品 + 渠道 + 地区（省）> 产品 + 渠道 + 地区（全部） > 产品 + 渠道(全部）+ 地区（省/市）>  产品 + 渠道(全部）+ 地区（省) >  产品 + 渠道(全部）+ 地区（全部）
   3. 当满足条件后，瑞雪将自动向项目 APP 发送分享内容，APP 如何展示，由项目组处理。
2. 一个埋点，仅支持选择一次，那么如果需要在同一个埋点下，增加其他分享内容，如何处理？

   1. 目前支持编辑策略，找到原策略，点击编辑，即可增加分享内容，并编辑分享内容权重。
