## 一、功能介绍

对于新项目急需流量快速获取用户，项目合作是一个通用的做法。可以在来源应用内添加导量入口或活动，引流至目标应用。然后在目标应用的瑞雪数仓中统计合作应用的导量来源数据。

## 三、操作流程

### 步骤一：创建子渠道参数

| 菜单<br/>     | 企业管理后台 / 商务管理 /  子渠道管理<br/>                                                                                                                                                                                                                                                                                                                  |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 操作示意<br/> | ![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/helpcenter/Q9NZbpUQYoxdUgxm9PycdcOsnRh.png)<br/>操作步骤：<br/>1. 使用场景：选择【导量】；<br/>2. 渠道分组：可自定义分组名称，主要用于数据统计；<br/>3. 子渠道标识：输入英文数字组合，子渠道参数（唯一不可重复）；<br/>4. 结算规则：裂变前（广告投放获取原始用户）裂变后（广告投放获取原始用户加分享获得用户）；<br/> |

### 步骤二：复制子渠道参数

::: info 如何操作？
复制子渠道参数，给到「来源应用」研发；
:::

导量参数示例：

```json
type=rx&user_source=guide&subchannelid=子渠道标识
```

#### 向应用程序导量

::: tip
来源应用的研发：
1. 在导量入口位置，将导量参数先写到内存中；
2. 唤起下载应用商店；
:::

#### 向微信小游戏导量

::: tip
来源应用的研发：
1. 在导量入口位置，将导量参数放到唤起微信小游戏的路径参数中；
:::
