## 一、功能介绍

未成年- 防沉迷配置主要是针对国内项目，海外项目根据需求自行添加配置。依据中国宣传部要求，国内游戏 APP 或小游戏需在中宣部认证，并在游戏端对玩家用户实名认证，限制未成年用户仅可在节假日 20 至 21 点登录游戏。

## 二、操作步骤
### 国内配置
可配置适用年龄，以及图标、实名认证提示文案，防沉迷提示文案。渠道侧开启防沉迷后，会根据配置进行验证并下发文案等信息。

![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1763357476575.png)

```tip
1. 产品在配置完毕防沉迷配置后，方可使用实名认证功能。
2. 针对已实名认证的未成年用户，限制仅在节假日的 20-21 点可玩游戏。
3. 此功能仅针对国内游戏，海外游戏需要自行配置。
```

### 海外配置
:::tip
1. 目前越南、日本实名瑞雪已接入。这两个地区的配置页面只有法规要求的支付限制设置，没有登录限制设置与其他地区不同。<br/>
2. 默认地区是瑞雪自带的配置。除了适用年龄以及图标可修改外，其他文案不能调整。如果没有配置其他地区时，相关请求会匹配使用默认设置。<br/>
3. 使用其他地区的配置确保客户端已经调用过设置地区的接口。
:::
4. 添加地区。选择想要添加的地区进行相关配置。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1763357908681.png)
5. 删除已有的地区配置。请确保当前配置没有被引用，如果删除，当找不到配置时会使用默认配置。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1763357961141.png)
#### 日本付费限制配置
:::tip
付费限制需要指定选择对应的币种。此币种会影响累充规则，修改后请同步配置计费点人员按国家匹配方式配置对应相同币种的价格，如未配置则会按 0 累加。无法进行限制。
:::
