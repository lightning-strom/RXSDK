## 一、功能介绍

在游戏中，计费点是指游戏中的付费点，贯穿整个游戏整个生命周期，比如购买钻石、欢乐豆、首充等。

## 二、操作步骤
:::tip
瑞雪抖音小游戏sdk3.2.6以上支持小额支付。如果需要使用小额支付，在计费点配置中配置金额为10，20，30，40，50，60分时自动触发小额支付。
:::
1.点击左侧 <strong>产品 > 计费点信息管理</strong>，进入功能页面。可以对已经创建的计费点进行维护。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1768179672188.png)
支持批量导入计费点功能
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/image-1722497428275.png)
```tip
海外项目计费点需按照匹配国家或者匹配币种方式进行配置。

计费点配置币种匹配时需要在客户端下单时传currency对应的标识。
```
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1768179694868.png)

2.可根据产品、支付方式关联渠道侧的三方计费点标识。例如：苹果，华为等支付需要在对应后台创建指定商品的方式需要配置关联
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1768179733211.png)
```tip
如果使用三方计费点配置，确保配置的信息和对应商品后台的商品标识保持一致。
三方计费点仅展示需要配置的支付方式
```
