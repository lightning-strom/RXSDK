# 属性分析
```tip
属性分析是一种专门分析用户属性的统计与分布情况的模型。
通过该模型可以快速掌握特定用户群的用户画像，为精细化运营提供帮助，如对比不同渠道用户的累计付费金额人均值，或者按用户当前等级和 VIP 等级拆分查看用户数量。
```
## 属性分析的意义
1. 属性分析是一种专门分析用户属性的统计与分布情况的模型。
2. 模型按照用户属性进行归类，可以同时查看不同分组值用户的统计数与分布情况。如查看用户在各省的分布情况、用户的年龄分布情况等。可以快速描绘出整体用户群的用户画像。多角度、全方位的掌握指定用户群的特征，宏观上把握整体用户的组成与偏好，从而为精细化运营提供依据。
## 属性分析使用方法
1. 进入瑞雪平台首页，点击左侧菜单：**大数据分析平台**。
2. 点击页面上方「用户分析」，选择「属性分析」后点击进入。
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/L46IbchNeoWIegxyGmkc3X1Jnzb.png)
### 分析属性
1. 可以分析的内容为用户属性。
2. 根据数据类型不同，可分析角度有所不同。

| **分析对象** | **数据类型** | **分析角度**                                                                                                                                                                                     |
| ------------ | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 用户属性     | 数值         | 总和、均值、人均值、中位数、最大值、最小值、去重数、99 分位数、95 分位数、90 分位数、80 分位数、75 分位数、70 分位数、60 分位数、40 分位数、30 分位数、25 分位数、20 分位数、10 分位数、5 分位数 |
| 用户属性     | 布尔         | 为真数、为假数、去重数                                                                                                                                                                           |
| 用户属性     | 文本         | 去重数                                                                                                                                                                                           |
| 用户属性     | 时间         | 去重数                                                                                                                                                                                           |
| 用户属性     | 列表         | 列表去重数、元素去重数                                                                                                                                                                           |
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/NlSSbW4D7otGqKxSQbScuhyJnQf.png)
### 且用户符合
#### 添加条件
1. 点击【添加条件】可对当前参与分析事件增加限制条件。
2. 添加多个条件时，条件之间可设置且和或的逻辑关系。最多支持 2 层逻辑嵌套
3. 筛选项目与筛选逻辑间关系
| **数据类型** | **举例**  | **可支持的筛选逻辑关键字**                                               |
| ------------ | --------- | ------------------------------------------------------------------------ |
| 数值         | 消费金额  | 等于、不等于、小于、小于等于、大于、大于等于、有值、无值、区间           |
| 文本         | 省份      | 等于、不等于、包含、不包含、有值、无值                                   |
| 列表         | ID 名单   | 存在元素、不存在元素、元素位置、有值、无值                               |
| 时间         | 注册时间  | 位于区间、小于等于、大于等于、相对当前日期、相对事件发生时刻、有值、无值 |
| 布尔         | Wifi 使用 | 为真、为假、有值、无值                                                   |
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/NjVVb0O4lolGpBx1VDtcrqjrnGf.png)
### 分组项
#### 添加分组项
1. 点击【添加分组项】可设置多个分组。
2. 分组项可根据用户属性、事件属性进行不同粒度划分数据。。
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/EKQwb8v7oo9hOaxZErkcQRA9nyf.png)
