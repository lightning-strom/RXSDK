# SQL 查询
## SQL 分析的意义
对于难以使用分析模型实现的高级分析，您可以使用 SQL 查询来进行实现。
同时我们提供了动态参数的功能，帮助使用者在不用修改 SQL 语句的情况下，通过调整参数值，对语句中的部分参数内容进行变更，以适应新的查询条件，实现一次编写、多次使用。
SQL 查询结果可以被保存成报表，支持放入看板中进行数据查看。
## SQL 分析的使用方法
1. 进入雪平台首页，点击左侧菜单：**大数据分析平台**。
2. 点击页面上方「行为分析」，选择「 SQL 查询」后点击进入。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1735536901543.png)
### 1、语句编写框
- 在输入框编写 SQL 查询语句时，需要注意：字段名请使用反单引号 `` 括起。
- 输入框下方，您可以点击“添加动态参数”按钮，在语句末尾插入一个动态参数。后续可通过调整参数值的方法，对语句中的部分参数内容进行变更以适应新的查询条件。
- 工具栏右侧从左到右分别为：
  1. 复制：将输入框内的查询语句复制到剪切板。
  2. 格式化：将查询语句进行格式化。
  3. 计算：执行输入框内的查询语句。
### 2、表结构&字段列表
![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/TvSLbca2OoooRKxTDyDcMnkinZf.png)
1. 表结构标签页，主要呈现的是数据表的结构。
2. 选择某一个表后，右侧会展示表内的字段。
### 3、查询结果
- 在本页面，您可以下载结果数据；此外，保存成报表的 SQL 查询可以被放在看板中，进行数据展示。
- 点击“下载数据”，将下载此次查询结果的 `.csv` 格式文件。
- 点击“保存报表”，会将该条查询语句的结果保存为报表。
### 4、添加图表
- 点击【添加图表】后，针对本次查询出的结果数据，可进行二次加工编辑。包括编辑生成一维表、折线图、柱状图。
- 二次编辑后的图表，可保存为报表形式，后续可添加到看板中。
