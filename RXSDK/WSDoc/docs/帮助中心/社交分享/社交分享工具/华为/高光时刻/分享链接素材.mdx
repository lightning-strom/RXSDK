## 一、功能介绍
APP 链接，指的是分享到平台一个落地页链接。瑞雪支持分享一条超链接，并可对此超链接进行图片、标题、分享内容的包装，从而达到分享效果的最大化。
## 二、准备工作
使用分享链接素材配置 功能前，请确保以下内容已配置完毕：
1.华为后台配置落地页
2.华为高光时刻模板关联落地页
## 三、操作步骤
1.<strong>菜单位置：社交分享工具> 华为>高光时刻 > 分享链接素材</strong>
配置链接的信息。**华为模版id**必须和华为后台配置一致。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1737168625951.png)

```tip
重点说明：策略类型将在分享策略配置中的类型一一对应，千万不要选错。
```
## 四、华为后台新建落地页
“分享落地页”主要用于后续的视频分享展示，不仅可以帮助接收方查看精彩视频，还可以有效地引导其进一步跳转到合适的目标位置，例如游戏内部或应用市场下载页，从而提高游戏的用户活跃度或安装率。
1.登录AppGallery Connect，点击“我的项目”。
2.在项目列表中找到您的项目，并在项目下的应用列表中选择您的游戏应用。
3.在左侧导航栏中选择“构建 > 高光时刻”，进入高光时刻服务页面。
4.在“分享落地页”页签下，点击右上角“新增落地页”。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1737166384920.png)
5.设置落地页名称（最长64个字符），并点击“新建”前往“魔方创意”网站。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1737166398725.png)
6.根据使用需要，拖拽左侧相关组件至中间编辑区域，并配置按钮组件中“打开游戏”的跳转链接。关于魔方创意的使用指南请参见魔方创意。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1737166413312.png)
:::tip
deepLink：当在华为手机上点击分享落地页中“打开游戏”按钮时，会优先根据deepLink拉起游戏。如手机未安装此游戏，则会跳转到该游戏的华为应用市场下载详情页。<br/>
游戏官方下载URL：当在非华为手机上点击分享落地页中“打开游戏”按钮时，则会跳转到该游戏的官方下载页。
:::
7.编辑完成后点击右上角“保存”，然后返回高光时刻分享落地页的“自定义页面”，并点击“提交”。
:::tip
如未返回点击“提交”，则相关编辑内容无法生效，且离开落地页自定义页面后已编辑的内容将会丢失。
:::
8.分享落地页提交后，将会自动送检，您可根据风控审核结果对落地页进一步管理。如需修改或删除已配置的落地页，可在落地页列表中，点击对应“操作”列“编辑”或“删除”即可。
审核中：风控审核中暂不支持编辑，请耐心等待审核结果。
审核不通过：落地页内容中涉嫌广告、色情、欺诈等违规信息，请检查并修改落地页相关内容后重新提交。
审核异常：异常原因导致审核失败，建议点击“编辑”后重新提交，支持修改与删除落地页。
发布成功：落地页为“未使用”状态时，支持修改、删除落地页与关联模板。落地页已关联模板处于“生效中”状态时，则无法进行修改或删除操作。
发布异常：异常原因导致发布失败，建议点击“编辑”后重新提交，支持修改与删除落地页。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1737166429806.png)

:::tip
“已关联”状态的落地页无法删除。配置后的落地页可在模板中进行关联。
:::
