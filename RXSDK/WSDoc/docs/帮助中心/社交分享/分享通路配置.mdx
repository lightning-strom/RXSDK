### 一、功能介绍
分享通路，指的是我可以将我的 APP 或小游戏分享到哪些社交 APP 上。目前瑞雪国内版本分享通路支持微信、QQ、系统分享。
瑞雪分享，不仅支持接通功能，同时提供分享 UI 。
### 二、准备工作
使用 分享通路前，确定以下内容已配置完毕：
1.已接入瑞雪 SDK，并确认接通瑞雪分享功能或瑞雪分享 UI。
2.勾选想要接入的通路。
