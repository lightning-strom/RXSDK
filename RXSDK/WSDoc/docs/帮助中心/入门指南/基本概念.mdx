## 概念介绍

初次上手「瑞雪游戏发行平台」，如果对于工具内的一些词汇不熟悉，可以试试在本文中查阅对应的词汇。

## 基本概念

| 概念 | 说明 | 示例 |
| - | - | - |
| 集群 | 指服务器资源，瑞雪使用阿里云提供的服务； | 微乐家乡棋牌（项目集群） |
| 项目 | 合作或自研的游戏，使用企业管理后台独立部署瑞雪环境，为游戏提供专属服务； | 微乐家乡棋牌（游戏发行平台） |
| 产品 | 创建与维护一款即将发行的游戏； | 微乐掼蛋 |
| 渠道 | 一般指游戏即将发行或上架的渠道，例如：苹果、华为、oppo、vivo等； | 华为应用商店 |
| 子渠道 | 一般用于导量、投放、分包等场景，可以根据子渠道区分用户来源； | 头条推广（106） |
| 渠道包 | 游戏即将发行或推广的渠道安装包。例如：遇见喵克斯（华为包）； | 华为应用安装包 |
| 计费点 | 苹果、华为渠道支付时，要求维护商品信息； | 300钻石 |
| 兑换码 | 瑞雪生成的兑换码，可以在游戏内兑换相应的游戏道具； | 000224aotmr21omd |
| 广告调度 | 定义有效用户或无效用户，使其分享还是观看广告； | 分享->看广告->分享 |
