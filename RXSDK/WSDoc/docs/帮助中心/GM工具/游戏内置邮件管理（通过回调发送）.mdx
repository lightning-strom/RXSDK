## 一、功能介绍

用户可以定义发送邮件范围、邮件内容、发送的道具信息。发送范围可以是全服、指定渠道、指定用户；指定地区和自定义范围将陆续开发上线。

## 二、操作步骤
点击左侧 **邮件相关工具> 游戏内置邮件管理** 进入该功能页面。列表中会显示发送的状态和发送进度。
```tip
发送状态、发送进度均指瑞雪将玩家游戏 ID 推送到 CP 侧的状态和进度，实际邮件发送时间和邮件发送状态请已 CP 侧数据为准。
建议 CP 侧异步处理瑞雪推送的玩家游戏 ID，避免推送请求超时产生的问题！！！
```
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1768182237600.png)
### 指定用户发送邮件
1. 配置发送范围：发送范围选择指定用户，选择产品并填写用户的 CPUserID；
2. 配置邮件发送内容：输入邮件标题和邮件内容；
3. 配置包含道具：可配置邮件内的奖励道具（非必须）；
4. 配置发送时间：可配置立即发送 或者 定时发送。
5. 配置发送的默认语言：默认语言必选，内容必填。获取到用户指定语言时通过配置的指定语言发送，如果未配置该语言，则按照默认语言发送。为查询到用户语言信息时也会通过默认语言推送
  ![image.png](http://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/1720147510939-image.png)
### 指定渠道发送邮件
1. 配置发送范围：发送范围选择指定渠道，选择所属产品和所属渠道（所属产品和渠道根据用户注册时的值进行筛选）；
2. 配置邮件发送内容：输入邮件标题和邮件内容；
3. 配置包含道具：可配置邮件内的奖励道具（非必须）；
4. 配置发送时间：可配置立即发送 或者 定时发送。
5. 配置发送的默认语言：默认语言必选，内容必填。获取到用户指定语言时通过配置的指定语言发送，如果未配置该语言，则按照默认语言发送。为查询到用户语言信息时也会通过默认语言推送
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1768182254550.png)
### 发全服邮件
1. 配置发送范围：发送范围选择全服；（当选择全服时user_id会被设置为ALL-USERS）
2. 配置邮件发送内容：输入邮件标题和邮件内容；
3. 配置包含道具：可配置邮件内的奖励道具（非必须）；
4. 配置发送时间：可配置立即发送 或者 定时发送。
5. 配置发送的默认语言：默认语言必选，内容必填。全服推送一条信息按照默认语言推送。
 
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1768182265050.png)
### 再次推送玩家信息
瑞雪将记录推送失败的数据，点击 **失败数量** 后弹出推送情况统计。当前推送任务进度达到 100% 后，可对失败的数据再次推送。
