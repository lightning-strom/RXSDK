## 功能介绍
基于微信的通知渠道，我们为开发者提供了可以高效触达用户的订阅消息能力，以便实现服务的闭环并提供更佳的体验。
开发者在游戏内，可向用户发起消息订阅。开发者需后台自行记录用户是否订阅成功及订阅成功的次数。
用户在小游戏中订阅指定的消息内容后，开发者可以在后台通过下发消息的 api 把一条模版消息发送给用户，用户最终在微信的“服务通知”中收到。开发者可通过场景值（1014）区分从模版消息进入游戏的用户。
用户成功订阅一次，开发者可在游戏认为场景合适的时机，向该用户发下一条模版消息。

## 瑞雪后台配置订阅模板信息
### 菜单位置：推送管理>小游戏订阅管理
#### 1.创建订阅信息。可以从后台复制信息自动载入到瑞雪信息。
:::tip
透传选择是后，在用户订阅时会将此条消息透传给 CP,CP自己控制订阅消息。无法在瑞雪后台新建任务。需要cp自行配置产品中的订阅消息回调地址。
:::
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1737534405063.png)
#### 2.发布任务。透传选择否的可以进行发布任务。
支持使用大数据进行筛选。并进行发布周期的配置。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1737536011352.png)
#### 3.查看任务
查看任务列表以及任务状态。未开始的任务可以停止。
![image.png](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1737538789253.png)
