::: info 游戏渠道上架步骤

1. 运维：创建产品
2. 商务：创建渠道或确定发行的渠道（==是否需要修改渠道标识==）
3. 商务：创建渠道包
4. 研发：渠道包参数配置

## 使用分享策略管理的准备工作


1. 商务：分享通路设置
2. 运维：域名设置APP 域名小游戏域名
3. 商务：分享账号配置
4. 商务：埋点配置
