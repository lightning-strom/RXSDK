>info 主要职责
负责版本测试提 BUG；
## 如何测试版本提 BUG ？
1. 策划：创建版本（一般由策划发起，定义版本更新内容）
2. 研发：版本实现（一般由研发实现版本内容，更新版本）
3. 测试：版本测试（一般由测试对当前版本测试，保障正确性）
4. 运营：审核发版（一般由运营对当前版本审核确认，发布上线）
