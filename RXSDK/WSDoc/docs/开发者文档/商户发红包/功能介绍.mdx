# 商家转账（红包）

商家转账（红包）用于在活动奖励、达人推广等场景中向用户发起微信商家转账。

## 接入流程

1. 游戏客户端向游戏服务端请求转账。
2. 游戏服务端校验业务条件后，调用望舒服务端发起转账接口。
3. 望舒返回商户号、AppID 和调起收款所需信息。
4. 游戏客户端调用对应平台的收款接口，引导用户确认收款。
5. 望舒通过 CP 回调将收款单状态同步给游戏服务端。

## 接入入口

- App 端请参考 Android / iOS 收款接入文档。
- 小游戏请参考微信小游戏收款文档。
- 服务端请参考商家转账服务端接入文档。
