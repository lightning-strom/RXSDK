## 获取法务信息

**接口原型**

```csharp
/// summary>
/// 获取法务信息（条款+未成年保护）
/// summary>
/// param name="callback"> code 状态码0时成功 data 返回的数据 msg 错误消息 param>
void Legal(Actionint, object, string> callback)；
```

### 参数说明

无

**调用示例**

```csharp
RuiXueSdk.Legal(callback);
```

### 响应结构

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 |
| data | [Data](/docs/开发者文档/openinstall/原生接入) | 否 | key 跟请求的 keys 对应 |

#### 获取法务信息Data

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| terms | [Terms](/docs/开发者文档/openinstall/原生接入) | 是 | 文档类 |
| permissions | [Permissions](/docs/开发者文档/openinstall/原生接入) | 是 | 权限类 |
| minor | [Minor](/docs/开发者文档/openinstall/原生接入) | 是 | 未成年人保护 |

## 获取法务条款

**接口原型**

```csharp
/// summary>
/// 获取法务条款
/// summary>
/// param name="args">参照参数说明param>
/// param name="callback">param>
void LegalTerms(LegalArgs args, Actionint, object, string> callback)
```

**参数说明**

| 参数 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| product_id | string | 否 | 产品 id |
| channel_id | string | 否 | 渠道 ID |
| keys | string | 是 | 法务条款 key ，多个使用【,】分隔； 例如： 00001,00002 |
| position | string | 否 | 1 登录 2 用户中心 4 其他， 可 keys 二选一 |

**调用示例**

```csharp
string[] k = { "00001", "00002", "00003" };
var data = new LegalArgs().SetKeys(k);
RuiXueSdk.LegalTerms(data，callback);
```

### 响应结构

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 |
| data | Map[String][Data](/docs/开发者文档/openinstall/原生接入) | 否 | key 跟请求的 keys 对应 |

#### 获取法务条款Data

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| title | String | 是 | 标题 |
| content | String | 是 | 内容 |
