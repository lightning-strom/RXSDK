## 功能介绍

服务条款是需要展示给用户的相关协议，比如用户协议和隐私条款。

## 接入准备

请确认已经在 **企业管理后台 > 法务管理 > 法务合规配置 > 服务条款配置** 选择对应渠道包，完成条款配置。

## 预设条款

| key | 条款 | 备注 |
| --- | --- | --- |
| 00001 | 用户服务协议 | 不可删除，国内、海外必要条款。 |
| 00002 | 隐私保护指引 | 不可删除，国内、海外必要条款。 |
| 00003 | 第三方 SDK 目录 | 预设条款，可编辑可删除。 |
| 00004 | 健康游戏公告 | 预设条款，可编辑可删除。 |
| 00005 | 适龄提示 | 预设条款，可编辑可删除。 |
| 00006 | 绿色游戏公告 | 预设条款，可编辑可删除。 |
| 00007 | 版号信息 | 预设条款，可编辑可删除。 |
| 00008 | 游戏账号注销条件 | 不可删除，国内、海外必要条款。 |
| 00009 | 游戏账号注销协议 | 不可删除，国内、海外必要条款。 |
| 00010 | 其他 | 预设条款，可编辑可删除。 |
