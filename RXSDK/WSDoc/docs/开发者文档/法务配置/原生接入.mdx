<TabItem value="android" label="Android">

**接口原型**

```java
void legal(RXRequestCallback callback);
```

**调用示例**

```java
RXSDK.getInstance().legal(new RXRequestCallback() {
    @Override
    public void onResponse(JSONObject jsonObject) {
        int code = jsonObject.optInt("code", -1);
        if (code == 0) {
            JSONObject data = jsonObject.optJSONObject("data");
            if (data != null) {
                LegalData legalData = new Gson().fromJson(data.toString(), LegalData.class);
            }
        }
    }
});
```

</TabItem>

## 响应参数（JSON）

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 |
| data | [Data](/docs/开发者文档/openinstall/原生接入) | 否 | key 跟请求的 keys 对应 |

### 获取法务信息 Data

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| terms | [Terms](/docs/开发者文档/openinstall/原生接入) | 是 | 文档类 |
| permissions | [Permissions](/docs/开发者文档/openinstall/原生接入) | 是 | 权限类 |
| minor | [Minor](/docs/开发者文档/openinstall/原生接入) | 是 | 未成年人保护 |

#### Terms

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| id | Number | 是 | 文档 id |
| Key | String | 是 | 文档标识 |
| title | String | 是 | 稳定标题 |
| content | String | 是 | 内容 |
| is_default | Number | 是 | 是否默认 |

#### Permissions（作废）

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| title | String | 是 | 权限名称 |
| content | String | 是 | 权限类总说明 |
| list | [][List](/docs/开发者文档/openinstall/原生接入) | 是 | 内容列表 |

##### List

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| id | Number | 是 | 权限 id |
| key | String | 是 | 权限标识 |
| name | String | 是 | 展示的文字 |
| content | String | 是 | 详细说明 |
| enable | Number | 是 | 0 无需获取 1 需要获取 |

#### Minor

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| age | Number | 是 | 法务法规适用的年龄 |
| image | String | 是 | 对外展示的图片 |
| real_name | [][RealName](/docs/开发者文档/openinstall/原生接入) | 是 | 实名认证 |
| login | String | 是 | 未成年大于等于适龄年龄非节假日时间访问提示语 |
| login_lt | String | 是 | 未成年小于适龄年龄非节假日时间访问提示语 |
| age_8 | String | 是 | 幼儿（未满 8 岁及以下）充值限制提示语（作废） |
| age_8_16 | String | 是 | 儿童（ 8~16 岁）充值限制提示语（作废） |

| age_group1 | String | 是 | 幼儿（未满 8 岁及以下）充值限制提示语 |
| age_group2 | String | 是 | 儿童（ 8~16 岁）充值限制提示语 |
| age_group3 | String | 是 | 青少年(16~18 岁)充值限制提示语 |
