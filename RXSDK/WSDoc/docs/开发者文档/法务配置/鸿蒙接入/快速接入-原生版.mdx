## 获取法务信息

**接口原型**

```typescript
legal(callback?: RCallback): PromiseRXResult>
```

**调用示例**

```typescript

let result= await RXApi.getInstance().legal();

```

### 响应结构

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 |
| data | [Data](/docs/开发者文档/openinstall/原生接入) | 否 | key 跟请求的 keys 对应 |

## 获取法务条款

**接口原型**

```typescript
/**
 * 获取并展示法务条款内容，支持多种条款类型和展示位置
 * @param args - 请求参数
 * @param args.product_id - 产品ID（可选）
 * 默认为SDK配置中的产品ID
 * @param args.channel_id - 渠道ID（可选）
 * 默认为SDK配置中的渠道ID
 * @param args.keys - 法务条款key（必选，与position二选一）
 * 多个key使用【,】分隔
 * 例如："00001,00002" 对应 "服务条款,隐私政策"
 * @param args.position - 展示位置（可选，与keys二选一）
 * 1: 登录页面, 2: 用户中心, 4: 其他位置
 * @param callback - 可选的回调函数，用于接收操作结果
 * 支持传统回调模式与Promise模式并存
 * @returns 返回Promise，解析为统一的响应结果对象
 */
legalTerms(args: Recordstring, any>, callback?: RCallback): PromiseRXResult>
```

**参数说明**

| 参数 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| product_id | string | 否 | 产品 id |
| channel_id | string | 否 | 渠道 ID |
| keys | string | 是 | 法务条款 key ，多个使用【,】分隔； 例如： 00001,00002 |
| position | string | 否 | 1 登录 2 用户中心 4 其他， 可 keys 二选一 |

**调用示例**

```typescript
let result= await RXApi.getInstance().legalTerms({
 keys: "00001,00002"
 })
```

### 响应结构

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 |
| data | Map[String][Data](/docs/开发者文档/openinstall/原生接入) | 否 | key 跟请求的 keys 对应 |

#### 获取法务条款Data

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| title | String | 是 | 标题 |
| content | String | 是 | 内容 |
