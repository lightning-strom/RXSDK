### 接入方式

Package Manager 导入 RuiXue.Legal

## 获取法务配置

**接口原型**

```csharp
 public void Legal(RequestResponseDelegate onResponse,
 RequestErrorDelegate onError);
```

**调用示例**

```csharp
 private void OnLegal()
 {
 RXLegal.Legal(LegalResponseDelegate, LegalErrorDelegate);
 }

 private void LegalResponseDelegate(string data)
 {
 LogUtil.Log("EventManager", $"LegalResponseDelegate : {data}");
 }

 private void LegalErrorDelegate(string error)
 {
 LogUtil.Log("EventManager", $"LegalErrorDelegate : {error}");
 }
```

### 响应参数(JSON)

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 |
| data | [Data](/docs/开发者文档/openinstall/原生接入) | 否 | key 跟请求的 keys 对应 |

#### 获取法务信息Data

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| terms | [Terms](/docs/开发者文档/openinstall/原生接入) | 是 | 文档类 |
| permissions | [Permissions](/docs/开发者文档/openinstall/原生接入) | 是 | 权限类 |
| minor | [Minor](/docs/开发者文档/openinstall/原生接入) | 是 | 未成年人保护 |

##### 获取法务信息Terms

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| id | Number | 是 | 文档 id |
| Key | String | 是 | 文档标识 |
| title | String | 是 | 稳定标题 |
| content | String | 是 | 内容 |
| is_default | Number | 是 | 是否默认 |

##### 获取法务信息Permissions 作废

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| title | String | 是 | 权限名称 |
| content | String | 是 | 权限类总说明 |
| list | [][List](/docs/开发者文档/openinstall/原生接入) | 是 | 内容列表 |

| 参数 | 类型 | 是否必须 | 说明 |
