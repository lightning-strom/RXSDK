## 服务端 API

## 获取意见反馈类型

> **GET: ** `/v1/feedbackapi/kind/list`
>
> **认证方式：** 无

### CURL 示例

```bash
curl --location --request GET '{{接口域名}}/v1/feedbackapi/kind/list'
```

### 响应参数（JSON）

**HTTP 状态码：**`200 OK`

| 字段 | 类型 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 | 0 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 | data |
| [PageData](#pagedata) | 否 | 结果 |  |  |

#### PageData


| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| page | Number | 是 | 第几页 |
| size | Number | 是 | 每页大小 |
| total | Number | 是 | 总数量 |
| list | [][Kind](#kind) | 是 | 意见反馈数据 |


##### Kind


| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| id | Number | 是 | 唯一 ID |
| name | string | 是 | 意见反馈类型 |
| email_reply | Number | 是 | 是否邮件回复 |
| is_accident | Number | 是 | 是否产生事故 |
| kind_desc | Number | 是 | 描述 |


**响应示例**

```json
{
 "code": 0,
 "data" : {
 "page": 1,
 "size" : 10000,
 "total" : 1,
 "list" : [
 {
 "id" : 1,
 "name" : "类型名",
 "email_reply" : 1,
 "is_accident" : 0,
 "kind_desc" : "描述"
 }
 ]
 }
}
```

## 创建意见反馈

> **POST: ** `/v1/feedbackapi/player/create`
>
> **认证方式：** 无

### CURL 示例

```bash
curl --location --request POST '{{接口域名}}/v1/feedbackapi/player/create' \
--header 'Content-Type: application/json' \
--data-raw '{
 "product_id":"{{产品标识}}",
 "channel_id":"{{渠道标识}}",
 "game_id": 100,
 "kind_id": 1,
 "kind_name":"意见反馈类型",
 "priority" : 1,
 "content" : "说明",
 "picture" : "url1,url2,url3",
 "player_gameid": "玩家游戏id",
 "send_voided_mails":1
}'
```

### 请求参数（JSON）


| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| product_id | String | 是 | 产品标识 |
| channel_id | String | 是 | 渠道标识 |
| game_id | Number | 是 | 游戏 ID |
| kind_id | Number | 是 | 意见反馈 ID |
| kind_name | String | 是 | 意见反馈类型 |
| priority | Number | 是 | 紧急程度 1:紧急 2:不紧急 |
| content | String | 是 | 反馈内容 |
| picture | String | 是 | 多个图片 url ，用 逗号 隔开 |
| player_gameid | String | 是 | 玩家游戏 id |
| send_voided_mails | Number | 是 | 作废是否发邮件 1:发 2:不发 |


**请求示例**

```json
{
 "product_id":"{{产品标识}}",
 "channel_id":"{{渠道标识}}",
 "game_id": 123,
 "kind_id": 1,
 "kind_name":"意见反馈类型",
 "priority" : 1,
 "content" : "说明",
 "picture" : "url1,url2,url3",
 "player_gameid": "玩家游戏id",
 "send_voided_mails":1
}
```

### 响应参数（JSON）

**HTTP 状态码：**`200 OK`

| 字段 | 类型 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 | 0 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 |  |

**响应示例**

```json
{"code": 0}
```

## 满意度评价

> **POST: ** `/v1/feedbackapi/pleased/update`
>
> **认证方式：** 无

### CURL 示例

```bash
curl --location --request POST '{{接口域名}}/v1/feedbackapi/pleased/update' \
--header 'Content-Type: application/json' \
--data-raw '{
 "key_number":10,
 "pleased_status":1,
 "reason": "good"
}'
```

### 请求参数（JSON）


| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| key_number | Number | 是 | 创建意见反馈的 ID |
| pleased_status | Number | 是 | 满意度 1:满意 2:不满意 |
| reason | String | 是 | 理由 |


**请求示例**

```json
{
 "key_number":10,
 "pleased_status":1,
 "reason": "good"
}
```

### 响应参数（JSON）

**HTTP 状态码：**`200 OK`

| 字段 | 类型 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 | 0 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 |  |

**响应示例**

```json
{"code": 0}
```
