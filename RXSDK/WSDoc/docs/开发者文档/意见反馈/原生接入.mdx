## 获取意见反馈类型

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

**接口原型**

```objectivec
/**
 * 获取意见反馈类型
 */
- (void)getFeedbackKindListWithComplete:(RequestComplete)complete;
```

**调用示例**

```objectivec
[[RXSDK sharedSDK] getFeedbackKindListWithComplete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {

}];
```

</TabItem>

<TabItem value="android" label="Android">

**接口原型**

```java
void getFeedbackKindList(RXJSONCallback callback);
```

**调用示例**

```java
RXSDK.getInstance().getFeedbackKindList(jsonCallback);
```

</TabItem>

</Tabs>

### 响应参数（JSON）

| 字段 | 类型 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 | 0 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 |  |
| [PageData](#pagedata) | 否 | 结果 |  |  |

#### PageData

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| page | Number | 是 | 第几页 |
| size | Number | 是 | 每页大小 |
| total | Number | 是 | 总数量 |
| list | [][Kind](#kind) | 是 | 意见反馈数据 |

#### Kind

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| id | Number | 是 | 唯一 ID |
| name | string | 是 | 意见反馈类型 |
| email_reply | Number | 是 | 是否邮件回复 |
| is_accident | Number | 是 | 是否产生事故 |
| kind_desc | Number | 是 | 描述 |

**响应示例**

```json
{
 "code": 0,
 "data": {
 "page": 1,
 "size": 10000,
 "total": 1,
 "list": [
 {
 "id": 1,
 "name": "类型名",
 "email_reply": 1,
 "is_accident": 0,
 "kind_desc": "描述"
 }
 ]
 }
}
```

## 创建意见反馈

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

**接口原型**

```objectivec
/**
 * 创建意见反馈
 * @note params 说明
 - game_id: 游戏ID #NSInteger
 - kind_id: 意见反馈ID #NSInteger
 - kind_name: 意见反馈类型 #NSString
 - priority: 紧急程度 1:紧急 2:不紧急 #NSInteger
 - content: 反馈内容 #NSString
 - picture: 图片url #NSString
 - player_gameid: 玩家游戏id #NSString
 - send_voided_mails: 作废是否发邮件 1:发 2:不发 #NSInteger
 */
- (void)createFeedbackWithParams:(NSDictionary *)params
 complete:(RequestComplete)complete;
```

**调用示例**

```objectivec
NSDictionary *dic = @{
 @"game_id": @"(游戏 ID)",
 @"kind_id": @(1000000012),
 @"kind_name": @"土豆土豆",
 @"priority": @(1),
 @"content": @"我是从接口来的",
 @"picture": @"pic1,pic2,pic3",
 @"player_gameid": @"123456"
};
[[RXSDK sharedSDK] createFeedbackWithParams:dic complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {

}];
```

</TabItem>

<TabItem value="android" label="Android">

**接口原型**

```java
void createFeedback(Map<String, Object> map, RXJSONCallback callback)
```

**调用示例**

```java
Map<String, Object> map = new HashMap<>();
map.put("game_id", 100);
map.put("kind_id", 1);
map.put("kind_name", "意见反馈类型");
map.put("priority", 1);
map.put("content", "说明");
map.put("picture", "图片url");
map.put("player_gameid", "玩家游戏id");
map.put("send_voided_mails", 1);
RXSDK.getInstance().createFeedback(map, jsonCallback);
```

</TabItem>

</Tabs>

## 上报反馈日志

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

需要在全局通用回调中监听上报时机（[全局通用回调接入说明](/docs/开发者文档/入门指南/快速开始/iOS-SDK配置#全局通用回调)）。

**接口原型**

```objectivec
/**
 * 上报反馈日志
 * @note 客服后台创建反馈时生效
 * @param data 文件二进制
 */
- (void)reportFeedbackLogWithData:(NSData *)data
 complete:(RequestComplete)complete;
```

**调用示例**

```objectivec
[[RXSDK sharedSDK] reportFeedbackLogWithData:data complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {

}];
```

</TabItem>

<TabItem value="android" label="Android">

需要在全局通用回调中监听上报时机。

**接口原型**

```java
void reportFeedbackLog(Context context, byte[] data, RXJSONCallback callback)
```

**调用示例**

```java
File file = new File("your_log.json");
FileInputStream fis = new FileInputStream(file);
byte[] byteArr = new byte[(int) file.length()];
fis.read(byteArr);
fis.close();
RXSDK.getInstance().reportFeedbackLog(activity, byteArr, new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject data) {
        // 上报成功
    }

    @Override
    public void onFailed(@NonNull JSONObject cause) {
        // 上报失败
    }
});
```

</TabItem>

</Tabs>
