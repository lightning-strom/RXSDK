**HTTP 状态码：**`200 OK`

| **字段** | **类型**                               | **是否必填** | **说明** | **示例** |
|--------|--------------------------------------| --- | --- | --- |
| code   | Number                               | 是   | 响应状态码，0为成功，非0表示出错 | 0   |
| msg    | String                               | 否   | 响应信息，仅在status为非0时不为空 |     |
| data | `PageData` | 否   | 结果  |     |

##### **PageData**

| **字段** | **类型**                         | **是否必填** | **说明** | **示例** |
| --- |--------------------------------| --- |--------| --- |

| list | []`Kind` | 是   | 意见反馈数据 |     |

##### **Kind**
| **字段** | **类型**                         | **是否必填** | **说明** | **示例** |
| --- |--------------------------------| --- |--------| --- |
