# 概览

望舒开发者服务（RDS）是一站式游戏 SDK 平台，帮助开发者快速集成登录、支付、推送、数据分析等核心能力，降低研发和运维成本。

:::tip[快速开始]
首次接入？建议按顺序阅读：[准备工作](/docs/开发者文档/入门指南/准备工作) → [SDK 初始化](/docs/开发者文档/入门指南/快速开始/Android初始化/快速接入)
:::

**支持平台**：Android · iOS · 鸿蒙 · Unity · Quick H5 · 小游戏 · Steam

## 名词解释

| 名词 | 说明 |
|------|------|
| **CP** | 项目组、游戏开发团队、内容提供商（Content Provider） |
| **CPID** | 望舒为每个项目分配的唯一 ID，7 位数字，从 1000000 起递增 |
| **CPKey** | 与 CPID 对应，配置在 APIGate 和服务端接口上，用于服务端通信验签 |
| **ProductID** | 产品标识，在望舒后台[创建](/docs/开发者文档/入门指南/准备工作)，字符串类型 |
| **ChannelID** | 渠道标识，在望舒后台创建，字符串类型 |
| **SubChannelID** | 子渠道标识，用于投放推广或导量的数据统计 |
| **DeviceCode** | 设备码，通过策略生成的用户端设备唯一标识（受系统限制，可能无法获取或不 100% 唯一） |
| **AccessToken** | 通行证登录成功后返回的访问令牌，调用绝大多数接口的凭证 |
| **RefreshToken** | 与 AccessToken 一同返回，AccessToken 有效期较短（通常 1 小时），过期时可用此令牌刷新 |
| **TraceID** | 每次请求的唯一标识（UUID v4），接口出错时提供给望舒团队快速定位 |
| **OpenID** | 玩家在项目中的唯一标识（大小写敏感，长度 32~50 字符，建议 varchar(64)） |
