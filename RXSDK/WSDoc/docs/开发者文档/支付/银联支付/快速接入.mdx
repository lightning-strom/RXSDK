## 望舒支付配置

## 下单支付

### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| params | IPay | 是 | 参数 |
| callback | IMethodParams | 是 | 回调函数集合 |

> IPay 说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| pay_type | string | 是 | 支付的类型 |
| goods_tag | string | 是 | 计费点标识 |
| trade_no | string | 是 | CP 订单号 |
| ext | object | 是 | 支付方式类型以及其他透传参数 |
| currency | string | 否 | 币种 默认传: CNY 根据支付币种传递[国家编码 币种字典](/docs/开发者文档/支付/服务端接入/国家编码-币种字典) |
| indulge_auth | number | 是 | 是否进行防沉迷支付验证 ， 0 不验证 1 验证，默认不验证 |

如果为 1 age 必传
notify_url
| string | 否 | 支付成功通知 CP 发货地址 |
| --- | --- | --- |
| age | number | 否 |
| 用户年龄 |  |  |

indulge_auth 为 1 时必传该字段
| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| transmit_args | string | 否 | 客户端透传参数， key1=val1&key2=val2 的格式 |
| is_debug | number | 否 | 是否测试订单， 0 正式 1 为测试订单，默认为 0 |
| env | number | 否 | 是否使用沙盒环境支付， 0 正式 1 沙盒，默认为 0 |
| game_info | object | 否 | 游戏自定义数据， 上报区服和角色需要在 game_info 中传入属性，具体使用方式参考下方 game_info 字段说明 |
| bigdata_report | object | 否 | 商业化支付参数， 通过商业化触发的支付行为要传以下参数，否则数据统计会有丢失，具体使用方式参考下方 bigdata_report 字段说明 |


> `bigdata_report` 字段说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| scene_identifier | string | 否 | 场景标识 |
| scene_name | string | 否 | 场景名称 |
| trigger_button_identifier | string | 否 | 触发按钮标识 |
| trigger_button_name | string | 否 | 触发按钮名称 |
| window_identifier | string | 否 | 窗口标识 |
| window_name | string | 否 | 窗口名称 |
| window_sequence | string | 否 | 窗口展示顺序 |
| gift_package | object | 否 | 礼包 |

> `gift_package` 字段说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| identifier | string | 否 | 礼包标识 |
| name | string | 否 | 礼包名称 |
| purchase_medium | string | 否 | 购买礼包介质 |
| price | number | 否 | 礼包价格 |
| billing_point | string | 否 | 礼包计费点 |

> `game_info` 字段说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| cp_game_character_id | string | 否 | 角色 id |
| cp_game_area_id | string | 否 | 区服 id |

> pay_type 说明

| 字段 | 备注 |
| --- | --- |
| aums | 银联支付 |

> ext 说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| hq_type | string | 是 | 支付方式类型 移动端支付方式： minih5 ，二维码支付： qrcode |

> IMethodParams 说明

| 字段 | 备注 |
| --- | --- |
| complete | (data) => void |

complete ：为函数且必传， data 为结果数据

**调用示例**

```javascript
sdk.pay(
 {
 pay_type: "aums",
 goods_tag: "bytest",
 trade_no: "" + new Date().getTime(),
 transmit_args: "a=1&b=2",
 indulge_auth: 1,
 age: 18,
 ext: {
 hq_type: 'minih5'
 }

 // 商业化下单参数示例
 // 'bigdata_report': {
 // 'scene_identifier': 'xxx',
 // 'scene_name': 'xxx',
 // 'trigger_button_identifier': 'xxx',
 // 'trigger_button_name': 'xxx',
 // 'window_identifier': 'xxx',
 // 'window_name': 'xxx',
 // 'window_sequence': 'xxx',
 // 'gift_package': {
 // 'identifier': 'xxx',
 // 'name': 'xxx',
 // 'purchase_medium': 'xxx',
 // 'price': 100,
 // 'billing_point': 'xxx',
 // },
 // }

 // 游戏自定义数据示例
 // 'game_info': {
 // 'cp_game_character_id': 'test',
 // 'cp_game_area_id': 'testarea',
 // }
 },
 {
 complete: (data) => {
 console.log(data);
 },
 }
);
```

### 响应结构

| 字段 | 类型 | 备注 |
| --- | --- | --- |
| code | number | 0 : 表示拉起支付面板成功（支付成功状态监听不到） |

## 关闭二维码窗口

用于二维码支付收到游戏服到账发货通知关闭二维码窗口。

**调用示例**

```javascript
sdk.closePay();
```
