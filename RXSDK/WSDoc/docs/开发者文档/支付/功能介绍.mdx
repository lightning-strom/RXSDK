# 功能介绍

## 产品介绍

望舒系统集成了市场上主流的[三方支付方式](/docs/开发者文档/支付/功能介绍)，项目组可以快速接入，并应用到自己的游戏当中。

## 核心优势

节省成本：直接对接 RDS ，减少开发成本。

数据回传：支付数据自动上传至 RDS 大数据平台，方便查看。

维护方便：不依赖第三方服务支持，且更新不需要升级 SDK。

## 接入准备

### 望舒系统中配置支付方式

请确认已经在**企业管理后台 > 商务管理> 三方账号管理 > 支付账号管理 > 新建支付账号**完成了相关三方支付的参数配置。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/wechat/pay/pay_minigame.png)
