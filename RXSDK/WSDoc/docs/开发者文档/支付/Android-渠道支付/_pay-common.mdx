#### 接口原型

```java
/**
 * 支付
 * @param activity 应用上下文对象
 * @param hashMap HQParams 参数，参照参数说明
 * @param callback 回调函数
 */
void pay(Activity activity, @NonNull Map<String, Object> map, RXJSONCallback callback)
```

#### 参数说明

> Map 结构说明

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| hq_type | string | 否 | 支付类型 |
| goods_tag | string | 是 | 望舒计费点标识 |
| trade_no | string | 是 | 商户订单号 |
| transmit_args | string | 否 | 透传参数 |
| notify_url | string | 否 | 支付成功通知 CP 发货地址 |
| currency | string | 是 | 币种，全大写，国内传 CNY，参考 [国家编码 币种字典](/docs/开发者文档/支付/服务端接入/国家编码-币种字典) |
| ext | object | 否 | 支付下单扩展信息，不同渠道具体对接 |
| indulge_auth | int | 否 | 是否进行防沉迷验证，0 不验证、1 验证（自运营默认 1，三方默认 0）|
| age | int | 否 | 默认取登录返回的 age 字段 |
| game_info | object | 否 | 游戏自定义数据，上报区服和角色需要在此传入属性 |
| bigdata_report | HashMap | 否 | 商业化支付参数，商业化触发的支付行为需传此参数 |
| custom_ext | Map | 否 | 自定义透传参数 |

> `custom_ext` 结构说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| bigdata_ext | Map | 否 | 大数据预置事件透传参数 |

> `bigdata_report` 字段说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| scene_identifier | string | 否 | 场景标识 |
| scene_name | string | 否 | 场景名称 |
| trigger_button_identifier | string | 否 | 触发按钮标识 |
| trigger_button_name | string | 否 | 触发按钮名称 |
| window_identifier | string | 否 | 窗口标识 |
| window_name | string | 否 | 窗口名称 |
| window_sequence | string | 否 | 窗口展示顺序 |
| gift_package | HashMap | 否 | 礼包 |

> `gift_package` 字段说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| identifier | string | 否 | 礼包标识 |
| name | string | 否 | 礼包名称 |
| purchase_medium | string | 否 | 购买礼包介质 |
| price | int | 否 | 礼包价格 |
| billing_point | string | 否 | 礼包计费点 |

> `game_info` 字段说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| cp_game_character_id | string | 否 | 角色 id |
| cp_game_area_id | string | 否 | 区服 id |

#### 调用示例

```java
Activity activity;
String goods_tag; // 望舒后台计费点名称
String pay_type;  // 渠道对应的 hq_type 值（见上方说明）
Map<String, Object> extmap = new HashMap<>();

HQParams.GameInfo gameInfo = new HQParams.GameInfo();
gameInfo.setCpGameCharacterId("角色 id");
gameInfo.setCpGameAreaId("区服 id");

Map<String, Object> payParams = new HashMap<>();
payParams.put("hq_type", pay_type);
payParams.put("goods_tag", goods_tag);
payParams.put("trade_no", "cp订单号");
payParams.put("transmit_args", "cp透传参数，非必传");
payParams.put("ext", extmap);
payParams.put("game_info", gameInfo.toMap());
payParams.put("indulge_auth", 1);

RXRequestCallback rxRequestCallback = new RXRequestCallback() {
    @Override
    public void onResponse(JSONObject jsonObject) {
        int code = jsonObject.optInt("code", -1);
        if (code == 0) {
            JSONObject data = jsonObject.optJSONObject("data");
            // 处理成功逻辑
        } else {
            String msg = jsonObject.optString("msg");
            String thirdcode = String.valueOf(jsonObject.opt("thirdcode"));
            // 根据错误码处理失败逻辑
        }
    }
};
RXSDK.getInstance().pay(activity, payParams, rxRequestCallback);
```
