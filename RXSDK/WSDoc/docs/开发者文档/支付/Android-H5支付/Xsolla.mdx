### 望舒支付配置

联系商务获取 Xsolla 支付配置参数，配置至 **资源管理 > 三方账号管理 > 支付账号管理**。

### SDK 集成


:::tip[版本说明]
`version` 为 SDK 版本号（替换为实际版本号），最新版本请从 [更新日志](/docs/开发者文档/入门指南/更新日志/Android) 中查看。
:::

```groovy
implementation 'com.ruixue:rxsdk_h5pay:${version}'
```

### hq_type 值

| hq_type 值 | 说明 |
| --- | --- |
| `xsa` | Xsolla 支付 |

:::info[Xsolla ext 扩展参数]
通过 `ext` 字段传入 Xsolla 特有参数：

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| return_url | String | 是 | 支付结束后跳转页面地址 |
| user_name | String | 否 | 游戏侧玩家昵称 |
| button_name | String | 否 | 跳转页面按钮名称 |
| tag | String | 否 | 三方子支付方式 |
:::
