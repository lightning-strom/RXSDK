### 望舒支付配置

联系商务获取京东支付配置参数，配置至 **资源管理 > 三方账号管理 > 支付账号管理**。

### SDK 集成


:::tip[版本说明]
`version` 为 SDK 版本号（替换为实际版本号），最新版本请从 [更新日志](/docs/开发者文档/入门指南/更新日志/Android) 中查看。
:::

```groovy
implementation 'com.ruixue:rxsdk_h5pay:${version}'
```
