### SDK 集成


:::tip[版本说明]
`version` 为 SDK 版本号（替换为实际版本号），最新版本请从 [更新日志](/docs/开发者文档/入门指南/更新日志/Android) 中查看。
:::

```groovy
implementation 'com.ruixue:rxsdk_h5pay:${version}'
```

### hq_type 值

| hq_type 值 | 说明 |
| --- | --- |
| `wch_hw` | 微信海外 H5 支付 |

:::info[海外特有参数]
在标准参数基础上，海外支付需额外传入：

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| user_real_currency | string | 否 | 用户实际支付币种，如 `USD`、`EUR` |
| user_real_price | int | 否 | 用户实际支付金额（分） |
:::
