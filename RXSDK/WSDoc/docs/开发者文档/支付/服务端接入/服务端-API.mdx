## 获取订单信息

> **POST：** `/v1/ke/order/query`
>
> **认证方式：** [CPSign](/docs/开发者文档/入门指南/服务端接入须知)

提示：非必接接口， CP 服务端可主动请求获取指定订单信息

### CURL 示例

```bash
curl --location --request POST '{{接口域名}}/v1/ke/order/query' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
-d '{"date":"2304","openid":"rxxxx"}'
```

## 通知苹果退款订单的风控信息

> **POST：** `/v1/ke/refundcp`
>
> **认证方式：** [CPSign](/docs/开发者文档/入门指南/服务端接入须知)

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/payment/YkaubQnqfodLXPxiWEEcdCNQnyh.png)

需要望舒后台 > 基础配置 > 支付设置 > 苹果支付配置中配置 App Store Connect 用户访问 密钥 ID

**调用场景：**

苹果用户发生退款时，苹果会通知望舒补充相关信息（苹果评估玩家是否是合理退款）。

望舒通知 CP 方补充信息， CP 调用该接口回传相关信息。

望舒把 CP 方补充信息回传给苹果。

###CURL 示例

```bash
curl --location --request POST '{{接口域名}}/v1/ke/order/refundcp' \
--header 'Content-Type: application/json' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--data-raw '{"transaction_id":"xxxxxxx","account_tenure":0,"consumption_status":0,"delivery_status":0,"lifetime_dollars_purchased":0,"lifetime_dollars_refunded":0,"platform":0,"playtime":0,"sample_content_provided":false,"user_status":0}'
```

**请求示例**

```json
{
 "transaction_id":"xxxxxxx",
 "account_tenure":0,
 "consumption_status":0,
 "delivery_status":0,
 "lifetime_dollars_purchased":0,
 "lifetime_dollars_refunded":0,
 "platform":0,
 "playtime":0,
 "sample_content_provided":false,
 "user_status":0
}
```

## xsolla(艾克索拉) web支付

用户使用 xsolla 支付,用户下单及支付成功时 xsolla 服务器会通知望舒,望舒将消息处理后转发 cp 服务器

申请厂商服务代码需要提供的服务器信息：（需按产品申请）

webhook(https://publisher.xsolla.com/399655/projects/228862/edit/webhooks/store): ` 望舒 api 地址+/v1/ke/web_order/callback/产品 id/xsolla`

Secret(https://publisher.xsolla.com/399655/projects/228862/edit/api_key): 消息密钥（用于生成 webhook 请求 body 签名）

接入 xsolla 需要如下步骤(https://developers.xsolla.com/zh/solutions/payments/other/quickstart/):

1.在 xsolla 发布商帐户中创建项目。一个项目对应一个游戏。如有多个游戏，请为每个游戏各创建一个项目。

2.将要销售的商品添加到艾克索拉侧的目录。

3.cp 配置计费点关联艾克索拉要销售的商品

4.测试创建模拟用户要支付的订单。

5.进行测试性购买并设置 webhook 通知。

6.在发布商帐户中签署与艾克索拉的协议以开始处理真实支付。

7.望舒处理支付消息,通知 cp 发货

8.cp 根据订单通知给用户发货
