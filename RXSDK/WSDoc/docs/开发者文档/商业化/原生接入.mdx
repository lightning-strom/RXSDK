## 商业化信息上报

**接口原型**

```java
/**
    * 商业化信息上报
    */
void reportWindowExposure(Map<String, Object> properties);
```

### 请求参数

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| scene_identifier | string | 否 | 场景标识，**data.list[].tag** |
| scene_name | string | 否 | 场景名称，**data.list[].name** |
| trigger_button_identifier | string | 否 | 场景名称，**data.list[].button_list[].tag** |
| trigger_button_name | string | 否 | 触发按钮名称，**data.list[].button_list[].name** |
| window_identifier | string | 否 | 窗口标识，**data.list[].button_list[].window_list[].tag** |
| window_name | string | 否 | 窗口名称，**data.list[].button_list[].window_list[].name** |
| window_sequence | string | 否 | 窗口展示顺序，**data.list[].button_list[].window_list[] 中的数组的 key （第几个窗口）** |
| gift_package | array[object] | 否 | 礼包，**data.list[].button_list[].window_list[].gift_package[]** |

> gift_package 结构说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| identifier | string | 否 | 礼包标识，**data.list[].button_list[].window_list[].gift_package[].tag** |
| name | string | 否 | 礼包名称，**data.list[].button_list[].window_list[].gift_package[].name** |
| purchase_medium | string | 否 | 购买礼包介质名称，**data.list[].button_list[].window_list[].gift_package[].buy_type.name** |
| trigger_button_name | string | 否 | 触发按钮名称，**data.list[].button_list[].name** |
| price | int | 否 | 礼包名称，**data.list[].button_list[].window_list[].gift_package[].amount** |
| billing_point | string | 否 | 礼包计费点，**data.list[].button_list[].window_list[].gift_package[].goods.goods_tag** |

**调用示例**

```java
// 构造 scene 对象，Java 版的 Map
Map<String, Object> scene = new HashMap<>();

// 场景数据
scene.put("scene_identifier", "场景标识");
scene.put("scene_name", "场景名称");
scene.put("trigger_button_identifier", "触发按钮标识");
scene.put("trigger_button_name", "触发按钮名称");
scene.put("window_identifier", "窗口标识");
scene.put("window_name", "窗口名称");
scene.put("window_sequence", "窗口展示顺序");

// 构造礼包数据
List<Map<String, Object>> giftPackage = new ArrayList<>();
Map<String, Object> gift = new HashMap<>();
gift.put("identifier", "礼包标识");
gift.put("name", "礼包名称");
gift.put("purchase_medium", "购买礼包介质名称");
gift.put("price", 100); // 礼包价格
gift.put("billing_point", "礼包计费点");
giftPackage.add(gift);

// 添加礼包列表到 scene
scene.put("gift_package", giftPackage);

// 调用接口
RuiXueSdk.getApi().reportWindowExposure(scene);
```

## 道具兑换

商业化窗口中非付费的道具兑换需要使用**道具兑换**接口。

通过支付接口中的参数区分**付费**还是**道具兑换**。

**接口原型**

```java
    void pay(Activity activity, @NonNull Map<String, Object> hashMap, RXJSONCallback callback);
```

### 请求参数

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| exchange | bool | 是 | 是否是道具兑换， true 道具兑换， flase 支付，默认 false |
| mode | int | 否 | 扣除发放模式 1 一次性事务扣除, 默认 1 |
| scene_tag | string | 是 | 场景标识 |
| window_id | int | 否 | 扣除发放模式 1 一次性事务扣除, 默认 1 |
| window_version | string | 是 | 窗口版本 |
| cp_gift_tag | string | 是 | cp 侧礼包标识，校验道具是否一致 |
| cp_prop_tag | string | 是 | cp 侧待消费的 道具标识，校验道具是否一致 |
| cp_prop_number | string | 是 | cp 侧待消费的 道具数量，校验道具是否一致 |
| item_list | array[object] | 是 | 待兑换道具列表 |

> item_list 结构说明


| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| number | int | 是 | 待发放的 道具数量 |
| tag | string | 是 | 待发放的 道具标识 |


**调用示例**

```java
// 构造支付请求的参数字典
Map<String, Object> dict = new HashMap<>();

// 设置支付参数
dict.put("exchange", true); // 道具兑换
dict.put("mode", 1); // 扣除发放模式 1 一次性事务扣除，默认1
dict.put("scene_tag", "cjtag1"); // 场景标识
dict.put("window_id", 20008); // 窗口ID
dict.put("window_version", "8fcd03a965c9104b62b209fca6d18fa0"); // 窗口版本
dict.put("cp_gift_tag", "a3"); // CP侧礼包标识
dict.put("cp_prop_tag", "hi"); // CP侧待消费的道具标识
dict.put("cp_prop_number", 11); // CP侧待消费的道具数量

// 构造待兑换道具列表
List<Map<String, Object>> itemList = new ArrayList<>();
itemList.add(new HashMap<String, Object>() {{
    put("number", 100); // 数量
    put("tag", "60006"); // 标签
}});
itemList.add(new HashMap<String, Object>() {{
    put("number", 88); // 数量
    put("tag", "Dj016"); // 标签
}});
itemList.add(new HashMap<String, Object>() {{
    put("number", 999); // 数量
    put("tag", "71005"); // 标签
}});

// 将道具列表添加到字典
dict.put("item_list", itemList);
RuiXueSdk.getApi().pay(activity, dict, new RXRequestCallback() {
    @Override
    public void onResponse(JSONObject jsonObject) {

    }
});

```

### 响应结构

| 字段 | 类型 | 备注 |
| --- | --- | --- |
| order_no | NSString | 望舒订单号 |
| trade_no | NSString | CP 订单号 |
| window | NSDictionary | 签名的窗口信息 |

> window 结构说明

| 字段 | 类型 | 备注 |
| --- | --- | --- |
| window_key | NSString | 窗口唯一标识 |
| buttons | NSArray | 按钮列表 |
| payment | NSDictionary | 支付配置 |
| rewards | NSArray | 奖励配置 |
| sign | NSString | 窗口签名，商业化道具兑换校验用 |

> payment 结构说明

| 字段 | 类型 | 备注 |
| --- | --- | --- |
| type | int | 支付方式 1 无消耗 2 道具 3 计费点 |
| billing_point | NSDictionary | 计费点配置 |
| props | NSDictionary | 道具配置 |

> payment.billing_point 结构说明

| 字段 | 类型 | 备注 |
| --- | --- | --- |
| billing_point_key | NSString | 计费点标识 |

> payment.props 结构说明

| 字段 | 类型 | 备注 |
| --- | --- | --- |
| props_key | NSString | 道具标识 |
| num | int | 道具数量 |

> rewards 结构说明

| 字段 | 类型 | 备注 |
| --- | --- | --- |
| props_key | NSString | 奖励的道具标识 |
| num | int | 奖励的道具数量 |
