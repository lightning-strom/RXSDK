### 接入方式

Package Manager 导入 RuiXue.Uwa

### UWA调用方式

接入 UWA 需要调用**UWA 初始化**与**UWA 获取性能数据上报**两个方法。

这两个方法需要在**SDK 初始化成功后的回调方法中**进行调用。(其中**UWA 初始化方法**并不一定需要在SDK 初始化成功的回调方法中调用，但必须保持在**UWA 获取性能数据并上报**方法之前调用)。

**调用示例**

```csharp
 public void initSuccess()
 {
 UWAGPM.StaticInit(
 "your url",
 "your appID",
 "your version",
 "your channel",
 debug: false
 );
 PerformManceReport.PerformReport();
 }
```

### UWA初始化

**接口原型**

```csharp
 /// summary>
 /// Initializes the GPM SDK.
 /// summary>
 /// param name="url">UWA注册后下发的urlparam>
 /// param name="appID">UWA注册后下发的appIDparam>
 /// param name="appVersion">UWA版本号param>
 /// param name="channel">UWA渠道param>
 /// param name="debug">是否为调试模式，默认为falseparam>
 public static void StaticInit(string url, string appID, string appVersion, string channel = "", bool debug = false);
```

**调用示例**

```csharp
 public void initUWA()
 {
 UWAGPM.StaticInit(
 "your url",
 "your appID",
 "your version",
 "your channel",
 debug: false
 );

 }
```

### UWA获取性能数据并上报

UWA 性能数据收集上报时间间隔需在望舒管理平台进行配置

UWA 获取性能数据并上报的方法，必须要在SDK 初始化成功后进行调用，方可生效。

**接口原型**

```csharp
 public static void PerformReport();
```

**调用示例**

```csharp
 public void startUWAReport()
 {
 PerformManceReport.PerformReport();
 }
```

### UWA其他方法

#### 获取注册状态

**接口原型**

```csharp
 //获取注册状态，返回1时表示成功
 public static int GetRegisterState();
```

**调用示例**

```csharp
 RuiXueUWAGPM.GetRegisterState();
```

#### 切换场景操作

**接口原型**

```csharp
 //GPM 支持针对场景的异常检测，通过 Unity 接口切换场景时 SDK 将会自动记录，同时也支持通过 API 来切换场景
 public static void ChangeScene(string sceneName);
```

**调用示例**

```csharp
 RuiXueUWAGPM.ChangeScene("test");
```

#### 设置当前的网络延时

**接口原型**

```csharp
 //设置当前的网络延时（单位毫秒 ms），建议每秒更新一次，该数值会被作为统计项出现在线上报告中。
 public static void SetNetworkLatency(uint value);
```

**调用示例**

```csharp
 RuiXueUWAGPM.SetNetworkLatency(1);
```
