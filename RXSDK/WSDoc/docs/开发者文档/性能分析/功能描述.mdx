## 功能介绍

望舒提供了收集 iOS、Android 移动设备相关的性能指标。

数据收集方式分为两种： UWA、SDK ；

收集数据包含以下方面：

FPS

JANK 卡顿

PROCESS_MEMORY_MB 当前应用占用的运行内存

BATTERYLEVEL 剩余电量

BATTERYCAPACITY 电池总容量（ iOS 无法获取）

POWER 当前功率（ iOS 无法获取）

CURRENT 当前电流（ iOS 无法获取）

BATTERYTEMP 电池温度（ iOS 无法获取）

CPUTEMP CPU 温度（ iOS 无法获取）

GPUTEMP GPU 温度（ iOS 无法获取）

CPUUSAGE CPU 使用率（SDK 支持， UWA 不支持）

DEVICE_MODEL 机型

SYSTEM 系统版本

RESOLUTION 屏幕分辨率

EMULATOR 是否为模拟器

ROOT 是否刷机

CPU_CORE CPU 核心数量

GPU_MODEL GPU 名称

RAM_MB 运行内存大小

ROM_GB 存储内存大小

图形 API 渲染框架名称

设备唯一标识
