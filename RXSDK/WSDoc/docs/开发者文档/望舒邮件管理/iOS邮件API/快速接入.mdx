## 准备工作

接入请前先做好准备工作。已经接入过**RXSDK_Pure**组件，无需重复接入，只需要更新到**3.5.27 及以上版本**即可。

未接入过，则可通过 **pod** 方式接入 **RXSDK_Pure** 组件，安装**3.5.27 及以上版本**，并使用 **RXSDK_Pure**邮件相关功能。

在需要使用功能的类中引用头文件 `#import <RXSDK_Pure/RXSDK_Pure.h>`

## SDK 集成

编辑 Podfile 文件，添加如下配置，并注意安装**3.5.27 及以上版本**：

```objectivec
pod 'RXSDK_Pure'
```

## 获取望舒邮件-列表

**接口原型**

```objectivec
/**
 * 获取邮箱列表
 * cpUserID 游戏用户id
 */
- (void)getEmailListWithCpUserID:(NSString *)cpUserID complete:(void(^)(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error))complete;
```

**调用示例**

```objectivec
[[RXSDK sharedSDK] getEmailListWithCpUserID:@"your cpuserid" complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
 if (error == nil) {
 NSLog(@"%@",response);
 }else{
 NSLog(@"%@",error.responesObject);
 }
}];
```

### 响应结构（JSON）

| 参数 | 类型 | 约束 |
| --- | --- | --- |
| list | Array | 邮件列表 |
| all_count | Number | 列表邮件总数 |
| not_received_count | Number | 列表中未领取附件的邮件数量 |

**list**

| 参数 | 类型 | 约束 |
| --- | --- | --- |
| rx_mail_id | Number | 邮件 ID |
| title | String | 邮件标题 |
| send_at | String | 邮件发送时间，格式为 MM-dd HH:ii:ss ，不包含年份 |
| status | Number | 邮件状态： 1-已读 2-已领 3-已发送 |

## 获取望舒邮件-详情

**接口原型**

```java
/**
    * 获取邮箱详情
    * cpUserID 游戏用户id
    * emailID 邮件id
    */
- (void)getEmailDetailWithCpUserID:(NSString *)cpUserID emailID:(NSInteger)emailID complete:(void(^)(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error))complete;
```

**调用示例**

```objectivec
[[RXSDK sharedSDK] getEmailDetailWithCpUserID:@"your cpuserid" emailID:email id complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
 if (error == nil) {
 NSLog(@"%@",response);
 }else{
 NSLog(@"%@",error.responesObject);
 }
}];
```

### 响应结构（JSON）

| 参数 | 类型 | 约束 |
| --- | --- | --- |
| title | String | 邮件标题 |
| content | String | 邮件内容 |
| sign | String | 邮件落款 |
| props | Array | 邮件附件列表 |
| status | Number | 邮件状态： 1-已读 2-已领 3-未读 |

**props**

| 参数 | 类型 | 约束 |
| --- | --- | --- |
| name | String | 道具名称 |
| describe | Number | 道具描述 |
| icon | Number | 道具图标 url |
| tag | Number | 道具唯一标识 |
| count | Number | 道具数量 |
| count_format | String | 道具数量单位换算，支持简繁体中文、英文和越南文的单位换算，其他语言默认使用英文单位换算 |
| is_permanent | Number | 道具是否永久有效， 0 ：永久有效 1 ：非永久有效 |
| time_limit | Number | 道具有效期，以天为单位 |

## 望舒邮件-领取

**接口原型**

```objectivec
/**
 * 领取道具
 * cpUserID 游戏用户id
 * type 传1为领取当前礼物，需要同时传emailID；传2，为一键领取所有礼物，无需传emailID，或传0即可
 * emailID 邮箱id
 */
- (void)receivePropsWithCpUserID:(NSString *)cpUserID type:(NSInteger)type emailID:(NSInteger)emailID complete:(void(^)(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error))complete;
```

当 type 为 2 时， mailId 为 0 即可。此时 maiId 不会传递给服务端

**调用示例**

```objectivec
[[RXSDK sharedSDK] receivePropsWithCpUserID:@"your cpuserid" type:1 emailID:email id complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
 if (error == nil) {
 NSLog(@"%@",response);
 }else{
 NSLog(@"%@",error.responesObject);
 }
}];
```

**响应示例**

```objectivec
{
 "code": 0,
 "msg": "",
 "data": ""
}
```
