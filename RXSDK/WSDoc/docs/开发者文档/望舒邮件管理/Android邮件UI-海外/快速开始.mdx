邮件支持横屏、竖屏两种展示方式

## 邮件展示

**接口原型**

```java
    /**
    * @param activity activity
    * @param userId 用户id
    * @return
    */
    public IRXView showMailCenter(Activity activity, String userId)
```

**调用示例**

```java
    OverseasSdkUI.getInstance().showMailCenter(this, "xxxxx").show();
```
