# 预置事件和预置属性

本节将会介绍望舒大数据平台中所有的的预置事件、预置事件属性内容。自定义事件、事件属性和用户属性按照游戏方数据分析场景自行上报，具体预置事件的数据上报指南可以参考:iOS SDK 、Android SDK、H5 & 小程序 SDK、服务端 SDK、RESTful API 如果您是第一次使用大数据平台，我们衷心建议您在数据接入前先阅读指南 快速使用指南 接入前的准备工作 ，通过阅读指南可以帮助您快速了解大数据平台功能和数据接入流程中的注意事项以及实用建议。

## 一、预置事件和预置属性说明

游戏方通过接入**SDK （通行证、支付、分享等）** 相关接口上报预置事件数据，接入预置事件后大数据平台为用户提供预置的日报、月报、分享等数据分析报表入口供游戏方使用。所有的预置事件和属性以"#"开头，且都为事件属性，且这些属性的中文名以及意义都已经确定。

除以下罗列的预置事件外，任何以"#"开头的事件和属性都被视为非法字段，将无法入库，因此不建议您将自定义事件和属性设置成以"#"开头。
