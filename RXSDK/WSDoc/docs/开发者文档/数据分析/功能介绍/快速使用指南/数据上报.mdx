# 数据上报

## 一、选择接入方式

将之前整理的事件 Excel 文档成功上传到埋点方案中后，您需要选择您的接入方式，您可以使用客户端和服务端进行数据上报。详细内容可参考 [iOS SDK](/docs/开发者文档/数据分析/iOS-数据分析/快速接入) 、 [Android SDK](/docs/开发者文档/数据分析/Android-数据分析/快速接入)、[JavaScript SDK](/docs/开发者文档/数据分析/JavaScript-接入)、[Go SDK](/docs/开发者文档/数据分析/服务端接入/Go-SDK)、[服务端 API](/docs/开发者文档/数据分析/服务端接入/服务端-API)。

## 二、测试基础指标

对于第一次使用大数据平台的用户，我们建议先接入预置事件，也就是注册、登录和付费等预置事件并上传测试数据，以此来测试数据传输以及数据结构的正确及可靠性。详细内容可参考 [预置事件和预置属性](/docs/开发者文档/数据分析/功能介绍/快速使用指南/预置事件和预置属性)。

大数据平台后台采用无延迟技术，只要收到数据，即可在后台**数据管理 > 埋点方案 > 实时数据** 上查询到数据，因此在上传测试数据后，您可以在实时数据界面查询是否有数据，并核对上报的预置事件及数据结构是否正确。目前大数据平台指标计算的**时间粒度小时级别**，因此上报数据后，需**等待一小时**后便可基于上报的数据进行数据分析。

## 三、根据事件文档进行埋点

根据之前整理的事件 Excel 文档进行埋点，需要注意事件的描述以及用户属性的意义，这些会影响到埋点的触发条件以及调用的接口。

而用户属性的意义的不同，调用的接口不同，具体的逻辑在[用户属性和事件属性](/docs/开发者文档/数据分析/功能介绍/快速使用指南/用户属性和事件属性) 一节中已有详细描述，此处不再赘述。
