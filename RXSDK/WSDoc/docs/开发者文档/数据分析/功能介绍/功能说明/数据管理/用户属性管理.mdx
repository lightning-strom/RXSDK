# 用户属性管理

## 修改事件属性信息

进入望舒平台首页，点击左侧菜单：**大数据分析平台**。

在页面右上方，点击**数据管理 > 元数据管理 > 用户属性**。

点击列表页右侧的编辑按钮。输入信息后，点击【保存】。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/AM0PbErdaosRtMxMm9AcsC33nhe.png)

## 添加维度表

进入望舒平台首页，点击左侧菜单：**大数据分析平台**。

在页面右上方，点击**数据管理 > 元数据管理 > 用户属性**。

点击列表页右侧的维度表按钮，选择新建或替换。

在弹窗中设置维度表属性后，上传文件。点击下一步，解析成功后，维度表属性设置完成。
