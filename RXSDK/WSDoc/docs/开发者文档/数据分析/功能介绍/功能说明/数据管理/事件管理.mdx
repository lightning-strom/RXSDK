# 事件管理

本章节为您介绍在该页面对事件进行相关操作。包括事件信息修改、状态修改。以下将分别为您介绍相应的设置步骤和需要注意信息点。

请注意重点关注文档中加粗、标注部分的描述。

## 修改事件信息

进入望舒平台首页，点击左侧菜单：**大数据分析平台**。

在页面右上方，点击**数据管理 > 元数据管理 > 元事件**。

点击列表页右侧的编辑按钮。输入信息后，点击【保存】。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/dataAnalysis/JSMobVcT5ow7D5xXDSLc5vUxnld.png)

只有自定义事件可修改。

只能修改显示名和事件说明。

点击事件名，可弹窗展示该事件下包含的属性。

显示状态可点击关闭。关闭后，在新建看板时，将无法选择该事件。

如果该事件已经被看板使用，则不能操作状态关闭。
