# 1. 上报事件

- 需要通过区服信息进行统计的事件里需要上报区服、角色 id ，用于后续统计。
- 分享、下单支付等事件是望舒侧上报，因此需要在对应的接口或 sdk 中增加区服、角色 id 信息。

## 1.1 分享

- 当 cp 侧需要对分享事件#share 做区服、角色分析统计时，需要在调用 sdk 时传递对应的区服、角色 id 信息；

[文档示例](/docs/开发者文档/意见反馈/Unity-接入)

## 1.2 下单支付

- 当 cp 侧需要对支付事件#order 订单、#paid 付款事件做区服、角色分析统计时，需要再调用 sdk 时传递对应的区服、角色 id 信息；
- 接口文档地址：请参照不同支付协议文档固定结构 game_info 所需参数传值；
