## 一、LogBus 简介

- LogBus 是一款用于实时导入 Kafka 数据到望舒大数据平台后台的工具。当 kafka 指定 Topic 有新数据产生时， LogBus 会实时发送至望舒大数据平台后台。
- LogBus 适用于以下几类用户来接入数据：
- 服务端使用 Kafka 存储望舒大数据标准格式数据的用户，可通过 LogBus 上传数据。
- 对数据的准确性及维度要求较高，仅使用客户端 SDK 无法满足数据需求或不方便接入客户端 SDK 的用户。
- 不希望自行开发后端数据推送流程、需要传输大批量历史数据，并对内存使用和传输效率有一定要求的情况。

## 三、使用前准备

### Kafka

- 确保 Kafka Message 的 value 符合望舒大数据上报格式 ,格式请参见[望舒大数据标准格式数据]；
- 使用 docker/kubernetes 部署时,请对运行目录下的**cache**文件夹创建永久储存卷；

### 启动

```shell
./logsbus
```

### 重启

- 每次启动 LogBus 时，它都会尝试从 cache 文件中恢复上次的任务信息。但是，如果你更换了新的数据源或需要重新上传数据，则建议在再次启动前清空 cache 文件夹。

### 异常退出

- 在出现硬件、操作系统或程序错误，导致 LogBus 程序异常退出的情况下，当重新启动 LogBus 时，程序将自动尝试从 cache 文件夹中恢复之前上传的任务信息。若无需恢复上次任务，则建议在再次启动前清空 cache 文件夹。
