**接口原型**

```csharp
/// summary>
/// 上报/更新经纬度坐标
/// summary>
/// param name="types">坐标分组，由 CP 自定义param>
/// param name="lon">WGS84 经度param>
/// param name="lat">WGS84 纬度param>
/// param name="radius">限定半径距离，单位：米param>
/// param name="count">获取数量，0 表示获取全部param>
/// param name="page">获取第几页的数据 从 1 开始param>
/// param name="page_size">每页数量param>
/// param name="callback">param>
void LbsRadius(string types, float lon, float lat, float radius, int count, int page, int page_size, Actionint, object, string> callback);
```

#### 参数说明

| 字段 | 类型 | 是否必填 | 备注 | 其他信息 |
| --- | --- | --- | --- | --- |
| lon | number | 是 | WGS84 经度 | mock: 125.36970905364038 |
| lat | number | 是 | WGS84 纬度 | mock: 43.814125235156496 |
| radius | integer | 是 | 限定半径距离，单位：米 | mock: @integer(100, 10000) |
| count | integer | 否 | 获取数量， 0 表示获取全部 | mock: @integer(1, 100) |
| page | integer | 是 | 获取第几页的数据 从 1 开始 | mock: 1 |
| page_size | integer | 是 | 每页数量 | mock: 10 |
| type | string | 是 | 坐标分组，由 CP 自定义 |  |

**调用示例**

```csharp
float lon = 118.19646377354036f;
float lat = 24.4837108022851f;
var radius = 20000;
var count = 0;
var page = 1;
var page_size = 10;
var type = "friend";
RuiXueSdk.SocialAPI.LbsRadius(type, lon, lat, radius, count, page, page_size, RXCallback);
```

#### 响应结构

**HTTP 状态码：**`200 OK`

| 字段 | 类型 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 | 0 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 | data |
| DataNode | 否 | 结果数据集 |  |  |

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |

| birthday | String | 否 | 用户生日日期 |
| remarks | String | 否 | 当前用户对其的备注 |
| avatar | String | 否 | 用户头像 |
| custom | String | 否 | CP 自定义信息 |
| dist | Float64 | 是 | 距离当前用户的距离（米） |
| sex | Number | 否 | 用户性别， 1:男； 0:女 |
| cp_userid | Number | 否 | CP 侧 用户 id |
