## 定位

### 授权定位

#### 参数说明

| **字段** | **类型**         | **是否必填** | **备注**     |
| ------------ | -------------------- | ---------------- | ---------------- |
| callback | IMethodParams    | 是           | 回调函数集合 |

> IMethodParams 说明

| **字段** | **备注**                                                  |
| ------------ | ------------------------------------------------------------- |
| complete | (data) => voidcomplete：为函数且必传，data 为结果数据 |

**调用示例**
```javascript
sdk.authorizeLocation(
  {
    complete: (data) => {
      console.log(data);
    },
  }
);
```

### 授权定位

:::tip
获取当前的地理位置
微信基础库 2.25.0 开始支持，请注意当前设置的微信基础库版本。
:::

| **字段** | **类型** | **备注** |
| ------------ | ------------ | ----------------------------------------------------------------------------------------------------------- |
| code | number | 0: 表示成功 6020: 表示定位失败 6021: 表示定位被拒绝 |
| data | object | 经纬度信息 |
| data.latitude | number | 纬度，范围为 -90~90，负数表示南纬 |
| data.longitude | number | 经度，范围为 -180~180，负数表示西经 |
