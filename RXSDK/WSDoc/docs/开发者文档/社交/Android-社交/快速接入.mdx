## 定位

### 获取附近的人

**接口原型**

```java
void lbsRadius(Map<String, Object> hashMap, RXRequestCallback callback)
```

#### 参数说明

| 字段 | 类型 | 是否必填 | 备注 | 其他信息 |
| --- | --- | --- | --- | --- |
| lon | number | 是 | WGS84 经度 | mock: 125.36970905364038 |
| lat | number | 是 | WGS84 纬度 | mock: 43.814125235156496 |
| radius | integer | 是 | 限定半径距离，单位：米 | mock: @integer(100, 10000) |
| count | integer | 否 | 获取数量， 0 表示获取全部 | mock: @integer(1, 100) |
| page | integer | 是 | 获取第几页的数据 从 1 开始 | mock: 1 |
| page_size | integer | 是 | 每页数量 | mock: 10 |
| type | string | 是 | 坐标分组，由 CP 自定义 |  |

**调用示例**

```java
HashMap lbsRadius = new HashMap<>();
lbsRadius.put("lon", 118.19646377354036);
lbsRadius.put("lat", 24.483710802285128);
lbsRadius.put("radius", 20000);
lbsRadius.put("count", 0);
lbsRadius.put("page", 1);
lbsRadius.put("page_size", 10);
lbsRadius.put("type", "friend");
RXSDK.getInstance().lbsRadius(lbsRadius, callback);
```

#### 响应参数（JSON)

**HTTP 状态码：**`200 OK`

| 字段 | 类型 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 | 0 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 | data |
| DataNode | 否 | 结果数据集 |  |  |

##### DataNode


| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| openid | String | 是 | 用户望舒 OpenID |
| nickname | String | 否 | 用户昵称 |
| birthday | String | 否 | 用户生日日期 |
| remarks | String | 否 | 当前用户对其的备注 |
| avatar | String | 否 | 用户头像 |
| custom | String | 否 | CP 自定义信息 |
| dist | Float64 | 是 | 距离当前用户的距离（米） |
| sex | Number | 否 | 用户性别， 1:男； 0:女 |
| cp_userid | Number | 否 | CP 侧 用户 id |


**响应示例**

```json
{
 "data": [
 {
 "openid": "rxuSl4QZoNk0G1HY2-Za6GlO7wO-p_ej",
 "nickname": "xdh"
 }
 ],
 "code": 0
}
```
