### 获取附近人

**接口原型**

```csharp

public void LbsRadius(string type, float lon, float lat, float radius, int count, int page, int page_size,
            RequestResponseDelegate onResponse, RequestErrorDelegate onError);

```

#### 参数说明

| **字段**  | **类型** | **是否必填** | **备注**                   | **其他信息**               |
| --------- | -------- | ------------ | -------------------------- | -------------------------- |
| lon       | number   | 是           | WGS84 经度                 | mock: 125.36970905364038   |
| lat       | number   | 是           | WGS84 纬度                 | mock: 43.814125235156496   |
| radius    | integer  | 是           | 限定半径距离，单位：米     | mock: @integer(100, 10000) |
| count     | integer  | 否           | 获取数量，0 表示获取全部   | mock: @integer(1, 100)     |
| page      | integer  | 是           | 获取第几页的数据 从 1 开始 | mock: 1                    |
| page_size | integer  | 是           | 每页数量                   | mock: 10                   |
| type      | string   | 是           | 坐标分组，由 CP 自定义     |                            |

**调用示例**

```csharp

    private void OnLbsRadius()
    {
        RXSocial.LbsRadius("friend", 118.19646377354036f, 24.483710802285128f, 1000, 10, 1, 10, 
            SocialResponseDelegate, RegisterErrorDelegate);
    }

```

#### 响应结构

**HTTP 状态码：**`200 OK`

| **字段** | **类型**                                  | **是否必填** | **说明** | **示例** |
| --- |-----------------------------------------| --- | --- | --- |
| code | Number                                  | 是   | 响应状态码，0为成功，非0表示出错 | 0   |
| msg | String                                  | 否   | 响应信息，仅在status为非0时不为空 |     |
| data | `DataNode` | 否   | 结果数据集 |     |

##### DataNode

| **字段** | **类型** | **是否必填** | **说明** | **示例** |
| --- | --- | --- | --- | --- |
| openid | String | 是   | 用户望舒 OpenID |     |
| nickname | String | 否   | 用户昵称 |     |
