## SDK集成


:::tip[版本说明]
`version` 为 SDK 版本号（替换为实际版本号），最新版本请从 [更新日志](/docs/开发者文档/入门指南/更新日志/Android) 中查看。
:::

```groovy
implementation 'com.ruixue:rxsdk_feedback_ui:${version}'
```

## 显示创建意见反馈UI

**接口原型**

```java
/**
    * 显示创建意见反馈UI
    * @param context Context
    */
public void showCreateFeedbackView(Context context)
```

**调用示例**

```java
RXFeedbackUI.showCreateFeedbackView(activity);
```

## 显示意见反馈列表

**接口原型**

```java
/**
    * 显示意见反馈列表UI
    * @param context Context
    */
public void showFeedbackListView(Context context)
```

**调用示例**

```java
RXFeedbackUI.showFeedbackListView(activity);
```
