## 创建玩家反馈

> **POST: ** `/v1/feedbackapi/player_feedback/create`
>
> **认证方式：** [AccessToken](/docs/开发者文档/入门指南/服务端接入须知)

### CURL 示例

```bash
curl --location --request POST '{{接口域名}}/v1/feedbackapi/player_feedback/create' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-accesstoken: {{登录token}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--header 'Content-Type: application/json' \
--data-raw '{
 "content":"",
 "phone":"",
 "attachments": [""],
 "tags": [""]
}'
```

### 请求参数（JSON）


| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| content | String | 是 | 反馈内容 |
| phone | String | 否 | 联系电话 |
| attachments | []String | 否 | 附件， 支持图片和视频 |
| tags | []String | 否 | 反馈标签 |


**请求示例**

```json
{
 "content":"",
 "phone":"",
 "attachments": [""],
 "tags": [""]
}
```

### 响应参数（JSON）

**HTTP 状态码：**`200 OK`

| 字段 | 类型 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 | 0 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 |  |

**响应示例**

```json
{"code": 0}
```

## 玩家反馈列表

> **认证方式：** [AccessToken](/docs/开发者文档/入门指南/服务端接入须知)

### CURL 示例

```bash
curl --location --request GET '{{接口域名}}/v1/feedbackapi/player_feedback/list?page=1&size=10' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-accesstoken: {{登录token}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}'
```

### 请求参数（JSON）


| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| page | Number | 是 | 第几页 |
| size | Number | 是 | 每页的条数 |


### 响应参数（JSON）

**HTTP 状态码：**`200 OK`

| 字段 | 类型 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |

| Data | 否 | 响应内容 |  |  |

#### Data


| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| page | Number | 是 | 第几页 |
| 0 | size | Number | 否 |
| 每页条数 | total | Number | 是 |
| 总数量 | list | []List | 否 |
| 响应内容 |  |  |  |


#### List


| 字段 | 类型 | 是否必填 | 说明 |

| id | Number | 是 | 唯一标识 |
| content | String | 是 | 反馈内容 |
| created_at | String | 是 | 反馈时间 |

| 是 | 1 待回复 1 已回复 | recover_at | String |
