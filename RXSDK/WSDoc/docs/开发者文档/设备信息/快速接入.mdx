在首次安装应用时 SDK 会根据规则生成设备码并保存，为保证设备码的唯一性首次生成后将一直读取缓存中的设备码。

**生成策略：**

- **iOS**：随机生成 uuid 存入 keychain 中，卸载重装设备码不会变，App 主体转让、越狱等导致 keychain 存储区域变更时会重新生成设备码。
- **Android**：根据 imei、AndroidID 等设备信息 hash 生成，正常情况设备码不会重复。卸载重装设备码不变；个别支持刷串码的手机型号会导致设备码改变。

## 获取设备码

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

**接口原型**

```objectivec
/**
 * 获取设备码
 */
- (NSString *)getDeviceCode;
```

**调用示例**

```objectivec
NSString *deviceCode = [[RXSDK sharedSDK] getDeviceCode];
```

</TabItem>

<TabItem value="android" label="Android">

**接口原型**

```java
public static String getDeviceCode();
```

**调用示例**

```java
String deviceCode = RXSDK.getDeviceCode();
```

</TabItem>

</Tabs>
