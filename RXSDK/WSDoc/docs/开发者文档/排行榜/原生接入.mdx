## 增加用户分数

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

**接口原型**

```objectivec
/**
 * 增加用户分数
 * @param rank_id 字符串本身带有类型信息，格式为：Flag_榜单容量_重置周期_自定义标识 必须
 * @param score 增加的分数值 必须
 */
- (void)addscoreWithRank_id:(NSString *)rank_id
 score:(NSInteger)source
 complete:(RequestComplete)complete;
```

**调用示例**

```objectivec
[[RXSDK sharedSDK] addscoreWithRank_id:@"" score:0 complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {

}];
```

</TabItem>

<TabItem value="android" label="Android">

**接口原型**

```java
void addScore(String rank_id, int score, RXRequestCallback callback);
```

**调用示例**

```java
RXSDK.getInstance().addScore(rank_id, score, jsonCallback);
```

</TabItem>

</Tabs>

### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| rank_id | String | 是 | 排行榜 ID，格式为：Flag_榜单容量_重置周期_自定义标识 |
| score | int | 是 | 增加的分数值 |

### 响应参数（JSON）

| 字段 | 类型 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 | 0 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 |  |

| 字段 | 类型 | 是否必填 | 备注 |

| 字段 | 类型 | 是否必填 | 说明 | 示例 |

#### DataO

| 字段 | 类型 | 是否必填 | 说明 |

## 获取排行榜列表

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

**接口原型**

```objectivec
/**
 * 获取排行榜列表
 * @param rank_id 字符串本身带有类型信息 必须
 * @param start_rank 获取排行榜开始排名。取值[1,榜单容量)。可以用于分页加载 必须
 * @param end_rank 获取排行榜结束排名。取值[1,榜单容量]。可以用于分页加载 必须
 */
- (void)getRankListWithRank_id:(NSString *)rank_id
 start_rank:(NSInteger)start_rank
 end_rank:(NSInteger)end_rank
 complete:(RequestComplete)complete;
```

**调用示例**

```objectivec
[[RXSDK sharedSDK] getRankListWithRank_id:@"" start_rank:1 end_rank:1 complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {

}];
```

</TabItem>

<TabItem value="android" label="Android">

**接口原型**

```java
void getRankList(String rank_id, int start_rank, int end_rank, RXRequestCallback callback);
```

**调用示例**

```java
RXSDK.getInstance().getRankList(rank_id, start_rank, end_rank, jsonCallback);
```

</TabItem>

</Tabs>

### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| rank_id | String | 是 | 排行榜 ID |
| start_rank | int | 是 | 获取排行榜开始排名，取值 [1, 榜单容量)，可用于分页加载 |
| end_rank | int | 是 | 获取排行榜结束排名，取值 [1, 榜单容量]，可用于分页加载 |

### 响应参数（JSON）

| 字段 | 类型 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 | 0 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 |  |
| [][Node](/docs/开发者文档/用户信息/获取指定用户信息) | 否 | 结果数组 |  |  |

#### Node

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| score | Number | 是 | 排行榜分数 |
| rank | Number | 是 | 排行榜排名 |
| user | [UserO](/docs/开发者文档/用户信息/获取指定用户信息) | 是 | 用户信息数据集 |

**响应示例**

```json
{
 "data": [
 {
 "score": 100,
 "rank": 1,
 "user": {
 "OpenID": "rxuSl4QZoNk0G1HY2-Za6GlO7wO-p_ej",
 "NickName": "user1"
 }
 },
 {
 "score": 90,
 "rank": 2,
 "user": {
 "OpenID": "rxuSl4QZoNk0G1HY2-Za6GlO7wO-p_ej",
 "NickName": "user2"
 }
 }
 ],
 "code": 0
}
```
