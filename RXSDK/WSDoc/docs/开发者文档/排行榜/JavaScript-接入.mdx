### Unity

### 对用户托管数据进行写数据操作

**托管数据的限制**
1. 每个 openid 所标识的微信用户在每个游戏上托管的数据不能超过 128 个 key-value 对。
2. 上报的 key-value 列表当中每一项的 key+value 长度都不能超过 1K(1024) 字节。
3. 上报的 key-value 列表当中每一个 key 长度都不能超过 128 字节。

#### 响应结构

成功 code 为 0


### Unity

### 获取当前用户托管数据当中对应 key 的数据

该接口只可在开放数据域下使用
[开放数据域使用指南](https://developers.weixin.qq.com/minigame/dev/guide/open-ability/opendata/basic.html)

#### 响应结构

| **字段** | **类型** | **备注** |
| ------------ | ------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| code | number | 0: 表示成功 |
| msg | string | 仅在 code 为非 0 时不为空 |
| data | KVData[] | 用户的托管 KV 数据列表， 结构参考 [微信小游戏 KVData](https://developers.weixin.qq.com/minigame/dev/api/open-api/data/KVData.html) |

**响应示例**

```json
{
    "code":0,
    "data":[
        {
            "key":"score",
            "value":"{\"wxgame\":{\"score\":16,\"update_time\": 1513080573},\"cost_ms\":36500}"
        }
    ]
}
```

### 拉取当前用户所有同玩好友的托管数据

该接口只可在开放数据域下使用
[开放数据域使用指南](https://developers.weixin.qq.com/minigame/dev/guide/open-ability/opendata/basic.html)

#### 响应结构

| **字段** | **类型** | **备注** |
| ------------ | ------------------ | ------------------------------------- |
| code | number | 0: 表示成功 |
| msg | string | 仅在 code 为非 0 时不为空 |
| data | UserGameData[] | code 为 0，返回同玩好友的托管数据 |

> UserGameData 结构说明

| **字段** | **类型** | **备注** |
| -------------- | ------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| avatarUrl | string | 用户的微信头像 url |
| nickname | string | 用户的微信昵称 |
| openid | string | 用户的 openid |
| KVDataList | KVData[] | 用户的托管 KV 数据列表， 结构参考 [微信小游戏 KVData](https://developers.weixin.qq.com/minigame/dev/api/open-api/data/KVData.html) |
