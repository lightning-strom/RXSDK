## SDK 集成




<Tabs groupId="platform">
<TabItem value="ios" label="iOS" default>

iOS依赖的相关SDK已通过脚本自动引用到工程中，您无需手动引用。受网络环境等因素影响，相关SDK有可能引用失败，所以在生成iOS工程后，您需要检查工程中的Podfile文件中的SDK名称，在Podfile.lock文件中是否存在，如果Podfile中的SDK名称在Podfile.lock中未存在，说明SDK未完全下载成功，您需要进入Podfile文件所在路径，执行以下命令安装SDK：
```objectivec
pod install 
```

## 增加用户分数

**接口原型**

```csharp

public void AddScore(string rank_id, int score,
 RequestResponseDelegate onResponse, RequestErrorDelegate onError);

```

### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| rank_id | string | 是 | 排行榜 ID |
| score | int | 是 | 增加的分数值 |

**调用示例**

```csharp
 public void OnAddScore()
 {
 RXRank.AddScore(_rankID, 80, RankResponseDelegate, RankErrorDelegate);
 }
```

### 响应结构

**HTTP 状态码：**`200 OK`

| 字段 | 类型 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 | 0 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 |  |

## 查询用户分数

**接口原型**

```csharp
 public void QueryUserRank(string rank_id, string open_id,
 RequestResponseDelegate onResponse, RequestErrorDelegate onError);
```

### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| rank_id | string | 是 | 字符串本身带有类型信息，格式为： Flag_榜单容量_重置周期_自定义标识（ flag 是一个 int64 位标记，用以扩展和规定绑定属性） |
| open_id | string | 是 | 目标用户 OpenID |

**调用示例**

```csharp
 public void OnQueryUserRank()
 {
 RXRank.QueryUserRank(_rankID, _openID, RankResponseDelegate, RankErrorDelegate);
 }
```

### 响应结构

**HTTP 状态码：**`200 OK`

| 字段 | 类型 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 | 0 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 | data |
| [DataO](/docs/开发者文档/用户信息/获取指定用户信息) | 否 | 结果数据集 |  |  |

#### DataO


| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| score | Number | 是 | 排行榜分数 |
| rank | Number | 是 | 排行榜排名 |
| user | [UserO](/docs/开发者文档/用户信息/获取指定用户信息) | 是 | 用户信息数据集 |


##### UserO


| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| openid | String | 是 | 用户望舒 OpenID |
| nickname | String | 是 | 用户昵称 |
| birthday | String | 否 | 用户生日日期 |
| remarks | String | 否 | 当前用户对其的备注 |
| avatar | String | 否 | 用户头像 |
| custom | String | 否 | CP 自定义信息 |
| time | Number | 否 | 关系形成时间戳（单位：秒） |
| sex | Number | 否 | 用户性别， 1:男； 0:女 |


## 获取排行榜列表

**接口原型**

```csharp
 public void GetRankList(string rank_id, int start_rank, int end_rank,
 RequestResponseDelegate onResponse, RequestErrorDelegate onError);
```

### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| rank_id | string | 是 | 字符串本身带有类型信息，格式为： Flag_榜单容量_重置周期_自定义标识（ flag 是一个 int64 位标记，用以扩展和规定绑定属性） |
| start_rank | int | 是 | 获取排行榜开始排名。取值[1,榜单容量)。可以用于分页加载 |
| end_rank | int | 是 | 获取排行榜结束排名。取值[1,榜单容量]。可以用于分页加载 |

**调用示例**

```csharp
 public void OnGetRankList()
 {
 RXRank.GetRankList(_rankID, 1, 100, RankResponseDelegate, RankErrorDelegate);
 }
```

### 响应结构

**HTTP 状态码：**`200 OK`

| 字段 | 类型 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 | 0 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 | data |
| [][Node](/docs/开发者文档/用户信息/获取指定用户信息) | 否 | 结果 数组结构 |  |  |

#### Node


| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| score | Number | 是 | 排行榜分数 |
| rank | Number | 是 | 排行榜排名 |
| user | [UserO](/docs/开发者文档/用户信息/获取指定用户信息) | 是 | 用户信息数据集 |
