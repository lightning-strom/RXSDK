> “排行榜”相关接口只能由 CP 方通过服务端接口调用，游戏方客户端仅支持数据上报

以下是 CP 服务端请求接口，需要准备好 `cp_id` `product_id` `channel_id` `cp_key` 等参数。

domain ：为产品对外域名

请求头：[望舒服务端请求头](/docs/开发者文档/入门指南/服务端接入须知)

## 创建排行榜

> **POST：** `/v1/social/serverapi/createrank`
>
> **认证方式:** **[CPSign](/docs/开发者文档/入门指南/服务端接入须知)**

### CURL 示例

```bash
curl --location --request POST '{{接口域名}}/v1/social/serverapi/createrank' \
--header 'ruixue-language: {{语言}}' \
--header 'ruixue-cpid: {{CPID}}' \
--header 'ruixue-productid: {{产品标识}}' \
--header 'ruixue-cpts: {{时间戳}}' \
--header 'ruixue-traceid: {{TraceID}}' \
--header 'ruixue-cpsign: {{请求签名}}' \
--header 'ruixue-devicecode: {{设备码}}' \
--header 'ruixue-channelid: {{渠道标识}}' \
--header 'ruixue-platformid: {{平台标识}}' \
--header 'Content-Type: application/json' \
--data-raw '{
 "rank_id":"0_100_168_weekly",
 "start":"2022-08-16T08:00:00+08:00",
 "destroy":"2022-08-17T08:00:00+08:00"
}'
```

### 请求参数（JSON）

| 字段 | 类型 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| rank_id | String | 是 | 最长 64 字节。字符串本身带有类型信息，格式为： Flag_榜单容量_持续时间(单位小时)_自定义标识（ flag 是一个 int64 位标记，用以扩展和规定绑定属性); 持续时间如果 &lt;=0 表示排行榜永久有效 | 0_100_168_weekly |
| start | String | 是 | 排行榜开始时间；格式为 RFC3339 | 2022-08-16T08:00:00+08:00 |
| destroy | String | 是 | 排行榜所有数据销毁时间；格式为 RFC3339 |  |
| 2022-08-17T08:00:00+08:00 |  |  |  |  |

此时间要大于 start+周期时间

**请求示例**

```json
{
 "rank_id":"0_100_168_weekly",
 "start":"2022-08-16T08:00:00+08:00",
 "destroy":"2022-08-17T08:00:00+08:00"
}
```

### 响应参数（JSON）

**HTTP 状态码：**`200 OK`

| 字段 | 类型 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 | 0 |
| msg | String | 否 | 响应信息，仅在 code 非 0 时返回 |  |

**响应示例**

```json
{"code": 0}
```
