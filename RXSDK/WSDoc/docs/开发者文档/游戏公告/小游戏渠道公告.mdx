## 获取公告列表

### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| limit | Number | 是 | 返回公告条数 数量范围 1-100 ，超过 100 则只返回最近 100 条 |
| callback | IMethodParams | 是 | 回调函数集合 |

> IMethodParams 说明

| 字段 | 备注 |
| --- | --- |
| complete | (data) => void |

complete ：为函数且必传， data 为结果数据

**调用示例**

```javascript
this.sdk.getAnnouncement(10, {
 complete(res) {
 console.log(res)
 }
})
```

### 响应结构(JSON)

| 参数 | 类型 | 备注 |
| --- | --- | --- |
| code | Number | 0 为成功 |
| msg | String | 失败信息 |
| data | [][Data](/docs/开发者文档/意见反馈/Unity-接入) |  |

#### data

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | Number | 公告 id |
| type | Number | 1 版本更新公告 3 常规公告 |
| timezone | Number | 时区 |
| start | String | 开始时间 |
| end | Start | 结束时间 |
| content_type | Number | 1 图文 2 图片 |
| is_popup | Number | 是否弹出 1 是 2 否 |
| title | String | 公告标题 |
| content | String | 图文时的内容 |
| images | []Images | 图片时的内容 |

##### images

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| image_url | String | 图片 url |
| link_url | String | 跳转地址 |
