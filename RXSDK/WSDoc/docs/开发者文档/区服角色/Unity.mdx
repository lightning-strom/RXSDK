Unity SDK 1.6.21 以上支持

## 上报区服角色

**调用示例**

```plaintext
RuiXueSdk.SetGameInfo("游戏角色 ID", "区服标识");
```

## 查询角色信息

登录后调用

**调用示例**

```plaintext
RuiXueSdk.SearchGameAccount(SearchGameAccountResponseDelegate, SearchGameAccountErrorDelegate);
```

### 响应参数（JSON）

**HTTP 状态码：**`200 OK`

| 字段 | 类型 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| code | Number | 是 | 响应状态码， 0 为成功，非 0 表示出错 | 0 |
| msg | String | 否 | 响应信息，仅在 code 为非 0 时不为空 | data |
| Data | 否 | 响应内容 |  |  |

#### Data

| 字段 | 类型 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| list | []Item | 是 | 角色列表 |  |

#### Item


| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| ~~~~ | region_tag | String | 是 |
| cp_role_id | String | 是 | 角色 id |
| extension | json | 否 | 扩展信息符合 json 格式的数据 |
| json | 否 | 扩展信息符合 json 格式的数据 |  |
