## SDK 集成

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

可通过 **pod** 方式接入 **RXAliCloudDNSSDK** 组件。

在需要使用功能的类中引用头文件 `#import <RXAliCloudDNSSDK/RXAliCloudDNSSDK.h>`

编辑 Podfile 文件，添加如下配置：

```objectivec
pod 'RXAliCloudDNSSDK'
```

</TabItem>

<TabItem value="android" label="Android">

:::tip[版本说明]
`version` 为 SDK 版本号（替换为实际版本号），最新版本请从 [更新日志](/docs/开发者文档/入门指南/更新日志/Android) 中查看。
:::

```groovy
implementation 'com.ruixue:ruixue_aliyun_dns:${version}'
```

在您的项目根目录中，打开 `build.gradle (Project)` 并添加以下存储库：

```groovy
allprojects {
 repositories {
 maven {
 url 'https://maven.aliyun.com/nexus/content/repositories/releases/'
 }
 }
}
```

</TabItem>

</Tabs>

## 设置 region 节点

如果 APP 需要在海外环境使用 HTTPDNS，为了提升解析效率，可以主动设置本 SDK 的启动服务节点。设置节点后，SDK 会使用该节点进行域名解析和随后的调度节点列表更新。

在 DNS 初始化前调用。

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

**接口原型**

```objectivec
/**
 * 指定region，指定后会读取该region对应配置作为初始化配置
 * @param region 需要指定的region，缺省为中国大陆
 */
- (void)setRegion:(NSString *)region;
```

</TabItem>

<TabItem value="android" label="Android">

**接口原型**

```java
/**
 * 指定region，指定后会读取该region对应配置作为初始化配置
 * @param region 需要指定的region，缺省为中国大陆
 */
public void setRegion(String region)
```

</TabItem>

</Tabs>

> region 说明

| region | 说明 |
| --- | --- |
| cn | 中国大陆 |
| hk | 中国香港 |
| sg | 新加坡 |
| de | 德国 |
| us | 美国 |

## 初始化

DNS 初始化应放在SDK 初始化之前。

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

**接口原型**

```objectivec
/**
 * 初始化方法
 * accountID appkey
 * secretKey 秘钥
 * debug 调试日志模式，YES开启，NO关闭，默认NO
 */
- (void)initWithAccountID:(int)accountID secretKey:(NSString *)secretKey debug:(BOOL)debug;
```

**调用示例**

```objectivec
- (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
 [[RXAliCloudDNSSDKService sharedSDK] setRegion:@"所需节点"];
 [[RXAliCloudDNSSDKService sharedSDK] initWithAccountID:your account id secretKey:@"your secretKey" debug:YES];
 return YES;
}
```

</TabItem>

<TabItem value="android" label="Android">

**接口原型**

```java
/**
 * @param context 应用上下文 3.7.22后添加
 * @param accountID accountID
 * @param secretKey 秘钥
 * @param isDebug 调试日志模式，true 开启，false 关闭，默认 false
 */
public void initAppID(Context context, String accountID, String secretKey, boolean isDebug)
```

**调用示例**

```java
AliCloudDnsManager.getInstance().setRegion("所需节点"); // 可选 默认国内
AliCloudDnsManager.getInstance().initAppID(context, "xxxx", "xxxxx", true);

String cpid = cpid;
String productid = productId();
String channelid = channelId();
RXSdkInitConfig rxSdkInitConfig = new RXSdkInitConfig(cpid, productid, channelid, urls, initCallback);
rxSdkInitConfig.setUseDNS(true);
RuiXueSdk.initialize(rxSdkInitConfig);
```

</TabItem>

</Tabs>

## 开启 DNS

在调用SDK 初始化设置时，将 **isUseDNS** 设置为 YES / true（已在上方调用示例中体现）。
