## SDK 集成

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

可通过 **pod** 方式接入 **RXTecentCloudDNSSDK** 组件。

在需要使用功能的类中引用头文件 `#import <RXTecentCloudDNSSDK/RXTecentCloudDNSSDK.h>`

编辑 Podfile 文件，添加如下配置：

```objectivec
pod 'RXTecentCloudDNSSDK'
```

</TabItem>

<TabItem value="android" label="Android">

:::tip[版本说明]
`version` 为 SDK 版本号（替换为实际版本号），最新版本请从 [更新日志](/docs/开发者文档/入门指南/更新日志/Android) 中查看。
:::

```groovy
implementation 'com.ruixue:ruixue_tencent_dns:${version}'
```

</TabItem>

</Tabs>

## 初始化

DNS 初始化应在SDK 初始化之前调用。

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

**接口原型**

```objectivec
/**
 * 初始化方法
 * appID app的Bundle ID
 * dnsID appkey
 * dnsKey 秘钥
 * debug 调试日志模式，YES开启，NO关闭，默认NO
 */
- (void)initWithAppID:(NSString *)appID dnsID:(int)dnsID dnsKey:(NSString *)dnsKey debug:(BOOL)debug;
```

**调用示例**

```objectivec
- (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
 [[RXTecentCloudDNSSDKService sharedSDK] initWithAppID:@"your appID" dnsID:your dnsID dnsKey:@"your dnsKey" debug:YES];
 return YES;
}
```

</TabItem>

<TabItem value="android" label="Android">

**接口原型**

```java
/**
 * @param context 应用上下文 3.7.32 后添加
 * @param dnsID dnsID
 * @param dnsKey dnsKey
 * @param isDebug 调试日志模式，true 开启，false 关闭，默认 false
 */
public void initAppID(Context context, String dnsID, String dnsKey, boolean isDebug)
```

**调用示例**

```java
TencentDnsManager.getInstance().initAppID(context, "xxx", "xxx", true);
```

</TabItem>

</Tabs>

## 开启 DNS

在调用SDK 初始化设置时，将 **isUseDNS** 设置为 YES / true。

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

```objectivec
RXSdkInitConfig *config = [[RXSdkInitConfig alloc] init];
config.productId = @"your product id";
config.channelId = @"your channel id";
config.cpId = @"your cpId";
config.baseUrlList = @[@"your base url"];
config.isUseDNS = YES;
[[RXService sharedSDK] initWithConfig:config complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
 if (!error) {
 NSLog(@"初始化成功");
 } else {
 NSLog(@"初始化失败");
 }
}];
```

</TabItem>

<TabItem value="android" label="Android">

```java
String cpid = cpid;
String productid = productId();
String channelid = channelId();
RXSdkInitConfig rxSdkInitConfig = new RXSdkInitConfig(cpid, productid, channelid, urls, initCallback);
rxSdkInitConfig.setUseDNS(true);
TencentDnsManager.getInstance().initAppID(context, "xxx", "xxxx", true);
RuiXueSdk.initialize(rxSdkInitConfig);
```

</TabItem>
