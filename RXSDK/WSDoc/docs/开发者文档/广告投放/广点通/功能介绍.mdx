## 望舒后台配置

### 应用管理

点击**信息流广告>工具管理>应用管理**，创建广点通应用。配置相关参数。

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1764826957552.png)

### 窗口期配置

点击**信息流广告>窗口期配置>回传配置**，开启 sdk 回传，配置相关三方参数。

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1764827035634.png)
