## 用户登陆

**接口原型**

```go
// IMSLogin ims 登陆接口
func (c *Client) IMSLogin(req *IMSLoginReq) (*IMSLoginResp, error)
```

### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| req | [IMSLoginReq](/docs/开发者文档/即时通讯/服务端接入/消息定义) | 是 | 消息结构 |

#### IMSLoginReq

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| UserID | string | 是 | CP 下的唯一标识符 |
| ProductID | string | 是 | 产品 ID |
| ChannelID | string | 是 | 渠道 ID |
| DeviceCode | string | 否 | 设备码 |
| CPID | uint32 | 是 | CPID |
| ClientType | int32 | 是 | 客户端类型 |

**调用示例**

```go
ack, err := ruixuego.GetDefaultClient().IMSLogin(&ruixuego.IMSLoginReq {
 UserID: "cpuserid-123456"
 ClientType: 256,
 ProductID: testAppID,
 ChannelID: testChannelID,
 DeviceCode: "aaaaaaaaaa",
 CPID: 1001,
 })
if err != nil { panic(err) }
```

### 响应结构

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| ack | [IMSLoginResp](/docs/开发者文档/即时通讯/服务端接入/消息定义) | 是 | 登陆信息 |
| err | error | 是 | 成功时 nil, 其他为错误 |

#### IMSLoginResp

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| AccessToken | string | 是 | 连接令牌 |
| AccessTokenExpire | int64 | 是 | 过期时间，毫秒 |
| RefreshToken | string | 是 | 刷新令牌 |
| RefreshTokenExpire | int64 | 是 | 刷新令牌过期时间，毫秒 |
| AESKey | string | 是 | AES 密钥，返回格式为 16 进制 64 位字符串，需解析成 32 Byte 密钥使用 |

## 发送消息

**接口原型**

```go
// IMSSendMessage 发送消息
func (c *Client) IMSSendMessage(req *IMSMessage) (*IMSMessageAck, error)
```

### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| req | [IMSMessage](/docs/开发者文档/即时通讯/服务端接入/消息定义) | 是 | 消息结构 |

#### IMSMessage

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| Option | int64 | 否 | [消息选项](/docs/开发者文档/即时通讯/服务端接入/消息定义)（位运算组合） |
| ClientType | int32 | 是 | [客户端类型](/docs/开发者文档/即时通讯/服务端接入/数据约束)，其是一个位运算结果值 |
| Type | int32 | 是 | [消息类型](/docs/开发者文档/即时通讯/服务端接入/消息定义) |
| SubType | int32 | 否 | 消息子类型，当 type 为 CP 自定义消息时有效， CP 请使用 [ 1 , 1 亿 ] |
| UUID | string | 是 | 消息发送者在发送时生成的唯一 ID ，用于去重 |
| Sender | string | 是 | 发送人 UserID |

注意：服务端发送消息时，该值应尽量为空，否则对于群聊或频道聊天要保证其已加入会话
R| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| eceivers | []string | 否 | 接收人列表，单聊必须为空；群聊表示 @ 用户列表；自定义单聊表示实际接收人 UserID 清单； |
| ConversationID | string | 是 | [会话 ID](/docs/开发者文档/即时通讯/服务端接入/数据约束) |
| ConvType | int32 | 是 | 会话类型，即会话 ID 两个 $ 中间的值 |
| ProductID | string | 是 | 产品 ID |
| ChannelID | string | 是 | 渠道 ID |
| Content | string | 是 | 消息内容 JSON 字符串。需要满足各个[消息格式](/docs/开发者文档/即时通讯/服务端接入/消息定义) |
| Ext | map[string]string | 否 | CP 扩展字段 |


**调用示例**

```go
ack, err := ruixuego.GetDefaultClient().IMSSendMessage(&ruixuego.IMSMessage{
 Option: 3,
 Type: 2,
 Sender: "testkk2012",
 UUID: "34567890991",
 ClientType: 256,
 ConversationID: "$4$worldChannel",
 ConvType: 4,
 ProductID: testAppID,
 ChannelID: testChannelID,
 Content: "{\"text\":\"22222\"}",
 Ext: map[string]string{"userData": "{\"game\" : \"22222\"}"},
 })
if err != nil { panic(err) }
```

### 响应结构

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| ack | [IMSMessageAck](/docs/开发者文档/即时通讯/服务端接入/消息定义) | 是 | 用户排行榜信息 |
| err | error | 是 | 成功时 nil, 其他为错误 |

#### IMSMessageAck

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| MsgID | string | 是 | 消息 id |
| UUID | string | 是 | 发消息时的 UUID |
| InboxID | int64 | 是 | 邮件在发消息玩家邮箱里的 id |
| MilliTS | int64 | 是 | 发消息时间戳 |

## 创建会话

**接口原型**

```go
// IMSCreateConversation 创建会话
func (c *Client) IMSCreateConversation(req *IMSCreateConvReq) error
```

### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| req | [IMSCreateConvReq](/docs/开发者文档/即时通讯/服务端接入/消息定义) | 是 | 会话 ID |

#### IMSCreateConvReq

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| ConversationID | string | 是 | 会话 ID |
| Option | int64 | 否 | [消息选项](/docs/开发者文档/即时通讯/服务端接入/消息定义)（位运算组合） |
| ConvType | int32 | 是 | 会话类型 |
| Creator | string | 是 | 会话创建者，即单聊的发起者或群的创建者。应为 CP 侧 玩家 id |
| Members | [][MemberInfo](/docs/开发者文档/即时通讯/服务端接入/消息定义) | 否 | 会话的参与者，可以包括创建者 |
| Ext | map[string]string | 否 | 该会话 CP 自定义扩展信息 |

##### memberinfo

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| UserID | string | 是 | 用户 id。 应为 CP 侧 玩家 id |
| Option | int64 | 否 | 用户的 [会话选项](/docs/开发者文档/即时通讯/服务端接入/消息定义)（位运算组合） |
| Ext | map[string]string | 否 | 该用户在会话内的自定义扩展信息 |

**调用示例**

```go
messages, err := ruixuego.GetDefaultClient().IMSCreateConversation(&IMSCreateConvReq{
 ConversationID : "$1$testA:testB",
 Option: 3,
 ConvType: 1,
 Creator: "creator",
 Members: []*MemberInfo{
 {
 UserID: "CP 用户 userid",
 Option: 3,
 Ext: map[string]string{"自定义key" : "user 自定义参数"},
 }
 },
 Ext: map[string]string{"自定义key" : "会话自定义参数"} })

if err != nil { panic(err)}
```

### 响应结构

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| err | error | 是 | 成功时 nil, 其他为错误 |
