## 产品包版本检查（通用）

<Tabs groupId="platform">

<TabItem value="js" label="JS">

### 参数说明

| **字段** | **类型**         | **是否必填** | **备注**     |
| ------------ | -------------------- | ---------------- | ---------------- |
| params   | ICheckAppVersion | 是           | 参数         |
| callback | IMethodParams    | 是           | 回调函数集合 |

> ICheckAppVersion 说明

| **字段**      | **类型** | **是否必填** | **备注**                           |
| ----------------- | ------------ | ---------------- | -------------------------------------- |
| clientversion | string   | 是           | 客户端版本号， 3 段或 4 段         |
| devicecode    | string   | 是           | 客户端设备码，没有传唯一值         |
| region        | number   | 否           | 地区码， 默认 0                    |
| type          | string   | 否           | 脚本类型，默认 js， 可选 lua， u3d |
| format        | string   | 否           | 输出文件后缀，默认 json，可选 lua  |

> IMethodParams 说明

| **字段** | **备注**                                                  |
| ------------ | ------------------------------------------------------------- |
| complete | (data) => voidcomplete：为函数且必传，data 为结果数据 |

**调用示例**
```javascript
sdk.checkAppVersion(
  {
    type: "js",
    format: "json",
    devicecode: "test",
    clientversion: "1.0.1.0",
    region: 150000,
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);
```

</TabItem>

### 参数说明

| **字段** | **类型**      | **是否必填** | **备注**     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params   | ICheckVersion | 是           | 参数         |
| callback | IMethodParams | 是           | 回调函数集合 |

> ICheckVersion 说明

| **字段**      | **类型** | **是否必填** | **备注**                                 |
| ----------------- | ------------ | ---------------- | -------------------------------------------- |
| clientversion | string   | 是           | 客户端版本号， 3 段或 4 段               |

| region        | number   | 否           | 地区码， 默认 0                          |
| type          | string   | 否           | 脚本类型，默认 js， 可选 lua， u3d       |
| format        | string   | 否           | 输出文件后缀，默认 json，可选 lua        |
| games         | object   | 否           | key 客户端游戏 id，value 客户端游戏版本  |
| activities    | object   | 否           | key 客户端活动别名，value 客户端活动版本 |

> IMethodParams 说明

| **字段** | **备注**                                                  |
| ------------ | ------------------------------------------------------------- |

```javascript
sdk.checkVersion(
  {
    type: "js",
    format: "json",
    devicecode: "test",
    clientversion: "1.0.1.0",
    region: 150000,
    games: { 5157686: 0 },
    activities: { cc: 0 },
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);
```

### 参数说明

| **字段**      | **类型** | **是否必填** | **备注**                                 |
| ----------------- | ------------ | ---------------- | -------------------------------------------- |
| clientversion | string   | 是           | 客户端版本号， 3 段或 4 段               |
| region        | number   | 否           | 地区码， 默认 0                          |
| type          | string   | 否           | 脚本类型，默认 js， 可选 lua， u3d       |
| games         | object   | 否           | key 客户端游戏 id，value 客户端游戏版本  |
| activities    | object   | 否           | key 客户端活动别名，value 客户端活动版本 |

**调用示例**

```csharp
using System;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.UI;
using RuiXue;
using RuiXue.VersionCheck;

#if UNITY_WEBGL
using RuiXue.MiniGame.WeiXin;
#endif

public class RuiXueWeiXinMiniGameDemo : MonoBehaviour {
    public void OnCheckVersion()
    {
        var games = new Dictionary<string, int>() { { "123", 123 } };
        var activities = new Dictionary<string, int>() { { "test", 123 } };
        RXVersionCheck.CheckUpdateApp("1.0.1", "0", "u3d", games, activities,
            OnResponse, OnError);
    }
}
```

```javascript
    format: "json",
    gameid: 1041697,
    gameversion: 0,
  },
  {
    complete: (data) => {
      console.log(data);
    },
  }
);
```
