## 登录

**启动路径参数注意事项**

SDK 登录内部会从启动路径上获取参数，用于裂变和导量效果的数据分析，所以 CP 如果需要自定义分享需要拼接以下参数，分享参数来自 `getShareData` 接口，并且注意除了 CP 自定义分享场景，不要使用以下参数！！！

| 字段 | 类型 | 备注 |
| --- | --- | --- |
| type | string | rx |
| user_source | string | share ｜ guide ｜ transmits |

`share` 分享 `guide` 导量 `transmits` 自定义透传参数

> 分享相关字段

| 字段 | 类型 | 备注 |
| --- | --- | --- |
| landing_id | string | 广告推广来源信息 |
| trigger_id | string | 埋点 ID |
| trigger_tag | string | 埋点唯一标识 |
| trigger_type | string | 埋点类型 |
| material_type | string | 分享素材类型 |
| material_id | string | 分享素材类型 |
| strategy_type | string | 策略类型 |
| strategy_id | string | 策略唯一 ID |
| share_time | string | 分享时间 |
| share_type | string | mini ，游戏客户端自定义的分享类型 |
| inviter_region | string | 分享者所在地区编码 |
| inviter_openid | string | 分享者的望舒 openid |
| inviter_productid | string | 分享者的产品 ID, 若为空, 则通行证通过 inviter_openid 获取关联信息 |
| inviter_channelid | string | 分享者的渠道 ID, 若为空, 则通行证通过 inviter_openid 获取关联信息 |
| inviter_subchannelid | string | 分享者的子渠道 ID, 若为空, 则通行证通过 inviter_openid 获取关联信息 |

> 导量相关字段

| 字段 | 类型 | 备注 |
| --- | --- | --- |
| guide_platform | string | 导量来源游戏平台 |
| guide_app | string | 导量来源游戏 app 标识 |

> transmits 字段

transmits 的数据为透传参数，规则需要满足 user_source=transmits ，除 user_source=transmits 外其他拼接的参数登录后将原样返回。

示例： `https://xxx.html?user_source=transmits&a=b&c=d` 登录成功数据会新增字段 `user_transmits:{"a":"b", "c":"d"}`

### 获取验证码

优先根据指定 email 或 phone 发送验证码；否则根据当前登录的手机或者邮箱账号发送验证码。

#### 参数说明

| --- | --- | --- | --- |

> purpose 说明

| 字段 | 备注 |
| --- | --- |

> IMethodParams 说明

| 字段 | 备注 |
| --- | --- |
| complete | (data) => void |

#### 调用示例


#### 响应结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| age | Number | 用户年龄，根据实名信息获取。 |
| sex | Number | 性别。0 表示女性， 1 表示男性。 |
| user_state | Number | 用户状态定义, 0 为正常用户。为正数时，使用各位编码用户的不同状态（以下表述中，第 0 位表示最低位）:第 0 位: 为 1 表示玩家已提交注销申请第 1 位: 为 1 表示已注销。可以是客服同意玩家的注销申请，也可以是客服直接在后台操作将账号注销。第 2 位: 为 1 表示已封停。 |
| attr | Number | 账号状态标记，使用位运算构成。参考下文 [attr 标记说明](/docs/开发者文档/登录-通行证/服务端接入/服务端-API) |
| openid | String | 望舒用户 OpenID。 |
| external_openid | String | 三方 openid |
| external_unionid | String | 三方 unionid |
| wx_unionid | String | [DEPRECATED] 三方 unionid |
| mobile_phone | String | 手机号 |
| nickname | String | 昵称 |
| avatarurl | String | 头像 |
| idCard | String | 身份证号 |
| realName | String | 姓名 |

##### attr标记

attr 标记，由以下标记位构成

| 标识 | 备注 |
| --- | --- |
| 0 | 是否已通过望舒完成实名认证， 1 表示已实名。 |
| 1 | 用户当前是否有绑定手机号， 1 表示有绑定。 |
| 2 | 用户当前是否有绑定邮箱， 1 表示有绑定。 |
| 3 | 用户当前是否有已设置密码的登录凭证， 1 表示有。 |
| 4 | 用户是否通过望舒完成实名认证， 1 表示是。 |

### 获取用户信息

创建获取用户信息的按钮，通过绑定 userInfoButton.onTap(callback) 事件，点击获取挂有用户信息的对象

#### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| params | IContactButton | 是 | 参数 |
| callback | IMethodParams | 是 | 回调函数集合 |

> IContactButton 说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| type | string | 是 | 按钮的类型，取值 image 或 text。image 对应图片按钮， text 对应文本按钮 |
| image | string | 否 | 按钮的背景图片， type 为 image 时必填。仅支持本地图片 |
| text | string | 否 | 按钮上的文本内容， type 为 text 时有效 |
| style | object | 是 | 按钮的样式 |

> style 说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| left | number | 是 | 左上角横坐标 |
| top | number | 是 | 左上角纵坐标 |
| width | number | 是 | 宽度 |
| height | number | 是 | 高度 |
| backgroundColor | string | 是 | 背景颜色 |
| borderColor | string | 是 | 边框颜色 |
| borderWidth | number | 是 | 边框宽度 |
| borderRadius | number | 是 | 边框圆角 |
| textAlign | string | 是 | 文本的水平居中方式 |

"left" / "center" / "right"
fontSize
| number | 是 | 字号 |
| --- | --- | --- |
| lineHeight | number | 是 |
| 文本的行高 | textColor | string |
| 是 | 文本颜色 |  |

> IMethodParams 说明

| 字段 | 备注 |
| --- | --- |
| complete | (data) => void |

complete ：为函数且必传， data 为结果数据

**调用示例**

```javascript
sdk.getUserInfo(
 {
 type: "text", // image | text
 // image: "./test.jpg", //仅支持本地图片，type为image时生效
 text: "我是一个按钮", //仅在type等于text时生效
 style: {
 //控制按钮的样式
 left: 20, //左上角横坐标
 top: 40, //左上角纵坐标
 width: 150, //宽度
 height: 150, //高度
 lineHeight: 40, //文本的行高
 backgroundColor: "#ffffff", //背景颜色
 textAlign: "center", //文本的水平居中方式
 fontSize: 16, //字号
 borderRadius: 4, //边框圆角
 borderColor: "#ffffff", //边框颜色
 borderWidth: 1, //边框宽度
 textColor: "#ffffff", //文本颜色
 },
 },
 {
 complete: (btnInstance) => {
 //返回一个按钮的实例用于控制按钮
 function listenUserInfoBtnTap(res) {
 console.log(res)
 }
 btnInstance.onTap(listenUserInfoBtnTap);
 },
 }
);
```

#### 响应结构

返回一个 [userInfoButton](https://smartprogram.baidu.com/docs/game/api/openApi/userInfo/#swan-createUserInfoButton) 对象， 方法如下：

| 方法 | 备注 |
| --- | --- |
| onTap(function callback) | 监听按钮点击事件 |
| offTap(function callback) | 移除 onTap 绑定的监听函数 |
| destroy() | 销毁按钮 |
| show() | 显示按钮 |
| hide() | 隐藏按钮 |
