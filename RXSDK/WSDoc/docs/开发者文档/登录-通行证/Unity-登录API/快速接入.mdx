"非法注册（限制代码1）" code : 312232 为 注册ip限制，默认开启，同一ip默认1小时注册账号不能超过2个，如有需求请联系商务添加ip白名单或调整限制条件。

### 注册

**接口原型**

```csharp
public void Register(string username, string password, string captchaCode, Dictionary<string, object> ext, 
            RequestResponseDelegate onResponse, RequestErrorDelegate onError);
```

**参数说明**



| **字段**     | **类型**                                                 | **是否必填** | **说明**                                                                         |
| ------------ | -------------------------------------------------------- | ---------------- | -------------------------------------------------------------------------------- |
| username     | string                                                   | 是               | 用户名                                                                           |
| password     | string                                                   | 是               | 密码                                                                             |
| captcha_code | string                                                   | 否               | 使用 `sendCaptcha` 接口获取                                                        |
| ext          | Dictionary                                               | 否               | 扩展参数                                                                         |

**调用示例**

```csharp
    private void OnRegister()
    {
        Dictionary<string, object> dic = new();
        dic.Add("nickname", "dfasf");
        dic.Add("avatarUrl", "www.baidu.com");
        dic.Add("sex", 1);
        RXLogin.Register("xiaohai3333", "1122232wewe", "", dic, RegisterResponseDelegate, RegisterErrorDelegate);

    private void RegisterResponseDelegate(string data)
    {
        LogUtil.Log("EventManager", $"OnRegister Response : {data}");
    }

    private void RegisterErrorDelegate(string error)
    {
        LogUtil.Log("EventManager", $"OnRegister Error : {error}");
    }
```

}

### 登录

**接口原型**

```csharp
public void Login(string loginType, string username, string password, string captchaCode, string loginOpenId, 
            Dictionary<string, object> ext, string[] signFields, object migrateArgs, 
            RequestResponseDelegate onResponse,RequestErrorDelegate onError);
```

#### 参数说明

&gt; Map 结构说明

| **字段**     | **类型**                                                 | **是否必填**  | **说明**                                                                                                                                                                                                                                                                                                                                                               |
| ------------ | -------------------------------------------------------- | ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| loginType    | string                                                   | 是               | 可用方式，参照下面登录方式说明                                                                                                                                                                      
| username     | string                                                   | 否               | 用户名
| password     | string                                                   | 否               | 密码
| captchaCode  | string                                                   | 否               | 验证码
| loginOpenId  | string                                                   | 否               | 二次登录loginOpenId
| ext          | Dictionary&lt;string, object&gt;                               | 否               | 额外参数
| signFields   | string[]                                                 | 否               | 指定对登录成功后返回的特定字段, 使用 CPKEY 计算签名. CP 服务器可重新计算签名并与登录返回的签名比对, 作为对瑞雪登录数据的校验. 支持的字段包括: nickname, avatar, openid, region, sex, age, 计算签名的逻辑会对指定字段进行排序, 此处传参与顺序无关.
| migrate_args | 任意合法的 json 类型, 比如 string, number, array, object    | 否               | 账号迁移用的参数, 调用 CP account-query 及 account-queryandbind 接口时透传给 CP.                                                                                                                                                                    |

* ( ) ios::init1
* ( ) android::init2

### 设置密码等级
::: tip
默认等级为 strong
:::
**接口原型**

```csharp
/// <summary>
/// 设置密码等级
/// </summary>
/// <returns>type 密码强度等级枚举</returns>
public static void SetPasswordStrength(RXPasswordStrength type);
```

**type 说明**

| **字段**  | **说明**                                                                         |
| ----------------- | --------------------------------- |
| Default      | 6-32 位任意字符   |
| Custom      | 自定义密码正则  |
| Average      | 简易密码， 6-32 位任意字符 |
| Strong      | 强密码，  6-32 位，包含数字+字母+特殊符号  |


**调用示例**

```csharp
RuiXueSdk.SetPasswordStrength(RXPasswordStrength.Strong);
```

### 获取验证码（发送验证码）
::: tip
获取验证码需填写对应意图 purpose。
type 和 target 需对应，否则无法接收验证码。
target 传空或 nil 默认为当前绑定的手机或邮箱。
:::

**接口原型**

```csharp
public void SendCaptcha(CaptchaType type, string target, string purpose, RequestResponseDelegate onResponse, RequestErrorDelegate onError);
```

#### 参数说明

&gt; Map 结构说明

| **字段** | **类型** | **是否必填** | **备注**                               |
| -------- | -------- | ------------ | -------------------------------------- |
| email    | String   | 否           | 接收验证码的邮箱地址，邮箱手机号二选一 |
| phone    | String   | 否           | 接收验证码的手机号，邮箱手机号二选一   |
| purpose  | String   | 是           | 验证码的用途                           |

&gt; `purpose` 字段值 验证码用途说明

| **字段**    | 备注     |
| ----------- | -------- |
| register    | 注册     |
| bindphone   | 绑定手机 |
| unbindphone   | 解绑手机 |
| resetpwd    | 重置密码 |
| bindemail   | 绑定邮箱 |
| unbindemail   | 解绑邮箱 |
| login       | 登录     |
| setpwd      | 设置密码 |

**调用示例**

```csharp
    public void OnSendCaptcha()
    {
        RXLogin.SendCaptcha(CaptchaType.CaptchaType_phone, "18243088053", "login",
             SendCaptchaResponseDelegate, SendCaptchaErrorDelegate);
    }

    private void SendCaptchaResponseDelegate(string data)
    {
        LogUtil.Log("EventManager", $"OnSendCaptcha Response : {data}");
    }

    private void SendCaptchaErrorDelegate(string error)
    {
        LogUtil.Log("EventManager", $"OnSendCaptcha Error : {error}");
    }
```

#### 响应结构

```json
{
    "code": 0,
    "data": {
        "interval": 60,
        "surplus": 60
    }
}
```

### 校验验证码

::: tip
用途和手机号或邮箱需要和调用发送验证码时一致。
:::

**接口原型**

```csharp
public void VerifyCaptcha(CaptchaType type, string target, string purpose, string captcha_code, 
    RequestResponseDelegate onResponse, RequestErrorDelegate onError);
```

#### 参数说明

| **字段** | **类型**    | **是否必填** | **备注**                                                        |
| -------- | ----------- | ------------ | --------------------------------------------------------------- |
| type     | CaptchaType    | 是           | 验证码类型                                                      |
| target   | string         | 是           | 发送的目标（手机或邮箱），传空或 nil 默认为当前绑定的手机或邮箱 |
| purpose  | string         | 是           | 短信意图                                                        |
| captcha_code  | string    | 是           | 验证码                                                       |

&gt; type 说明

| **字段**          | **备注** |
| ----------------- | -------- |
| CaptchaType_email | 邮箱     |
| CaptchaType_phone | 手机     |

&gt; `purpose` 字段值 验证码用途说明

| **字段**    | 备注     |
| ----------- | -------- |
| register    | 注册     |
| bindphone   | 绑定手机 |
| unbindphone   | 解绑手机 |
| resetpwd    | 重置密码 |
| bindemail   | 绑定邮箱 |
| unbindemail   | 解绑邮箱 |
| login       | 登录     |
| setpwd      | 设置密码 |

**调用示例**

```csharp
    public void OnVerifyCaptcha()
    {
        RXLogin.VerifyCaptcha(CaptchaType.CaptchaType_phone, "18243088053", "login", "1111", 
            VerifyCaptchaResponseDelegate, VerifyCaptchaErrorDelegate);
    }

    private void VerifyCaptchaResponseDelegate(string data)
    {
        LogUtil.Log("EventManager", $"VerifyCaptcha Response : {data}");
    }

    private void VerifyCaptchaErrorDelegate(string error)
    {
        LogUtil.Log("EventManager", $"VerifyCaptcha Error : {error}");
    }
```

#### 响应结构





不返回 data 信息，验证码不正确会直接返回相应的错误。

```json
{
    "code": 0
}
```
