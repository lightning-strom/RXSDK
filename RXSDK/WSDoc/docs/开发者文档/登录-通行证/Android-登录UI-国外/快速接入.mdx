## 登录

### 集成海外渠道库


:::tip[版本说明]
`version` 为 SDK 版本号（替换为实际版本号），最新版本请从 [更新日志](/docs/开发者文档/入门指南/更新日志/Android) 中查看。
:::

```groovy
implementation 'com.ruixue:rxsdk_overseas:${version}'
```

"非法注册（限制代码 1 ）" code : 312232 为 注册 ip 限制，默认开启，同一 ip 默认 1 小时注册账号不能超过 2 个，如有需求请联系商务添加 ip 白名单或调整限制条件。"非法注册（限制代码 2 ）" code : 312232 为 注册设备限制，默认关闭，同一设备 x 小时注册账号不能超过 x 个，如有需求请联系商务开启。

### 登录弹窗

设置为登录后强制实名认证时登录成功的数据将在实名认证后返回，并且不会返回实名认证的结果，只会在 UI 上体现实名认证成功。如需要获取实名认证回调数据，请关闭登录后强制实名认证设置，并单独调用实名认证 UI。

```java
/**
```

#### 参数说明

> RXLoginUIModel 结构说明

| 字段 | 类型 | 是否必填 | 备注 |

| loginMethods | Array | 否 | 登录方式，默认读取望舒后台配置，没配置则需要手动传入 |
| setPrivacies | Array | 否 | 协议地址，顺序 0 为用户协议， 1 为隐私协议。默认读取望舒后台配置，没配置则需要手动传入 |

| setLoginContinue | bool | 否 | 如果账号在注销中是继续登录还是退出登录, true 继续登录， false 退出登录，默认 false |
| setCustomParams | Map&lt;String, Object> | 否 | 自定义参数 |
| googleClientid | String | 否 | google 登录客户端秘钥，默认读取望舒后台配置，没配置则需要手动传入 |

==使用扩展方式请注意， requestParams 为 retrun block ， params 会将手机号或邮箱，密码等参数返回，由客户端处理业务逻辑， SDK 会根据 return 的 needBreak 参数决定是否继续执行。
