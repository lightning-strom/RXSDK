## 登录

"非法注册（限制代码 1 ）" code : 312232 为 注册 ip 限制，默认开启，同一 ip 默认 1 小时注册账号不能超过 2 个，如有需求请联系商务添加 ip 白名单或调整限制条件。"非法注册（限制代码 2 ）" code : 312232 为 注册设备限制，默认关闭，同一设备 x 小时注册账号不能超过 x 个，如有需求请联系商务开启。

#### 参数说明

> LoginUIConfig 结构说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| loginTypes | Array | 否 | 登录方式，默认读取望舒后台配置，没配置则需要手动传入 |
| privacies | Array | 否 | 协议地址，顺序 0 为用户协议， 1 为隐私协议。默认读取望舒后台配置，没配置则需要手动传入 |
| privacieTitles | Array | 否 | 协议显示名称，顺序 0 为用户协议， 1 为隐私协议。默认读取望舒后台配置，没配置则需要手动传入 |

| isHistoryViewEnable | bool | 否 | 是否展示登录历史弹窗， YES 展示， NO 不展示，默认 YES。 注： SDK 会记录已登录的账号记录，下次调用会展示登录历史弹窗 |

| needRealAuth | bool | 否 | 未实名用户登录成功后是否需要强制实名认证，默认强制。 注：强制实名后登录数据将在实名认证成功后返回。 |

| isQuickButtonBarVisible | bool | 否 | 是否显示底部快速登录按钮，默认显示。 |
| isShowDeregister | bool | 否 | 处于注销中的用户登录后是否显示注销窗口，默认不显示 |
| customParams | Map&lt;String, Object> | 否 | 自定义参数 |

使用后台配置: 登录方式，以及对应平台登录密钥，等其它参数可在后台配置。

```csharp

 public void LoginResponseDelegate(string data)

```

自定义配置：方法调用时配置相关参数，会覆盖后台配置。

```csharp
 public LoginUIConfig GetLoginUIConfig(bool isCaptcha, bool isPhone, bool isQuick, bool withOther)
 {
 LoginUIConfig loginUIConfig = new()
 {
 needRealAuth = false,
 isHistoryViewEnable = isQuick,

 logoImage = LoadImage(),
 };

 List<string> privacieTitles = new List<string>
 {
 "用户协议",
 "隐私协议",
 "儿童隐私"
 };
 loginUIConfig.privacieTitles = privacieTitles;

 List<string> privacies = new List<string>
 {
 "http://rxapi.jilinhaiqi.com/static/landing/#/v1/legal/terms/100/00001",
 "https://rxapi.jilinhaiqi.com/static/landing/#/v1/legal/terms/ccc/jkldajfljalsdfj/00001?lang=zh",
 "http://rxapi.jilinhaiqi.com/static/landing/#/v1/legal/terms/100/00001"
 };
 loginUIConfig.privacies = privacies;
 if (withOther)
 {
 List<string> loginTypes = new List<string>
 {
 LoginMethod.FaceBook,
 LoginMethod.Google,
 LoginMethod.Line,
 LoginMethod.Guest,
 LoginMethod.Username
 };
 loginUIConfig.loginTypes = loginTypes;
 }
 return loginUIConfig;
 }

 public void OnLoginUI()
 {
 RXLoginUIOverSeas.LoginUI(GetLoginUIConfig(true, true, true, true), LoginResponseDelegate, LoginErrorDelegate);
 }
```

无论使用后台配置，或者自定义配置，需要在望舒后台配置对应登录方式和相应平台要求的密钥。

LoginUIConfig 各个字段配置解释，请看 SDK 中 LoginUIConfig.cs 类代码注释。
