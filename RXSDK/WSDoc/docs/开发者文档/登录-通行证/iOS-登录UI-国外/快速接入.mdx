## 准备工作

## SDK 集成

接入请前先做好准备工作。

可通过 pod 方式接入通行证 UIKit 组件，并使用通行证 UIKit 相关功能。

在需要使用功能的类中引用头文件#import &lt;RXUIKit_OS/RXUIKit_OS.h>

编辑 Podfile 文件，添加如下配置：

```objectivec
pod 'RXOSUIKit'
```

## 初始化

在 [SDK 初始化方法](/docs/开发者文档/性能分析/GPM-SDK接入/快速开始) 之前调用。

**接口原型**

```objectivec tab={"label":"接口原型"}
/**
 * 初始化
 */
- (void)regist;
```

```objectivec tab={"label":"调用示例"}
[[RXOSUIKitService sharedSDK] regist];
```

### 登录回调

登录结果通过 **delegate** 或 **block** 方式进行回调，两种方式数据结构一致，推荐使用 **block** 方式。

注意：指定了 delegate 必须要实现，否则会引起闪退问题，不指定则不用实现。

**delegate** 方式实现如下：

在需要接收回调的类中添加代理，并指定接受者实现代理方法。

`<RXOSUILoginDelegate>`

**接口原型**

```objectivec tab={"label":"接口原型"}
/**
 * 登录回调
 * @param response 返回数据，登录失败返回nil
 * @param error 错误返回，登录成功返回nil
 */
- (void)rxu_LoginCallBackWithResponse:(NSDictionary * _Nullable)response error:(RX_CommonRequestError *)error;
```

```objectivec tab={"label":"调用示例"}
- (void)rxu_LoginCallBackWithResponse:(NSDictionary *)response error:(RX_CommonRequestError *)error
{
 if (!error) {
 NSLog(@"%@",response);
 }else{
 NSLog(@"%@",error.responesObject);
 }
}
```
#### 响应结构

请参考 [服务端登录 API](/docs/开发者文档/用户信息/获取指定用户信息)响应结构

### 忘记密码

**UI 示例**

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/passportUI/CVzcb8xSJoaLLexU7xjcttPpnGK.png)

**接口原型**

==使用扩展方式请注意， requestParams 为 retrun block ， params 会将手机号或邮箱，密码等参数返回，由客户端处理业务逻辑， SDK 会根据 return 的 needBreak 参数决定是否继续执行。

详情请参考调用示例。==

```objectivec

/**
 * 忘记密码
 */
- (void)getBackPasswordWithComplete:(void(^)(NSDictionary *response, RX_CommonRequestError *error))complete;

/**
 * 忘记密码 扩展方式
 * @param params 页面配置信息
 * ！username 默认填充的账号 #NSString类型
 * ！account_type 账号类型提示 （1-通用提示 ，2-手机号提示，3-邮箱提示 [可选 默认 2]） #NSInteger类型
 * ！password_hint 输入密码提示文本 #NSString类型
 * @param requestParams 回调函数
 * ！params 会将手机号或邮箱，密码等参数返回，由客户端处理业务逻辑，SDK会根据 return 的 needBreak 参数决定是否继续执行
 * 详情请参考文档示例
 */
- (void)getBackPasswordWithParams:(NSDictionary *)params
 requestParams:(NSMutableDictionary *(^)(NSMutableDictionary *params))requestParams
 complete:(void(^)(NSDictionary *response, RX_CommonRequestError *error))complete;
```

#### 参数说明

> params 结构说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| username | NSString | 否 | 默认填充的账号。 |
| account_type | int | 否 | 账号类型提示 （ 1-通用提示 ， 2-手机号提示， 3-邮箱提示 [默认 2]）。 |
| password_hint | NSString | 否 | 输入密码提示文本。海外需要自行处理国际化。 |

**调用示例**

```objectivec tab={"label":"接口原型"}
[[RXOSUIKitService sharedSDK] getBackPasswordWithComplete:^(NSDictionary * _Nonnull response, RX_CommonRequestError * _Nonnull error) {
 if (!error) {
 NSLog(@"%@",response);
 }else{
 NSLog(@"%@",error.responesObject);
 }
}];

// 扩展方式
NSDictionary *dic = @{@"username" : @"",
 @"account_type" : @(1),
 @"password_hint" : @"请输入密码"};
[[RXOSUIKitService sharedSDK] getBackPasswordWithParams:dic requestParams:^NSMutableDictionary * _Nonnull(NSMutableDictionary * _Nonnull params) {
 NSLog(@"params = %@", params);
 NSMutableDictionary *dic = [NSMutableDictionary dictionaryWithDictionary:params];
 // 会将手机号或邮箱，密码等参数返回，由客户端处理业务逻辑，SDK会根据 return 的 needBreak 参数决定是否继续执行
 // needBreak = YES 为 不继续执行
 // needBreak = NO或不传 为 继续执行
 // [dic setValue:@YES forKey:@"needBreak"];
 return dic;
} complete:^(NSDictionary * _Nonnull response, RX_CommonRequestError * _Nonnull error) {
 if (!error) {
 NSLog(@"%@",response);
 }else{
 NSLog(@"%@",error.responesObject);
 }
}];
```

```json tab={"label":"响应示例"}
{
 "code": 0
}
```

| game_user_id | NSString | 用户的游戏 id ，不传在望舒后台不会账号注销页面不显示游戏侧的用户 id |
| nickname | NSString | 用户昵称 |
| head_img_url | NSString | 用户头像 |
| queue_name | NSString | 在望舒客服系统设置的接入点名称 不填写默认为 default |
| setConfigParams | NSDictionary | 用户中心配置，默认读取望舒后台配置 |
| setSyncInfoEnable | BOOL | 用户中心是否展示同步信息按钮， YES 为展示， NO 为不展示，默认不展示，用于同步三方信息 |

> setConfigParams 说明

| 字段 | 类型 | 备注 |
| --- | --- | --- |
| btns | NSArray | 配置用户中心入口 |

> btns 说明

| 字段 | 备注 |
| --- | --- |
| real_name | 实名认证 |
| privacy_policy | 隐私政策 |
| binding_phone | 绑定手机 |
| binding_email | 绑定邮箱 |
| acount_cancel | 账号注销 |
| change_pwd | 修改密码 |

**调用示例**

```objectivec
RXOSUserCenterConfig *config = [[RXOSUserCenterConfig alloc] init];
config.game_user_id = @"游戏 id";
config.nickname = @"游戏昵称";
config.queue_name = @"客服接入节点";
config.setConfigParams = @{@"btns" : @[
 @"real_name",
 @"privacy_policy",
 @"acount_cancel",
 @"phone_management",
 @"change_pwd"
]};
[[RXOSUIKitService sharedSDK] userCenterWithConfig:config complete:^(NSDictionary * _Nonnull response, RX_CommonRequestError * _Nonnull error) {
 if (!error) {
 NSLog(@"%@",response);
 }else{
 NSLog(@"%@",error.responesObject);
 }
}];

// 关闭用户中心
[[RXOSUIKitService sharedSDK] closeUserCenter];
```
