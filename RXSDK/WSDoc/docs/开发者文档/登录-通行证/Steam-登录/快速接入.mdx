## 望舒通行证API

### 注册

**接口原型**

```csharp
void Register(RegisterArgs args, Actionint, object, string> callback)
```

**参数说明**

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| username | string | 是 | 用户名 |
| password | string | 是 | 密码 |
| nickname | string | 否 | 昵称 |
| captcha_code | string | 否 | 使用 `sendCaptcha` 接口获取 |
| avatarUrl | string | 否 | 头像地址 |
| user_attrs | object | 否 | 设置大数据用户属性，仅对本次登录新注册的用户有效 |
| sex | integer | 否 | 性别,1:男,0:女 |
| migrate_args | 任意合法的 json 类型, 比如 string, number, array, object | 否 | 账号迁移用的参数, 调用 CP account-query 及 account-queryandbind 接口时透传给 CP. |

**调用示例**

```csharp
 RegisterArgs registerArgs = new()
 {
 type = AccountType.Phone,//手机号类型
 username = usernameFiled.text,// 用户名
 password = passwordFiled.text,//密码
 };

 RuiXueSdk.Register(registerArgs, (code, data, msg) =>
 {
 if (data != null)
 {
 Debug.Log("data= " + data);
 mText.text = data.Tostring();
 }
 else
 {
 Debug.Log("code:" + code + ", msg:" + msg);
 mText.text = "code:" + code + ", msg:" + msg;
 }
 });
```

| android_id | String | 否 | 仅用于 Android 设备。Android 版本 = 8.0 ，应用签名、用户（即系统上的用户账号）和设备的每个组合都具有唯一的 ANDROID_ID 值，即使系统升级也不变。 |
| imei | String | 否 | 仅用于 Android 设备。Android 版本 &lt; 6.0 ，只需要 READ_PHONE_STATE 静态权限（安装 App 时即可获取到该权限），即可通过系统 API TelephonyManager#getDeviceId API 获取准确值； 6.0 &lt;= Android 版本 &lt;= 9.0 ， READ_PHONE_STATE 升级为动态权限，安装 App 时不会获得该权限，需要在 App 运行时用户在弹窗确认授权后才可以获取； Android 版本 >= 10.0 ，设备不可变 ID 的隐私保护得到进一步升级，需要 READ_PRIVILEGED_PHONE_STATE 权限才可以获取 IMEI ，而该权限只有系统级别的应用才可以获得，因此一般 App 无法获取到 IMEI。 |
| oaid | String | 否 | 仅用于 Android 设备。移动安全联盟（简称 MSA ）制定的匿名设备标识符。可用于 android 系统的补充设备标示，通常 android10 以上的国内主流设备都可以获取。具体 OAID 介绍以及最新覆盖厂商范围请详见 MSA 官网：[https://msa-alliance.cn](https://msa-alliance.cn)。 |

### 登录

**接口原型**

```csharp
/// summary>
/// 登录
/// summary>
/// param name="method">登录方式param>
/// param name="keyValuePairs">登录参数param>
/// param name="callback">回调param>
void Login(LoginMethod method, Dictionarystring, object> keyValuePairs, Actionint, LoginData, string> callback)
```

#### 参数说明

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| method | string | 否 | 登录方式 |
| login_openid | string | 否 | 上次登录返回的 login_openid 数据，同时 method 也要使用上次登录获取 login_openid 时使用的登录方式 |
| user_attrs | object | 否 | 设置大数据用户属性，仅对本次登录新注册的用户有效 |
| sign_fields | []string | 否 | 指定对登录成功后返回的特定字段, 使用 CPKEY 计算签名. CP 服务器可重新计算签名并与登录返回的签名比对, 作为对望舒登录数据的校验. 支持的字段包括: nickname, avatar, openid, region, sex, age, 计算签名的逻辑会对指定字段进行排序, 此处传参与顺序无关. |
| migrate_args | 任意合法的 json 类型, 比如 string, number, array, object | 否 | 账号迁移用的参数, 调用 CP account-query 及 account-queryandbind 接口时透传给 CP. |

**调用示例**

```plaintext
string method="steam";
Dictionary parm = new()
{
 {"sign_fields",new string[]{"openid"}}
};
RuiXueSdk.Login(method, parm, (code, data, msg) =>
{
 if (data != null)
 {
 Debug.Log("data= " + data.ToJson());
 mText.text = data.ToJson();
 }
 else
 {
 Debug.Log("code:" + code + ", msg:" + msg);
 mText.text = "code:" + code + ", msg:" + msg;
 }
});

```

### 获取验证码（发送验证码）

注： steam 暂不支持滑块验证

**接口原型**

```csharp
void SendCaptcha(SendCaptchaArgs args, Actionint, object, string> callback)
```

#### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| email | string | 否 | 接收验证码的邮箱地址，邮箱手机号二选一 |
| phone | string | 否 | 接收验证码的手机号，邮箱手机号二选一 |
| purpose | string | 是 | 验证码的用途 |

> `purpose` 字段值 验证码用途说明

| 字段 | 备注 |
| --- | --- |
| register | 注册 |
| bindphone | 绑定手机 |
| unbindphone | 解绑手机 |
| resetpwd | 重置密码 |
| bindemail | 绑定邮箱 |
| unbindemail | 解绑邮箱 |
| login | 登录 |
| setpwd | 设置密码 |


**调用示例**

```csharp
data = new SendCaptchaArgs()
{
 phone = "1395xxxxxxx",
 purpose = "xxxxxx"

};
RuiXueSdk.SendCaptcha(data, callback);
```

#### 响应结构

```json
{
 "code": 0,
 "data": {
 "interval": 60,
 "surplus": 60
 }
}
```

### 校验验证码

用途和手机号或邮箱需要和调用发送验证码时一致。

**接口原型**

```csharp

void VerifyCaptcha(VerifyCaptchaArgs args, Actionint, object, string> callback)
```

#### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| phone | string | 是 | 接收验证码的邮箱地址，邮箱手机号二选一 |
| email | string | 是 | 接收验证码的邮箱地址，邮箱手机号二选一 |
| purpose | string | 是 | 验证码的用途 |
| captcha_code | string | 是 | 验证码 |

> `purpose` 字段值 验证码用途说明

| 字段 | 备注 |
| --- | --- |
| register | 注册 |
| bindphone | 绑定手机 |
| unbindphone | 解绑手机 |
| resetpwd | 重置密码 |
| bindemail | 绑定邮箱 |
| unbindemail | 解绑邮箱 |
| login | 登录 |
| setpwd | 设置密码 |


**调用示例**

```csharp
 data = new VerifyCaptchaArgs()
{
 phone = phone1,
 purpose = pru,
 captcha_code = phone1.Substring(phone1.Length - 4),
};
RuiXueSdk.VerifyCaptcha(data,callback);
```

#### 响应结构

不返回 data 信息，验证码不正确会直接返回相应的错误。

```json
{
 "code": 0
}
```
