## 自定义望舒API请求

**接口原型**

```typescript
/**
 * @param options - 请求配置对象
 * @param options.method - HTTP请求方法，支持标准方法或自定义枚举值
 * @param options.path - 请求路径（相对路径或绝对URL）
 * @param [options.data] - 请求数据，可为字符串或对象（对象会自动JSON序列化）
 * @param [options.headers] - 请求头对象，可自定义任何HTTP头信息
 * @param [callback] - 可选的回调函数，支持传统回调模式（与Promise并存）
 * @returns 返回一个Promise，解析为统一的响应结果对象
 * 包含状态码、数据、错误信息等标准字段
 */
requestT>(options: RequestOptions, callback?: RCallbackT>): PromiseRXResultT>>
```

**调用示例**

```typescript

 RXRequest.request({
 path: 'https://rxfile-test.ruixueyun.com/sdk' ,
 method: 'GET',
 headers: {
 '自定义 key': '自定义 value'
 },
 body: 请求数据 object 或 string
 }) .then((resp: RXResultobject>) => {
 this.showText(resp)
 }).catch((e: BusinessError) => {
 this.showText(e)
 })

```

## 望舒通行证API

### 注册

**接口原型**

```typescript
 /**
 * @param username 用户名
 * @param password password
 * @param captchaCode 验证码
 * @param ext "nickname" : "昵称", // string
 * "avatarUrl" : "头像地址" // string
 * "sex" : 0 // 0男 1女 number
 */
 registerT>(username: string, password: string, captchaCode: string, ext: object, callback?: RCallbackT>)
```

**参数说明**

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| username | string | 是 | 用户名 |
| password | string | 是 | 密码 |
| nickname | string | 否 | 昵称 |
| captcha_code | string | 否 | 使用 `sendCaptcha` 接口获取 |
| avatarUrl | string | 否 | 头像地址 |
| user_attrs | object | 否 | 设置大数据用户属性，仅对本次登录新注册的用户有效 |
| sex | integer | 否 | 性别,1:男,0:女 |
| migrate_args | 任意合法的 json 类型, 比如 string, number, array, object | 否 | 账号迁移用的参数, 调用 CP account-query 及 account-queryandbind 接口时透传给 CP. |

**调用示例**

```typescript
 RXApi.getInstance().passport().register(this.userName, this.password, {}, (ret: RXResult) => {
 //todo cp 义务逻辑
 if (ret.code == 0) {

 }
 })
```

### 登录

**接口原型**

```typescript
/**
 * 用户登录接口，支持多种登录方式（密码、第三方、验证码等）
 * @param params - 登录请求参数
 * @param params.method - 登录方式（可选），默认使用密码登录
 * @param params.username - 用户名（密码登录时必填）
 * @param params.password - 密码（密码登录时必填）
 * @param params.login_openid - 第三方登录授权码（如微信、QQ登录）
 * @param params.user_attrs - 用户扩展属性（JSON字符串格式）
 * @param params.sign_fields - 需要签名的字段列表（用于安全验证）
 * @param params.migrate_args - 账号迁移参数（如旧系统迁移）
 * @param params.user_transmits - 用户透传数据（会原样返回给客户端）
 * @param params.device - 设备信息（如设备ID、型号、系统版本等）
 * @param params.distinct_id - 客户端唯一标识（首次登录时生成并传递）
 * @param params.ext - 扩展参数（如验证码信息、额外安全校验参数）
 * @param callback - 可选的回调函数，用于接收登录结果
 * @returns 返回Promise，解析为包含登录数据的统一响应结构
 */
login(params: LoginParams, callback?: RXCallbackRXResultLoginData>>): PromiseRXResultLoginData>>
```

#### 参数说明

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| method | string | 否 | 登录方式 （默认 harmony ） |
| login_openid | string | 否 | 上次登录返回的 login_openid 数据，同时 method 也要使用上次登录获取 login_openid 时使用的登录方式 |
| user_attrs | object | 否 | 设置大数据用户属性，仅对本次登录新注册的用户有效 |
| sign_fields | []string | 否 | 指定对登录成功后返回的特定字段, 使用 CPKEY 计算签名. CP 服务器可重新计算签名并与登录返回的签名比对, 作为对望舒登录数据的校验. 支持的字段包括: nickname, avatar, openid, region, sex, age, 计算签名的逻辑会对指定字段进行排序, 此处传参与顺序无关. |
| migrate_args | 任意合法的 json 类型, 比如 string, number, array, object | 否 | 账号迁移用的参数, 调用 CP account-query 及 account-queryandbind 接口时透传给 CP. |

**调用示例**

```typescript
 RXApi.getInstance().login({ method:"username", username: 'test', password: '123456' })
 .then(res => console.log('登录成功', res.data.token))
```

**接口原型**

```typescript
 /**
 * 发起联合登录流程，支持多平台统一认证与授权

 * @param params.loginPanelType - 登录面板样式类型（0: 标准，1: 简化，2: 高级）

 * @param params.firstNeedSetPassword - 首次登录是否需要设置密码
 * @param params.quickLoginEnable - 是否启用快捷登录（如一键登录）
 * @param params.isDeregisterShow - 是否显示注销账号选项
 * @param params.privacyEnable - 是否启用隐私协议功能

unionLogin(params: RXLoginConfig, uiContext: UIContext, callback?: RXCallbackRXResultLoginData>>): PromiseRXResultLoginData>>
```

#### 参数说明

### 解绑鸿蒙账号

**接口原型**

```typescript
unbindPlayer(): Promise<string>
```

**调用示例**

```plaintext
//用于账号和鸿蒙解绑
```
