## 1. Google Chrome

### 启用或禁用通知

打开 Chrome 浏览器。

点击右上角的三个点（菜单）图标。

选择“设置”。

在左侧菜单中选择“隐私与安全”。

点击“网站设置”。

滚动到“权限”部分，点击“通知”。

在这里，您可以查看允许或阻止通知的网站列表。

### 添加例外

点击“添加”按钮以输入您希望允许或阻止通知的网站 URL。

## 2. Mozilla Firefox

### 启用或禁用通知

打开 Firefox 浏览器。

点击右上角的三条横线（菜单）图标。

选择“设置”。

点击“隐私与安全”选项。

向下滚动到“权限”部分，找到“通知”。

点击“设置”按钮来管理通知权限。

### 添加例外

在弹出的窗口中，您可以输入网站 URL 并选择允许或阻止。

## 3. Microsoft Edge

### 启用或禁用通知

打开 Edge 浏览器。

点击右上角的三个点（菜单）图标。

选择“设置”。

点击“Cookies 和站点权限”。

在“站点权限”下，点击“通知”。

在这里，您可以管理网站的通知权限。

### 添加例外

点击“添加”以允许或阻止特定网站的通知。

## 4. Safari (Mac)

### 启用或禁用通知

打开 Safari 浏览器。

从顶部菜单中选择“Safari” > “偏好设置”。

点击“网站”选项卡。

在左侧菜单中选择“通知”。

您会看到已经请求通知的站点列表。

### 添加例外

使用下拉菜单选择“允许”或“拒绝”特定网站的通知。
