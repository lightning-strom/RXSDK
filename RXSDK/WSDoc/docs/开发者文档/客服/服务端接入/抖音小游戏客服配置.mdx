> 如何接入小游戏客服？
>
> 答：CP 方通过抖音小游戏的客服会话按钮，通过抖音官方服务器或 CP 服务器转发的形式。

### 整体流程

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1750406736478.png)

### 跳转抖音小游戏客服

根据 sdk 提供的方法跳转到抖音客服进行沟通。

跳转按钮 **：客服会话**

### 小游戏消息推送地址绑定

进入[抖音小游戏详情页](https://developer.open-douyin.com/)，开发-开发设置-消息推送配置

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1750382147230.png)

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1750382171420.png)

启用消息推送，并按提示填写相关信息，具体如下：

URL(服务器地址):望舒首页域名/v1/servicedouyin/notify_v2/产品 id/渠道 id

TOKEN:**通过望舒游戏发行平台首页选择微信小游戏渠道包-客服参数-进行参数复制获取**。如下图所示

数据格式： JSON

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1750406631832.png)

### 抖音后台开通服务

#### 使用抖音客服需要先开通抖音客服平台服务

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1751245614013.png)

#### 新建客服角色

搜索添加项目协作者在开放平台的用户名。添加客服组长或者普通客服的权限。

只需要添加一个客服组长保持在线即可。

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1751246680836.png)

#### 闭非工作时间提示

进入**抖音客服平台>运营管理>自动回复>关闭非工作时间提示**

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1751246920445.png)

#### 设置客服状态

进入**抖音客服平台>IM 工作台>设置客服为在线**

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1751247126938.png)
