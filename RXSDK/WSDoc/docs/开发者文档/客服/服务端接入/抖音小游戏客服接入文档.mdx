>
> 答：CP 方通过抖音小游戏的客服会话按钮，通过抖音官方服务器或 CP 服务器转发的形式。

### 跳转抖音小游戏客服

跳转按钮 **：客服会话**

## FAQ

### 小游戏消息推送地址绑定

绑定规则 ：**API 域名 +**v1/servicedouyin/notify/ProductID/ChannelID

ProductID : 望舒产品 ID

ChannelID :望舒渠道 ID

Token : 固定值 ruixue

消息加密方式:明文

数据格式:JSON
