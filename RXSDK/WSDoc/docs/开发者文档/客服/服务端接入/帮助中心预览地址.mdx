### 跳转预览帮助中心地址信息

跳转地址 **： API 域名 +/static/passport/#/helpcenter/questioncatalogue-new**

跳转方式 **： URL 跳转**

传参方式 **： GET**

### 参数

| 参数 | 名称 | 含义 | 必填 | 示例 |
| --- | --- | --- | --- | --- |
| cpid | cpid | 应用的 cpid | 是 | 100010 |
| productid | 产品 id | 应用的产品 id | 是 | 1002 |
| channelid | 渠道 id | 应用的渠道 | 是 | 818 |
| devicecode | 设备码 | 设备码 | 否 | a581b5db-0414-4ae8-9a83-8e0d41566351 |
| language | 语言 | 展示语言 | 是 | zh、en |
| isPreview | 是否预览 | 是否预览 | 是 | 1(固定值 1 即可) |


### 示例

https://cn-api-test.ruixueyun.com/static/passport/#/helpcenter/questioncatalogue-new?cpid=114&productid=1002&channelid=100&language=zh&isPreview=1
