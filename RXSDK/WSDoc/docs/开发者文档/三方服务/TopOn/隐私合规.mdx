## App《隐私政策》说明

您可以参考以下说明添加 App《隐私政策》：

1、App 需要制订《隐私政策》，同时在用户首次启动 App 时展示《隐私政策》并取得用户同意。请务必确保用户同意 App《隐私政策》之后，再初始化 TopOn SDK。

2、您需要在 App《隐私政策》告知用户您选择使用 TopOn SDK 服务，同时需要在 App《隐私政策》里增加[《TopOn 隐私政策》](https://help.toponad.com/cn/docs/1Mn1B7)的相关介绍内容.

3、App 的《隐私政策》您也可以参考市场监管总局发布的[《信息安全技术个人信息安全规范》](https://baike.baidu.com/item/%E4%BF%A1%E6%81%AF%E5%AE%89%E5%85%A8%E6%8A%80%E6%9C%AF%E2%80%94%E4%B8%AA%E4%BA%BA%E4%BF%A1%E6%81%AF%E5%AE%89%E5%85%A8%E8%A7%84%E8%8C%83/55779999?fr=ge_ala)文件中的隐私政策模板，进行实现。

您可以通过访问 [《TopOn 隐私政策》](https://help.toponad.com/cn/docs/1Mn1B7) 进一步了解 TopOn 的隐私政策，以及了解 TopOn 对个人信息的处理和保护策略。

## 欧盟区域-通用数据保护条例GDPR

自 2018 年 5 月 25 日起，欧盟《一般数据保护条例》将正式生效。自此，需要在欧盟区域内上架的应用或游戏，需要支持 GDPR 协议。

如果集成的广告平台中未接入 admob 平台，请参考 [设置 GDPR](https://help.toponad.com/cn/docs/she-zhi-GDPR)；

如果集成的广告平台中包含 admob 平台，可以参考 [Google UMP 适配使用指南](https://help.toponad.com/cn/docs/Google-UMP-shi-pei-shi-yong-zhi-nan-fMgm)。

:::tip重要提示

如果你的应用同时获取了 App Tracking Transparency 授权弹窗，我们强烈建议参考 [同时获取 App Tracking Transparency 授权弹窗与 GDPR 弹窗流程建议](https://help.toponad.com/cn/docs/zODjLF#5._%E5%85%B6%E4%BB%96%E4%BA%8B%E9%A1%B9) ，否则有提审被拒的风险！

### 设置GDPR相关方法

#### 获取当前位置是否在欧盟或英国区域内

首先在工程的 info.plist 中设置添加 Privacy - Location When In Use Usage Description ，并添加对应描述：获取您的位置便于推荐更多相关信息 。

**接口原型**

```objectivec
/**
 获取用户当前位置是否在欧盟以内，如果在欧盟以内，需要在管理后台设置Google UMP流程设置欧盟的GDPR(《通用数据保护条例》)配置。
 按照文档配置完成后，再调用以下方法获取所在区域，并进行授权申请。
 使用了admob平台，调用‘showGDPRConsentDialogInViewController:dismissalCallback:’方法进行授权申请
 未使用admob平台，调用‘presentDataConsentDialogInViewController:loadingFailureCallback:dismissalCallback’方法进行授权申请
 location：ATUserLocationUnknown 未知位置；ATUserLocationInEU 在欧盟；ATUserLocationOutOfEU 未在欧盟
 */
- (void)getUserLocationWithCallback:(void(^)(ATUserLocation location))callback;
```

**调用示例**

```objectivec
[[RXTopOnInitManager sharedSDK] getUserLocationWithCallback:^(ATUserLocation location) {
 if (location == ATUserLocationInEU && [RXTopOnInitManager sharedSDK].dataConsentSet == ATDataConsentSetUnknown) {

 //iOS 14

 [[RXTopOnInitManager sharedSDK] startWithAppID:kTopOnAppID appKey:kTopOnAppKey error:nil];
 //to do something，like preloading
 }];
 } else {
 [[RXTopOnInitManager sharedSDK] startWithAppID:kTopOnAppID appKey:kTopOnAppKey error:nil];
 }
 }];
 }else{
 if (@available(iOS 14, *)) {
 //iOS 14
 [ATTrackingManager requestTrackingAuthorizationWithCompletionHandler:^(ATTrackingManagerAuthorizationStatus status) {
 [[RXTopOnInitManager sharedSDK] startWithAppID:kTopOnAppID appKey:kTopOnAppKey error:nil];
 //to do something，like preloading
 }];
 } else {
 [[RXTopOnInitManager sharedSDK] startWithAppID:kTopOnAppID appKey:kTopOnAppKey error:nil];
```

## 海外隐私配置-通用数据保护条例GDPR

自 2018 年 5 月 25 日起，欧盟《一般数据保护条例》将正式生效。为了保护我们的开发人员和您的用户的利益和隐私，我们更新了我们的"TopOn privacy Policy"。同时，我们在 SDK 添加了隐私权限设置。请检查以下配置并完成 SDK 集成：[海外隐私配置](https://help.toponad.com/cn/docs/MWsWVm)

## Google UMP 适配使用指南

自 2024 年 1 月 16 日起，使用 Google AdSense、Ad Manager 或 AdMob 的发布商和开发者在面向欧洲经济区或英国的用户投放广告时，必须使用通过 Google 认证且已与 IAB 的透明度和用户意见征求框架 (TCF) 相集成的意见征求管理平台 (CMP)

TopOn SDK 从 6.2.87 开始提供兼容 UMP SDK 方式配置 GDPR 等级， TopOn SDK 内部根据该等级去设置第三方广告平台 GDPR 上报等级。具体使用流程如下：[Google UMP 适配使用指南](https://help.toponad.com/cn/docs/Google-UMP-shi-pei-shi-yong-zhi-nan-IKqd)

## 通过TopOn SDK API设置TopOn GDPR等级

设置之后，内部根据该等级去设置第三方广告平台 GDPR 上报等级

**接口原型**

```java
    public static void setGDPRUploadDataLevel(Context context, int level);
```

**调用示例**

```java
    int level= { //level有以下选择
    ATSDK.PERSONALIZED //设备数据允许上报
    ATSDK.NONPERSONALIZED //设备数据不允许上报
    ATSDK.UNKNOWN //未知等级，只能通过getGDPRDataLevel方法获取，不能用setGDPRUploadDataLevel方法设置
    }
    TopOnHelper.setGDPRUploadDataLevel(context, level);
```

## 通过TopOn提供的授权的页面设置TopOn GDPR等级

**接口原型**

```java
    public static void showGdprAuth(Activity activity)；
```

**调用示例**

```java
    TopOnHelper.showGdprAuth(activity, new ATGDPRAuthCallback() {
    @Override
    public void onAuthResult(int level) {
    //其中level的数值为ATSDK.PERSONALIZED或者是ATSDK.NONPERSONALIZED
    ATSDK.setGDPRUploadDataLevel(context, level);
    RuiXueSdk.getApi().initThirdSdk(activity, map, new RXJSONCallback());
    }
    });
```

## 通过Ogury SDK设置GDPR等级

当您集成 Ogury 时，请通过以下代码进行 GDPR 的设置。因为 Ogury 没有提供设置 GDPR 等级的 API ，只能通过他们的弹窗进行设置。

**调用示例**

```java
    ConsentManager.ask(context, "YourAssetKey", new ConsentListener() {
    @Override
    public void onComplete(final ConsentManager.Answer answer) {
    runOnUiThread(new Runnable() {
    @Override
    public void run() {
    if(ConsentManager.gdprApplies()) {
    TopOnHelper.setGDPRUploadDataLevel(context, ATSDK.PERSONALIZED);
    } else {
    TopOnHelper.setGDPRUploadDataLevel(context, ATSDK.NONPERSONALIZED);
    }

    RuiXueSdk.getApi().initThirdSdk(activity, map, new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject data) {
    RXLogger.e("demo rx third init success: " + data.toString());
    }

    @Override
    public void onFailed(@NonNull JSONObject cause) {
    RXLogger.e("rx third init failed :" + cause);
    }
    });
```

## 不使用TopOn SDK提供的欧盟判断API

流程说明：

1、APP 启动后，开发者判断用户是否在欧盟(开发者自行实现是否在欧盟的判断方法）

不在欧盟，跳到第 4 步

在欧盟，下一步

2、判断 TopOn SDK 的 Dataconsent 是否为 Unknown

为 Unknown （未设置过 GDPR 等级），下一步

不为 Unknown （设置过 GDPR 等级），跳到第 4 步

3、调用 TopOn SDk 的 showGdprAuth 方法(由用户设置 GDPR 等级）

4、初始化 SDK

**调用示例**

```java
public void initTopOnSDK() {
    if (App. isEU() ) //App. isEU() 为开发者自行实现的欧盟地区判断方法
    {
    if (TopOnHelper.getGDPRDataLevel(applicationContext) == ATSDK.UNKNOWN) {
    TopOnHelper.showGdprAuth(activity, new ATGDPRAuthCallback() {
    @Override
    public void onAuthResult(int level) {
    TopOnHelper.setGDPRUploadDataLevel(applicationContext, level);
    RuiXueSdk.getApi().initThirdSdk(activity, map, new RXJSONCallback());
    }
    });
    }
    return;
    }
    RuiXueSdk.getApi().initThirdSdk(activity, map, new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject data) {
    RXLogger.e("demo rx third init success: " + data.toString());
    }

    @Override
    public void onFailed(@NonNull JSONObject cause) {
    RXLogger.e("rx third init failed :" + cause);
    }
    });
}
```

## 使用TopOn SDK提供的欧盟判断API

1、App 启动后，执行 ATSDK.checkIsEuTraffic 方法动态去获取当前的欧盟信息，同时去初始化 ATSDK

2、接收到检测结果的回调之后：

True ，则执行下一步

False ，则不再处理

3、判断 TopOn SDK 的 Dataconsent 是否为 Unknown

为 Unknown （未设置过 GDPR 等级），下一步

不为 Unknown （设置过 GDPR 等级），则不再处理

4、调用 TopOn SDk 的 showGdprAuth 方法(由用户设置 GDPR 等级）

**调用示例**

```java
    TopOnHelper.checkIsEuTraffic(this, new NetTrafficeCallback() {

    @Override
    public void onResultCallback(boolean isEU) {
    if (isEU && TopOnHelper.getGDPRDataLevel(DemoApplicaion.this) == ATSDK.UNKNOWN) {
    TopOnHelper.showGdprAuth(DemoApplicaion.this);
    }

    }

    @Override
    public void onErrorCallback(String errorMsg) {
    Log.i("Demoapplication", "onErrorCallback:" + errorMsg);
    }
    });

    RuiXueSdk.getApi().initThirdSdk(activity, map, new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject data) {
    RXLogger.e("demo rx third init success: " + data.toString());
    }

    @Override
    public void onFailed(@NonNull JSONObject cause) {
    RXLogger.e("rx third init failed :" + cause);
    }
    });
```
