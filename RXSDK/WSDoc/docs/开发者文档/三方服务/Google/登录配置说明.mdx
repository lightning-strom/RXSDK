## 准备工作

Google 云平台地址：[https://console.cloud.google.com/](https://console.cloud.google.com/apis/credentials?project=fishing-game-zone&hl=fi&supportedpurview=project)

望舒系统地址：[企业管理后台中获取望舒地址](/docs/开发者文档/入门指南/准备工作)。

## 获取配置

登录 [Google 云平台](https://console.cloud.google.com/apis/credentials?project=fishing-game-zone&hl=fi&supportedpurview=project)，位置：**凭据 > OAuth2.0 客户端 ID > 客户端 ID**，复制信息。

新建凭据时需要注意：

安卓应用创建 OAuth2.0 客户端 ID 应用类型需要选择 Web 应用。

IOS 应用创建 OAuth2.0 客户端 ID 应用类型需要选择 IOS。

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1733705467063.png)

firebase 后台配置 google 登录，一般会自动生成客户端 ID。

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/img_v3_02ga_e9e92955-2610-4b68-a124-da9519e92dcg-1730708770359.jpg)

### 望舒系统中配置信息

#### 登录配置

通过获取到的 ` 客户端 ID` 复制到望舒系统,填写到 google appid 中。位置：**渠道管理 > 渠道包管理 > 添加登录方式**。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/google/ruixue/login.jpg)
