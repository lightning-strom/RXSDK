## SDK集成


:::tip[版本说明]
`version` 为 SDK 版本号（替换为实际版本号），最新版本请从 [更新日志](/docs/开发者文档/入门指南/更新日志/Android) 中查看。
:::

```groovy
//oppo 海外渠道库
 implementation 'com.ruixue:rxsdk_overseas_oppo:${version}'
```

## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| appSecret | String | initThirdSdk 接口传入 |

## 配置说明

在您的项目中， ` 打开 your_app | AndroidManifest.xml` ，在 application 标签下添加如下配置：

```xml
</application>
 ....

 uses-library
 android:name="org.apache.http.legacy"
 android:required="false" />

 meta-data
 android:name="debug_mode"
 android:value="true" />

 meta-data
 android:name="is_offline_game"
 android:value="false" />

 meta-data
 android:name="app_key"
 android:value="应用申请的 app key" />
</application>
```

## 初始化

[参考这里](/docs/开发者文档/三方服务/三方接入说明)

```java
Map<String, Object> params = new HashMap<>();

// 这里填写使用方自己对应的参数
params.put("appSecret", "");
RuiXueSdk.getApi().initThirdSdk(this, params, new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject jsonObject) {
    Log.d(TAG, "init third sdk success");
    }

    @Override
    public void onFailed(@NonNull JSONObject jsonObject) {
    Log.d(TAG, "init third sdk failed " + jsonObject);
    }
});
```

## 登录 请一定确保要初始化成功再调用登录

OPPO 海外没有强制接入 OPPO 账号，并且他们账号接入存在问题，所以可以接入其它登录，如 游客， google 登录等，具体参考 Android 端登录 API

请参考 [Android 端登录 API](/docs/开发者文档/登录-通行证/Android-登录API/快速接入)

参考代码

```java
String username = null;
String loginType = LoginMethod.GUEST;
String captchaCode = null;
String loginOpenId = null;
Map<String, Object> ext = null;
String[] signFields = null;
Object migrateArgs = null;
RuiXueSdk.getApi().login(DemoActivity.this, loginType, username, password, captchaCode, loginOpenId, ext, signFields, migrateArgs, new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject data) {
    Toast.makeText(DemoActivity.this, "登录成功", Toast.LENGTH_SHORT).show();
    }

    @Override
    public void onFailed(@NonNull JSONObject cause) {
    Toast.makeText(DemoActivity.this, "登录失败", Toast.LENGTH_SHORT).show();
    }
});
```

## 获取手机区域接口（非必须）

```java
/**
    * callback 中的 data 数据 如{"region":"IN"}代表印度，{"region":"ID"}代表印度尼西亚，{"region":"TW"}代表台湾， {"region":"VN"}代表越南， {"region":"TH"}代表泰国， {"region":"PH"}代表菲律宾， {"region":"MY"}代表马来西亚。目前支持以上七个地区。其他地区暂不支持。
    */
OppoOverseasSdkHelper.doGetRegion(RXJSONCallback callback)
```

调用示例

```java
OppoOverseasSdkHelper.doGetRegion(new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject data) {
    // data 形如 {"region":"IN"}
    }

    @Override
    public void onFailed(@NonNull JSONObject cause) {

    }
});
```

## 游戏提现接口(非必须)

```java
OppoOverseasSdkHelper.doWithdrawal(Context context, WithdrawalInfo withdrawalInfo, ApiCallback callback)
```

### 参数说明

WithdrawalInfo 数据结构

| 名称 | 类型 | 长度字符 | 是否必填 | 说明 |
| --- | --- | --- | --- | --- |
| pkg | string | 128 | 是 | 应用包名 |
| sign | string | 256 | 是 | 签名 |
| timestamp | string | 19 | 是 | 发送请求的时间， 13 位时间戳 |
| region | string | 2 | 是 | 区域代码，印度 IN |
| signType | string | 10 | 是 | 商户生成 签名字符串所使用的签名类型 |
