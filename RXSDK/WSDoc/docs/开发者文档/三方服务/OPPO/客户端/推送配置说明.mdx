## 准备工作

oppo 开放平台：[https://open.oppomobile.com/](https://open.oppomobile.com/)

望舒系统地址：[企业管理后台中获取望舒地址](/docs/开发者文档/入门指南/准备工作)。

## 推送配置

### oppo 开放平台获取推送信息

登录 [oppo 开放平台](https://open.oppomobile.com/)，位置：**管理中心 > OPush 推送服务平台**。

复制 `APPKey` 、`AppID` 信息。

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1725515588498.png)

其中 MasterSecret 为望舒所需要填写的 AppSecret。

### 望舒系统中配置推送信息

从 oppo 开放平台获取 `AppID` ， `APPKey` 、`AppSecret` 信息。

复制到望舒系统，位置：**道管理 > 渠道包管理 > 推送配置 > 添加推送方式**。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/oppo/push/push_ruixue.jpg)

### oppo后台推送回调地址

api 域名/v1/pusher/notify/oppo?product_id=产品 ID&channel_id=渠道 ID
