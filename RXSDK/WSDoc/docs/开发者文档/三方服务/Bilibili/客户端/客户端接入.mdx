## 配置说明

请将以下内容全部复制到 AndroidManifest.xml 的 application 标签下

```xml

<meta-data android:name="BSGameSdk_PaidGame" android:value="false">
```

在 application 中添加 activity

由于加入微信支付功能，接入时需要在你的应用包名相应目录下新建一个 wxapi 目录，并在该 wxapi 目录下新增一个 WXEntryActivity 类，该类继承 com.ruixue.sdk.BiliBiliWXEntryActivity

```xml

activity
 android:name=".wxapi.WXEntryActivity"
 android:theme="@android:style/Theme.Translucent.NoTitleBar"
 android:exported="true"
 android:taskAffinity="net.sourceforge.simcpux"
 android:launchMode="singleTask">
</activity>
activity

 android:theme="@android:style/Theme.Translucent.NoTitleBar"
 android:exported="true"
 android:taskAffinity="net.sourceforge.simcpux"
```

## 依赖信息

使用 `aar` 接入方式的的请添加下面依赖配置，否则无需添加

```groovy
api 'com.gsc.pub:gsc_android_library:5.9.0'
api 'com.base.oaid:game-oaid:1.1.0'
api 'com.bun.miitmdid:oaid_sdk:1.0.25'
implementation 'com.alipay.sdk:alipaysdk:15.8.11'
```

**常见问题**

出现 Duplicate class okhttp3.Address found in modules jetified-gsc_android_library-5.9.0-runtime (com.gsc.pub:gsc_android_library:5.6.2) and jetified-okhttp-3.12.1 (com.squareup.okhttp3:okhttp:3.12.1) 问题的处理办法。

在项目 app 模块中 bulid.gradle 文件中添加下面配置

```groovy
configurations {
 all*.exclude group: 'com.squareup.okhttp3', module: 'okhttp'
}

```

初接入 B 站授权登录时错误码提示【-906】是正常的，授权登录需要使用过审后的二签包才能拉起，目前可以更换为账密登录，点粉色 bilibili 按钮切换。

```java
    @Override
```

## 登出

在游戏需要登出的地方调用如下代码

```java
    RuiXueSdk.getApi().logout(new OnLogoutCallback() {
    @Override
    public void onSuccess(@Nullable String data) {
    Toast.makeText(QuickDemoActivity.this, "登出成功", Toast.LENGTH_SHORT).show();
    }

    @Override
    public void onFailed(int code, String msg) {
    RXLogger.d("logout failed code = " + code + " msg = " + msg);
    Toast.makeText(QuickDemoActivity.this, "登出失败", Toast.LENGTH_SHORT).show();
    }
});
```

## 游戏账号切换 和 logout 全局监听

参考代码

```java
RuiXueSdk.setRuiXueSdkCallback(new RuiXueSdkCallback() {

    // ... 省略了一些无关代码

    /**
    * 切换账号全局回调,如果有游戏内切换账号可关注此回调
    * @param code 0
    * @param data 三方数据
    */
    @Override
    public boolean onSwitchAccount(int code, String data) {
    // 调用方如果有要处理的逻辑放在此处
    // 返回 true ，SDK ，会执行 logout 操作
    // 返回 false ，SDK 不执行任何操作
    return true;
    }

    @Override
    public void onLogout(int code, String msg) {
    // code 0: 登出成功
    RXLogger.d(TAG, "onLogout code = " + code + " msg = " + msg);
    }
});
```
