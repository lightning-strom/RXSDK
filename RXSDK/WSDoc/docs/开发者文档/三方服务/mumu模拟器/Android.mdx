## 项目根目录增加 maven 库依赖

在项目根目录的 build.gradle 中对应位置添加如下配置

```groovy
allprojects {
 repositories {
 // 新增如下一行
 maven { url "https://maven-release.webapp.163.com/repository/maven-releases/" }
 }
}
```

:::tip[版本说明]
`version` 为 SDK 版本号（替换为实际版本号），最新版本请从 [更新日志](/docs/开发者文档/入门指南/更新日志/Android) 中查看。

## 初始化配置

在 app/build.gradle 中填入网易 Yofun 提供的游戏参数。

```xml
manifestPlaceholders = [
 "app_id": "${这里替换为从网易Yofun获取的APP_ID}"
]
```

在 app/AndroidManifest.xml 中 application 节点 内配置一个占位节点。

```xml
meta-data
 android:name="YOFUN_APP_ID"
 android:value="${app_id}" />
```

## 初始化

在 applicaiton 中新增

```java
    @Override
    protected void attachBaseContext(Context base) {
    super.attachBaseContext(base);
    YofunSdkHelper.install(base);
    YofunSdkHelper.applicationAttach(this);
    }

    @Override
    public void onCreate() {
    super.onCreate();
    YofunSdkHelper.applicationCreate(this);
    }
```

## 闪屏

闪屏接入方式，在游戏主界面(一般为 MainActivity ，每个游戏可能不一样） onCreate 增加如下方法

```java
    @Override
    protected void onCreate(Bundle savedInstanceState) {
    super.onCreate(savedInstanceState);

    ... 初始化SDK 代码

    // MUMU SDK 内置了3种类型实现的闪屏（0,1,2）可以自测效果选择调用。
    int type = 0;
    YofunSdkHelper.displayChannelLogo(this, type, new Runnable() {
    @Override
    public void run() {
    RXLogger.d("闪屏已显示"); // 闪屏结束回调。
    }
    });
    }
```

## 监听渠道UI是否展示（保活功能）

```java
    RuiXueSdk.setRuiXueSdkCallback(new RuiXueSdkCallback() {
    @Override
    public void onLogout(int code, String msg) {
    Log.d("mumu", "退出登录");
    }

    @Override
    public void rxPublicCallback(int type, Map<String, Object> map) {
    super.rxPublicCallback(type, map);
    // 游戏需要做的就是当收到生命周期UI隐藏的时候（测试MuMu的弹框正在显示），游戏的界面是正常运行的即可（游戏不能暂停，NPC或者角色是可以移动的）
    if (type == 1) {
    Log.d("mumu", "UI 展示");
    // 如果游戏暂停了的话，在这里恢复, Unity 调用示例
    // 调用 UnityPlayer.resume();
    }else {
    Log.d("mumu", "UI 隐藏");
    }
    }
    });
```

## 登录 (必须接入)

请参考 [Android 端登录 API](/docs/开发者文档/登录-通行证/Android-登录API/快速接入)

```java
String username = null;
String loginType = LoginMethod.MUMU;
String captchaCode = null;
String loginOpenId = null;
Map<String, Object> ext = null;
String[] signFields = null;
Object migrateArgs = null;
RuiXueSdk.getApi().login(DemoActivity.this, loginType, username, password, captchaCode, loginOpenId, ext, signFields, migrateArgs, new RXJSONCallback() {
    @Override
    public void onSuccess(@Nullable JSONObject data) {
    Toast.makeText(DemoActivity.this, "登录成功", Toast.LENGTH_SHORT).show();
    }

    @Override
    public void onFailed(@NonNull JSONObject cause) {
    Toast.makeText(DemoActivity.this, "登录失败", Toast.LENGTH_SHORT).show();
    }
});
```

## 上传游戏事件（必接）

```java
/**
    * GameEventInfo 具体字段请根据实际情况填写
    * roleId: String 角色id (必填)

    * serverId: String 区服id (必填)

    * roleLevel: long 角色等级 (选填)

    * partyName: String 工会名称 (选填)

    * gameMoney: long 游戏货币数量 (选填)
    * GameEventType
    * LOGIN_SUCCESS
    * ROLE_CREATE_SUCCESS
    * ROLE_UPGRADE;
```
