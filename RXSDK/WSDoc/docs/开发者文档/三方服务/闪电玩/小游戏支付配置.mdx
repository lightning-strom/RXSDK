## 准备工作

闪电玩游戏开放平台地址：[http://h5.shandw.com/](http://h5.shandw.com/t)

望舒系统地址：[企业管理后台中获取望舒地址](/docs/开发者文档/入门指南/准备工作)。

## 支付配置

### 闪电玩游戏开放平台获取配置

登录[闪电玩游戏开放平台](http://h5.shandw.com/)，位置：**首页>开发者后台 >游戏管理>我创建的游戏/添加创建游戏>选择游戏>查看**。

获取关键配置： `AppID`、`Key`。

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1758156313622.png)

### 望舒系统中配置支付信息

复制到望舒系统，位置：**运维资源管理> 三方账号管理 > 支付账号管理 > 新建闪电玩小游戏支付账号**。

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1758157568495.png)

### 开放平台配置回调地址

开放平台配置支付回调地址。位置：**首页>开发者后台 >游戏管理>添加创建游戏>付费类型为付费>配置回调地址**。

回调地址格式： API 域名/v1/ke/callback/f_channel/产品 ID/渠道 ID/minigame_shandw

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1758156587462.png)
