### 抖音开放平台配置推荐流能力

抖音该能力对于响应时间要求比较高。所以使用的 api 域名和游戏侧回调的域名不要使用带 CDN 的。

配置格式： api 域名/v1/thirdparty/api/dy_feed/产品 ID/渠道 ID

#### 操作页面

登录[字节小程序开发者平台](https://developer.open-douyin.com/)，获取 `Secret` ，位置：**字节小程序 >小游戏 > 运营 > 运营能力> 推荐流直出游戏能力**。

### 望舒产品配置回调

配置回调地址，位置：**版本发布>区服配置>选择区服>回调配置>添加回调事件>三方服务>抖音推荐流回调**。[查看服务端回调接口](/docs/开发者文档/订阅消息/微信/服务端回调)

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1753322135179.png)

### 望舒渠道包中配置信息

获取到的 `Secret` 填写到望舒配置的 ` 推荐流 Secret` ，位置：**渠道&产品>渠道包管理>抖音小游戏登录**

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1741677681008.png)
