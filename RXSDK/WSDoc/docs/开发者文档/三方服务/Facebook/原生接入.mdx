## SDK 集成

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

可通过 **pod** 方式接入 **RXFacebookSDK** 组件。在需要使用功能的类中引用头文件 `#import <RXFacebookSDK/RXFacebookSDK.h>`

```objectivec
pod 'RXFacebookSDK'
```

```groovy

implementation 'com.ruixue:rxsdk_facebook:${version}'
```

### 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| facebook_app_id | Long | strings.xml 内配置 FACEBOOK_APP_ID 值 |
| facebook_client_token | String | strings.xml 内配置 |

### 配置说明

在 `src/main/res/values/strings` 文件下：

```xml
<string name="facebook_app_id">268619981955495</string>
<string name="facebook_client_token">0799c45bcb03a3153cbfba1920dee0e8</string>
```

在 AndroidManifest.xml 配置：

```xml
</application>
<meta-data android:name="com.facebook.sdk.ApplicationId" android:value="@string/facebook_app_id" />
<meta-data android:name="com.facebook.sdk.ClientToken" android:value="@string/facebook_client_token" />
</application>
```

> 由于 meta-data 不支持 long 数据类型，如果配置的值为数字类型，需要配置在 `strings.xml` 文件内。

在 build.gradle (Module: app) 的 `defaultConfig` 块中添加：

```groovy
manifestPlaceholders = [
    FACEBOOK_APP_ID : "xxxxxxx"
]
```

## 初始化

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

### 注册 Facebook

```objectivec
- (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
 [[RXFacebookService sharedSDK] FBRegistWithApplication:application launchOptions:launchOptions];
 return YES;
}
```

### 跳转 openURL

必须实现此方法，否则无法正常使用 Facebook 登录或分享功能。

```objectivec
- (BOOL)application:(UIApplication *)app openURL:(NSURL *)url options:(NSDictionary<NSString *, id> *)options {
 if ([[RXFacebookService sharedSDK] FBApplication:app openURL:url options:options]) {
 return YES;
 }
 return YES;
}
```
