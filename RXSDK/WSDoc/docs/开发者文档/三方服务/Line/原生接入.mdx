## SDK 集成

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

可通过 **pod** 方式接入 **RXLineSDK** 组件。在需要使用功能的类中引用头文件 `#import <RXLineSDK/RXLineSDK.h>`

```objectivec
pod 'RXLineSDK'
```

### 工程配置

在 Xcode -> Info -> URL Types 中添加 **line3rdp.$(PRODUCT_BUNDLE_IDENTIFIER)**。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/iosline.png)

在 Xcode -> Info -> Custom iOS Target Properties 中添加白名单 **lineauth2**。

在 Xcode -> Info -> Custom iOS Target Properties 中添加 **LineSDKConfig** 配置，并填写 **ChannelID**，申请 **ChannelID** 请到 [Line 开放平台](https://developers.line.biz/en/)。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/iosline2.png)

</TabItem>

<TabItem value="android" label="Android">

重要：请先查看渠道接入说明！[快速入口](/docs/开发者文档/入门指南/准备工作)

:::tip[版本说明]
`version` 为 SDK 版本号（替换为实际版本号），最新版本请从 [更新日志](/docs/开发者文档/入门指南/更新日志/Android) 中查看。
:::

```groovy
implementation 'com.ruixue:rxsdk_line:${version}'
```

### 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| line_channel_id | String | initThirdSdk 接口传入 |

### 三方 SDK 版本信息

使用 `5.3.1` 版本

## 初始化

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

在SDK 初始化方法之前调用。

**接口原型**

```objectivec
/**
 * 初始化
 */
- (void)regist;
```

**调用示例**

```objectivec
[[RXLineService sharedSDK] regist];
```

## 处理跳转

不添加此方法将无法正常使用 Line 相关功能。

```objectivec
- (BOOL)application:(UIApplication *)app openURL:(NSURL *)url options:(NSDictionary *)options
{
 return [[RXLineService sharedSDK] handleOpenURL:url];
}
```

</TabItem>

<TabItem value="android" label="Android">

集成 SDK 后自动处理，无需额外初始化。

</TabItem>
