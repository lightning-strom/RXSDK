## 准备工作

宙斯开放平台地址：[https://jos-console.jd.com/#/app/index](https://jos-console.jd.com/#/app/index)

京东小游戏平台地址: [https://mp-console.jd.com/](https://mp-console.jd.com)

望舒系统地址：[企业管理后台中获取望舒地址](/docs/开发者文档/入门指南/准备工作)。

## 支付配置

京东小游戏支付参数需要联系京东人员获取即可。

### 望舒系统中配置支付信息

获取到的参数复制到望舒系统，位置：**企业管理后台> 三方账号管理 > 支付账号管理 > 新建支付账号**。

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1734588195404.png)

### 回调地址

将回调地址提供给京东人员即可。

回调地址为：**望舒首页 api 域名/v1/ke/callback/f_channel/产品 ID/渠道 ID/minigame_jd** 或者配置地址可以从**望舒游戏平台>首页>筛选渠道包>复制参数>支付参数>获取需要的支付方式的回调地址**。
