#### 腾讯云获取配置

登录[腾讯云平台](https://cloud.tencent.com/login)，获取对应得 Biztype 场景。

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/img_v3_02h9_86ed6bff-ff09-4046-9bc9-ef34ebd3f87g-1733380891037.png)

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/img_v3_02h9_1ada5116-d2ca-4b1b-93c1-61954737759g-1733380896842.png)

使用内容安全服务时,请到企业后台配置以下几个步骤：

1.位置：**企业管理后台>运维管理>平台集群管理>项目配置>服务商配置>内容安全**选择所需的服务商进行参数配置。

2. 位置：**企业管理后台>项目参数配置>内容安全>新建** 服务商选择已配置的，.根据获取到对应的 Biztype 参数进行模板配置。

3.在**产品管理** 中找到图片/文本审核配置 选择已配置好的模板信息进行关联保存。
