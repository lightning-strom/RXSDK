## SDK集成

<Tabs groupId="platform">
  <TabItem value="ios-sdk" label="iOS" default>

</TabItem>
  <TabItem value="android-sdk" label="Android">

```groovy
    //二选一
    //不包含支付功能
    implementation " com.ruixue:rxsdk_weixin:${version}"
    //包含支付功能
    implementation " com.ruixue:rxsdk_weixin_withpay:${version}"
```
