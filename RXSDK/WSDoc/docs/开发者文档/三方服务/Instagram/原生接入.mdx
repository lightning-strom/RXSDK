## SDK 集成

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

**RXInstagramSDK 版本 1.0.1** / **RXSDK_Pure 版本 3.4.32** / **RXOSUIKit 版本 3.4.18**

可通过 **pod** 方式接入。在需要使用功能的类中引用头文件 `#import <RXInstagramSDK/RXInstagramSDK.h>`

```objectivec
pod 'RXInstagramSDK'
```

</TabItem>

<TabItem value="android" label="Android">

:::tip[版本说明]
`version` 为 SDK 版本号（替换为实际版本号），最新版本请从 [更新日志](/docs/开发者文档/入门指南/更新日志/Android) 中查看。
:::

```groovy
// 海外渠道引用此库
implementation 'com.ruixue:rxsdk_instagram:${version}'
```

### 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| clientId | Long | string.xml 中配置 instagram_client_id 值 |
| redirectUrl | String | 在开发者后台查看 |

### 配置说明

在 `src/main/res/values/strings` 文件下配置 clientId，在 AndroidManifest.xml 中配置相关 meta-data。

</TabItem>

</Tabs>

## 初始化

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

在调用 Instagram 相关功能前必须先在 `didFinishLaunchingWithOptions` 中进行初始化。

**接口原型**

```objectivec
/**
 * 初始化 instagram
 * @param clientID 应用ID
 * @param redirectURI 应用重定向网址
 */
- (void)initWithClientID:(NSString *)clientID redirectURI:(NSString *)redirectURI;
```

**调用示例**

```objectivec
- (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
 [[RXInstagramService sharedSDK] initWithClientID:@"your client id" redirectURI:@"your redirect uri"];

 [[RXService sharedSDK] initWithProductId:@"your productId"
 channelId:@"your channelId"
 cpid:@"your cpid"
 baseUrlList:@[@"https:xxx"]
 complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
 if (!error) {
 NSLog(@"初始化成功");
 } else {
 NSLog(@"初始化失败");
 }
 }];
 return YES;
}
```

</TabItem>

<TabItem value="android" label="Android">

集成 SDK 并配置参数后自动完成初始化。

</TabItem>

</Tabs>
