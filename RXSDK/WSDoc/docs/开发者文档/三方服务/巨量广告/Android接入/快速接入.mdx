## SDK概述

注意： 3.4.10 以后不再维护客户端手动调用巨量广告 SDK 接口，只需接入 SDK 只需接入 SDK 并设置上下文即可，上报条件通过望舒投放模块中的窗口期进行配置。

注意： 3.7.13 移除 setContext 设置上下文接口。

**主要功能**

通过在望舒投放模块中的窗口期配置进行动态上报（假回传）；

**接入准备**

正式接入前请务必仔细阅读商业开放平台关于 SDK 接入流程的介绍，并且在巨量引擎广告投放平台官网成功申请真实可用的 appid 之后再进行接入动作。

申请 appid 时请务必仔细阅读申请页关于申请 appid 的细则要求，并保证接入时写入的 appname、package 等字段信息与申请 appid 时填入的一致，否则后续测试无法通过。

申请 appid 流程：上传真实在投包体至应用管理平台，完成 app 相关信息和资质填写后，即可获取到对应的 appid ，用于后续 SDK 对接。

窗口期配置：在望舒投放模块中的窗口期配置 appid 和上报条件，目前只支持安卓，请注意应用选择的产品渠道；

## 快速集成

**引入仓库**

在 project 级别的 build.gradle 中添加 maven 仓库。

```java
    // 在allprojects的repositories中添加maven仓库
    allprojects {
    repositories {
    maven {
    url 'https://artifact.bytedance.com/repository/Volcengine/'
    }
    // 其他仓库
    }
    }
```

## 导入望舒SDK

在 app module 级别的 .gradle 文件中，在 dependencies 里引入 SDK。


:::tip[版本说明]
`version` 为 SDK 版本号（替换为实际版本号），最新版本请从 [更新日志](/docs/开发者文档/入门指南/更新日志/Android) 中查看。
:::

```groovy
 implementation 'com.ruixue:rxsdk_bytedance_log:${version}'

```
