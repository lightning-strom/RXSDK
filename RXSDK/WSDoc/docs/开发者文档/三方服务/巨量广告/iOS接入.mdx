## SDK概述

**主要功能**

通过在望舒投放模块中的窗口期配置进行动态上报（假回传）；

**接入准备**

正式接入前请务必仔细阅读商业开放平台关于 SDK 接入流程的介绍，并且在巨量引擎广告投放平台官网成功申请真实可用的 appid 之后再进行接入动作。

申请 appid 时请务必仔细阅读申请页关于申请 appid 的细则要求，并保证接入时写入的 appname、package 等字段信息与申请 appid 时填入的一致，否则后续测试无法通过。

申请 appid 流程：上传真实在投包体至应用管理平台，完成 app 相关信息和资质填写后，即可获取到对应的 appid ，用于后续 SDK 对接。

窗口期配置：在望舒投放模块中的窗口期配置 appid 和上报条件

## 快速集成

接入请前先做好准备工作。可通过 **pod** 方式接入 **RXBDASignalSDK** 组件，并使用 **RXBDASignalSDK** 相关功能。

在需要使用功能的类中引用头文件 `#import <RXBDASignalSDK/RXBDASignalSDK.h>`

## SDK 集成

编辑 Podfile 文件，添加如下配置：

```objectivec
pod 'RXBDASignalSDK'
```

## 初始化

**接口原型**

```objectivec
/**
 * 上报冷启动事件（激活）
 */
- (void)windowDidFinishLaunchingWithOptions:(NSDictionary *)launchOptions connectOptions:(UISceneConnectionOptions *)connetOptions;
```

**调用示例**

```java
- (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
    // Override point for customization after application launch.

    [[RXBDAsignalService sharedSDK] windowDidFinishLaunchingWithOptions:launchOptions connectOptions:nil];
    [[RXBDAsignalService sharedSDK] enableIdfa:YES];

    return YES;
}
```
