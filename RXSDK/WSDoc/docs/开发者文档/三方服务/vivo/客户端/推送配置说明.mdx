## 准备工作

vivo 开放平台地址：[https://dev.vivo.com.cn/](https://dev.vivo.com.cn/)

望舒系统地址：[企业管理后台中获取望舒地址](/docs/开发者文档/入门指南/准备工作)。

## 推送配置

### 登录 vivo 获取推送信息

登录 [vivo 开放平台](https://dev.vivo.com.cn/)，位置：**vivo 开放平台 > 应用分发 > 游戏列表 > 游戏详情页 > 消息推送**。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/RrrebE0sVo7SkQxwDhcc5NLlnVc.png)

获取关键配置： `AppID`、`Appkey`、`AppSecret`。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/VE7kbsjjfown8Bx6hBEc9Y8LnCd.png)

api 域名/v1/pusher/notify/vivo?product_id=产品 ID&channel_id=渠道 ID

### 望舒系统中配置推送信息

从 vivo 平放平台获取 `AppID`、`Appkey`、`AppSecret` 信息。

复制到望舒系统，位置：**渠道管理 > 渠道包管理 > 推送配置 > 添加推送方式**。

是否测试环境配置 1 或 0 ， 1 为测试环境， 0 为正式环境。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/vivo/push/push_ruixue.jpg)
