## SDK集成

打开 mainTemplate.gradle 文件，在 dependencies 中新增：


:::tip[版本说明]
`version` 为 SDK 版本号（替换为实际版本号），最新版本请从 [更新日志](/docs/开发者文档/入门指南/更新日志/Unity) 中查看。
:::

```groovy
 //4399，渠道库必接一个
 implementation 'com.ruixue:rxsdk_9game:${version}'
```

## 配置说明
1、游戏包名称命名规范全新游戏包名使用".aligames"，仅需出一个游戏包，接入九游 SDK 即可，包于开放平台上传即可，已在九游上线过的游戏，保持原包名不改

2、icon 图片游戏图标需增加九游角标，角标位置在接入包内“角标 logo 及使用说明”文件夹下，添加角标后在 AndroidManifest.xml 中指定。如 android:icon="@drawable/iconuc"。其中 iconuc 为在原游戏图标基础上制作的能表明九游渠道的图标文件。

3、游戏包体在开放平台提审时，九游这边会对游戏包体进行重签名。游戏若有加固的，请改为支持修改游戏包，或不加固。

 游戏需支持 SDK 修改的地方：

1 ）将游戏 META-INF 删除重签名

2 ）修改游戏 assets 下 ucgamesdk 目录

3 ） assets 下添加 UCGameConfig.ini 文件

4 ） res 下替换 icon 文件

4.【新增】更新/接入 SDK 的时候，请在 SDK 初始化之前，先弹出游戏自己的隐私协议

### 初始化第三方渠道

```csharp

Dictionarystring, object> map = new();

// 设置 SDK 屏幕方向
// ActivityInfo.SCREEN_ORIENTATION_LANDSCAPE 横屏（默认值）
// ActivityInfo.SCREEN_ORIENTATION_PORTRAIT 竖屏
map.put("screen_orientation", ActivityInfo.SCREEN_ORIENTATION_LANDSCAPE);

// 如果游戏已经申请了权限，不想sdk主动请求权限，避免重复弹授权弹窗被拒
// true 游戏已经弹了，SDK不需要弹出权限申请窗
// false 游戏没有弹，SDK可以按需弹出权限申请窗(默认值)
map.put("had_req_permission", false)

RuiXueSdk.InitThirdSdk(map, InitThirdSdkResponseDelegate, InitThirdSdkErrorDelegate);

public void InitThirdSdkResponseDelegate(string data)
{
 LogUtil.Log("EventManager", $"RequestResponseDelegate: {data}");
}
public void InitThirdSdkErrorDelegate(string data)
{
 LogUtil.Log("EventManager", $"RequestErrorDelegate: {data}");
}

```
