## 配置说明

1、游戏包名称命名规范全新游戏包名使用".aligames"，仅需出一个游戏包，接入九游 SDK 即可，包于开放平台上传即可，已在九游上线过的游戏，保持原包名不改

2、icon 图片游戏图标需增加九游角标，角标位置在接入包内“角标 logo 及使用说明”文件夹下，添加角标后在 AndroidManifest.xml 中指定。如 android:icon="@drawable/iconuc"。其中 iconuc 为在原游戏图标基础上制作的能表明九游渠道的图标文件。

3、游戏包体在开放平台提审时，九游这边会对游戏包体进行重签名。游戏若有加固的，请改为支持修改游戏包，或不加固。

 游戏需支持 SDK 修改的地方：

1 ）将游戏 META-INF 删除重签名

2 ）修改游戏 assets 下 ucgamesdk 目录

3 ） assets 下添加 UCGameConfig.ini 文件

4 ） res 下替换 icon 文件

4.【新增】更新/接入 SDK 的时候，请在 SDK 初始化之前，先弹出游戏自己的隐私协议

## 初始化 SDK

首先，您需要在程序开始的地方初始化，通过调用 initThirdSdk 方法初始化九游游戏 SDK。

在初始化失败的状态下，游戏不应继续调用 SDK 的其余 API ，此方法必须在 UI 线程中调用。

游戏启动后，非初始化失败或异常情况下，不允许多次调用初始化接口。

```java
Map<String,Object> thirdSdkParams=new HashMap<>();
// 设置 SDK 屏幕方向
// ActivityInfo.SCREEN_ORIENTATION_LANDSCAPE 横屏（默认值）
// ActivityInfo.SCREEN_ORIENTATION_PORTRAIT 竖屏
thirdSdkParams.put("screen_orientation", ActivityInfo.SCREEN_ORIENTATION_LANDSCAPE);

// 如果游戏已经申请了权限，不想sdk主动请求权限，避免重复弹授权弹窗被拒
// true 游戏已经弹了，SDK不需要弹出权限申请窗
// false 游戏没有弹，SDK可以按需弹出权限申请窗(默认值)
thirdSdkParams.put("had_req_permission", false)
RuiXueSdk.getRXSdkApi().initThirdSdk(activity, thirdSdkParams, new RXRequestCallback() {
    @Override
    public void onResponse(JSONObject jsonObject) {
    int code = jsonObject.optInt("code", -1);
    if (code == 0) {
    //todo 成功
    }else {
    //todo 失败
    }
    }
});
```

    }

## 退出 (必须接入)

当游戏退出前必须调用该方法，进行清理工作。如果游戏直接退出，而不调用该方法，可能会出现未知错误，导致程序崩溃。

```java
// 在游戏需要退出的地方调用该方法，如游戏主 Activity，中 onBackPressed() 应该需要调用此方法
RuiXueSdk.getApi().exitApp(activity, new new OnAppExitCallback() {
    @Override
    public void onExitConfirm(@Nullable String res) {
    // 退出成功
    }
});
```

## 游戏账号切换

参考代码

```java
RuiXueSdk.setRuiXueSdkCallback(new RuiXueSdkCallback() {

    // ... 省略了一些无关代码

    /**
    * 切换账号全局回调,如果有游戏内切换账号可关注此回调
    * @param code 0
    * @param data 三方数据
    */
    @Override
    public boolean onSwitchAccount(int code, String data) {
    // 调用方如果有要处理的逻辑放在此处
    // 返回 true，望舒sdk，会执行 logout 操作
    // 返回 false，望舒sdk 不执行任何操作
    return true;
    }
});
```
