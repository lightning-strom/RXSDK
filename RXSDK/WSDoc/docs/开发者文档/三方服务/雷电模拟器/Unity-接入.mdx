## SDK集成

[官方文档](https://docs.ldmnq.com/docs/3iyTEo)

在 mainTemplate.gradle 添加


:::tip[版本说明]
`version` 为 SDK 版本号（替换为实际版本号），最新版本请从 [更新日志](/docs/开发者文档/入门指南/更新日志/Unity) 中查看。
:::

```groovy
 implementation 'com.ruixue:rxsdk_ld:${version}'
```

## 配置说明

在 AndroidManifest.xml 添加

```xml

 <meta-data android:name="GAME_ID" android:value="10000">
 <meta-data android:name="CHANNEL_ID" android:value="10001">
 <meta-data android:name="SUN_CHANNEL_ID" android:value="10002">
 注意：GAME_ID 如果和游戏有冲突，可改为LD_GAME_ID
```

## 初始化

```csharp
 private void Awake()
 {
 Dictionarystring, object> map = new();
 map.Add("ld_app_key", "82451108656044469d666b73573688c8");
 RuiXueSdk.InitThirdSdk(map, InitThirdSdkResponseDelegate, InitThirdSdkErrorDelegate);

 }

 public void InitThirdSdkResponseDelegate(string data)
 {
 LogUtil.Log("EventManager", $"RequestResponseDelegate: {data}");
 }

 public void InitThirdSdkErrorDelegate(string data)
 {
 LogUtil.Log("EventManager", $"RequestErrorDelegate: {data}");
 }
```
