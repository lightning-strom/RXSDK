## 准备工作

steamworks 平台地址：[https://partner.steamgames.com/apps/](https://partner.steamgames.com/apps/)

望舒系统地址：[企业管理后台中获取望舒地址](/docs/开发者文档/入门指南/准备工作)。

创建包含 steam 相关的渠道，渠道分类为 PC ：[创建渠道](/docs/开发者文档/入门指南/准备工作)

## 登录配置

### steam开放平台获取配置

登录[steamworks 平台](https://partner.steamgames.com/apps/)，位置：**首页>应用与程序包>所有应用程序>选择应用>Steamworks 管理员**。获取关键配置： `appid`。

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1744423205648.png)

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1744423275521.png)

获取 ` 发行商密钥 `。 如果要创建发行商 Web API 密钥：

如果是具有您 Steamworks 帐户管理员权限的用户，首先请在“用户与权限”下的“管理组”中访问组列表。

在组列表中选择或创建包含有您希望能用 Web API 密钥进行访问的 App ID 的组。

点击该组以浏览组中的用户及应用程序。

如您有管理权限，您应能看见右侧的“创建 WebAPI 密钥”选项。 或密钥如已创建，您应可看到密钥。

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1744424466084.png)

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1744424582125.png)

### steamworks开启应用内购买

正式版游戏需要开启支付功能。登录[steamworks 平台](https://partner.steamgames.com/apps/)，位置：**首页>应用与程序包>所有应用程序>选择应用>商店管理员**。进入 ` 基本信息 ` 找到下方的 ` 支持功能 ` 勾选应用内购买并保存。

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1744425394942.png)

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1744425420528.png)

### 望舒系统中配置支付信息

获取到的参数填写到望舒系统，位置：**资源管理>三方账号管理 > 支付账号管理 > 新建 steam 支付账号**。

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1744418658277.png)

## 计费点配置

### steamworks配置商品

登录[steamworks 平台](https://partner.steamgames.com/apps/)，位置：**steamworks > 应用与程序包>所有应用程序>选择应用>Steamworks 管理员>社区>库存服务>物品定义**。[steam 配置商品](https://partner.steamgames.com/doc/features/inventory/schema)

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1744424865130.png)

` 物品定义 ID` 由配置自定义，应与望舒系统计费点管理的「三方计费标识」配置一致。

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1744424891762.png)

### 望舒系统中配置计费点信息

[steamworks 平台](https://partner.steamgames.com/apps/) 获取 ` 物品定义 ID` 信息，填写到「三方计费标识」。

复制到望舒系统，位置：**项目管理 >计费点管理 > 添加计费点>选择关联三方计费点**。
