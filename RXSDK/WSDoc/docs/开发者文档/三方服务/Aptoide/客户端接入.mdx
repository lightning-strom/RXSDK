## 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| catappult_public_key | String | catappult API 密钥 initThirdSdk 接口传入 |


## SDK集成


:::tip[版本说明]
`version` 为 SDK 版本号（替换为实际版本号），最新版本请从 [更新日志](/docs/开发者文档/入门指南/更新日志/Android) 中查看。
:::

```groovy
 implementation 'com.ruixue:rxsdk_catappult:${version}'
```

## 支付

```java

    Map<String, Object> hashMap = new HashMap<>();
    // 计费点
```
