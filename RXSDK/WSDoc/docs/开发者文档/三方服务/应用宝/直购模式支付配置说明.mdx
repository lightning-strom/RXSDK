## 准备工作

腾讯开放平台：[https://op.open.qq.com/](https://op.open.qq.com/)望舒系统地址：[企业管理后台中获取望舒地址](/docs/开发者文档/入门指南/准备工作)。

### 腾讯开放平台获取信息

登录 [腾讯开放平台](https://op.open.qq.com/) ，位置：**我的应用** **> 点击对应应用 > 首页** 。

获取关键配置： `AppID`、`AppKey`。

配置支付回调地址。回调地址可以从**望舒游戏平台>首页>筛选渠道包>复制参数>支付参数>获取需要的支付方式的回调地址**

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/yingyongbao/pay/pay_param.png)

### 应用宝后台开启直购模式

位置：**我的应用** **> 点击对应应用 > 基础服务>支付管理>接入计费**

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/yingyongbao/pay/pay_ysdk1.jpg)

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/yingyongbao/pay/pay_ysdk2.jpg)

**配置支付回调地址。**

API 域名/v1/ke/callback/f_channel/产品 ID/渠道 ID/ysdk

发布正式环境后会产生正式支付 AppKey。将首页获取的 appkey 替换为正式支付 AppKey。

### 望舒系统中配置支付信息

通过获取的 `AppID`、`AppKey` 复制到望舒系统，位置：**企业管理后台 > 商务管理> 三方账号管理 > 支付账号管理 > 新建支付账号**。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/yingyongbao/pay/pay_ruixue_purchase.jpg)

应用宝直购模式 直接消费不需要单独配置 3 方计费点
