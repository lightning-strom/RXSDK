## 准备工作

爱奇艺游戏开放平台地址：[http://developer.game.iqiyi.com/account/login](http://developer.game.iqiyi.com/account/login)

望舒系统地址：[企业管理后台中获取望舒地址](/docs/开发者文档/入门指南/准备工作)。

## 支付配置

### 爱奇艺游戏开放平台获取配置

登录[爱奇艺游戏开放平台](http://developer.game.iqiyi.com/account/logint)，位置：**首页>开发者后台 >H5 小游戏>选择游戏>获取设置**。

获取关键配置： ` 游戏 ID`、`Paykey`。

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1758098253424.png)

### 望舒系统中配置支付信息

复制到望舒系统，位置：**运维资源管理> 三方账号管理 > 支付账号管理 > 新建爱奇艺小游戏支付账号**。

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1758097800249.png)

### 开放平台配置回调地址

开放平台配置支付回调地址。位置：**首页>开发者后台 >H5 小游戏>选择游戏>详细信息>支付信息页**。

回调地址格式： API 域名/v1/ke/callback/f_channel/产品 ID/渠道 ID/minigame_iqiyi
