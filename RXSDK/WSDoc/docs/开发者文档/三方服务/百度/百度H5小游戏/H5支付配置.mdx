## 准备工作

百度小游戏开放平台地址：[https://houtai.baidu.com/](https://houtai.baidu.com/)

望舒系统地址：[企业管理后台中获取望舒地址](/docs/开发者文档/入门指南/准备工作)。

## 支付配置

### 百度H5开放平台获取配置

登录[百度 H5 开放平台](https://houtai.baidu.com/)，位置：**首页>游戏自助对接>游戏信息**。

获取关键配置： `api key`、`secret key`。

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1766131574984.png)

### 配置相关地址

将相关地址提供给百度的工作人员进行配置。其中：

**登录接口：** 为 H5 游戏地址。

**角色查询接口： API 域名/v1/thirdparty/notify/产品 ID/渠道 ID/baiduh5/role**

**支付接口： API 域名/v1/ke/callback/f_channel/产品 ID/渠道 ID/baiduh5**

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1766131803157.png)

### 望舒系统中配置登录信息

获取关键配置： `api key`、`secret key` 复制到望舒系统，位置：**运维资源管理 > 三方账号管理 > 添加百度 H5 支付方式**。其中渠道包信息中也需要配置对应的 `secret key`

![](https://haiqi-ruixue-test.oss-cn-beijing.aliyuncs.com/docOnline/image-1766132078252.png)
