## 准备工作

渠道后台地址：[https://open.vgamepop.com/zh-CN](https://open.vgamepop.com/zh-CN)

望舒系统地址：[企业管理后台中获取望舒地址](/docs/开发者文档/入门指南/准备工作)。

## 获取配置

在渠道后台下载 **公钥**。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/apkpure/ScreenShot_2026-04-14_172308_800.png)

### 支付相关回调配置

配置回调地址：

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/apkpure/ScreenShot_2026-04-14_172456_250.png)

支付回调： api 域名/v1/ke/callback/f_channel/产品 id/渠道 id/apkpure

### 望舒系统中配置信息

#### 支付配置

通过获取到的 ` 公钥 ` 复制到望舒系统,填写到支付账号的密钥中。位置：**运维资源管理> 三方账号管理 > 支付账号管理 > 新建支付账号**。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/tripartite/apkpure/ScreenShot_2026-04-14_173041_061.png)
