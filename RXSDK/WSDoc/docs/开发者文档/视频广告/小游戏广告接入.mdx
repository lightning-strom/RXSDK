## 激励广告


### JS

### 参数说明

| **字段** | **类型**      | **是否必填** | **备注**     |
| ------------ | ----------------- | ---------------- | ---------------- |
| params   | IAd           | 是           | 参数         |
| callback | IMethodParams | 是           | 回调函数集合 |

> IAd 说明

| **字段** | **类型** | **是否必填** | **备注**                                                                                    |
| ------------ | ------------ | ---------------- | ----------------------------------------------------------------------------------------------- |
| func | string   | 否           | 埋点标记，可在望舒社交分享-广告管理工具配置，同一埋点只能关联一种广告类型，如需关联多种广告类型请使用[调度方式](https://doc.ruixueyun.com/main/#/view?viewPath=caa1a302-425a-42ae-b3df-cc8a4b97ec37&title=%E8%B0%83%E5%BA%A6%E5%88%86%E4%BA%AB(%E5%88%86%E4%BA%AB%E3%80%81%E5%B9%BF%E5%91%8A)&tab=&index=1)                                                                                  |
| adUnitId | string   | 否           | 广告单元 id，若传则使用此id，若不传则取埋点对应配置广告单元id                                                                                 |
| multiton  | boolean   | 否           | 是否启用多例模式                                                                                 |
| destroyAd  | boolean   | 否           | 是否销毁当前广告（单例模式下销毁当前广告，相同广告位不能再次拉起）                                                                                 |
| isCheck  | boolean  | 否           | 是否仅检测能否拉取广告, 而不显示`ture` 表示仅检测能否拉取广告，返回结果包含激励广告实例 |
| custom_ext         | CustomExt   | 否           |自定义透传参数 |

> `CustomExt  ` 字段说明

| **字段**  | **类型** | **是否必填** | **备注** |
| --------- | ------  | ----------- |---------|
| bigdata_ext| object| 否             | 大数据预置事件透传参数                          |

> IMethodParams 说明

| **字段** | **备注**                                                  |
| ------------ | ------------------------------------------------------------- |
| complete | (data) => voidcomplete：为函数且必传，data 为结果数据 |
| fail | (err) => void非必传，err为拉取广告失败结果数据1、传入adUnitId为错误的广告位id，调用rewardedVideoAd拉取广告失败，会走入该回调2、若未传入adUnitId，且func埋点对应的广告管理配置广告位id为空或为错误的，调用rewardedVideoAd拉取广告失败，会走入此回调3、若未传入adUnitId，调用流程错误，如func埋点对应当前调度为share，使用rewardedVideoAd拉取广告位id为空，则拉取广告失败，会走入该回调4、还有其他场景，拉取广告失败，会走入该回调 |

**调用示例**
```javascript
sdk.rewardedVideoAd(
  {
    func: 'test',
    adUnitId: "adunit-4de541945b96fxxx",
    multiton: true,
    destroyAd: true
  },
  {
    complete: (data) => {
      console.log(data);
    },
    fail: (err) => {
      console.log(err);
    },
  }
);
```

## 激励广告

**响应示例**

```text
{
    "code": 0,
    "isEnded": false
    "ad": {load: ƒ, show: ƒ, onClose: ƒ, offClose: ƒ, onError: ƒ, …},
    "adUnitId": "81d0635de0cabb5dc47447a2cea353f3",
    "isCheck": true
}
```

### 响应结构

| **字段** | **类型** | **备注** |
| ------------ | --------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| code | number | 0，表示成功 |

| ad | object | 激励视频广告组件 请参考 [微信小游戏激励视频广告 API ](https://developers.weixin.qq.com/minigame/dev/api/ad/RewardedVideoAd.html) |
| adUnitId | string | 请求的参数，如果传了，原样返回，否则字段不存在 |
| isCheck | boolean | 请求的参数，如果传了，原样返回，否则字段不存在 |

## 常见错误码(第三方平台侧)

| 错误 code | 说明 |
| --- | --- |
| **1000** | 后端接口调用失败 |
| **1001** | 参数错误 |
| **1002** | 广告单元无效 |
| **1003** | 内部错误 |
| **1004** | 无合适的广告 |
| **1005** | 广告组件审核中 |
| **1006** | 广告组件被驳回 |
| **1007** | 广告组件被封禁 |
| **1008** | 广告单元已关闭 |

## 激励广告

### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| params | IAd | 是 | 参数 |
| callback | IMethodParams | 是 | 回调函数集合 |

> IAd 说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| adUnitId | string | 否 | 广告单元 id ，若传则使用此 id ，若不传则取埋点对应配置广告单元 id |
| func | string | 否 | 埋点标记，可在望舒社交分享-广告管理工具配置 |
| isCheck | boolean | 否 | 是否仅检测能否拉取广告, 而不显示 |
| destroyAd | boolean | 否 | 是否关闭广告时销毁广告组件 |

`true` 表示仅检测能否拉取广告，返回结果包含激励广告实例

`true` 表示销毁广告组件

> IMethodParams 说明

| 字段 | 备注 |
| --- | --- |
