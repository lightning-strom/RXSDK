使用阿里云短信服务发送验证码前，需先在阿里云控制台完成**短信签名**与**短信模板**申请，审核通过后将模板 **Template Code** 配置到望舒后台。

## 如何申请短信模版

可参考下方视频操作，主要步骤如下：

1. 登录 [阿里云控制台](https://home.console.aliyun.com/)
2. 进入 **短信服务** > **国内消息** > **签名管理**，申请并等待签名审核通过
3. 进入 **模板管理** > **添加模板**，选择验证码类模板并填写模板内容
4. 模板审核通过后，在模板列表中复制 **Template Code**（模板 CODE）
5. 将签名、模板 CODE 及 AccessKey 等信息配置到望舒企业管理后台对应服务商参数中

:::
