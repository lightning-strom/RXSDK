## HTTP Headers 定义

望舒的自定义头并没有采用 "X-" 开头的公共前缀范例，而是以 "ruixue-" 开头。**注意：为避免产生歧义，所有望舒头参数全部为"小写"字母。**

### 客户端请求头

> Accesstoken 鉴权方式

| 参数名 | 说明 | 是否必须 | 示例 |
| --- | --- | --- | --- |
| ruixue-traceid | 本次请求唯一标识（UUID v4），接口出现错误时可提供给望舒团队快速定位 | 是 | `0e2971af-823a-4298-b7d8-3ef38094b500` |
| ruixue-cpid | 望舒 CPID，望舒为每个 CP 分配的唯一 ID，从 7 位数 1000000 开始递增 | 是 | `1000000` |
| ruixue-productid | 产品标识，CP 在望舒后台自行创建，字符串类型 | 是 | `test` |
| ruixue-channelid | 渠道标识，CP 在望舒后台自行创建，字符串类型 | 是 | `test` |
| ruixue-platformid | 客户端类型：1=Android，2=iOS，3=H5，4=微信小程序，5=web，6=鸿蒙，10=望舒服务端 SDK | 是 | `2` |
| ruixue-devicecode | 设备码，通过策略推导生成的 C 端设备唯一标识（受系统限制，可能无法获取或不 100% 唯一） | 否 | `abcdefghijklmnopqrstuvwxyz123456` |
| ruixue-language | 系统语言标识 | 否 | `zh-CN` |
| ruixue-version | SDK 版本号 | 否 | `ios-v2.0.0` |
| ruixue-accesstoken | 望舒通行证授权令牌，C 端用户登录后由通行证分发，访问需鉴权的接口时必须携带 | 否 | 见下方示例 |
| ruixue-tzoffset | 基于 UTC 的时区偏移值（小时），不指定时默认为 8（北京时间东 8 区） | 否 | `8` |
| [ruixue-area](/docs/开发者文档/支付/服务端接入/国家编码-币种字典) | 地区编码 | 否 | `CN` |

### 服务端请求头

> CPSign 鉴权方式

| 参数名 | 说明 | 是否必须 | 示例 |
| --- | --- | --- | --- |
| ruixue-traceid | 本次请求唯一标识（UUID v4），接口出现错误时可提供给望舒团队快速定位 | 是 | `0e2971af-823a-4298-b7d8-3ef38094b500` |
| ruixue-cpid | 望舒 CPID，望舒为每个 CP 分配的唯一 ID，从 7 位数 1000000 开始递增 | 是 | `1000000` |
| ruixue-cpts | 时间戳，CP 服务端发起请求时的毫秒时间戳 | 是 | `1669619948739` |
| ruixue-cpsign | 请求签名，签名规则：`sha1(traceid + cpts + cpkey)` | 是 | `dc87e3db3ec7a0a8edbd470abd58107ae1b66268` |
| ruixue-productid | 产品标识，CP 在望舒后台自行创建，字符串类型 | 是 | `test` |
| ruixue-language | 系统语言标识 | 否 | `zh-CN` |
| ruixue-version | SDK 版本号（直接调用时不需要此字段） | 否 | `go-v2.0.1` |
| ruixue-tzoffset | 基于 UTC 的时区偏移值（小时），不指定时默认为 8（北京时间东 8 区） | 否 | `8` |
| ruixue-servicemark | CP 游戏服的标识信息 | 否 | `default` |
| ruixue-region | CP 游戏服的分区信息 | 否 | `default` |
| ruixue-cp-role-id | CP 游戏服的角色信息 | 否 | `default` |

## 服务端回调接口

望舒系统接入前，请仔细阅读本条款。**请确认要使用的功能，必须实现对应的接口！！！** 接口实现完成后，需要在望舒系统（产品管理 > 回调参数配置）调试与配置。
