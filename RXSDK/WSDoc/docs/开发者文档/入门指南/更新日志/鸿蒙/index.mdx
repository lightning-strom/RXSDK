望舒鸿蒙 SDK 支持 **原生 ArkTS** 与 **团结引擎** 两条接入线。请根据项目技术栈选择对应文档，SDK 版本需与更新日志中的版本号对齐。

[SDK 下载地址](https://pan.jiaxianghudong.com/s/RmAwUrbm4hM)

:::tip[环境要求（以最新版本为准）]
团结引擎接入线建议：**团结引擎 1.6.7+**、**DevEco Studio 6.0 Release+**、**OpenHarmony API 14+**。具体版本约束以各更新日志条目为准。
:::
