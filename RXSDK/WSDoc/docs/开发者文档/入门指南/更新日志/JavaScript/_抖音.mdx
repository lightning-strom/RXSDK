## v3.10.8 更新时间 2025-6-17
**功能更新**
- Feed 推荐流预置事件上报逻辑调整：
  - 预加载注册：**注册事件（#register）** 新增 **is_preload** 属性；
  - 预加载登录：新增 **#preload** 事件，原有 **#login** 事件预加载时不上报，用户从推荐流点击进入游戏后补报 **#login** 事件，客户端在 **feedEnter** 中调用 **sdk.trackLogin()**，未进入游戏不上报 **#login** 事件；
注意：以上改动仅针对推荐流预加载流程产生的望舒预置事件，游戏事件请自行处理，非推荐流方式进入游戏未改动。

```javascript
// 监听 Feed 流进入/退出小游戏事件
function feedChangeCallback({ type }) {
    if (type === 'feedEnter') {
        console.log('触发从Feed流进入小游戏事件回调')
        
        // 上报登录事件，sdk内部会对预加载登录事件进行上报
        sdk.trackLogin()
    }
    if (type === 'feedExit') {
        console.log('触发从小游戏退回到Feed流事件回调')
    }
}

// 注册事件监听
tt.onFeedStatusChange(feedChangeCallback);

// 取消事件监听
tt.offFeedStatusChange(feedChangeCallback);
```
