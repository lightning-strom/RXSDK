各平台 SDK 更新日志按客户端类型分文档维护。接入或升级前请对照对应日志确认版本号与依赖组件版本。

:::tip[版本核对]
- **iOS / Android**：控制台搜索 `RXSDK--` 确认主库版本
- **Unity**：对照 Unity 包版本与各原生 SDK 依赖版本
- **小游戏 / H5**：按渠道 Tab 查看 JavaScript SDK 版本
:::
