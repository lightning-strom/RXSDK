## SDK 初始化

初始化为异步调用，失败将不能使用 SDK 功能，请注意处理调用逻辑。

初始化 SDK 时需传入 `productId`、`channelId`、`cpid`、`baseUrlList` 参数信息。


| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| string | 是 | 产品 id ，望舒游戏发行平台创建产品，[查看使用说明](/docs/开发者文档/入门指南/准备工作)。 | **channelId** |
| string | 是 | 渠道 id ，望舒游戏发行平台创建渠道，[查看使用说明](/docs/开发者文档/入门指南/准备工作)。 | **cpid** |
| string | 是 | CP id ，望舒企业管理后台创建项目，[查看使用说明](/docs/开发者文档/入门指南/准备工作)。 | **baseUrlList** |
| string[] | 是 | 请求域名队列，望舒企业管理后台创建项目，[查看使用说明](/docs/开发者文档/入门指南/准备工作)。 | **complete** |
| function | 是 | 初始化回调函数 |  |


接口实例：

```javascript
// 路径仅为示例，需要传入SDK在项目中的真实路径，如出现引用错误请检查路径是否正确
const channelSdk = require("your path/channelSDK/index.js")
//以下参数为测试参数，需要更换为接入方对应的参数
const sdk = new channelSdk({
 productId: '1', //产品 id
 channelId: '818', //渠道id
 cpid: '49', //cpid
 baseUrlList: ['https://ruixue.weiletest.com'],//请求域名队列
 complete: (data) => {
 console.log('init complete: ', data)
 if (data.code === 0) {
 // 初始化成功
 }
 },
})
```

### 设置子渠道

通行证记录来源（分包）、子渠道参数。必须在 登录 前调用。

#### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| params | string | 是 | 子渠道 id |

**调用示例**

```javascript
// 同步函数
const result = sdk.setSubChannelId('your sub_channel_id')
console.log('setSubChannelId res: ', result)
```

#### 响应结构

成功 code 为 0

### 设置自定义返回错误消息

规则 1 ：根据错误码直接读取对应提示替换 msg ；

规则 2 ：如果表中有 default 的 key ，将未配置的错误码 msg 统一替换为 default 的 value ；

规则 3 ：$code$ $thirdcode$ $thirdmsg$ 为动态配置字段，如下所示，最终展示的信息为 支付错误 4002

以上规则仅适用于调用了 setErrorMsg 接口，未调用保持原有规则

**调用示例**

```javascript
// 同步函数
sdk.setErrorMsg({
 4001: 'cancel pay',
 4002: '支付错误$code$',
 2001: 'init fail',
 default: 'default$code$$thirdcode$'
})
```

### 清除自定义返回错误消息

**调用示例**

```javascript
// 同步函数
sdk.clearErrorMsg()
```

## 接入功能

SDK 提供了众多功能。请在初始化 SDK 后，根据项目需要，参考相应功能的文档，接入相应功能。 绝大多数游戏都会接入望舒登录，所以我们推荐从这一功能开始。

### 游戏场景上报

[淘宝开放平台文档](https://miniapp.open.taobao.com/doc.htm?spm=a21j26.28113440.0.0.267f1fd6EKR2Fw&docId=121853&docType=1&tag=game-dev)

#### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| params | IParams | 是 | 参数 |

> IParams 说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| sceneId | number | 是 | 场景 ID |
| costTime | number | 否 | 耗时 |
| timestamp | string | 否 | 当前时间戳 |
| extra | number | 否 | 额外携带的参数 |
| extra.money | number | 否 | 付费金额 |

**调用示例**

```javascript
sdk.reportScene({
 sceneId: 100,
 timestamp: Date.now(),
 costTime: 2000,
})
```
