## SDK 初始化

初始化为异步调用，失败将不能使用 SDK 功能，请注意处理调用逻辑

初始化 SDK 时需传入 `productId`、`channelId`、`cpid`、`baseUrlList` 参数信息。


| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| string | 是 | 产品 id ，望舒游戏发行平台创建产品，[查看使用说明](/docs/开发者文档/入门指南/准备工作)。 | **channelId** |
| string | 是 | 渠道 id ，望舒游戏发行平台创建渠道，[查看使用说明](/docs/开发者文档/入门指南/准备工作)。 | **cpid** |
| string | 是 | CP id ，望舒企业管理后台创建项目，[查看使用说明](/docs/开发者文档/入门指南/准备工作)。 | **baseUrlList** |
| string[] | 是 | 请求域名队列，望舒企业管理后台创建项目，[查看使用说明](/docs/开发者文档/入门指南/准备工作)。 | **appid** |
| string | 是 | 当前小游戏 appid | **complete** |
| function | 是 | 初始化回调函数 |  |


接口实例：

```javascript
// 路径仅为示例，需要传入SDK在项目中的真实路径，如出现引用错误请检查路径是否正确
const channelSdk = require("your path/channelSDK/index.js")
//以下参数为测试参数，需要更换为接入方对应的参数
const sdk = new channelSdk({
 productId: '1', //产品 id
 channelId: '818', //渠道id
 cpid: '1000049', //CP id
 appid: 'xxxx', // 小游戏appid
 baseUrlList: ['https://ruixue.weiletest.com'],//请求域名队列
 complete: (data) => {
 console.log('init complete: ', data)
 if (data.code === 0) {
 // 初始化成功
 }
 },
})
```

### 设置子渠道

通行证记录来源（分包）、子渠道参数。必须在 登录 前调用。

#### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| params | string | 是 | 子渠道 id |

**调用示例**

```javascript
// 同步函数
const result = sdk.setSubChannelId('your sub_channel_id')
console.log('setSubChannelId res: ', result)
```

#### 响应结构

成功 code 为 0

### 设置自定义返回错误消息

规则 1 ：根据错误码直接读取对应提示替换 msg ；

规则 2 ：如果表中有 default 的 key ，将未配置的错误码 msg 统一替换为 default 的 value ；

规则 3 ：$code$ $thirdcode$ $thirdmsg$ 为动态配置字段，如下所示，最终展示的信息为 支付错误 4002

以上规则仅适用于调用了 setErrorMsg 接口，未调用保持原有规则

**调用示例**

```javascript
// 同步函数
sdk.setErrorMsg({
 4001: 'cancel pay',
 4002: '支付错误$code$',
 2001: 'init fail',
 default: 'default$code$$thirdcode$'
})
```

### 清除自定义返回错误消息

**调用示例**

```javascript
// 同步函数
sdk.clearErrorMsg()
```

### 获取窗口信息

#### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| callback | IMethodParams | 是 | 回调函数集合 |
| **字段** | **备注** | complete | (data) => void |

complete ：为函数且必传， data 为结果数据

#### 调用示例

```javascript
sdk.getWindowInfo();
```

#### 响应结构


| 字段 | 类型 | 说明 |
| --- | --- | --- |
| pixelRatio | number | 设备像素比 |
| screenWidth | number | 屏幕宽度，单位 px |
| screenHeight | number | 屏幕高度，单位 px |
| windowWidth | number | 可使用窗口宽度，单位 px |
| windowHeight | number | 可使用窗口高度，单位 px |
| statusBarHeight | number | 状态栏的高度，单位 px |
| safeArea | Object | 竖屏正方向下的安全区域 |
| screenTop | number | 窗口上边缘的 y 值 |


##### safeArea


| 字段 | 类型 | 说明 |
| --- | --- | --- |
| left | number | 左上角横坐标 |
| right | number | 右下角横坐标 |
| top | number | 左上角纵坐标 |
| bottom | number | 右下角纵坐标 |
| width | number | 安全区域的宽度 |
| height | number | 安全区域的高度 |
