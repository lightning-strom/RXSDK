## SDK 初始化

注意：如需要在 game.html 的 body 中放置一个 id 为 `sdk-container` 的 dom 节点用来放置登录、帮助中心、服务条款等界面

```html
div id='sdk-container'>div>
```

初始化 SDK 时需传入 `productId`、`channelId`、`cpid`、`baseUrlList` 参数信息。


| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| string | 是 | 产品 id ，望舒游戏发行平台创建产品，[查看使用说明](/docs/开发者文档/入门指南/准备工作)。 | **channelId** |
| string | 是 | 渠道 id ，望舒游戏发行平台创建渠道，[查看使用说明](/docs/开发者文档/入门指南/准备工作)。 | **cpid** |
| string | 是 | CP id ，望舒企业管理后台创建项目，[查看使用说明](/docs/开发者文档/入门指南/准备工作)。 | **baseUrlList** |
| string[] | 是 | 请求域名队列，望舒企业管理后台创建项目，[查看使用说明](/docs/开发者文档/入门指南/准备工作)。 | **complete** |
| function | 是 | 初始化回调函数 |  |


接口实例：

```javascript
// 路径仅为示例，需要传入SDK在项目中的真实路径，如出现引用错误请检查路径是否正确
const channelSdk = require("your path/channelSDK/index.js")
//以下参数为测试参数，需要更换为接入方对应的参数
const sdk = new channelSdk({
 productId: 'test_productId', //产品 id
 channelId: 'test_channelId', //渠道id
 cpid: 'test_cpId', //CP id
 baseUrlList: ['https://xxxx.com'],//请求域名队列
 complete: (data) => {
 console.log('init complete: ', data)
 if (data.code === 0) {
 // 初始化成功
 }
 },
})
```

## 接入功能

SDK 提供了众多功能。请在初始化 SDK 后，根据项目需要，参考相应功能的文档，接入相应功能。 绝大多数游戏都会接入望舒登录，所以我们推荐从这一功能开始。

### 望舒登录

请根据开发者指南，[登录（通行证）](/docs/开发者文档/登录-通行证/实名认证奖励道具/实名认证配置) 完成操作。

### 实名认证

请根据开发者指南，[实名认证](/docs/开发者文档/登录-通行证/实名认证奖励道具/实名认证配置) 完成操作。

### 注销账号

请根据开发者指南，[注销账号](/docs/开发者文档/登录-通行证/实名认证奖励道具/实名认证配置) 完成操作。

### 客服中心

请根据开发者指南，[客服中心](/docs/开发者文档/客服/服务端接入/帮助中心预览地址) 完成操作。

### 帮助中心

请根据开发者指南，[帮助中心](/docs/开发者文档/客服/服务端接入/帮助中心预览地址) 完成操作。

### 获取设备码

**调用示例**

```javascript
const result = sdk.getDeviceCode()
console.log('getDeviceCode: ', result)
```

### 服务条款

**调用示例**

```javascript
 sdk.openProtocol({
 protocol: {
 key: '00002', // 当前想展示协议的标识
 key_list: ['00002', '00003'] // 展示协议标识列表
 }
})
```

### 设置子渠道

通行证记录来源（分包）、子渠道参数。必须在 登录 前调用。

**调用示例**

```javascript
const result = sdk.setSubChannelId('your sub_channel_id')
console.log('setSubChannelId res: ', result)
```

### 上报大数据

需要在 SDK 初始化后调用！！！

#### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| params | ITrack | 是 | 参数 |
| callback | IMethodParams | 是 | 回调函数集合 |

> ITrack 说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| event | string | 是 | 埋点标识 |
| distinct_id | string | 否 | 用户唯一标识，一般为用户 ID （由 CP 调用时传入） |
| properties | object | 否 | 自定义属性 |

注意：

1、properties 中上传的属性内容，必须与在后台中添加的属性内容保持一致。否则数据无法统计。

2、properties 中上传的属性内容不能与以上字段重复。

> platform_id 说明

| 字段 | 备注 |
| --- | --- |
| 1 | 安卓 |
| 2 | iOS |
| 3 | H5 |
| 4 | 小程序 |
| 10 | 服务端 |

> IMethodParams 说明

| 字段 | 备注 |
| --- | --- |
| complete | (data) => void |

complete ：为函数且必传， data 为结果数据

**调用示例**

```javascript
sdk.track(
 {
 complete: (data) => {
 console.log(data);
 },
 },
 {
 event: "xxx",
 properties: {
 test1: "1",
 test2: "2",
 },
 }
);
```

### 设置公共属性

设置后由 SDK 填入自定义属性中进行上报，设置后 SDK 进行缓存，多次设置则会覆盖。

#### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| params | object | 是 | 例如： |

```json
{

 "property1" : "test1",

 "property2" : "test2",

 "property3" : "test3",

 "property4" : "test4"

}

**调用示例**

```javascript
// 同步函数
const result = sdk.setPublicProperties(
 {
 property1: 1,
 property2: 'test',
 }
)
console.log('setPublicProperties res: ', result)
```

### 修改公共属性

修改的属性会将原有属性覆盖，未设置的属性则会补入缓存中。

#### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| params | object | 是 | 例如： |

```json
{

 "property1" : "test1",

 "property2" : "test2",

 "property3" : "test3",

 "property4" : "test4"

}

**调用示例**

```javascript
// 同步函数
const result = sdk.updatePublicProperties(
 {
 property2: 'update',
 }
)
console.log('updatePublicProperties res: ', result)
```

### 删除公共属性

删除缓存的某个公共属性。

#### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| params | string[] | 是 | 参数 |

**调用示例**

```javascript
// 同步函数
const result = sdk.deletePublicProperties(['property1', 'property2', 'property3'])
console.log('deletePublicProperties res: ', result)
```

### 设置自定义返回错误消息

规则 1 ：根据错误码直接读取对应提示替换 msg ；

规则 2 ：如果表中有 default 的 key ，将未配置的错误码 msg 统一替换为 default 的 value ；

规则 3 ：$code$ $thirdcode$ $thirdmsg$ 为动态配置字段，如下所示，最终展示的信息为 支付错误 4002

以上规则仅适用于调用了 setErrorMsg 接口，未调用保持原有规则

**调用示例**

```javascript
// 同步函数
sdk.setErrorMsg({
 4001: 'cancel pay',
 4002: '支付错误$code$',
 2001: 'init fail',
 default: 'default$code$$thirdcode$'
})
```

### 清除自定义返回错误消息

**调用示例**

```javascript
// 同步函数
sdk.clearErrorMsg()
```
