## 环境要求

iOS 12 或更高版本

## 隐私权限

SDK 会获取一些设备相关信息，有些信息会涉及到隐私权限。部分渠道审核会有限制，请注意相关配置，并在审核模式下进行相关处理。

获取的相关信息不违反苹果审核条例，但要注意提审时的相关信息是否配置正确。

设备相关：（设备启动时间、国家、语言、设备名称、系统版本、设备 Machine、运营商、物理内存容量、硬盘内存容量、系统更新时间、设备 Model、设备时区、设备 mnt_id、设备初始化时间）生成 caid。

隐私相关：获取剪贴板内容、获取 IDFA、接入了定位功能需要获取定位权限。

### 用途

| 名称 | 备注 |
| --- | --- |
| 设备码 | 设备唯一标识，用于生成游客账号、大数据筛选条件 |
| oaid/caid | 广告标识，用于媒体平台投放归因 |

## SDK 集成

### 自动化集成（推荐）

在终端窗口中输入以下命令，安装 CocoaPods。

```objectivec
sudo gem install cocoapods
```

进入项目所在路径，在终端窗口中输入以下命令，创建 Podfile 文件。

```objectivec
pod init
```

编辑 Podfile 文件，添加 pod 'RXSDK_Pure'

```objectivec
pod 'RXSDK_Pure'
```

在终端窗口中输入以下命令。pod 命令执行完成后，会生成集成了的 SDK 的 .xcworkspace 后缀的工程文件，双击打开即可更新并安装 SDK。

```objectivec
pod install
```

更新执行 pod update

```objectivec
pod update
```

### 工程配置

**请求添加权限**

Info.plist 添加获取 IDFA 权限 **Privacy - Tracking Usage Description** 此标识符将用于向您推送个性化广告。

**关闭 Bitcode。**

由于 SDK 不支持 Bitcode ，所以需要在工程中关闭 Bitcode 选项，将 Enable Bitcode 置为 NO 状态即可。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/introduction/VhzwbdS5ioChGnxEj8lcNtrZnld.png)

**添加 Framework**

在 TARGETS > Project Name > General > Frameworks, Libraries, and Embedded Content 菜单，点击 +，将 AuthenticationServices 添加。

注：引用到 **RXSDK_Pure.framework** 的 **target** 都需要添加，否则会引起闪退问题。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/introduction/WechatIMG418.jpg)

在 TARGETS > Build Phases > Link Binary With Libraries 中将 Status 设置为 Optional。

![](https://guanwangyun.oss-cn-beijing.aliyuncs.com/document/introduction/WechatIMG419.jpg)

创建一个 swift 文件，否则会引起闪退。

## SDK 初始化（必须）

初始化 SDK 时需传入 `productId`、`channelId`、`cpid`、`baseUrlList` 参数信息。

`productId`、`channelId` 在望舒游戏发行平台获取（创建产品或渠道），[查看使用说明](/docs/开发者文档/入门指南/准备工作)。

`cpid`、`baseUrlList` 在望舒企业管理后台获取（创建项目），[查看使用说明](/docs/开发者文档/入门指南/准备工作)。

初始化为异步调用，失败将不能使用 SDK 功能，请注意处理调用逻辑。

**接口原型**

```objectivec
/**
 * 初始化SDK
 * 初始化后会 SDK 会自动激活
 * @param config 初始化配置
 */
- (void)initWithConfig:(RXSdkInitConfig *)config
 complete:(RequestComplete)complete;
```

### RXSdkInitConfig 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| productId | NSString | 是 | 产品 id |
| channelId | NSString | 是 | 渠道 id |
| cpid | NSString | 是 | cpid |
| baseUrlList | NSArray | 是 | 请求域名队列 |
| complete | Block | 是 | 回调函数 |
| launchOptions | NSDictionary | 是 | 启动参数， `- (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions` 中的 **launchOptions** |
| isLogEnable | NSString | 否 | 日志开关， debug 默认开启， release 默认关闭 |
| usePrivacy | BOOL | 否 | 首次启动是否展示用户隐私授权页面， YES 展示， NO 不展示，默认 NO 不展示 |
| agreementMap | NSMutableDictionary | 否 | 自定义协议键值对， key:00001 （ 00001 是示例，实际值是望舒协议 key ）或链接 value:《用户协议》 |
| agreementTitle | NSString | 否 | 协议标题，默认为 "用户协议和隐私政策" |
| isUseDNS | BOOL | 否 | 是否打开 DNS ， YES 打开， NO 关闭，默认为 NO ，需配合[阿里 DNS SDK](/docs/开发者文档/DNS/阿里DNS/原生接入)或[腾讯 DNS SDK](/docs/开发者文档/DNS/腾讯DNS/原生接入)使用 |
| openRacing | BOOL | 否 | 是否开启竞速， YES 开启 NO 关闭，默认 NO ，详情查看[openRacing 说明](#openracing-说明) |

#### openRacing 说明

baseUrlList 数量为 1 时 不生效。

开启竞速模式：当 baseUrlList 有多个时，根据网络请求响应速度对数组进行排序，后续 SDK 内部网络请求根据排序后的数组使用对应域名。

关闭竞速模式：当 baseUrlList 有多个时， SDK 内部网络请求根据数组顺序使用对应域名。

#### complete 说明

SDK 中使用的 complete 为通用结构，成功返回 response 不返回 error ，失败不返回 response 返回 error。

**response** 数据结构参照具体使用的 Api 响应结构；

**RX_CommonRequestError** 中包含 **error （ http 原始错误信息）** 和 **responesObject （望舒包装后的错误数据）**，正常使用中只需处理 **responesObject** 数据即可，**responesObject** 无返回数据时可通过 **error** 获取 iOS 原始错误信息排查问题；

**调用示例**

```objectivec
RXSdkInitConfig *config = [[RXSdkInitConfig alloc] init];
config.productId = @"your product id";
config.channelId = @"your channelid id";
config.cpId = @"your cpid id";
config.baseUrlList = @[@"https://xxx"];
[[RXSDK sharedSDK] initWithConfig:config complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
 if (!error) {
 NSLog(@"初始化成功");
 } else {
 NSLog(@"初始化失败");
 }
}];
```

- [iOS 登录 API](/docs/开发者文档/登录-通行证/iOS-登录API/快速接入)

### 支付

接入支付前，需要先完成 [服务端下单配置](/docs/开发者文档/支付/服务端接入/服务端-API)，客户端根据支付渠道选择对应接入方案：

- [苹果支付（IAP）](/docs/开发者文档/支付/苹果支付/快速接入) — App Store 内购，适用于 iOS 端虚拟货币、订阅等场景
- [拉卡拉支付](/docs/开发者文档/支付/拉卡拉支付/快速接入) — 第三方支付渠道
- [银联支付](/docs/开发者文档/支付/银联支付/快速接入) — 银联渠道支付

:::tip
支付接入流程：**服务端创建订单 → 客户端调起支付 → 服务端验单**，客户端不直接处理支付结果，以服务端回调为准。
:::
