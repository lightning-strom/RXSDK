## 准备工作

请登录望舒系统初始化相关服务，如果还没有望舒账号请[查看准备工作说明](/docs/开发者文档/入门指南/准备工作)。

望舒系统地址，可登录企业管理后台 > 已部署项目中查看。

## 环境要求

Android 5.0 （ API level 21 ）或更高版本

## 隐私权限

SDK 会获取一些设备相关信息，有些信息会涉及到隐私权限。部分渠道审核会有限制，请注意相关配置，并在审核模式下进行相关处理。

设备相关：（ imei、androidid、oaid、sn 号、主板、系统 boot 版本号、系统定制商、abi、显示屏参数、无线固件版本号、硬件制造商、硬件序列号、硬件名称、主机名、系统用户名、系统编译类型） hash 32 位生成设备码和 oaid。

如需在审核模式下禁用隐私权限请查看 [设置用户隐私相关功能](/docs/开发者文档/入门指南/快速开始/Android-SDK配置#设置用户隐私相关功能)。

注意：禁用后生成的设备码将会有大概率重复！

隐私相关：获取剪贴板内容、接入了定位功能需要获取定位权限。

### 用途

| 名称 | 备注 |
| --- | --- |
| 设备码 | 设备唯一标识，用于生成游客账号、大数据筛选条件 |
| oaid/caid | 广告标识，用于媒体平台投放归因 |

## SDK 集成

### 自动化集成（推荐）

配置 SDK 依赖：在 `app/build.gradle` 文件的 `dependencies` 块中引用望舒 `SDK` 依赖 `implementation 'com.ruixue:库名称:${ version }'` ，此处的 `version` 为对应的 SDK 版本号，最新 `version` 版本请从 [更新日志](/docs/开发者文档/入门指南/更新日志/Android) 中查看。

渠道库 ，以下库**单选 (必接一个)**

参考 [三方服务->渠道接入说明](/docs/开发者文档/三方服务/三方接入说明)

组件库 库可**多选(可接多个)**

参考三方服务对应三方组件库。

### 混淆配置

在应用级根目录下打开混淆配置文件 `proguard-rules.pro` ，加入排除 SDK 的混淆配置

```proguard
-keep class com.ruixue.** { *; }
```

### 工程配置

以下配置示例为 gradle 6.7.1 配置示例， gradle 版本非硬性要求，实际版本以项目本身为准。

在您的项目中，打开 `your_app | Gradle Scripts | build.gradle (Project)` 并将以下存储库添加到 `buildscript { dependencies {}}` 部分：

```groovy
//以当前项目gradle版本对应对应的插件版本为准
classpath "com.android.tools.build:gradle:4.2.2"
```

在您的项目中，打开 `your_app | Gradle Scripts | gradle-wrapper.properties` 并替换 `distributionUrl` 值：

```groovy
distributionUrl=https\://services.gradle.org/distributions/gradle-6.7.1-bin.zip
```

gradle.properties 配置

```groovy
android.useAndroidX=true
android.enableJetifier=true

#ysdk 渠道需要添加
android.useNewApkCreator=false

#vivo oppo 等设备无法调试安装加入此配置，其他无需添加
android.injected.testOnly=false

#gradle 8.x版本，如果开启混淆功能请添加此属性
android.enableR8.fullMode=false
```

`SDK` 使用 API 版本信息 build.gradle 下

```groovy
android {
 buildToolsVersion = '30.0.3' // 仅为示例，具体版本根据项目情况自行配置
 compileSdkVersion = 31 // 仅为示例，具体版本根据项目情况自行配置

 defaultConfig {
 minSdkVersion 21 // 大于等于21即可
 targetSdkVersion 28 // 仅为示例，sdk支持28或以上版本，具体版本可根据渠道要求自行升级测试
 }
}
```

配置 Maven 库地址，在 `build.gradle` 文件的 `allprojects{repositories{}}` 块中引用

```groovy
google()
mavenCentral()
jcenter { url 'https://maven.aliyun.com/nexus/content/repositories/jcenter' }

//望舒库地址
maven {
 url 'http://60.205.123.114:8081/repository/maven-releases/'
 allowInsecureProtocol = true
}
// 备用地址 [可选]，凭据请向望舒商务或技术支持获取
maven {
 credentials {
 username 'YOUR_MAVEN_USERNAME'
 password 'YOUR_MAVEN_PASSWORD'
 }
 url 'https://packages.aliyun.com/maven/repository/2168735-release-Zcdy1x/'
}
```

在 `build.gradle` 文件的 android `{}` 块中引用中添加,`JavaVersion` 至少 `1.8` 以

sourceCompatibility 关系到你使用到的 Java 语法特性及库

sourceCompatibility 不能比 targetCompatibility 大

targetCompatibility 不能比目标客户端运行环境的 JavaVersion 大

targetCompatibility 不能比当前 Gradle 使用的 JavaVersion 大

```java
compileOptions {
    sourceCompatibility JavaVersion.VERSION_1_8
    targetCompatibility JavaVersion.VERSION_1_8
}
```

【可选】接入三方渠道时，需参照 [Android 渠道接入说明](/docs/开发者文档/三方服务/三方接入说明) 对应配置。

### 生命周期

直接继承 Application

游戏的 Application 直接继承 `com.ruixue.openapi.RXApplication` ，如下：

```java
import com.ruixue.openapi.RXApplication
public class GameApplication extends RXApplication{
    //....
}
```

间接调用 Application

```java
//注意非 Activity 的 onCreate
@Override
public void onCreate() {
    super.onCreate();
    RXSDK.onApplicationCreate(this);
}

@Override
protected void attachBaseContext(Context base) {
    super.attachBaseContext(base);
    RXSDK.attachBaseContext(base);
}
```

配置 app 启动 application ，在 AndroidManifest.xml 中 application 标签的 `android:name` 属性修改默认 application 关联，例如：

```xml
<application android:name=".GameApplication"></application>

 或 游戏没有自定义application，直接使用望舒默认application ，可省去 1、2步配置

 <application android:name="com.ruixue.openapi.RXApplication"></application>
```

配置 Activity 生命周期监听

自动监听生命周期， 继成自 LifecycleOwner 接口的 AppCompatActivity 等可使用此方式

```java
RXSDK.trackingLifecycle(this);
```

或手动调用：继承自 `Activity` 的页面使用下面方式。

```java
@Override
public void onCreate(Bundle savedInstanceState) {
    super.onCreate(savedInstanceState);
    RXSDK.onCreate(this);
}

@Override
public void onStart() {
    super.onStart();
    RXSDK.onStart(this);
}

@Override
public void onRestart() {
    super.onRestart();
    RXSDK.onRestart(this);
}

@Override
public void onResume() {
    super.onResume();
    RXSDK.onResume(this);
}

@Override
public void onPause() {
    super.onPause();
    RXSDK.onPause(this);
}

@Override
public void onStop() {
    super.onStop();
    RXSDK.onStop(this);
}
```

配置权限 、设备配置等监听

```java
@Override
public void onNewIntent(Intent newIntent) {
    super.onNewIntent(newIntent);
    RXSDK.onNewIntent(this, newIntent);
}

@Override
public void onActivityResult(int requestCode, int resultCode, Intent data) {
    super.onActivityResult(requestCode, resultCode, data);
    RXSDK.onActivityResult(this, requestCode, resultCode, data);
}

@Override
public void onConfigurationChanged(Configuration newConfig) {
    super.onConfigurationChanged(newConfig);
    RXSDK.onConfigurationChanged(this, newConfig);
}

@Override
public void onRequestPermissionsResult(int requestCode, String[] permissions, int[] grantResults) {
    super.onRequestPermissionsResult(requestCode, permissions, grantResults);
    RXSDK.onRequestPermissionsResult(this, requestCode, permissions, grantResults);
}
```

## SDK 初始化（必须）

初始化 SDK 时需传入 `productId`、`channelId`、`cpid`、`baseUrlList` 参数信息。

`productId`、`channelId` 在望舒游戏发行平台获取（创建产品或渠道），[查看使用说明](/docs/开发者文档/入门指南/准备工作)。

`cpid`、`baseUrlList` 在望舒企业管理后台获取（创建项目），[查看使用说明](/docs/开发者文档/入门指南/准备工作)。

初始化为异步调用，失败将不能使用 SDK 功能，请注意处理调用逻辑。

**接口原型**

```java
/**
* 使用配置初始化sdk
* @param config {@link RXSdkInitConfig}
*/
void initialize(RXSdkInitConfig config)
```

### RXSdkInitConfig参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| productId | String | 是 | 产品 id |
| channelId | String | 是 | 渠道 id |
| cpid | String | 是 | cpid |
| baseUrlList | `List<String>` | 是 | 请求域名队列 |
| initializeCallback | RXRequestCallback | 是 | 回调函数 |
| isLogEnable | boolean | 否 | 日志开关， true 默认开启， false 默认关闭 |
| usePrivacy | boolean | 否 | 首次启动是否展示用户隐私授权页面， true 展示， false 不展示，默认 true 展示 |
| agreementMap | `Map<String, String>` | 否 | 自定义协议键值对， key:00001 （ 00001 是示例，实际值是望舒协议 key ）或链接 value:《用户协议》 |
| agreementTitle | String | 否 | 协议标题，默认为 "用户协议和隐私政策" |
| isUseDNS | boolean | 否 | 是否打开， true 打开， false 关闭，默认为 false ，需配合[阿里 DNS SDK](/docs/开发者文档/DNS/阿里DNS/原生接入)或[腾讯 DNS SDK](/docs/开发者文档/DNS/腾讯DNS/原生接入)使用 |
| openRacing | boolean | 否 | 是否开启竞速， true 开启 false 关闭，默认 false ，详情查看 [openRacing 说明](#openracing-说明) |
| setActivity | Activity | 是 | 应用的主 Activity |

#### openRacing 说明

baseUrlList 数量为 1 时 不生效。

开启竞速模式：当 baseUrlList 有多个时，根据网络请求响应速度对数组进行排序，后续 SDK 内部网络请求根据排序后的数组使用对应域名。

关闭竞速模式：当 baseUrlList 有多个时， SDK 内部网络请求根据数组顺序使用对应域名。

**调用示例**

```java
String productId = "your_product_id";
String channelId = "your_channel_id";
String cpid = "your_cp_id";

// 配置多个备用域名，提高请求可靠性
List<String> baseUrlList = new ArrayList<>();
baseUrlList.add("https://api-prod.example.com"); // 主域名
baseUrlList.add("https://api-backup1.example.com"); // 备用域名1
baseUrlList.add("https://api-backup2.example.com"); // 备用域名2
RXSdkInitConfig rxSdkInitConfig = new RXSdkInitConfig(cpid, productId, channelId, baseUrlList, initCallback);

rxSdkInitConfig.setLogEnable(true);

//初始化sdk
RXSDK.initialize(rxSdkInitConfig);
```

### 支付

接入支付前，需要先阅读 [支付功能介绍](/docs/开发者文档/支付/功能介绍) 并完成 [服务端下单配置](/docs/开发者文档/支付/服务端接入/服务端-API)。

客户端根据支付渠道选择对应接入方案：

| 接入方式 | 适用场景 |
|---------|----------|
| 渠道支付 | 国内应用商店（华为、小米、OPPO、vivo、B站、应用宝等）及海外渠道（Google、微信App、支付宝App、银联等） |
| H5 支付 | 微信H5、支付宝H5、望舒收银台、PayerMax 等网页支付方式 |

:::tip
支付接入流程：**服务端创建订单 → 客户端调起支付 → 服务端验单**，客户端不直接处理支付结果，以服务端回调为准。
:::
