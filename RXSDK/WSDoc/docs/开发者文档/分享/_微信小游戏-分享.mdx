## 获取分享信息

此接口用于根据入参获取分享的具体数据，然后使用数据将配置的内容分享到各大媒体平台，以达到用户裂变的效果。数据内容与后台的埋点配置，策略配置相关


### JS

## 获取分享信息

:::tip
此接口用于根据入参获取分享的具体数据，然后使用数据将配置的内容分享到各大媒体平台，以达到用户裂变的效果。数据内容与后台的埋点配置，策略配置相关

:::

### 响应结构

| **字段** | **类型**                                                                                          | **说明**         |
| -------- | ------------------------------------------------------------------------------------------------- | ---------------- |
| code     | Number                                                                                            | 状态码 0 为成功  |
| msg      | String                                                                                            | 失败时的错误信息 |
| data     | `Data`   | 返回信息         |

### 获取分享数据Data

| **字段**  | **类型**                  | **说明**             |
| --------- | ----------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| trigger   | `Trigger`  | 埋点数据                                                                                                         |
| strategy  | `Strategy` | 策略数据                                                                                                         |
| content | `Content` |  |
| platforms | Platforms                                                                                             | 平台信息 值参考  `API` |
| platform  | String                                                                                                | 当前分享平台                                                                                                     |
| identity  | String                                                                                                | 平台标识                                                                                                         |
| transmits | String                                                                                                | 透传信息，传入 use_url_param=true 时， 将不使用短链接返回，而是将所有参数拼接到 url 中                                                                                                      |
| scheduling |  `Scheduling`                                                            | 分享调度配置埋点时返回                                                                                        |

#### 获取分享数据Trigger

| **字段**   | **类型** | **说明**                              |
| ---------- | -------- | ------------------------------------- |
| id         | Number   | 埋点id                                |
| tag        | String   | 埋点标识                              |
| title      | String   | 埋点标题                              |
| failed_msg | String   | 错误提示                              |
| type       | Number   | 类型 1:诱导 2:活动 3:成就 4:好友房 5:特殊分享埋点 |
| status       | Number   | 状态 1, 正常; -1, 禁用 |
| time_interval       | Number   | 触发间隔时间 |

#### 分享策略内容StrategyContent
| **字段**   | **类型** | **说明**                        |
| ---------- |--------|-------------------------------|
| id         | Number | 埋点id                          |
| strategy_id        | Number | 策略ID                          |
| content_type      | Number | 分享内容类型. 1:图片; 2:链接; 3:卡片; 4:落地页; 5:口令; 6:视频 |
| content_id | Number | 内容ID                          |
| weight       | Number | 权重            |
| title       | String | 标题                   |
| region       | String | 按地区配置的策略，如果存在，优先获取。 [望舒地区码列表](https://pan.jiaxianghudong.com/s/pdEzbPRkDS9)  |

#### 获取分享数据Content

**分享内容素材类型 Content.material_type**

| **标识**  | **备注**              |
|---------|---------------------|
| card    | `卡片`     |
| poster   | `海报`    |

#### 素材内容Card

| **字段**      | **类型** | **备注**                     |
| ------------- | -------- | ---------------------------- |
| title         | String   | 标题                         |
| material_type | String   | 素材类型，主要用于大数据上报 |
| material_id   | Number   | 素材ID，主要用于大数据上报   |
| image         | String   | 卡片的缩略图地址             |
| content       | String   | 卡片上显示的内容             |

> 示例： 此种素材主要应用于小程序分享。

| **字段**      | **类型** | **备注**                     |

| material_type | String   | 素材类型，主要用于大数据上报 |
| material_id   | Number   | 素材ID，主要用于大数据上报   |
| image         | String   | 海报背景图 url            |

| title     | string   | 否           | 分享卡片标题，若不传则取埋点对应卡片文案                                                                                                              |

:::

### 响应结构

| **字段** | **类型**                                                                                          | **说明**         |
| -------- | ------------------------------------------------------------------------------------------------- | ---------------- |
| code     | Number                                                                                            | 状态码 0 为成功  |
| msg      | String                                                                                            | 失败时的错误信息 |

### 获取分享数据Data

| **字段**  | **类型**                  | **说明**             |
| --------- | ----------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| trigger   | `Trigger`  | 埋点数据                                                                                                         |
| strategy  | `Strategy` | 策略数据                                                                                                         |
| content | `Content` |  |
| platforms | Platforms                                                                                             | 平台信息 值参考  `API` |
| platform  | String                                                                                                | 当前分享平台                                                                                                     |
| identity  | String                                                                                                | 平台标识                                                                                                         |
| transmits | String                                                                                                | 透传信息，传入 use_url_param=true 时， 将不使用短链接返回，而是将所有参数拼接到 url 中                                                                                                      |
| scheduling |  `Scheduling`                                                            | 分享调度配置埋点时返回                                                                                        |

#### 获取分享数据Trigger

| **字段**   | **类型** | **说明**                              |
| ---------- | -------- | ------------------------------------- |
| id         | Number   | 埋点id                                |
| tag        | String   | 埋点标识                              |
| title      | String   | 埋点标题                              |
| failed_msg | String   | 错误提示                              |
| type       | Number   | 类型 1:诱导 2:活动 3:成就 4:好友房 5:特殊分享埋点 |
| status       | Number   | 状态 1, 正常; -1, 禁用 |
| time_interval       | Number   | 触发间隔时间 |

#### 分享策略内容StrategyContent
| **字段**   | **类型** | **说明**                        |
| ---------- |--------|-------------------------------|
| id         | Number | 埋点id                          |
| strategy_id        | Number | 策略ID                          |
| content_type      | Number | 分享内容类型. 1:图片; 2:链接; 3:卡片; 4:落地页; 5:口令; 6:视频 |
| content_id | Number | 内容ID                          |
| weight       | Number | 权重            |
| title       | String | 标题                   |
| region       | String | 按地区配置的策略，如果存在，优先获取。 [望舒地区码列表](https://pan.jiaxianghudong.com/s/pdEzbPRkDS9)  |

| poster   | `海报`    |

| material_id   | Number   | 素材ID，主要用于大数据上报   |
| image         | String   | 卡片的缩略图地址             |

### 分享调度初始化

:::tip
如果在望舒后台开启了分享调度功能必须调用 分享调度初始化 接口，否则将无法正常使用分享调度功能
:::

#### **响应结构**

**响应示例**：

```json
{
    "code": 0,
    "msg":"",
    "data": "func1": {
        "scheduling_sign": "xx",
        "scheduling_type": "ad",
        "user_type": 1, // 1有效用户 2无效用户
    }
}
```

**响应参数（JSON）**
:::warning
未命中策略的埋点不返回
:::

| **参数**               | **类型** | **是否必填** | **备注**                                  |
| ---------------------- | -------- | ------------ | ----------------------------------------- |
| scheduling_sign    | String   | 是           | 调度分享看广告总次数                           |
| scheduling_type | String   | 是           | 分享 share 广告 ad |  
| user_type | Number   | 是           | 用户状态 1有效用户 2无效用户 |

## 获取分享信息

:::tip
此接口用于根据入参获取分享的具体数据，然后使用数据将配置的内容分享到各大媒体平台，以达到用户裂变的效果。数据内容与后台的埋点配置，策略配置相关

:::

### 响应结构

| **字段** | **类型**                                                                                          | **说明**         |
| -------- | ------------------------------------------------------------------------------------------------- | ---------------- |
| code     | Number                                                                                            | 状态码 0 为成功  |
| msg      | String                                                                                            | 失败时的错误信息 |
| data     | `Data`   | 返回信息         |

### 获取分享数据Data

| **字段**  | **类型**                  | **说明**             |
| --------- | ----------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| trigger   | `Trigger`  | 埋点数据                                                                                                         |
| strategy  | `Strategy` | 策略数据                                                                                                         |
| content | `Content` |  |
