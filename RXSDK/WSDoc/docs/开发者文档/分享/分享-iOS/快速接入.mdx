## 获取分享信息

**接口原型**

```objectivec
/**
 * 获取分享信息 New
 * @param func 埋点标识 必须
 * @param platform 分享平台 wechat
 * @param region 地区码 非必须
 * @param transmits 透传参数，原样返回， 请使用key=value形式，并对值使用urlencode，返回时会原样返回 非必须
 * @param ext 扩展字段，拼接url用 非必须
 * @param readCache 是否读取缓存，YES 读取缓存 NO 不读取缓存，默认不取缓存
 */
- (void)getShareInfoWithFunc:(NSString *)func
 platform:(NSString *)platform
 region:(NSString *)region
 transmits:(NSString * _Nullable)transmits
 ext:(NSDictionary * _Nullable)ext
 readCache:(BOOL)readCache
 complete:(RequestComplete)complete;
```

### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| func | NSString | 是 | 埋点标识 |
| platform | NSString | 是 | 分享平台 |
| region | NSString | 否 | 地区码。 [望舒地区码列表](https://pan.jiaxianghudong.com/s/pdEzbPRkDS9) |
| transmits | NSString | 否 | 透传参数，原样返回， 请使用 key=value 形式，并使用 urlencode 编码，此数据在落地页中可以通过 key 获取到，示例： `"a=b&c={\"d\":\"e\"}"` |
| ext | NSDictionary | 否 | 扩展字段， SDK 会将 ext 中的 key/value 拼接在回调数据的 url 字段中 |
| readCache | BOOL | 否 | 是否读取缓存， YES 读取缓存 NO 不读取缓存，默认不取缓存 |
| setCustomExt | NSDictionary | 否 | cp 自定义数据，目前仅用于大数据预置事件透传参数场景 |
| useShortUrl | BOOL | 否 | 是否使用短链，默认 NO |

> setCustomExt 结构说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| bigdata_ext | NSDictionary | 否 | 大数据预置属性透传参数 |

> [platform 说明](/docs/开发者文档/意见反馈/Unity-接入)

> ext 结构说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| protocol_ios | NSString | 否 | iOS 唤醒协议 |
| protocol_android | NSString | 否 | 安卓唤醒协议 |
| use_scheme | NSString | 否 | 由 cp 控制是否使用游戏协议，如传 0 则在落地页上操作不会尝试打开应用，直接跳转到对应商店，如传 1 则会尝试打开应用 |

**调用示例**

```objectivec
RXShareConfig *config = [[RXShareConfig alloc] init];
config.func = @"埋点";
config.platform = @"wechat";
config.androidScheme = @"";
config.iOSScheme = @"";

// 【可选】大数据预置属性透传参数
config.setCustomExt = @{@"bigdata_ext" : @{@"a" : @"b"}};

// config.properties = @{@"key" : @"value"};
// NSString *transmits = @"use_url_param=true";
// config.transmits = [transmits stringByAddingPercentEncodingWithAllowedCharacters:[NSCharacterSet URLQueryAllowedCharacterSet]];

[[RXSDK sharedSDK] getShareInfoWithConfig:config complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {

}];
```

### 分享调度

当埋点配置了分享调度后，诱导类分享会根据分享调度策略决定用户是分享还是广告， 分享成功或者失败， 返回值中会增加 scheduling 对象，值如下：

**scheduling_event** 分享结果仅代表根据望舒后台设置的成功率计算的结果，不表示实际的分享结果。**scheduling_event** 是在拉起分享前的预算的结果，三方平台的分享机制不同，建议根据平台处理实际结果。

例如：**微信** 的机制是用户点击 **关闭、取消** 都算 **分享成功**，而 **Facebook** 有真实的回调，用户点击 **关闭、取消** 会返回 **取消分享** 结果。

#### 获取分享调度Scheduling

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| scheduling_type | String | 值为 ad 时为广告， share 时为分享。 |
| scheduling_sign | String | 调度策略当前可分享看广告总数密文, 需用 aes 解密，使用 cpkey 作为 key。 |
| 解出值转为字符串， 格式: "type=share&count=10&uuid=xxx&ts=1695796034&ddid=a" [详情](/docs/开发者文档/意见反馈/Unity-接入) | scheduling_event | Number |
| 1 分享成功 -1 分享失败 | scheduling_failed_msg | String |
| 分享失败时的信息 |  |  |

##### scheduling_sign对应标识

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| type | String | 值为 ad 时为广告， share 时为分享。 |
| count | Number | 调度策略当前可分享看广告总数 |
| uuid | String | 唯一标识 |
| ts | Number | 时间戳 |
| ddid | String | 调度标识 |

## 拉起分享

**RXSDK_Pure**只提供系统分享，其他分享方式参考三方服务。

**一键分享**的分享素材需要在望舒后台进行配置 [查看使用说明](/docs/开发者文档/数据分析/服务端接入/上报插件-LogBus-使用指南)。

**接口原型**

```objectivec
/**
 * 一键分享
 * @param config 分享配置
 */
- (void)share:(RXShareConfig *)config
 complete:(RequestComplete)complete;

/**
 * 自定义分享
 * @param config 分享配置
 */
- (void)shareCustom:(RXCustomShareConfig *)config
 complete:(RequestComplete)complete;
```

**调用示例**

```objectivec
/**
 * 一键分享
 */
RXShareConfig *config = [[RXShareConfig alloc] init];
config.func = @"望舒后台创建的埋点";
config.platform = @"wechat";
[[RXSDK sharedSDK] share:config complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
 if (!error) {
 NSLog(@"分享成功");
 } else {
 NSLog(@"分享失败");
 }
}];

/**
 * 自定义分享
 */
RXCustomShareConfig *config = [[RXCustomShareConfig alloc] init];
config.platform = @"wechat";
config.url = @"http://
config.title = @"title";
config.content = @"content";
config.materialType = @"link";
config.shareScene = 1;
config.thirdAppid = @"wx123123123"; // 微信 appid 为示例，需要根据分享平台传不同的 appid

[[RXSDK sharedSDK] shareCustom:config complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
 if (!error) {
 NSLog(@"分享成功");
 } else {
 NSLog(@"分享失败");
 }
}];
```

## 分享/广告结果上报

如果在望舒后台开启了分享调度功能，在上报时需要将调用 获取分享信息 时的 func、platform、region、transmits 传入。

不使用分享调度只需传入 scheduling_event 即可， properties 按需传入，如果不需要上报自定义数据可传 nil

**接口原型**

```objectivec
/**
 * 分享/广告结果上报
 * @param func 埋点标识 必须
 * @param platform 分享平台 wechat
 * @param region 地区码 非必须
 * @param transmits 透传参数，原样返回， 请使用key=value形式，并对值使用urlencode，返回时会原样返回 非必须
 * @param scheduling_event 上报结果 YES 成功 NO 失败
 * @param scheduling_type 上报类型 ad 广告 share 分享
 * @param properties 自定义属性
 */
- (void)shareSchedulingReportWithFunc:(NSString *)func
 platform:(NSString *)platform
 region:(NSString *)region
 transmits:(NSString * _Nullable)transmits
 scheduling_event:(BOOL)scheduling_event
 scheduling_type:(NSString *)scheduling_type
 properties:(NSDictionary * _Nullable)properties
 complete:(RequestComplete)complete;
```

### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| func | String | 是 | 埋点标识 |
| platform | String | 是 | 分享平台 |
| region | String | 否 | 地区码 。 [望舒地区码列表](https://pan.jiaxianghudong.com/s/pdEzbPRkDS9) |

| scheduling_type | String | 是 | 上报类型 ad 广告 share 分享 |

| --- | --- | --- | --- |
| system | 真实回调 | 无法区分取消、失败，统一返回分享失败回调 | 无法区分取消、失败，统一返回分享失败回调 |
| wechat | 跳转到微信后点击 取消、关闭、分享 都返回成功回调 | 无失败回调 | 无取消回调 |
| facebook | 真实回调 | 真实回调 | 真实回调 |

| tiktok | 真实回调 | 真实回调 | 真实回调 |

## 获取自动重定向短链接

如果拼接后的分享链接过长，可使用此接口获取自动重定向短链接。

**接口原型**

```objectivec
/**
 * 获取自动重定向短链接
 * @note 仅作为生成短链接使用
 * @param url 要生成短链接的url
 */
- (void)getShortUrl:(NSString *)url
 complete:(RequestComplete)complete;

/**
 * 获取自动重定向短链接
 * @note 支持生成可以解析 og 标签（图片、标题、描述）的短链接
 * @note og 标签常用场景为三方平台通过链接中的 开放协议 解析展示的缩略图、标题、描述等，具体说明：https://cloud.tencent.com/developer/article/1820467
 * @param url 要生成短链接的url
 * @param title 标题
 * @param content 描述
 * @param image 图片地址
 * @param ext 透传参数
 */
- (void)getShortUrl:(NSString *)url
 title:(NSString *)title
 content:(NSString *)content
 image:(NSString *)image
 ext:(NSDictionary *)ext
 complete:(RequestComplete)complete;

```

### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| funcs | NSArray | 是 | 埋点数组，传空获取所有埋点调度 |

```objectivec
/**
 * 获取自动重定向短链接
```
