如果在望舒后台开启了分享调度功能，必须调用分享调度初始化接口，否则将无法正常使用分享调度功能。

## 分享调度初始化

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

**接口原型**

```objectivec
/**
 * 分享调度初始化
 * @param funcs 埋点数组，传空获取所有埋点调度
 */
- (void)shareSchedulingInitWithFuncs:(NSArray *)funcs
 complete:(RequestComplete)complete;
```

**调用示例**

```objectivec
[[RXShareService sharedSDK] shareSchedulingInitWithFuncs:@[@"maidian"] complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
 NSLog(@"");
}];
```

</TabItem>

<TabItem value="android" label="Android">

**接口原型**

```java
void shareSchedulingInit(@NonNull Map<String, Object> hashMap, RXJSONCallback callback)
```

**调用示例**

```java
Map<String, Object> m = new HashMap<>();
m.put("funcs", Arrays.asList("func1","func2"));
RXSdkApi.getInstance().shareSchedulingInit(m, jsonCallback);
```

</TabItem>

</Tabs>

### 初始化参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| funcs | Array | 是 | 埋点数组，传空获取所有埋点调度 |

### 响应参数（JSON）

未命中策略的埋点不返回

| 参数 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| scheduling_sign | String | 是 | 调度分享看广告总次数 |
| scheduling_type | String | 是 | 分享 share 广告 ad |
| user_type | Number | 是 | 用户状态 1 有效用户 2 无效用户 |

**响应示例**

```json
{
 "code": 0,
 "msg": "",
 "data": {
 "func1": {
 "scheduling_sign": "xx",
 "scheduling_type": "ad",
 "user_type": 1
 }
 }
}
```

## 获取埋点调度

分享调度初始化后 SDK 会将数据缓存，客户端需要使用时可以调用获取埋点调度来获取需要的埋点调度数据，无需再次初始化。需要在登录后调用。

<Tabs groupId="platform">

<TabItem value="ios" label="iOS">

**接口原型**

```objectivec
/**
 * 获取埋点调度
 * @param funcs 埋点数组，传空获取所有埋点调度
 */
- (void)getShareSchedulingWithFuncs:(NSArray *)funcs
 complete:(RequestComplete)complete;
```

**调用示例**

```objectivec
[[RXShareService sharedSDK] getShareSchedulingWithFuncs:@[] complete:^(NSDictionary * _Nullable response, RX_CommonRequestError * _Nullable error) {
 NSLog(@"");
}];
```

</TabItem>

<TabItem value="android" label="Android">

**接口原型**

```java
Map<String, Object> getShareScheduling(String... func)
```

**调用示例**

```java
String[] funcs = new String[]{"func1", "func2"};
RXSdkApi.getInstance().getShareScheduling(funcs);
```

</TabItem>

</Tabs>

### 响应参数（JSON）

| 参数 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| scheduling_sign | String | 是 | 调度分享看广告总次数 |
| scheduling_type | String | 是 | 分享 share 广告 ad |
| user_type | Number | 是 | 用户状态 1 有效用户 2 无效用户 |

**响应示例**

```json
{
 "func1": {
 "scheduling_sign": "xx",
 "scheduling_type": "ad",
 "user_type": 1
 },
 "func2": {
 "scheduling_sign": "xx",
 "scheduling_type": "ad",
 "user_type": 1
 }
}
```
