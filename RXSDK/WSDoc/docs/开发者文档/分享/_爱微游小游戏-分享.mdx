## 拉起分享

### 参数说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| params | IShareData | 是 | 参数 |
| callback | IMethodParams | 是 | 回调函数集合 |

> IShareData 说明

| 字段 | 类型 | 是否必填 | 备注 |
| --- | --- | --- | --- |
| query | string | 否 | 查询字符串，必须是 key1=val1&key2=val2 的格式。 |

> IMethodParams 说明

| 字段 | 备注 |
| --- | --- |
| complete | (data) => void |

complete ：为函数且必传， data 为结果数据

**调用示例**

```javascript
sdk.share({
 query: 'a=1&b=2'
}, {
 complete(data) {
 console.log(data)
 }
})
```
