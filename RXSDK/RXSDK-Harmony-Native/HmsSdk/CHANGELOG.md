# 瑞雪 SDK 变更日志

## 重要提示
使用瑞雪 SDK 时，需确保 SDK 版本与团结引擎版本和变更日志中的版本信息对齐。若使用低版本出现报错情况，需自行进行兼容处理。

## v2.4.4 - 2025-02-13
### 开发环境要求
- 团结引擎：升级至 1.4.2 或更高版本。
- DevEco Studio：升级至 5.0.7 Release 或更高版本。
- OpenHarmony API：使用 12 或更高版本。

### 功能更新
团结引擎的 SendCaptcha API 现已支持图形验证码验证，提升了验证码验证的安全性与多样性。

## v2.4.3 - 2025-02-11
### 开发环境要求
- 团结引擎：升级至 1.4.2 或更高版本。
- DevEco Studio：升级至 5.0.7 Release 或更高版本。
- OpenHarmony API：使用 12 或更高版本。

### 功能更新
在 SDK 初始化过程中，新增了通过开关控制是否自动弹出剪贴板权限申请的功能。默认设置为自动弹出，用户选择允许或拒绝后，后续不再弹出该权限申请窗口；若选择本次允许每次都弹出，则每次初始化时都会弹出。

- DevEco Studio：升级至 5.0.5 Release 或更高版本。

### 功能更新
登录功能得到增强，支持上报设备型号和设备网络类型，便于开发者更精准地了解用户使用环境。

## v2.4.1 - 2025-01-24
### 开发环境要求

- DevEco Studio：升级至 5.0.5 Release 或更高版本。

- **新增碰一碰分享功能**：增强了游戏内容的分享能力，用户可以通过碰一碰的方式快速分享游戏内容，提升了社交传播效率。

## v2.3.4 - 2024-10-25
### 开发环境要求
- 团结引擎：升级至 1.3.2 版本。
- DevEco-Studio：升级至 5.0.3.900 release 或更高版本。
- OpenHarmony API：使用 12 或更高版本。

### 功能更新
- **关联授权优化**：当关联授权取消时，系统会自动调用华为解绑接口，用户可返回上一级重新选择转移或关联操作，优化了授权流程。
- **新增登录方式**：支持游戏官方账号登录，为用户提供了更多的登录选择。

## v2.3.2 - 2024-10-25
### 开发环境要求
- 团结引擎：升级至 1.3.1 版本。
- DevEco-Studio：升级至 5.0.3.900 或更高版本。
- OpenHarmony API：使用 12 或更高版本。

### 功能更新
- **联合登录参数扩展**：联合登录 `UnionLoginArgs` 新增 `ext` 参数支持，开发者可以使用该参数传递自定义参数，增强了联合登录的灵活性。
- **二次登录优化**：当 `UnionLoginArgs` 的 `ext` 自定义参数中包含 `method` 和 `login_openid` 参数时，系统会优先尝试瑞雪二次登录；若登录报错，则自动拉起联合登录窗口，提升了登录的成功率和用户体验。

### 开发环境要求
- 团结引擎：升级至 1.3.1 版本。
- DevEco-Studio：升级至 5.0.3.900 或更高版本。
- OpenHarmony API：使用 12 或更高版本。

### 功能更新

## v2.0.3 - 2024-10-15
### 开发环境要求
适配团结引擎 1.2.6 及以下版本。

### 功能更新
登录返回数据中新增 `binding` 标识，当该标识值为 `true` 时，表示该账号是华为关联账号，方便开发者进行账号类型区分。

## v2.0.1 - 2024-09-14
### 功能更新
- **新增功能模块**：新增用户中心、帮助中心和游戏官方登录 UI，完善了用户服务和登录体验。
- **审核支持**：针对审核需求，支持 `UnionLogin` 登录接口，满足了不同场景下的登录需求。
